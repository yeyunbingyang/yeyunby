# 资源库说明

资源库用于收集工具、素材、课程、网站、AI 平台和外部参考。这里保存“可调用的外部资源”，不保存已经加工完成的知识结论。

## 目录说明

- `00 Github优质项目/`：GitHub 优质开源项目收集。

- `01-软件工具/`：开发工具、效率工具、系统工具、插件和软件清单。
- `02-课程索引/`：技术课程、语言课程、商业课程和系统学习路径。
- `03-网站导航/`：常用网站、文档站、社区、资料库和导航页。
- `04-素材库/`：图片、封面、图表、数据、案例、提示词素材。
- `05-AI工具/`：AI 工具、模型平台、AI 创作工具、Prompt 案例和前沿资讯。

## 使用规则

- 只收集值得再次使用的资源。
- 每条资源尽量写清“用途”和“适用场景”。
- 学到的结论迁移到 `02-Knowledge/`。
- 可复用流程迁移到 `02-Knowledge/`，并使用 `SOP` 或 `方法论` 标签。
- 产出成果记录到相关知识笔记或 `01-日常流(日常流层)/`。
