# 本机软件与绿色软件清单

> [!info] 盘点范围
> 读取了 Windows 开始菜单、公共桌面、当前用户开始菜单中的 `.lnk/.url`，并交叉读取卸载注册表。系统组件、驱动、运行库、卸载项和重复入口已排除。版本以 2026-08-02 本机状态为准。

## Grill-me 自问自答与规划结论

**问：是否要把注册表里的每个条目都列出来？**  答：不要。SDK、CUDA 子包、ASUS 服务等不是用户直接使用的软件，应归入“环境组件”，否则清单失去可读性。

**问：什么算绿色软件？**  答：快捷方式存在但注册表没有对应卸载项，或目标位于用户自定义目录的程序，标记为“疑似绿色/便携”，不凭名称武断判断。

**问：官网和 GitHub 都找不到怎么办？**  答：官网优先；无官方 GitHub 的商业软件填“—”，不使用第三方下载站作为官网替代。

**问：这份清单下一步如何维护？**  答：新增软件时补一行并填写盘点日期；卸载软件改为 `归档` 或移至历史区，不直接删除记录。

## 疑似绿色/便携软件与待确认项

以下条目在快捷方式或桌面中出现，但无法仅凭当前盘点确认是否便携版；建议下一步读取 `.lnk` 的 `TargetPath` 并检查目标目录是否存在卸载注册表项：`JVS Claw`、`Flix`、`Hermes`、`Kimi`、`Nightly Private Browsing`、`UU远程`、`WorkBuddy`、`OpenList-Desktop`、`闪电藤`、`绿联云`、`AULA F108Pro 三模机械键盘`、`RESP`。

## 维护

- 盘点脚本来源：Windows PowerShell `Get-ChildItem`（快捷方式）与卸载注册表三处路径。
- 本表只记录可启动应用；CUDA、Java、Python、Visual Studio、Windows SDK 等环境组件建议另建“开发环境基线”笔记。
- 官网链接优先采用厂商域名；开源项目同时记录 GitHub 仓库。Clash Verge Rev 的项目仓库已通过网页搜索核验：<https://github.com/clash-verge-rev/clash-verge-rev>。
