**WatermarkImage** 是一款轻量级的图片加水印工具，主要用于批量为图片添加文字或图片水印，适合设计师、摄影师或内容创作者快速处理素材。以下是它的详细介绍👇

------

### 🧩 一、软件简介

- **名称**：Watermark Image
- **类型**：图片加水印工具
- **支持系统**：Windows（常见绿色便携版）
- **用途**：为图片批量添加文字或图像水印，可自定义字体、透明度、位置、旋转角度等。

------

### 💡 二、主要功能

| 功能             | 说明                                                       |
| ---------------- | ---------------------------------------------------------- |
| ✅ **批量处理**   | 支持一次性给多张图片添加相同的水印。                       |
| 🖋 **文字水印**   | 自定义字体、大小、颜色、阴影、透明度、旋转角度。           |
| 🖼 **图片水印**   | 支持 PNG 透明图片作为水印，可设置缩放比例和位置。          |
| 🧭 **位置控制**   | 支持九宫格定位（左上、右上、居中等）或自定义坐标。         |
| 🌈 **透明度调节** | 让水印更自然地融合到原图。                                 |
| ⚙️ **输出设置**   | 可选择输出目录、重命名规则、图片格式（JPG、PNG等）和质量。 |

------

### 🎨 三、使用步骤

1. **打开程序**
    解压运行 `WatermarkImage.exe`（无需安装）。
2. **添加图片**
    点击「Add Images」或直接拖入多张图片。
3. **设置水印**
   - 选择「Text Watermark」或「Image Watermark」模式。
   - 设置文字或图片样式、位置、透明度等。
4. **输出设置**
    选择输出文件夹与文件格式。
5. **点击 Start**
    批量生成带水印图片。

------

### ⚡ 四、特点优势

- 绿色免安装，体积小（约2MB）。
- 操作简洁，适合快速批量处理。
- 保留原图质量，可自定义输出路径。
- 稳定性好，兼容主流图片格式（JPG、PNG、BMP、TIFF）。

------

### 🧰 五、常见使用场景

- 电商店铺主图加品牌 Logo；
- 摄影作品加版权水印；
- 微信公众号或网站素材统一标识；
- 企业批量生成带 Logo 的宣传图。
