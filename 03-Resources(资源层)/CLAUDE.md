## 01-软件工具 组织规范

每个软件目录下统一二分：

```
软件分类/
└── 某软件/
    ├── 软件/      ← 安装包（.exe/.7z/.zip），被 .gitignore 排除
    └── 资料/      ← 软件说明.md + 截图(assets/) + 教程/文案
```

- `软件说明.md` 必须包含：软件名称、用途、版本、来源链接
- 多版本时在 `软件/` 下按版本建子目录
- `软件/` 目录下的任何文件都不进 Git

## 关联 Skills

- **撰写软件说明/教程**：使用 `write` Skill 润色
- **整理目录结构**：使用 `Obsidian-Agent操作指南` 中的 CLI 命令
- **调研软件评价**：使用 `agent-reach` 搜索小红书/知乎评测
- **生成小红书图文**：使用 `write` + 软件说明.md 生成文案

## 新软件入库流程

1. 确定软件属于哪个分类
2. 在对应分类下创建 `某软件/` 目录
3. 创建 `资料/软件说明.md`（名称、版本、用途、来源）
4. 安装包放入 `软件/` 目录（自动被 .gitignore 排除）
5. 截图放入 `资料/assets/`
6. 更新 `软件工具-MOC.md` 索引
