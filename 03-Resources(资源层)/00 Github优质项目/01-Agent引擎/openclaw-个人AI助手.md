# OpenClaw 个人AI助手

https://github.com/openclaw/openclaw

**类型：** 工具（个人AI助手）

**语言：** TypeScript
**许可证：** MIT

## 是什么

OpenClaw 是 GitHub 排名第一的**个人 AI 助手**。运行在你自己设备上，通过你已经在用的消息渠道回复你——WhatsApp、Telegram、Slack、Discord、微信、QQ、iMessage、Signal 等 20+ 渠道。支持 macOS/iOS/Android 语音交互，可渲染实时 Canvas。

## 适用场景

- 个人全渠道 AI 助手（消息+语音+Canvas）
- 自部署——数据不出本机
- 与 OpenHuman 互补：OpenHuman 做知识记忆，OpenClaw 做多渠道触达

## 评价

- **优点**：374k Stars 断层第一、20+ 渠道覆盖极广、MIT 开源、个人部署友好
- **局限**：配置复杂（需自部署 Gateway）、非编程专用 Agent
- **是否值得长期保留**：✅ 关注——最高 Star 的个人 AI 助手项目
