# book-to-skill 技术书籍转 Claude Code 技能

> [!abstract] 一句话定位
> 把任意技术书籍 PDF 转换成 Claude Code 技能，边工作边学习、查阅、使用书中的知识。

## 解决的问题

技术书籍的知识通常躺在 PDF 里，Agent 工作时"用不上"。book-to-skill 把书籍内容封装成 Agent 可直接调用的 Skill，让书变成工作时可引用的能力，而不是只被"读过"。

## 为什么值得研究（⭐⭐⭐⭐⭐）

- **最适合"知识库 → Skill"的路径**：正好承接个人知识库的沉淀——把已有 PDF 资产变成可执行的 Agent 技能。
- 与本仓库其他技能项目（cangjie-skill、mattpocock/skills）形成"内容蒸馏"的完整链路。

## 在「资料 → Skill → Memory → Agent」体系中的位置

**知识蒸馏环节**：输入原始资料（书籍 PDF），输出可执行 Skill。是这条链路里"把书变成能力"的直接实现。
