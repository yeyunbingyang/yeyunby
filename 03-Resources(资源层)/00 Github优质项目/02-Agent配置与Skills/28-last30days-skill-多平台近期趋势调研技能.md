# last30days-skill 多平台近期趋势调研技能

## 项目定位

`/last30days` 是面向 AI Agent 的近期趋势调研 Skill，聚合多个社区、视频、新闻与预测市场来源，侧重“最近人们正在讨论什么”。

## 安装

Codex、Cursor、Gemini CLI 等兼容 Agent Skills 的宿主：

```bash
npx skills add mvanhorn/last30days-skill -g
```

Reddit、HN、Polymarket 和 GitHub 可零配置使用；X、YouTube、TikTok 等渠道需要按向导配置相应后端或凭据。

## 注意事项

- 点赞、播放量和市场赔率代表关注度，不等于事实正确。
- 社交平台内容应与官方资料、一手数据交叉验证。
- 登录 Cookie、API Token 和抓取内容需遵守平台条款及隐私要求。
