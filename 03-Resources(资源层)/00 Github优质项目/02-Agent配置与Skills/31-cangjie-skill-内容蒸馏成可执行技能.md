## 解决的问题

书、长视频、播客是高价值但"不可执行"的原始内容。cangjie-skill 把它们蒸馏成 Agent Skills，解决"内容看过就忘、Agent 用不上"的问题，把学习资产转化为可复用能力。

## 为什么值得研究（⭐⭐⭐⭐⭐）

- **覆盖多模态内容**：不仅限 PDF（书籍/长视频/播客），比 book-to-skill 覆盖面更广。
- **贴合"内容 → 可执行知识"的研究主线**：适合把日常收集的课程、视频、播客统一转成个人技能库。
- 展示一套可复用的"知识蒸馏 → Skill 生成"方法论。

## 在「资料 → Skill → Memory → Agent」体系中的位置

**知识蒸馏环节**：与 book-to-skill 同环节、更广义的实现——统一把各类内容蒸馏成 Skill，是体系链路的入口工序。
