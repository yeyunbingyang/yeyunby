# AG Kit Antigravity Agent 工程套件

## 项目定位

AG Kit 安装一套完整的 `.agents/` 工作区约定，主要生产运行时是 Google Antigravity。

## 核心能力

- 规则、Skills 与工作流发现。
- 20 种专家角色和智能路由。
- 持久记忆与上下文压缩指导。
- `/coordinate`、`/orchestrate` 等编排流程。
- MCP 配置与备份感知的同步辅助。
- 针对高置信度破坏性命令的 `PreToolUse` 安全门。

## 注意事项

- 其他 Agent 可读取其 Markdown 组件，但官方不保证 Antigravity 之外的运行行为。
- 安全钩子只拦截有限的高风险模式，不能替代权限、沙箱、工作区信任和人工审批。
