## 是什么

GitHub 官方的 **Spec-Driven Development** 工具包。核心理念：规格不再只是代码的脚手架，而是可执行的——直接生成工作实现。用 `specify init my-project --integration copilot` 初始化，让 AI Agent 按规格严格生成代码，避免 vibe coding。

## 适用场景

- 需要严格规格驱动的团队项目
- 与 GitHub Copilot 深度集成
- 与 superpowers 互补：superpowers 偏对话式流程，spec-kit 偏规格文档驱动

## 评价

- **优点**：GitHub 官方出品、MIT 开源、Copilot 原生集成
- **局限**：需要学习 `specify` CLI 工具链
- **是否值得长期保留**：✅ 关注
