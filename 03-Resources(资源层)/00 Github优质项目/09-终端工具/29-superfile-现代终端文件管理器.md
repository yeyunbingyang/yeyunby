# superfile 现代终端文件管理器

## 项目定位

superfile 用 TUI 界面在终端中完成文件浏览与常见操作，适合希望保留键盘工作流、又需要比传统命令更直观界面的用户。

## 安装

```powershell
winget install --id yorukot.superfile
```

也可使用 Scoop 或官方安装脚本。执行远程脚本前应先阅读脚本内容。

## 核心特点

- 跨 Windows、macOS 与 Linux。
- 支持快捷键、主题、插件和常见文件操作。
- Go 编写，提供预编译版本和源码构建方式。
