# reverse-skill 逆向/渗透/安全技能路由包

> [!abstract] 一句话定位
> 面向逆向工程、授权渗透与安全研究的 Agent Skill 路由包——AI 自动路由到合适技能、按需自举工具链、经验库自动进化。

| 支持客户端 | Claude Code、Kiro、Cursor、Cline 等 AI 编码客户端 |

## 核心能力

- **AI 自动路由**：根据任务自动选择对应安全技能，而非让用户手动挑选。
- **按需自举工具链**：用到时才安装/加载所需工具，降低初始配置成本。
- **自动进化经验库**：每次操作沉淀经验，形成自我更新的知识库。

## 为什么值得研究（⭐⭐⭐⭐⭐）

- **"逆向 + Agent + Skills"三者结合**：既是安全研究者的利器，也是"技能路由包"这种 Agent Skill 组织模式的优秀范本。
- 展示安全技能如何模块化、自动路由、自进化——这套机制可迁移到其他垂直领域（渗透、逆向、漏洞研究）。
- 与个人自动化/逆向研究兴趣高度重合。

## 在「资料 → Skill → Memory → Agent」体系中的位置

**Skill 环节**：体现"技能包"的组织形态——按领域封装 + 路由分发 + 经验回写（回写即 Memory 环节）。是体系里"Skill 自进化"的参考实现。
