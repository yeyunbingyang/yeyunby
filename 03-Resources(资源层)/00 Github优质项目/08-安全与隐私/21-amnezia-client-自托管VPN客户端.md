# Amnezia VPN 自托管 VPN 客户端

## 项目定位

Amnezia VPN 是跨平台开源客户端，可根据服务器 IP、SSH 用户和密码自动部署 Docker 化 VPN 服务并建立连接。

## 核心特点

- 支持 Windows、macOS、Linux、Android 和 iOS。
- 支持 OpenVPN、WireGuard、IKEv2、AmneziaWG、XRay 等协议。
- 提供 Cloak、Shadowsocks 等流量混淆方案。
- 支持按网站或应用进行分流。

## 注意事项

- 使用前应核对所在地法律、网络服务条款和组织安全规定。
- SSH 凭据和 VPN 配置属于高敏感信息，应保护本地配置与服务器权限。
- 自托管提高控制力，但服务器 IP、运维安全和可用性仍由使用者负责。
