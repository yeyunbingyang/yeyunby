# 学习方法论

学习本身是一门技能，可以系统优化。核心目标：用更少的时间，建立更深刻、更持久的理解。

## 学习流程

```
输入（获取原材料）
    ↓
加工（理解与联结）
    ↓
输出（巩固与应用）
    ↓         ↑
间隔复习 ──→ 复盘（反馈修正）
```

## 核心方法

### 主动提取练习（Testing Effect）
- **原理**：提取练习比重复阅读强 2-3 倍，因为提取本身强化记忆痕迹
- **实践**：读完合上书回忆、自测、做题、向别人解释
- **工具**：Anki（间隔重复）、纸上脑图、提问列表

### 间隔重复（Spaced Repetition）
- **原理**：利用遗忘曲线，在即将忘记前复习，效率最高
- **间隔公式**：1天 → 3天 → 7天 → 21天 → 60天
- **工具**：Anki（SM-2算法自动计算最优复习间隔）
- **注意**：卡片粒度要小，一张卡一个概念

### 费曼技巧
1. 选择一个概念
2. 用简单语言向外行解释（假设对象是 12 岁孩子）
3. 找到解释卡壳的地方 → 返回原材料补充
4. 简化术语，用类比打通

### 交错练习（Interleaving）
- **原理**：混合多种主题练习，比单一集中训练长期记忆更好
- **代价**：短期感觉低效（实际是深度加工）
- **应用**：数学题目混合类型、语言学习混合语法场景

### 精细追问（Elaborative Interrogation）
- 对每个知识点问"为什么？""怎么做到的？""有什么例外？"
- 建立知识间的联结，而非孤立记忆

### 复盘（Structured Retrospective）
- **原理**：结构化反思将经验转化为可复用的教训——复盘是经验学习的加速器
- **方法**：KPT（日/周轻量持续改进）、GRAI（阶段目标复盘）、PDCA（系统级元复盘）
- **实践**：详见 [[复盘指南]]，对应模板 [[日记-模板]]、[[周复盘-模板]]、[[阶段规划-模板]]
