# 生活基础设施

支撑一切高效工作与持续成长的底层系统——身体、数字工具、财务和个人能量。这些是"元技能"，投资回报率极高。

## 学习路径

`健康基础（睡眠→运动→饮食）` → `数字工具整合` → `财务系统建立` → `兴趣技能培养`

## 核心知识点

### 健康与体能
- **睡眠（最高优先级）**
  - 成人需 7-9 小时；固定作息时间比总时长更重要
  - 睡眠债无法通过"补觉"完全偿还
  - 优化：黑暗/凉爽环境、睡前 1h 无屏幕、固定起床时间

- **运动**
  - 有氧运动（每周 150min）：提升认知、情绪和睡眠质量
  - 力量训练（每周 2-3次）：维持肌肉量、改善代谢
  - 复利原则：每天 30min 运动，十年后的身体是两倍的资产

- **饮食**
  - 减少超加工食品（包装食品中含量最高的成分）
  - 足量蛋白质摄入（0.8-1.6g/kg 体重/天）
  - 不需要完美，需要可持续的 80% 健康习惯

### 数字生活管理
- **信息管理**：RSS 订阅 + 定期清理；区分"重要信息"和"娱乐内容"
- **设备整洁**：桌面无图标；应用按使用频率分文件夹；定期清理不用APP
- **数字安全**：密码管理器（1Password/Bitwarden）；重要账户开二步验证；定期备份
- **时间使用**：屏幕时间统计；社交媒体使用限制；通知精简

### 个人财务规划
- **基础公式**：净资产 = 资产 - 负债；每月储蓄 = 收入 - 支出
- **财务六步**：应急基金（3-6个月支出）→ 还债 → 养老金 → 投资 → 兴趣消费
- **自动化**：工资到账自动转入储蓄/投资账户，消费剩余而非储蓄剩余
- **记账**：每月回顾，识别"心理账户"陷阱

### 兴趣技能
- **选择原则**：能让你进入心流的技能；与职业有协同效应加分
- **刻意练习**：有反馈、在舒适区边缘、有明确目标的练习才有效
- **保护时间**：给兴趣固定的时间块，不让工作占满
