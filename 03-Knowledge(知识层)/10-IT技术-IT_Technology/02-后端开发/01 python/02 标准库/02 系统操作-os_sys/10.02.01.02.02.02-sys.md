# sys 模块 — 解释器交互

## 一句话结论

> `sys.argv` 拿命令行参数，`sys.exit()` 控制退出状态，`sys.path` 管模块导入路径，`sys.platform` 判操作系统——这四个是写脚本时最常用的 sys API。

---

## 一、命令行参数与程序控制

| 函数/变量 | 描述 | 常用程度 |
|----------|------|---------|
| `sys.argv` | 命令行参数列表（索引 0 是脚本名）| ⭐⭐⭐⭐⭐ |
| `sys.exit([arg])` | 退出程序，可指定退出码或错误信息 | ⭐⭐⭐⭐⭐ |
| `sys.getrecursionlimit()` | 获取递归深度上限 | ⭐⭐⭐ |
| `sys.setrecursionlimit(limit)` | 设置递归深度上限 | ⭐⭐⭐ |

```python
import sys

# ====== sys.argv — 命令行参数 ======
# python script.py arg1 arg2 arg3
print("脚本名称:", sys.argv[0])
print("所有参数:", sys.argv[1:])

# 安全取值
first_arg = sys.argv[1] if len(sys.argv) > 1 else None

# ====== sys.exit — 退出程序 ======
sys.exit()            # 正常退出（返回码 0）
sys.exit(0)           # 正常退出
sys.exit(1)           # 异常退出（调用方可检测）
sys.exit('错误信息')   # 打印信息后退出（返回码 1）

# ====== 递归深度 ======
print(sys.getrecursionlimit())   # 默认 1000
sys.setrecursionlimit(2000)      # 修改上限
```

**命令行工具模板**：

```python
import sys

def main():
    if len(sys.argv) < 2:
        print('用法: python script.py <文件名>')
        sys.exit(1)

    filename = sys.argv[1]
    verbose = '--verbose' in sys.argv

    if not os.path.exists(filename):
        print(f'错误: 文件 {filename} 不存在', file=sys.stderr)
        sys.exit(1)

    # ... 业务逻辑 ...

if __name__ == '__main__':
    main()
```

## 二、模块与路径管理

| 函数/变量 | 描述 | 常用程度 |
|----------|------|---------|
| `sys.path` | 模块搜索路径列表 | ⭐⭐⭐⭐⭐ |
| `sys.modules` | 已加载模块字典 | ⭐⭐⭐ |
| `sys.prefix` | Python 安装目录 | ⭐⭐ |
| `sys.executable` | Python 解释器路径 | ⭐⭐ |

```python
import sys

# ====== sys.path — 模块搜索路径 ======
# Python 导入模块时按此列表逐个搜索
print(sys.path)
# ['', '/usr/lib/python3.12', '/usr/lib/python3.12/site-packages', ...]

# 临时添加搜索路径
sys.path.append('/my/custom/modules')
import my_module   # 现在可以导入了

# 插到最前面（优先搜索）
sys.path.insert(0, '/my/custom/modules')

# ====== sys.modules — 查看已加载的模块 ======
print('json' in sys.modules)     # False（还没导入）
import json
print('json' in sys.modules)     # True
```

## 三、输入输出流

| 变量 | 描述 | 常用程度 |
|------|------|---------|
| `sys.stdin` | 标准输入流 | ⭐⭐⭐⭐ |
| `sys.stdout` | 标准输出流 | ⭐⭐⭐⭐ |
| `sys.stderr` | 标准错误流 | ⭐⭐⭐⭐ |

```python
import sys

# 输出（等价于 print）
sys.stdout.write('hello\n')
sys.stderr.write('错误信息\n')

# 读取标准输入
data = sys.stdin.read()           # 读取全部
line = sys.stdin.readline()       # 读取一行

# 重定向输出到文件
with open('output.txt', 'w') as f:
    old_stdout = sys.stdout
    sys.stdout = f
    print('这行写入了文件 output.txt')   # 写入文件而非终端
    sys.stdout = old_stdout             # 恢复
```

## 四、系统与解释器信息

| 变量 | 描述 | 常用程度 |
|------|------|---------|
| `sys.platform` | 平台标识 | ⭐⭐⭐⭐⭐ |
| `sys.version` | Python 版本字符串 | ⭐⭐⭐⭐ |
| `sys.version_info` | 版本元组（可比较）| ⭐⭐⭐⭐ |
| `sys.maxsize` | 最大整数 | ⭐⭐ |
| `sys.getsizeof(obj)` | 对象内存占用 | ⭐⭐ |

```python
import sys

# ====== 平台判断 ======
print(sys.platform)   # 'win32' / 'linux' / 'darwin'

if sys.platform == 'win32':
    print('Windows 系统')
elif sys.platform == 'darwin':
    print('macOS 系统')
else:
    print('Linux 系统')

# ====== 版本检查 ======
print(sys.version)            # '3.12.0 (...)'
print(sys.version_info)       # sys.version_info(major=3, minor=12, micro=0)

# 兼容性判断
if sys.version_info < (3, 8):
    print('需要 Python 3.8+')
    sys.exit(1)

# ====== 内存信息 ======
print(sys.getsizeof('hello'))      # 字符串占用
print(sys.getsizeof([1, 2, 3]))    # 列表占用
```

## 五、综合示例：跨平台文件搜索工具

```python
import os, sys

def search_files(root_dir, keyword, case_sensitive=False):
    """递归搜索文件名包含关键词的文件"""
    if not os.path.isdir(root_dir):
        print(f'错误: {root_dir} 不是有效目录', file=sys.stderr)
        sys.exit(1)

    results = []
    for root, dirs, files in os.walk(root_dir):
        # 跳过隐藏目录
        dirs[:] = [d for d in dirs if not d.startswith('.')]
        for file in files:
            target = file if case_sensitive else file.lower()
            kw = keyword if case_sensitive else keyword.lower()
            if kw in target:
                results.append(os.path.join(root, file))

    return results

if __name__ == '__main__':
    if len(sys.argv) < 3:
        print('用法: python search.py <目录> <关键词> [--case-sensitive]')
        print('示例: python search.py . report --case-sensitive')
        sys.exit(1)

    root = sys.argv[1]
    keyword = sys.argv[2]
    case = '--case-sensitive' in sys.argv

    files = search_files(root, keyword, case)
    print(f'找到 {len(files)} 个匹配文件:')
    for f in files:
        print(f'  {f}')
```

## 关键概念

- **sys.argv**：`[0]` 是脚本名，`[1:]` 是参数——取值前先 `len()` 检查
- **sys.exit(0/1)**：0 正常，非 0 异常——调用方可通过返回码判断成败
- **sys.path**：list 类型——可运行时 `insert` / `append` 动态修改模块搜索路径
- **sys.platform**：`'win32'` / `'linux'` / `'darwin'`——跨平台代码的首要判断
- **sys.stdout/stderr**：可重定向——`stderr` 写错误信息，`stdout` 写正常输出

## 可行动建议

- 命令行工具开头检查 `len(sys.argv)` 并给出用法提示
- 退出用 `sys.exit()` 而非 `exit()` 或 `quit()`（后者在脚本中不可靠）
- 错误信息输出到 `sys.stderr` 而非 `print()`
- 临时加模块路径用 `sys.path.insert(0, path)`，不用 `append`
- 版本兼容检查用 `sys.version_info >= (3, 8)`
