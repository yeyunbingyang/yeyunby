# re 模块速查

> 详细版见 [[02-re模块]]

## 一、核心函数（5 个匹配 + 3 个处理）

| 函数                    | 作用          | 返回值               |
| --------------------- | ----------- | ----------------- |
| `re.match(p, s)`      | 从**开头**匹配   | `Match` / `None`  |
| `re.search(p, s)`     | 搜索**第一个**匹配 | `Match` / `None`  |
| `re.findall(p, s)`    | 查找**所有**匹配  | `list[str]`       |
| `re.finditer(p, s)`   | 迭代**所有**匹配  | `iterator[Match]` |
| `re.fullmatch(p, s)`  | **完整**字符串匹配 | `Match` / `None`  |
| `re.sub(p, repl, s)`  | 替换匹配内容      | `str`             |
| `re.subn(p, repl, s)` | 替换并返回次数     | `(str, count)`    |
| `re.split(p, s)`      | 按模式分割       | `list[str]`       |

**Match 对象常用方法：** `group()`, `group(n)`, `groupdict()`, `span()`, `start()`, `end()`

```python
import re
m = re.search(r"(\d{4})-(\d{2})-(\d{2})", "日期: 2025-12-26")
m.group()    # '2025-12-26'
m.group(1)   # '2025'
m.groups()   # ('2025', '12', '26')
m.span()     # (3, 13)
```

## 二、字符类

| 符号 | 匹配内容 | 等价写法 |
|------|---------|---------|
| `.` | 除换行外的任意字符 | — |
| `\d` | 数字 | `[0-9]` |
| `\D` | 非数字 | `[^0-9]` |
| `\w` | 字母/数字/下划线 | `[a-zA-Z0-9_]` |
| `\W` | 非单词字符 | `[^a-zA-Z0-9_]` |
| `\s` | 空白（空格/Tab/换行） | `[ \t\n\r\f\v]` |
| `\S` | 非空白 | `[^ \t\n\r\f\v]` |
| `[...]` | 自定义字符集 | `[aeiou]`、`[0-9a-f]` |
| `[^...]` | 取反字符集 | `[^0-9]` |

## 三、量词（重复）

| 符号 | 含义 | 示例 |
|------|------|------|
| `*` | 0 次或多次 | `a*` → `""`, `"a"`, `"aaa"` |
| `+` | 1 次或多次 | `a+` → `"a"`, `"aaa"` |
| `?` | 0 次或 1 次 | `a?` → `""`, `"a"` |
| `{n}` | 恰好 n 次 | `a{3}` → `"aaa"` |
| `{n,}` | 至少 n 次 | `a{2,}` → `"aa"`, `"aaaa"` |
| `{n,m}` | n 到 m 次 | `a{2,4}` → `"aa"`, `"aaa"`, `"aaaa"` |

**贪婪 vs 非贪婪：** 默认贪婪；量词后加 `?` 变为非贪婪

| 贪婪 | 非贪婪 | 效果 |
|------|--------|------|
| `.*` | `.*?` | 尽可能少匹配 |
| `.+` | `.+?` | 尽可能少匹配 |
| `.{n,m}` | `.{n,m}?` | 尽可能少匹配 |

## 四、边界与锚点

| 符号 | 含义 |
|------|------|
| `^` | 字符串开头（`re.M` 下也匹配行首） |
| `$` | 字符串结尾（`re.M` 下也匹配行尾） |
| `\b` | 单词边界 |
| `\B` | 非单词边界 |
| `\A` | 字符串绝对开头（不受 `re.M` 影响） |
| `\Z` | 字符串绝对结尾（不受 `re.M` 影响） |

## 五、分组与引用

| 语法              | 含义                                       |
| --------------- | ---------------------------------------- |
| `(...)`         | 捕获分组，可通过 `\1`、`group(1)` 引用              |
| `(?:...)`       | 非捕获分组，不占用编号                              |
| `(?P<name>...)` | 命名分组，通过 `group(name)` 或 `groupdict()` 访问 |
| `(?P=name)`     | 引用命名分组                                   |
| `\1`, `\2`      | 反向引用第 n 个分组                              |
| `(?#...)`       | 注释（配合 `re.VERBOSE`）                      |

## 六、零宽断言

| 语法 | 含义 | 示例 |
|------|------|------|
| `(?=...)` | 正向先行断言：后面是... | `\d+(?=元)` → 匹配"元"前面的数字 |
| `(?!...)` | 负向先行断言：后面不是... | `\d+(?!元)` → 匹配后面不是"元"的数字 |
| `(?<=...)` | 正向后行断言：前面是... | `(?<=￥)\d+` → 匹配￥后面的数字 |
| `(?<!...)` | 负向后行断言：前面不是... | `(?<!￥)\d+` → 匹配前面不是￥的数字 |

## 七、Flags（编译标志）

| Flag            | 简写     | 作用                       |
| --------------- | ------ | ------------------------ |
| `re.IGNORECASE` | `re.I` | 忽略大小写                    |
| `re.MULTILINE`  | `re.M` | `^` `$` 匹配每行的首尾          |
| `re.DOTALL`     | `re.S` | `.` 匹配换行符                |
| `re.VERBOSE`    | `re.X` | 允许注释和空白，增强可读性            |
| `re.ASCII`      | `re.A` | `\w` `\d` `\s` 仅匹配 ASCII |
| `re.UNICODE`    | `re.U` | （默认）Unicode 模式           |

## 八、常用实战模式

| 场景 | 模式 | 说明 |
|------|------|------|
| 手机号 | `1[3-9]\d{9}` | 1 开头，第二位 3-9，共 11 位 |
| 邮箱 | `[\w.-]+@[\w.-]+\.\w{2,}` | 常见的简化邮箱匹配 |
| 日期 | `\d{4}-\d{2}-\d{2}` | YYYY-MM-DD 格式 |
| IP 地址 | `(\d{1,3}\.){3}\d{1,3}` | 简化版；精确需检查 0-255 |
| 中文 | `[\u4e00-\u9fff]+` | 匹配中文字符 |
| URL | `https?://[\w./-]+` | 简化版 |
| 身份证 | `\d{17}[\dXx]` | 18 位身份证 |
| 空白行 | `^\s*$` | 匹配空行或仅含空白行 |
| 提取双引号内容 | `"([^"]*)"` | 非贪婪提取引号内容 |
| HTML 标签 | `<[^>]+>` | 匹配 HTML 标签 |

## 九、核心要点

1. **用 `r"..."` 原始字符串**写模式，避免反斜杠地狱
2. **`re.compile()`** 预编译重复使用的模式，提升性能
3. **非贪婪 `*?` `+?`** 避免过度匹配，是 90% 问题的解药
4. **`re.search()` vs `re.match()`**：前者搜任意位置，后者仅从开头
5. **分组**：捕获用 `()`，不捕获用 `(?:)`，命名用 `(?P<name>)`
6. **`re.VERBOSE`** 适合复杂模式，可加注释分行写
7. **`re.sub()` 支持函数**作为替换参数，适合复杂替换逻辑
