# FastAPI 异步数据库驱动选型

## 一句话结论

> FastAPI 的核心优势是 `async/await` 异步并发，使用同步驱动（PyMySQL、mysqlclient）会在数据库 IO 时**阻塞整个事件循环**，把异步服务退化成串行；必须换上异步驱动才能真正发挥 FastAPI 的并发能力。

## 核心内容

### 1. 为什么同步驱动不适合 FastAPI

FastAPI 底层基于 Starlette + asyncio，所有请求在同一个事件循环中处理。同步 DB 调用会让当前协程阻塞等待网络 IO，期间该线程无法处理任何其他请求：

```python
# ❌ 反模式：同步驱动阻塞事件循环
@app.get("/users")
def get_users():
    conn = pymysql.connect(...)       # 阻塞
    cursor = conn.cursor()
    cursor.execute("SELECT ...")      # 阻塞
    return cursor.fetchall()          # 阻塞
```

```python
# ✅ 正确方式：异步驱动释放控制权
@app.get("/users")
async def get_users():
    async with asyncmy.connect(...) as conn:   # await，不阻塞
        async with conn.cursor() as cursor:
            await cursor.execute("SELECT ...")  # await，不阻塞
            return await cursor.fetchall()
```

### 3. MySQL 异步驱动

#### 3.1 asyncmy（推荐 ★）

基于 Rust 重写的 MySQL 协议实现，速度极快：

```powershell
pip install asyncmy
```

```python
import asyncio
import asyncmy

async def main():
    conn = await asyncmy.connect(
        host='localhost', port=3306,
        user='root', password='123456',
        database='school', charset='utf8mb4'
    )

    async with conn.cursor() as cursor:
        await cursor.execute(
            "SELECT name, score FROM students WHERE class_id = %s",
            (3,)
        )
        rows = await cursor.fetchall()
        for row in rows:
            print(row)

    conn.close()

asyncio.run(main())
```

**FastAPI 集成示例：**

```python
from fastapi import FastAPI
import asyncmy

app = FastAPI()

# 全局连接池（生产环境用）
pool = None

@app.on_event("startup")
async def startup():
    global pool
    pool = await asyncmy.create_pool(
        host='localhost', port=3306,
        user='root', password='123456',
        database='school', charset='utf8mb4',
        minsize=5, maxsize=20
    )

@app.on_event("shutdown")
async def shutdown():
    pool.close()
    await pool.wait_closed()

@app.get("/students/{class_id}")
async def get_students(class_id: int):
    async with pool.acquire() as conn:
        async with conn.cursor() as cursor:
            await cursor.execute(
                "SELECT name, score FROM students WHERE class_id = %s",
                (class_id,)
            )
            rows = await cursor.fetchall()
            return [{"name": r[0], "score": r[1]} for r in rows]
```

#### 3.2 aiomysql

PyMySQL 的异步封装，API 接近 PyMySQL 但全部 `await`：

```powershell
pip install aiomysql
```

```python
import aiomysql

pool = await aiomysql.create_pool(
    host='localhost', port=3306,
    user='root', password='123456',
    db='school', charset='utf8mb4',
    minsize=5, maxsize=20
)

async with pool.acquire() as conn:
    async with conn.cursor() as cursor:
        await cursor.execute("SELECT * FROM students")
        rows = await cursor.fetchall()
```

#### 3.3 MySQL 异步驱动对比

| 维度         | asyncmy        | aiomysql           |
| ---------- | -------------- | ------------------ |
| 实现         | Rust（PyO3）     | 纯 Python           |
| 速度         | ★★★★★（最快）      | ★★★☆☆              |
| 协议兼容       | MySQL 8.0 完整支持 | MySQL 5.5+         |
| 生态成熟度      | 新锐，社区增长快       | 老牌，坑少              |
| PyMySQL 迁移 | 需改 API         | API 与 PyMySQL 几乎一致 |
| 连接池        | 内置             | 内置                 |

> **选择建议**：新项目直接上 asyncmy；已有 PyMySQL 项目想最小改动异步化则选 aiomysql。

### 4. PostgreSQL 异步驱动 — asyncpg（推荐 ★）

PostgreSQL 的异步驱动选型很简单：只有一个王者 asyncpg。

```powershell
pip install asyncpg
```

```python
import asyncpg

async def main():
    pool = await asyncpg.create_pool(
        host='localhost', port=5432,
        user='postgres', password='123456',
        database='school',
        min_size=5, max_size=20
    )

    async with pool.acquire() as conn:
        # asyncpg 使用 $1, $2 占位符（不是 %s）
        rows = await conn.fetch(
            "SELECT name, score FROM students WHERE class_id = $1",
            3
        )
        for row in rows:
            print(row['name'], row['score'])  # 直接返回 dict-like 记录

    await pool.close()

asyncio.run(main())
```

**FastAPI 集成：**

```python
from fastapi import FastAPI
import asyncpg

app = FastAPI()
pool = None

@app.on_event("startup")
async def startup():
    global pool
    pool = await asyncpg.create_pool(
        host='localhost', user='postgres',
        password='123456', database='school',
        min_size=5, max_size=20
    )

@app.get("/students/{class_id}")
async def get_students(class_id: int):
    async with pool.acquire() as conn:
        rows = await conn.fetch(
            "SELECT name, score FROM students WHERE class_id = $1",
            class_id
        )
        return [dict(r) for r in rows]
```

> asyncpg 比 psycopg2（同步 PG 驱动）快 3-5 倍，是所有 Python 数据库驱动中性能的天花板。

### 5. ORM 层方案

直接写 SQL 适合简单场景，复杂业务需要 ORM。

#### 5.1 SQLAlchemy 2.0 Async（推荐 ★）

```powershell
pip install sqlalchemy[asyncio] asyncmy   # MySQL
pip install sqlalchemy[asyncio] asyncpg   # PostgreSQL
```

```python
from sqlalchemy.ext.asyncio import create_async_engine, AsyncSession, async_sessionmaker
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column
from sqlalchemy import String, Float, select

# 模型定义
class Base(DeclarativeBase):
    pass

class Student(Base):
    __tablename__ = "students"
    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(50))
    score: Mapped[float] = mapped_column(Float)

# 异步引擎（MySQL 用 asyncmy，PG 用 asyncpg）
engine = create_async_engine(
    "mysql+asyncmy://root:123456@localhost:3306/school",
    echo=False
)

AsyncSessionLocal = async_sessionmaker(engine, class_=AsyncSession, expire_on_commit=False)

# FastAPI 依赖注入
async def get_db():
    async with AsyncSessionLocal() as session:
        yield session

@app.get("/students/high-score")
async def high_score(db: AsyncSession = Depends(get_db)):
    result = await db.execute(
        select(Student).where(Student.score > 90)
    )
    students = result.scalars().all()
    return [{"name": s.name, "score": s.score} for s in students]
```

> SQLAlchemy 2.0 async 是最稳妥的选择：生态最大、文档最全、Django 之外的事实标准。

#### 5.2 Tortoise ORM

异步原生的 Django 风格 ORM，配置极简：

```powershell
pip install tortoise-orm asyncmy
```

```python
from tortoise import Tortoise, fields, run_async
from tortoise.models import Model

class Student(Model):
    id = fields.IntField(pk=True)
    name = fields.CharField(max_length=50)
    score = fields.FloatField()

    class Meta:
        table = "students"

async def init():
    await Tortoise.init(
        db_url="mysql://root:123456@localhost:3306/school",
        modules={"models": ["__main__"]}
    )
    await Tortoise.generate_schemas()

# 查询
students = await Student.filter(score__gt=90).all()
student = await Student.get(name="赵云")
await Student.create(name="张飞", score=85.0)
```

**FastAPI 集成（官方推荐）：**

```python
from fastapi import FastAPI
from tortoise.contrib.fastapi import register_tortoise

app = FastAPI()

register_tortoise(
    app,
    db_url="mysql://root:123456@localhost:3306/school",
    modules={"models": ["app.models"]},
    generate_schemas=True,
    add_exception_handlers=True,
)
```

> Tortoise ORM 是异步原生的，不需要 `await db.execute()` 这种间接调用，写起来最接近 Django ORM 手感。

#### 5.3 encode/databases（轻量中间层）

不想上完整 ORM 但又需要连接池和类型转换：

```powershell
pip install databases asyncmy
```

```python
import databases
import sqlalchemy

# 使用 SQLAlchemy Core 定义表，databases 执行
metadata = sqlalchemy.MetaData()
students = sqlalchemy.Table(
    "students", metadata,
    sqlalchemy.Column("id", sqlalchemy.Integer, primary_key=True),
    sqlalchemy.Column("name", sqlalchemy.String(50)),
    sqlalchemy.Column("score", sqlalchemy.Float),
)

database = databases.Database("mysql+asyncmy://root:123456@localhost/school")

@app.on_event("startup")
async def startup():
    await database.connect()

@app.on_event("shutdown")
async def shutdown():
    await database.disconnect()

@app.get("/students")
async def list_students():
    query = students.select().where(students.c.score > 90)
    rows = await database.fetch_all(query)
    return [dict(r) for r in rows]

@app.post("/students")
async def add_student(name: str, score: float):
    query = students.insert().values(name=name, score=score)
    student_id = await database.execute(query)
    return {"id": student_id}
```

### 6. 选型决策矩阵

| 需求 | MySQL | PostgreSQL |
|------|-------|------------|
| **只要异步驱动** | asyncmy ★ | asyncpg ★ |
| **最小迁移成本** | aiomysql（API 同 PyMySQL） | — |
| **完整 ORM（大项目）** | SQLAlchemy 2.0 async | SQLAlchemy 2.0 async |
| **快速原型 / 中小项目** | Tortoise ORM | Tortoise ORM |
| **只想要连接池 + 原生 SQL** | encode/databases | encode/databases |

### 7. 性能对比（参考数据，ops/s 越高越好）

| 驱动 | MySQL 读 | MySQL 写 | PostgreSQL 读 | PostgreSQL 写 |
|------|----------|----------|---------------|---------------|
| asyncmy | ~12,000 | ~8,500 | — | — |
| aiomysql | ~4,000 | ~3,500 | — | — |
| asyncpg | — | — | ~18,000 | ~12,000 |
| PyMySQL（sync） | ~3,500 | ~2,800 | — | — |
| mysqlclient（sync） | ~7,000 | ~5,500 | — | — |
| psycopg2（sync） | — | — | ~4,500 | ~3,500 |

> asyncpg 是绝对的性能王者；asyncmy 在 MySQL 赛道上远超所有同步驱动。

## 关键概念

- **事件循环阻塞**：同步 IO 让整个线程卡死，asyncio 的优势荡然无存
- **连接池**：异步驱动普遍内置连接池，避免每次请求都新建 TCP 连接
- **`await` 释放控制权**：异步驱动的核心价值——IO 等待期间事件循环可处理其他请求
- **混合使用**：FastAPI 中可以把同步 DB 调用丢进 `run_in_executor` 的线程池，但不是最优解

## 适用场景

- FastAPI / Starlette / aiohttp / Sanic 等异步 Web 框架
- 高并发 API 服务（WebSocket、长轮询、SSE）
- 微服务间数据库访问
- 需要同时处理大量并发 DB 查询的场景

## 最佳实践

- **新项目直接 asyncmy + SQLAlchemy 2.0 async**：高性能 + 成熟生态
- **连接池不要省**：生产环境至少 min=5, max=20
- **事务务必 await**：`await db.commit()` / `await db.rollback()`
- **PostgreSQL 项目无脑 asyncpg**：没有理由不用它
- **把 DB 配置环境变量化**：切换驱动只改 URL scheme（`mysql+asyncmy://` ↔ `mysql+aiomysql://`）

## 反例与边界

- **同步驱动 + FastAPI = 自废武功**：表面是异步，实际上一次 DB 查询阻塞整个线程
- **asyncmy 不支持 MySQL 5.5 以下**：老数据库用 aiomysql
- **Tortoise ORM 的迁移工具不成熟**：复杂表结构变更建议用 Alembic + SQLAlchemy
- **不要在 async 函数里调同步驱动**：即使用了 `run_in_executor`，线程池也有上限

## 可行动建议

- 打开现有 FastAPI 项目，检查是否还在 `import pymysql` → 换成 asyncmy
- 新建项目搭建模板：FastAPI + SQLAlchemy 2.0 async + asyncmy + Alembic
- 用 `asgi-lifespan` 模式管理启动/关闭时的连接池生命周期
