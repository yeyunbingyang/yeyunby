# XPath与lxml — HTML/XML 数据提取

## 一句话结论

> `tree.xpath('//div[@class="item"]/h2/text()')` 一行代码精准提取所有目标数据——XPath 是整个爬虫数据提取环节最核心的技能，90% 的网页提取场景靠它解决。

---

## 一、lxml 简介与安装

### 1.1 什么是 lxml

`lxml` 是一个 Python 第三方库，底层基于 C 语言实现（libxml2），是 Python 生态中**性能最高**的 HTML/XML 解析器。

| 解析器                   | 底层         | 性能     | XPath 支持      |
| --------------------- | ---------- | ------ | ------------- |
| **lxml**              | C（libxml2） | ⭐⭐⭐ 极快 | ✅ 原生支持        |
| BeautifulSoup4 + lxml | C + Python | ⭐⭐ 较快  | ❌ 需 CSS 选择器转换 |
| html.parser           | Python     | ⭐ 慢    | ❌ 不支持         |

### 1.2 安装

```bash
pip install lxml
```

### 1.3 基本使用三步法

```python
from lxml import etree

# 步骤 1：获取 HTML 源码
html_str = "<html><body><div>Hello</div></body></html>"

# 步骤 2：创建 Element 树
tree = etree.HTML(html_str)   # HTML 用 etree.HTML()，XML 用 etree.XML()

# 步骤 3：XPath 提取
result = tree.xpath("//div/text()")
print(result)   # ['Hello']
```

### 1.4 etree.HTML() 的容错能力：自动补全缺失标签

`etree.HTML()` 有一个重要特性：它会**自动修复 HTML 中的语法缺失**——补全未闭合的标签、添加缺失的 `<html>` 和 `<body>` 包裹。

```python
from lxml import etree

# 一段不规范的 HTML——ul 前缺少 <li> 闭合标签
broken_html = '''
<div>
    <ul>
        <a href="/page1">链接1</a>
    </ul>
</div>
'''

tree = etree.HTML(broken_html)

# 用 tostring 查看 lxml 修复后的完整 HTML
print(etree.tostring(tree, encoding="unicode"))
# 输出（lxml 自动补充了 <html>、<body>，并修复了标签结构）：
# <html><body><div>
#     <ul>
#         <a href="/page1">链接1</a>
#     </ul>
# </div></body></html>
```

> **关键理解**：是 `etree.HTML()` 在创建 Element 树时做了补全，不是 `etree.tostring()` 补的。这是 HTML 也能用 XPath 的根本原因——容错后形成了合法树结构。

## 二、XPath Helper — 语法验证利器

### 2.1 什么是 XPath Helper

Chrome 浏览器插件，在网页上**实时测试** XPath 表达式——写完表达式立即看到匹配结果，是写 XPath 的必备工具。

### 2.2 安装与使用

1. Chrome 应用商店搜索 **XPath Helper** → 安装
2. 打开目标网页 → 点击插件图标 → 左侧写 XPath → 右侧实时高亮匹配节点
3. 快捷键 `Ctrl+Shift+X` 打开/关闭

### 2.3 核心功能

- **实时预览**：每敲一个字符，立即显示匹配结果
- **高亮节点**：匹配到的页面元素黄色高亮
- **结果统计**：显示匹配数量

### 2.4 ⚠️ 重要：XPath Helper 验证通过 ≠ lxml 一定可用

这是爬虫开发中最常见的坑——浏览器中的 XPath 表达式在 XPath Helper 中完全正常，但到了 Python lxml 中可能返回 `None` 或空列表。

**原因**：
- 浏览器渲染的是**动态 DOM**（JS 执行后的结果）
- lxml 解析的是**静态 HTML 源码**（`response.content`）
- 两者的 DOM 树可能不同——JS 可能动态添加/修改了节点和属性

**解决方案**：

```python
# 步骤 1：在 XPath Helper 验证通过后，右键查看网页源代码
# 步骤 2：在源代码中 Ctrl+F 搜索目标节点——确认它在原始 HTML 中存在

# 步骤 3：如果 lxml 返回空，换一种定位方式
# ❌ 属性选择在 lxml 中失败
tree.xpath('//a[@class="j_th_tit"]/@href')

# ✅ 改用文本匹配或 contains
tree.xpath('//a[contains(text(), "下一页")]/@href')

# ✅ 或改用 CSS 选择器思路（用 contains 模糊 class）
tree.xpath('//a[contains(@class, "j_th_tit")]/@href')
```

> 经验法则：**优先用 `contains()` 做模糊匹配，避免精确属性选择**——HTML 源码中的 class 值可能和浏览器 Elements 面板展示的不同。

## 三、XPath 语法 — 基础节点选择

### 3.1 路径表达式

| 表达式        | 含义            | 示例               |
| ---------- | ------------- | ---------------- |
| `nodename` | 选取此节点的所有子节点   | `div`            |
| `/`        | 从根节点选取（绝对路径）  | `/html/body/div` |
| `//`       | 从任意位置选取（相对路径） | `//div`          |
| `.`        | 当前节点          | `.`              |
| `..`       | 父节点           | `..`             |
| `@`        | 选取属性          | `@class`         |

### 3.2 基本选择示例

```html
<html>
  <body>
    <div class="container">
      <h1>标题</h1>
      <ul>
        <li class="item">项目 A</li>
        <li class="item">项目 B</li>
        <li>项目 C</li>
      </ul>
    </div>
  </body>
</html>
```

```python
from lxml import etree
tree = etree.HTML(html_str)

tree.xpath("//div")                   # 所有 div
tree.xpath("//li/text()")             # ['项目 A', '项目 B', '项目 C']
tree.xpath("//li[@class='item']")     # class="item" 的 li
tree.xpath("//li[@class='item']/text()")  # ['项目 A', '项目 B']
tree.xpath("//h1/text()")             # ['标题']
tree.xpath("/html/body/div/h1/text()")    # 绝对路径
```

## 四、XPath 语法 — 节点修饰语法

### 4.1 谓语（Predicate）

谓语写在 `[]` 中，XPath 下标从 **1** 开始：

| 谓语                                | 含义                    |
| --------------------------------- | --------------------- |
| `[1]`                             | 第一个（⚠️ 从 1 开始，不是 0）   |
| `[last()]`                        | 最后一个                  |
| `[last()-1]`                      | 倒数第二个                 |
| `[position()<3]`                  | 前两个                   |
| `[@class]`                        | 有 class 属性            |
| `[@class="value"]`                | class 精确等于 value      |
| `[text()="value"]`                | 文本精确等于 value          |
| `[contains(@class, "partial")]`   | class **包含** partial  |
| `[starts-with(@class, "prefix")]` | class **以** prefix 开头 |

### 4.2 谓语实战

```python
tree.xpath("//li[1]/text()")                  # 第一个
tree.xpath("//li[last()]/text()")              # 最后一个
tree.xpath("//li[position()<=3]/text()")       # 前 3 个
tree.xpath("//li[@class]/text()")              # 有 class 属性的
tree.xpath("//li[contains(@class, 'item')]/text()")  # class 模糊匹配
tree.xpath("//li[contains(text(), '项目')]/text()")  # 文本模糊匹配
```

### 4.3 属性提取

```python
tree.xpath("//div/@class")      # 提取 class 属性值
tree.xpath("//a/@href")         # 提取 href
tree.xpath("//li/@class")       # 所有 li 的 class
```

### 4.4 通配符

| 表达式      | 含义            |     |
| -------- | ------------- | --- |
| `*`      | 匹配任意元素节点      |     |
| `@*`     | 匹配任意属性节点      |     |
| `node()` | 匹配任意类型节点（含文本） |     |

```python
tree.xpath("//div/*")     # div 下所有子元素
tree.xpath("//li[@*]")    # 有任意属性的 li
```

## 五、XPath 语法 — 其他常用语法

### 5.1 多路径选择（`|`）

```python
tree.xpath("//h1/text() | //h2/text()")  # 同时取 h1 和 h2
```

### 5.2 轴（Axis）— 节点关系导航

| 轴                     | 含义      | 缩写   |
| --------------------- | ------- | ---- |
| `child::`             | 子节点     | （默认） |
| `parent::`            | 父节点     | `..` |
| `ancestor::`          | 祖先节点    | —    |
| `descendant::`        | 后代节点    | `//` |
| `following-sibling::` | 之后的同级节点 | —    |
| `preceding-sibling::` | 之前的同级节点 | —    |

```python
tree.xpath("//div/ancestor::*")                          # 所有祖先
tree.xpath("//li[@class='item']/parent::*")              # 父节点
tree.xpath("//li[1]/following-sibling::li/text()")       # 之后同级
```

### 5.3 函数

| 函数                  | 用途                  |
| ------------------- | ------------------- |
| `text()`            | 提取直接文本              |
| `string()`          | 提取节点内**所有文本**（含子节点） |
| `contains(a, b)`    | a 是否包含 b            |
| `starts-with(a, b)` | a 是否以 b 开头          |
| `not(expr)`         | 逻辑取反                |
| `normalize-space()` | 去空白 + 合并中间空格        |
| `count(node-set)`   | 统计节点数量              |

```python
tree.xpath("string(//div[@class='container'])")           # 所有文本
tree.xpath("count(//li)")                                 # li 总数
tree.xpath("//li[not(contains(@class, 'item'))]/text()")  # 不含 item 的 li
```

## 七、实战：百度贴吧（基础版 — 单页提取）

### 7.1 分析目标

`https://tieba.baidu.com/f?kw=python` → 提取每个帖子的标题、作者、回复数、链接。

### 7.2 页面结构

```html
<ul id="thread_list">
    <li class="j_thread_list">
        <a class="j_th_tit" href="/p/123456" title="帖子标题">帖子标题</a>
        <span class="frs-author-name">作者名</span>
        <span class="threadlist_rep_num">123</span>
    </li>
</ul>
```

### 7.3 XPath 对照表

| 目标 | XPath |
|------|-------|
| 所有帖子条目 | `//li[contains(@class, 'j_thread_list')]` |
| 帖子标题 | `.//a[@class="j_th_tit"]/@title` |
| 帖子链接 | `.//a[@class="j_th_tit"]/@href` |
| 作者 | `.//span[@class="frs-author-name"]/text()` |
| 回复数 | `.//span[@class="threadlist_rep_num"]/text()` |

### 7.4 单页代码

```python
import requests
from lxml import etree

url = "https://tieba.baidu.com/f?kw=python"
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                  "AppleWebKit/537.36 (KHTML, like Gecko) "
                  "Chrome/120.0.0.0 Safari/537.36"
}

resp = requests.get(url, headers=headers, timeout=10)
tree = etree.HTML(resp.content)

threads = tree.xpath('//li[contains(@class, "j_thread_list")]')

results = []
for thread in threads:
    title = thread.xpath('.//a[@class="j_th_tit"]/@title')
    href = thread.xpath('.//a[@class="j_th_tit"]/@href')
    author = thread.xpath('.//span[@class="frs-author-name"]/text()')
    reply = thread.xpath('.//span[@class="threadlist_rep_num"]/text()')

    results.append({
        "标题": title[0] if title else "",
        "链接": f"https://tieba.baidu.com{href[0]}" if href else "",
        "作者": author[0] if author else "",
        "回复": reply[0] if reply else "0",
    })

print(f"共提取 {len(results)} 条帖子")
for r in results[:10]:
    print(f"{r['标题'][:30]} | {r['作者']} | 回复:{r['回复']}")
```

### 7.5 ⚠️ 循环内必须用 `.//`

```python
# ❌ // 从文档根搜索——取到的永远是第一页第一条的标题
thread.xpath("//a[@class='j_th_tit']/@title")

# ✅ .// 从当前 thread 内搜索——每条帖子的标题各不同
thread.xpath(".//a[@class='j_th_tit']/@title")
```

## 八、实战进阶：百度贴吧翻页爬虫

### 8.1 翻页逻辑分析

贴吧 URL 翻页格式：`https://tieba.baidu.com/f?kw=python&pn=0`（pn=0 第 1 页，pn=50 第 2 页……每页 50 条）

但实际开发中不应手动拼接 pn，而应**从页面中提取「下一页」链接**——更健壮。

### 8.2 翻页 XPath

```python
# 提取「下一页」链接
next_url = tree.xpath('//a[contains(text(), "下一页")]/@href')
# 或更精确
next_url = tree.xpath('//a[@class="next pagination-item "]/@href')
```

### 8.3 while True 翻页模板

这是爬虫翻页的通用模式——适用于所有分页网站：

```python
import requests
from lxml import etree
import time

class TiebaSpider:
    """百度贴吧翻页爬虫"""

    def __init__(self, kw):
        self.kw = kw
        self.base_url = f"https://tieba.baidu.com/f?kw={kw}"
        self.headers = {
            "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                          "AppleWebKit/537.36 (KHTML, like Gecko) "
                          "Chrome/120.0.0.0 Safari/537.36"
        }
        self.all_data = []

    def fetch_page(self, url):
        """请求单页并返回 Element 树"""
        resp = requests.get(url, headers=self.headers, timeout=10)
        return etree.HTML(resp.content)

    def parse_page(self, tree):
        """解析单页帖子列表"""
        threads = tree.xpath('//li[contains(@class, "j_thread_list")]')
        page_data = []
        for t in threads:
            page_data.append({
                "标题": (t.xpath('.//a[@class="j_th_tit"]/@title') or [""])[0],
                "作者": (t.xpath('.//span[@class="frs-author-name"]/text()') or [""])[0],
                "回复": (t.xpath('.//span[@class="threadlist_rep_num"]/text()') or ["0"])[0],
            })
        return page_data

    def get_next_url(self, tree):
        """提取下一页链接——返回 None 表示最后一页"""
        result = tree.xpath('//a[contains(text(), "下一页")]/@href')
        if not result:
            return None
        next_path = result[0]
        if next_path == "#" or not next_path.strip():
            return None
        return "https:" + next_path if next_path.startswith("//") else "https://tieba.baidu.com" + next_path

    def run(self, max_pages=5):
        """主流程：循环翻页直到最后一页或达到上限"""
        current_url = self.base_url
        page = 1

        while True:
            print(f"正在爬取第 {page} 页: {current_url}")

            tree = self.fetch_page(current_url)
            page_data = self.parse_page(tree)
            self.all_data.extend(page_data)

            print(f"  本页 {len(page_data)} 条，累计 {len(self.all_data)} 条")

            # 检查翻页终止条件
            if page >= max_pages:
                print(f"已达到最大页数 {max_pages}，停止")
                break

            next_url = self.get_next_url(tree)
            if next_url is None:
                print("已到最后一页，停止")
                break

            current_url = next_url
            page += 1
            time.sleep(1)   # 礼貌爬取

        return self.all_data


# 使用
spider = TiebaSpider("python")
all_posts = spider.run(max_pages=3)

print(f"\n=== 共爬取 {len(all_posts)} 条帖子 ===")
for post in all_posts[:10]:
    print(f"  {post['标题'][:35]} | {post['作者']} | {post['回复']}回复")
```

### 8.4 翻页模板核心要素

| 要素 | 说明 |
|------|------|
| `while True` | 无限循环直到触发终止条件 |
| `get_next_url()` | 从当前页提取下一页链接——返回 None 时终止 |
| 终止条件 | ① 找不到下一页链接 ② 达到最大页数上限 |
| `time.sleep(1)` | 请求间延迟——避免被封 |
| URL 拼接 | 提取的链接可能是相对路径，需要补全域名 |

## 九、tostring — 将 Element 转回字符串

### 9.1 用途

- **调试**：查看提取到的 Element 的完整 HTML 结构
- **验证**：确认 lxml 的容错补全效果

### 9.2 用法

```python
from lxml import etree

html_str = '<div class="item"><h2>标题</h2><p>内容</p></div>'
tree = etree.HTML(html_str)
div = tree.xpath('//div[@class="item"]')[0]

# 查看 Element 的 HTML（推荐 encoding="unicode"）
print(etree.tostring(div, encoding="unicode"))
# <div class="item"><h2>标题</h2><p>内容</p></div>

# bytes 形式
raw = etree.tostring(div, encoding="utf-8")

# 美化输出
pretty = etree.tostring(div, encoding="unicode", pretty_print=True)
```

### 9.3 注意

`etree.tostring()` 只是**输出**当前 Element 的 HTML 字符串，不做任何修改。标签补全是 `etree.HTML()` 在创建树时完成的。

## XPath 语法速查总表

| 语法 | 含义 | 示例 |
|------|------|------|
| `//div` | 任意位置的 div | `//div` |
| `/html/body/div` | 绝对路径 | `/html/body/div` |
| `[@class="item"]` | 属性精确匹配 | `//div[@class="item"]` |
| `[contains(@class, "item")]` | class 模糊匹配 | `//div[contains(@class, "item")]` |
| `[text()="下一页"]` | 文本精确匹配 | `//a[text()="下一页"]` |
| `[contains(text(), "关键词")]` | 文本模糊匹配 | `//h2[contains(text(), "Python")]` |
| `[1]` | 第 1 个（从 1 开始！）| `//li[1]` |
| `[last()]` | 最后 1 个 | `//li[last()]` |
| `[position()<3]` | 位置筛选 | `//li[position()<3]` |
| `//@href` | 提取属性值 | `//a/@href` |
| `//text()` | 提取文本 | `//h2/text()` |
| `|` | 多路径 | `//h1/text() | //h2/text()` |
| `string()` | 节点内所有文本 | `string(//div)` |
| `parent::*` | 父节点 | `//li[1]/parent::*` |
| `.` | 当前节点（局部搜索）| `.//a[@class="title"]` |
| `[not(@class)]` | 逻辑取反 | `//li[not(@class)]` |

## 关键概念

- **lxml**：Python 最快的 HTML/XML 解析器，C 底层实现
- **etree.HTML() 自动补全**：解析时自动修复缺失标签、补充 `<html>`/`<body>` 包裹——这是 HTML 能用 XPath 的根本原因
- **XPath Helper 验证 ≠ lxml 可用**：浏览器 DOM ≠ 静态 HTML 源码——优先用 `contains()` 模糊匹配
- **`//` vs `.//`**：`//` 从文档根搜索，`.//` 从当前节点搜索——循环中必须用 `.//`
- **XPath 下标从 1 开始**：`[1]` 是第一个，不是第 0 个
- **while True 翻页模式**：提取下一页链接 → 判断终止条件 → 循环请求——通用爬虫翻页模板

## 可行动建议

- 写 XPath 前先在 XPath Helper 中实时验证，再贴到 Python 代码
- class 匹配首选 `contains(@class, "value")`——HTML 源码的 class 可能和浏览器面板不同
- 如果浏览器 XPath Helper 通过但 lxml 返回空 → 换 `contains(text(), "...")` 或 `contains(@class, "...")`
- 循环中提取子节点**必须用 `.//`** 而非 `//`
- 翻页不要手动拼接 URL 参数——从页面提取「下一页」链接更健壮
- 调试时用 `etree.tostring(el, encoding="unicode")` 查看 Element 完整 HTML
