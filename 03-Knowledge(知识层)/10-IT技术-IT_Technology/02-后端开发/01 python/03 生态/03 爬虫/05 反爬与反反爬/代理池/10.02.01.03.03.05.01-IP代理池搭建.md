# IP 代理池搭建 — 免费采集、测试验证与付费代理对接

## 一句话结论

> 免费代理 IP 可用率不足 20%，必须**先测试再入库**；付费代理（快代理等）API 提取免去采集测试环节，是生产环境首选。代理池核心逻辑：定时线程填充 IP → Queue 供爬虫线程取用 → 用完放回或废弃。

---

## 一、为什么需要代理 IP

| 原因 | 说明 |
|------|------|
| **隐藏真实 IP** | 高匿名代理使目标服务器看不到你的真实地址——保护信息安全 |
| **突破 IP 封禁** | 单 IP 高频请求被封后，换代理继续——爬虫持久化的基础 |
| **提高访问速度** | 代理服务器有缓存——别人访问过的数据直接从缓存返回 |
| **突破地域限制** | 部分网站按地区展示不同内容——代理 IP 可伪装地区 |

### 代理匿名度区分

| 级别 | 特征 | 适用 |
|------|------|------|
| **高匿名** | 服务器完全不知道你在用代理 | 爬虫首选 |
| **普匿** | 服务器知道你用代理，但不知道真实 IP | 一般够用 |
| **透明** | 服务器能看到你的真实 IP——等于没用 | 不用于爬虫 |

### 2.3 完整采集+测试代码

```python
import time
import requests
from lxml import etree

class FreeProxyPool:
    def __init__(self):
        self.base_url = 'https://www.kuaidaili.com/free/inha/{}/'
        self.test_url = 'http://httpbin.org/ip'
        self.headers = {
            'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) '
                          'AppleWebKit/537.36 Chrome/120.0.0.0'}
        self.valid_proxies = []   # 验证通过的代理

    def fetch_page(self, page):
        """爬取一页代理列表"""
        url = self.base_url.format(page)
        resp = requests.get(url, headers=self.headers)
        html = etree.HTML(resp.text)
        rows = html.xpath('//table/tbody/tr')
        proxies = []
        for row in rows:
            ip = row.xpath('./td[1]/text()')[0]
            port = row.xpath('./td[2]/text()')[0]
            proxies.append(f'http://{ip}:{port}')
        return proxies

    def test_proxy(self, proxy):
        """测试单个代理是否可用"""
        try:
            resp = requests.get(
                self.test_url,
                headers=self.headers,
                proxies={'http': proxy, 'https': proxy},
                timeout=3   # 超时 3 秒视为不可用
            )
            if resp.status_code == 200:
                print(f'✓ {proxy} 可用')
                return True
        except:
            pass
        print(f'✗ {proxy} 超时')
        return False

    def run(self, pages=5):
        """采集多页 + 测试筛选"""
        for page in range(1, pages + 1):
            proxies = self.fetch_page(page)
            for proxy in proxies:
                if self.test_proxy(proxy):
                    self.valid_proxies.append(proxy)
                time.sleep(0.5)   # 测试间隔——避免被封

        print(f'\n采集完成：{len(self.valid_proxies)} 个可用代理')
        return self.valid_proxies


if __name__ == '__main__':
    pool = FreeProxyPool()
    pool.run(pages=int(input('输入爬取页码: ')))
```

### 2.4 免费代理的局限

| 问题 | 影响 |
|------|------|
| 可用率 < 20% | 采集 100 个只有 15-20 个能用 |
| 存活短 | 几分钟到几小时就失效——需要持续补充 |
| 速度慢 | 延迟高（500ms-3s），拖慢整体爬虫 |
| 不稳定 | 同一个 IP 可能这次能用下次不能用 |

> **结论**：免费代理适合学习和小规模测试。生产环境一律用付费代理。

## 三、付费代理 IP

### 3.1 免费 vs 付费

| | 免费 | 付费 |
|------|------|------|
| 可用率 | < 20% | > 99% |
| 速度 | 慢（500ms-3s） | 快（50-200ms） |
| 稳定性 | 分钟级失效 | 按购买时长稳定 |
| 获取方式 | 手动采集测试 | API 一键提取 |
| 成本 | 0 | 几十到几百元/月 |

> 除了免费，没有优点 vs 除了付费，没有缺点。

### 3.2 快代理付费流程（示例）

```
1. 注册 → 充值
2. 选择套餐 → 购买
3. 账户管理 → 我的订单 → 提取 IP → 生成 API 链接
4. 设置参数：提取数量、返回格式（json/text）、分隔符
5. 请求 API → 直接拿到可用 IP 列表
```

### 3.3 API 提取代码

```python
import requests

# 付费代理 API（购买后生成）
API_URL = 'https://dps.kdlapi.com/api/getdps/?secret_id=xxx&signature=xxx&num=10&format=json'

def get_paid_proxies():
    resp = requests.get(API_URL)
    data = resp.json()
    # data['data']['proxy_list'] → ['1.2.3.4:5678', '5.6.7.8:9012', ...]
    return [f'http://{p}' for p in data['data']['proxy_list']]

proxies = get_paid_proxies()
# 直接使用——无需测试，平台保证可用
```

## 四、代理池集成到爬虫

### 4.1 架构

```
┌──────────────┐   定时补充    ┌──────────────┐
│ 代理获取线程  │ ──────────→  │  代理 Queue   │
│ (免费采集/付费API) │          │  (IP 池)      │
└──────────────┘              └───┬──────┬───┘
                                  │ 取用  │ 归还
                             ┌────▼──────▼───┐
                             │  爬虫工作线程   │
                             └───────────────┘
```

### 4.2 完整集成代码

```python
import threading
import requests
import time
from queue import Queue

class ProxyPoolSpider:
    def __init__(self):
        self.proxy_queue = Queue()
        self.url_queue = Queue()
        self.data_queue = Queue()
        self.headers = {'User-Agent': 'Mozilla/5.0 ...'}
        self.test_url = 'http://httpbin.org/ip'

    # ====== 代理池 ======
    def fill_proxies(self):
        """定时线程：持续补充代理"""
        while True:
            # 从付费 API 获取（或免费采集+测试）
            new_proxies = self.get_paid_proxies()
            for p in new_proxies:
                if self.test_proxy(p):
                    self.proxy_queue.put(p)
            time.sleep(60)   # 每分钟补充一次

    def get_proxy(self):
        """取一个代理"""
        while True:
            proxy = self.proxy_queue.get()
            self.proxy_queue.put(proxy)   # 放回——循环使用
            return proxy

    def discard_proxy(self, proxy):
        """废弃失败代理"""
        # Queue 无法直接删除指定元素——方案：标记过期，取用时跳过
        pass

    def test_proxy(self, proxy):
        try:
            resp = requests.get(self.test_url, proxies={'http': proxy}, timeout=3)
            return resp.status_code == 200
        except:
            return False

    # ====== 爬虫逻辑 ======
    def fetch(self):
        while True:
            url = self.url_queue.get()
            proxy = self.get_proxy()
            try:
                resp = requests.get(
                    url,
                    headers=self.headers,
                    proxies={'http': proxy, 'https': proxy},
                    timeout=10
                )
                self.data_queue.put(resp.json())
            except Exception:
                self.discard_proxy(proxy)   # 代理不行就丢弃
                self.url_queue.put(url)     # 重新排队
            finally:
                self.url_queue.task_done()

    def run(self):
        # 启动代理补充线程
        t_proxy = threading.Thread(target=self.fill_proxies)
        t_proxy.setDaemon(True)
        t_proxy.start()

        # 预填充 URL
        for page in range(1, 100):
            self.url_queue.put(f'https://example.com/api?page={page}')

        # 启动爬虫线程
        for _ in range(5):
            t = threading.Thread(target=self.fetch)
            t.setDaemon(True)
            t.start()

        self.url_queue.join()
```

## 五、代理池使用原则

| 原则 | 说明 |
|------|------|
| **先测试再入库** | 无论免费还是付费——入库前验证可用性不可或缺 |
| **定时补充** | 代理有生命周期——独立线程持续填充 |
| **失败即废弃** | 请求失败的代理立即标记过期，不要重试 |
| **循环使用** | 成功返回的代理放回池中——提高利用率 |
| **区分免费/付费** | 免费代理频率更低、超时更长——分开管理 |
| **注意地域** | 目标网站可能限制特定地区——选对应地域的代理 |

---

## 关键概念

- **高匿名代理**：服务器完全不知道你在用代理——爬虫首选
- **代理测试**：用 `httpbin.org/ip` 验证——返回的 IP = 代理 IP 则代理有效
- **代理 Queue**：线程安全的 IP 池——爬虫线程取用、代理线程补充
- **付费代理 API**：一次请求直接返回可用 IP 列表——免去采集和测试
- **代理轮换**：每个请求换一个代理——降低单 IP 请求频率

## 可行动建议

- 免费代理仅用于学习——生产环境不要幻想着免费 IP 能稳定跑
- 付费代理买之前先看文档——确认 API 格式、提取数量限制、有效时长
- `httpbin.org/ip` 是测试代理最可靠的工具——返回 JSON，一眼判断
- 代理池必须独立线程维护——不要和爬虫逻辑混在一起
- 请求超时设 10s——代理慢了直接换，不要等
