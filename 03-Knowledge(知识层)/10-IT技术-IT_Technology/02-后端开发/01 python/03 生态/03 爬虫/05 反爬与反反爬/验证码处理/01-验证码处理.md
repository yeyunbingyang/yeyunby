# 验证码处理 — 打码平台对接与图片获取

## 一句话结论

> 验证码是爬虫与反爬博弈的终极战场——一旦触发说明身份和行为已被识别。爬虫不会自研图像识别，**统一走第三方打码平台**（云打码、超级鹰等，约 1 分钱/次）。核心环节就两个：**拿到验证码图片**（抓包下载 or Selenium 截图抠图）→ **交给打码平台识别** → 把结果填回去。

---

## 一、验证码在反爬体系中的位置

```
反爬三层防御：
  身份识别 → 行为分析 → 数据加密
                              ↓ 全部突破后
                          验证码（最后防线）
```

**核心逻辑**：当你的 IP、Cookie、请求频率、加密参数都"过关"时，服务器弹出验证码做最终确认——你到底是不是人。

> 验证码的验证参数本质上和登录密码一样：滑块拖到某个位置 → 生成一个**数值** → 作为请求参数传给服务端校验。

---

## 二、常见验证码类型与处理方案

| 类型 | 示例 | 难度 | 处理方案 |
|------|------|------|---------|
| **数字字母图片** | 4 位数字+字母 | ⭐ | 打码平台 / Tesseract OCR |
| **纯数字** | 4-6 位数字 | ⭐ | 打码平台（最快 0.5s） |
| **纯汉字** | 2-4 个中文 | ⭐⭐ | 打码平台（汉字类型） |
| **加减乘除** | "3 + 5 = ?" | ⭐ | 打码平台 / 直接 eval |
| **滑块拼图** | 拖动拼图到缺口 | ⭐⭐ | 打码平台 + Selenium 模拟拖动 |
| **点选验证** | 按顺序点击图中文字 | ⭐⭐⭐ | 打码平台（返回坐标）+ Selenium 点击 |
| **旋转验证** | 旋转图片到正确角度 | ⭐⭐⭐ | 打码平台（返回角度）+ 模拟拖动 |
| **九宫格** | Google 式图片选择 | ⭐⭐⭐ | 专门打码平台 |
| **行为验证（极验/顶象）** | 滑动 + 轨迹分析 | ⭐⭐⭐⭐ | 打码平台 / 逆向 w 参数 |

## 三、获取验证码图片的两种路径

这是处理验证码的第一个实际问题——你连图都拿不到，识别无从谈起。

### 3.1 路径一：抓包分析 URL → 直接下载

适用于：验证码的 `<img>` 标签有明确的 `src`，且每次访问该 URL 都会返回新验证码。

```python
import requests

session = requests.Session()

# 获取验证码图片的 URL（从 HTML 中提取或抓包获取）
captcha_url = 'https://example.com/captcha/image?t=1234567890'

# 直接下载到内存（不落盘）
resp = session.get(captcha_url)
captcha_bytes = resp.content  # 直接拿 bytes，交给打码平台
```

**常见坑**：URL 不变但验证码会变——每次 `GET` 同一个 URL 返回不同图片（后端用 Cookie/Session 绑定）。解决：请求时保持 Session，不要跨 Session 下载。

### 3.2 路径二：Selenium 截屏 → 抠图

适用于：验证码图片是通过 Canvas 渲染、或 URL 无法直接访问、或有复杂的 Cookie 绑定。

```python
from selenium import webdriver
from PIL import Image
from io import BytesIO

driver = webdriver.Chrome()
driver.get('https://example.com/login')

# 1. 定位验证码元素
captcha_el = driver.find_element(By.ID, 'captcha_img')

# 2. 获取验证码元素在页面中的位置和尺寸
location = captcha_el.location      # {'x': 200, 'y': 300}
size = captcha_el.size              # {'width': 120, 'height': 40}

# 3. 截取整个浏览器窗口
screenshot = driver.get_screenshot_as_png()

# 4. 用 PIL 从全屏截图中抠出验证码区域
full_img = Image.open(BytesIO(screenshot))
left = location['x']
top = location['y']
right = left + size['width']
bottom = top + size['height']
captcha_img = full_img.crop((left, top, right, bottom))

# 5. 转为 bytes 交给打码平台
buf = BytesIO()
captcha_img.save(buf, format='PNG')
captcha_bytes = buf.getvalue()
```

> Selenium 抠图方案操作繁琐但通用性强——任何能显示在浏览器中的验证码都能拿到。适合复杂前端渲染、Canvas 类型的验证码。

### 3.3 两种路径对比

| | 抓包下载 | Selenium 截图抠图 |
|------|---------|----------------|
| 速度 | 快 | 慢（开浏览器 + 截图 + 裁剪） |
| 复杂度 | 低 | 中（需要算坐标） |
| 适用性 | URL 可直连的场景 | 任何可见验证码 |
| DPI 问题 | 无 | 需注意高分屏缩放导致的坐标偏移 |

## 四、打码平台对接（以云打码为例）

### 4.1 为什么用第三方平台

| 方案 | 问题 |
|------|------|
| 自研 OCR（Tesseract） | 对模糊、扭曲、干扰线验证码几乎无效——准确率 < 30% |
| 自训模型 | 需要大量标注数据，投入产出比极低 |
| **第三方打码平台** | 背后是人工打码+AI 混合，准确率 > 95%，1 分钱/次 |

> **爬虫铁律**：不自研验证码识别。打码平台是唯一合理方案。

### 4.2 云打码接入流程

**Step 1：注册并充值**

访问云打码官网 → 注册账号 → 登录后台 → 充值（积分制）。

**Step 2：获取 API 文件**

进入开发文档 → 调用示例 → 下载 Python HTTP 示例 → 解压得到接口文件。

**Step 3：配置参数**

```python
# 云打码接口文件中的关键配置
username = 'your_username'     # 登录账号（必填）
password = 'your_password'     # 登录密码（必填）
app_id    = '1234'             # 软件 ID（用于分成，可不填）
app_key   = 'your_app_key'     # 软件 Key（用于分成，可不填）
codetype  = 1004               # 验证码类型（如 1004 = 4位字母+数字）
timeout   = 60                 # 超时时间（秒）
```

**Step 4：常用 codetype 速查**

| codetype | 含义 |
|----------|------|
| 1004 | 4 位英文字母+数字 |
| 1005 | 不定长英文字母+数字 |
| 1006 | 纯汉字 |
| 1007 | 纯英文 |
| 1008 | 纯数字 |
| 2000 | 特殊类型（加减乘除、知识问答等） |
| 3000 | 不定长汉字 |

**Step 5：调用识别**

```python
import requests

# 封装为通用方法——直接接收 response.content（bytes），不落盘
class YdmVerify:
    def __init__(self, username, password, codetype=1004):
        self.username = username
        self.password = password
        self.codetype = codetype
        # 登录获取 token（具体参数以官方 API 文档为准）
        self.token = self._login()

    def _login(self):
        resp = requests.post('http://api.yundama.com/login', data={
            'username': self.username,
            'password': self.password,
        })
        return resp.json()['token']

    def identify(self, image_bytes):
        """传入图片的 bytes，返回识别结果字符串"""
        resp = requests.post('http://api.yundama.com/identify', data={
            'token': self.token,
            'codetype': self.codetype,
        }, files={'image': ('captcha.png', image_bytes)})
        return resp.json()['result']  # 如 '3xK9'


# ====== 使用 ======
ydm = YdmVerify('username', 'password')

# 方式 1：从 URL 直接下载
captcha_resp = requests.get('http://example.com/captcha.png')
result = ydm.identify(captcha_resp.content)
print(f'识别结果: {result}')

# 方式 2：从本地文件读取
with open('captcha.png', 'rb') as f:
    result = ydm.identify(f.read())
print(f'识别结果: {result}')
```

> **核心技巧**：封装 `identify(image_bytes)` 方法——调用方直接传 `response.content`，无需先把图片保存到磁盘再读回来。省一次 IO，简化调用链。

## 五、完整登录流程（含验证码）

```python
import requests
from ydm_api import YdmVerify   # 上面封装的打码类

session = requests.Session()
session.headers.update({'User-Agent': 'Mozilla/5.0 ...'})

# 1. GET 登录页 → 拿 Cookie + 提取表单隐藏字段
login_page = session.get('https://example.com/login')
csrf_token = re.search(r'name="csrf_token" value="(.*?)"', login_page.text).group(1)

# 2. 下载验证码图片
captcha_url = 'https://example.com/captcha/image'
captcha_resp = session.get(captcha_url)

# 3. 打码平台识别
ydm = YdmVerify('user', 'pass')
captcha_result = ydm.identify(captcha_resp.content)

# 4. 构造登录请求
login_data = {
    'csrf_token': csrf_token,
    'username': 'admin',
    'password': '123456',
    'captcha': captcha_result,      # ← 识别结果填入
}

# 5. 提交登录
resp = session.post('https://example.com/api/login', data=login_data)
print(resp.json())

# 6. 验证码错误 → 重试
if '验证码错误' in resp.text:
    print('验证码识别失败，重试中...')
    captcha_resp = session.get(captcha_url)
    captcha_result = ydm.identify(captcha_resp.content)
    login_data['captcha'] = captcha_result
    resp = session.post('https://example.com/api/login', data=login_data)
```

## 六、其他打码平台速览

| 平台 | 特点 | 适用场景 |
|------|------|---------|
| **云打码** | 老牌平台，文档全，Python 示例完备 | 通用图片验证码 |
| **超级鹰** | 支持滑块/点选/旋转等复杂类型 | 行为验证码 |
| **图鉴** | 接口简单，响应快 | 简单数字字母 |
| **斐斐打码** | 价格低，量大优惠 | 大批量常规验证码 |
| **极验验证码** | 专门针对极验（GEETEST）滑块 | 极验系网站 |

> 选择原则：先确定目标网站验证码类型 → 找支持该类型的平台 → 对比价格和文档质量。云打码解决 80% 通用场景，剩下 20% 复杂类型上超级鹰。

## 七、Tesseract 本地 OCR（备选方案）

打码平台的免费替代——但仅适用于**极简单**的验证码（无干扰线、无扭曲、字体标准）。

### 7.1 安装

```bash
pip install pytesseract Pillow
# Windows 还需安装 Tesseract-OCR 程序并配置环境变量
```

### 7.2 基本使用

```python
import pytesseract
from PIL import Image
from io import BytesIO
import requests

# 下载验证码
resp = requests.get('http://example.com/simple_captcha.png')
img = Image.open(BytesIO(resp.content))

# 直接识别
text = pytesseract.image_to_string(img)
print(f'识别结果: {text.strip()}')
```

### 7.3 预处理提升准确率

```python
from PIL import ImageFilter

# 1. 灰度化
img = img.convert('L')

# 2. 二值化（阈值 127）
img = img.point(lambda x: 0 if x < 127 else 255)

# 3. 去噪 / 锐化
img = img.filter(ImageFilter.SHARPEN)

# 4. 放大（提高 OCR 准确率）
img = img.resize((img.width * 2, img.height * 2), Image.LANCZOS)

text = pytesseract.image_to_string(img, config='--psm 7')
print(f'预处理后识别: {text.strip()}')
```

> **结论**：Tesseract 对标准印刷体准确率高，对扭曲/干扰线/低对比度验证码几乎失效。只适合作为备选方案，不要指望它解决实际问题。

## 八、验证码处理决策树

```
遇到验证码
  ├→ 能跳过吗？
  │     └→ 换 IP / 降速 / 换 Cookie 试——验证码是最后防线，前置方案没做好才会触发
  │
  ├→ 必须处理 → 什么类型？
  │     ├→ 简单数字字母 → 云打码（1 分钱/次）
  │     ├→ 滑块/点选/旋转 → 超级鹰 / 专门平台
  │     └→ 极验/顶象行为验证 → 打码平台 or 逆向 w 参数（成本高）
  │
  └→ 图片怎么拿到？
        ├→ URL 可直接请求 → 直接 requests 下载
        └→ Canvas/复杂渲染 → Selenium 截图抠图
```

---

## 关键概念

- **打码平台**：人工打码 + AI 混合的第三方验证码识别服务，准确率 > 95%
- **codetype**：验证码类型编号——告诉平台你要识别的是什么（数字/汉字/特殊类型）
- **`response.content` 直传**：验证码图片不落盘，从 HTTP 响应直接取 bytes 交给打码平台——省 IO，是爬虫的最佳实践
- **Selenium 抠图**：截取全屏 → 用元素坐标裁剪出验证码区域——通用方案但需要处理高分屏缩放

## 可行动建议

- **不要自研验证码识别**——用打码平台，成本 1 分钱/次，节省的时间远超过打码费用
- 触发验证码是先兆——先检查 IP/频率/Cookie 是否有问题，而不是上来就打码
- 封装 `identify(bytes)` 方法——让调用方传 `response.content`，不要落盘
- Selenium 截图抠图时注意 DPI 缩放——高分屏（150% 缩放）会导致坐标偏移 1.5 倍
- 云打码 codetype 要设对——类型不对识别结果全废，查阅平台文档确认
