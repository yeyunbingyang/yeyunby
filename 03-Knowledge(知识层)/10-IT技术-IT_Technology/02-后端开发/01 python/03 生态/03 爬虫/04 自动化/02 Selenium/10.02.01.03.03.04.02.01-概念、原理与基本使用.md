# Selenium 介绍 — 概念、原理与基本使用

## 一句话结论

> Selenium 通过 ChromeDriver 操控真实浏览器——JS 渲染、反爬对抗它都能搞定，代价是速度慢。在能用 requests + 数据提取搞定的场景不要用它，遇到强制 JS 渲染的页面时它是最可靠的后备方案。

---

## 一、Selenium 是什么

### 定位

Selenium 是一个 **Web 自动化测试工具**，最初为软件测试设计。对爬虫而言，它的核心价值是：

> **直接操控真实的浏览器**——浏览器看到的页面什么样，Selenium 拿到的就什么样。

### 支持的浏览器

| 浏览器 | 驱动 |
|--------|------|
| Chrome | ChromeDriver |
| Firefox | GeckoDriver |
| Safari | SafariDriver（内置）|
| Edge | EdgeDriver |
| Opera | OperaDriver |

> 360、搜狗、UC 等国产浏览器**不支持**。爬虫中最常用 Chrome + ChromeDriver。

### 工作原理

```
你的 Python 代码
    ↓ 发送指令（find_element / click / send_keys）
ChromeDriver（中间桥梁）
    ↓ 翻译成浏览器能理解的协议
Chrome 浏览器（真实浏览器实例）
    ↓ 渲染页面、执行 JS、发起网络请求
返回结果给 Python
```

> ChromeDriver 是**必须安装**的中间件，没有它 Selenium 无法工作。

## 二、安装与配置

### 2.1 安装 Selenium

```bash
pip install selenium
```

### 2.2 安装 ChromeDriver

这是 Selenium 使用中最容易踩的坑——**版本必须匹配**：

| 步骤 | 操作 |
|------|------|
| 1 | 打开 Chrome → 地址栏 `chrome://version/` → 查看版本号（如 `120.0.6099.109`）|
| 2 | 去 https://chromedriver.chromium.org/ 下载**对应大版本**的 ChromeDriver |
| 3 | 解压 `chromedriver.exe`，放到 Python 安装目录下（和 `python.exe` 同级）|

**验证安装**：

```bash
chromedriver --version
# ChromeDriver 120.0.6099.109 (...)
```

> 版本不对齐 = 代码跑不起来。大版本匹配即可（120.x.x 配 120.x.x）。

### 2.3 基础验证代码

```python
from selenium import webdriver

# 创建浏览器对象（ChromeDriver 必须已安装到 PATH）
driver = webdriver.Chrome()

# 访问页面
driver.get('https://www.baidu.com')

# 打印标题
print(driver.title)          # 百度一下，你就知道

# 打印当前 URL
print(driver.current_url)

# 关闭浏览器
driver.quit()
```

运行效果：自动打开 Chrome → 访问百度 → 打印标题 → 自动关闭。

## 三、Selenium vs requests 定位

| | requests + lxml | Selenium |
|---|---|---|
| 速度 | ⭐⭐⭐ 快 | ⭐ 慢（每次操作都走浏览器） |
| JS 渲染 | ❌ 不支持 | ✅ 完整支持 |
| 反爬对抗 | 弱（需手动处理 headers/cookie）| 中（真实浏览器指纹） |
| 资源占用 | 低 | 高（开一个完整浏览器进程） |
| 使用门槛 | 低 | 中（需安装驱动、处理等待） |
| 适用场景 | 静态页面、API 接口 | **JS 动态渲染**、复杂交互 |

### 选型黄金法则

```
能用 requests 搞定 → 不用 Selenium
页面数据通过 Ajax 返回 JSON → 直接调接口（比 Selenium 快 10 倍）
页面必须 JS 渲染后才出数据 → 上 Selenium
需要模拟点击/滚动/拖拽 → Selenium（或 DrissionPage）
```

## 四、基本 API 速览

```python
from selenium import webdriver

driver = webdriver.Chrome()

# ====== 页面操作 ======
driver.get('https://www.baidu.com')           # 打开页面
driver.refresh()                                # 刷新
driver.back()                                   # 后退
driver.forward()                                # 前进
driver.close()                                  # 关闭当前标签页
driver.quit()                                   # 退出整个浏览器

# ====== 获取页面信息 ======
driver.title                                    # 页面标题
driver.current_url                              # 当前 URL
driver.page_source                              # 页面 HTML 源码

# ====== 窗口管理 ======
driver.maximize_window()                        # 最大化
driver.set_window_size(1920, 1080)              # 设置窗口大小
driver.get_screenshot_as_file('screenshot.png') # 截图
```

## 五、Selenium 生态现状

> ⚠️ Selenium 是经典工具但已有更优替代方案。

| 工具 | 优势 | 劣势 |
|------|------|------|
| **Selenium** | 生态成熟、资料多、跨语言 | 需装驱动、API 繁琐、速度慢 |
| **DrissionPage** | 无需驱动、自动等待、iframe 穿透、可接管已有 Chrome | 仅 Python、社区较小 |
| **Playwright** | 速度快、自动等待、多浏览器 | 安装较大、API 变动频繁 |

> 本课程以 Selenium 教学为主（因为资料多、原理通用），但实际项目中可优先考虑 DrissionPage。

## 关键概念

- **ChromeDriver**：Selenium 与 Chrome 之间的桥梁，版本必须与 Chrome 匹配
- **真实浏览器**：Selenium 操控的是真实浏览器实例——JS 渲染、Cookie、WebSocket 全部原生支持
- **性能代价**：每打开一个 Selenium 实例 = 启动一个浏览器进程，比 requests 慢 10-100 倍
- **`.quit()` vs `.close()`**：前者关闭整个浏览器（推荐），后者只关当前标签页

## 可行动建议

- ChromeDriver 版本对齐是第一关——打开 `chrome://version/` 确认大版本号再去下载
- 能用 requests + 数据提取搞定的场景绝对不用 Selenium
- 必须用浏览器自动化的场景优先考虑 DrissionPage（更轻量）
- 代码结束必须 `driver.quit()`，否则会有残留浏览器进程
