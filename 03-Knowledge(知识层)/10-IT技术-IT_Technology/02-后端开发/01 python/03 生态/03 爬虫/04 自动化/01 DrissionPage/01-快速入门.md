# DrissionPage 快速入门 — 安装与浏览器控制

## 一句话结论

> DrissionPage = `requests` 的简洁 + `Selenium` 的浏览器能力——一个库同时搞定 HTTP 请求和浏览器自动化，且无需下载 chromedriver，开箱即用。

---

## 一、DrissionPage 是什么

### 定位

DrissionPage 是一个国产 Python 自动化库（作者：g1879），它融合了两种能力：

| 能力 | 对应模块 | 相当于 |
|------|---------|--------|
| HTTP 请求 + 解析 | `SessionPage` | requests + BeautifulSoup 合体 |
| 浏览器控制 | `ChromiumPage` | Selenium 但无需 WebDriver 配置 |

### 为什么选它

| 对比        | requests      | Selenium               | DrissionPage         |
| --------- | ------------- | ---------------------- | -------------------- |
| HTTP 请求   | ✅ 核心能力        | ❌                      | ✅ SessionPage        |
| 浏览器控制     | ❌             | ✅ 需 chromedriver       | ✅ 自动接管               |
| JS 渲染     | ❌             | ✅                      | ✅                    |
| 反爬对抗      | 弱             | 中                      | 强（可操控已打开的浏览器）        |
| 安装复杂度     | `pip install` | `pip` + 下载驱动 + 配置 PATH | **`pip install` 一步** |
| iframe 切换 | ❌             | 需 `switch_to`          | 自动穿透                 |
| 学习曲线      | 低             | 中                      | 低                    |

### 核心设计理念

```
「页面对象」模式：把整个网页（或浏览器标签页）抽象为一个对象
    → 你操作 page 对象，page 对象帮你完成底层 HTTP 或浏览器操作
    → 同一套 API 风格贯穿 SessionPage 和 ChromiumPage
```

## 二、安装

### 2.1 基础安装

```bash
pip install DrissionPage
```

**一步完成**，无需下载 chromedriver，无需配置 PATH，无需处理浏览器版本匹配。

### 2.2 自动下载浏览器

从 v4.0 开始，首次使用 ChromiumPage 时会**自动下载**匹配的 Chromium 浏览器：

```python
from DrissionPage import ChromiumPage

# 首次运行会自动下载 Chromium 浏览器到用户目录
page = ChromiumPage()   # 自动启动浏览器
```

如果你想**手动指定**浏览器路径：

```python
from DrissionPage import ChromiumOptions, ChromiumPage

co = ChromiumOptions()
co.set_browser_path(r'C:\Program Files\Google\Chrome\Application\chrome.exe')

page = ChromiumPage(co)
```

### 2.3 接管已打开的浏览器（核心反爬能力）

DrissionPage 的杀手级功能——接管你**手工打开的 Chrome**，继承所有登录态、Cookie、指纹：

```python
from DrissionPage import ChromiumOptions, ChromiumPage

co = ChromiumOptions()
# 设置调试端口——和 Chrome 启动时一致
co.set_local_port(9222)
# 或自动查找已有端口
co.auto_port()

page = ChromiumPage(co)
# page 现在是你在 Chrome 中已经登录的那个标签页
```

**Chrome 启动方式**（Windows）：

```bash
# 快捷方式 → 目标 一栏后面添加：
chrome.exe --remote-debugging-port=9222
```

> 这一步在实际爬虫开发中价值极高：你手动登录 → DrissionPage 接管 → 所有 Cookie/WebSocket/指纹全继承，反爬直接绕过。

## 三、浏览器控制入门 — ChromiumPage

### 3.1 打开页面

```python
from DrissionPage import ChromiumPage

page = ChromiumPage()

# 访问网址
page.get('https://www.baidu.com')

# 打印页面标题
print(page.title)          # 百度一下，你就知道

# 获取页面 HTML
print(page.html[:200])     # 前 200 字符

# 获取当前 URL
print(page.url)
```

### 3.2 元素定位

DrissionPage 的元素定位方式极其简洁：

```python
# ====== 方式一：直接属性定位（推荐）======
page.ele('@id=kw')                         # id 定位
page.ele('@name=wd')                       # name 定位
page.ele('@class=form-control')            # class 定位
page.ele('@placeholder=搜索')              # 任意属性
page.ele('tag=input')                      # 标签名
page.ele('text=百度一下')                  # 文本定位

# ====== 方式二：CSS 选择器 ======
page.ele('#kw')
page.ele('.form-control')

# ====== 方式三：XPath ======
page.ele('xpath://input[@id="kw"]')

# 获取多个元素
items = page.eles('tag=li')               # 所有 li 标签
```

### 3.3 元素操作

```python
# 定位搜索框
input_box = page.ele('@id=kw')

# 输入文本
input_box.input('DrissionPage')

# 清空后输入
input_box.clear()
input_box.input('Python 爬虫')

# 点击
search_btn = page.ele('@id=su')
search_btn.click()

# 获取文本
result = page.ele('@class=result')
print(result.text)

# 获取属性
link = page.ele('tag=a')
print(link.attr('href'))
print(link.link)           # 获取绝对链接（自动补全）
```

### 3.4 等待机制

DrissionPage 内置**自动等待**——大多数情况无需手动 `sleep()`：

```python
# 默认等待元素加载（自动重试）
page.ele('@id=kw').input('hello')   # 如果元素还没出现，自动等待

# 显式等待
page.wait.ele_displayed('@id=result', timeout=5)    # 等待元素可见
page.wait.ele_hidden('@class=loading', timeout=5)   # 等待元素隐藏
page.wait.load_complete()                             # 等待页面加载完成

# 自定义等待条件
page.wait(3)   # 简单等 3 秒
```

### 3.5 标签页管理

```python
page = ChromiumPage()

# 获取当前所有标签页
tabs = page.get_tabs()
print(f'共 {len(tabs)} 个标签页')

# 创建新标签页
new_tab = page.new_tab('https://www.example.com')

# 切换到指定标签页
page.set.tab(tabs[0])

# 关闭当前标签页
page.close()
```

### 3.6 iframe 自动穿透

这是 DrissionPage 相比 Selenium 的一大优势——**无需 `switch_to`**，直接操作 iframe 内元素：

```python
# Selenium 写法（繁琐）
driver.switch_to.frame('iframe_id')
driver.find_element(By.ID, 'btn').click()
driver.switch_to.default_content()

# DrissionPage 写法（直接操作）
page.ele('@id=btn').click()   # 自动跨 iframe 定位
```

## 四、SessionPage — 无需浏览器的 HTTP 请求

对于不需要 JS 渲染的场景，用 `SessionPage` 替代 `requests`：

```python
from DrissionPage import SessionPage

page = SessionPage()

# GET 请求
page.get('https://www.baidu.com')
print(page.status_code)
print(page.html[:200])

# POST 请求
page.post('https://httpbin.org/post', data={'key': 'value'})

# 自动解析 JSON
resp = page.get('https://api.example.com/data')
print(resp.json)           # dict 类型

# headers / cookies
page.set.headers({'User-Agent': 'Mozilla/5.0 ...'})
page.set.cookies({'token': 'abc123'})

# 元素定位——和 ChromiumPage 完全一致
items = page.eles('tag=li')
for item in items:
    print(item.text)
```

### SessionPage vs requests 对比

| 功能 | requests | SessionPage |
|------|---------|------------|
| 发请求 | ✅ | ✅ |
| 自动保持 Session | 需 `requests.Session()` | 默认内置 |
| HTML 解析 | 需额外 BS4/lxml | **内置** `ele()` / `eles()` |
| 编码处理 | 手动 | 自动 |
| 连接池 | 默认 | 连接复用 |
| API 风格 | 多库配合 | **一个对象搞定全部** |

## 五、DrissionPage 选型速查

```
需要操控浏览器（JS 渲染、反爬、登录）？
    → 是 → ChromiumPage
        → 需要继承已有登录态？→ 接管已打开的 Chrome
    → 否 → 只用 HTTP 请求 + HTML 解析？
        → 是 → SessionPage（比 requests + BS4 更简洁）
```

## 常用 API 速查

| 需求 | 代码 |
|------|------|
| 创建浏览器页面 | `page = ChromiumPage()` |
| 创建请求页面 | `page = SessionPage()` |
| 访问 URL | `page.get(url)` |
| 定位单个元素 | `page.ele('@id=xxx')` |
| 定位多个元素 | `page.eles('tag=li')` |
| 输入文本 | `ele.input('text')` |
| 点击 | `ele.click()` |
| 获取文本 | `ele.text` |
| 获取属性 | `ele.attr('href')` |
| 获取 HTML | `page.html` |
| 等待元素出现 | `page.wait.ele_displayed('@id=xxx')` |
| 接管已有 Chrome | `co.auto_port()` + `ChromiumPage(co)` |
| 新建标签页 | `page.new_tab(url)` |

## 关键概念

- **ChromiumPage**：浏览器控制模式——操控真实 Chromium 浏览器
- **SessionPage**：HTTP 请求模式——不打开浏览器，直接发请求 + 解析
- **接管浏览器**：连接到已打开的 Chrome 窗口，继承所有登录态和指纹
- **自动等待**：元素未出现时自动重试，不需要手动 `sleep()`
- **iframe 穿透**：直接定位 iframe 内元素，无需 `switch_to`
- **ele() vs eles()**：前者返回单个元素，后者返回列表

## 可行动建议

- 简单 HTTP 请求 + 解析 → **SessionPage** 一步到位，替代 requests + BS4
- 需要 JS 渲染 → **ChromiumPage**，替代 Selenium
- 需要登录态 → **接管 Chrome**，手动登录后接管，反爬效果最好
- 定位元素优先用 `'@属性=值'` 格式，比 CSS/XPath 更直观
- 不需要手动 `sleep()`——DrissionPage 内置等待机制
