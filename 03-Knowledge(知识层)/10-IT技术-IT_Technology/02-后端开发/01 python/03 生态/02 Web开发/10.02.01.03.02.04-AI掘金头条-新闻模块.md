## 三、模块化路由

### 为什么要模块化路由

将每个业务功能的接口拆分到独立文件里，再统一挂载到主应用中。

```python
# 避免 main.py 爆炸 — 所有接口堆在一个文件

@app.get("/users")
def get_users(): ...
@app.post("/users")
def create_user(): ...
@app.get("/news_categories")
def get_categories(): ...
@app.get("/news_list")
def get_news_list(): ...
@app.get("/news_detail")
def get_news_detail(): ...
# ... 越来越多，难以维护
```

### 优势

- **避免 main.py 爆炸**：main.py 只负责启动应用
- **项目结构更清晰**：接口按模块拆分
- **更易维护**：每个模块负责自己的接口，便于快速查找和定向修改

### 实现方式

**编写独立路由模块：**

```python
from fastapi import APIRouter

# 创建 APIRouter 实例
router = APIRouter(prefix="/api/news", tags=["news"])

@router.get("/categories")
async def get_categories():
    return {"msg": "获取分类成功"}
```

**main.py 中挂载路由：**

```python
app.include_router(news.router)
```

## 四、跨域资源共享（CORS）

### 什么是 CORS

CORS 是一种浏览器安全机制，用于允许运行在一个源（Origin）的 Web 应用，通过浏览器向另一个源的服务器发起跨域 HTTP 请求。

**同源的三个条件：** 协议 + 域名 + 端口（三者必须相同）

```
前端 Vue:  http://localhost:5173/
后端 API:  http://127.0.0.1:8000/
           ↑ 协议相同，但域名不同 → 跨域
```

### 解决方案：CORS 中间件

```python
from fastapi.middleware.cors import CORSMiddleware

# 允许的来源（可以是域名列表）
origins = [
    "http://localhost",
    "http://localhost:3000",
    "https://your-frontend-domain.com"
]

# 添加 CORS 中间件
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],     # 允许访问的源
    allow_credentials=True,  # 允许携带 Cookie
    allow_methods=["*"],     # 允许所有请求方法
    allow_headers=["*"],     # 允许所有请求头
)
```

## 六、新闻列表接口

### 请求参数

```python
@router.get("/list")
async def get_news(
    category_id: int = Query(..., alias="categoryId"),
    page: int = 1,
    page_size: int = Query(10, le=100, alias="pageSize")
):
    return {
        "code": 200,
        "message": "success",
        "data": {
            "list": "news_list",
            "total": "total_count",
            "hasMore": "has_more"
        }
    }
```

### 业务逻辑流程

```
进入请求 → 按分类ID查询新闻 → 分页查询(offset/limit)
       → 获取新闻总数量 → 计算是否有更多新闻 → 响应结果
```

- **分页查询**：`select().offset(skip).limit(pageSize)`，其中 `skip = (page - 1) * pageSize`
- **聚合计算**：`select(func.count())`
- **是否有更多**：`(offset + 当前新闻列表条数) < 总量`

## 八、ORM 索引与排序

### 创建索引

```python
class News(Base):
    __tablename__ = "news"
    __table_args__ = (
        Index('fk_news_category_idx', 'category_id'),
        Index('idx_publish_time', 'publish_time')
    )
```

### 排序

```python
# 按浏览量降序
select(News).order_by(News.views.desc())
```

### update 方式更新字段

```python
async def increase_news_views(db: AsyncSession, news_id: int):
    stmt = update(News).where(News.id == news_id).values(views=News.views + 1)
    result = await db.execute(stmt)
    await db.commit()
    return result.rowcount > 0  # 命中了一条数据返回 True
```
