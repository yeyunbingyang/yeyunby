> 用户注册、用户登录、获取和修改用户信息

```

    ↓              ↓              ↓              ↓
APIRouter      class 继承    select()/add()   Depends 注入
include_router DeclarativeBase  /update()/    调用逻辑
```

## 二、用户注册

### 路由定义

```python
router = APIRouter(prefix="/api/user", tags=["user"])

@router.post("/register")
async def register_user(user_data: UserRegisterRequest):
    return {
        "code": 200,
        "message": "注册成功",
        "data": {
            "token": "token",
            "userInfo": {
                "id": "user.id",
                "username": "user.username",
                "bio": "user.bio",
                "avatar": "user.avatar"
            }
        }
    }
```

### 业务流程

```
进入请求 → 检查用户是否存在
              → 不存在：创建用户（密码加密 + add）→ 生成 Token → 响应
              → 存在：抛出异常
```

**参数（POST，Pydantic 类型）：**
- `username`：用户名
- `password`：密码

**关键步骤：**
- 检查用户：`select().where(User.username == username)`
- 密码加密：passlib（哈希算法）
- 生成 Token：`token = str(uuid.uuid4())`

```python
# 2. 创建加密上下文
from passlib.context import CryptContext

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")

# 3. 加密或校验
hashed = pwd_context.hash(password)                          # 加密
is_valid = pwd_context.verify(plain_password, hashed_password)  # 校验
```

## 四、Token 认证

### 什么是 Token

Token 是服务器发给客户端的一段字符串，用来在后续请求中证明"你已经登录过了"。

**作用：** 解决 HTTP 无状态问题，在每次请求中"自我证明身份"。

### Token 工作流程

```
登录或注册 → 后端生成 Token → 返回 Token → 前端保存 Token
                                          ↓
                              每次请求时携带 Token → 后端验证 Token
```

### Token 在请求头中的位置

```
Authorization: Bearer <token>
```

- `Authorization`：专门用来放身份信息的请求头
- `Bearer`：表示"持有者令牌"
- `<token>`：真正的身份凭证（UUID 生成）

## 五、封装通用响应格式

### 三层封装

```python
# ① 封装函数：统一响应格式
from fastapi.responses import JSONResponse
from fastapi.encoders import jsonable_encoder

def success_response(message: str = "success", data=None):
    content = {"code": 200, "message": message, "data": data}
    return JSONResponse(content=jsonable_encoder(content))

# ② 定义响应模型类
from pydantic import BaseModel, ConfigDict

class UserAuthResponse(BaseModel):
    token: str
    user_info: UserInfoResponse
    model_config = ConfigDict(
        from_attributes=True,  # 自动序列化 user_info 中的 ORM 对象
    )

# ③ 调用函数响应结果
response_data = UserAuthResponse(
    token=token,
    user_info=UserInfoResponse.model_validate(user)
)
return success_response(message="注册成功", data=response_data)
```

**`jsonable_encoder`**：把任何 FastAPI/Pydantic/ORM 对象转换成可以被 JSON 安全序列化的数据结构。

## 六、全局异常处理器

全局异常处理器注册在 FastAPI 应用级别，用于捕获业务层、数据库层以及系统层抛出的异常，并以统一的响应格式返回给前端。

**可捕获的异常：**
- SQL 错误
- 外键关联失败
- 数据库连接异常
- 提交事务失败
- 以及其他未预期的异常

### 注册方式

```python
# Step 1: 定义异常处理器（函数）
async def business_exception_handler(request, exc):
    return JSONResponse(
        status_code=400,
        content={"code": 400, "message": str(exc)}
    )

# Step 2: 全局注册异常处理器
app.add_exception_handler(BusinessException, business_exception_handler)
```

**注册顺序（由具体到通用）：**
1. 业务异常
2. 数据约束异常（子类）
3. 数据库异常（父类）
4. 所有异常（兜底）

## 七、用户登录

### 路由定义

```python
@router.post("/login")
async def login_user(login_data: UserRequest):
    return {
        "code": 200,
        "message": "登录成功",
        "data": {
            "token": "token",
            "userInfo": {
                "id": "user.id",
                "username": "user.username",
                "nickname": "user.nickname",
                "avatar": "user.avatar",
                "bio": "user.bio"
            }
        }
    }
```

### 业务流程

```
进入请求 → 检查用户是否存在
              → 存在 → 验证密码（明文 vs 密文）
                         → 一致 → 生成 Token → 响应
                         → 不一致 → 返回 None
              → 不存在 → 返回 None
```

**参数（POST，Pydantic 类型）：**
- `username`：用户名
- `password`：密码

**验证密码：** 使用 `CryptContext` 内置 `verify` 方法

## 八、获取用户信息

### 路由定义

```python
@router.get("/info")
async def get_user_info():
    return {
        "code": 200,
        "message": "success",
        "data": {
            "id": "user.id",
            "username": "user.username",
            "nickname": "user.nickname",
            "avatar": "user.avatar",
            "gender": "user.gender",
            "bio": "user.bio"
        }
    }
```

### 业务流程

```
进入请求 → 检查令牌有效性
           → 有令牌且未过期 → 查找对应用户 → 响应
           → 无令牌或过期 → 返回 None → 抛出异常
```

**认证方式：** 从请求头获取 Token

```python
from fastapi import Header

@app.get("/info")
async def get_token(authorization: str = Header(...)):
    pass
```

```python
from fastapi import Header

@app.get("/info")
async def get_user_info(authorization: str = Header(...)):
    # 从请求头 Authorization 字段获取 Token
    pass
```

**请求头主要包含：**
- 身份信息（Authorization）
- 请求控制信息
- 数据格式说明
- 客户端环境信息

## 十一、修改密码

```python
@router.put("/password")
async def change_password(password_data: UserChangePwdRequest):
```

### 业务流程


**参数：** 旧密码、新密码
