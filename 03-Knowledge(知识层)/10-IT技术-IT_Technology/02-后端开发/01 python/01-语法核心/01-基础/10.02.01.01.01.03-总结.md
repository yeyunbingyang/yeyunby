## 2. print() —— 输出

```python
print("hello")                      # 普通输出
print("a", "b", sep="-")            # a-b
print("hello", end="!")             # hello!
```

### 格式化输出

| 方式           | 语法               | 推荐度    |
| ------------ | ---------------- | ------ |
| **f-string** | `f"{变量:.2f}"`    | ⭐⭐⭐ 首选 |
| format()     | `"{}".format(x)` | ⭐⭐     |
| % 占位符        | `"%.2f" % x`     | ⭐ 旧式   |

### 常用占位符速查

| 占位符         | 含义     | 示例                          |
| ----------- | ------ | --------------------------- |
| `%s`        | 字符串    | `"%s" % "hi"`               |
| `%d`        | 整数     | `"%d" % 42`                 |
| `%f`        | 浮点数    | `"%f" % 3.14`               |
| `%.2f`      | 保留2位   | `"%.2f" % 3.14159` → `3.14` |
| `%x` / `%o` | 十六/八进制 |                             |

```python
name = "张三"; age = 25
print(f"{name} 今年 {age} 岁")       # f-string
print("{} 今年 {} 岁".format(name, age))  # format
print("%s 今年 %d 岁" % (name, age)) # %-style
```

## 3. input() —— 输入

```python
name = input("请输入姓名：")
print(f"你好，{name}")
```

> **注意**：`input()` 始终返回**字符串**，需要数字时用 `int()` / `float()` 转换。

## 4. 类型检查

```python
type(42)              # <class 'int'>  —— 精确类型
isinstance(42, int)   # True          —— 考虑继承（推荐）
isinstance(42, (int, float))  # True  —— 检查多种类型
```

| | `type()` | `isinstance()` |
|---|---|---|
| 用途 | 精确匹配 | 支持继承 |
| 布尔值 | `type(True)` → bool | `isinstance(True, int)` → True |
| 多类型 | ❌ | ✅ |

## 5. 编码规范（PEP 8 要点）

| 规则         | 要求                                             |
| ---------- | ---------------------------------------------- |
| **缩进**     | 4 个空格，**不要混用 Tab**                             |
| **行长**     | ≤ 79 字符（注释 ≤ 72）                               |
| **空行**     | 函数/类之间 2 行，方法之间 1 行                            |
| **命名**     | 变量 `snake_case`，类 `PascalCase`，常量 `UPPER_CASE` |
| **编码**     | UTF-8                                          |
| **分号**     | ❌ 行尾不要加分号                                      |
| **行末空格**   | ❌ 不要以空格结尾                                      |
| **import** | 每个导入独占一行，标准库 → 第三方 → 本地                        |

## 6. 项目环境

```bash
python -m venv .venv          # 创建虚拟环境
.venv\Scripts\activate        # 激活（Windows）
source .venv/bin/activate     # 激活（Linux/macOS）
deactivate                    # 退出
```

- `.venv/` —— 项目隔离的 Python 环境
- `__init__.py` —— 标识目录为 Python 包（Python 3.3+ 可选）
