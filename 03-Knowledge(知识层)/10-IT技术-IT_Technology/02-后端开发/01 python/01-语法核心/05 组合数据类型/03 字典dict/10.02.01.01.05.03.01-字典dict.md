# 字典（dict）

> [!NOTE]
> 值可以是任意类型，键必须是不可变类型（字符串、数字、元组）。

列表、元组按位置索引，字段一多就很难记住第几个是什么。字典按名称（键）存取，最适合把相关联的信息组织在一起。

```python
# 列表：不知道索引含义
person_list = ['王大锤', 55, 168, 60, '成都市武侯区...', '13122334455']
# 字典：键即语义
person = {'name': '王大锤', 'age': 55, 'height': 168, 'tel': '13122334455'}
```

就像《新华字典》中每个字（键）对应一段解释（值），Python 字典也是由键值对组成的容器。

## 创建字典

四种常用方式：

```python
# 1. 字面量 {}
xinhua = {'麓': '山脚下', '路': '道，往来通行的地方'}

# 2. dict() 构造器
dict(name='王大锤', age=55, height=168)
# → {'name': '王大锤', 'age': 55, 'height': 168}

# 3. zip() 压缩两个序列
dict(zip('ABCDE', '12345'))       # {'A': '1', 'B': '2', ...}
dict(zip('ABCDE', range(1, 10)))  # {'A': 1, 'B': 2, ...}

# 4. 字典生成式
{x: x ** 3 for x in range(1, 6)}  # {1: 1, 2: 8, 3: 27, 4: 64, 5: 125}
```

## 基本操作

以下示例基于这个字典：

```python
d = {'name': '王大锤', 'age': 55, 'height': 168}
```

### 取值

```python
# 直接索引 —— 键不存在会报 KeyError
d['name']         # '王大锤'
d['age']          # 55
# d['tel']        # KeyError: 'tel'

# get() —— 安全取值，键不存在返回 None 或指定默认值
d.get('name')     # '王大锤'
d.get('tel')      # None
d.get('tel', '未登记')  # '未登记'
```

### 新增 / 修改

```python
# 索引赋值：键不存在 → 新增；键存在 → 覆盖
d['tel'] = '13122334455'   # 新增
d['age'] = 25              # 覆盖
print(d)
# {'name': '王大锤', 'age': 25, 'height': 168, 'tel': '13122334455'}

# setdefault：键存在返回原值，键不存在写入默认值
d.setdefault('name', '张三')    # 返回 '王大锤'（已存在，不覆盖）
d.setdefault('addr', '成都')    # 返回 '成都'（不存在，写入）
print(d)
# {'name': '王大锤', 'age': 25, 'height': 168, 'tel': '13122334455', 'addr': '成都'}
```

### 合并

```python
d1 = {'name': '王大锤', 'age': 55}
d2 = {'age': 30, 'addr': '成都'}

d1.update(d2)      # d1 被修改：同名键覆盖，新键追加
print(d1)
# {'name': '王大锤', 'age': 30, 'addr': '成都'}

# Python 3.9+ 可用 |= 运算符
d1 = {'name': '王大锤', 'age': 55}
d1 |= d2
print(d1)
# {'name': '王大锤', 'age': 30, 'addr': '成都'}
```

### 删除

```python
d = {'name': '王大锤', 'age': 25, 'height': 178, 'addr': '成都'}

# pop(key) —— 删除并返回值，键不存在报错
age = d.pop('age')   # age = 25
print(d)             # {'name': '王大锤', 'height': 178, 'addr': '成都'}

# popitem() —— 删除并返回末尾键值对（Python 3.7+ LIFO）
item = d.popitem()   # item = ('addr', '成都')
print(d)             # {'name': '王大锤', 'height': 178}

# del —— 直接删除
del d['height']
print(d)             # {'name': '王大锤'}

# clear —— 清空
d.clear()
print(d)             # {}
```

### 成员判断

```python
d = {'name': '王大锤', 'age': 55}

'name' in d       # True
'tel' in d        # False
'tel' not in d    # True
len(d)            # 2
```

### 遍历

```python
d = {'name': '王大锤', 'age': 55}

# 遍历键
for k in d:
    print(k)

# 遍历值
for v in d.values():
    print(v)

# 同时遍历键值（推荐）
for k, v in d.items():
    print(f'{k}: {v}')
```

## 字典与 JSON

JSON 结构与字典几乎一致，Python 通过 `json` 模块互转，是 Web/API 开发的核心粘合层。

```python
import json

d = {'name': '王大锤', 'age': 55, 'skills': ['Python', 'Linux']}

# 字典 → JSON 字符串（序列化）
s = json.dumps(d, ensure_ascii=False)
print(s)  # {"name": "王大锤", "age": 55, "skills": ["Python", "Linux"]}
print(type(s))  # <class 'str'>

# 字典 → 写入 JSON 文件
with open('data.json', 'w', encoding='utf-8') as f:
    json.dump(d, f, ensure_ascii=False)

# JSON 字符串 → 字典（反序列化）
d2 = json.loads('{"name": "王大锤", "age": 55}')
print(d2['name'])  # 王大锤
print(type(d2))    # <class 'dict'>

# JSON 文件 → 字典
with open('data.json', 'r', encoding='utf-8') as f:
    d3 = json.load(f)
```

| 方向 | 函数 |
|------|------|
| dict → JSON 字符串 | `json.dumps(obj)` |
| dict → JSON 文件 | `json.dump(obj, f)` |
| JSON 字符串 → dict | `json.loads(s)` |
| JSON 文件 → dict | `json.load(f)` |

## 实战示例

**字母频率统计** — `get()` 计数模式：

```python
sentence = input('请输入一段话: ')
counter = {}
for ch in sentence:
    if 'A' <= ch <= 'Z' or 'a' <= ch <= 'z':
        counter[ch] = counter.get(ch, 0) + 1
for key in sorted(counter, key=counter.get, reverse=True):
    print(f'{key} 出现了 {counter[key]} 次.')
```

**股票筛选** — 字典生成式过滤：

```python
stocks = {'AAPL': 191.88, 'GOOG': 1186.96, 'IBM': 149.24, 'ORCL': 48.44}
high = {k: v for k, v in stocks.items() if v > 100}
# {'AAPL': 191.88, 'GOOG': 1186.96, 'IBM': 149.24}
```

## 总结

字典以键值对存储数据，通过键快速检索。键必须是不可变类型（str、int、tuple），列表、集合、字典不可作键。

## 关键概念

- **键值对**：`:` 左侧为键（不可变类型），右侧为值（任意类型）
- **键必须 hashable**：`str`、`int`、`tuple` 可作键；`list`、`set`、`dict` 不可
- **底层哈希表**：键通过 `hash()` 定位，平均查找 O(1)
- **Python 3.7+ 保证插入顺序**

## 常见陷阱

- `d[key]` 键不存在抛 `KeyError` → 优先用 `d.get(key, default)`
- 重复键后写覆盖前写，无警告
- 空 `{}` 是 dict 不是 set；空集合必须用 `set()`
- 遍历时增删键会报错 → 先 `list(d.keys())` 取副本再操作
