# 函数

## 函数的概念

函数是带名字的代码块，用于完成具体任务，可重复使用。Python 必须先定义后调用。

```python
'''
    该案例演示了向控制台打印2*3的 "*"
'''
row = 2
while row > 0 :
    print("*" * 3)
    row -= 1
```

重复输出同样图形时，不用复制代码，封装成函数调用即可：

```python
row = 2
while row > 0 :
    print("*" * 3)
    row -= 1
print("-" * 50)
# 如果需要再次输出
row = 2
while row > 0 :
    print("*" * 3)
    row -= 1
```

## 函数的定义

![[Pasted image 20260613235033.png]]

**语法：**

```python
def 函数名 (参数列表) :
        函数体
        [return]
```

**规则：**

- 以 `def` 关键词开头，后接函数名和圆括号
- 参数放在圆括号内，多个用逗号分隔
- 函数体缩进，第一行可选文档字符串（`'''...'''`）
- 参数列表后跟冒号 `:`
- `return [表达式]` 返回值，无 `return` 返回 `None`

## 函数的抽取及调用

```python
'''
    该案例演示了函数的抽取以及调用
    打印如下图形
        ***
        ***
        -------
        ***
        ***
'''
# 定义一个函数,该函数完成打印输出2*3 "*"的功能
def printStar() :
    '''
        这是对函数功能的说明
    '''
    row = 2
    while row > 0 :
        print("*" * 3)
        row -= 1

# 调用函数
printStar()
print("-" * 20)
printStar()
```

> 函数必须先定义再调用。定义时只是声明，调用时才执行。

## 函数的参数

### 形参和实参

- **形参**：定义函数时的参数名（占位符，无实际值）
- **实参**：调用函数时传入的实际数据

函数调用时在栈区分配空间，执行结束后释放。

### 参数传递

在 Python 中，变量无类型，对象有类型。参数传递本质是**对象的引用传递**。

```python
'''
    验证：*=
'''
def multiply(var1):
    print("函数内var1 id:", id(var1))
    var1 *= 2
    var1 = var1 * 2
    print("var1 = var1 * 2后，函数内var1 id:", id(var1))

list1 = [1, 2, 3]
multiply(list1)
```

- **不可变类型**（int, str, tuple）：`+=` 等操作会创建新对象，不影响外部变量
- **可变类型**（list, dict, set）：原地修改会反映到外部
- `var1 *= 2` 会原地修改可变对象；`var1 = var1 * 2` 总是创建新对象

### 函数可使用的参数形式

**位置参数** —— 按顺序匹配：

```python
def printInfo(name, age):
    print("姓名:", name, "年龄:", age)

printInfo("zhangsan", 18)
```

**关键字参数** —— 按名称匹配，顺序无关：

```python
printInfo(name="zhangsan", age=18)
printInfo(age=18, name="zhangsan")
```

**默认值参数** —— 调用时可省略，非默认参数必须在前：

```python
def printInfo(name, age=18):
    print(name, age)

printInfo("zhangsan")         # 使用默认 age=18
printInfo("zhangsan", 25)     # 覆盖默认值
```

**可变参数 `*args`** —— 接收任意数量位置参数，打包为元组：

```python
def printInfo(num1, *vartuple):
    print(num1)
    print(vartuple)

printInfo(70, 60, 50)
# 不定长参数后面的参数必须用关键字传参
def printInfo1(num1, *vartuple, num):
    print(num, num1, vartuple)

printInfo1(10, 20, num=40)
```

**可变关键字参数 `**kwargs`** —— 接收任意数量关键字参数，打包为字典：

```python
def printInfo(**var_args_dict):
    print(var_args_dict)

printInfo(name="zhang3", age=18)
```

### 解包传参

`*` 拆序列，`**` 拆字典：

```python
def func(a, b, c):
    return a + b + c

tuple11 = (1, 2, 3)
print(func(*tuple11))
# 字典中key的名称和参数名必须一致
dict1 = {"a": 1, "b": 2, "c": 3}
print(func(**dict1))
```

### 强制位置参数 / 关键字参数

`/` 之前的参数只能按位置传入，`*` 之后的参数只能按关键字传入：

```python
def f(a, b, /, c, d, *, e, f):
    pass
# a, b —— 仅位置
# c, d —— 位置或关键字均可
# e, f —— 仅关键字
```

### 防止函数修改列表

传入列表副本：

```python
import copy

def modify(names):
    names.append("张三")

my_friends = ["李四", "王五"]
modify(copy.copy(my_friends))
```

## 函数说明文档

用 `'''...'''` 写在函数体第一行，通过 `help()` 查看。

```python
def adult(age=18):
    """判断是否成年"""
    return age >= 18
```

## 返回值

`return` 返回结果并结束函数。可返回多个值（打包为元组）：

```python
def f(a, b, c):
    return a, b, c

result = f(1, 2, 3)  # (1, 2, 3)
```

## 函数嵌套调用

函数内部可调用其他函数：

```python
def function_A():
    print("A")

def function_B():
    function_A()
    print("B")

function_B()
```

## 变量的作用域

Python 查找变量遵循 **LEGB** 规则：Local → Enclosing → Global → Built-in。

```python
'''
a = int(2.9)  # 内建作用域 (Python本身提供的,在所有位置都可以访问)
b = 0  # 全局作用域
def outer():
    c = 1  # 嵌套作用域
    def inner():
        d = 2  #局部作用域
        print(d,c,b,a)
    return inner
in_func=outer()
in_func()
```

只有模块、类、函数会引入新作用域，`if`/`for`/`while` 等不会：

```python
# 分支,循环不会引入新的作用域
num = 2
if num > 1:
    msg = "helloWorld"
print(msg)  # 可访问
```

### global 关键字

在函数内声明使用全局变量：

```python
var1 = 100

def function_outer():
    global var1
    var1 = 200        # 修改全局变量
    print(var1)       # 200

function_outer()
print(var1)           # 200
```

修改可变类型全局变量不需要 `global`：

```python
def function_a():
    list1.append("hello")

list1 = [1, 2, 3]
function_a()
print(list1)          # [1, 2, 3, 'hello']
```

### nonlocal 关键字

在嵌套函数中声明使用外层（非全局）变量：

```python
def function_outer():
    var1 = 100
    def function_inner():
        nonlocal var1
        var1 = 200
    function_inner()
    print(var1)       # 200

function_outer()
```

## 递归

函数自调用。核心要素：**终止条件** + **递推公式**。

```python
'''
    该案例演示了求整数的阶乘
    5! = 5 * 4 * 3 * 2 * 1
'''
# 不使用递归的方式
def get_factorial(num):
    res = 1
    for n in range(1, num + 1):
        res *= n
    return res

# 递归方式
def get_factorial_recursion(num):
    if num >= 1:
        res = num * get_factorial_recursion(num - 1)
    else:
        res = 1
    return res
```

## 匿名函数（Lambda）

Python 使用 `lambda` 定义匿名函数——没有函数名，只有一行表达式。

```python
lambda 参数列表: 表达式
```

- `lambda` 是一个表达式，可以嵌在任何需要函数的地方
- 函数体只能是单个表达式，不能包含复杂逻辑

### 基本用法

```python
# 无参数
f = lambda: 10
print(f())              # 10

# 单参数
square = lambda x: x * x
print(square(5))        # 25

# 多参数
add = lambda x, y: x + y
print(add(3, 5))        # 8

# 默认参数
add = lambda x, y=2: x + y
print(add(3))           # 5

# 条件表达式
is_even = lambda x: 'Even' if x % 2 == 0 else 'Odd'
print(is_even(4))       # Even
```

### 作为函数参数

```python
def function(a, b, op):
    return op(a, b)

# 传普通函数
def my_add(a, b): return a + b
print(function(1, 2, my_add))

# 传 lambda —— 无需单独定义
print(function(1, 2, lambda x, y: x + y))
```

### 与内置高阶函数搭配

```python
# sorted —— 按指定 key 排序
students = [{"name": "zhang3", "age": 36}, {"name": "li4", "age": 14}]
sorted(students, key=lambda x: x["age"])

# map —— 逐元素映射
list(map(lambda x: x * x, [0, 1, 3, 7, 9]))   # [0, 1, 9, 49, 81]

# filter —— 逐元素过滤
list(filter(lambda x: x >= 0, [0, -1, -3, 7, 9]))  # [0, 7, 9]

# reduce —— 逐元素累积
from functools import reduce
reduce(lambda x, y: x * y, [1, 2, 3, 4, 5])    # 120
```

### 链式组合

```python
old_nums = [35, 12, 8, 99, 60, 52]
new_nums = list(map(lambda x: x ** 2, filter(lambda x: x % 2 == 0, old_nums)))
print(new_nums)  # [144, 64, 3600, 2704]
```

### 进阶：一行代码

```python
import functools, operator

# 阶乘
fac = lambda n: functools.reduce(operator.mul, range(2, n + 1), 1)
print(fac(6))        # 720

# 判断素数
is_prime = lambda x: all(map(lambda f: x % f, range(2, int(x ** 0.5) + 1)))
print(is_prime(37))  # True
```

### 注意事项

- 只能包含单个表达式，复杂逻辑用 `def`
- `reduce`、`filter`、`map` 构成函数式编程的**过滤 → 映射 → 归约**三件套

## 函数的注释（了解）

Python 3.x 支持类型注释，存储在 `__annotations__` 属性中：

```python
# 普通的自定义函数：
def dog(name, age, species):
   return (name, age, species)
# 添加了注释的自定义函数：
def dog(name:str, age:(1, 99), species:'狗狗的品种') -> tuple:
    return (name, age, species)
print(dog.__annotations__)
```

## 装饰器（了解）

**在不修改原函数的前提下增加额外功能**。`functools.wraps` 保留被装饰函数的元数据。

```python
from functools import wraps

def my_decorator(func):
    @wraps(func)
    def wrapper(*args, **kwargs):
        print("Something is happening before the function is called.")
        result = func(*args, **kwargs)
        print("Something is happening after the function is called.")
        return result
    return wrapper

@my_decorator
def say_hello(name):
    """This function greets the person passed in as a parameter."""
    print(f"Hello, {name}!")

# 调用被装饰的函数
say_hello("Alice")

# 访问原函数
original_function = say_hello.__wrapped__
print(original_function.__name__)  # 输出: say_hello

# 直接调用原函数
original_function("Bob")
```

- `functools.wraps` 保留被装饰函数的元数据（名称、文档字符串等）
- 通过 `__wrapped__` 属性可访问未被装饰的原函数

### 基础总结

- **定义**：`def 函数名(参数):` 开头，缩进函数体，`return` 返回值
- **参数顺序**：位置 → 关键字 → 默认值 → `*args` → `**kwargs`
- **解包**：`*` 拆序列，`**` 拆字典
- **作用域**：LEGB 规则，`global` 声明全局变量，`nonlocal` 声明外层变量
- **递归**：函数自调用，必须有终止条件
- **Lambda**：单行匿名函数，常与 `sorted`/`map`/`filter`/`reduce` 搭配

## 函数使用进阶

Python 函数是"一等公民"——可赋值给变量、可作参数传入、可作返回值。把一个函数作为其他函数的参数或返回值的用法称为**高阶函数**。

### 高阶函数

接收函数作为参数或返回函数的函数：

```python
def calc(init_value, op_func, *args, **kwargs):
    items = list(args) + list(kwargs.values())
    result = init_value
    for item in items:
        if type(item) in (int, float):
            result = op_func(result, item)
    return result
```

传入不同运算函数得到不同结果：

```python
def add(x, y):
    return x + y

def mul(x, y):
    return x * y

print(calc(0, add, 1, 2, 3, 4, 5))  # 15
print(calc(1, mul, 1, 2, 3, 4, 5))  # 120
```

也可使用 `operator` 模块提供的标准运算函数：

```python
import operator
print(calc(0, operator.add, 1, 2, 3, 4, 5))  # 15
print(calc(1, operator.mul, 1, 2, 3, 4, 5))  # 120
```

### 内置高阶函数

`filter`、`map`、`sorted` 接收函数作为参数：

```python
def is_even(num):
    return num % 2 == 0

def square(num):
    return num ** 2

old_nums = [35, 12, 8, 99, 60, 52]
new_nums = list(map(square, filter(is_even, old_nums)))
print(new_nums)  # [144, 64, 3600, 2704]
```

等价的列表生成式写法：

```python
old_nums = [35, 12, 8, 99, 60, 52]
new_nums = [num ** 2 for num in old_nums if num % 2 == 0]
```

### 偏函数

`functools.partial` **固定函数的部分参数，返回新函数**，简化重复调用：

```python
from functools import partial

def power(base, exponent):
    return base ** exponent

square = partial(power, exponent=2)
print(square(3))  # 9
```

**示例：二进制转换**

```python
from functools import partial

# 定义原始函数
def int_base(value, base):
    return int(value, base)

# 创建偏函数，固定base参数为2
int2 = partial(int_base, base=2)

# 使用偏函数
print(int2('1000000'))  # 64
print(int2('1010101'))  # 85
```

**示例：文件路径拼接**

```python
from functools import partial
import os

def dest_join(dest, folder):
    return os.path.join(dest, folder)

dest_join = partial(dest_join, './dest')

print(dest_join('dir1'))  # ./dest/dir1
print(dest_join('dir2'))  # ./dest/dir2
```

### 总结

**一等函数**：Python 函数赋值给变量、作参数传入、作返回值。这是高阶函数、装饰器、闭包等高级特性的基石。

**函数定义**：`def` 声明，参数支持位置/关键字/默认/可变/解包，`return` 返回值（无则返回 `None`）。

**作用域规则**：LEGB 查找顺序（Local → Enclosing → Global → Built-in），`global` 和 `nonlocal` 可跨层修改。

**Lambda 匿名函数**：单行表达式即返回值，常用于 `sorted`/`map`/`filter`/`reduce` 等需要临时函数的地方。

**高阶函数**：接收函数作参数或返回函数的函数，`functools.partial` 可固定参数生成偏函数，简化重复调用。

### 速查

| 语法 | 说明 |
|------|------|
| `def f(a, b=0, *args, **kw):` | 定义函数，参数顺序：必选 → 默认 → 可变位置 → 可变关键字 |
| `f(*seq, **dic)` | 解包传参 |
| `f(a, b, /, c, *, d)` | `/` 前仅位置，`*` 后仅关键字 |
| `global x` / `nonlocal x` | 声明全局/外层变量 |
| `lambda x: x * 2` | 匿名函数 |
| `functools.partial(f, x=1)` | 偏函数，固定部分参数 |
| `functools.wraps(func)` | 装饰器保留元数据 |
