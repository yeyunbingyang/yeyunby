### **Python条件判断基本格式**

```python
if 条件1:
    # 条件1为True时执行的代码块
elif 条件2:
    # 条件1为False且条件2为True时执行的代码块
else:
    # 所有条件均为False时执行的代码块
```

#### **核心规则**

1. **缩进**：代码块必须通过缩进（通常4个空格）表示层级关系
2. **逻辑顺序**：`if`必须存在，`elif`和`else`可选且顺序不可调换
3. **条件表达式**：所有条件必须是布尔值（`True/False`或可隐式转换的值）

### **1. 单条件判断（if）**

```python
age = 18
if age >= 18:
    print("已成年")  # 满足条件时输出
```

---

### **2. 双分支判断（if-else）**

```python
score = 85
if score >= 60:
    print("及格")
else:
    print("不及格")  # 输出：及格
```

---

### **3. 多分支判断（if-elif-else）**

```python
temperature = 25
if temperature > 30:
    print("高温")
elif 20 <= temperature <= 30:
    print("舒适")  # 输出：舒适
else:
    print("低温")
```

---

### **4. 嵌套条件判断**

```python
num = 15
if num % 2 == 0:
    if num % 3 == 0:
        print("能被2和3整除")
    else:
        print("能被2整除但不能被3整除")
else:
    print("奇数")  # 输出：奇数
```

---

### **5. 复合条件（逻辑运算符组合）**

```python
username = "admin"
password = "123456"
if username == "admin" and password == "123456":
    print("登录成功")  # 输出：登录成功
```

---

### **6. 特殊条件判断技巧**

#### **(1) 隐式布尔值判断**

```python
my_list = []
if my_list:  # 空列表等价于False
    print("列表有内容")
else:
    print("列表为空")  # 输出：列表为空
```

#### **(2) 成员判断（in）**

```python
colors = ["red", "blue", "green"]
if "yellow" not in colors:
    print("黄色不在列表中")  # 输出：黄色不在列表中
```

#### **(3) 身份判断（is）**

```python
a = [1,2,3]
b = a
if a is b:
    print("指向同一对象")  # 输出：指向同一对象
```

---

### **7. 三元表达式（简化版条件判断）**

```python
# 格式：结果1 if 条件 else 结果2
max_value = x if x > y else y  # 取x和y中的较大值
```

---

### **8. 条件判断注意事项**

1. **缩进错误**：缺少/多余缩进会导致`IndentationError`
2. **误用赋值运算符**：`if x = 5`（错误）应改为`if x == 5`
3. **浮点数比较**：避免直接`==`比较浮点数（精度问题）

```python
# 正确方式：使用误差范围
if abs(a - b) < 1e-9:
    print("近似相等")
```

### **完整示例：成绩等级判断**

```python
score = 78

if score >= 90:
    grade = "A"
elif 80 <= score < 90:
    grade = "B"
elif 70 <= score < 80:
    grade = "C"  # 实际赋值结果：C
elif 60 <= score < 70:
    grade = "D"
else:
    grade = "F"

print(f"成绩等级：{grade}")
```

```python
x = 1  # 假设 x 的值

match x:
    case 1:
        print("x is 1")
    case 2:
        print("x is 2")
    case _:  # 修正：通配符是【下划线 _】，不是减号 -
        # 匹配所有其他值
        print("x is not 1 or 2") # 修正：拼写 print
```
