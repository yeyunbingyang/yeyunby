# 面向对象

## 面向过程 vs 面向对象

**面向过程**：以过程为中心，将问题分解为一系列步骤，每个步骤写成函数，按顺序调用。

```python
def buy():
    print("去超市购买食材。")
def wash():
    print("清洗蔬菜。")
def cut():
    print("切菜。")
def cook():
    print("开始烹饪。")
def serve():
    print("上菜啦！")

buy()
wash()
cut()
cook()
serve()
```

这种方式直接、适合简单任务。但当程序变复杂——不同菜品需要不同步骤、需要同时做多道菜——代码会越来越长且没有通用性。

**面向对象**：以对象为中心，将数据（属性）和操作（方法）封装在类中。Python 同时支持两种范式。

```python
class Dish:
    def __init__(self, name):
        self.name = name
    def prepare(self):
        pass

class Salad(Dish):
    def prepare(self):
        print(f"为 {self.name} 购买食材。")
        print(f"清洗 {self.name} 的蔬菜。")
        print(f"切 {self.name} 的蔬菜。")

class Stew(Dish):
    def prepare(self):
        print(f"为 {self.name} 购买食材。")
        print(f"切 {self.name} 的肉。")
        print(f"烹饪 {self.name}。")

class Soup(Dish):
    def prepare(self):
        print(f"为 {self.name} 购买食材。")
        print(f"煮 {self.name}。")

salad = Salad("蔬菜沙拉")
stew = Stew("炖肉")
soup = Soup("西红柿鸡蛋汤")

salad.prepare()
stew.prepare()
soup.prepare()
```

封装、继承、多态的优势：添加新菜品只需新建子类，不改已有代码。


### 面向对象简史

对象作为编程实体的概念最早由 **Simula 67**（1960 年代，挪威计算中心）引入。Simula 的设计初衷是模拟船只行为——将不同类型的船只归纳为不同的**类**，每个对象基于其类定义自己的属性和行为。这是类与实例思想的最早应用，奠定了后来 C++、Java、Python 等 OOP 语言的基石。
## 类和对象

- **类（Class）**：对象的模板，描述共同的属性和方法。类是对大量对象共性的抽象。
- **对象（Object）**：类的实例，是具体的。每个对象有自己的状态和行为。

class Person:
    """人类"""

- 通过 `类名()` 实例化，自动调用 `__init__`

## `__init__` 构造方法

对象实例化时第一个被调用的方法，用于初始化实例属性。

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

stu = Student("张三", 20)
```


> **注意**：`__init__` 不是必需的（未定义时 Python 使用默认构造），且只能返回 `None`，返回其他值会引发 `TypeError`。
## self

`self` 代表当前实例对象。实例方法的第一个参数必须是 `self`（名称约定，可用其他名但不推荐）。

### self 作为实例传参

```python
class Person:
    def __init__(self, name):
        self.name = name

    def say_hello(self):
        print(f"Hello, I am {self.name}")

p = Person("张三")
p.say_hello()  # 等价于 Person.say_hello(p)
```

### 通过 self 访问属性和方法

```python
class Student:
    def __init__(self, name):
        self.name = name

    def study(self, course):
        print(f"{self.name} 在学习 {course}")

    def introduce_and_study(self, course):
        print(f"我是 {self.name}")
        self.study(course)          # 通过 self 调用其他方法
```

## 属性

### 类属性 vs 实例属性

|      | 类属性               | 实例属性                       |
| ---- | ----------------- | -------------------------- |
| 定义位置 | 类体内，方法外           | `__init__` 或方法内 `self.xxx` |
| 访问方式 | `类名.属性` 或 `实例.属性` | `实例.属性`                    |
| 共享性  | 所有实例共享            | 每个实例独有                     |

```python
class Student:
    school = "北京大学"     # 类属性

    def __init__(self, name):
        self.name = name   # 实例属性

s1 = Student("张三")
s2 = Student("李四")
print(s1.school)  # 北京大学
print(s2.school)  # 北京大学

Student.school = "清华大学"  # 通过类名修改类属性
print(s1.school)  # 清华大学
print(s2.school)  # 清华大学
```


> **陷阱**：用 `实例.属性 = 值` 赋值会创建新的**实例属性**，不会修改类属性。此时该实例的类属性被同名实例属性遮盖。始终用 `类名.属性` 修改类属性。
## 方法

### 实例方法

第一个参数是 `self`，通过实例调用，可访问实例属性和类属性。

```python
class Person:
    def instance_method(self):
        print(f"实例方法，self = {self}")

p = Person()
p.instance_method()
```

### 类方法

`@classmethod` 装饰，第一个参数是 `cls`，通过类或实例调用，可访问类属性。

```python
class Person:
    home = "earth"

    @classmethod
    def class_method(cls):
        print(cls.home)

Person.class_method()   # 通过类调用
p = Person()
p.class_method()        # 通过实例调用
```

### 静态方法

`@staticmethod` 装饰，无 `self`/`cls`，不访问类或实例内部信息，类似工具函数。

```python
class Person:
    @staticmethod
    def static_method():
        print("static method")

Person.static_method()
p = Person()
p.static_method()
```

### 在类外定义方法

将外部函数赋值给类内变量：

```python
def f1(self, x, y):
    print(x & y)

class C:
    f = f1

C().f(6, 13)  # 4
```


### 特殊方法（魔法方法）

方法名中有两个前缀下划线和两个后缀下划线的方法为特殊方法，也叫魔法方法。上文提到的 `__init__()` 就是一个特殊方法。这些方法会在进行特定的操作时自动被调用。

| 方法                   | 作用                                             |
| -------------------- | ---------------------------------------------- |
| `__new__()`          | 对象实例化时**第一个**调用的方法                             |
| `__init__()`         | 类的初始化方法                                        |
| `__del__()`          | 对象销毁器，引用计数归零时触发（`del obj` 不一定立即调用）             |
| `__str__()`          | 定义 `str(obj)` 时的行为，面向用户                        |
| `__repr__()`         | 定义 `repr(obj)` 时的行为，面向开发者，输出应尽量是可执行的 Python 代码 |
| `__getattribute__()` | 属性访问拦截器，属性被访问前触发                               |


> 详见下方 [[#魔法方法\|魔法方法]] 章节，含全部 15+ 种魔法方法的分类总表与代码示例。

# 三大特性
## 封装

将属性和方法封装在类内，隐藏实现细节，只暴露必要接口。

### 可见性（访问控制）

| 类型 | 定义方式 | 访问方式 | 特点 |
|------|---------|---------|------|
| 公有属性 | 直接定义 | 可直接访问 | 无限制 |
| 受保护属性 | `_name` | 可访问，但不建议 | 约定内部使用 |
| 私有属性 | `__name` | 不能直接访问 | 名称改写为 `_ClassName__name` |
| 公有方法 | 直接定义 | 任意位置 | 对外接口 |
| 受保护方法 | `_method` | 不建议外部调用 | 约定内部/子类使用 |
| 私有方法 | `__method` | 不能直接访问 | 名称改写 |

```python
class Student:
    def __init__(self, name, age):
        self.name = name          # 公有
        self._salary = 5000        # 受保护（约定）
        self.__bank_balance = 10000  # 私有

    def show_info(self):           # 公有方法
        return f"姓名: {self.name}"

    def _show_salary(self):        # 受保护方法
        return self._salary

    def __show_balance(self):      # 私有方法
        return self.__bank_balance

    def get_balance(self):         # 公开接口访问私有属性
        return self.__show_balance()

stu = Student("王大锤", 20)
print(stu.name)              # 王大锤
# print(stu.__bank_balance)  # AttributeError
print(stu._Student__bank_balance)  # 10000（名称改写，可强行访问）
```


> **Python 哲学**：We are all consenting adults here（大家都是成年人）。Python 不对访问可见性做强限制——`__` 私有属性通过名称改写仍可访问，这体现了 Python 开放优于封闭的设计理念。
### property 装饰器

将方法调用转为属性访问，实现 getter/setter/deleter：

```python
class Person:
    def __init__(self, name):
        self.__name = name

    @property
    def name(self):           # getter
        return self.__name

    @name.setter
    def name(self, value):    # setter
        if not value:
            raise ValueError("姓名不能为空")
        self.__name = value

    @name.deleter
    def name(self):           # deleter
        del self.__name

p = Person("张三")
print(p.name)      # 张三 —— 像属性一样访问
p.name = "李四"    # 调用 setter
del p.name         # 调用 deleter
```

**property 使用场景：**

| 类型    | 装饰器                         | 说明     |
| ----- | --------------------------- | ------ |
| 只读属性  | `@property`                 | 只能读取   |
| 可读写属性 | `@property` + `@xxx.setter` | 支持验证   |
| 伪私有属性 | `@property` 返回固定值           | 隐藏敏感数据 |

## 继承

子类继承父类的属性和方法，实现代码复用。

### 单继承

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        pass

class Dog(Animal):
    def speak(self):
        return f"{self.name}：汪汪！"

class Cat(Animal):
    def speak(self):
        return f"{self.name}：喵喵！"

dog = Dog("旺财")
print(dog.speak())  # 旺财：汪汪！
```

### 多继承

```python
class A:
    def method(self):
        print("A")

class B:
    def method(self):
        print("B")

class C(A, B):     # 继承 A 和 B
    pass

c = C()
c.method()         # A —— 按 MRO 顺序查找
```

### 复用父类方法

```python
class Parent:
    def __init__(self, name):
        self.name = name

class Child(Parent):
    def __init__(self, name, age):
        super().__init__(name)    # 调用父类 __init__
        # Parent.__init__(self, name)  # 等价写法
        self.age = age
```

### 方法解析顺序（MRO）

多继承时，Python 使用 **C3 线性化算法** 决定方法查找顺序：

```python
class A: pass
class B(A): pass
class C(A): pass
class D(B, C): pass

print(D.__mro__)
# (<class 'D'>, <class 'B'>, <class 'C'>, <class 'A'>, <class 'object'>)
```

### 方法重写

子类定义与父类同名方法，优先调用子类版本。`super()` 可调用父类版本。


> **注意**：子类重写 `__init__` 后不会自动调用父类的 `__init__`，如需继承父类初始化逻辑，必须显式写 `super().__init__()`。
## 多态

不同类定义同名方法，通过统一接口调用，运行时决定具体执行：

```python
def animal_sound(animal):
    print(animal.speak())

animal_sound(Dog("旺财"))  # 旺财：汪汪！
animal_sound(Cat("咪咪"))  # 咪咪：喵喵！
```

> Python 的多态基于**鸭子类型**：不检查对象类型，只看是否有对应方法。


# 进阶

## 魔法方法

方法名中有两个前缀下划线和两个后缀下划线的方法为特殊方法，也叫魔法方法。上文提到的 `__init__()` 就是一个特殊方法。这些方法会在进行特定的操作时自动被调用。

### 速览：全部魔法方法

下面按功能归类列出所有常用魔法方法及其触发条件。

| 分类 | 方法 | 触发时机 | 典型用途 |
|------|------|---------|---------|
| **对象生命周期** | `__new__(cls)` | 创建实例前 | 单例模式、不可变类型继承 |
|  | `__init__(self)` | 实例创建后 | 属性初始化 |
|  | `__del__(self)` | 对象销毁时 | 资源清理（慎用）|
| **字符串表示** | `__str__(self)` | `print()` / `str()` | 用户友好输出 |
|  | `__repr__(self)` | `repr()` / 交互环境 | 开发者调试 |
|  | `__format__(self, spec)` | `format()` / f-string | 自定义格式化 |
| **算术运算** | `__add__` / `__sub__` / `__mul__` 等 | `+` `-` `*` `/` `//` `%` `**` | 数值/向量运算 |
|  | `__neg__` / `__pos__` / `__abs__` | `-obj` / `+obj` / `abs()` | 一元运算 |
| **比较运算** | `__eq__` / `__ne__` / `__lt__` / `__le__` / `__gt__` / `__ge__` | `==` `!=` `<` `<=` `>` `>=` | 对象排序、去重 |
| **容器协议** | `__getitem__` / `__setitem__` / `__delitem__` | `obj[key]` 读写删 | 自定义容器 |
|  | `__len__` | `len(obj)` | 容器大小 |
| **可调用对象** | `__call__(self, ...)` | `obj()` | 函数式对象 |
| **上下文管理** | `__enter__` / `__exit__` | `with obj:` | 资源自动管理 |
| **属性访问** | `__getattr__` | 访问**不存在**的属性时 | 代理、懒加载 |
|  | `__getattribute__` | 访问**任何**属性时 | 全局拦截（慎用递归）|
|  | `__setattr__` / `__delattr__` | 设置 / 删除属性时 | 属性校验 |

> **规律**：所有魔法方法遵循 `__方法名__` 的命名约定，Python 解释器在特定操作时自动查找并调用。你只需在类中定义它们即可改变对象的内置行为。

### 对象创建与销毁

```python
class MyClass:
    def __new__(cls, *args, **kwargs):
        """创建实例（在 __init__ 之前调用）"""
        instance = super().__new__(cls)
        return instance

    def __init__(self, name):
        """初始化实例"""
        self.name = name

    def __del__(self):
        """析构：对象被销毁时调用（引用计数归零时触发，del obj 不一定立即调用）"""
        print(f"{self.name} 被销毁")
```

**单例模式示例：**

```python
class Singleton:
    _instance = None

    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
        return cls._instance

a = Singleton()
b = Singleton()
print(a is b)  # True
```

### 字符串表示

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        """用户友好：print() / str()"""
        return f"{self.name}, {self.age}岁"

    def __repr__(self):
        """开发者友好：repr() / 交互环境"""
        return f"Person(name='{self.name}', age={self.age})"

    def __format__(self, format_spec):
        """控制 format() 和 f-string 行为"""
        return f"Person: {self.name}"
```

### 算术运算符重载（了解）

| 一元运算符 | 方法 |
|-----------|------|
| `-obj` | `__neg__` |
| `+obj` | `__pos__` |
| `abs(obj)` | `__abs__` |

| 二元运算符 | 方法 |
|-----------|------|
| `+` | `__add__` |
| `-` | `__sub__` |
| `*` | `__mul__` |
| `/` | `__truediv__` |
| `//` | `__floordiv__` |
| `%` | `__mod__` |
| `**` | `__pow__` |

```python
class Number:
    def __init__(self, value):
        self.value = value

    def __add__(self, other):
        return Number(self.value + other.value)

    def __neg__(self):
        return Number(-self.value)

a = Number(10)
b = Number(5)
print((a + b).value)  # 15
print((-a).value)     # -10
```

### 比较运算符（了解）

| 运算符 | 方法 |
|--------|------|
| `==` | `__eq__` |
| `!=` | `__ne__` |
| `<` | `__lt__` |
| `<=` | `__le__` |
| `>` | `__gt__` |
| `>=` | `__ge__` |

```python
class Person:
    def __init__(self, age):
        self.age = age

    def __lt__(self, other):
        return self.age < other.age

p1 = Person(25)
p2 = Person(30)
print(p1 < p2)  # True
```

### 容器协议（了解）

| 方法 | 作用 |
|------|------|
| `__getitem__(self, key)` | `obj[key]` 取值 |
| `__setitem__(self, key, value)` | `obj[key] = value` 赋值 |
| `__delitem__(self, key)` | `del obj[key]` 删除 |
| `__len__(self)` | `len(obj)` |

```python
class MyList:
    def __init__(self):
        self.data = {}

    def __getitem__(self, key):
        return self.data.get(key, "Not found")

    def __setitem__(self, key, value):
        self.data[key] = value

    def __len__(self):
        return len(self.data)

ml = MyList()
ml[1] = "A"
print(ml[1])     # A
print(len(ml))   # 1
```

### 可调用对象 `__call__`（了解）

使实例像函数一样调用：

```python
class Adder:
    def __call__(self, x, y):
        return x + y

add = Adder()
print(add(3, 4))  # 7
```

### 上下文管理器（了解）

实现 `__enter__` 和 `__exit__`，用于 `with` 语句：

```python
class MyResource:
    def __enter__(self):
        print("Resource acquired")
        return self

    def __exit__(self, exc_type, exc_value, traceback):
        print("Resource released")
        return False  # 不压制异常

with MyResource():
    print("Using resource")
```

### 属性访问（了解）

| 方法                               | 触发时机                       |
| -------------------------------- | -------------------------- |
| `__getattr__(self, name)`        | 访问不存在的属性时                  |
| `__setattr__(self, name, value)` | 设置属性时                      |
| `__delattr__(self, name)`        | 删除属性时                      |
| `__getattribute__(self, name)`   | 访问任何属性时（优先于 `__getattr__`） |

> **特别注意**：`__getattribute__` 在访问**任何**属性时触发（优先于 `__getattr__`），若在其中使用 `self.xxx` 会导致无限递归，必须通过 `super().__getattribute__(name)` 获取实际值。

## 动态添加属性与方法

### 动态添加属性

```python
class Person:
    def __init__(self, name=None):
        self.name = name

p = Person("张三")
p.age = 18              # 动态给对象添加属性
Person.age = 0          # 动态给类添加属性
```

### 动态添加实例方法

```python
import types

class Person:
    def __init__(self, name=None):
        self.name = name

def eat(self):
    print(f"{self.name}在吃饭")

p = Person("张三")
p.eat = types.MethodType(eat, p)
p.eat()  # 张三在吃饭
```

### 动态添加类方法

给类添加的方法对所有实例生效：

```python
class Person:
    home = "earth"
    def __init__(self, name=None):
        self.name = name

@classmethod
def come_from(cls):
    print(f"来自{cls.home}")

@staticmethod
def static_function():
    print("static function")

Person.come_from = come_from
Person.come_from()  # 来自earth

Person.static_function = static_function
Person.static_function()  # static function
```

### 动态删除

```python
del p.age              # 删除对象属性
delattr(p, "age")      # 等价写法
```

### `__slots__` 限制属性

限制实例可添加的属性名集合，节省内存。仅对当前类生效，不影响子类：

```python
import types

class Person:
    __slots__ = ("name", "age", "eat")

    def __init__(self, name=None):
        self.name = name

def eat(self):
    print(f"{self.name}在吃饭")

p = Person("张三")
p.age = 10                 # ✓ 在 __slots__ 中
p.eat = types.MethodType(eat, p)
p.eat()                    # 张三在吃饭

# p.weight = 100           # AttributeError —— 不在 __slots__ 中
```

## 打印对象内容

### __str__ vs __repr__

| 方法       | 目标用户  | 调用方式                  | 场景      |
| -------- | ----- | --------------------- | ------- |
| __str__  | 用户友好  | print(obj) / str(obj) | 日志、展示   |
| __repr__ | 开发者友好 | repr(obj) / 交互环境直接输入  | 调试、重建对象 |

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
    def __str__(self):
        return f'Person(name={self.name}, age={self.age})'
    def __repr__(self):
        return f"Person({self.name!r}, {self.age!r})"

p = Person('张三', 25)
print(p)         # Person(name=张三, age=25)  — 调用 __str__
print(repr(p))   # Person(张三, 25)           — 调用 __repr__
```

### 查看类结构

```python
# dir() — 列出所有属性和方法
print(dir(Person))
# ['__class__', '__delattr__', ..., '__str__', 'name', 'age']

# inspect — 获取详细信息
import inspect
methods = inspect.getmembers(Person, predicate=inspect.isfunction)
print('方法列表:', methods)
```

### 动态打印

```python
def print_object(obj):
    """通用对象打印函数"""
    attrs = vars(obj)  # 获取实例属性字典
    class_name = obj.__class__.__name__
    print(f'{class_name} 对象内容：')
    for key, value in attrs.items():
        print(f'  {key}: {value}')

print_object(p)
# Person 对象内容：
#   name: 张三
#   age: 25
```

### 安全打印

```python
# 检查属性是否存在
if hasattr(p, 'age'):
    print(p.age)

# pprint 格式化复杂对象
from pprint import pprint
pprint(vars(p))
```

# 总结

- **类**是模板，**对象**是实例。`class` 定义，`__init__` 初始化，`self` 指向实例
- **三大特性**：封装（私有化 + property）、继承（单/多继承 + super + MRO + 重写）、多态（鸭子类型）
- **魔法方法**：`__str__`/`__repr__` 控制输出格式，`__add__`/`__eq__` 等重载运算符，`__call__` 实现可调用对象，`__enter__`/`__exit__` 支持上下文管理
- **动态特性**：运行时添加属性和方法，`__slots__` 限制实例属性集合
