在Python中，打印类的内容通常涉及以下场景：

---

### 一、打印类的结构（属性/方法）

#### 1. 使用 `dir()` 函数

```
class Student03:
    def __init__(self, name, age):
        self.name = name
        self.age = age

print(dir(Student03))
# 输出：['__class__', '__delattr__', ..., 'age', 'name']
```

#### 2. 使用 `inspect` 模块（获取详细信息）

```
import inspect

# 获取类的方法列表
methods = inspect.getmembers(Student03, predicate=inspect.isfunction)
print("方法列表:", methods)

# 获取类的属性列表
attrs = inspect.getmembers(Student03, predicate=inspect.isdatadescriptor)
print("属性列表:", attrs)
```

---

### 二、打印对象信息

#### 1. 自定义 `__str__` 方法（用户友好）

```
class Student03:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"Student03对象：姓名={self.name}, 年龄={self.age}"

stu = Student03("张三", 20)
print(stu)  # 输出：Student03对象：姓名=张三, 年龄=20
```

#### 2. 自定义 `__repr__` 方法（开发者友好）

```
class Student03:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __repr__(self):
        return f"Student03('{self.name}', {self.age})"

stu = Student03("李四", 22)
print(repr(stu))  # 输出：Student03('李四', 22)
```

#### 3. 手动打印属性

```
stu = Student03("王五", 18)
print(f"姓名：{stu.name}, 年龄：{stu.age}")
# 输出：姓名：王五, 年龄：18
```

---

### 三、打印类属性（类变量）

```
class Student01:
    name = '小明'
    age = 18

# 直接访问类属性
print(Student01.name)  # 输出：小明

# 通过实例访问类属性
s = Student01()
print(s.age)  # 输出：18
```

---

### 四、动态打印对象内容

```
def print_object(obj):
    """通用对象打印函数"""
    attrs = vars(obj)  # 获取实例属性字典
    class_name = obj.__class__.__name__
    print(f"{class_name}对象内容：")
    for key, value in attrs.items():
        print(f"  {key}: {value}")

stu = Student03("赵六", 25)
print_object(stu)
# 输出：
# Student03对象内容：
#   name: 赵六
#   age: 25
```

### 五、完整代码示例

```
# code_01_类的定义.py
class Student:
    pass

class Student01:
    name = '小明'
    age = 18

class Student02:
    def study(self, course_name):
        print(f'{self.name}正在学习{course_name}.')

class Student03:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return f"Student03对象：{self.name} ({self.age}岁)"

    def study(self, course_name):
        print(f'{self.name}正在学习{course_name}.')

# main.py
from code_01_类的定义 import Student03

stu = Student03("张三", 20)
print("--- 直接打印对象 ---")
print(stu)  # 自动调用 __str__

print("\n--- 详细信息 ---")
print(repr(stu))  # 默认未定义 __repr__ 时输出对象地址

print("\n--- 动态属性打印 ---")
print(f"姓名：{stu.name}, 年龄：{stu.age}")
```

---

### 六、关键注意事项

1. `__str__` **vs** `__repr__`：

- `__str__`：面向用户，通过 `print(obj)` 或 `str(obj)` 调用
- `__repr__`：面向开发者，通过 `repr(obj)` 或在交互式环境直接输入对象名调用

2. **类属性与实例属性**：

```
class Demo:
    class_attr = "类属性"  # 类级别

    def __init__(self, value):
        self.instance_attr = value  # 实例级别

d = Demo("实例属性")
print(Demo.class_attr)  # 类直接访问
print(d.instance_attr)  # 实例访问
```

3. **安全打印建议**：

```
# 处理可能的属性缺失
if hasattr(stu, 'age'):
    print(stu.age)
else:
    print("属性不存在")
```

如果需要进一步调试，推荐使用 `pprint` 模块格式化复杂对象：

```
from pprint import pprint
pprint(vars(stu))  # 美观打印属性字典
```
