对于想学习编程的新手来说，有两个问题可能是他们很想知道的，其一是“什么是（计算机）程序”，其二是“写（计算机）程序能做什么”。先说说我对这两个问题的理解：**程序是数据和指令的有序集合**，**写程序就是用数据和指令控制计算机做我们想让它做的事情**。今时今日，为什么有那么多人选择用 Python 语言来写程序，因为 Python 语言足够简单和强大。相较于 C、C++、Java 这样的编程语言，Python 对初学者和非专业人士更加友好，很多问题在 Python 语言中都能找到简单优雅的解决方案。接下来，我们就从最基础的语言元素开始，带大家认识和使用 Python 语言。

# 一些常识

在开始系统的学习 Python 编程之前，我们先来科普一些计算机的基础知识。计算机的硬件系统通常由五大部件构成，包括：**运算器**、**控制器**、**存储器**、**输入设备**和**输出设备**。其中，**运算器和控制器**放在一起就是我们常说的**中央处理器**（CPU），它的功能是执行各种运算和控制指令。刚才我们提到过，程序是指令的集合，写程序就是将一系列的指令按照某种方式组织到一起，然后通过这些指令去控制计算机做我们想让它做的事情。存储器可以分为**内部存储器**和**外部存储器**，前者就是我们常说的内存，它是中央处理器可以直接寻址的存储空间，程序在执行的过程中，对应的数据和指令需要加载到内存中。输入设备和输出设备经常被统称为 I/O 设备，键盘、鼠标、麦克风、摄像头是典型的输入设备，而显示器、打印机、扬声器等则是典型的输出设备。目前，我们使用的计算机基本大多是遵循“冯·诺依曼体系结构”的计算机，这种计算机有两个关键点：一是**将存储器与中央处理器分开**；二是**将数据以二进制方式编码**。

二**进制**是一种“逢二进一”的计数法，跟人类使用的“逢十进一”的计数法本质是一样的。对于计算机来说，二进制在物理器件上最容易实现的，因为可以用高电压表示 1，用低电压表示 0。不是所有写程序的人都需要熟悉二进制，熟悉十进制与二进制、八进制、十六进制的转换，大多数时候我们即便不了解这些知识也能写程序。但是，我们必须知道，计算机是使用二进制计数的，不管什么样的数据，到了计算机内存中都是以二进制形态存在的。

**说明**：关于二进制计数法以及它与其他进制如何相互转换，大家可以翻翻名为《计算机导论》或《计算机文化》的书，都能找到相应的知识，此处就不再进行赘述了，不清楚的读者可以自行研究。

## 书写格式

### **一、基础规则**

1. **字符限制**

- 变量名只能包含**字母、数字和下划线**（如 `user_name1`），且**不能以数字开头**（如 `2var` 非法）。
- **禁止使用Python关键字**（如 `if`, `class`, `return` 等）作为变量名。
- **区分大小写**：`age` 和 `Age` 被视为不同变量。

2. **命名风格**

- **普通变量/函数/参数**：推荐使用 **snake_case**（小写字母 + 下划线分隔，如 `total_amount`）。
- **类名**：采用 **PascalCase**（首字母大写的驼峰式，如 `ClassName`）。
- **常量**：使用 **UPPER_SNAKE_CASE**（全大写 + 下划线，如 `MAX_LENGTH`）。

- 值永远不会发生改变的量

### **二、特殊变量与作用域**

1. **私有变量**

- **单下划线开头**（如 `_internal_var`）：表示“内部使用”，但外部仍可访问。 【保护】
- **双下划线开头**（如 `__private_var`）：触发名称修饰（Name Mangling），防止子类意外覆盖。【私有】

2. **专有变量**

- 双下划线包围（如 `__init__`）：用于特殊方法或属性，由Python解释器定义。

3. **全局变量**

- 建议在模块内使用全大写，并通过 `__all__` 或前导下划线控制导出（如 `GLOBAL_VAR`）。

#### 1. 私有变量

##### 单下划线开头：`_internal_var`

- **含义**：这是一种**约定俗成的“保护”成员**。
- **作用**：提示其他程序员“这是一个内部变量，请勿在类或模块外部直接使用它”。Python解释器**不会**阻止你访问它，这只是一种编程约定。
- **常见用途**：

- 模块内部的辅助函数或变量。
- 类的内部状态，不希望被子类直接继承或修改。
- 当使用 `from module import *` 时，以单下划线开头的名称**不会被导入**（除非在 `__all__` 列表中明确列出）。

**示例代码**：

```
class MyClass:
    def __init__(self):
        self.public = "大家都能用"
        self._internal = "建议内部使用"  # 保护成员

obj = MyClass()
print(obj.public)      # 输出：大家都能用
print(obj._internal)   # 输出：建议内部使用（可以访问，但不建议）
```

##### 双下划线开头：`__private_var`

- **含义**：这触发了 **名称修饰（Name Mangling）**，是一种更强的“私有”机制。
- **作用**：解释器会在运行时将变量名重写为 `_类名__变量名` 的形式。这主要是为了防止子类意外覆盖父类的私有属性。
- **注意**：它**不是真正的私有**，通过修饰后的名称仍然可以访问，但这需要刻意为之，因此被视为一种强提示。

**示例代码**：

```
class MyClass:
    def __init__(self):
        self.__private = "我是私有的"  # 名称将被修饰

obj = MyClass()
# print(obj.__private)  # 直接访问会报错：AttributeError
print(obj._MyClass__private)  # 输出：我是私有的（通过修饰后的名称可以访问）

class SubClass(MyClass):
    def __init__(self):
        super().__init__()
        self.__private = "子类的私有变量"  # 不会覆盖父类的 __private

sub_obj = SubClass()
print(sub_obj._SubClass__private)  # 输出：子类的私有变量
print(sub_obj._MyClass__private)   # 输出：我是私有的（父类的变量依然存在）
```

#### 2. 专有变量（魔术方法/属性）

##### 双下划线包围：`__init__`, `__name__`, `__file__`

- **含义**：这是 **Python 语言定义的“魔术方法”或特殊属性**。
- **作用**：它们有特定的语法含义，由Python解释器在特定场景下自动调用或提供。
- **规则**：**永远不要**自己发明这种格式的变量名，只使用Python官方定义的。

**常见示例**：

```
# 特殊方法
class MyClass:
    def __init__(self, value):  # 对象初始化时自动调用
        self.value = value
    def __str__(self):          # 被 print() 或 str() 时调用
        return f"MyClass({self.value})"

# 特殊属性
print(__name__)          # 当前模块名，如果是主程序则为 '__main__'
import os
print(os.__file__)       # 模块的文件路径
```

#### 3. 全局变量

##### 命名与导出控制

- **命名约定**：在模块级别定义的、希望被视为全局常量的变量，通常使用**全大写字母加下划线**（`GLOBAL_VAR`, `MAX_SIZE`）。
- **导出控制**：

- `__all__` **列表**：这是一个字符串列表，用于明确指定当使用 `from module import *` 时，哪些名称会被导出。这是**最推荐**的控制方式。
- **前导下划线**：在模块中，以单下划线开头的变量（如 `_internal_constant`）不会被 `import *` 导入。

**示例代码 (**`my_module.py`**)**：

```
# 模块：my_module.py

# 公共常量（建议全大写）
PUBLIC_CONSTANT = "我是公开的"
_INTERNAL_CONSTANT = "我是内部的"  # 保护变量

# 控制 from my_module import * 的行为
__all__ = ["PUBLIC_CONSTANT", "public_function"]  # 只导出这两个名字

def public_function():
    return "公共函数"

def _internal_function():
    return "内部函数"
```

**使用该模块**：

```
# 主程序
from my_module import *  # 只导入 __all__ 中指定的名称

print(PUBLIC_CONSTANT)        # 可以访问
print(public_function())      # 可以访问
# print(_INTERNAL_CONSTANT)   # 报错：未定义（因为未导出）
# print(_internal_function()) # 报错：未定义

# 但显式导入仍然可以访问“保护”成员
import my_module
print(my_module._INTERNAL_CONSTANT)  # 可以访问（但不建议）
```

#### 总结与最佳实践

|   |   |   |   |   |
|---|---|---|---|---|
|变量类型|命名样式|目的|访问性|最佳实践|
|**公共变量**|`normal_var`, `CONSTANT`|公开接口|完全可访问|提供清晰、稳定的API。|
|**保护变量**|`_internal_var`|内部使用|可访问（不阻止）|作为对开发者的提示，约定不在外部使用。用 `__all__` 控制导出。|
|**私有变量**|`__private_var`|防止子类覆盖|通过名称修饰可访问|主要用于类继承场景，防止命名冲突。|
|**专有变量**|`__magic__`|语言特性|由解释器管理|**绝不**自定义此类名称，只使用Python定义的。|
|**全局常量**|`GLOBAL_VAR`|模块级常量|取决于导出控制|使用全大写，并通过 `__all__` 明确导出列表。|

**核心原则**：

1. **约定大于强制**：Python的“私有”更多依赖于开发者之间的约定和工具（如`__all__`）来管理，而非语言的强制约束。
2. **明确接口**：使用 `__all__` 来清晰地定义模块的公共接口，这是最专业和可维护的做法。
3. **尊重约定**：遵循这些命名约定可以使你的代码更易读、更易维护，并与其他Python程序员协作更顺畅。

## 二、字面量（Literal）总结

字面量是直接在代码中表示固定值的语法形式，无需变量声明。

## 三、核心注意事项

1. **可变性差异**

- 不可变类型（如 `str`, `tuple`）在修改时会创建新对象。
- 可变类型（如 `list`, `dict`）允许原地修改。

2. **类型推断**  
    Python根据字面量自动推断类型：

```
type(42)        # <class 'int'>
type(3.14)      # <class 'float'>
type("text")    # <class 'str'>
```

3. **字面量边界规则**

- 元组单元素必须加逗号：`(1,)` vs `(1)`（后者视为整型）。
- 空集合必须用 `set()`，因为 `{}` 表示空字典。

## 小整数的地址问题

- Python中的小整数，通常指的是==-5至256之间的整数。==
- 当你在Python中创建一个整数对象时，Python会根据该整数的值动态地为其分配内存空间。对于小整数，Python会使用一种称为“**小整数缓存**”的机制来优化内存使用。这个缓存池中的整数对象会被重复利用，而不是为每个新创建的小整数分配新的内存空间。这样可以减少内存分配和释放的开销，提高程序的性能。
- 如果你需要跟踪Python对象的内存地址，可以使用Python提供的**内置函数id()**来获取对象的唯一标识符，这个标识符通常可以用来近似地表示对象的内存地址。但是请注意，这个标识符并不是真正的内存地址，而是由Python解释器生成的一个唯一标识符，用于区分不同的对象实例。
