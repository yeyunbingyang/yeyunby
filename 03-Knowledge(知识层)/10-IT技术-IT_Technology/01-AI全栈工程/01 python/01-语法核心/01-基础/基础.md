## 第一个Python程序

在上一课中，我们对 Python 语言的过去现在有了一些了解，我们准备好了运行 Python 程序所需要的解释器环境。相信大家已经迫不及待的想开始自己的 Python 编程之旅了，但是新问题来了，我们应该在什么地方书写 Python 程序，然后又怎么运行它呢？

### 编写代码的工具

下面我们为大家讲解几种可以编写和运行 Python 代码的工具，大家可以根据自己的需求来选择合适的工具。当然，对于初学者，我个人比较推荐使用 PyCharm，因为它不需要太多的配置也非常的强大，对新手还是很友好的。如果你也听说过或者喜欢 PyCharm，可以直接跳过下面对其他工具的介绍，直接快进到讲解 PyCharm 的地方。

#### 默认的交互式环境

我们打开 Windows 的“命令提示符”或“PowerShell”工具，输入`python`然后按下`Enter`键，这个命令会把我们带到一个交互式环境中。所谓交互式环境，就是我们输入一行代码并按下`Enter`键，代码马上会被执行，如果代码有产出结果，那么结果会被显示在窗口中，如下所示。

```
Python 3.10.10
Type "help", "copyright", "credits" or "license" for more information.
>>> 2 * 3
6
>>> 2 + 3
5
>>>
```

**说明**：使用 macOS 系统的用户需要打开“终端”工具，输入`python3`进入交互式环境。

如果希望退出交互式环境，可以在交互式环境中输入`quit()`，如下所示。

```
>>> quit()
```

### 你好世界

按照行业惯例，我们学习任何一门编程语言写的第一个程序都是输出`hello, world`，因为这段代码是伟大的丹尼斯·里奇（C 语言之父，和肯·汤普森一起开发了 Unix 操作系统）和布莱恩·柯尼汉（awk 语言的发明者）在他们的不朽著作《_The C Programming Language_》中写的第一段代码，下面是对应的 Python 语言的版本。

```
print('hello, world')
```

**注意**：上面代码中的圆括号、单引号都是在英文输入法状态下输入的，如果不小心写成了中文的圆括号或单引号，运行代码时会出现`SyntaxError: invalid character '（' (U+FF08)`或`SyntaxError: invalid character '‘' (U+2018)`这样的错误提示。

上面的代码只有一个语句，在这个语句中，我们用到了一个名为`print`的函数，它可以帮助我们输出指定的内容；`print`函数圆括号中的`'hello, world'`是一个字符串，它代表了一段文本内容；在 Python 语言中，我们可以用单引号或双引号来表示一个字符串。不同于 C、C++ 或 Java 这样的编程语言，Python 代码中的语句不需要用分号来表示结束，也就是说，如果我们想再写一条语句，只需要回车换行即可，代码如下所示。此外，Python 代码也不需要通过编写名为`main`的入口函数来使其运行，提供入口函数是编写可执行的 C、C++ 或 Java 代码必须要做的事情，这一点很多程序员都不陌生，但是在 Python 语言中它并不是必要的。

### 注释你的代码

注释是编程语言的一个重要组成部分，用于在代码中解释代码的作用，从而达到增强代码可读性的目标。当然，我们也可以将代码中暂时不需要运行的代码段通过添加注释来去掉，这样当你需要重新使用这些代码的时候，去掉注释符号就可以了。简单的说，**注释会让代码更容易看懂但不会影响代码的执行结果**。

Python 中有两种形式的注释：

1. 单行注释：以`#`和空格开头，可以注释掉从`#`开始后面一整行的内容。
2. 多行注释：三个引号（通常用双引号）开头，三个引号结尾，通常用于添加多行说明性内容。

```
"""
第一个Python程序 - hello, world

Version: 1.0
Author: 骆昊
"""
# print('hello, world')
print("你好，世界！")
```

## print()函数【输出/打印指定内容】

官⽅定义： print( *objects , sep=' ', end='\n' , file=None , flush=False)

将`objects`打印输出⾄`file`指定的⽂本流，以`sep`分隔并在末尾加上`end`。

`sep`、`end`、 `file` 和 `flush`必须以关键字参数的形式给出。

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1741096506202-d9716984-1ded-4f32-a8b4-1620112a1e49.png)

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1741096763867-7f5affa1-cfcb-4797-b84b-13fb145353c4.png)

所有⾮关键字参数都会被转换为字符串，就像是执⾏了 `str()` ⼀样，并会被写⼊到流，以 `sep` 分隔并在末尾加上`end`。`sep`和`end`都必须为字符串；它们也可以为 `None`，这意味着 使⽤默认值【/n】。如果没有给出`objects【可以是多个内容】`，则 `print()` 将只写⼊`end`。

`file` 参数必须是⼀个具有 将使⽤ `write(string)` ⽅法的对象；如果参数不存在或为 None ，则 `sys.stdout` 。由于要打印的参数会被转换为⽂本字符串，因此对于⼆进制模式的⽂件对象。对于这些对象，应改⽤ `print()` 不能⽤ `file.write(...)` 。

输出缓冲通常由file确定。但是，如果`flush`为真值，流将被强制刷新。

### 格式化输出【面向整数及浮点数】

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1741096799900-af1afaea-4538-4fb3-83ee-351eaf68cf27.png)

以下是更全面的格式化输出占位符总结，包括整数和浮点数的多种用法：

#### 格式化占位符总结

|   |   |   |   |
|---|---|---|---|
|占位符|数据类型|说明|示例|
|`%s`⭐|字符串|输出字符串|`"名字是 %s" % name`|
|`%d`⭐|整数|输出有符号十进制整数|`"年龄是 %d" % age`|
|`%i`|整数|同 `%d`，输出有符号十进制整数|`"编号是 %i" % num`|
|`%u`|整数|输出无符号十进制整数|`"无符号数是 %u" % unsigned_num`|
|`%o`|整数|输出八进制整数|`"八进制是 %o" % octal_num`|
|`%x`|整数|输出小写十六进制整数|`"十六进制是 %x" % hex_num`|
|`%X`|整数|输出大写十六进制整数|`"大写十六进制是 %X" % hex_num`|
|`%f`|浮点数|输出浮点数|`"价格是 %f" % price`|
|`%.2f`⭐|浮点数|小数点后保留两位|`"折扣是 %.2f" % discount`|
|`%e`|浮点数|科学计数法表示浮点数|`"科学计数法是 %e" % scientific`|
|`%E`|浮点数|大写科学计数法表示浮点数|`"大写科学计数法是 %E" % scientific`|
|`%%`⭐|百分号|输出百分号 `%`|`"完成度是 100%%"`|

#### 整数与浮点数用法总结

##### 整数格式化

- **基本用法**：`%d` 或 `%i` 用于输出十进制整数。
- **无符号整数**：使用 `%u`。
- **八进制与十六进制**：

- `%o` 用于八进制。
- `%x`（小写）和 `%X`（大写）用于十六进制。

- **宽度和填充**：可以指定输出宽度和填充方式。⭐

- 例如：`%5d` 表示宽度为5，`%05d` 表示宽度为5，不足部分用0填充。

##### 浮点数格式化

- **基本用法**：`%f` 用于输出浮点数。
- **指定小数位数**：使用 `%.2f` 表示小数点后保留两位。
- **科学计数法**：使用 `%e` 或 `%E` 表示浮点数的科学计数法形式。
- **宽度与精度**：可以同时指定宽度和精度，如 `%8.2f` 表示总宽度为8，小数点后保留2位。⭐

### f-string（格式化字符串字面值，Python 3.6+）【最推荐】

这是目前最简洁、可读性最强、性能也最好的方法，在字符串前加 `f` 或 `F`，并直接在 `{}` 内写入表达式。

- **基本语法**：`f"字符串{表达式}字符串"`

```
name = "Charlie"
age = 30

# 直接嵌入变量和表达式

print(f"编号: {7:04d}")                # 输出：编号: 0007
```

```
response = input("请输入您的反馈（可留空）：")
```

4. **使用** `eval()` **或** `float()` **进行数学输入**

**使用** `float()`：当你只需要**获取数字时**，使用 `float()` 进行类型转换是安全的。

**使用** `eval()`：`eval()` 允许用户输入任何有效的 **Python 表达式**，计算并返回结果，但存在安全隐患。如果输入的表达式包含恶意代码，可能会导致安全问题。因此，在实际应用中应谨慎使用，最好仅在受信任的输入源上使用 `eval()`。

```
# 获取用户输入的浮点数

try:
    number = float(number)  # 转换为浮点数
    print("您输入的数字是：", number)
except ValueError:
    print("输入无效，请输入一个有效的数字。")
number = input("请输入一个数字：")
number = float(number)  # 转换为浮点数
print("您输入的数字是：", number)
```

```
# 获取用户输入的数学表达式

    print("您输入的表达式的结果是：", result)

    print("输入无效，请输入一个有效的数学表达式。")

    print("发生错误：", e)
```

### 注意事项

- **始终返回字符串**：无论用户输入什么类型的数据，`input()` 都会将其视为字符串。
- **类型安全**：在转换输入数据类型时，需要确保输入的内容可以安全地转换，否则会引发错误（如 `ValueError`）。
- **Python 2.x**：在 Python 2.x 中，使用 `raw_input()` 获取字符串输入，`input()` 则会执行表达式求值。

### 总结

`input()` 函数是 Python 中获取用户输入的基本工具，通过提示字符串引导用户输入，默认返回值为字符串。根据需要，可以进行类型转换来处理不同类型的数据输入。

## 类型检查

在 Python 中，可以使用内置的 `type()` 函数和 `isinstance()` 函数来检查变量的类型。以下是这两种方法的详细说明：

### 1. 使用 `type()`

`type()` 函数返回对象的类型。可以通过比较返回的类型与目标类型进行检查。

#### 示例：

```
# 示例变量
value = 10

# 检查类型
if type(value) == int:
    print("value 是整数")
elif type(value) == float:
    print("value 是浮点数")
elif type(value) == str:
    print("value 是字符串")
else:
    print("value 是其他类型")
```

### 2. 使用 `isinstance()`

`isinstance()` 函数更灵活且更常用，它检查一个对象是否是特定类或其子类的实例。此方法在处理继承时尤其有用。

#### 示例：

```
# 示例变量
value = 10.5

# 检查类型
if isinstance(value, int):
    print("value 是整数")
elif isinstance(value, float):
    print("value 是浮点数")
elif isinstance(value, str):
    print("value 是字符串")
else:
    print("value 是其他类型")
```

### 3. 检查多个类型

`isinstance()` 还支持同时检查多个类型，可以将类型作为元组传递。

#### 示例：

```
# 示例变量
value = "Hello"

# 检查多个类型
if isinstance(value, (int, float)):
    print("value 是数字")
elif isinstance(value, str):
    print("value 是字符串")
else:
    print("value 是其他类型")
```

### 小结

- 使用 `type()` 进行类型检查简单直接，但不考虑继承关系。
- 使用 `isinstance()` 更加灵活且推荐使用，特别是在处理对象时。它可以有效检查一个对象是否属于某个类或其子类。⭐

这两种方法都可以帮助你在程序中进行类型检查，以确保数据类型符合预期。

## **init**.py

`__init__.py` 文件在 Python 中有几个重要的作用，主要用于包的定义和管理。以下是其主要功能：

1. **包的标识**：`__init__.py` 文件的存在表明该目录是一个 Python 包，使得 Python 可以识别并导入该目录中的模块。没有这个文件，Python 将无法将该目录视为包。
2. **初始化代码**：在导入包时，`__init__.py` 中的代码会被执行。这使得可以在包被导入时进行一些初始化操作，比如设置包的状态或导入某些模块。
3. **控制导入内容**：可以通过在 `__init__.py` 中定义 `__all__` 列表，控制从包中导入的模块或子模块。例如：

```
__all__ = ['module1', 'module2']
```

4. **封装功能**：可以在 `__init__.py` 中定义一些公共接口，提供给包的使用者，隐藏内部实现细节。
5. **允许空包**：即使 `__init__.py` 文件为空，包仍然是有效的，允许在包中定义模块而不需要添加额外的代码。

总结来说，`__init__.py` 是**定义和管理 Python 包**的重要文件，确保包的正确导入和初始化。
