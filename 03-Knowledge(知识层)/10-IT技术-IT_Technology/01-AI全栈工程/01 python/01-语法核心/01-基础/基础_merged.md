## 变量与数据类型

### 变量

变量是存放数据的容器。Python 是动态类型语言，声明时无需指定类型：

```python
name = "张三"
age = 25
score = 98.5
is_pass = True
```

#### 标识符命名规则

- 只能包含字母、数字和下划线，且不能以数字开头
- 区分大小写（`Name` ≠ `name`）
- 不能使用 Python 关键字（如 `if`、`for`、`class`）

常用命名方法：`snake_case`（变量/函数）、`PascalCase`（类名）

#### 变量的修改

```python
x = 10
x = 20          # 重新赋值
x = x + 5       # 自增
```

### 常量

Python 没有真正的常量机制，约定用**全大写**表示不应修改的值：

```python
PI = 3.14159
MAX_SIZE = 100
```

### 数据类型概览

| 类型 | 示例 | 说明 |
|------|------|------|
| `int` | `42` | 整数，无大小限制 |
| `float` | `3.14` | 浮点数 |
| `bool` | `True`, `False` | 布尔值 |
| `str` | `"hello"` | 字符串 |
| `list` | `[1, 2, 3]` | 列表 |
| `tuple` | `(1, 2, 3)` | 元组 |
| `dict` | `{"key": "value"}` | 字典 |
| `set` | `{1, 2, 3}` | 集合 |
| `NoneType` | `None` | 空值 |

#### 整数分隔符

Python 3.6+ 支持用 `_` 分隔大数字以提高可读性：

```python
big = 1_000_000  # 一百万
```

### 进制以及转换

| 进制 | 前缀 | 示例 |
|------|------|------|
| 十进制 | 无 | `42` |
| 二进制 | `0b` | `0b101010` |
| 八进制 | `0o` | `0o52` |
| 十六进制 | `0x` | `0x2A` |

```python
bin(42)   # '0b101010'  十进制→二进制
oct(42)   # '0o52'      十进制→八进制
hex(42)   # '0x2a'      十进制→十六进制
int('101010', 2)  # 42  二进制→十进制
```

### 类型检查

#### `type()` —— 返回精确类型

```python
type(42)        # <class 'int'>
type("hello")   # <class 'str'>
```

#### `isinstance()` —— 考虑继承关系（推荐）

```python
isinstance(42, int)          # True
isinstance(True, int)        # True（bool 是 int 的子类）
isinstance("hello", (int, str))  # True（检查多个类型）
```

### 小整数池与大整数池

- **小整数池**：`-5 ~ 256` 范围内的整数由解释器预先创建，所有引用指向同一对象
- **大整数池**：超出范围每次创建新对象

```python
a = 256; b = 256
a is b   # True（同一个对象）

a = 257; b = 257
a is b   # False（不同对象）
```

## 运算符

### 算术运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `+` | 加 | `3 + 2` → `5` |
| `-` | 减 | `3 - 2` → `1` |
| `*` | 乘 | `3 * 2` → `6` |
| `/` | 除（浮点） | `3 / 2` → `1.5` |
| `//` | 整除 | `3 // 2` → `1` |
| `%` | 取余 | `3 % 2` → `1` |
| `**` | 幂 | `3 ** 2` → `9` |

### 赋值运算符

`=`, `+=`, `-=`, `*=`, `/=` 等。

### 比较运算符

`==`, `!=`, `>`, `<`, `>=`, `<=`。不同类型之间不能比较大小，字符串按 ASCII 逐字符比较。

### 逻辑运算符

`and`, `or`, `not`。支持短路求值。

### 位运算符

`&`（与）、`|`（或）、`^`（异或）、`~`（非）、`<<`（左移）、`>>`（右移）。

### 成员运算符

`in`, `not in`——检查元素是否在容器中。

### 身份运算符

`is`, `is not`——判断两个变量是否引用同一对象（比较内存地址 `id()`）。

## 输入与输出

### input() —— 获取用户输入

```python
name = input("请输入姓名：")
print(f"你好，{name}")
```

**注意：** `input()` 返回的始终是**字符串**，需要时用 `int()` / `float()` 转换。

### print() —— 输出内容

```python
print("Hello")                      # 普通输出
print("a", "b", "c", sep="-")       # 分隔符：a-b-c
print("Hello", end="!")             # 结尾符：Hello!
```

#### f-string 格式化（推荐，Python 3.6+）

```python
name = "张三"
age = 25
print(f"{name} 今年 {age} 岁")

# 格式化数字
pi = 3.14159
print(f"π ≈ {pi:.2f}")   # 3.14
```

#### 传统格式化占位符

| 占位符 | 说明 |
|--------|------|
| `%s` | 字符串 |
| `%d` | 整数 |
| `%f` | 浮点数 |
| `%.2f` | 保留两位小数 |
| `%x` | 十六进制 |

## Python 编码规范

- **缩进**：使用 4 个空格（不要混用 Tab）
- **行长**：每行不超过 79 个字符
- **空行**：函数/类之间空两行，方法之间空一行
- **分号**：不要在行尾加分号
- **空格**：运算符两侧各一个空格，逗号后加空格
- **源文件编码**：使用 UTF-8（`# -*- coding: utf-8 -*-`）

## 项目环境

### .venv 目录

虚拟环境目录，隔离项目依赖：

```bash
python -m venv .venv          # 创建
.venv\Scripts\activate        # 激活（Windows）
source .venv/bin/activate     # 激活（Linux/Mac）
deactivate                    # 退出
```

### `__init__.py`

标识目录为 Python 包，可以为空文件。Python 3.3+ 支持隐式命名空间包（没有 `__init__.py` 的目录也可作为包使用）。
