## 1. Vue2 vs Vue3 通信方式对比

### Vue2 组件通信方式

| 方式            | 方向  | 说明                                |
| ------------- | --- | --------------------------------- |
| props         | 父→子 | 子组件通过 `props` 接收父组件传递的数据          |
| 自定义事件（$emit）  | 子→父 | 子组件通过 `$emit` 向父组件传递数据            |
| 全局事件总线（$bus）  | 任意  | 通过 `Vue.prototype.$bus` 实现任意组件间通信 |
| PubSub（发布-订阅） | 任意  | 通过发布订阅模式实现任意组件间通信                 |
| Vuex          | 全局  | 集中式状态管理容器                         |
| ref           | 父→子 | 父组件通过 `ref` 获取子组件实例               |
| slot（插槽）      | 父→子 | 通过插槽实现灵活的父子组件通信                   |

### Vue3 组件通信方式

| 方式 | 方向 | 说明 |
|------|------|------|
| props | 父→子 | 通过 `defineProps` 获取父组件传递的值 |
| 自定义事件（defineEmits） | 子→父 | 通过 `defineEmits` 定义自定义事件 |
| mitt（全局事件总线） | 任意 | 使用 `mitt` 插件替代 Vue2 的 `$bus` |
| v-model | 父↔子 | 实现父子组件间的数据同步，支持多个 v-model |
| useAttrs | 祖→孙 | 获取组件的所有属性和事件（合并了 Vue2 的 `$attrs` 和 `$listeners`） |
| ref / $parent | 父↔子 | `ref` 获取子组件实例，`$parent` 获取父组件实例 |
| provide / inject | 祖→孙 | 跨级组件传递数据，解决祖孙组件通信问题 |
| Pinia | 全局 | Vue3 推荐的状态管理库，替代 Vuex |
| slot（插槽） | 父→子 | 默认插槽、具名插槽、作用域插槽 |

### Vue2 与 Vue3 的关键区别

- **事件总线**：Vue3 移除了内置事件总线，使用 `mitt` 代替
- **状态管理**：`Vuex` 换成了 `Pinia`
- **v-model**：把 `.sync` 优化到了 `v-model` 里面
- **$attrs**：把 `$listeners` 所有的东西合并到 `$attrs` 中
- **$children**：被砍掉了

## 2. Props（父子通信）

> `props` 是使用频率最高的一种通信方式，常用于：**父 ↔ 子**。
> - 若 **父传子**：属性值是**非函数**
> - 若 **子传父**：属性值是**函数**

### 父组件

```vue
<template>
  <div class="father">
    <h3>父组件</h3>
    <h4>我的车：{ car }</h4>
    <h4>儿子给的玩具：{ toy }</h4>
    <Child :car="car" :getToy="getToy"/>
  </div>
</template>

<script setup lang="ts" name="Father">
  import Child from './Child.vue'
  import { ref } from "vue";

  // 数据
  const car = ref('奔驰')
  const toy = ref()

  // 方法（子传父的回调）
  function getToy(value: string) {
    toy.value = value
  }
</script>
```

### 子组件

```vue
<template>
  <div class="child">
    <h3>子组件</h3>
    <h4>我的玩具：{ toy }</h4>
    <h4>父给我的车：{ car }</h4>
    <button @click="getToy(toy)">玩具给父亲</button>
  </div>
</template>

<script setup lang="ts" name="Child">
  import { ref } from "vue";
  const toy = ref('奥特曼')

  defineProps(['car', 'getToy'])
</script>
```

### Vue3 中 defineProps 的两种方式

**方式 1：带类型校验**

```ts
let props = defineProps({
  info: {
    type: String,
    default: '默认参数',
  },
  money: {
    type: Number,
    default: 0,
  }
});
```

**方式 2：简单声明**

```ts
let props = defineProps(["info", "money"]);
```

> ⚠️ `props` 是只读的，不能在子组件内修改。

## 3. 自定义事件（子→父）

> 自定义事件常用于：**子 → 父**。

### 注意区分：原生事件 vs 自定义事件

| 特性 | 原生事件 | 自定义事件 |
|------|----------|------------|
| 事件名 | 特定的（click、mouseenter 等） | 任意名称 |
| `$event` | 包含事件相关信息的对象（pageX、target、keyCode 等） | 调用 `emit` 时所提供的数据，可以是任意类型 |

### 父组件监听自定义事件

```vue
<!-- 在父组件中，给子组件绑定自定义事件 -->
<Child @send-toy="toy = $event"/>

<!-- 注意区分原生事件与自定义事件中的 $event -->
<button @click="toy = $event">测试</button>
```

### 子组件触发自定义事件

```vue
<template>
  <button @click="handler">点击我触发 xxx 自定义事件</button>
</template>

<script setup lang="ts">
  let $emit = defineEmits(["xxx"]);

  const handler = () => {
    $emit("xxx", "法拉利", "茅台");
  };
</script>
```

## 4. 全局事件总线（mitt）

> 与消息订阅与发布（pubsub）功能类似，可以实现**任意组件间通信**。

### 安装 mitt

```bash
npm i mitt
```

### 创建 emitter（src/utils/emitter.ts）

```ts
// 引入 mitt 
import mitt from "mitt";

// 创建 emitter
const emitter = mitt()

/*
  // 绑定事件
  emitter.on('abc', (value) => {
    console.log('abc事件被触发', value)
  })
  emitter.on('xyz', (value) => {
    console.log('xyz事件被触发', value)
  })

  setInterval(() => {
    // 触发事件
    emitter.emit('abc', 666)
    emitter.emit('xyz', 777)
  }, 1000);

  setTimeout(() => {
    // 清理事件
    emitter.all.clear()
  }, 3000); 
*/

// 创建并暴露 mitt
export default emitter
```

### 接收数据的组件：绑定事件 + 销毁前解绑

```vue
<script setup lang="ts">
  import emitter from "@/utils/emitter";
  import { onUnmounted } from "vue";

  // 绑定事件
  emitter.on('send-toy', (value) => {
    console.log('send-toy事件被触发', value)
  })

  onUnmounted(() => {
    // 解绑事件
    emitter.off('send-toy')
  })
</script>
```

### 提供数据的组件：触发事件

```vue
<script setup lang="ts">
  import emitter from "@/utils/emitter";

  function sendToy() {
    // 触发事件
    emitter.emit('send-toy', toy.value)
  }
</script>
```

> 注意：总线依赖 Vue 组件的内置关系。

## 5. v-model（双向绑定）

> 实现 **父 ↔ 子** 之间相互通信。

### v-model 的本质

```vue
<!-- 使用 v-model 指令 -->
<input type="text" v-model="userName">

<!-- v-model 的本质是下面这行代码 -->
<input 
  type="text" 
  :value="userName" 
  @input="userName = ($event.target as HTMLInputElement).value"
>
```

### 组件标签上的 v-model 本质

```vue
<!-- 组件标签上使用 v-model 指令 -->
<AtguiguInput v-model="userName"/>

<!-- 组件标签上 v-model 的本质 -->
<AtguiguInput :modelValue="userName" @update:model-value="userName = $event"/>
```

### 子组件实现 v-model

```vue
<template>
  <div class="box">
    <!-- 将接收的 value 值赋给 input 元素的 value 属性，目的是：为了呈现数据 -->
    <!-- 给 input 元素绑定原生 input 事件，触发 input 事件时，进而触发 update:model-value 事件 -->
    <input 
       type="text" 
       :value="modelValue" 
       @input="emit('update:model-value', $event.target.value)"
    >
  </div>
</template>

<script setup lang="ts" name="AtguiguInput">
  // 接收 props
  defineProps(['modelValue'])
  // 声明事件
  const emit = defineEmits(['update:model-value'])
</script>
```

### 更换 value 名称（例如改成 abc）

```vue
<!-- 也可以更换 value，例如改成 abc -->
<AtguiguInput v-model:abc="userName"/>

<!-- 上面代码的本质如下 -->
<AtguiguInput :abc="userName" @update:abc="userName = $event"/>
```

子组件中：

```vue
<template>
  <div class="box">
    <input 
       type="text" 
       :value="abc" 
       @input="emit('update:abc', $event.target.value)"
    >
  </div>
</template>

<script setup lang="ts" name="AtguiguInput">
  defineProps(['abc'])
  const emit = defineEmits(['update:abc'])
</script>
```

### 多个 v-model 同时使用

```vue
<AtguiguInput v-model:abc="userName" v-model:xyz="password"/>
```

## 6. $attrs（祖→孙）

> `$attrs` 用于实现**当前组件的父组件**，向**当前组件的子组件**通信（**祖→孙**）。
> 
> `$attrs` 是一个对象，包含所有父组件传入的标签属性。会自动排除 `props` 中声明的属性（可以认为声明过的 `props` 被子组件自己"消费"了）。

### 父组件

```vue
<template>
  <div class="father">
    <h3>父组件</h3>
    <Child :a="a" :b="b" :c="c" :d="d" v-bind="{x:100, y:200}" :updateA="updateA"/>
  </div>
</template>

<script setup lang="ts" name="Father">
  import Child from './Child.vue'
  import { ref } from "vue";

  let a = ref(1)
  let b = ref(2)
  let c = ref(3)
  let d = ref(4)

  function updateA(value) {
    a.value = value
  }
</script>
```

### 子组件（透传 $attrs）

```vue
<template>
  <div class="child">
    <h3>子组件</h3>
    <GrandChild v-bind="$attrs"/>
  </div>
</template>

<script setup lang="ts" name="Child">
  import GrandChild from './GrandChild.vue'
</script>
```

### 孙组件（接收所有透传属性）

```vue
<template>
  <div class="grand-child">
    <h3>孙组件</h3>
    <h4>a：{ a }</h4>
    <h4>b：{ b }</h4>
    <h4>c：{ c }</h4>
    <h4>d：{ d }</h4>
    <h4>x：{ x }</h4>
    <h4>y：{ y }</h4>
    <button @click="updateA(666)">点我更新 A</button>
  </div>
</template>

<script setup lang="ts" name="GrandChild">
  defineProps(['a', 'b', 'c', 'd', 'x', 'y', 'updateA'])
</script>
```

## 7. ref 与 $parent

| 属性 | 说明 | 方向 |
|------|------|------|
| `$refs` | 值为对象，包含所有被 `ref` 属性标识的 DOM 元素或组件实例 | 父→子 |
| `$parent` | 值为对象，当前组件的父组件实例对象 | 子→父 |

### ref（父→子）

```vue
<!-- 父组件 -->
<template>
  <Son ref="son"></Son>
</template>

<script setup lang="ts">
  import { ref, onMounted } from 'vue';
  const son = ref();

  onMounted(() => {
    console.log(son.value); // 获取子组件实例
  });
</script>
```

### $parent（子→父）

```vue
<!-- 子组件 -->
<template>
  <button @click="handler($parent)">点击我获取父组件实例</button>
</template>
```

## 8. provide 与 inject（祖孙通信）

> 实现**祖孙组件**直接通信。
> - 在祖先组件中通过 `provide` 配置向后代组件提供数据
> - 在后代组件中通过 `inject` 配置来声明接收数据

### 父组件（提供数据）

```vue
<template>
  <div class="father">
    <h3>父组件</h3>
    <h4>资产：{ money }</h4>
    <h4>汽车：{ car }</h4>
    <button @click="money += 1">资产+1</button>
    <button @click="car.price += 1">汽车价格+1</button>
    <Child/>
  </div>
</template>

<script setup lang="ts" name="Father">
  import Child from './Child.vue'
  import { ref, reactive, provide } from "vue";

  // 数据
  let money = ref(100)
  let car = reactive({
    brand: '奔驰',
    price: 100
  })

  // 用于更新 money 的方法
  function updateMoney(value: number) {
    money.value += value
  }

  // 提供数据
  provide('moneyContext', {money, updateMoney})
  provide('car', car)
</script>
```

> 注意：子组件中不用编写任何东西，不会受到任何打扰。

### 孙组件（注入数据）

```vue
<template>
  <div class="grand-child">
    <h3>我是孙组件</h3>
    <h4>资产：{ money }</h4>
    <h4>汽车：{ car }</h4>
    <button @click="updateMoney(6)">点我</button>
  </div>
</template>

<script setup lang="ts" name="GrandChild">
  import { inject } from 'vue';

  // 注入数据（提供默认值防止 undefined）
  let {money, updateMoney} = inject('moneyContext', {money: 0, updateMoney: (x: number) => {}})
  let car = inject('car')
</script>
```

## 9. Pinia（状态管理）

> `Pinia` 是 Vue3 推荐的状态管理库，类似于 Vuex，但更轻量和简洁。
> - 核心概念没有 `mutation` 和 `modules`
> - 更注重直接的状态管理

参考 Pinia 官方文档进行深入学习。

## 10. Slot（插槽）

> 插槽可以实现父子组件的通信，Vue3 支持默认插槽、具名插槽和作用域插槽。

### 10.1 默认插槽

```vue
<!-- 父组件 -->
<Category title="今日热门游戏">
  <ul>
    <li v-for="g in games" :key="g.id">{ g.name }</li>
  </ul>
</Category>

<!-- 子组件 -->
<template>
  <div class="item">
    <h3>{ title }</h3>
    <!-- 默认插槽 -->
    <slot></slot>
  </div>
</template>
```

### 10.2 具名插槽

```vue
<!-- 父组件 -->
<Category title="今日热门游戏">
  <template v-slot:s1>
    <ul>
      <li v-for="g in games" :key="g.id">{ g.name }</li>
    </ul>
  </template>
  <template #s2>
    <a href="">更多</a>
  </template>
</Category>

<!-- 子组件 -->
<template>
  <div class="item">
    <h3>{ title }</h3>
    <slot name="s1"></slot>
    <slot name="s2"></slot>
  </div>
</template>
```

### 10.3 作用域插槽

> 数据在组件的自身，但根据数据生成的结构需要组件的使用者来决定。
> （新闻数据在 `News` 组件中，但使用数据所遍历出来的结构由 `App` 组件决定）

```vue
<!-- 父组件 -->
<Game v-slot="params">
<!-- <Game v-slot:default="params"> -->
<!-- <Game #default="params"> -->
  <ul>
    <li v-for="g in params.games" :key="g.id">{ g.name }</li>
  </ul>
</Game>

<!-- 子组件 -->
<template>
  <div class="category">
    <h2>今日游戏榜单</h2>
    <slot :games="games" a="哈哈"></slot>
  </div>
</template>

<script setup lang="ts" name="Category">
  import { reactive } from 'vue'
  let games = reactive([
    {id:'asgdytsa01', name:'英雄联盟'},
    {id:'asgdytsa02', name:'王者荣耀'},
    {id:'asgdytsa03', name:'红色警戒'},
    {id:'asgdytsa04', name:'斗罗大陆'}
  ])
</script>
```

## 11. 常见搭配形式速查

| 场景 | 推荐方式 |
|------|----------|
| 父 → 子 | Props |
| 子 → 父 | 自定义事件（$emit） |
| 父 ↔ 子 | v-model |
| 祖 → 孙 | $attrs / provide + inject |
| 任意组件 | mitt（全局事件总线） |
| 全局状态 | Pinia |
| 父 → 子（内容传递） | Slot（插槽） |
| 父 → 子（获取实例） | ref |
| 子 → 父（获取实例） | $parent |

---

## 总结

- **Props 和 v-model**：父子组件通信的基础方式，尤其是 `v-model` 在 Vue3 中的多重使用
- **自定义事件和 $emit**：子组件向父组件传递数据的常见方式
- **全局事件总线**：通过 `mitt` 插件实现任意组件间通信
- **ref 和 $parent**：父组件通过 `ref` 获取子组件实例，子组件通过 `$parent` 获取父组件实例
- **provide 与 inject**：用于跨级组件传递数据，解决祖孙组件通信问题
- **Pinia**：Vue3 推荐的状态管理工具
- **插槽**：提供了灵活的父子组件通信方式，支持默认插槽、具名插槽和作用域插槽

这些通信方式能够帮助开发者在项目中更高效地实现组件间的数据传递和逻辑共享。
