### **一、常见配置项**

ECharts的核心配置项通过`option`对象实现，主要包括：

1. **标题（title）** ：设置主/副标题文本、位置、样式等 。
2. **图例（legend）** ：标识不同数据系列，控制显示位置和样式 。
3. **提示框（tooltip）** ：鼠标悬停时显示数据详情，可自定义触发方式和内容格式 。
4. **网格（grid）** ：控制图表区域的位置、大小和边距 。
5. **坐标轴（xAxis/yAxis）**：

- 类型（`category`分类轴/`value`数值轴）
- 数据（`data`）、刻度、标签样式、网格线 。

6. **数据系列（series）**：

- 图表类型（`type`如`line`、`bar`、`pie`）
- 数据（`data`）、颜色、标签显示、平滑曲线等 。

7. **工具栏（toolbox）** ：提供导出图片、数据视图、缩放等工具 。
8. **数据缩放（dataZoom）** ：支持滑动查看数据区间 。

**注**：完整配置项参考[官方文档](https://echarts.apache.org/zh/option.html) 。

### **二、不同图表的配置方式**

通过`series.type`指定图表类型，关键配置如下：

1. **折线图（Line Chart）**：

- `series.type: 'line'`
- 平滑曲线：`smooth: true`
- 标记点：`symbol: 'circle'` 。

2. **柱状图（Bar Chart）**：

- `series.type: 'bar'`
- 柱宽：`barWidth`
- 横向柱状图：交换`xAxis/yAxis`的`data` 。

3. **饼图（Pie Chart）**：

- `series.type: 'pie'`
- 半径：`radius: ['30%', '70%']`（环形图）
- 标签位置：`label: { position: 'inner' }` 。

4. **散点图（Scatter Chart）**：

- `series.type: 'scatter'`
- 点大小：`symbolSize`
- 颜色映射：`visualMap`组件 。

**扩展图表**：地图（`type: 'map'`）、雷达图（`type: 'radar'`）需额外引入文件或配置坐标系 。

### **三、动态数据刷新**

通过`setOption()`更新数据，两种方式：

1. **全量更新**：替换整个`option`对象（适用于结构变化）。
2. **增量更新**：仅修改数据部分（推荐性能优化）：

```
// 更新折线图数据（示例）
var newData = [30, 40, 25, 50]; 
myChart.setOption({
  series: [{ data: newData }]
}); [[12, 13]]
```

- **饼图**：更新`legend.data`和`series.data` 。
- **柱状图**：更新`dataset.so urce`或`yAxis.data` 。

3. **定时刷新**：结合`setInterval`或Ajax请求后端数据 。

**注意**：Vue项目中可用`watch`监听数据变化后刷新图表 。

### **四、最佳实践**

1. **图表选型原则**：

- 趋势分析 → 折线图
- 类别比较 → 柱状图
- 占比展示 → 饼图/环形图
- 相关性 → 散点图 。

2. **性能优化**：

- 大数据量时启用`dataZoom`缩放 。
- 使用`dataset`管理数据，避免重复解析 。
- 动态更新时尽量局部刷新（非全量`setOption`） 。

3. **交互增强**：

- 添加`tooltip.fo rmatter`自定义提示内容 。
- 事件监听：`myChart.on('click', callback)`实现点击联动 。

4. **响应式设计**：

- 监听窗口变化：`window.ad dEventListener('resize', myChart.re size)` 。
