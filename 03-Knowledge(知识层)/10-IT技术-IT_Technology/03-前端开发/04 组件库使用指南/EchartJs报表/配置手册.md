# 📘 ECharts 配置项详细注释版

```
const option = {
  // ================== 全局配置 ==================
  backgroundColor: '#fff', 
  // 图表背景色
  // 默认：'transparent'（透明）
  // 可选：任意 CSS 颜色值（#RRGGBB, rgb(), rgba()）
  // 常用于：统一看板主题（如深色背景 #2c343c）

  color: ['#5470C6', '#91CC75', '#EE6666', '#FAC858'], 
  // 全局调色盘（series 不指定 color 时会循环使用）
  // 用法：在柱状图、折线图等多个系列时自动分配颜色
  // 建议：与设计系统/品牌色保持一致

  // ================== 标题 ==================
  title: {
    text: '销售数据分析',        // 主标题
    subtext: '数据来源：ERP系统', // 副标题（小字体）
    left: 'center',              // 水平位置
    // 可选值：'left' | 'center' | 'right' | 数字(px) | 百分比('20%')
    top: 10,                     // 垂直位置
    textStyle: {
      fontSize: 20,              // 标题字号
      fontWeight: 'bold',        // 可选：'normal' | 'bold' | 'bolder' | 'lighter'
      color: '#333'              // 标题颜色
    },
    subtextStyle: { //标题副文本（title.subtext） 的样式设置。
      fontSize: 12,
      color: '#666'
    }
  },

  // ================== 图例 ==================
  legend: {
    type: 'scroll',        // 图例类型
    // 'plain'：所有项目直接展示（少量数据）
    // 'scroll'：支持滚动（数据系列多时推荐）
    orient: 'horizontal',  // 排列方向
    // 可选值：'horizontal' | 'vertical'
    top: 40,               // 距离容器顶部位置
    data: ['销量', '库存'], // 图例项，需与 series.name 对应
    icon: 'circle'         // 图例图标
    // 可选：'circle' 圆点 | 'rect' 矩形 | 'roundRect' 圆角矩形
    //      'triangle' 三角形 | 'diamond' 菱形 | 'arrow' 箭头 | 'none'
  },

  // ================== 提示框 ==================
  tooltip: {
    trigger: 'axis',        
    // 'item'：鼠标移到某个数据点时显示（适合散点、饼图）
    // 'axis'：在整个轴上触发（适合折线、柱状，显示多序列对比）
    // 'none'：禁用提示框
    axisPointer: {
      type: 'shadow'        
      // 'line'：竖直/水平线
      // 'shadow'：阴影背景（常见于柱状图）
      // 'cross'：十字交叉（常见于折线+散点图）
    },
    formatter: params => {
      // params：当 trigger='axis' 时是数组，当 trigger='item' 时是对象
      return params.map(p => `${p.marker}${p.seriesName}: ${p.value}`).join('<br/>');
    }
  },

  // ================== 工具栏 ==================
  toolbox: {
    show: true,
    right: 20,  // 工具栏位置（右上角偏移量）
    feature: {
      saveAsImage: {},               // 保存为图片（默认 PNG）
      restore: {},                   // 还原（恢复默认配置）
      dataView: { readOnly: false }, // 数据视图（支持修改数据）
      magicType: {                   
        type: ['line', 'bar', 'stack']
        // 可选类型：
        // 'line'：折线图
        // 'bar'：柱状图
        // 'stack'：堆叠模式
        // 'tiled'：平铺模式
      }
    }
  },

  // ================== 网格布局 ==================
  grid: {
    top: 100,
    left: '8%',
    right: '8%',
    bottom: 60,
    containLabel: true 
    // 是否包含坐标轴标签
    // true：自动留白避免文字溢出（推荐）
  },

  // ================== 数据缩放 ==================
  dataZoom: [
    {
      type: 'slider',  // 可见滑块
      start: 0,        // 初始显示的范围（0% ~ 100%）
      end: 50          // 显示前半段数据
    },
    {
      type: 'inside'   // 鼠标滚轮缩放、拖拽平移
    }
  ],

  // ================== 视觉映射 ==================
  visualMap: {
    type: 'piecewise', 
    // 'continuous'：连续映射（渐变色）
    // 'piecewise'：分段映射（区间着色）
    show: false,       
    pieces: [          // 分段配置
      { gt: 0, lte: 100, color: '#91CC75' },
      { gt: 100, lte: 200, color: '#FAC858' },
      { gt: 200, color: '#EE6666' }
    ],
    seriesIndex: 0     // 应用到第 0 个系列
  },

  // ================== 坐标轴 ==================
  xAxis: {
    type: 'category',    
    // 'category'：类目轴（适合离散数据，如产品类别）
    // 'value'：数值轴（连续数据，如金额、数量）
    // 'time'：时间轴（自动格式化日期）
    // 'log'：对数轴（数据跨度大时使用）
    data: ['手机', '电脑', '平板', '耳机', '手表'],
    axisLine: { lineStyle: { color: '#999' } },
    axisTick: { alignWithLabel: true } 
    // 刻度是否对齐到标签
  },
  yAxis: {
    type: 'value',        
    name: '数量',          
    splitLine: { lineStyle: { type: 'dashed' } } 
    // 分隔线类型：solid | dashed | dotted
  },

  // ================== 数据系列 ==================
  series: [
    {
      name: '销量',          
      type: 'bar',           
      barWidth: '40%',       
      data: [120, 200, 150, 80, 70],
      label: { 
        show: true, 
        position: 'top' 
        // 'top' 顶部
        // 'inside' 柱子内部
        // 'bottom' 底部
        // 'left'/'right' 左右
      }
    },
    {
      name: '库存',
      type: 'line',
      smooth: true,           
      // 平滑曲线，true 时自动插值为贝塞尔曲线
      symbol: 'circle',       
      // 数据点标记形状，常用值同 legend.icon
      symbolSize: 8,          
      // 标记大小
      data: [60, 150, 100, 120, 110]
    }
  ]
};
```

# 📑 配置项可选值与效果说明表（扩展版）

|   |   |   |
|---|---|---|
|配置项|可选值|效果/说明|
|`title.left/top`|`'left'`<br><br>`'center'`<br><br>`'right'`<br><br>数字 px 百分比|标题位置|
|`legend.type`|`'plain'`<br><br>`'scroll'`|普通图例/支持滚动的图例|
|`legend.orient`|`'horizontal'`<br><br>`'vertical'`|水平/垂直排列|
|`tooltip.trigger`|`'item'`<br><br>`'axis'`<br><br>`'none'`|单点触发/轴触发/关闭|
|`tooltip.axisPointer`|`'line'`<br><br>`'shadow'`<br><br>`'cross'`|坐标轴指示器样式|
|`grid.containLabel`|`true`<br><br>/ `false`|是否避免坐标轴标签溢出|
|`dataZoom.type`|`'slider'`<br><br>`'inside'`<br><br>`'both'`|滑块缩放/鼠标缩放/组合|
|`visualMap.type`|`'continuous'`<br><br>`'piecewise'`|连续映射/分段映射|
|`xAxis/yAxis.type`|`'category'`<br><br>`'value'`<br><br>`'time'`<br><br>`'log'`|坐标轴类型（类目/数值/时间/对数）|
|`series.type`|`'bar'`<br><br>`'line'`<br><br>`'pie'`<br><br>`'scatter'`<br><br>`'radar'`<br><br>`'gauge'`<br><br>`'map'`<br><br>等|决定图表类型|
|`series.label.position`|`'top'`<br><br>`'inside'`<br><br>`'bottom'`<br><br>`'left'`<br><br>`'right'`<br><br>等|数据标签位置|
|`line.smooth`|`true`<br><br>/ `false`|折线是否平滑|
|`bar.stack`|相同字符串|同组柱子堆叠|
|`symbol`|`'circle'`<br><br>`'rect'`<br><br>`'triangle'`<br><br>`'diamond'`<br><br>`'pin'`<br><br>`'arrow'`<br><br>等|折线/散点数据点形状|

# 📊 ECharts 图表类型对照表

|   |   |   |   |   |
|---|---|---|---|---|
|图表类型|`series.type`|核心配置项|常用可选值 / 说明|推荐场景|
|**柱状图**（Bar）|`'bar'`|`barWidth`<br><br>（柱宽）、`stack`<br><br>（堆叠）、`label.position`|`barWidth: '40%'`<br><br>控制柱宽；`stack: '总量'`<br><br>堆叠展示；`label.position: 'top' / 'inside'`<br><br>标签显示位置|分类对比（销量、库存）、区间统计|
|**折线图**（Line）|`'line'`|`smooth`<br><br>（平滑）、`symbol`<br><br>（点形状）、`areaStyle`<br><br>（填充区域）|`smooth: true`<br><br>平滑曲线；`symbol: 'circle'/'rect'/'triangle'`<br><br>；`areaStyle: {}`<br><br>区域面积图|趋势分析（销量变化、温度曲线、财务指标）|
|**饼图**（Pie）|`'pie'`|`radius`<br><br>（半径）、`roseType`<br><br>（玫瑰图）、`label.formatter`|`radius: ['40%', '70%']`<br><br>环形；`roseType: 'radius'/'area'`<br><br>南丁格尔玫瑰图；`label.formatter`<br><br>自定义文本|占比展示（市场份额、比例关系）|
|**散点图**（Scatter）|`'scatter'`|`symbolSize`<br><br>（点大小）、`encode`<br><br>（维度映射）|`symbolSize: (val) => val[2]`<br><br>按数值映射大小；`encode: { x: 0, y: 1 }`|二维/三维数据分布（考试成绩、房价 vs 面积）|
|**雷达图**（Radar）|`'radar'`|`indicator`<br><br>（维度定义）、`shape`<br><br>（形状）|`indicator: [{name: '销售', max: 100}, ...]`<br><br>；`shape: 'circle' / 'polygon'`|多指标对比（绩效考核、能力评估、产品对比）|
|**仪表盘**（Gauge）|`'gauge'`|`min/max`<br><br>、`axisLine`<br><br>（仪表盘样式）、`pointer`<br><br>（指针）|`min: 0, max: 100`<br><br>；`axisLine.lineStyle.color`<br><br>区间配色；`pointer: { width: 4 }`|KPI 展示（完成率、进度百分比、温度/速度）|
|**地图**（Map）|`'map'`|`map`<br><br>（地图类型）、`roam`<br><br>（缩放/平移）、`visualMap`|`map: 'china' / 'world' / 自定义`<br><br>；`roam: true`<br><br>允许缩放；结合 `visualMap`<br><br>颜色分层|地域分布（人口、销售、疫情地图）|
|**热力图**（Heatmap）|`'heatmap'`|`coordinateSystem`<br><br>（坐标系）、`visualMap`<br><br>（颜色映射）|`coordinateSystem: 'geo'`<br><br>结合地图；`visualMap: { min, max }`<br><br>渐变色区分|密度分布（访问热点、温度热力、地理热力）|
|**树图**（Tree）|`'tree'`|`orient`<br><br>（方向）、`expandAndCollapse`<br><br>（展开折叠）|`orient: 'LR' / 'TB'`<br><br>左右 / 上下布局；`expandAndCollapse: true`|层级关系（组织架构、目录结构）|
|**桑基图**（Sankey）|`'sankey'`|`nodeWidth`<br><br>、`nodeGap`<br><br>、`layoutIterations`|`nodeWidth: 20`<br><br>节点宽度；`nodeGap: 8`<br><br>节点间距；`layoutIterations: 32`<br><br>调整布局|流程/能量/资金流向（资金流、转化路径）|
|**关系图**（Graph）|`'graph'`|`layout`<br><br>（布局）、`roam`<br><br>（缩放）、`force`<br><br>（力导向参数）|`layout: 'force'/'circular'`<br><br>；`force.repulsion`<br><br>控制点排斥；`roam: true`|网络关系（社交关系、依赖关系）|
|**矩形树图**（Treemap）|`'treemap'`|`leafDepth`<br><br>（下钻）、`label.formatter`|`leafDepth: 2`<br><br>控制可下钻层级；`label.formatter`<br><br>显示百分比|占比 & 层级结构（文件大小、业务分类）|
|**旭日图**（Sunburst）|`'sunburst'`|`radius`<br><br>、`highlightPolicy`|`radius: [0, '90%']`<br><br>；`highlightPolicy: 'ancestor'`|层级占比（业务占比、组织结构）|
|**盒须图**（Boxplot）|`'boxplot'`|`boxWidth`<br><br>、`itemStyle`|`boxWidth: [10, 40]`<br><br>；`itemStyle: { color: '...' }`|数据分布统计（最大值、中位数、四分位）|

# 📑 小结

- **对比型** → 柱状图、条形图、折线图
- **占比型** → 饼图、环形图、旭日图、矩形树图
- **趋势型** → 折线图、面积图
- **分布型** → 散点图、热力图、箱线图
- **层级/关系型** → 树图、桑基图、关系图
- **指标展示型** → 仪表盘
