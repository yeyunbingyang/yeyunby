# 对象类型（上）函数

## Function

### 定义函数

**格式1：**

```js
function 函数名(参数) {
    // 函数体
    return 结果;
}
```js

例

```js
function add(a, b) {
    return a + b;
}
```js

**格式2：**

第二种可以通过 var 去定义函数的名字，具体格式如下：

```js
var functionName = function (参数1, 参数2..){
    //要执行的代码
}
```js

### 调用函数

```js
函数名(实参);
```js

例

```js
add(1, 2);     // 返回 3
```js

js 中的函数调用特点：对参数的**类型**和**个数**都没有限制，例如

```js
add('a', 'b');  // 返回 ab
add(4, 5, 6);   // 返回 9, 第三个参数没有被用到, 不会报错
add(1);         // 返回 NaN, 这时 b 没有定义是 undefined, undefined 做数学运算结果就是 NaN
```js

### 默认参数

java 中（spring）要实现默认参数的效果得这么做：

```java
@RestController
public class MyController {
    @RequestMapping("/page")
    @ResponseBody
    public void page(
        @RequestParam(defaultValue="1") int page,
        @RequestParam(defaultValue="10") int size
    ){
        // ...
    }
}
```

js

```js
function pagination(page = 1, size = 10) {
    console.log(page, size);
}
```js

### 匿名函数

**语法：建议加 () 将匿名函数看做表达式**

```js
(function (参数) {
    // 函数体
    return 结果;
})
```js

例

```js
(function(a,b){
    return a + b;
})
```js

**第一种场景：定义完毕后立刻调用，只调用一次**

```js
(function(a,b){
    return a + b;
})(1,2)
```js

**第二种场景：作为其它对象的方法**

例如页面有元素

```html
<p id="p1">点我啊</p>
```

此元素有一个 onclick 方法，会在鼠标单击这个元素后被执行，onclick 方法刚开始是 null，需要赋值后才能使用

```js
document.getElementById("p1").onclick = (function(){
    console.log("鼠标单击了...");
});
```js

### 箭头函数

```js
(参数) => {
    // 函数体
    return 结果;
}
```js

- 如果没有参数，() 还是要保留
- 如果只有一个参数，() 可以省略
- 如果函数体内只有一行代码，{} 可以省略
- 如果这一行代码就是结果，return 可以省略

例

```js
document.getElementById("p1").onclick = () => console.log("aa");
```js

和 Java 中的函数有很大区别，js 函数可以参与赋值运算。

### js 函数是对象

以下形式在 js 中非常常见！

**1. 可以参与赋值，例，具名函数也能参与赋值**

```js
function abc() {
    console.log("bb");
}

document.getElementById("p1").onclick = abc;
```js

**2. 有属性、有方法，执行 `console.dir(abc)`，输出结果如下

```
ƒ abc()
    arguments: null
    caller: null
    length: 0
    name: "abc"
    ➡prototype: {constructor: ƒ}
    [[FunctionLocation]]: VM1962:1
    ➡[[Prototype]]: ƒ ()
    ➡[[Scopes]]: Scopes[1]
```

- 其中带有 f 标记的是方法，不带的是属性
- 带有 ➡ 符号的可以继续展开，限于篇幅省略了
- 带有 `[[ ]]` 的是内置属性，不能访问，只能查看
- 相对重要的是 `[[Prototype]]` 和 `[[Scopes]]` 会在后面继承和作用域时讲到

**3. 可以作为方法参数**

```js
function a() {
    console.log('a')
}

function b(fn) {          // fn 将来可以是一个函数对象
    console.log('b')
    fn();                 // 调用函数对象
}

b(a)
```js

**4. 可以作为方法返回值**

```js
function c() {
    console.log("c");

    function d() {
        console.log("d");
    }
    return d;  //返回函数对象
}

c()()  // c()返回函数对象, ()调用函数对象
```js

### 函数作用域

函数可以嵌套（js 代码中很常见，只是嵌套的形式更多是匿名函数，箭头函数）

```js
function a() {
    function b() {
    }
}
```js

看下面的例子

```js
function c() {
    var z = 30;
}

var x = 10;
function a() {
    var y = 20;
    function b() {
        // 看这里
        console.log(x, y);
    }
    b();
}
a();
```js

- **以函数为分界线划定作用域**，所有函数之外是全局作用域【每个函数都创建了一个新的作用域】
- 查找变量时，由内向外查找
- 在内层作用域找到变量，就会停止查找，不会再找外层
- 所有作用域都找不到变量，报错
- 作用域本质上是函数对象的属性，可以通过 console.dir 来查看调试

### 闭包 ⭐

函数定义就有了定义域，无论什么地方都能够访问自己的作用域中变量

**一个函数可以"记住"并访问它定义时的词法作用域中的变量，即使这个函数在其作用域之外被调用**。

换句话说：函数出生时就带着自己的"作用域包"，到哪都能访问当时的变量。

**特性：**

1. **函数定义时，作用域就确定了**。
2. 闭包可以"保存"并**访问其外部函数作用域中的变量**。
3. 闭包会连带其**词法环境**一起被创建并保留在内存中。

- 闭包 = 函数 + 定义时作用域的引用
- 闭包让函数"携带着记忆"执行

```js
var x = 10;
function a() {
    var y = 20;
    function b() {
        console.log(x,y);
    }
    return b;
}
a()();  // 在外面执行了 b
```js

- 函数定义时，它的作用域已经确定好了，因此**无论函数将来去了哪，都能从它的作用域中找到当时那些变量**

以下是一个简单的闭包示例：

```js
function outerFunction() {
    var message = 'Hello, World!';

    return function() {
        console.log(message);
    };
}

var innerFunc = outerFunction();
innerFunc(); // 输出 'Hello, World!'
```js

在这个例子中

- `outerFunction` 定义了一个局部变量 `message` 和一个匿名函数。
- 这个匿名函数是 `outerFunction` 的返回值，它可以访问 `message`。
- `outerFunction` 调用后返回这个匿名函数，并将其赋值给 `innerFunc`。
- 当我们调用 `innerFunc` 时，它仍然能够访问并打印 `message`，因为它保持了对 `outerFunction` 作用域的引用。

**闭包的主要用途有两个，一个是函数外部可以读取函数内部的变量，另一个就是让这些变量的值始终保持在内存中。**

### let、var 与作用域

如果函数外层引用的是 let 变量，那么外层普通的 {} 也会作为作用域边界，最外层的 let 也占一个 script 作用域

```js
let x = 10;
if(true) {
    let y = 20;
    function b() {
        console.log(x,y);
    }
    console.dir(b);
}
```js

如果函数外层引用的是 var 变量，外层普通的 {} 不会视为边界

```js
var x = 10;
if(true) {
    var y = 20;
    function b() {
        console.log(x,y);
    }
    console.dir(b);
}
```js

如果 var 变量出现了重名，则他俩会被视为同一作用域中的同一个变量：warning:

```js
var e = 10;
if(true) {
    var e = 20;
    console.log(e);  // 打印 20
}
console.log(e);      // 因为是同一个变量，还是打印 20
```js

如果是 let，则视为两个作用域中的两个变量，与 Java 语法类似，**推荐使用**

```js
let e = 10;
if(true) {
    let e = 20;
    console.log(e);  // 打印 20
}
console.log(e);      // 打印 10
```js

要想里面的 e 和外面的 e 能区分开来，最简单的办法是改成 let，或者用函数来界定作用域范围

```js
var e = 10;
if(true) {
    function b() {
        var e = 20;
        console.log(e);
    }
    b();
}
console.log(e);
```js
