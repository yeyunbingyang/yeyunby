## 02-rem

### 简介

- rem单位，是相对单位
- rem单位是相对于HTML标签的字号计算结果
- 1rem = 1HTML字号大小

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1747496894485-54c07454-5240-4972-8159-aabfb85a2d89.png)

### 媒体查询

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1747497174665-d9821fd0-bc3a-4143-8036-3612689b2002.png)

媒体查询能够检测视口的宽度，然后编写差异化的 CSS 样式

当某个条件成立, 执行对应的CSS样式

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1747490939100-52f69eb7-037f-4036-84e7-9c07c756334f.png "null")

```css

  html {
    background-color: green;
  }
```

flexible.js 是手淘开发出的一个用来适配移动端的 js 库。

核心原理就是根据不同的视口宽度给网页中 html 根节点设置不同的 font-size。


## 03-less

Less是一个CSS预处理器, Less文件后缀是.less。扩充了 CSS 语言, 使 CSS 具备一定的逻辑性、计算能力

注意：浏览器不识别 Less 代码，目前阶段，网页要引入对应的 CSS 文件

VS Code 插件：Easy LESS，保存 less文件后自动生成对应的 CSS 文件

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1747490939218-bac2ff2d-7345-4deb-9854-16062810fbb5.png "null")

### 注释

- 单行注释

- 语法：// 注释内容
- 快捷键：ctrl + /

- 块注释

- 语法：/* 注释内容 */
- 快捷键： Shift + Alt + A

### 运算

- 加、减、乘直接书写计算表达式
- 除法需要添加 小括号 或 .
- 表达式存在多个单位以第一个单位为准

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1747490939278-95cdba73-7d99-456c-9e68-07be0afc09a2.png "null")

### 嵌套

作用：快速生成后代选择器

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1747490939332-9fc54e3a-3e5c-4a98-9de8-77c8aafd9e37.png "null")

提示：用 & 表示当前选择器，不会生成后代选择器，通常配合伪类或伪元素使用

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1747490939391-5a6ce059-cc68-4f0d-ad70-a75f7d5fccf8.png "null")

### 变量

概念：容器，存储数据

作用：存储数据，方便使用和修改

语法：

- 定义变量：@变量名: 数据;
- 使用变量：CSS属性：@变量名;

```less
// 定义变量
@myColor: pink;
// 使用变量
.box {
  color: @myColor;
}
a {
  color: @myColor;
}
```

### 导入

作用：导入 less 公共样式文件

语法：导入: @import “文件路径”;

提示：如果是 less 文件可以省略后缀

```less
@import './base.less';
@import './common';
```

### 导出

写法：在 less 文件的第一行添加 // out: 存储URL

提示：文件夹名称后面添加 /

```less
// out: ./index.css
// out: ./css/
```

## 05-vw适配方案

### vw和vh基本使用

vw和vh是相对单位，相对视口尺寸计算结果

- vw：viewport width（1vw = 1/100视口宽度 ）
- vh：viewport height ( 1vh = 1/100视口高度 )

### vw布局⭐

vw单位的尺寸 = px 单位数值 / ( 1/100 视口宽度 )

### vh问题

**思考：开发中，能不能vw和vh混用呢？**

只用一个 其他自适应

不能混用

vh是1/100视口高度，全面屏视口高度尺寸大，如果混用可能会导致盒子变形
