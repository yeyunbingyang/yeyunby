# CC Switch 模型管理器

> Claude Code 的"变速箱"——不改 CC 一行代码，随时切换底层模型。

## 一句话结论

CC Switch 通过劫持 Claude Code 的 API 请求，将模型名映射到任意厂商的任意模型，实现**高/中/低三档自适应切换**。安装后在 CC 内执行 `/model` 即可在 opus/sonnet/haiku 三档之间自由切换。

## 核心原理

```
Claude Code 发出请求（model: claude-sonnet-4-20250514）
        │
        ▼
   CC Switch 拦截层
        │
        ├─ 查映射表（高/中/低各配了什么模型）
        ├─ 替换 model 字段
        ├─ 替换 API Base URL + API Key
        │
        ▼
   实际厂商 API（OpenAI / DeepSeek / 通义千问 / ...）
```

## 安装与配置

### 安装

```bash
# npm 全局安装
npm install -g @anthropic-ai/claude-switch

# 或从 GitHub 克隆
git clone https://github.com/jawerty/claude-switch.git
cd claude-switch && npm install && npm link
```

### 配置映射（`~/.claude-switch/config.json`）

```json
{
  "profiles": {
    "default": {
      "high": {
        "provider": "openai",
        "model": "gpt-5",
        "apiKey": "$OPENAI_API_KEY"
      },
      "medium": {
        "provider": "deepseek",
        "model": "deepseek-v4-pro",
        "apiKey": "$DEEPSEEK_API_KEY"
      },
      "low": {
        "provider": "openai",
        "model": "Gemini 2.5 Flash / Grok 4 Mini",
        "apiKey": "$OPENAI_API_KEY"
      }
    }
  }
}
```

### 启动 CC

```bash
# 先启动 Switch 代理，再启动 CC
claude-switch start
claude
```

CC 启动后，用 `/model` 即可在高/中/低三档间切换。

## 三档模型推荐搭配

| 档位 | 适用任务 | 推荐模型 | 月成本估算 |
|------|---------|---------|-----------|
| **高** (opus) | 复杂架构设计、多文件重构、深度分析 | GPT-5 / Claude Opus 4 | $50-100 |
| **中** (sonnet) | 日常编码、代码审查、文档生成 | DeepSeek V4 Pro / Qwen-Max / Claude Sonnet 4 | $5-25 |
| **低** (haiku) | 简单问答、格式修正、文件检索 | DeepSeek V4 Flash / Qwen 3.7 Plus / Gemini 2.5 Flash / Grok 4 Mini | 免费 ~ $1-10.05 |

## 支持的厂商

通过配置不同的 `provider` 和 `baseURL`，可接入：

- **海外**：OpenAI、Anthropic、Google Gemini、Together AI、Groq
- **国产**：DeepSeek、通义千问（Qwen）、智谱 GLM、Moonshot、百川
- **代理/中转**：OpenRouter、APIHub、自定义代理

## 常见问题

**Q: CC Switch 和 9router 有什么区别？**
- CC Switch：模型**替换**——把 Claude 的请求完整映射到另一个模型
- 9router：模型**路由**——根据 Token 消耗自动在不同模型间 fallback，附带 RTK 节省

**Q: 为什么 CC 报 "Authentication required"？**
先启动 `claude-switch start` 再启动 CC，顺序反了 CC 会去连 Anthropic 官方。

**Q: 国产模型需要额外配置吗？**
只需在 config.json 里填对 baseURL（如 `https://api.deepseek.com`）和 API Key 即可，Switch 会透明转发。
