# 模型路由策略

> 不是所有问题都值得烧 Opus。学会分层路由，同样的任务成本砍掉一半。

## 一句话结论

将任务按复杂度分三档，高复杂度用旗舰模型保证质量，日常任务用 DeepSeek V4 Pro，简单操作用 Flash 或免费方案。搭配 9router 的自动 fallback，可节省 30-50% 总 Token 成本。

## 三档路由模型

```
任务复杂度评估
   │
   ├─ 高（~10% 请求）
   │   特征：多文件重构、架构设计、复杂 Debug、长链推理
   │   模型：GPT-5 / Claude Opus 4 / Grok 4
   │   成本：高，但量少
   │
   ├─ 中（~60% 请求）
   │   特征：日常编码、代码审查、文档生成、简单分析
   │   模型：DeepSeek V4 Pro / Claude Sonnet 4 / Qwen 3.7 Plus
   │   成本：中等，量大但性价比高
   │
   └─ 低（~30% 请求）
       特征：格式修正、文件检索、简单问答、模板填充
       模型：DeepSeek V4 Flash / Grok 4 Mini / Gemini 2.5 Flash（免费）
       成本：极低或免费
```

## CC Switch 三档配置示例

```json
{
  "profiles": {
    "coding": {
      "high": {
        "provider": "openai",
        "model": "gpt-5",
        "apiKey": "$OPENAI_API_KEY"
      },
      "medium": {
        "provider": "deepseek",
        "model": "deepseek-v4-pro",
        "apiKey": "$DEEPSEEK_API_KEY"
      },
      "low": {
        "provider": "deepseek",
        "model": "deepseek-v4-flash",
        "apiKey": "$DEEPSEEK_API_KEY"
      }
    }
  }
}
```

## 9router 自动路由配置

```yaml
routes:
  - name: smart-fallback
    primary:
      model: deepseek-v4-pro       # $0.435/$0.87
    fallback:
      - model: deepseek-v4-flash    # $0.14/$0.28
      - model: gemini-2.5-flash     # 免费
    trigger:
      token_limit: 8000
      cost_threshold: 0.02
```

## 决策矩阵

| 任务类型 | 档位 | 推荐模型 | 为什么 | 数据可靠度 |
|---------|------|---------|--------|-----------|
| 从零搭建项目架构 | 高 | GPT-5 / Claude Opus 4 | 顶级推理和代码理解 | ⚠️ |
| 跨 5+ 文件重构 | 高 | Claude Opus 4 / Grok 4 | 多文件上下文 + 推理 | ⚠️/✅ |
| 复杂 Bug 排查 | 高 | Grok 4 | 长推理链，1M 上下文 | ✅ |
| 实现新功能模块 | 中 | DeepSeek V4 Pro | 编码强，成本极低 | ✅ |
| Code Review | 中 | Claude Sonnet 4 | 代码审查专长 | ⚠️ |
| 写单元测试 | 中 | DeepSeek V4 Pro | 模式化任务 | ✅ |
| 生成文档/注释 | 低 | Qwen 3.6 Flash | 中文文档质量好 | ⚠️(定价) |
| 文件批量格式化 | 低 | DeepSeek V4 Flash | 机械任务，$0.14/M | ✅ |
| 简单问答 | 低 | Gemini 2.5 Flash | 完全免费 | ✅ |
| 配置文件修改 | 低 | Grok 4 Mini | $0.025/M，极低 | ✅ |

## 降级策略（Fallback）

```
请求 GPT-5
   ├─ 成功 → 输出
   └─ 失败/超时
        └─ 请求 DeepSeek V4 Pro
             ├─ 成功 → 输出（标注降级）
             └─ 失败
                  └─ 请求 DeepSeek V4 Flash
                       └─ 成功 → 输出（标注二次降级）
```

## 成本优化实操

假设月均 10M token（Agent 典型用量），三档策略效果：

| 策略 | 高档 | 中档 | 低档 | 月成本 | 节省 |
|------|------|------|------|--------|------|
| 全高档（Opus 4） | 100% | 0% | 0% | ~$150 | 基准 |
| 混合（无策略） | 30% | 50% | 20% | ~$80 | 47% |
| **三档路由** | 10% | 50% | 40% | **~$35** | **77%** |

> 核心逻辑：用免费 Gemini 2.5 Flash 和 $0.14/M 的 DeepSeek V4 Flash 吃掉 40% 的简单请求，高档模型只用在真正需要深度推理的 10%。
