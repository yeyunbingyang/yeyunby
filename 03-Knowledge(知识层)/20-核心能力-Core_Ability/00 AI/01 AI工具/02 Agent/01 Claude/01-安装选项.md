 # 三种方式的区别
 
 Claude Code can be used with your Claude subscription or billed based on API usage through your Console account.

 Select login method:
 > 1. Claude account with subscription · Pro, Max, Team, or Enterprise
   2. Anthropic Console account · API usage billing
   3. 3rd-party platform · Amazon Bedrock, Microsoft Foundry, or Vertex AI

你现在看到的是 Claude Code 首次运行的登录方式选择界面：



| 选项                 | 适用人群               | 计费方式                                    |
| ------------------ | ------------------ | --------------------------------------- |
| **1. Claude 订阅账号** | 已有 Pro/Max/Team 订阅 | 按月付费，不限 API 额度（有速率限制）                   |
| **2. Console 账号**  | 开发者，按量使用           | 按 API 调用量计费，需在 console.anthropic.com 充值 |
| **3. 第三方平台**       | 企业用户               | 通过 AWS Bedrock / Azure / GCP 走已有账单      |

---

## 简单建议

- **个人日常用 → 选 1**。如果你买了 Claude Pro（$20/月）或 Max（$100/月），用它登录最省心，没有额外费用
- **开发项目、低频用 → 选 2**。按 token 付费，用多少花多少，先去 console.anthropic.com 创建 API Key
- **公司已用云平台 → 选 3**。如果公司已在 AWS/Azure/GCP 上有合作，走统一账单

---

你是哪种情况？用键盘上下键选好后按回车就行。



你现在到 OAuth 授权这一步了，操作很简单：

---

## 操作步骤 【需要谷歌账号】

1. **复制链接** — 按 `c` 键复制那个 `https://platform.claude.com/oauth/authorize?...` 链接

2. **浏览器打开** — 把链接粘贴到浏览器地址栏，回车

3. **登录授权** — 在打开的页面里登录你的 Anthropic 账号（或用 Google 登录），然后点击 **Allow/授权**

4. **获取验证码** — 授权后会显示一串验证码（code），复制它

5. **粘贴回来** — 回到 Claude Code 终端窗口，把验证码粘贴到 `Paste code here if prompted >` 后面，回车

---

完成后 Claude Code 就激活了，可以直接用 `claude` 命令开始对话。

> 💡 链接已经自动存到剪贴板了（按了 `c` 的话），直接去浏览器 Ctrl+V 粘贴即可。
