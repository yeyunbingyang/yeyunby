# 职业能力

在职场中高效推进工作、管理自身发展的实践能力体系，核心是"做正确的事、正确地做事、持续做下去"。

## 学习路径

`时间管理基础` → `任务与项目管理` → `职业路径规划` → `效率工具体系`

## 核心知识点

### 时间管理
- **GTD（Getting Things Done）**：收集→清晰化→组织→回顾→执行五步法
- **四象限法则**：重要紧急 / 重要不紧急（核心投入区）/ 不重要紧急 / 不重要不紧急
- **时间块（Time Blocking）**：将任务固定到日历时间段，减少决策消耗
- **每日3重点**：每天开始前确定最重要的3件事，其余事情等待

### 项目管理
- **敏捷 Scrum**：Sprint 迭代、每日站会、Sprint Review/Retrospective
- **看板（Kanban）**：可视化工作流，限制在制品（WIP Limit），暴露瓶颈
- **OKR**：目标（O）+ 关键结果（KR），区分产出（Output）与成果（Outcome）
- **里程碑规划**：大目标拆解为可验证的阶段检查点
- **风险管理**：识别→评估（概率×影响）→应对→监控

### 职业路径规划
- **技能T型模型**：广度通识 + 1-2个深度专长
- **个人护城河**：稀缺性×需求量×替代难度
- **职业资本理论**：先积累稀缺技能，再用资本换自主权和使命感
- **晋升逻辑**：解决上级不会解决的问题；让上级省心

### 效率工具
- **笔记系统**：Obsidian（长期知识库）+ 快速 Inbox
- **任务管理**：Todoist / Things / 本知识库 [[Project_Dashboard]]
- **文档协作**：Notion / Confluence / 飞书文档
- **代码效率**：Cursor / GitHub Copilot + 正确的 Prompt 习惯
