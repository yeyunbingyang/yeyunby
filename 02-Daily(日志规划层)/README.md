# 日志规划层

每日记录、阶段规划、周复盘的时间维度容器。与 03-Knowledge（领域维度）互补，构成"时间 × 领域"的知识矩阵。

## 目录结构

```
02-Daily/
├── README.md              # ← 你在这里
├── 日记/                  # 每日笔记（按 YYYY-MM-DD 命名）
├── 周复盘/                # 每周回顾（按 YYYY-Wxx 命名）
└── 阶段规划/              # 学习阶段/项目阶段的计划与总结
```

## 三种笔记类型

| 类型 | 存放位置 | 频率 | 说明 |
|------|----------|------|------|
| **每日笔记** | `日记/` | 每天 | 当日输入输出、灵感、待整理内容 |
| **周复盘** | `周复盘/` | 每周 | 一周回顾、Inbox 清空检查、下周计划 |
| **阶段规划** | `阶段规划/` | 按需 | 学习阶段/项目阶段的目标、里程碑与进度追踪 |

## 与 Inbox 的关系

```
当天碎片 → 01-Inbox（临时收集）
     ↓
每日笔记 ← 整理当天 Inbox，记录学到什么
     ↓
有价值内容 → 03-Knowledge（知识加工）
     ↓
周复盘 ← 检查 Inbox 清空、MOC 更新、知识迁移
```

## 使用规则

- 每日笔记不追求完整，重点记录"今天学到了什么"
- 每日笔记末尾的"待整理"条目，是次日 Inbox 清理的输入
- 阶段规划在开始一个学习模块或项目前创建，结束时写总结
- 周复盘是固定的检查点，与 [[Clearance_Rules\|清空规则]] 联动
