# Overview

本 Wiki 旨在系统性地整理和探索 IT 技术领域的核心知识与实践。当前覆盖四大主题领域：**云原生运维**、**AI工程**、**后端开发** 和 **前端开发**。

**云原生运维** 领域涵盖容器化技术、Kubernetes、DevOps 与 SRE 实践等，以 `云原生运维.xmind` 思维导图为结构化知识载体。该领域还包含 Linux 系统管理的基础操作，如 CentOS Stream 的 yum/dnf 软件源配置、国内镜像站的使用、dnf 包管理工具的核心命令，以及系统时间同步管理。时间同步方面，CentOS Stream 9 默认使用 chrony 替代传统的 ntpd，通过配置国内 NTP 服务器（如阿里云）可提高同步可靠性，相关操作包括安装 chrony、配置 `/etc/chrony.conf`、使用 `chronyc` 验证同步状态，以及通过 `timedatectl` 设置时区。这些基础运维知识为上层容器化和编排实践提供了底层支撑。

**AI工程** 领域聚焦于将大语言模型集成到生产系统的工程实践，核心目标是"让模型稳定可靠地解决实际问题"。该领域以 `AI工程-MOC.md` 知识地图为骨架，建立了从 API 调用基础到模型部署的递进式学习路径，覆盖以下子领域：Prompt工程、RAG架构、Agent框架、模型调用与API、微调与部署。

**后端开发** 领域覆盖服务端软件工程的核心知识，从编程语言基础到分布式系统设计。该领域以 `后端开发-MOC.md` 知识地图为骨架，建立了递进式学习路径：`语言基础 → 框架与API设计 → 数据库与缓存 → 消息队列 → 系统设计与高并发`。核心概念包括 RESTful API 设计规范、缓存故障模式（穿透/击穿/雪崩）、分布式事务（Saga/TCC/2PC）、消息队列（Kafka/RabbitMQ）、以及系统稳定性保障机制（限流/熔断）。

**前端开发** 领域覆盖浏览器端用户界面工程，从 HTML/CSS/JS 三件套到现代框架工程化体系。该领域以 `前端开发-MOC.md` 知识地图为骨架，建立了递进式学习路径：`HTML/CSS 基础 → JavaScript 核心 → 框架（Vue/React） → 工程化工具链 → 性能优化`。核心概念包括 DOM 操作、事件循环、虚拟 DOM、响应式编程、代码分割、Core Web Vitals 性能指标，以及 Vue 3 和 React 两大主流框架的对比。

四大领域存在紧密的交叉关系：后端开发为 AI 工程和前端开发提供底层基础设施支撑——RAG 架构依赖数据库和缓存，Agent 框架需要消息队列进行异步通信，前端通过 HTTP API 与后端通信。云原生运维则为所有服务的部署和运维提供容器化和编排能力，而 Linux 系统管理（如软件源配置、时间同步）是运维工作的基础。未来可探索 AIOps 方向，将 AI 工程与云原生运维深度融合，以及前端与 AI 工程在 LLM 交互界面上的交叉应用。

当前 Wiki 已建立四大领域的核心概念框架，并补充了 Linux 系统管理的基础知识（包括软件源配置、包管理、时间同步）。后续工作包括：深入各子领域的具体技术细节、追踪工具和框架的演进、以及探索领域间的融合实践。
