# ADR 0006：流入清空工作流

## 状态

已接受（2026-08-02 确认）。

## 决策

新内容一律先进入 `01-日常流(日常流层)/00 流入/`，收集时不纠结分类；按清空规则定期判断去向（知识层、资源层、日常流其他子目录、系统层），目标每日清空、每周兜底。

## 背景

直接写目标目录需要先完成分类决策，在碎片时间容易被放弃；统一收集箱保证内容不丢失，清空动作集中决策，符合"收集 → 判断 → 加工 → 导航 → 复盘"的总流程。

## 权衡

- 备选：直接写目标目录。省一步移动，但碎片时刻需要分类决策，容易中断收集。
- 备选：多个分类收集箱。收集时就要选择，增加选择成本。
- 代价：需要清空纪律，否则流入积压；路径变更需要同步 AGENTS、操作工作流等文档。

## 后果

清空频率与触发条件由 `00-System(支撑层)/Rules/Clearance_Rules.md` 定义；项目仪表盘聚合未完成事项。流入路径以实际目录 `00 流入/` 为准，文档描述统一到该名称。
