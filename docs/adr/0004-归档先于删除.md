# ADR 0004：归档先于删除

## 状态

已接受（2026-08-02 确认）。

## 决策

过时或被替代的笔记改为 `status: 归档`，保留在原位置（或移入 `03-Resources(资源层)/` 的归档区），可选在原位置保留重定向注释；不删除正文。归档笔记不出现在常规导航与 Dataview 活跃查询中，但继续允许搜索与追溯。

## 背景

知识库内容有复盘与追溯价值，删除会丢失决策上下文。早期归档独立目录需要移动文件，造成 wikilink 断裂与相对路径失效。

## 权衡

- 备选：直接删除。仓库更整洁，但历史上下文不可恢复。
- 备选：归档独立目录。结构清晰，但移动成本高、链接易断。
- 代价：仓库会保留历史正文，需要清空规则控制规模，避免归档内容冒充现行规范。

## 后果

归档笔记文首注明被哪篇新文档替代并建立链接；被替代的规则不再充当现行规范。归档不占用 MOC 与 README 主导航。
