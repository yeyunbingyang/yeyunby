https://github.com/VoltAgent/awesome-design-md

## 是什么

Awesome DESIGN.md 收集了 **73 个知名品牌的设计系统文件**，基于 Google Stitch 的 [DESIGN.md 格式](https://stitch.withgoogle.com/docs/design-md/overview/)。每个文件从对应网站提取了真实的设计 Token——配色、字体、间距、阴影、组件样式。

**用法极其简单**：复制一个 DESIGN.md 到项目根目录，告诉 AI Agent「按这个设计风格来」，Agent 就能生成像素级匹配的 UI。

## 核心概念：AGENTS.md vs DESIGN.md

| 文件 | 谁来读 | 定义什么 |
|------|--------|----------|
| `AGENTS.md` | 编程 Agent | 怎么构建项目 |
| `DESIGN.md` | 设计 Agent | 项目应该长什么样 |

## 快速开始

1. 在 [getdesign.md](https://getdesign.md) 选择一个品牌
2. 复制 `DESIGN.md` 到项目根目录
3. 告诉 AI Agent：「build me a page that looks like this」

## 每个 DESIGN.md 包含

| 节 | 内容 |
|----|------|
| 视觉主题与氛围 | 设计哲学、密度、情绪 |
| 配色方案 | 语义化色名 + 十六进制值 + 功能角色 |
| 字体规则 | 字体族 + 完整层级表 |
| 组件样式 | 按钮/卡片/输入框/导航含状态 |
| 布局原则 | 间距刻度、网格、留白哲学 |
| 深度与阴影 | 阴影系统、表面层级 |
| 设计护栏 | 该做和不该做 |
| 响应式行为 | 断点、触摸目标、折叠策略 |
| Agent 提示指南 | 快速颜色参考、即用型 Prompt |

每个品牌还附带 `preview.html` + `preview-dark.html` 可视化目录。

## 适用场景

- 快速给 AI Agent 项目一个专业的设计风格（选一个品牌 DESIGN.md 即可）
- 学习顶级品牌的设计系统——配色/字体/间距的完整决策链
- 与 UI UX Pro Max 互补：UIUXPM 提供设计推理规则，Awesome DESIGN.md 提供真实品牌设计 Token
- 团队统一 UI 风格——选一个 DESIGN.md 作为团队标准

## 评价

- **优点**：Google Stitch 官方格式标准化、73 个品牌覆盖广、每个文件含 preview.html 可视化、用法极简（复制即用）、84.3k Stars 社区热烈、MIT 开源
- **局限**：只是静态 Token 提取（非完整设计系统）、品牌风格可能不匹配所有项目类型、依赖 Agent 对 DESIGN.md 的理解能力
- **是否值得长期保留**：✅ 关注——与 UI UX Pro Max 形成「推理规则+品牌 Token」的完整 AI 设计方案
