## 是什么

一个 `CLAUDE.md` 文件，提炼了 Karpathy 对 LLM 编程三大坑点的解法：

| 原则 | 解决的问题 |
|------|-----------|
| **Think Before Coding** | 错误假设、隐藏困惑、不展示权衡 |
| **Simplicity First** | 过度复杂、臃肿抽象 |
| **Surgical Changes** | 正交修改、误伤无关代码 |
| **Goal-Driven Execution** | 测试先行、可验证成功标准 |
