# 目录迁移检查清单

## 迁移前

- [ ] 已读取仓库规则与顶级 MOC。
- [ ] 已记录 Git 工作区状态。
- [ ] 已生成文件清单、重复哈希和疑似版本清单。
- [ ] 已记录图片、视频等二进制资产的数量、字节数、SHA-256集合及清单摘要。
- [ ] 已列出范围外的修改、未跟踪文件和子模块状态作为保护清单。
- [ ] 已完成关键问题的自问自答，并将确认结论写入文档或ADR。
- [ ] 已输出目标目录树。
- [ ] 已建立旧路径到新路径映射。
- [ ] 已声明 Markdown、JSON 和脚本路径分别相对哪个根目录解析。
- [ ] 已标记删除、覆盖和不可逆操作。

## 迁移中

- [ ] 每次只迁移一个主题或项目。
- [ ] 先合并有效内容，再处理旧版本。
- [ ] 同步修复 Wikilink、附件和脚本中的路径。
- [ ] 实体媒体、JSON和文档已同时迁移，没有只创建空目录或README。
- [ ] 失败记录包含症状、根因、解决方案、复验结果和版本链。
- [ ] 同步更新子 MOC、上级 MOC 和顶级知识地图。
- [ ] 未修改任务范围外的用户变更。

## 迁移后

- [ ] Frontmatter 合规。
- [ ] Wikilink 和附件引用无断链。
- [ ] Dataview 查询路径正确。
- [ ] 没有重复哈希、空目录和残留旧路径。
- [ ] 权威文档唯一。
- [ ] 文件数量和迁移映射能够对账。
- [ ] 分类数量、总字节数和二进制哈希集合能够对账。
- [ ] JSON全部可解析，外部URL已与本地文件引用分开验证。
- [ ] 相对引用按当前文件或项目根的既定语义解析，没有验证器误报。
- [ ] `git diff --check` 通过。
- [ ] 已说明 Obsidian 界面级验证是否执行。
- [ ] 只暂存目标范围，并关闭Git中文路径转义后复核提交清单。
- [ ] 提交与按需合并完成后已再次检查HEAD、祖先关系、引用、哈希和保护清单。
- [ ] 迁移期间的失败、原因和解决方案已进入验证报告。
