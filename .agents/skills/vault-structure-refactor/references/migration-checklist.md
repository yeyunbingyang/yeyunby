# 目录迁移检查清单

## 迁移前

- [ ] 已读取仓库规则与顶级 MOC。
- [ ] 已记录 Git 工作区状态。
- [ ] 已生成文件清单、重复哈希和疑似版本清单。
- [ ] 已输出目标目录树。
- [ ] 已建立旧路径到新路径映射。
- [ ] 已标记删除、覆盖和不可逆操作。

## 迁移中

- [ ] 每次只迁移一个主题或项目。
- [ ] 先合并有效内容，再处理旧版本。
- [ ] 同步修复 Wikilink、附件和脚本中的路径。
- [ ] 同步更新子 MOC、上级 MOC 和顶级知识地图。
- [ ] 未修改任务范围外的用户变更。

## 迁移后

- [ ] Frontmatter 合规。
- [ ] Wikilink 和附件引用无断链。
- [ ] Dataview 查询路径正确。
- [ ] 没有重复哈希、空目录和残留旧路径。
- [ ] 权威文档唯一。
- [ ] 文件数量和迁移映射能够对账。
- [ ] `git diff --check` 通过。
- [ ] 已说明 Obsidian 界面级验证是否执行。
