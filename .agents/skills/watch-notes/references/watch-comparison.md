# watch 与 watch-notes 对比

| 能力 | watch | watch-notes |
|---|---|---|
| 下载或读取视频 | 负责 | 调用 watch |
| 字幕与 Whisper 转写 | 负责 | 强制以 Whisper 时间轴为主 |
| 场景抽帧、定点抽帧 | 负责 | 根据语义证据决定抽取时间 |
| 回答视频问题 | 适合 | 可包含，但目标是持久化笔记 |
| 判断“哪张图必须放进笔记” | 通用抽帧 | 核心职责 |
| 文稿与转写对齐 | 非核心 | 核心职责 |
| 笔记结构与去口语化 | 非核心 | 核心职责 |
| Obsidian/Markdown 附件落盘 | 非核心 | 核心职责 |
| 更新已有笔记 | 非核心 | 使用托管区块安全更新 |
| 联系表 | 可提供原始帧 | 仅用户明确要求时生成 |
| 完整性验证 | 媒体处理级 | 笔记、嵌图和附件级 |

`watch-notes` 是编排层，不应复制、分叉或修改 `watch`。当 `watch` 的参数或路径变化时，先重新读取它的 `SKILL.md`。
