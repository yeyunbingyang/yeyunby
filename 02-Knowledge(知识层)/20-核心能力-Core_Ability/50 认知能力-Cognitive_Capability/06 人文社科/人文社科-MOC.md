# 人文社科

宏观认知资源，提供理解人类社会运作的底层框架。学习人文社科的目标不是记住史实，而是**提取可迁移的规律与视角**。

## 学习路径

`逻辑学基础（思维工具）` → `哲学核心问题` → `历史规律提取` → `社会学视角` → `跨域应用`

## 核心视角

### 历史规律
- **历史周期律**：王朝/组织/技术的兴衰螺旋（不完全重复但押韵）
- **技术决定论 vs 社会建构论**：技术如何改变权力结构
- **路径依赖**：历史选择如何锁定当前可能性（QWERTY键盘效应）
- **一手史料 vs 二手解读**：区分"发生了什么"与"如何解读"

### 哲学基础
- **认识论**：我们如何知道我们知道的是真的？（理性主义 vs 经验主义）
- **伦理学**：功利主义（最大多数人最大利益）vs 义务论（规则优先）
- **存在主义**：自由与责任，意义不是发现而是创造
- **逻辑学**：有效论证 vs 可靠论证，常见谬误（诉诸权威/稻草人/滑坡）

### 社会学视角
- **社会资本**：网络中的信任与互惠如何创造经济价值
- **制度经济学**：规则/惯例/文化如何塑造个体行为
- **群体动力学**：从众、角色压力、群体极化
- **阶层与流动**：社会结构如何影响个体机会

### 经济学常识
- **激励机制**：人们按激励行动，而非按意图
- **边际分析**：决策基于边际成本/收益，而非总量
- **信息不对称**：谁拥有更多信息，谁占主动
- **博弈论基础**：囚徒困境、纳什均衡、协调博弈
