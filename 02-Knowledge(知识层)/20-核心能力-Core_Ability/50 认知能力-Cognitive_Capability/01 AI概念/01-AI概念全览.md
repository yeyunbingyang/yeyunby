# AI 概念全览

> 一份文件覆盖所有 AI 高频概念。忘了哪个词直接搜。上半部分表格速查，下半部分概念详解。

---

## 一、基础概念 — AI / ML / DL

| English | 中文 | 一句话 | 大白话 |
|---------|---------|--------|--------|
| **AI** | **人工智能**                       | 让机器模拟人类智能    | 让电脑像人一样思考和做事          |
| **ML** | **机器学习**                       | 不写规则，从数据中学习  | 给电脑一万张猫图，它自己学会认猫      |
| **DL** | **深度学习**                       | 多层神经网络处理复杂模式 | ML 的升级版——网络更深，能做更复杂的事 |
| **Supervised Learning** | **监督学习**    | 用带标签的数据学     | 每道题都有标准答案，对着答案学       |
| **Unsupervised Learning** | **无监督学习** | 给无标签数据自己找规律  | 不给答案自己分堆——"这堆圆的，那堆方的" |
| **Reinforcement Learning** | **强化学习** | 通过奖励和惩罚试错    | 训狗——做对了给零食，做错了不理      |

**三者的关系**：`AI ⊃ ML ⊃ DL`（深度学习是机器学习的一种，机器学习是人工智能的一种）

## 二、大语言模型（LLM）— 怎么工作

| English | 中文 | 一句话 | 大白话 |
|---------|---------|--------|--------|
| **LLM**                | **大语言模型** | 用海量文本训练的超大神经网络       | 读了几十亿篇文章后学会"说话"的 AI                    |
| **Token**              | **令牌/词元** | LLM 处理文本的最小单位        | 文字的"积木块"——一个汉字~1 token，一个英文词~1.3 token |
| **Context Window**     | **上下文窗口** | 模型一次能"看到"的最大 token 数 | 模型的"短期记忆容量"——超过就忘了开头                   |
| **Temperature**        | **温度参数**  | 控制输出随机性，0=确定 2=发散    | 0=照本宣科，1=正常发挥，2=放飞自我                   |
| **Embedding**          | **向量嵌入**  | 把文字映射为数学向量           | 给每个词一个 GPS 坐标——"猫"和"狗"离得近，和"汽车"离得远     |
| **Transformer**        | **变换器**   | 现代 LLM 的基础架构         | 注意力机制——读句子时知道哪些词最重要                    |
| **Hallucination**      | **幻觉**    | 模型自信地编造不存在的事实        | "鲁迅说 1+1=3"——说得很肯定，全是编的                |
| **Training/Inference** | **训练/推理** | 训练=让模型学数据，推理=生成输出    | 训练=喂书（做一次管很久），推理=回答问题（每次都在算）           |

## 三、Prompt 工程 — 怎么和 LLM 说话

| English | 中文 | 一句话 | 大白话 |
|---------|---------|--------|--------|
| **Prompt** | **提示词**           | 发给模型的输入文本       | "你问它的那句话"                      |
| **System Prompt** | **系统提示词**    | 设定角色和行为的顶层指令    | 给演员的剧本——"你是医生，语气专业温和"          |
| **Few-shot** | **少样本提示**         | 给几个例子让模型照做      | "翻译：hello->你好，world->世界，cat->" |
| **CoT** | **思维链**         | 让模型"一步步思考"再回答   | 中间多推几步，推理正确率暴增                 |
| **Function Calling** | **函数调用** | 让模型输出结构化的函数调用请求 | 模型不说答案，说"调这个函数，参数填这些"          |

## 四、Agent — 是什么

| English | 中文 | 一句话 | 大白话 |
|---------|---------|--------|--------|
| **Agent**       | **智能体**    | LLM + 规划 + 工具 + 记忆 = 自主 AI 系统              | 有脑子（LLM）、会动手（工具）、能记事（记忆）的 AI          |
| **ReAct**       | **推理行动循环** | 思考->行动->观察 循环                              | 边想边做，做一步看一步                           |
| **Multi-Agent** | **多智能体**   | 多个 Agent 分工协作                              | 公司团队——各司其职，消息互通                       |
| **Agent CLI**   | **终端智能体**  | 终端中的 AI 编程助手——读代码、改文件、跑命令全在命令行完成           | 直接在终端里干活的 AI 程序员——你说需求，它敲命令、写代码、改 Bug |
| **Skill**       | **技能**     | 给 Agent 配备的可复用能力单元——一个函数 + 一份 Markdown 说明书 | 给 AI 装"技能包"——就像给手机装 App，装一个会一项新本事     |

> Agent 本质 = while 循环调 LLM + 函数调用 + 存历史。核心原理不超过三句话。

## 五、知识增强 — 让 LLM 外挂大脑

| English | 中文 | 一句话 | 大白话 | 代码本质 |
| ------------------- | ----------- | ------------------- | ----------------------- | ------------ |
| **RAG**             | **检索增强生成**  | 先搜索相关资料再回答          | 问之前先翻书——把相关内容贴在问题前面再问   | 搜索 + 拼字符串    |
| **Vector Database** | **向量数据库**   | 存 Embedding 支持相似度搜索 | 按"意思相近"搜而不是"关键词匹配"      | 倒排索引升级版      |
| **MCP**             | **模型上下文协议** | AI 与工具之间的标准通信协议     | USB-C 接口——统一了 AI 调工具的方式 | REST API 标准化 |
| **Chunk**           | **文档分块**    | 文档切分后的片段            | 一本书拆成一页一页               | 分页           |
| **Rerank**          | **重排序**     | 对搜索结果二次精排           | 搜出 10 个->精选最相关的 3 个     | 二次排序         |

## 七、AIGC 生成式 AI

### 7.1 五大模态

| 模态 | 一句话 | 代表工具 |
|------|--------|---------|
| **文生文** Text-to-Text | 给 Prompt，出文章/翻译/代码 | ChatGPT, Claude, DeepSeek |
| **文生图** Text-to-Image | "一只戴墨镜的柴犬冲浪" -> AI 画出来 | Midjourney, DALL-E 3, Stable Diffusion |
| **文生视频** Text-to-Video | "跑车在雨夜街道漂移" -> AI 出片 | Sora, Runway, Kling（可灵） |
| **文生音乐** Text-to-Music | "周杰伦风格中国风 R&B" -> AI 谱曲 | Suno, Udio |
| **文生代码** Text-to-Code | "写个 Python 备份脚本" -> AI 出代码 | Copilot, Cursor, Claude Code |

### 7.2 文生图详解

**核心原理**：**扩散模型（Diffusion Model）**——先给图加噪点到纯噪点，再训练模型学会"去噪"，从噪点中一步步还原画面。

**大白话**：想象一块磨砂玻璃——Diffusion 就是"擦掉雾"的过程，每一步看清一点，最后完全清晰。

```
Prompt: "一只戴墨镜的柴犬在冲浪"
    ->
CLIP 编码器 -> 把文字转成"画面理解向量"
    ->
Diffusion 模型 -> 从纯噪点图一步步"去噪"
    ->
VAE 解码器 -> 还原为高清图片
    ->
🖼️ 输出
```

#### 三大工具对比

| | Midjourney | DALL-E 3 | Stable Diffusion |
|------|-----------|---------|-----------------|
| **上手难度** | ⭐ 最简单（Discord） | ⭐ 最简单（ChatGPT 内） | ⭐⭐⭐ 需配置 |
| **审美质量** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐（看模型） |
| **可控性** | 低 | 中 | 极高（ControlNet） |
| **本地部署** | ❌ | ❌ | ✅ 开源 |
| **成本** | $10-60/月 | 按量 | 免费（需 NVIDIA 显卡） |

#### ControlNet — 精细控制

不止用文字描述画面，还能用**线稿、姿态、深度图**控制构图："保持这个姿势，换赛博朋克风"。

### 7.3 文生视频

将 Diffusion 从"空间去噪"扩展到"时空去噪"——同时处理画面维度和时间维度，保证**每一帧好看 + 帧之间连贯**。当前主流 5-30 秒。

| 工具               | 特点 |
| ---------------- | -------------------------- |
| **Runway Gen-3** | 综合最强，图生视频+文生视频 |
| **Kling（可灵）**    | 快手出品，可用 |
| **Pika**         | 轻量，Lip Sync（让照片里的人说话）是杀手功能 |

### 7.4 文生音乐

将音频表示为频谱图 -> 用 Diffusion/Transformer 生成 -> 声码器还原波形。

| 工具 | 特点 |
|------|------|
| **Suno** | 最强文生音乐，免费额度够玩 |
| **Udio** | 音质更高但上手较难 |

> 注意：文生语音（TTS）和文生音乐不同——前者是"读文字"，后者是"作曲+演唱"：

| 工具 | 定位 | 特点 |
|------|------|------|
| **ElevenLabs** | 最逼真 TTS，克隆声音只需 1 分钟样本 |
| **GPT-SoVITS** | 开源中文语音克隆最强方案之一 |

### 7.5 文生代码

| | 代码补全（Copilot） | 代码 Agent（Claude Code/Devin） |
|----|-------------------|-------------------------------|
| 交互方式 | 你写，它补 | 你说，它全干 |
| 能力 | 当前函数/文件 | 跨文件、调终端、debug、部署 |
| 适合 | 日常编码加速 | 完整功能开发 |

### 7.6 AIGC 底层技术路线

| English | 中文 | 一句话 | 擅长 | 代表 |
|---------|---------|--------|------|---------|
| **Diffusion** | **扩散模型** | 学会去噪——从噪点中还原内容 | 图像、视频、音频 | SD, Sora, Suno |
| **Transformer** | **变换器** | 注意力机制——理解序列元素关系 | 文本、代码 | GPT, Claude |
| **GAN** | **生成对抗网络** | 两个网络对抗博弈 | 图像生成（早期） | StyleGAN |
| **CLIP** | **图文对比预训练** | 图文共用向量空间 | 图文匹配 | SD, DALL-E |

## 八、名词陷阱 — 这些概念的本质

> AI 圈盛产新名词包装旧技术。拆掉滤镜，核心原理都不超过三句话。

| English | 中文 | 一句话拆穿 | 实际价值 |
|---------|---------|--------|--------|
| **Skill** | **技能**       | 函数 + Markdown 说明书     | 让 LLM 知道什么时候调哪个函数 |
| **MCP** | **模型上下文协议**         | 标准化的 REST API 协议      | 统一了碎片化的工具调用标准 |
| **RAG** | **检索增强生成**         | 搜索 + 拼 Prompt         | 解决了幻觉和知识截止日期 |
| **Agent** | **智能体**       | while 循环 + LLM + 函数调用 | 把 LLM 从聊天变成工作流 |
| **Chain** | **调用链**       | A 的输出 = B 的输入（管道符换皮）  | 管道化 LLM 调用 |
| **Memory** | **记忆**      | 数组存历史 + 向量检索          | 跨会话保持上下文 |
| **Planning** | **规划**    | 让 LLM 列步骤             | 结构化任务分解 |
| **Multi-Agent** | **多智能体** | 多个 while 循环互相发消息      | 微服务架构 LLM 化 |

### 识别套路三法则

1. **能用三句话说清 -> 核心原理就这三句，剩下是工程**
2. **去掉英文缩写看中文 -> 大部分瞬间破功**
3. **问"这以前用什么方案" -> 如果是成熟技术 -> 就是换皮**
