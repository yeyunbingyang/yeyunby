# 认知科学与心理学

研究人类思维、记忆、决策和行为的规律，目标是理解大脑的"操作系统"，从而规避缺陷、发挥优势。

## 学习路径

`认知偏差识别` → `双系统理论` → `元认知与自我监控` → `注意力与心流` → `行为改变策略`

## 核心框架

### 双系统理论（卡尼曼）
| | 系统 1 | 系统 2 |
|--|--------|--------|
| 特点 | 快速、自动、直觉 | 慢速、有意识、分析 |
| 能耗 | 低 | 高 |
| 错误类型 | 偏差、捷径 | 懒惰不激活 |
| 代表 | 开车、情绪反应 | 数学计算、复杂决策 |

### 高频认知偏差

| 偏差名称 | 表现 | 对策 |
|----------|------|------|
| 确认偏误 | 只寻找支持自己观点的证据 | 主动寻找反例 |
| 锚定效应 | 过度依赖第一个信息 | 多设锚点，独立估算 |
| 可得性启发 | 越容易想起的越高估概率 | 查基准率数据 |
| 邓克效应 | 能力越低越高估自己 | 主动寻求外部反馈 |
| 沉没成本谬误 | 因已投入而继续不合理决策 | 问"如果今天重新选择" |
| 现时偏误 | 过度重视当下而轻视未来 | 预提交/承诺机制 |
| 光晕效应 | 一个特质影响对整体的评价 | 分离维度独立评估 |

### 元认知
- **定义**：对自己思维过程的认知与调控
- **组成**：元认知知识（我知道什么）/ 元认知监控（我理解了吗）/ 元认知调控（调整策略）
- **提升方法**：费曼技巧、教别人、反思日记

### 注意力管理
- 注意力是有限资源，每次切换都有认知切换成本
- **深度工作**：排除干扰的心流状态，是高价值知识产出的前提
- **注意力恢复理论**：自然环境能有效恢复定向注意力
- **实践**：时间块（Time Blocking）、单任务专注、减少通知
