# Obsidian 核心概念与界面

## 一句话结论

> Obsidian 的本质是一个**本地 Markdown 文件管理器**，通过双向链接 `[[wikilink]]` 将孤立笔记织成知识网络。所有数据以 `.md` 文件存储在本地，你拥有完全控制权。

## 核心概念

### 1. Vault（知识库）

Vault 就是硬盘上的一个**文件夹**。打开 Obsidian 时选择一个文件夹，该文件夹即成为当前 Vault。所有笔记、附件、配置都存储在这个文件夹内。

- 可以创建多个 Vault（如：工作知识库、个人知识库）
- 不同 Vault 之间完全隔离，插件和设置各自独立
- 当前知识库的 Vault 根目录即本仓库根目录

### 2. Note（笔记）

每篇笔记就是一个 **`.md` 文件**，使用标准 Markdown 语法 + Obsidian 扩展语法。

- 纯文本文件，任何编辑器都能打开
- 文件名即笔记标题，支持中文命名
- 文件在文件夹中的位置就是笔记在 Vault 中的位置

### 3. Wikilink（双向链接）

`[[笔记名]]` 是 Obsidian 最核心的语法。链接是**双向的**——A 链接了 B，B 的反向链接面板会自动显示 A。

- 内部链接：`[[笔记名]]` 或 `[[笔记名|显示文本]]`
- 链接到标题：`[[笔记名#标题]]`
- 链接到段落：`[[笔记名#^block-id]]`
- 自动补全：输入 `[[` 会弹出笔记列表

> 当前配置：`alwaysUpdateLinks: true`，重命名笔记时自动更新所有引用链接。

### 4. Graph View（图谱）

将笔记之间的链接关系可视化为**网络图**。每个节点是一篇笔记，每条边是一个链接。

- 本地图谱：查看当前笔记的直接关联
- 全局图谱：查看整个 Vault 的链接结构
- 按文件夹/标签/搜索词过滤

### 5. Frontmatter（元数据）

每篇笔记顶部的 YAML 块，用 `---` 包裹，存储结构化属性。

```yaml
---
title: 笔记标题
domain: IT_Technology
tags: [Obsidian, 插件]
status: 稳定
summary: "一句话核心结论"
---
```

- 属性面板（`Ctrl+Shift+P` → 属性）可图形化编辑
- Dataview 插件可查询 frontmatter 字段
- 本库的 Frontmatter 规范见 [[SCHEMA]]

### 6. Command Palette（命令面板）

`Ctrl+P` 打开命令面板，是**所有操作的统一入口**。不需要记住菜单位置，直接搜命令名即可。

- 搜索命令：输入关键词过滤
- 显示快捷键：命令右侧会显示已绑定的快捷键
- 插件命令：安装的插件会在此注册新命令

## 界面布局

```
┌──────────────────┬──────────────────┬──────────────────┐
│   左侧边栏        │    编辑区         │   右侧边栏        │
│                  │                  │                  │
│  📁 文件浏览器    │  当前打开的笔记    │  🔗 反向链接      │
│  🔍 搜索         │  支持多标签页      │  📋 大纲          │
│  🔖 书签         │  支持分屏          │  # 标签面板       │
│                  │  （水平/垂直）     │  📝 属性          │
│                  │                  │                  │
└──────────────────┴──────────────────┴──────────────────┘
                        状态栏：字数统计、当前模式
```

- **左侧边栏**：文件浏览器、搜索、书签
- **右侧边栏**：反向链接、大纲、标签面板、属性
- **编辑区**：多标签页，支持水平/垂直分屏
- **状态栏**：底部显示字数、编辑模式

### 核心操作面板

| 面板 | 快捷键 | 用途 |
|------|--------|------|
| 命令面板 | `Ctrl+P` | 所有操作的入口 |
| 快速切换器 | `Ctrl+O` | 快速打开任意笔记 |
| 设置 | `Ctrl+,` | 打开设置面板 |

## 快捷键速查

### 笔记操作

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+N` | 新建笔记 |
| `Ctrl+O` | 快速打开笔记 |
| `Ctrl+W` | 关闭当前标签页 |
| `Ctrl+Shift+T` | 恢复关闭的标签页 |

### 编辑操作

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+B` | 加粗 |
| `Ctrl+I` | 斜体 |
| `Ctrl+E` | 切换编辑/阅读视图 |
| `Ctrl+K` | 插入外部链接 |
| `>` + 空格 | 块引用 |
| `-` + 空格 | 无序列表 |

### 搜索操作

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+F` | 当前笔记内搜索 |
| `Ctrl+Shift+F` | 全局搜索 |
| `Ctrl+H` | 查找并替换 |

### 链接与导航

| 操作 | 方式 |
|------|------|
| 插入内部链接 | 输入 `[[` 自动弹出补全 |
| 前进/后退 | `Ctrl+Alt+←` / `Ctrl+Alt+→` |
| 打开链接笔记 | `Ctrl+点击` 链接 |

### 自定义快捷键

| 快捷键 | 作用 | 说明 |
|--------|------|------|
| `Alt+B` | 插入 callout | 当前唯一自定义快捷键 |

> 所有快捷键可在 设置 → 快捷键 中自定义。建议每天刻意练习 2-3 个新快捷键。

## 适用场景

- ✅ 个人知识管理（本库的用途）
- ✅ 项目文档与笔记
- ✅ 学习笔记与读书笔记
- ✅ 写作与长文创作
- ❌ 实时多人协作编辑
- ❌ 非 Markdown 格式文档管理

## 关联思考

- 与 Notion 对比：Obsidian 本地优先、离线可用、数据自有；Notion 云端协作强、数据库功能丰富
- 与 Logseq 对比：同为本地 Markdown + 双向链接，Logseq 是大纲式，Obsidian 是文档式
- 与 Roam Research 对比：Roam 是云端服务，Obsidian 是本地应用
