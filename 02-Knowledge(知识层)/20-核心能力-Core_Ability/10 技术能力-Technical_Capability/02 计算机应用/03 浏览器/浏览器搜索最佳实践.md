# 浏览器搜索最佳实践

> 会用搜索引擎，和用好搜索引擎，差距比想象中大。

## 搜索语法速查

### 精确匹配

| 语法 | 示例 | 效果 |
|------|------|------|
| `"关键词"` | `"Hermes Agent v0.16"` | 精确匹配完整短语 |
| `"A B" ~"C"` | `"AI agent" ~"framework"` | 精确短语 A B，但排除含 C 的结果 |

### 限定范围

| 语法 | 示例 | 效果 |
|------|------|------|
| `site:` | `site:github.com Hermes Agent` | 只搜指定站点 |
| `site:.edu` | `site:.edu transformer attention` | 只搜教育域名 |
| `inurl:` | `inurl:kanban hermes` | URL 中包含指定词 |
| `intitle:` | `intitle:"Hermes Agent" setup` | 标题中包含指定词 |
| `intext:` | `intext:"memory" "skill"` | 正文中包含指定词 |
| `filetype:` | `filetype:pdf "Agent框架"` | 限定文件类型 |

### 逻辑与排除

| 语法 | 示例 | 效果 |
|------|------|------|
| `AND` 或空格 | `docker kubernetes` | 同时包含（默认逻辑） |
| `OR` 或 `\|` | `Python OR JavaScript` | 包含任一即可 |
| `-` | `AI -"machine learning"` | 排除指定词 |
| `+` | `+Hermes Agent` | 强制包含（忽略同义词替换） |

### 高级组合

| 语法 | 示例 | 效果 |
|------|------|------|
| `(A B)` | `(docker kubernetes) deployment` | 分组逻辑 |
| `A * B` | `"docker * kubernetes"` | 通配符，匹配中间任意词 |
| `$` | `laptop $500..$800` | 价格范围搜索 |
| `after:` | `after:2025-01-01` | 限定时间之后 |
| `before:` | `before:2025-06-01` | 限定时间之前 |
| `daterange:` | `daterange:2025-01..2025-06` | 日期范围 |

## 实战场景

### 场景一：排查技术报错

```
"Error: connection refused" site:stackoverflow.com -"localhost" after:2024-01-01
```

→ 从 Stack Overflow 找连接被拒的解决方案，排除 localhost 相关，只看近两年的。

### 场景二：学习新技术

```
"LangChain tutorial" filetype:pdf site:.edu "beginner"
```

→ 找大学出品的 LangChain 入门 PDF 教程。

### 场景三：调研竞品/方案对比

```
(intitle:comparison OR intitle:"vs") (LangChain OR "LlamaIndex") RAG
```

→ 找标题含 comparison 或 vs 的文章，对比 LangChain 和 LlamaIndex 在 RAG 上的表现。

### 场景四：找开源项目

```
site:github.com "AI Agent" stars:>1000 language:python
```

→ 在 GitHub 找 AI Agent 相关、1000+ Stars 的 Python 项目。

### 场景五：排除干扰结果

```
"vector database" -Pinecone -weaviate -"Redis" site:medium.com
```

→ 在 Medium 上找关于向量数据库的文章，排除三家主流厂商的推广内容，看深度分析。

## 搜索引擎选型

| 引擎 | 优势 | 劣势 | 适用场景 |
|------|------|------|---------|
| **Google** | 索引最全，语法支持最好 | 国内访问不稳定 | 技术搜索、英文内容 |
| **Bing** | 国内可用，语法兼容性好 | 索引略少于 Google | Google 不可用时的替代 |
| **DuckDuckGo** | 隐私好，`!` bang 语法直达任意站 | 中文支持一般 | 快速跳转（`!w python` 直达维基百科） |
| **GitHub** | 代码搜索最精准 | 非代码内容不适用 | 项目/代码/issue 搜索 |
| **Perplexity** | AI 聚合+溯源，直接给答案 | 深度不如原生搜索引擎 | 快速调研、文献查找 |

## 搜索习惯建议

1. **先想清楚搜什么**：模糊的问题 → 拆成 2-3 个具体关键词组合
2. **从精确到宽泛**：先用精确短语搜不到 → 逐步去掉限定词
3. **善用 `site:` 限定高质量源**：`site:arxiv.org`、`site:github.com`、`site:stackoverflow.com`
4. **组合使用**：搜索语法之间可任意组合，效果叠加
5. **记笔记**：找到好的搜索结果后，记录搜索词和结果链接，下次复用
