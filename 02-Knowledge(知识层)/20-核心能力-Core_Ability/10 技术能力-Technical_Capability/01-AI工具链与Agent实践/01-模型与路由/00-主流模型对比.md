# 主流模型对比

> [!summary] 截至 2026-08-11 的结论
> 先选厂家，再选型号。OpenAI、Anthropic 仍占综合质量和复杂 Agent 的第一梯队；Google、xAI、Meta 各自在多模态、软件工程和人类偏好上形成差异；Moonshot、智谱、DeepSeek、阿里、MiniMax、小米把成本压到更低，并在编码或长任务上进入主流选型范围。榜单名次只能验证某种任务，不能代替自己的验收集。

> [!warning] 快照边界
> 本笔记核验于 2026-08-11。价格均指公开 API 的每百万 Token 标准价，缓存、长上下文、批处理、地区和活动价另算。模型名称后的 `high`、`xhigh`、`max` 属于不同推理配置，不能当作同一个成绩。完整读榜方法见 [[05-模型评测与榜单指南]]。

### 价格核验说明

- OpenAI 实际打开的模型页在 2026-08-11 显示 Terra 为 $2/$12、Luna 为 $0.20/$1.20；搜索缓存仍显示首发价 $2.50/$15、$1/$6。这里采用实时官方页面，并保留下次复核任务。
- Anthropic 官方模型总览显示 Fable 5 为 $10/$50、Opus 5 为 $5/$25、Sonnet 5 为 $3/$15、Haiku 4.5 为 $1/$5。Arena 部分页显示的 Fable 价格较低，不能覆盖厂商公开价。
- Qwen3.7-Max 的人民币价格有地区和限时折扣，表内保留列表价。Qwen3.8-Max-Preview 尚未找到稳定的公开价格页。
- MiniMax M3 的价格来自官方发布页定价图和公开镜像，正式账单前应重新打开控制台。Meta Muse Spark 1.1 仍处 API 公测，因此不写未经官方页面确认的价格。

## 榜单证据

### 综合能力

[Artificial Analysis Intelligence Index v4.1.1](https://artificialanalysis.ai/methodology/intelligence-benchmarking) 将 Agent、编码、科学推理和通用能力按 34%、24%、24%、18% 加权。2026-07-24 的公开结果中，Claude Opus 5 Max 为 61，Claude Fable 5 Max 为 60，GPT-5.6 Sol Max 为 59，Kimi K3 为 57。它是英文文本测试，并不能直接推出中文写作、多模态或产品体验结论。

[LiveBench 2026-06-25](https://livebench.ai/) 使用 23 个客观任务和 7 个类别。GPT-5.6 Sol Max 为 82.4，Claude Fable 5 Max 为 80.8，Claude Opus 5 xHigh 为 80.3，GPT-5.5 xHigh 为 79.9，GPT-5.6 Terra Max 为 79.8。这个版本中 Sol 的客观综合成绩领先，但 Fable 的语言、编码和人类偏好仍有独立优势。

### 软件工程与 Agent

[SWE-rebench](https://swe-rebench.com/) 使用持续更新的 GitHub 修复任务。2026 年 6 至 7 月窗口中，Fable 5 High 解决率 64.5%，Grok 4.5 High 63.8%，Opus 5 High 63.4%，GLM-5.2 High 62.9%，GPT-5.6 Sol Medium 62.3%。同榜还显示 Sonnet 5 为 56.8%，MiniMax M3 为 47.2%，MiMo-V2.5-Pro 为 46.5%。Harness、推理档和缓存会显著改变成本，不能只看解决率。

[Agent Arena](https://arena.ai/leaderboard/agent) 从真实会话中的完成确认、用户褒贬、可纠正性和 Bash 恢复等信号估计效果。公开快照中 Fable 5 High 居首，GPT-5.6 Sol xHigh 与 Kimi K3 位于前列；Kimi K3 的完成确认率较高。它不是统一任务集，结果反映平台流量和产品 Harness。

### 人类偏好与前端

[Arena 总览](https://arena.ai/leaderboard) 的近期快照显示：Text Arena 由 Claude Fable 5 领先，Muse Spark 1.1 和 Gemini 3.1 Pro 进入前十；WebDev Arena 由 Claude Opus 5 与 Kimi K3 领先，Fable 5、GPT-5.6 Sol、GLM-5.2、Grok 4.5 位于前列。新模型常带 Preliminary 标记，置信区间重叠时不要解读成确定名次。

## 本次会话调研结论

- 模型报告从厂家出发更稳定。厂商会用旗舰、均衡和高吞吐档形成产品梯队，单个型号的榜单位置变化更快。
- 没有一个榜单能代表“最好”。AA 和 LiveBench 更适合综合客观能力，Arena 适合偏好与产品体验，SWE-rebench 适合真实代码修复，Agent Arena 适合工具编排信号。
- 2026 年的头部模型差距已经细化到 Harness、推理档、缓存与工具配置。只写模型家族名会丢失关键实验条件。
- 国内厂家不再只靠价格进入选型。Kimi K3 的 WebDev 与 Agent、GLM-5.2 的软件工程、DeepSeek 和 MiMo 的成本，都有独立或可复核证据。
- 价格页比发布新闻更可靠。搜索缓存、路由平台和 Arena 展示价可能滞后，最终采购以厂家控制台和账单规则为准。
