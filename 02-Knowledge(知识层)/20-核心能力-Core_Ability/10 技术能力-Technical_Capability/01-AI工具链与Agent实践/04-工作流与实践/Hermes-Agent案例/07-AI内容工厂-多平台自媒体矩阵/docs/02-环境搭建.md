## 2. 安装 Hermes Agent

### 2.1 基础安装

```bash
# 使用 pip 安装
pip install hermes-agent

# 或使用 uv（推荐，更快）
uv pip install hermes-agent

# 验证安装
hermes --version
```

### 2.2 初始化配置

```bash
# 首次设置
hermes setup

# 配置 LLM Provider
hermes config set provider.openai.api_key "sk-xxx..."
hermes config set provider.anthropic.api_key "sk-ant-xxx..."

# 配置默认模型
hermes config set model.default "gpt-4o"
hermes config set model.topic-agent "claude-sonnet-4"
hermes config set model.copy-agent "gpt-4o"
hermes config set model.image-agent "gpt-4o"
hermes config set model.publish-agent "gpt-4o-mini"
hermes config set model.analytics-agent "gpt-4o-mini"
```

## 3. 创建内容工厂 Profile

### 3.1 批量创建 Profile

```bash
#!/bin/bash
# create-profiles.sh

PROFILES=(
  "topic-agent:claude-sonnet-4:你是一位资深新媒体选题策划专家，擅长从微博热搜、知乎热榜、百度指数中发现潜在爆款选题"
  "copy-agent:gpt-4o:你是一位多风格文案创作专家，精通公众号深度文、知乎专业回答、小红书种草笔记、头条快讯四种风格"
  "image-agent:gpt-4o:你是一位 AI 视觉设计师，擅长撰写 DALL-E 和 Midjourney 提示词，能根据文案主题生成高质量配图"
  "publish-agent:gpt-4o-mini:你是一位多平台内容运营专家，熟悉各平台排版规范、发布时间策略和互动管理"
  "analytics-agent:gpt-4o-mini:你是一位数据驱动的内容策略分析师，擅长从阅读数据中发现规律并提出优化建议"
)

for profile in "${PROFILES[@]}"; do
  IFS=':' read -r name model prompt <<< "$profile"
  hermes profile create "$name" --model "$model" --system-prompt "$prompt"
  echo "✅ Created profile: $name ($model)"
done
```

### 3.2 验证 Profile

```bash
# 列出所有 Profile
hermes profile list

# 切换到某个 Profile 测试
hermes profile use copy-agent
hermes chat "请用小红书风格写一篇关于 AI 工具的笔记"
```

## 4. 配置 Gateway（多端交互）

### 4.1 Telegram Gateway

```bash
# 配置 Telegram Bot
hermes config set gateway.telegram.token "123456:ABC-DEF..."
hermes config set gateway.telegram.enabled true

# 启动 Gateway
hermes gateway start --provider telegram
```

### 4.2 微信 Gateway

```bash
# 配置微信（需 Hermes Gateway 中间件）
hermes config set gateway.wechat.enabled true
hermes config set gateway.wechat.app_id "wx..."
hermes config set gateway.wechat.app_secret "..."

# 参考: hermes-gateway-wechat-qq skill
```

## 6. 配置 Cron 定时任务

### 6.1 每日流水线

```bash
# 每日 8:00 触发选题
hermes cron add --name daily-topic-pick \
  --schedule "0 8 * * *" \
  --profile topic-agent \
  --task "扫描今日热点，筛选 5 个最佳选题"

# 每日 9:00 开始创作
hermes cron add --name daily-content-creation \
  --schedule "0 9 * * *" \
  --profile copy-agent \
  --task "根据今日选题生成各平台文案"

# 每日 10:00 生成配图
hermes cron add --name daily-image-generation \
  --schedule "0 10 * * *" \
  --profile image-agent \
  --task "为今日文案生成配图"

# 每日 11:00 定时发布（错峰）
hermes cron add --name schedule-publish \
  --schedule "0 11,15,20 * * *" \
  --profile publish-agent \
  --task "按各平台最佳发布时间发布内容"

# 每日 23:00 数据回采
hermes cron add --name daily-analytics-collect \
  --schedule "0 23 * * *" \
  --profile analytics-agent \
  --task "回采今日发布数据，生成日报"
```

### 6.2 查看 Cron 状态

```bash
# 列出所有定时任务
hermes cron list

# 查看执行日志
hermes cron logs daily-content-creation
```

## 7. 配置 Kanban Swarm

```bash
# 创建 Kanban 看板
hermes kanban create content-factory-pipeline

# 添加泳道
hermes kanban add-lane --board content-factory-pipeline --name "选题"
hermes kanban add-lane --board content-factory-pipeline --name "创作"
hermes kanban add-lane --board content-factory-pipeline --name "配图"
hermes kanban add-lane --board content-factory-pipeline --name "发布"
hermes kanban add-lane --board content-factory-pipeline --name "分析"

# 启动 Swarm 模式
hermes kanban swarm --board content-factory-pipeline --parallel 3
```

## 9. 常见环境问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `hermes: command not found` | 未加入 PATH | `pip show hermes-agent` 找到路径后添加 |
| API Key 无效 | 配置错误 | `hermes config set provider.openai.api_key "新key"` |
| Profile 创建失败 | 名称冲突 | `hermes profile delete old-name` 后重试 |
| 插件安装失败 | 依赖缺失 | `pip install 插件依赖` 后重试 |
| Gateway 连接失败 | Token 无效 | 重新生成 Bot Token 并配置 |
