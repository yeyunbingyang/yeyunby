# 环境搭建

## 1. 前置检查清单

```bash
# 检查 Hermes Agent 是否安装
hermes --version

# 检查 Hermes 健康状态
hermes doctor

# 检查 Python 环境
python --version   # 需 >= 3.10

# 检查 Git
git --version
```

## 2. Hermes Agent 安装与配置

### 2.1 安装 Hermes Agent

```bash
# 一键安装（Linux / macOS / WSL）
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# Windows 用户建议通过 WSL 或 git-bash 运行
# 安装后确认
hermes --version
```

### 2.2 启用必要工具集

```bash
# 查看当前启用的工具集
hermes tools list

# 确保以下工具集已启用
hermes tools enable terminal    # 终端操作（文件扫描、Git）
hermes tools enable web         # 网页搜索（辅助标签推荐）
hermes tools enable memory      # 持久记忆
hermes tools enable session_search  # 跨会话搜索
hermes tools enable cronjob     # 定时任务
hermes tools enable kanban      # 任务板（可选）
```

> **注意**：工具集变更需重启会话生效，执行 `/reset` 或重新启动 Hermes。

### 2.3 配置模型

```bash
# 选择模型（推荐支持长上下文的模型）
hermes model

# 或直接配置
hermes config set model.default "anthropic/claude-sonnet-4"
hermes config set model.provider "openrouter"
```

### 2.4 配置 Memory

```bash
# 查看 Memory 状态
hermes memory status

# 启用 Memory（如未启用）
hermes config set memory.memory_enabled true
hermes config set memory.user_profile_enabled true
```

## 3. Obsidian 环境准备

### 3.1 确认 Vault 结构

项目依赖 vault 的 6 层目录结构：

```
YourVault/
├── 00-Inbox(收件箱)/
├── 10-Project(项目层)/
├── 20-核心能力-Core_Ability/
│   └── 00 AI/
│       └── 01-AI工具链与Agent实践/
│           └── 02 Agent/
│               └── 项目实战/
│                   └── 06-个人知识库自动整理Agent/  ← 本项目
├── 30-领域知识-Domain/
├── 40-输出-Output/
└── 50-归档-Archive/
```

### 3.2 安装必要插件

#### Dataview 插件

在 Obsidian 社区插件中搜索并安装 **Dataview**。

```yaml
# .obsidian/community-plugins.json 中应包含
"dataview"
```

验证安装：

```dataview
TABLE file.ctime as "创建时间", file.mtime as "修改时间"
FROM "00-Inbox(收件箱)"
SORT file.ctime DESC
LIMIT 10
```

#### Templater 插件

安装 **Templater** 并配置模板目录：

```yaml
# Templater 设置
Template folder location: _templates/
```

### 3.3 创建 Frontmatter 模板

在 `_templates/frontmatter.md` 中创建模板：

```markdown
---
title: <% tp.file.title %>
description: 
created: <% tp.date.now("YYYY-MM-DD") %>
updated: <% tp.date.now("YYYY-MM-DD") %>
author: 
tags:
  - 
status: draft
---

# <% tp.file.title %>
```

在 `_templates/note-standard.md` 中创建标准笔记模板：

```markdown

  - <% tp.system.prompt("标签（逗号分隔）") %>
```

## 4. Git 初始化

```bash
# 在 vault 根目录初始化 Git
cd /path/to/your/vault
git init

# 创建 .gitignore
cat > .gitignore << 'EOF'
.obsidian/workspace
.obsidian/cache
.trash/
*.tmp
.DS_Store
EOF

# 首次提交
git add .
git commit -m "chore: 初始化知识库 Git 仓库"
```

## 5. Hermes Cron 任务配置

### 5.1 创建 Frontmatter 检测任务

```bash
hermes cron create "every 6h" \
  --name "frontmatter-check" \
  --prompt "扫描 Obsidian vault 路径 X:/KMS/yeyunby/，检测所有缺少 frontmatter 的 .md 文件。对于缺少 title、description、tags、status、created 字段的笔记，列出文件路径和缺失字段。使用 terminal 工具执行 find+grep 扫描，使用 @file 读取可疑文件确认。输出格式化报告。" \
  --deliver chat
```

### 5.2 创建链接检查任务

```bash
hermes cron create "0 8 * * *" \
  --name "link-integrity-check" \
  --prompt "检查 Obsidian vault 中的内部链接完整性。使用 terminal 工具扫描所有 .md 文件中的 [[wikilink]] 和 [markdown](link) 格式链接，验证目标文件是否存在。报告死链、空链和指向已归档笔记的链接。输出格式化报告。" \
  --deliver chat
```

### 5.3 创建关联推荐任务

```bash
hermes cron create "0 9 * * 1" \
  --name "note-relation-recommend" \
  --prompt "分析 Obsidian vault 中最近一周新建或修改的笔记，基于内容语义相似度推荐关联链接。使用 session_search 查找主题相似的旧笔记，结合 Memory 中的用户偏好，为每条新笔记推荐 3-5 个可能的 [[wikilink]] 关联。输出关联建议报告。" \
  --deliver chat
```

### 5.4 创建归档建议任务

```bash
hermes cron create "0 10 1 * *" \
  --name "archive-suggestion" \
  --prompt "分析 Obsidian vault 中所有笔记的活跃度。使用 terminal 执行 git log 获取每个文件的最后修改时间，使用 Dataview 查询获取笔记元数据。识别以下笔记：1) 超过 90 天未更新 2) 状态为 draft 但超过 30 天未修改 3) 孤立笔记（没有任何入链）。输出归档建议报告。" \
  --deliver chat
```

### 5.5 查看和管理 Cron 任务

```bash
# 列出所有任务
hermes cron list

# 查看任务状态
hermes cron status

# 暂停某个任务
hermes cron pause frontmatter-check

# 立即触发任务
hermes cron run link-integrity-check
```

## 6. Kanban 任务板初始化（可选）

```bash
# 初始化 Kanban 看板
hermes kanban init --name "知识库整理"

# 创建初始任务
hermes kanban create "初始全库扫描" \
  --description "对 vault 进行首次全面扫描，建立基准报告" \
  --priority high

hermes kanban create "配置 Cron 任务" \
  --description "完成所有 Cron 任务的创建和测试" \
  --priority high

# 查看看板
hermes kanban list
```

## 8. 常见环境问题

| 问题 | 排查方法 |
|------|----------|
| Hermes 找不到 terminal 工具 | `hermes tools enable terminal` 后 `/reset` |
| Cron 任务不触发 | `hermes cron status` 检查调度器是否运行 |
| Memory 不生效 | `hermes config set memory.memory_enabled true` |
| Git 操作失败 | 检查 vault 目录是否已 `git init` |
| Dataview 查询无结果 | 确认笔记有完整 frontmatter |
| 路径包含中文报错 | 使用 MSYS2 路径格式 `/x/KMS/...` 替代 `X:/...` |
