# 环境搭建指南

## 1. 前置条件

| 组件 | 版本要求 | 说明 |
|------|---------|------|
| Hermes Agent | ≥ v2.0 | 核心 Agent 框架 |
| Python | ≥ 3.10 | 辅助脚本运行环境 |
| Git | ≥ 2.30 | 版本管理 |
| 网络 | 可访问各社交媒体 | 搜索数据采集 |

## 2. 安装 Hermes Agent

### 2.1 一键安装

```bash
# Linux / macOS
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

# Windows (PowerShell)
iwr -Uri https://hermes-agent.nousresearch.com/install.ps1 -UseBasicParsing | iex
```

### 2.2 验证安装

```bash
hermes --version
hermes doctor
```

`hermes doctor` 会检查所有依赖项是否就绪。确保输出中没有红色错误。

### 2.3 配置模型提供商

本项目推荐使用以下模型进行情感分析（需要良好的中文理解能力）：

```bash
# 交互式选择模型
hermes model

# 或直接配置
hermes config set model.default "anthropic/claude-sonnet-4"
hermes config set model.provider "openrouter"
```

> **提示**：情感分析对模型的中文理解能力要求较高。推荐使用 Claude Sonnet 4、GPT-4o 或 DeepSeek V3 等中文能力强的模型。

## 3. 配置 Hermes Gateway（消息推送）

Gateway 是舆情预警和日报推送的关键组件。

### 3.1 微信推送配置

```bash
# 启动 Gateway 设置向导
hermes gateway setup

# 选择 WeChat (Weixin) 平台
# 按照提示完成微信登录二维码扫描
```

**微信适配器配置示例** (`~/.hermes/config.yaml`)：

```yaml
gateway:
  enabled: true
  platforms:
    wechat:
      enabled: true
      # 推送目标：群聊或联系人
      default_target: "舆情监控群"
```

### 3.2 Telegram 推送配置（备选）

```bash
hermes gateway setup
# 选择 Telegram 平台
# 输入 Bot Token（从 @BotFather 获取）
```

**Telegram 配置示例**：

```yaml
gateway:
  platforms:
    telegram:
      enabled: true
      bot_token: "${TELEGRAM_BOT_TOKEN}"
      chat_id: "${MONITOR_CHAT_ID}"
```

### 3.3 启动 Gateway

```bash
# 前台运行（调试用）
hermes gateway run

# 后台服务（生产环境）
hermes gateway install
hermes gateway start
hermes gateway status
```

## 4. 配置 Cron 任务

### 4.1 创建监控 Cron 任务

```bash
# 高频轮询（国内平台，每30分钟）
hermes cron create "30m" \
  --name "social-monitor-cn" \
  --prompt "@skill social-media-monitor 执行微博、知乎、小红书舆情监控轮询，关键词见 configs/keywords.yaml" \
  --delivery wechat \
  --skills social-media-monitor

# 中频轮询（海外平台，每1小时）
hermes cron create "1h" \
  --name "social-monitor-en" \
  --prompt "@skill social-media-monitor 执行 Hacker News、Reddit 舆情监控轮询，关键词见 configs/keywords.yaml" \
  --delivery wechat \
  --skills social-media-monitor

# 日报生成（每日 09:00）
hermes cron create "0 9 * * *" \
  --name "daily-report" \
  --prompt "@skill social-media-monitor 生成昨日社交媒体舆情日报，汇总所有平台监控数据，包含情感趋势分析和关键事件回顾" \
  --delivery wechat \
  --skills social-media-monitor
```

### 4.2 验证 Cron 任务

```bash
# 查看所有任务
hermes cron list

# 手动触发测试
hermes cron run social-monitor-cn

# 查看调度器状态
hermes cron status
```

## 5. 配置监控关键词

### 5.1 创建关键词配置文件

```bash
mkdir -p configs
```

编辑 `configs/keywords.yaml`：

```yaml
keywords:
  brand:
    - "你的品牌名"
    - "你的产品名"
  product:
    - "产品名 评测"
    - "产品名 体验"
  competitor:
    - "竞品A"
    - "竞品B"
  industry:
    - "行业关键词"

platforms:
  weibo:
    search_template: "site:weibo.com {keyword}"
    max_results: 10
  zhihu:
    search_template: "site:zhihu.com {keyword}"
    max_results: 10
  xiaohongshu:
    search_template: "site:xiaohongshu.com {keyword}"
    max_results: 10
  hackernews:
    search_template: "site:news.ycombinator.com {keyword}"
    max_results: 5
  reddit:
    search_template: "site:reddit.com {keyword}"
    max_results: 5
```

### 5.2 配置情感分析阈值

编辑 `configs/sentiment.yaml`：

```yaml
sentiment:
  levels:
    critical_negative:
      range: [0, 20]
      action: alert_immediately
    negative:
      range: [21, 40]
      action: alert
    neutral:
      range: [41, 60]
      action: log_only
    positive:
      range: [61, 80]
      action: log_and_highlight
    strong_positive:
      range: [81, 100]
      action: log_and_highlight
```

## 6. 创建辅助脚本

### 6.1 单次监控执行脚本 (`scripts/monitor.sh`)

```bash
#!/bin/bash
# 社交媒体舆情监控 - 单次执行脚本
# 用于手动触发或 CI 集成

KEYWORDS_FILE="configs/keywords.yaml"
TIMESTAMP=$(date +"%Y%m%d_%H%M%S")
OUTPUT_DIR="data/${TIMESTAMP}"

mkdir -p "${OUTPUT_DIR}"

echo "=== 社交媒体舆情监控 ==="
echo "时间: $(date)"
echo "关键词配置: ${KEYWORDS_FILE}"
echo "输出目录: ${OUTPUT_DIR}"

# 通过 Hermes 执行监控
hermes chat -q "
请执行社交媒体舆情监控轮询：
1. 使用 web_search 搜索关键词（从 ${KEYWORDS_FILE} 读取）
2. 覆盖平台：微博、知乎、小红书、Hacker News、Reddit
3. 对每条结果进行情感分析（0-100分）
4. 标记强烈负面（<20分）和负面（21-40分）条目
5. 输出格式化为 JSON 保存到 ${OUTPUT_DIR}/results.json
6. 如有负面舆情，通过 Gateway 推送预警
"

echo "=== 监控完成 ==="
```

### 6.2 情感分析辅助脚本 (`scripts/sentiment.py`)

```python
#!/usr/bin/env python3
"""
情感分析辅助工具
用于对已采集的舆情数据进行批量情感分析
"""

import json
import sys
from pathlib import Path
from datetime import datetime


def load_results(filepath: str) -> list:
    """加载采集结果"""
    with open(filepath, "r", encoding="utf-8") as f:
        return json.load(f)


def classify_sentiment(score: int) -> str:
    """根据分数分类情感"""
    if score <= 20:
        return "critical_negative"
    elif score <= 40:
        return "negative"
    elif score <= 60:
        return "neutral"
    elif score <= 80:
        return "positive"
    else:
        return "strong_positive"


def generate_summary(results: list) -> dict:
    """生成舆情摘要"""
    total = len(results)
    if total == 0:
        return {"total": 0, "summary": "无数据"}

    sentiments = [r.get("sentiment_score", 50) for r in results]
    avg_score = sum(sentiments) / total
    negatives = [r for r in results if r.get("sentiment_score", 50) <= 40]

    return {
        "total": total,
        "avg_sentiment": round(avg_score, 1),
        "negative_count": len(negatives),
        "negative_ratio": round(len(negatives) / total * 100, 1),
        "platforms": list(set(r.get("platform", "unknown") for r in results)),
        "generated_at": datetime.now().isoformat(),
    }


if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("用法: python sentiment.py <results.json>")
        sys.exit(1)

    filepath = sys.argv[1]
    results = load_results(filepath)
    summary = generate_summary(results)
    print(json.dumps(summary, ensure_ascii=False, indent=2))
```

### 7.2 常见问题快速排查

| 问题 | 检查项 |
|------|--------|
| Gateway 无法启动 | `hermes gateway status` 查看日志 |
| 搜索无结果 | 确认网络可访问目标平台 |
| Cron 不触发 | `hermes cron status` 检查调度器 |
| 推送未收到 | 确认 Gateway 目标群组/联系人配置正确 |
| 情感分析不准 | 尝试更换更强的大语言模型 |
