# 02 — 环境搭建

## 1. 环境要求

### 1.1 硬件要求

| 配置项 | 最低要求 | 推荐配置 |
|--------|----------|----------|
| CPU | 4 核 | 8 核以上 |
| 内存 | 8 GB | 16 GB 以上 |
| 磁盘 | 20 GB 可用 | 50 GB+（SSD 更佳） |
| 网络 | 稳定互联网连接 | 50 Mbps 以上 |
| 操作系统 | Windows 10 / Ubuntu 20.04 | Windows 11 / Ubuntu 22.04 |

### 1.2 软件依赖

| 软件 | 版本要求 | 用途 |
|------|----------|------|
| Hermes Agent | ≥ 1.0 | Agent 核心引擎 |
| Python | ≥ 3.10 | 脚本运行环境 |
| FFmpeg | ≥ 5.0 | 视频合成处理 |
| Git | ≥ 2.30 | 版本管理 |
| Node.js（可选） | ≥ 18 | 部分视频处理工具 |

## 2. 安装步骤

### 2.1 安装 Hermes Agent

```bash
# Windows (PowerShell 管理员)
winget install HermesAgent

# 或通过 pip 安装
pip install hermes-agent

# 验证安装
hermes --version

# 初始化配置
hermes init
```

### 2.2 安装 FFmpeg

```bash
# Windows (使用 winget)
winget install FFmpeg

# 或手动下载后添加到 PATH
# 下载地址: https://ffmpeg.org/download.html

# 验证安装
ffmpeg -version
```

### 2.3 安装 Python 依赖

```bash
# 创建虚拟环境（推荐）
python -m venv venv
source venv/bin/activate  # Linux/Mac
# 或
venv\Scripts\activate     # Windows

# 安装核心依赖
pip install edge-tts          # Edge TTS 配音
pip install openai            # OpenAI API（TTS + LLM）
pip install ffmpeg-python     # FFmpeg Python 绑定
pip install pyyaml            # YAML 配置解析
pip install requests          # HTTP 请求
pip install schedule          # 本地定时任务（备选）

# 可选依赖
pip install moviepy           # Python 视频编辑
pip install Pillow            # 图片处理
pip install aiohttp           # 异步 HTTP（批量发布）
```

### 2.4 克隆项目

```bash
# 克隆到本地
git clone <your-repo-url> 09-AI短视频自动生成与发布Agent
cd 09-AI短视频自动生成与发布Agent

# 创建必要目录
mkdir -p data/scripts data/videos data/assets data/analytics
mkdir -p config
mkdir -p skills
mkdir -p scripts
```

## 3. 平台 API 配置

### 3.1 配置文件结构

编辑 `config/platforms.yaml`：

```yaml
# config/platforms.yaml
platforms:
  douyin:
    enabled: true
    app_id: "你的抖音 App ID"
    app_secret: "${DOUYIN_APP_SECRET}"  # 使用环境变量
    access_token: "${DOUYIN_ACCESS_TOKEN}"
    publish_interval_minutes: 30  # 发布间隔
    max_daily_posts: 20           # 每日上限
    video_requirements:
      max_duration: 180           # 最长 3 分钟
      aspect_ratio: "9:16"        # 竖屏
      min_resolution: "720x1280"

  xiaohongshu:
    enabled: true
    app_id: "你的小红书 App ID"
    app_secret: "${XHS_APP_SECRET}"
    access_token: "${XHS_ACCESS_TOKEN}"
    publish_interval_minutes: 20
    max_daily_posts: 10
    video_requirements:
      max_duration: 300
      aspect_ratio: "3:4"         # 小红书竖版
      min_resolution: "720x960"

  bilibili:
    enabled: true
    app_id: "你的 B站 App ID"
    app_secret: "${BILI_APP_SECRET}"
    access_token: "${BILI_ACCESS_TOKEN}"
    publish_interval_minutes: 60
    max_daily_posts: 5
    video_requirements:
      max_duration: 600
      aspect_ratio: "16:9"        # B站横屏为主
      min_resolution: "1920x1080"
```

### 3.2 TTS 配置

编辑 `config/tts_config.yaml`：

```yaml
# config/tts_config.yaml
tts:
  default_engine: "edge"  # edge | openai | fish | cosyvoice

  edge:
    voice: "zh-CN-XiaoxiaoNeural"  # 中文女声
    rate: "+0%"                     # 语速调整
    volume: "+0%"                   # 音量调整
    pitch: "+0Hz"                   # 音调调整

  openai:
    model: "tts-1"
    voice: "alloy"                  # alloy | echo | fable | nova | onyx | shimmer
    speed: 1.0                      # 语速 0.25-4.0
    api_key: "${OPENAI_API_KEY}"

  # 多语言配音配置（出海场景）
  multilingual:
    en:
      edge_voice: "en-US-JennyNeural"
      openai_voice: "nova"
    ja:
      edge_voice: "ja-JP-NanamiNeural"
      openai_voice: "shimmer"
    ko:
      edge_voice: "ko-KR-SunHiNeural"
      openai_voice: "alloy"
```

### 3.3 Cron 调度配置

编辑 `config/cron_schedule.yaml`：

```yaml
# config/cron_schedule.yaml
cron:
  # 热点追踪 - 每 2 小时
  hot_topic_tracker:
    schedule: "0 */2 * * *"
    skill: "hot-topic-tracker"
    params:
      keywords: ["AI", "科技", "热点", "教程"]
      max_topics: 5

  # 短视频生产 - 每 4 小时
  video_production:
    schedule: "0 */4 * * *"
    skill: "short-video-pipeline"
    params:
      batch_size: 3
      priority: "hot"

  # 数据回采 - 每 30 分钟
  data_collection:
    schedule: "*/30 * * * *"
    skill: "data-collector"
    params:
      fetch_last_hours: 2

  # 内容优化分析 - 每天凌晨
  content_optimization:
    schedule: "0 3 * * *"
    skill: "content-optimizer"
    params:
      analyze_days: 7
```

## 6. 快速测试

### 6.1 测试 TTS 配音

```python
# scripts/test_tts.py
import asyncio
import edge_tts

async def test_tts():
    text = "你好，欢迎使用 AI 短视频自动生成系统。"
    tts = edge_tts.Communicate(text, "zh-CN-XiaoxiaoNeural")
```

## 7. 常见环境问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `ffmpeg: command not found` | FFmpeg 未安装或不在 PATH | 安装 FFmpeg 并添加到系统 PATH |
| `ModuleNotFoundError: edge_tts` | Python 依赖未安装 | `pip install edge-tts` |
| API 返回 401 | API Key 配置错误 | 检查环境变量和配置文件 |
| 视频合成花屏 | 像素格式不兼容 | 添加 `-pix_fmt yuv420p` 参数 |
| 发布超时 | 网络问题或平台限流 | 检查网络，增加重试机制 |
