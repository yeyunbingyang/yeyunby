# 环境搭建与依赖安装

## 一、环境总览

| 组件 | 版本要求 | 说明 |
|------|----------|------|
| Python | ≥ 3.10 | 脚本运行环境 |
| Hermes Agent | ≥ 0.5.0 | Agent 框架 |
| ComfyUI | ≥ 0.2.0 | 图像生成后端 |
| CUDA | ≥ 11.8 | GPU 加速（推荐 24GB+ VRAM） |
| Git | ≥ 2.30 | 版本管理 |

## 二、Hermes Agent 安装

### 2.1 安装 Hermes

```bash
# Windows (PowerShell)
winget install Hermes
# 或手动下载安装包

# macOS / Linux
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

### 2.2 验证安装

```bash
hermes --version
# 预期输出: Hermes Agent v0.5.0+
```

### 2.3 启用必要功能

```bash
# 启用 Kanban 插件
hermes plugin enable kanban

# 启用 Cron 调度
hermes config set cron.enabled true

# 配置 Memory 存储（推荐 SQLite）
hermes config set memory.backend sqlite
```

## 三、ComfyUI 部署

### 3.1 安装 ComfyUI

```bash
# 克隆仓库
git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI

# 安装依赖
pip install -r requirements.txt

# Windows 用户额外安装
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121
```

### 3.2 下载必要模型

```bash
# ComfyUI 模型目录结构
ComfyUI/
├── models/
│   ├── checkpoints/       # 基础模型（SDXL / Flux）
│   ├── loras/             # LoRA 模型
│   ├── controlnet/        # ControlNet 模型
│   ├── upscale_models/    # 放大模型
│   └── rembg/             # 去背模型
```

**推荐模型清单**：

| 模型 | 用途 | 下载来源 |
|------|------|----------|
| SDXL 1.0 base | 基础文生图 | HuggingFace: stabilityai/stable-diffusion-xl-base-1.0 |
| Flux.1 dev | 高质量生成（可选） | HuggingFace: black-forest-labs/FLUX.1-dev |
| RMBG-1.4 | 去背 | HuggingFace: briaai/RMBG-1.4 |
| 4x-UltraSharp | 图片放大 | OpenModelDB |
| IP-Adapter | 模特图一致性 | HuggingFace: h94/IP-Adapter |

### 3.3 安装 ComfyUI 自定义节点

```bash
cd ComfyUI/custom_nodes

# ComfyUI-Manager（推荐）
git clone https://github.com/ltdrdata/ComfyUI-Manager.git

# 去背节点
git clone https://github.com/Acly/comfyui-rembg.git

# IP-Adapter 节点
git clone https://github.com/cubiq/ComfyUI_IPAdapter_plus.git

# ControlNet 辅助节点
git clone https://github.com/Fannovel16/comfyui_controlnet_aux.git
```

### 3.4 启动 ComfyUI

```bash
# 启动服务（默认端口 8188）
python main.py --listen 0.0.0.0 --port 8188

# 验证：浏览器打开 http://localhost:8188
```

## 四、Python 依赖安装

## 五、配置文件

### 5.1 Hermes 配置

```yaml
# ~/.hermes/config.yaml
cron:
  enabled: true
  timezone: Asia/Shanghai

kanban:
  enabled: true
  board_path: ./kanban_board.json

memory:
  backend: sqlite
  path: ./hermes_memory.db

plugins:
  - name: comfyui
    enabled: true
    config:
      base_url: http://localhost:8188
      timeout: 120
```

### 5.2 项目环境变量

```bash
# .env 文件
COMFYUI_BASE_URL=http://localhost:8188
COMFYUI_TIMEOUT=120

# 平台 API 密钥
TAOBAO_APP_KEY=your_app_key
TAOBAO_APP_SECRET=your_app_secret
PDD_CLIENT_ID=your_client_id
PDD_CLIENT_SECRET=your_client_secret
SHOPIFY_ACCESS_TOKEN=your_access_token
SHOPIFY_STORE_URL=your_store.myshopify.com

# 存储路径
OUTPUT_DIR=./output
TEMP_DIR=./temp
LOG_DIR=./logs
```

## 七、GPU 要求参考

| 显卡 | VRAM | 可运行模型 | 批量大小 |
|------|------|------------|----------|
| RTX 3060 | 12GB | SDXL 基础 | 1-2 |
| RTX 4070 | 12GB | SDXL + LoRA | 2-4 |
| RTX 4090 | 24GB | SDXL + ControlNet + IP-Adapter | 4-8 |
| A100 | 80GB | Flux + 全插件 | 16+ |

> **提示**：VRAM 不足时可启用 `--lowvram` 模式，但生成速度会显著下降。
