# Vibe-Coding视频创作场景

> Vibe Coding 就是用自然语言描述你的创意需求，让 AI 直接生成可交付的视频文件。本笔记收集 hyperframes 和 remotion 两个视频插件的实战 prompt 场景，可以直接复制粘贴使用。

---

## 插件选择速查

| 维度            | hyperframes                                                    | remotion                      |
| ------------- | -------------------------------------------------------------- | ----------------------------- |
| **技术栈**       | HTML + GSAP + Three.js                                         | React 组件 + 逐帧渲染               |
| **上手难度**      | 低（写 HTML 就行）                                                   | 中（需要 React 基础）                |
| **场景适合**      | 轻量动效/片头/转场/社交媒体                                                | 复杂合成/数据视频/批量出片                |
| **输出质量**      | 快速出片                                                           | 专业级可控                         |
| **内置 Skills** | 5 个 (hyperframes, cli, registry, gsap, website-to-hyperframes) | 1 个 (remotion-best-practices) |

**选择原则**：简单动效用 hyperframes（快），复杂合成用 remotion（强）。

---

## hyperframes Vibe Coding 场景

### 场景 1：产品介绍视频
- **操作示例**："帮我用 hyperframes 做 30 秒产品介绍，包含开场标题→3 个功能介绍（卡片切换）→CTA+LOGO，风格现代，品牌色 #2563EB"
- **工作流**：Codex 用 GSAP 写 HTML 动效 → 生成每帧画面 → 合成视频 → 输出 MP4
- **输出**：`.mp4` 文件（可选带字幕+配音）

### 场景 2：教程讲解视频
- **操作示例**："帮我把这篇博客做成讲解视频：提取要点作分页，加 GSAP 渐入动画，TTS 配音，自动添加中文字幕"
- **技巧**：先让 agent-reach 调研内容，再用 hyperframes 制作，内容更扎实

### 场景 3：社交媒体短视频（竖屏 9:16）
- **操作示例**："做 15 秒竖屏视频：前 3 秒标题动画→中间 8 秒 4 个卖点→最后 4 秒品牌露出+引导关注"
- **输出**：直接生成可发布的竖屏视频文件，适合 Reels / TikTok / 视频号

### 场景 4：网页转视频
- **操作示例**："帮我把这个网页（贴 URL）转成一段介绍视频，含截图和文字讲解"
- **原理**：browser-use 截取网页 → 整理脚本 → hyperframes 渲染

### 场景 5：创意粒子动画
- **操作示例**："用 hyperframes 做一个 10 秒的粒子系统动画，彩色粒子从中心向外扩散，逐渐组成 'Hello World' 文字，GSAP 缓动，深色背景"
- **应用**：视频开场/intro/转场素材

### 场景 6：产品 3D 旋转展示
- **操作示例**："用 Three.js + hyperframes 做一个产品 360 度旋转展示视频，产品在白色背景上缓慢旋转，加环境光反射效果，底部有产品名称淡入"
- **技巧**：hyperframes 支持 Three.js 嵌入，适合产品官网/电商主图视频

### 场景 7：动态数据可视化短视频
- **操作示例**："帮我生成长宽比 1:1 的短视频，背景是深色渐变，中间是一个动态的环形图，数据从 0 增长到 75%，旁边显示 '75% 用户满意度'，用 GSAP 缓动动画，时长 8 秒"
- **原理**：先用 visualize 插件设计图表布局，hyperframes 渲染成动画视频

### 场景 8：A/B 测试视频素材
- **操作示例**："帮我生成 3 个版本的 5 秒片头动画，分别是：蓝色科技风、金色商务风、彩色创意风，每个版本输出单独的 MP4，方便我做 A/B 测试"
- **效率**：一次 prompt 批量生成多个版本，比手动制作快 10 倍

### 场景 9：动态 Logo 动画
- **操作示例**："帮我做一个 5 秒的公司 LOGO 动画：LOGO 从透明淡入，然后有一个微缩放大的呼吸效果循环，最后定格。背景渐变色 #0A1628 到 #1A365D"
- **输出**：可直接用于视频片头 / 网站 Hero 区域 / PPT 开场

### 场景 10：文字排版动画
- **操作示例**："做一个 quote 引用视频：'Vibe Coding is the future'，字体用粗体，文字逐字弹出，每字带轻微旋转，背景用毛玻璃效果，时长 6 秒"
- **格式**：竖屏 9:16，适合社交媒体传播

## remotion Vibe Coding 场景

### 场景 1：产品发布会视频
- **操作示例**："用 remotion 做一个 60 秒的产品发布会开场视频：0-5s LOGO 淡入（发光粒子）→5-20s 3 个数据动效（曲线图/柱状图/地图）→20-45s 功能 3D 翻转→45-55s 评价轮播→55-60s CTA，深蓝+青色配色"
- **特点**：数据驱动的动画——传入 JSON 数据自动生成图表动画

### 场景 2：数据报告视频
- **操作示例**："帮我把这份季度销售数据做成 2 分钟的可视化报告视频：开头概览动画→月度趋势折线图逐月展开→各区域环形图逐个弹出→同比柱状图对比→结尾关键结论页。数据在附件 CSV 里"
- **技巧**：提前准备结构化数据（CSV/JSON），Codex 直接嵌入 React 组件

### 场景 3：教学/演示视频
- **操作示例**："用 remotion 做一个代码教学视频：逐行显示代码高亮当前行→右侧同步显示运行结果→底部进度条显示进度→45 秒"

### 场景 4：多尺寸广告视频
- **操作示例**："帮我做一个产品广告视频，输出 3 个版本：横屏 16:9（YouTube）→竖屏 9:16（Reels）→方形 1:1（朋友圈/小红书）"
- **技巧**：同一组 React 组件改几个 Props 就能控制输出尺寸

### 场景 5：数据叙事动画
- **操作示例**："用 remotion 做一个数据叙事动画：公司从创立到现在的里程碑时间线，每个节点图标+年份+描述，用平滑缩放过渡"
- **扩展**：remotion 的 React 生态可复用 d3.js / recharts 等图表库

### 场景 6：AI 产品宣传片
- **操作示例**："用 remotion 做 30 秒 AI 产品宣传片：开场粒子效果拼出产品名，3 个核心功能截图嵌入，每截图旁动态标注箭头，背景渐变粒子，结尾倒计时后出现 CTA。全程用 spring 物理缓动"
- **特点**：remotion 的 React 生态可直接用 framer-motion / react-spring

### 场景 7：交互式作品集 Demo
- **操作示例**："用 remotion 做个人作品集展示视频：5 个项目卡片依次出现，含截图、技术栈标签、描述。卡片用 3D 翻转 rotateY 动画进场，底部进度条"
- **技巧**：remotion 也支持输出交互式 HTML 版本（不只是视频）

### 场景 8：音乐可视化
- **操作示例**："帮我做音乐可视化视频：输入音频，基于频谱实时生成动态波形图，波形颜色从 #FF6B6B 渐变到 #4ECDC4，深色粒子系统随节拍跳动，时长与音频同步"
- **工作流**：Codex 用 Web Audio API 分析音频，remotion 逐帧渲染

### 场景 9：GIF 动效生成器
- **操作示例**："用 remotion 生成 3 个 loading 动画 GIF：旋转环形进度条→弹跳的三个点→渐变色流动背景，每个 2 秒循环，透明背景"
- **用途**：直接用于 Web 项目 / App 启动页 / 微交互演示

### 场景 10：代码到视频——从 GitHub 仓库生成项目演示
- **操作示例**："接入这个 GitHub 仓库（贴 URL），自动生成 1 分钟项目演示视频：展示架构图、文件结构树、运行截图、核心代码高亮、Star 数量动效"
- **原理**：Codex clone 仓库并分析 → remotion 渲染为视频。完全自动化的 repo→demo video 管线

### 场景 11：动态时间线视频
- **操作示例**："做一个项目里程碑时间线：2024 Q1 立项→Q2 原型→Q3 内测→Q4 上线，每个节点圆点标记，连线流动虚线动画，背景根据时间进度颜色渐变"
- **应用**：融资 Pitch Deck / 年终总结 / 产品发布

### 场景 12：短视频批量工厂
- **操作示例**："帮我准备一个 5 条短视频的批量脚本模板。主题：AI 科普，每条 20 秒，含标题卡、2-3 个要点图标动画、底部字幕，输出全部 5 条。第一条主题：什么是大语言模型"
- **效率**：用 remotion React Props 机制，一套模板 + 不同数据 = 批量出片

## 最佳实践

### hyperframes
1. **先写脚本再制作**：让 Codex 生成大纲确认后再渲染，省额度
2. **固化为 Skill**：做满意的效果后让 Codex 保存，"把这套流程做成一个 Skill"
3. **分段迭代**：单段 clip 建议 3-8 秒，先画面后配音分步迭代

### remotion
1. **分步迭代**：先让 Codex 生成基础骨架视频，预览后逐步加细节（"给标题加渐入效果"）
2. **先短后长**：remotion 渲染消耗额度较大，先做短版本（15-30 秒）测试效果
3. **复用组件**：做好的 React 组件可让 Codex 保存为模板
4. **黄金搭档**：remotion + visualize 插件 = 数据动画的最佳组合
5. **与 hyperframes 配合**：简单动效用 hyperframes（快），复杂合成用 remotion（强）
