# Agent 对话与提示词诊断报告

> **分析日期**: 2026-08-02
> **数据来源**: 本机 Claude Code 会话记录（12 个会话、105 条用户提示词）+ 公开反模式资料
> **适用模型背景**: 会话主要跑在 `deepseek-v4-flash`（4768 条），属廉价高速模型，指令遵循能力弱于旗舰模型

---

## 一、大众提示词最常见的问题

> 依据：[Prompt 反模式清单](https://github.com/oxbshw/LLM-Agents-Ecosystem-Handbook/blob/main/prompt_engineering/anti_patterns.md) 与 [Agentic AI 提示工程 10 大原则](https://cloud.baidu.com/article/5533347)，按与本人相关度筛选。

| # | 大众通病 | 说明 | 命中情况 |
|---|---------|------|---------|
| 1 | **极短指令、缺上下文** | "继续""处理""优化"——模型只能猜 | ✅ 命中 |
| 2 | **只给目标、不给约束** | 要结果但不说边界/禁忌 | ✅ 命中 |
| 3 | **不指定输出格式** | 不明确要表格/列表/JSON | ⚠️ 部分 |
| 4 | **用"否定式"指令** | "不要X"堆叠，效果差，应正面引导 | ⚠️ 少量 |
| 5 | **一次问多件事** | 需求堆积，模型逐个偏离 | ⚠️ 少量 |
| 6 | **不验证、盲目信任** | 让 AI 跑完就算完，不检查 | ✅ 命中 |

## 二、个人数据：优势与缺点

### ✅ 做得好的（保持）

| 优点 | 证据 |
|------|------|
| 会用 `@` 引用文件 | 15 次，明确指定操作对象 |
| 会指定方向 | "取消去除图片、我手动粘贴"——明确改变策略 |
| 会用 `/grill-me` 打磨方案 | 5 次，主动做方案压力测试 |
| 会反向确认 | "还有其他方法吗""分析方案还有其他方式更合适吗" |

### ❌ 主要缺点（按影响排序）

**1. 极短指令占比高达 58%**（61/105 条 3 词以内）

```text
继续 / 处理 / 清理 / 修复 / 同意 / 优化方案 / 图片位置错误
```

没有告诉 AI 上下文、目标、验收标准，完全依赖 AI 猜。在 Flash 模型上猜错概率更高，直接导致反复"重新修复"。

**2. 频繁"继续/修复"循环**

"继续"9 次、"修复"8 次。暴露第一轮没讲清楚，正确做法是开头就写明验收标准，而不是靠"继续"迭代 5 轮。

**3. 粘贴终端输出代替描述问题**（6 次）

把整个 `PS>` 终端输出、报错堆栈贴进来，却没有一句"我想要什么、期望是什么"。应改用"报错 + 期望 + 已试过"三段式。

**4. 无任何上下文的超短命令**（34 次）

如"同意""认知通识是50""完整知识点体系"。作为承接上文的回复可以接受，但作为独立指令完全无法执行。

**5. 知识库任务放 Flash 模型跑**（归因于模型而非本人）

复杂目录重构、格式修复放 `deepseek-v4-flash`，效果必然打折。这是工具选型问题，不是提示词问题。

## 三、表现好的提示词：标杆与改写

### 标杆模板

```text
[任务类型] + [操作对象] + [目标] + [约束] + [验收标准] + [输出格式]
```

### 原话 → 优化版对比

| 原话 | 问题 | 优化版 |
|------|------|--------|
| "继续修复" | 无对象/无目标 | "继续修复 @.../数据分析.md，重点：①表格分隔行格式 ②加粗语法。验收：Obsidian 预览表格正常显示，不引入其他改动" |
| "图片位置错误" | 只报症状 | "@.../数据分析.md 图片应紧跟在对应小标题后，现在全部堆在文末。请调整到各自段落，图片文件名不变" |
| "如何排除所有svg文件" | 无目标 | "知识库推送到 GitHub 时排除所有 .svg 文件。约束：不影响其他格式。验收：push 成功且 .svg 不在仓库" |
| "整个商业实践都生成" | 范围模糊 | "为 01-商业实践/ 下的【财务基础、产品思维、市场与运营】3 个主题各生成一份完整笔记。格式：frontmatter + 大纲 + 要点，每篇 800-1500 字" |
| 粘贴 git push 报错 | 只给报错 | "push 到 GitHub 失败，报错 fatal: unable to access（连接超时）。我已在终端验证 ssh 认证成功。期望：用 ssh 方式推送成功" |

## 四、行动建议

> **每次输入前自问三件事**：① **对象**（`@文件`）；② **目标+约束**（要什么、不要碰什么）；③ **验收标准**（怎么算完成）。复杂任务**切换更强模型**，别让 Flash 背锅。

### 配套技能速查

| 场景 | 推荐 Skill |
|------|-----------|
| 方案设计、可行性判断 | `think` |
| 需求对齐、方案压力测试 | `/grill-me` |
| 查 bug 根因 | `hunt` |
| 代码/发布审查 | `check` |
| 网络调研 | `agent-reach`、`learn` |
| 文档润色 | `write` |
| 格式化/知识库操作 | `obsidian-markdown`、`obsidian-vault` |
