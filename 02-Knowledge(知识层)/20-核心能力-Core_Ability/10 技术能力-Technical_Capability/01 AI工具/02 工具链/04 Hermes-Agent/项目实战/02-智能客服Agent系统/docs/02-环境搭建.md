# 环境搭建指南

## 一、前置依赖

### 1.1 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10+ / macOS 12+ / Ubuntu 20.04+ |
| Python | 3.10+（推荐 3.11） |
| Node.js | 18+（部分 Gateway 插件需要） |
| Docker | 20+（可选，用于向量库） |
| 内存 | ≥ 8GB（推荐 16GB） |
| 磁盘 | ≥ 10GB 可用空间 |

### 1.2 确认环境

```bash
# 检查 Python 版本
python --version
# Python 3.11.5

# 检查 pip
pip --version

# 检查 Node.js（Gateway 插件需要）
node --version
# v20.11.0

# 检查 Docker（向量库需要）
docker --version
# Docker version 24.0.7
```

## 二、Hermes Agent 安装

### 2.1 安装 Hermes

```bash
# 通过 pip 安装
pip install hermes-agent

# 验证安装
hermes --version

# 查看可用命令
hermes --help
```

### 2.2 初始化配置

```bash
# 初始化 Hermes 工作目录
hermes init

# 查看当前配置
hermes config list

# 配置文件路径（Windows）
# C:\Users\<用户名>\.hermes\config.yaml
```

## 三、创建 Profile（多 Agent 架构）

智能客服系统需要多个 Profile 分别承担不同职责：

### 3.1 客服 Agent（主 Agent）

```bash
# 创建客服 Agent Profile
hermes profile create customer-service-agent

# 设置角色描述
hermes config set profile.customer-service-agent.description \
  "智能客服主 Agent，负责接收用户消息、协调各子 Agent 协作、生成最终回复"
```

**对应的 SKILL.md 文件**（位于 `~/.hermes/profiles/customer-service-agent/skills/customer-service/SKILL.md`）：

```yaml
---
name: customer-service
description: 智能客服核心技能 - 意图识别、多轮对话、知识检索
model: gpt-4o
temperature: 0.3
max_tokens: 1024
---

# 智能客服核心技能

## 行为准则
1. 始终保持友好、专业的语气
2. 回答需附上知识来源引用
3. 不确定时主动询问澄清，不编造答案
4. 检测到用户情绪负面时优先安抚
5. 无法解决时主动引导转人工

## 意图分类规则
- 产品咨询 → 调用 knowledge_agent
- 订单查询 → 调用 ticket_agent
- 投诉建议 → 调用 human_handoff
- 问候 → 直接回复
```

### 3.2 知识库 Agent

```bash
# 创建知识库 Agent Profile
hermes profile create knowledge-agent

# 配置知识库模型（长上下文优先）
hermes config set profile.knowledge-agent.model claude-3.5-sonnet
hermes config set profile.knowledge-agent.temperature 0.1
```

**SKILL.md**：

```yaml
---
name: knowledge-retrieval
description: 企业知识库检索与问答
model: claude-3.5-sonnet
temperature: 0.1
---

# 知识库检索技能

## 检索流程
1. 接收用户问题
2. 调用向量库进行语义检索（Top-5）
3. 对结果进行重排序
4. 拼接上下文生成回答
5. 标注知识来源

## 回答规范
- 必须引用知识来源文档
- 不确定时标注"此信息来自[文档名称]"
- 检索不到时，回复"我暂时没有找到相关信息，已为您转接人工客服"
```

### 3.3 工单 Agent

```bash
# 创建工单 Agent Profile
hermes profile create ticket-agent

# 配置工单 Agent
hermes config set profile.ticket-agent.model deepseek-v3
hermes config set profile.ticket-agent.temperature 0.2
```

**SKILL.md**：

```yaml
---
name: ticket-handling
description: 工单创建、查询与流转管理
model: deepseek-v3
temperature: 0.2
---

# 工单处理技能

## 工单创建条件
- 用户要求创建工单
- 问题 3 轮内未解决
- 涉及退款/投诉/售后
- 用户情绪为负面

## 工单字段
- 标题：自动摘要
- 描述：完整对话记录
- 优先级：P0(紧急) / P1(高) / P2(中) / P3(低)
- 分类：售后/投诉/咨询/建议
- 用户ID：自动关联
```

### 3.4 人工兜底路由 Agent

```bash
# 创建人工兜底路由 Profile
hermes profile create human-handoff-agent

# 配置
hermes config set profile.human-handoff-agent.model gpt-4o
hermes config set profile.human-handoff-agent.temperature 0.2
```

**SKILL.md**：

```yaml
---
name: human-handoff
description: 判断是否需要转人工，完成平滑过渡
model: gpt-4o
temperature: 0.2
---

# 人工兜底路由技能

## 转人工条件（满足任一即可）
1. 用户明确要求"转人工"
2. 意图置信度 < 0.6
3. 同一问题重复 ≥ 3 次
4. 涉及法律/财务/医疗等高风险领域
5. 用户情绪检测为愤怒
6. 连续 2 次满意度评价为不满意

## 转人工流程
1. 生成对话摘要
2. 附加用户画像信息
3. 分配坐席（按技能组匹配）
4. 发送上下文给坐席
5. 通知用户"正在为您转接人工..."
```

## 四、模型配置

### 4.1 配置 LLM Provider

```bash
# 配置 OpenAI（GPT-4o）
hermes config set llm.openai.api_key sk-xxxxx
hermes config set llm.openai.model gpt-4o
hermes config set llm.openai.temperature 0.3

# 配置 Anthropic（Claude）
hermes config set llm.anthropic.api_key sk-ant-xxxxx
hermes config set llm.anthropic.model claude-3.5-sonnet

# 配置 DeepSeek
hermes config set llm.deepseek.api_key sk-xxxxx
hermes config set llm.deepseek.model deepseek-chat
```

### 4.2 按 Profile 指定模型

```yaml
# ~/.hermes/config.yaml 片段
profiles:
  customer-service-agent:
    model: gpt-4o
    temperature: 0.3
    
  knowledge-agent:
    model: claude-3.5-sonnet
    temperature: 0.1
    
  ticket-agent:
    model: deepseek-v3
    temperature: 0.2
    
  human-handoff-agent:
    model: gpt-4o
    temperature: 0.2
```

## 五、Gateway 配置

### 5.1 Telegram Gateway

```bash
# 1. 在 Telegram 中通过 @BotFather 创建 Bot，获取 Token
# 2. 配置 Hermes Gateway
hermes config set gateway.telegram.enabled true
hermes config set gateway.telegram.token "YOUR_BOT_TOKEN"
hermes config set gateway.telegram.allowed_users "user1,user2"

# 3. 配置消息路由到客服 Agent
hermes config set gateway.telegram.route_to "customer-service-agent"

# 4. 启动 Gateway
hermes gateway start
```

### 5.2 微信 / 企业微信 Gateway

```bash
# 企业微信配置
hermes config set gateway.wechat.enabled true
hermes config set gateway.wechat.corp_id "YOUR_CORP_ID"
hermes config set gateway.wechat.agent_id "YOUR_AGENT_ID"
hermes config set gateway.wechat.secret "YOUR_SECRET"
hermes config set gateway.wechat.token "YOUR_TOKEN"
hermes config set gateway.wechat.encoding_aes_key "YOUR_AES_KEY"

# 配置路由
hermes config set gateway.wechat.route_to "customer-service-agent"
```

### 5.3 Web Chat（嵌入式）

```html
<!-- 嵌入到网页中 -->
<script src="https://cdn.hermes-agent.dev/chat-widget.js"></script>
<script>
  HermesChat.init({
    gateway: 'wss://your-server/hermes/ws',
    profile: 'customer-service-agent',
    theme: 'light',
    title: '智能客服'
  });
</script>
```

## 六、RAG 知识库配置

### 6.1 准备知识文档

将企业知识文档放入知识库目录：

```bash
# 创建知识库目录
mkdir -p ~/.hermes/knowledge-base/products
mkdir -p ~/.hermes/knowledge-base/faq
mkdir -p ~/.hermes/knowledge-base/policies

# 放入文档（支持 .md / .txt / .pdf）
cp ./产品手册.md ~/.hermes/knowledge-base/products/
cp ./常见问题.md ~/.hermes/knowledge-base/faq/
cp ./售后政策.pdf ~/.hermes/knowledge-base/policies/
```

### 6.2 配置向量库

```bash
# 使用 Chroma（嵌入式，适合开发）
hermes config set knowledge.vector_store.type chroma
hermes config set knowledge.vector_store.path ~/.hermes/vector-db

# 或使用 Qdrant（Docker，适合生产）
docker run -d -p 6333:6333 -v qdrant_data:/qdrant/storage qdrant/qdrant
hermes config set knowledge.vector_store.type qdrant
hermes config set knowledge.vector_store.url http://localhost:6333
```

### 6.3 索引知识文档

```bash
# 构建知识库索引
hermes knowledge index --dir ~/.hermes/knowledge-base

# 查看索引状态
hermes knowledge status

# 测试检索
hermes knowledge query "产品退货政策是什么"
```

### 6.4 配置 Embedding 模型

```yaml
# ~/.hermes/config.yaml 知识库配置片段
knowledge:
  embedding:
    model: text-embedding-3-small  # OpenAI
    # 或使用本地模型
    # model: BAAI/bge-small-zh-v1.5
    # provider: local
    
  retrieval:
    top_k: 5
    score_threshold: 0.7
    rerank: true  # 启用重排序
    
  chunk:
    size: 512
    overlap: 64
```

## 八、常见环境问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `hermes: command not found` | 未安装或 PATH 未配置 | `pip install hermes-agent` 或 `python -m hermes` |
| Gateway 无法启动 | 端口被占用 | 修改端口配置或关闭占用进程 |
| 向量库连接失败 | Docker 未启动 | `docker start qdrant` 或检查端口 |
| 模型 API 报错 | API Key 无效 | 检查 `hermes config list` 中的 API Key |
