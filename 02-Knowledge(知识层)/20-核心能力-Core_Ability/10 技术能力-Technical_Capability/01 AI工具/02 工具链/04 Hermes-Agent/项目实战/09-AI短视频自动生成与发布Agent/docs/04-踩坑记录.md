## 1. TTS 相关

### 1.1 Edge TTS 首次调用超时

**现象**：首次调用 `edge_tts.Communicate().save()` 时耗时超过 30 秒，甚至超时失败。

**原因**：Edge TTS 首次运行需要下载语音模型缓存，后续调用会复用缓存。

**解决方案**：

```python
# 初始化时预热 TTS 引擎
async def warmup_tts():
    """预热 TTS，避免首次调用超时"""
    import edge_tts
    warmup_text = "预热测试。"
    tts = edge_tts.Communicate(warmup_text, "zh-CN-XiaoxiaoNeural")
    await tts.save("data/temp_warmup.mp3")
    import os
    os.remove("data/temp_warmup.mp3")
    print("✅ TTS 引擎预热完成")

# 在流水线启动时调用
await warmup_tts()
```

### 1.2 长文本 TTS 截断

**现象**：超过 3000 字符的文本调用 Edge TTS 时，音频在中间被截断。

**原因**：Edge TTS 单次请求有字符数限制（约 3000 字符）。

**解决方案**：

```python
async def long_text_tts(text: str, voice: str, output: str):
    """分段合成长文本"""
    import edge_tts
    from pydub import AudioSegment

    # 按句号分段，每段不超过 2000 字符
    segments = []
    current = ""
    for char in text:
        current += char
        if char in "。！？\n" and len(current) >= 500:
            segments.append(current)
            current = ""
    if current:
        segments.append(current)

    # 分段合成
    audio_segments = []
    for i, seg in enumerate(segments):
        temp_file = f"{output}_part{i}.mp3"
        tts = edge_tts.Communicate(seg, voice)
        await tts.save(temp_file)
        audio_segments.append(AudioSegment.from_mp3(temp_file))

    # 合并音频
    combined = sum(audio_segments)
    combined.export(output, format="mp3")

    # 清理临时文件
    import os
    for i in range(len(segments)):
        os.remove(f"{output}_part{i}.mp3")
```

### 1.4 配音语速与字幕不同步

**现象**：视频中配音语速与字幕出现时间不匹配，字幕显示过快或过慢。

**原因**：字幕时间轴基于文本长度平均分配，但实际朗读时停顿、重音等导致节奏不均。

**解决方案**：

```python
def align_subtitles_with_audio(audio_path: str, sentences: list) -> list:
    """使用音频能量检测精确对齐字幕"""
    import librosa

    # 加载音频，检测语音活动
    y, sr = librosa.load(audio_path)
    intervals = librosa.effects.split(y, top_db=30)

    # 将语音活动区间映射到句子
    aligned = []
    for i, (start, end) in enumerate(intervals):
        if i < len(sentences):
            aligned.append({
                "text": sentences[i],
                "start": start / sr,
                "end": end / sr
            })

    return aligned
```

## 2. 视频合成相关

### 2.1 FFmpeg 字幕中文乱码

**现象**：使用 FFmpeg 的 `subtitles` 滤镜时，中文字幕显示为方块或乱码。

**原因**：FFmpeg 字幕渲染需要指定中文字体，默认字体不支持中文。

**解决方案**：

```bash
# 方案一：指定中文字体
ffmpeg -i input.mp4 -vf "subtitles=sub.srt:force_style='FontName=Microsoft YaHei'" output.mp4

# 方案二：使用 ass 格式字幕（更丰富的样式支持）
# 将 SRT 转换为 ASS 格式
ffmpeg -i sub.srt sub.ass
# 然后使用 ass 滤镜
ffmpeg -i input.mp4 -vf "ass=sub.ass" output.mp4
```

### 2.2 视频合成速度慢

**现象**：单条 60 秒视频合成需要 5-10 分钟，批量生产时效率低下。

**原因**：`libx264` 编码器使用较慢的 preset，且未启用硬件加速。

**解决方案**：

```bash
# 方案一：使用更快的 preset
ffmpeg -i input.mp4 -c:v libx264 -preset ultrafast output.mp4

# 方案二：启用硬件加速（NVIDIA GPU）
ffmpeg -i input.mp4 -c:v h264_nvenc -preset p1 output.mp4

# 方案三：Intel QuickSync
ffmpeg -i input.mp4 -c:v h264_qsv output.mp4

# 方案四：Python 中动态选择编码器
def get_best_encoder():
    import subprocess
    result = subprocess.run(["ffmpeg", "-encoders"], capture_output=True, text=True)
    if "h264_nvenc" in result.stdout:
        return "h264_nvenc"
    elif "h264_qsv" in result.stdout:
        return "h264_qsv"
    else:
        return "libx264"
```

### 2.3 图片素材循环导致文件过大

**现象**：使用单张图片循环作为背景时，输出视频文件体积异常大。

**原因**：FFmpeg 默认将每一帧编码为关键帧，未利用帧间压缩。

**解决方案**：

```bash
# 使用 stillimage 优化
ffmpeg -loop 1 -i background.jpg \
       -i audio.mp3 \
       -c:v libx264 -tune stillimage \
       -c:a aac \
       -shortest \
       output.mp4

# 或使用 GIF 优化参数
ffmpeg -loop 1 -i background.jpg \
       -i audio.mp3 \
       -c:v libx264 -g 1 -crf 25 \
       -c:a aac \
       -shortest \
       output.mp4
```

### 2.4 视频比例适配问题

**现象**：同一视频在不同平台显示比例不同，导致画面被裁剪或留黑边。

**原因**：抖音（9:16）、小红书（3:4）、B站（16:9）对视频比例要求不同。

**解决方案**：

```python
def adapt_aspect_ratio(input_path: str, target_ratio: str, output_path: str):
    """智能适配目标比例"""
    import subprocess

    # 获取原视频信息
    probe = subprocess.run([
        "ffprobe", "-v", "error",
        "-select_streams", "v:0",
        "-show_entries", "stream=width,height",
        "-of", "csv=p=0",
        input_path
    ], capture_output=True, text=True)
    w, h = map(int, probe.stdout.strip().split(","))

    # 计算目标尺寸
    target_w, target_h = map(int, target_ratio.split(":"))
    target_ar = target_w / target_h
    current_ar = w / h

    if abs(current_ar - target_ar) < 0.01:
        # 比例接近，直接使用
        subprocess.run(["ffmpeg", "-i", input_path, "-c", "copy", output_path])
    elif current_ar > target_ar:
        # 画面过宽，裁剪左右
        new_w = int(h * target_ar)
        x = (w - new_w) // 2
        filter_str = f"crop={new_w}:{h}:{x}:0"
    else:
        # 画面过高，裁剪上下
        new_h = int(w / target_ar)
        y = (h - new_h) // 2
        filter_str = f"crop={w}:{new_h}:0:{y}"

    subprocess.run([
        "ffmpeg", "-i", input_path,
        "-vf", filter_str,
        "-c:a", "copy",
        output_path
    ])
```

## 3. 平台 API 相关

### 3.1 抖音 API 频率限制

**现象**：连续发布多条视频时，抖音 API 返回 `429 Too Many Requests`。

**原因**：抖音开放平台对 API 调用有严格的频率限制（QPS 限制 + 每日总量限制）。

**解决方案**：

```python
import time
import random

class RateLimiter:
    """API 频率限制器"""

    def __init__(self, max_calls: int, period: float):
        self.max_calls = max_calls
        self.period = period
        self.calls = []

    def wait_if_needed(self):
        now = time.time()
        # 移除过期记录
        self.calls = [t for t in self.calls if now - t < self.period]

        if len(self.calls) >= self.max_calls:
            # 等待到最早记录过期
            wait_time = self.period - (now - self.calls[0])
            wait_time += random.uniform(0.5, 2.0)  # 随机抖动
            print(f"⏳ 达到频率限制，等待 {wait_time:.1f} 秒...")
            time.sleep(wait_time)

        self.calls.append(time.time())

# 使用示例
douyin_limiter = RateLimiter(max_calls=10, period=60)  # 每分钟 10 次

async def publish_with_rate_limit(video_path, script):
    douyin_limiter.wait_if_needed()
    return await publish_to_douyin(video_path, script)
```

### 3.2 小红书 API Token 过期

**现象**：小红书发布 API 间歇性返回 `401 Unauthorized`。

**原因**：小红书 access_token 有效期较短（通常 7 天），且无自动刷新机制。

**解决方案**：

```python
class TokenManager:
    """Token 自动管理"""

    def __init__(self, config: dict):
        self.config = config
        self.token = None
        self.expires_at = 0

    async def get_valid_token(self) -> str:
        """获取有效 Token，自动刷新"""
        if time.time() >= self.expires_at - 3600:  # 提前 1 小时刷新
            await self._refresh_token()
        return self.token

    async def _refresh_token(self):
        """刷新 access_token"""
        resp = requests.post("https://api.xiaohongshu.com/oauth/token", data={
            "grant_type": "refresh_token",
            "refresh_token": self.config["refresh_token"],
            "client_id": self.config["app_id"],
            "client_secret": self.config["app_secret"]
        })
        data = resp.json()
        self.token = data["access_token"]
        self.expires_at = time.time() + data.get("expires_in", 604800)

        # 更新配置文件
        self.config["access_token"] = self.token
        with open("config/platforms.yaml", "w") as f:
            yaml.dump(self.config, f)
```

### 3.3 B站视频审核延迟

**现象**：B站 API 返回发布成功，但视频长时间处于「审核中」状态，无法获取播放数据。

**原因**：B站对视频有严格的人工+机器审核流程，高峰期审核可能延迟数小时。

**解决方案**：

```python
async def wait_for_bilibili_review(video_id: str, max_wait: int = 7200) -> bool:
    """等待 B站视频审核通过"""
    import asyncio

    start = time.time()
    while time.time() - start < max_wait:
        status = await check_bilibili_video_status(video_id)
        if status == "passed":
            return True
        elif status == "rejected":
            raise Exception(f"B站视频审核未通过: {video_id}")
        else:
            # 审核中，等待后重试
            await asyncio.sleep(300)  # 5 分钟检查一次

    return False  # 超时
```

### 4.2 web_search 结果不稳定

**现象**：不同时间执行 `web_search` 同一关键词，返回结果差异大，部分结果质量低。

**原因**：搜索引擎结果受实时热度、地域、语言等因素影响。

**解决方案**：

```python
async def robust_topic_search(keywords: list) -> list:
    """增强型热点搜索，多源交叉验证"""
    all_results = []

    for keyword in keywords:
        # 多组搜索词
        queries = [
            f"{keyword} 热点",
            f"{keyword} 最新",
            f"{keyword} 趋势",
            f"{keyword} 2026"
        ]

        for query in queries:
            results = await agent.web_search(query, limit=5)
            all_results.extend(results)

    # LLM 去重和排序
    deduped = await agent.llm_analyze(f"""
    对以下搜索结果去重并排序，保留最有价值的 5 个话题：

    {json.dumps(all_results, ensure_ascii=False)}

    返回 JSON 数组，每个元素包含 title、url、relevance_score。
    """)

    return json.loads(deduped)
```

### 4.3 Memory 数据过期导致流水线中断

**现象**：流水线从 Memory 读取热点队列时返回空值，导致生产中断。

**原因**：热点队列设置了 TTL（2 小时），若 Cron 调度间隔超过 TTL 则数据已过期。

**解决方案**：

```python
# 方案一：延长 TTL
await agent.memory.set("hot_topics_queue", data, ttl=14400)  # 4 小时

# 方案二：设置 fallback 机制
async def get_hot_topics():
    topics = await agent.memory.get("hot_topics_queue")
    if not topics:
        # Memory 中无数据，立即重新搜索
        topics = await track_hot_topics(["AI", "科技"])
        # 同时降低 Cron 调度间隔
    return topics
```

## 5. 素材与版权

## 6. 性能与稳定性

### 6.1 批量生产内存泄漏

**现象**：连续生产 20+ 条视频后，内存占用持续增长，最终 OOM。

**原因**：Python 中未及时释放大对象（音频/视频数据），FFmpeg 子进程未正确回收。

**解决方案**：

```python
import gc
import subprocess

async def batch_produce(topics: list, batch_size: int = 3):
    """分批生产，每批后清理内存"""
    for i in range(0, len(topics), batch_size):
        batch = topics[i:i + batch_size]

        for topic in batch:
            # 生产逻辑...

        # 强制垃圾回收
        gc.collect()

        # 确保所有子进程已结束
        # 短暂休息
        await asyncio.sleep(10)

        print(f"✅ 完成批次 {i//batch_size + 1}/{(len(topics)-1)//batch_size + 1}")
```

### 6.2 网络波动导致发布失败

**现象**：视频上传过程中网络波动导致上传中断，需重新上传整个文件。

**原因**：大文件上传未实现断点续传。

**解决方案**：

```python
def upload_with_retry(file_path: str, upload_url: str, max_retries: int = 3):
    """带重试和进度跟踪的文件上传"""
    import requests
    from requests.adapters import HTTPAdapter
    from urllib3.util.retry import Retry

    session = requests.Session()
    retries = Retry(
        total=max_retries,
        backoff_factor=2,  # 指数退避: 2, 4, 8 秒
        status_forcelist=[500, 502, 503, 504]
    )
    session.mount("https://", HTTPAdapter(max_retries=retries))

    with open(file_path, "rb") as f:
        files = {"video": f}
        resp = session.post(upload_url, files=files, timeout=600)
        resp.raise_for_status()
        return resp.json()
```

### 6.3 磁盘空间耗尽

**现象**：长时间运行后，`data/videos/` 目录占用大量磁盘空间。

**原因**：未设置视频文件自动清理策略。

**解决方案**：

```python
import os
import time
from pathlib import Path

def cleanup_old_files(directory: str, max_age_hours: int = 24, max_size_gb: int = 10):
    """清理过期文件"""
    dir_path = Path(directory)
    now = time.time()

    # 按文件时间清理
    for f in dir_path.glob("*.mp4"):
        age_hours = (now - f.stat().st_mtime) / 3600
        if age_hours > max_age_hours:
            f.unlink()
            print(f"🗑️ 清理过期文件: {f.name}")

    # 按总大小清理
    total_size = sum(f.stat().st_size for f in dir_path.glob("*") if f.is_file())
    if total_size > max_size_gb * 1024**3:
        # 删除最旧的文件直到低于阈值
        files = sorted(dir_path.glob("*"), key=lambda f: f.stat().st_mtime)
        while total_size > max_size_gb * 1024**3 * 0.8 and files:
            f = files.pop(0)
            total_size -= f.stat().st_size
            f.unlink()

# 在 Cron 中配置每日清理
# 0 4 * * * hermes run cleanup-task
```
