# 入门篇 文稿

## 1. Hermes Agent 课程介绍

如果你想自己开发一个 AI 智能体，那么一定要来试一下当下最热门的这款 Hermes Agent。大家好，我是老朋友猛哥。本次带来的是当下最新最潮的开源 AI Agent 智能体——Hermes，这个名字源于希腊神话中的赫尔墨斯，进入中国后与奢侈品品牌爱马仕同名，所以你也可以叫它爱马仕智能体。

为什么敢说这款 Hermes Agent 是当下最热门、最火、最潮的智能体呢？咱们一起来看一个网站。

直接进入国内的 AI 大模型龙头企业 DeepSeek，它现在的主页面更新了，我们直接点击"加入 DeepSeek"。加入完成后会让你选择一个部门岗位，直接选择第一个最重要的，进来之后映入眼帘的就是 Agent Hermes 团队。这说明现在 DeepSeek 厂家也不局限于去做底层的大模型了，也想要制作自己独有的 Agent 智能体，而它参考的就是当下开源最热门的 Hermes。

当然会有朋友说，Claude Code、Codex 不也是当下最热门的智能体吗？那不一样。Claude Code 和 Codex 是企业不开源的、比较闭源的，而 Hermes 是开源的，有本质区别。

那么 Hermes 难道只有开源一个优点吗？肯定不是。咱们来看一下后续的介绍。

**什么是 Hermes Agent？** 它是由 Nous Research（美国的一家公司）开发的开源 AI Agent 框架。你可以基于这个 AI Agent 框架进行二次开发，制作出自己公司内部使用的 AI Agent。

除了开源的优势之外，这个 AI Agent 还具有**自进化**的功能。以前使用的智能体，想要让它变得更聪明，都需要手动维护它的 Skill 技能系统，手动去添加。而 Hermes 不需要，它自己在使用过程中就能实现自我进化。你使用得足够多，它会把一些好的工作流程自己记录下来，进化成自己的 Skill，并且还会对 Skill 进行长期维护。

除了自进化功能之外，Hermes 还具备**多平台运行**的效果。这个多平台运行对于日常使用而言，最好用的就是多网关的消息平台。它已经覆盖了 23 个平台，其中包括国内最常使用的微信、钉钉、元宝等，可以实现微信远程办公的效果。

此外，Hermes Agent 因为足够开放，完全不被模型锁定，里面有大量的模型供你选择。它也支持国内的 DeepSeek、千问、质谱，也支持在本地部署一些小模型，一键切换使用。

最后一点，它是**开源透明**的。这一点要与之前比较热门的小龙虾 Open Cloud 进行对比。后续爆出了 Open Cloud 有消息泄露的风险，而 Hermes Agent 完全开源透明，经过行业内的大佬多次审查，源代码不涉及信息泄露问题，里面所有的消息都是开放的。

这就是 Hermes Agent，如果你要自己做一个 AI Agent，一定要来学习这门课程。

**课程介绍：** 整个课程分为五大模块：

- **入门篇**：介绍 Agent 的背景、如何安装部署、如何配置管理。里面有一个供应商体系 Provider，完全不被厂商锁定，你任意选择一个模型都可以，里面也有大量免费的模型供大家选择，不需要花任何钱。
- **能力篇**：介绍 Hermes 里面核心的能力，包括会话管理、工具集、MCP 协议和持久记忆功能。Hermes Agent 有一个非常强大的效果——跨会话检索。以前使用 Agent 智能体时，头两天交流的一个 bug 问题，过两天后又想起来了，还要找之前的会话在哪儿。而 Hermes 完全不需要，它具有非常强大的跨会话搜索能力，直接新开一个会话问"我头两天解决的 bug"，它就能直接想得起来。
- **进化篇**：把 Hermes 扩展的模块都加进来，包括 Skills 技能系统、Curator 维护、Hooks 钩子、Plugins 插件和 Cron 定时任务。这一切系统构成了 Agent 自进化的效果，让它越用越聪明。
- **协作篇**：扩展网关消息平台 Gateway、Profile 多实例、任务委派和看板多 Agent 协同工作。协作篇是当前 Hermes Agent 主打的功能，效果非常赞。直接在家里面用手机微信给 Hermes 发个消息，它就能在公司的电脑上帮你完成今天的工作。
- **实战篇**：以一个 AI 驱动的技术博客自动发布系统来演示 Hermes Agent 具备的 25 大核心功能，让你把前面学习的所有能力应用在一个完整的实战当中。演示的虽然是技术博客的发布，但大家不要局限于这个功能，可以根据自己在实际工作生产中的场景进行替换。

**课程适合谁来学？**
- **AI 开发者**：开源的 Hermes Agent 最适合做 AI 开发的人来构建自主的 Agent。
- **后端开发者、运维开发者**：可以借助这个 Agent 架构来搭建更加强大的自动化工作流。
- **技术管理员**：可以做技术选型，后续构建自己的 AI Agent Hermes 团队。

**前置知识要求：**
- 有一点点 Python 基础——但完全不懂 Python 也没有关系，可以使用 Hermes Agent 绝大多数功能。
- 对命令行操作有一定了解——后续有一些操作指令在命令行里执行。0.16 版本 Hermes 也推出了桌面应用程序，使用起来更方便。
- 了解一点点 Git 基础——需要执行一些类似克隆、拉取、提交的基本操作。
- 大模型的基本概念——建议有一定了解，课程中也会介绍。
- Docker 技术——可选项，如果你不希望 Hermes 运行在 Docker 当中，不了解也完全没有关系。

以上就是 Hermes Agent 课程的介绍，欢迎大家来学习。

## 2. Hermes Agent 版本内容和软硬件需求

大家好，接下来我们就正式开始进入 Hermes Agent 的教程。

Hermes 有很多种翻译方式，原本的意思是希腊神话里的赫尔墨斯，在中国也被翻译成了奢侈品品牌爱马仕，所以叫它什么都可以。我们这里就叫它 Hermes，以它原本的英文名。

接下来要讲述的版本是 **0.16 版本**，现在是 2026 年 6 月，这是最新的版本。这个 Agent 由美国的一家 AI Agent 公司 Nous Research 开发，这家公司也是新进的企业，现在已经是几十亿美元起步，发展非常快。Hermes 是这家公司主推的产品，是一个开源自进化的 AI Agent 框架。

课程适合没有什么代码开发基础的人直接上手学，对 AI Agent 比较感兴趣，不管你是开发人员、运维人员、技术管理人员，还是做业务的人员，都可以在自己的电脑上部署这样一个 Hermes Agent。

Hermes Agent 对比其他 AI Agent 工具还有一个很大的优势：它的母公司 Nous Research 自己也做一些大模型，是一个完整的平台，这个平台上收集了大量免费的模型。也就是说大家在部署 Hermes 的时候，使用免费的模型也能够很好地运行，不用付费。如果你想要更好的效果，也可以去订阅付费，或者自己去找像 DeepSeek 这种提供 API 的大模型厂家进行付费。所以非常灵活，适合各种各样的人群。

**课程学习路线：**

1. **入门篇**：介绍 Nous Research 的公司背景、Hermes 的发展历程、Hermes Agent 项目背景介绍，带着大家从零到一在自己的电脑上安装部署、配置管理。
2. **能力篇**：涉及主流 Agent 工具都要具备的能力，包括会话管理、Dashboard、工具集、MCP 协议、上下文文件和持久记忆。使用起来要比较方便，看起来比较直观，Agent 要有一定的上下文记忆能力。
3. **进化篇**：涉及 Agent 的扩展功能，包括 Skills、Curator 维护、Hooks 钩子、Plugins 插件和 Cron 定时任务，这些都是 Hermes 比较主打的进阶功能。
4. **协作篇**：涉及 Hermes 与外部进行扩展的高级特性功能，包括消息网关、多实例、委派、看板多 Agent 协作以及高级特性（0.16 版本的新功能）。
5. **实战篇**：大型综合案例——AI 驱动的技术博客自动发布系统，可以替换成任意感兴趣的内容，涵盖 25+ 个 Hermes 的功能。

**版本说明：** 我们现在用的是 0.16 版本。正是因为它更新到了 0.16 这个最新版本，我们才会把它做成一个完整的课程来学习。0.16 版本最大的更新是对中文的支持，一方面中文做得更好了，使用起来更方便；另一方面公测了 Desktop 桌面应用程序，这对大多数非程序员而言非常关键。如果没有桌面应用程序，就要到终端命令行去使用 Agent，对程序员来说习惯了，但对非程序员用起来很别扭。

## 4. Nous Research 其他产品介绍

大家好，接下来我们就进入模块一入门篇的学习。本篇主要介绍 Hermes Agent 这个项目，以及它是如何安装和配置的。

在介绍 Hermes Agent 之前，一定要先介绍它的母公司——Nous Research。为什么要介绍这家公司呢？看起来好像跟学习课程没什么关系，但其实不是的。我专门去查了 Nous Research 这家公司，它的理念非常符合最近 Agent 兴起的原因。所以大家除了要学习 Agent 工具之外，也要了解一下现在世界格局的 AI 发展行情大概到什么阶段了。

Nous Research 是一家**开源的 AI 研究工作室**。2023 年在美国德克萨斯州成立。2023 年这个时间点，想必大家有一定概念——2022 年 11 月 ChatGPT 推出，风靡全世界。2023 年，Nous Research 由一帮在社交媒体上结识的志愿者 AI 研究员成立。

他们为什么要创业？首先是有这样一个技术模板（ChatGPT）可以朝着它去学习、去创作。国内也一样，有 ChatGPT 掀起的这样的热潮。他们做这件事是因为有一个共同的信念——要做**透明无限制的开源 AI**，挑战的是 OpenAI、Anthropic 等闭源巨头的垄断。

为什么要专门说这件事？现在不管是使用国外的 OpenAI ChatGPT、Anthropic Claude，还是国内的千问、豆包等大型商业公司做的 AI，都有一个特点——**拒绝率模型**。有很多问题是拒绝回答的，在一些特定场景里检测到敏感关键字也不回答。这里面涉及到各个国家不同的政治正确问题、和谐问题，都是有这样的限制的。

而 Nous Research 就是为了尽量降低这样的限制，最大限度地保留模型的回答能力。相当于让每一个个体都能拥有一个自我的、独立的智能体。也正是因为 Nous Research 在最开始有这样的设计理念，这家公司火得特别快，短短两三年就已经几十亿美元的市值了。

**公司名称来源：** Nous 是古希腊哲学的概念，叫"直觉与心智"，也表达了他们的使命——为了真正理解人类、服务于个体自由的智能。自由在国外是非常有号召力的，你说"你这个东西是商业的、资本的，我这个东西是个体的、自由的"，这就很有热度。

**官方宣言：** 超级智能应当服务于最大化的个体自主性和精神自由。它的发展不能只掌握在少数公司和寡头的手中。这也是为什么我们要自己去创造一个能在电脑上部署、自己拥有的 Hermes Agent。

**核心理念三个关键词：**

1. **开源**：所有的模型、代码、数据集都是公开的，社区可以自由使用、修改和分发。可能有的同学问，公司把东西都开源了，拿什么赚钱？一般做开源的都是做平台、做用户来赚钱，把一些开源的东西整理到一起，如果你要用的话，花点钱可以给你更好的服务。在国外这种公司运营场景非常常见。

2. **无限制**：这家公司推出 Hermes 最大的原因——模型拒绝率仅为 40%。AI 智能体还是要有一定的拒绝回答的东西，比如反人类的事情，现在基本上所有的 AI 都会拒绝回答你。但商业模型的拒绝率通常在 95% 以上，绝大多数问题其实很多商业模型都是拒绝回答的。Nous Research 推出 Hermes 就是尽量降低拒绝率，但反人类的事还是不能回答你，是以人类主流价值观的限度去保留模型的回答能力。

   举一个真实案例：现在是世界杯，大家会买彩票看谁赢谁输。你可以去尝试，只要是你现在能用到的主流商业模型，基本上都拒绝回答你。你问"今天晚上葡萄牙踢球几比几"，它会拒绝回答，因为涉及到博彩等。大家可以试试，真的是这样。但如果用开源的 Agent 产品自己部署一个，让它帮助分析个人生活中遇到的实际问题，那自己部署的模型肯定可以回答你。

3. **人类对齐**：不再是安全对齐拒绝回答，让模型忠诚地去执行用户的意图。我觉得这个非常重要，在未来肯定也是一种主流。

**创始团队：** 虽然说是组织的一帮志愿者，但其实个个都是大佬。有做软件工程的、数学密码学的、做大模型的、大语言模型微调的、Hermes 模型系列创建者、优化器发明人、深度学习技术领域的。团队现在大概 40 个人，非常精简。网站月访问量 45 万次。2025 年 A 轮融资，现在估值几十亿美元。

## 5. Hermes Agent 项目介绍

大家好，咱们继续学习 Hermes Agent 的入门篇。接下来介绍 Nous Research 的**产品矩阵**。

Nous Research 这家公司并不只是去做应用端的 Agent 产品，它在底层的大语言模型也做得非常好。它的大语言模型就叫 Hermes，在国内可能不是那么有名，国内通常用的是 DeepSeek、千问这种。国外主要是商业化的 ChatGPT 和 Anthropic 的 Claude。其实美国还有很多开源的大语言模型系列做得也非常好。

Nous Research 的组成成员都是技术端的大佬，他们基于 Llama 架构推出了自己的 Hermes 大语言模型。现在最新已经到了 Hermes 4（4.3），参数量非常大，实际使用效果也非常好。他们还针对快速响应和思维链推理推出了 Deep Hermes 和 Nous Code 两款产品，效果也都非常好。因为是开源模型，并不存在说到哪个厂家去买，这个模型都可以下载到，只要有算力卡就可以在自己的服务器上进行部署。

**核心技术：**

1. **分布式训练优化器（D4 协议）**：Nous Research 自研的分布式训练协议，能够将训练过程的数据传输量降低 3~4 个数量级。在保持模型精度的同时大幅降低了带宽需求，让跨地域消费级网络环境的分布式训练成为现实。2024 年 12 月，他们直播演示了用纯分布式去中心化硬件成功训练了一个 15 亿参数模型，证明了这个技术完全没有问题。

   简单解释：你在北京有几台服务器，上海有几台，深圳也有几台。想要让全公司不同地方的这些电脑集中起来共同训练一个大语言模型，谁会造成限制？就是带宽——数据传输。Nous Research 研发的分布式训练协议不是让传输速度变快，而是让传输的数据量变少。以前要传 200GB，现在只用传 200MB，效率一下子就上去了。

2. **去中心化训练网络**：构建了区块链去中心化 AI 训练基础设施，协调全球贡献者的分布式 GPU 算力。全球都可以提供算力卡（NVIDIA 4090 到 A100、H100 都可以），通过代币奖励模型算力提供者。你家里如果有一台 4090 的计算机，可以把显卡算力给到这家公司使用去中心化训练网络，它会给你一点代币来奖励你。目前属于测试阶段。

**产品定位：** Nous Research 的开放程度非常高，它的模型像 DeepSeek 一样可以直接下载，直接放到电脑上就能运行。Meta AI 提供的 Llama 也比较开放，Hugging Face 提供的 Transformer 架构非常有名。而 Claude 和 GPT 是大型商业公司。

**Hermes Agent：** 这是本课程主要讲的内容，是一个应用层框架，底层可以对接不同的模型。你想用 Hermes 本家的 Hermes 4 模型行不行？可以的，后面给大家说怎么样去用。0.16 版本还公测了 Desktop 桌面客户端，让我们使用 Hermes Agent 更加方便了。

## 6. Hermes Agent 命令行安装

大家好，我们继续来学习 Hermes Agent 入门篇的内容。接下来咱们要去介绍这款产品了。

Hermes 是一款 Nous Research 开发的开源 AI Agent 框架。开源意味着你随便可以去使用，随便可以应用于商业上的产品。它可以运行在终端、桌面应用、消息平台等等，使用起来特别方便。你不需要一定绑定在笔记本电脑上，装在消息平台上也是完全没有问题的。它自身可以自主地调用工具并且完成任务，这也是每一个 Agent 必备的功能。

它本质上是一个**拥有内置学习循环的自主 AI Agent**。人工智能主要是模仿人类的两个技能：一个是拥有记忆，一个是拥有思考能力，还有一个就是要不断地能够自我学习。AI Agent 主要自我学习的是跟你打配合的方式。Hermes 拥有从经验中创造技能、在使用过程中自我进化、搜索自己的历史对话获取上下文并跨会话建立用户画像的能力。

它可以在使用过程中进行一系列逻辑上的存储记忆。比方说你用它开发了一个比较完整的项目，在这个完整的项目中就会凝练出一些技能。下次再使用的时候，它就会想起来你上一次用过类似的功能，推荐给你使用。在使用过程中会自己生成自己的技能，自我进行改进。

它可以跑在一个 5 美元的 VPS 或 GPU 集群上，不一定要跑在你的笔记本电脑上，跑在消息平台或云服务器也完全没有问题。因为它本质上是一个 Agent 应用，本身的量级不是特别大，占用的空间也不是特别大，性能要求也不是很高。

它涉及到一系列配置文件，包括长时间使用存储下来的数据文件，都要及时保存好。如果你想把它从你的电脑换到云服务器，只需要把这些文件同时迁移过去，就像把你的 Agent 朋友从电脑迁移到了另外一个位置，使用的时候还像之前一样，它还能够对接得上。

**发展历程：**
- 2024 年中：项目启动
- 2025 年 2 月：首次开源发布，一个月获得 2200 个 GitHub Stars
- 2025 年 4 月：从 Open Cloud（小龙虾）推出了一键迁移工具
- 2026 年前两个月：密集更新，引入了工具网关，发布了 400 多个模型（其中有一些是免费的模型）
- 2026 年 6 月（现在）：发布 0.16 版本，有了 Desktop 桌面应用客户端，使用起来更加方便
- 现在超过 11 万个 Stars，是现在最活跃的开源 Agent 项目之一

**核心亮点：**

1. **技能自进化**：以前使用智能产品需要人为添加 Skill，而 Hermes 能在自己解决了复杂问题之后，将复用的流程保存为 Skill。这些 Skill 是透明的、可读可编辑的。使用完成后，它会在自己的文件夹里面生成你也能看得到的内容。

2. **跨会话持久记忆**：不像一些没有状态记录的 Agent，每次对话都要从零开始。它可以跨会话保存关键信息，建立个性化的用户画像，越用越聪明。你不管新建几个会话，它有一些核心的东西会自己记录下来——你经常出现的内容，比如你是谁、你什么工作、你要开发的内容核心要求是什么。

3. **多平台网关**：同一个 Agent 可以在不同的平台上运行，同时都拥有完整工具的访问权限，包括微信等国内平台。

4. **Profile 多实例**：可以运行多个互相隔离的 Hermes 实例，让它们互相协同工作。

5. **可扩展能力强**：能实现自我维护、自我更新的功能——Curator。可以后台自动审查你现在使用 Agent 创建的本地数据，包括技能库，然后自己合并重叠的内容，进行归档。

**与 Open Cloud 的对比：**
- 最大的差异在于**公开透明**。Hermes Agent 不涉及信息安全问题，因为不管是技能存储还是一些个人信息，都是透明的、人类可读的，你可以直接看得到。而 Open Cloud 有不透明的数据格式。
- Hermes 还有自我改进、自我更新升级维护的功能。
- 底层使用的模型非常公开，使用任何国内外的大语言模型都没有问题，用 DeepSeek、千问都可以。
- Windows 也支持 Hermes Agent，是厂家专门做的。0.14 开始专门做，0.16 专门推出了桌面应用。

这是一个安全可靠的、个人能够直接使用、随着自己的使用不断进化的桌面级智能体。非常推荐不管是 IT 部门的开发人员、业务流程人员，还是日常进行文职工作的工作人员，都可以自己去部署这样一个 Agent。

## 7. Hermes Agent 桌面应用安装和订阅配置

大家好，咱们继续学习 Hermes Agent。接下来我们要进入快速上手的环节——安装部署。

想要安装部署 Hermes 非常简单，因为官方文档里介绍了安装时使用一个完整的安装脚本。这个安装脚本会自己去 GitHub 上面拉取或更新 Hermes 的源码，我们只需要按照官方文档的要求提前安装好 Git 就可以了。

先去看一下 Hermes 的官网。进入 Hermes 的官方文档后，在右边语言的地方切换成简体中文，看起来就非常方便了。在快速入门、安装这一节。

**两种安装方式：**

1. **命令行安装**（基于 Git）：分不同的操作系统。如果是 Linux 或苹果电脑，使用对应的命令。WSL 2 是 Windows 上面的 Linux 虚拟机，不了解的同学可以忽略不计，因为新版本的 Hermes 支持 Windows 原生的操作系统，不需要再搞虚拟机。

2. **Windows 原生安装**：无需 WSL 即可运行 Hermes，包括客户端、网关、TUI 和工具都可以直接运行。使用 PowerShell 运行安装脚本即可。安装程序会帮助你处理一切——包括 uv（构建 Python 虚拟环境的工具）、Python 3.11、Node.js 以及后续的工具。还会安装一个便携式的 Git Bash。

**安装步骤：**

1. 打开 Windows PowerShell。
2. 执行安装命令，它会检查你的 Python、Git 等环境。
3. 如果电脑上没有 Git，需要先安装 Git。双击安装程序，点击 Install 即可全自动安装。安装完成后，在桌面右键可以看到 "Open Git GUI Here" 和 "Open Git Bash Here" 两个选项，说明 Git 已经装好了。
4. 执行安装脚本后，它会检查各种依赖，自动下载和安装。
5. 安装过程中如果遇到网络问题（GitHub 连接不稳定），需要自己解决一下网络问题。
6. 安装完成后会进入配置环节，让你选择大模型。刚开始安装时可以不在安装页面配置模型，后续再配置。
7. 安装路径：Windows 下安装在 `%LOCALAPPDATA%\HERMES`（即 `C:\Users\用户名\AppData\Local\HERMES`）。Linux 下安装在 `~/.hermes`。

## 8. Hermes Agent 更新和卸载

大家好，在安装完 Hermes 的命令行程序之后，接下来给大家介绍使用 Desktop 桌面应用的安装。这样就不用再打开终端，可以直接在桌面应用里进行操作。

进入 Hermes 的官方网站，左边有 "Download for Windows"，点击下载桌面应用程序。下载完成后打开，进入极简风格的桌面应用程序。直接点击 "Install Hermes" 即可，它包含刚才命令行安装的相关内容。安装完成后会启动桌面应用，右下角可以看到当前版本。后续如果不是最新版本，可以在右下角点击让它进行更新。

**配置模型：** 安装完成后，可以使用 Hermes Model 选择不同的模型和供应商，使用 Setup 运行完整的设置向导，也可以使用一键配置。推荐配置会进行一些推荐的配置，配置的东西都存在 API Key 里面。

**订阅：** 点击 Free 免费订阅，使用 GitHub 账号登录绑定即可。免费账号里面也有很多对应的模型。如果想要付费，也有对应的套餐（20 美元等），支持中国这边直接付费。

订阅完成后，会让你选择模型。建议先装这些免费的模型，因为 Hermes 里面有非常多的功能，每个模型都自己去添加很麻烦。先使用系统推荐的免费模型做打底，后续如果想要写代码、处理文件，再去切换模型。

免费配置包括：Web Search（FireCrawl）、Image（图片处理）、Text（OpenAI）、TTS、STT 等。

## 9. Hermes Desktop 基础配置切换模型

在安装部署完成 Hermes Desktop 应用并配置完模型后，接下来介绍基础使用方式。

**两种使用方式：**
1. **桌面应用**（主要推荐）：最左边有会话管理，管理所有与 Hermes Agent 聊天的内容。可以直接在对话框中提问。
2. **命令行**：打开终端（PowerShell），输入 `hermes` 进入对话终端。终端使用 TUI，实时 token 流式输出，每轮对话耗时统计等。

**桌面应用 vs 命令行：** 桌面应用底层调用的是同样的 Hermes 引擎，所有的配置、会话、技能、记忆都是与 TUI 模式完全共享的。可以白天在上面用，晚上跑自动化，使用的是同一套数据。

**常用快捷键：**
- `Ctrl + D`：退出会话
- `Ctrl + C`：中断当前操作
- 退出后使用 `resume` 命令可以回到之前的会话，它会记住刚才问了什么
- 如果直接输入 `hermes` 进入，相当于创建新会话，不会记得之前的内容

**更新：** 右下角点击即可更新，也可以在命令行输入 `hermes update`。推荐在桌面 APP 上使用，更加方便。每次升级前最好备份配置文件（两个文件：JSON 和 YAML）。

**卸载：** 使用 `uninstall` 命令，会自动卸载。如果想彻底删除所有内容，把 `%LOCALAPPDATA%\HERMES` 里面的所有文件删除即可。
