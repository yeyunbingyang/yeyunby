# 内容创作

将知识、想法和经验转化为对他人有价值的内容，建立个人影响力与知识变现渠道。核心是"持续输出 + 不断迭代"。

## 学习路径

`明确定位与受众` → `写作基础结构` → `选题与素材积累` → `多媒体创作` → `AI 工具辅助`

## 核心知识点

### 选题方法
- **痛点切入**：目标读者最困扰的问题是什么？
- **知识差切入**：我知道而大多数目标读者不知道的是什么？
- **热点嫁接**：时事热点 × 专业视角
- **选题矩阵**：横轴（受众需求强度）× 纵轴（创作竞争度）→ 选高需求低竞争区

### 写作结构
- **文章骨架**：钩子（开头）→ 核心观点（1-3个）→ 论证支撑 → 行动号召
- **钩子类型**：数字冲击（"90%的人不知道"）/ 反直觉 / 故事导入 / 问题追问
- **论证质量**：数据 > 权威引用 > 案例 > 类比 > 个人观点

### 视频/音频创作
- **脚本结构**：钩子（0-15s）→ 价值承诺 → 核心内容 → 结尾行动
- **剪辑节奏**：删除所有不必要的停顿、"嗯""啊"、重复表述
- **封面/标题**：封面决定点击率，标题决定完播率
- **工具链**：剪映/CapCut（剪辑）、Canva（封面）、不咕剪辑（字幕）

### AI 辅助创作
- **使用场景**：初稿生成、标题优化、SEO关键词、翻译润色、图片生成
- **核心原则**：AI 提速，人类决定方向和质量；输出必须经过人工判断
- **Prompt 模板**：角色 + 任务 + 格式要求 + 限制条件 + 示例
- **工具**：Claude/ChatGPT（文字）、Midjourney/Flux（图像）、Suno（音乐）

### 审美与设计基础
- **排版四原则（CARP）**：对比/对齐/重复/亲密
- **色彩基础**：主色/辅色/强调色的三色搭配法则
- **字体选择**：标题用衬线/黑体，正文用可读性强的无衬线
