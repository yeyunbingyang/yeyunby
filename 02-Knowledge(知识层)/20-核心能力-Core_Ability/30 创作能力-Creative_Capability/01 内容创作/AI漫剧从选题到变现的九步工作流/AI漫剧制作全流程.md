# AI漫剧制作全流程

> [!abstract] 一句话结论
> AI 漫剧不是“写一句提示词就出片”，而是一条有明确门禁的生产线：先证明题材有人看，再把故事改成可拍剧本；提前锁定角色、场景和声音资产；用分镜、空间调度和动作拆分降低生成的不确定性；最后通过剪辑、封面、发布和数据复盘完成闭环。

> [!warning] 信息边界
> 本文以用户提供的课程整理稿为主体，并用视频语音转写补充操作细节。转写中的明显同音错误已结合上下文校正，但没有画面或外部资料支撑的内容不自行扩写。文中涉及市场规模、平台收益、榜单数量、工具版本、模型参数和平台规则的内容均属于课程观点，未做外部核验，实际使用前应查看平台最新规则。

## 一、课程定位与完整工作流

### 1.1 课程要解决的问题

课程把 AI 漫剧从零到发布拆成一条可执行的生产线。前半段解决“做什么”和“故事能不能成立”，中段解决“如何稳定地生产角色与画面”，后半段解决“怎样把素材变成成片并获得反馈”。

最大的误区是自嗨式创作：只做自己喜欢的题材，不判断平台需求，也不验证观众是否愿意看。AI 能降低制作成本，却不能替代市场判断、叙事判断和审美判断。

### 1.2 九步生产闭环

1. **市场验证**：确认平台存在真实需求。
2. **选题与 Brief**：把模糊灵感变成 AI 可执行的创作任务。
3. **剧本生成与诊断**：建立冲突、钩子、共鸣、爽点和反转。
4. **角色、场景与声音资产**：在开拍前锁定全局复用的元素。
5. **分镜与空间调度**：把文字转换成可理解、可生成的镜头。
6. **画面生成与表演控制**：拆小动作，明确运镜、神态和身体语言。
7. **剪辑与声音设计**：让观众看得懂、看得爽、愿意继续看。
8. **封面、发布与变现**：获得点击并接入平台收益路径。
9. **数据复盘**：用点击率、留存和反馈修正下一轮选题与制作。

### 1.3 每一步都要有门禁

| 阶段 | 必须回答的问题 | 合格输出 |
| --- | --- | --- |
| 选题 | 平台要不要、观众懂不懂、AI 做不做得出？ | 已验证的题材组合 |
| 剧本 | 主线能否一句话说清，前 15 秒是否有冲突？ | 可拆分镜的分集剧本 |
| 资产 | 角色、场景、声音能否跨镜头稳定复用？ | 最小资产库 |
| 分镜 | 去掉台词后，画面是否仍能说明发生了什么？ | 连贯的分镜表与关键构图 |
| 画面 | 每个片段是否只有一个明确动作？ | 可剪辑的短视频片段 |
| 后期 | 无声、纯声音和手机小屏检查是否都成立？ | 可发布母版 |
| 发布 | 封面是否在一秒内传达角色、冲突和题材？ | 多版本封面与发布信息 |
| 复盘 | 哪一环真正影响了点击、留存和转化？ | 下一轮改进清单 |

## 二、市场验证与选题

### 2.1 目标、输入与输出

- **目标**：用可观察的数据代替个人偏好，找到有需求且适合 AI 制作的题材。
- **输入**：平台榜单、搜索趋势、用户评论、行业报告和同赛道爆款。
- **输出**：题材组合、目标受众、对标样本及其结构拆解。
- **进入下一步的门槛**：同时满足“平台有需求、观众看得懂、AI 做得出”。

### 2.2 三重验证体系

| 验证层 | 观察对象 | 具体动作 | 要回答的问题 |
| --- | --- | --- | --- |
| 平台规模 | 抖音高点赞视频、红果热门榜和高分榜 | 记录题材、点赞、热度、上新数量和平台扶持 | 这个赛道是否真的有流量？ |
| 市场趋势 | 第三方数据平台和行业报告 | 查询搜索指数、相关词、趋势曲线和供需变化 | 需求是在增长还是衰退？ |
| 用户反馈 | 平台评论及话题讨论 | 汇总观众喜欢的爽点与常见槽点 | 观众为什么留下或划走？ |

课程提到可用蝉妈妈等第三方平台查询关键词数据，也可参考动画微短剧行业报告。第三方额度、榜单口径和报告结论会变化，不能把一次查询当作长期事实。

> [!note] 对课程观点的修正性理解
> “供给多”可以作为平台重视程度的信号，但不能直接等同于需求大或作品一定有价值。实际执行时，应把供给量、播放表现、增长趋势和用户反馈交叉验证。

### 2.3 三类高需求题材

课程依据当时的红果题材标签报告，重点讨论了以下三类：

| 题材 | 情绪价值 | 常见标签 | 制作特点 |
| --- | --- | --- | --- |
| 逆袭 | 羞辱后的反击和释放 | 打脸虐渣、马甲、神豪、战神归来、重生穿越 | 进入情绪快，前 15 秒必须迅速建立憋屈 |
| 总裁/豪门 | 身份差、权力差和关系张力 | 闪婚、契约婚姻、豪门恩怨、真假身份、追妻 | 办公室、豪宅、医院、车内等现代场景相对容易生成 |
| 现代言情 | 情感共鸣和关系期待 | 女性成长、亲情、甜宠、重生 | 受众入口直观，适合与逆袭、家庭伦理组合 |

课程还提到武侠、谍战、权谋、系统等供给较少的题材。低供给可能意味着窗口，也可能意味着需求不足或制作难度过高，因此新手不应仅凭“冷门”入场。

### 2.4 组合标签，而不是只选一个词

题材越具体，后续 Brief、剧本、封面和标题越容易保持同一方向。

案例：

> 《重生 18 岁，这声太奶你先叫为敬》  
> = 逆袭爽感 + 重生 + 亲情 + 家庭伦理 + 大女主 + 银发觉醒 + 养老院危机

### 2.5 爆款对标拆解

1. 在免费短剧平台按题材和标签寻找对标。
2. 从同赛道中收集 5–10 部高热度作品。
3. 建表记录标题、封面、前 15 秒、主角身份、核心冲突、爽点和每集钩子。
4. 将链接、简介或脚本交给大模型拆解结构。
5. 只迁移情绪路径、节奏、标签组合和钩子方式，不复制人设、台词和桥段。
6. 把拆解结论写回自己的 Brief。

**爆款结构拆解提示词**

```text
请拆解这部短剧的爆款结构，而不是复述剧情：

1. 它属于什么题材，使用了哪些组合标签？
2. 标题如何制造身份差、冲突或悬念？
3. 前 15 秒用了什么事件让观众进入情绪？
4. 主角的核心欲望和阻力分别是什么？
5. 爽点、泪点和反转如何排列？
6. 每集结尾用什么新危机或身份信息留人？
7. 哪些结构可以迁移，哪些具体设定不应照搬？

最后输出：
- 一句话结构；
- 情绪曲线；
- 可迁移手法；
- 原创改写方向；
- 适合写入 Brief 的信息。
```

### 2.6 选题验收

- [ ] 至少有三类证据支持这个题材，而不是只凭个人兴趣。
- [ ] 已明确目标受众及其核心情绪需求。
- [ ] 已收集 5–10 个同赛道对标。
- [ ] 能用一句话说清题材组合和主要卖点。
- [ ] 关键角色、场景和动作在现有 AI 能力范围内。
- [ ] 没有明显版权、肖像、血腥或擦边风险。

## 三、Brief 与剧本生成

### 3.1 目标、输入与输出

- **目标**：把选题变成可以继续拆资产和分镜的剧本。
- **输入**：题材组合、目标受众、对标结构和原创设定。
- **输出**：Brief、分集剧本、角色设定、场景和动作信息。
- **门槛**：剧本不仅“好读”，而且每一段都能被转换成画面。

### 3.2 Brief 是创作任务书

Brief 越具体，AI 需要猜测的部分越少。至少包含：

| 字段 | 需要写清的内容 |
| --- | --- |
| 故事名 | 标题暂定稿与题材信号 |
| 类型标签 | 主标签、辅标签和情绪价值 |
| 目标受众 | 年龄、兴趣和期待获得的情绪 |
| 主角 | 身份、欲望、缺陷、能力和视觉特征 |
| 对手 | 与主角的利益冲突及压迫方式 |
| 故事大纲 | 起点、升级、高潮、反转和结尾 |
| 核心冲突 | 谁要什么、谁在阻止、失败代价是什么 |
| 视觉落点 | 可生成的关键场景、道具和动作 |
| 限制条件 | 集数、时长、画幅、风格和合规边界 |

**案例 Brief 核心**

- **剧名**：《重生 18 岁，这声太奶你先叫为敬》
- **主角**：林清兰，80 岁的家族创业者，魂穿 18 岁孤女林兰。
- **主线**：夺回晴岚养老院 → 整顿纨绔重孙顾默笙 → 重振顾家事业。
- **核心反差**：年轻的外表，老练而威严的内核。
- **主要冲突**：顾默笙被赵家设局，企图用养老院和顾氏资产偿债。

### 3.3 工具选择与两种输入方式

| 工具 | 适合任务 | 使用前提 |
| --- | --- | --- |
| Gemini | 发散第一版故事，补充画面和情绪描写 | 创作者能判断节奏与文字质量 |
| ChatGPT | 整理结构、压缩支线、改写成可分镜格式 | 已有较明确的故事方向 |
| 小云雀短剧 Agent 2.0 | 从剧本继续拆人物、场景、分镜和制作资产 | 希望使用一体化生产管线 |

课程演示了小云雀的两种入口：

1. **上传已有剧本**：解析长剧本，提取视频风格、画面比例、摘要、分集场景、动作、旁白和镜头信息。
2. **AI 生成剧本**：把 Brief 直接交给 Agent，生成分集剧本并进入后续资产流程。

课程对具体模型、可输入参考数量、视频时长和合规能力的描述可能随版本变化，使用前应重新确认。

### 3.4 初稿诊断：方向对，不等于能拍

课程案例的 Gemini 初稿虽然方向正确，但第一次冲突用了大量台词回忆顾默笙的童年，造成两类问题：

- **剧情弱**：事件没有继续发展，只是在解释背景。
- **节奏断**：文本适合小说阅读，却不适合短剧观众快速进入冲突。

正确修法不是整篇推翻，而是先定位具体问题，再让 AI 做局部修改。

### 3.5 「金钩泪爽转」节奏公式

| 要素 | 含义 | 检查问题 |
| --- | --- | --- |
| 金 | 黄金 15 秒开局 | 是否立刻出现危机、羞辱或高价值信息？ |
| 钩 | 悬念钩子 | 观众为什么必须继续看？ |
| 泪 | 情绪共鸣 | 角色失去了什么，观众为何在乎？ |
| 爽 | 情绪释放 | 主角如何反击、揭露或翻盘？ |
| 转 | 意外反转 | 结论如何被新信息重新解释？ |

**剧本生成提示词**

```text
你是一名擅长竖屏漫剧的短剧编剧。

请根据下方 Brief 输出一份[集数]集剧本，并遵循“金钩泪爽转”：
- 前 15 秒用具体事件制造强冲突；
- 抛出身份或目标悬念；
- 用行动而非长篇解释建立情绪共鸣；
- 在高潮完成可视化的反击或打脸；
- 每集结尾增加新危机、身份线索或二层反转。

输出要求：
1. 每集标明场景、出场角色、动作、台词和镜头目的；
2. 减少心理描写，所有信息尽量变成可拍的动作、道具和画面；
3. 台词简短、有张力，不用长篇背景说明；
4. 每个段落都能直接拆成分镜；
5. 不增加与主线无关的恋爱线或工具人角色。

[粘贴 Brief]
```

### 3.6 剧本验收与定向修复

- [ ] 主线能否用一句话说清楚？
- [ ] 第一集前 15 秒是否出现明确冲突？
- [ ] 每集结尾是否有继续观看的理由？
- [ ] 主角行为是否符合人设，而不是为推进剧情突然降智？
- [ ] 角色姓名、年龄、关系和资产信息是否一致？
- [ ] 每段内容是否能拆成画面、动作、台词或道具？
- [ ] 是否存在只适合小说、不适合视频的心理描写？
- [ ] 是否标记潜在违规、版权或肖像风险？

**剧情太散**

```text
请删除与主线无关的支线。全剧只围绕以下三件事推进：
1. 夺回晴岚养老院；
2. 整顿纨绔重孙顾默笙；
3. 重振顾家事业。

不要加入无关恋爱线，也不要增加对主线没有推动作用的角色。
```

**太像小说**

```text
请将剧本改成 AI 漫剧可制作的格式：
- 删除无法直接拍摄的心理描写；
- 增加具体场景、角色动作、表情、道具和台词；
- 每个段落只表达一个可拆成分镜的事件；
- 标出每个镜头要让观众看懂的信息。
```

## 四、角色、场景与声音资产

### 4.1 目标、输入与输出

- **目标**：让角色、场景、道具和声音一次建立、全局复用。
- **输入**：通过验收的剧本。
- **输出**：最小角色库、场景库、声音库、道具清单和分集资产表。
- **门槛**：不同镜头中能认出同一个角色和地点，资产数量不会造成绑定混乱。

### 4.2 先建立最小资产库

AI 没有跨生成任务的天然记忆。角色换脸、服装漂移和场景变形，往往不是“模型突然变差”，而是没有提供稳定参考。

第一轮只制作首集真正使用的资产。不要一次生成日常装、校服、礼服、战损装、谈判装和回忆装等七八套造型；资产越多，后续分镜越容易误绑。先跑通第一集，剧情推进到新阶段时再补资产。

### 4.3 角色资产流程

1. 从剧本提取每个角色的年龄、外貌、气质、服装和剧情阶段。
2. 生成基础形象图。
3. 建立角色资产卡，集中记录正脸、侧脸、全身、服装、色彩和禁改项。
4. 为不同年龄或剧情阶段建立独立版本，例如 80 岁林清兰与 18 岁林兰。
5. 在创作画布中用角色节点连接到新图节点，让生成任务明确引用哪个角色。
6. 只修跑偏部分，不整组重抽。

**林兰的核心验收标准**

> 年轻的外表，老奶的内核。

- 银白发与约 18 岁外貌是正确方向。
- 服装不能变成仙侠礼服或校园偶像风。
- 气质应克制、沉稳、有阅历，而不是单纯“漂亮”。

**角色验收**

- [ ] 外貌是否符合核心人设？
- [ ] 年龄是否准确？
- [ ] 服装是否符合题材和剧情阶段？
- [ ] 气质是否支持角色功能？
- [ ] 不同阶段的造型是否容易混淆？
- [ ] 正侧面、远近景下的关键识别点是否一致？

**局部修改策略**

| 跑偏类型 | 修正动作 |
| --- | --- |
| 性格不鲜明 | 保留脸型和服装，只补气质、眼神和姿态 |
| 服装跑偏 | 锁定五官和发型，只重做服装 |
| 年龄不对 | 锁定角色识别点，单独修年龄与皮肤状态 |
| 构图不对 | 保留角色参考，只改景别、机位和站位 |

### 4.4 创作画布的工作方式

- **节点**存放角色图、场景图、灵感素材、参考图、音频和视频。
- **连线**表达引用关系，例如“新画面要沿用角色 A、角色 B 和场景 C”。
- 中间草稿和参考依据保留下来，方便回溯修改。
- 生成多人画面时，先连接全部角色和场景，再写构图指令。

课程还演示了光影、景别、俯仰角和三视图等导演工具。720°参考图可以转到需要的角度直接截图，用于补充背面或侧面参考，减少重复生成。

### 4.5 场景资产：场景也要参与叙事

**场景提示词公式**

```text
构图逻辑 + 主体元素 + 风格标签 + 后缀参数
```

同一部剧应复用同一套风格标签、光影和色调。Agent 可从剧本识别地点并批量生成场景库，随后把每集使用的角色、场景和镜头数量对应起来，减少误绑和重复抽卡。

**晴岚养老院大门应包含**

- 老旧铁门和“晴岚养老院”牌匾；
- 门口公告栏、墙皮脱落和生活痕迹；
- 与剧情有关的工程车、拆迁告示或施工围栏；
- 能容纳老人、施工队、顾默笙和林兰的空间关系。

**场景验收**

- [ ] 观众能否一眼看出地点？
- [ ] 场景是否包含剧情需要的关键信息？
- [ ] 拿走人物后，环境是否仍能讲故事？
- [ ] 画风、光影和色调是否统一？
- [ ] 是否过度美术化，却不服务剧情？
- [ ] 是否方便放入竖屏分镜和多人站位？

### 4.6 声音资产

AI 默认配音容易变成标准普通话朗读，缺少年龄、气场和性格。声音资产应记录：

- 音色、年龄、语速和情绪范围；
- 角色常态与爆发状态；
- 台词停顿、重音和呼吸；
- 可复用的声音文件及其角色绑定。

课程以即梦 AI 配音为例，为老年男性选择“老年、普通话、多情感、威严”等设定，获得低沉、缓慢且有压迫感的声音。具体音色名称和功能应以当前产品为准。

## 五、分镜设计与空间调度

### 5.1 目标、输入与输出

- **目标**：把剧本文字转换成位置明确、信息明确、动作明确的镜头。
- **输入**：剧本、角色库、场景库和声音资产。
- **输出**：分镜表、关键分镜图、站位参考和首尾帧关系。
- **门槛**：拿掉台词，观众仍能大致看懂事件和情绪变化。

### 5.2 分镜验收

- [ ] 镜头顺序是否与剧本一致？
- [ ] 角色是否绑定正确？
- [ ] 场景和剧情阶段是否匹配？
- [ ] 情绪是否能从动作与构图中看出来？
- [ ] 重要道具是否出现且位置合理？
- [ ] 每集结尾是否留下画面钩子？
- [ ] 同一角色是否反复左右跳位？

反馈必须具体。不要说“画面更好看”，要说：

> 这场戏的重点是林兰第一次压住顾默笙。减少无关环境镜头，把镜头集中在顾默笙举合同施压、老人后退、林兰从人群后走出、顾默笙转头四个动作上。

### 5.3 3D 导演台解决什么问题

适用于：

1. 多人站位难以用文字说清；
2. 同一场景的多机位方向不稳定；
3. 动作、视线和前后遮挡需要预排；
4. 长剧情中人物位置容易连续性出错。

**养老院冲突的五步调度**

1. **建立空间**：在画布中新建 3D 导演台节点。
2. **添加对象**：用不同颜色素模区分林兰、顾默笙、施工队和老人，并加入轿车、铁门、围栏和合同等道具。
3. **安排站位与姿势**：顾默笙站在轿车旁面对老人，林兰从施工队后方走出；顾默笙身体前倾并拿合同，林兰站直、平稳前行。
4. **设置机位**：
   - 远景交代养老院、老人和施工危机；
   - 中景表现顾默笙拿合同施压；
   - 低角度表现林兰年轻外表与强气场的反差。
5. **截图回传**：按最终横竖屏比例截图，发送到画布，并与角色图和场景图一同作为生成参考。

**空间替换提示词**

```text
根据 3D 参考图的站位生成分镜图：
- 将紫色人偶替换为林兰；
- 将绿色人偶替换为顾默笙；
- 将蓝色人偶替换为施工队；
- 将灰色群体替换为养老院老人。

严格保留人物的位置、姿势、朝向、前后关系和主要道具。
场景为晴岚养老院大门，现代都市写实风，冷灰色自然光。
```

已有 720°场景图时，可将其导入导演台作为背景，使同一地点的多镜头方向更稳定。

### 5.4 首尾帧与智能分镜图

- **首尾帧**解决相邻两个镜头怎样顺畅接上：用前一个镜头尾帧作为下一个镜头首帧参考。
- **智能分镜图/智能预演**解决一整组镜头怎样统一规划：先生成关键分镜，再把分镜图插入各片段作为参考，最后批量生成视频。

生成智能分镜图后，逐个检查：

- 人物位置和左右方向是否连续；
- 林兰是否始终从同一方向走出；
- 顾默笙是否一直位于轿车附近；
- 场景地标和重要道具是否稳定；
- 镜头是否真正服务当前剧情重点。

先预演再生成，通常比盲目批量抽卡更省成本。

## 六、画面生成、运镜与表演控制

### 6.1 目标、输入与输出

- **目标**：生成可用、连续且有表演的短片段。
- **输入**：分镜、角色与场景参考、动作和镜头指令。
- **输出**：每段 2–3 秒左右、动作单一且可剪辑的视频片段。
- **门槛**：角色没崩、动作完成、情绪可见、镜头没有贪多。

### 6.2 化整为零

不要要求一个长镜头同时完成转头、说话、走路、拿合同、情绪变化和复杂运镜。把它拆成多个片段：

- 林兰转头说话；
- 顾默笙抬手举起合同；
- 老人害怕后退；
- 林兰从人群后方走出；
- 顾默笙回头并露出轻蔑表情。

每个片段只完成一个动作，后期用剪辑建立连续性。

### 6.3 把情绪翻译成身体语言

抽象词对 AI 的约束很弱。把“嚣张”“有气场”拆成可观察的神态、姿势和运动。

| 抽象情绪 | 可执行描述 |
| --- | --- |
| 顾默笙嚣张 | 嘴角单侧上扬，眉眼下压，视线从上向下扫过老人，神情不耐烦而轻蔑 |
| 林兰有气场 | 没有笑意，目光稳定直视前方，下巴微收，视线放平，表情克制 |
| 纨绔起身 | 手撑车头缓慢站直，身体微歪，头高高扬起 |
| 太奶出场 | 仪态端庄，步伐缓慢均匀，从人群让开的通道中走过 |
| 老人愤怒又无力 | 手指攥紧，肩背绷紧，眼眶微红，但脚步迟疑 |

### 6.4 运镜 16 字口诀

> 紧张推进，离别拉远，爽点快切，泪点慢推。

| 情绪目的 | 镜头策略 | 注意事项 |
| --- | --- | --- |
| 紧张与压迫 | 缓慢推进、适当低角度 | 不同时叠加旋转和摇镜 |
| 离别与孤独 | 拉远并留出空白空间 | 让人物在画面中变小 |
| 爽点爆发 | 快切、硬切、动作最强点 | 节奏快不等于镜头乱 |
| 泪点沉淀 | 慢推、停顿、特写 | 给情绪留时间 |

一个镜头只选择一种主要运镜。顾默笙在车旁施压可用固定机位，林兰第一次开口压住全场可用缓慢推进。不要把推进、旋转、摇镜和跟拍全部塞进同一个镜头。

### 6.5 先设计情绪，再安排镜头

短剧并非每秒都要大动作。第一集养老院冲突可以按 20 秒左右设计：

| 时间 | 事件 | 观众情绪 |
| --- | --- | --- |
| 0–3 秒 | 养老院大门与拆迁危机 | 明白地点和危险 |
| 4–10 秒 | 顾默笙用合同施压老人 | 愤怒 |
| 11–15 秒 | 林兰的声音打断全场 | 悬念 |
| 16 秒后 | 林兰登场并指出合同问题 | 爽感与身份钩子 |

### 6.6 画面验收

- [ ] 角色身份和服装是否正确？
- [ ] 动作是否从起点走到终点？
- [ ] 表情和身体语言是否支持台词？
- [ ] 镜头中是否只有一种主运镜？
- [ ] 是否存在多余空帧、肢体错误或表情崩坏？
- [ ] 与前后镜头的视线、位置和运动方向是否连续？
- [ ] 最有效的 1–2 秒是否足以进入剪辑？

## 七、剪辑、字幕、音乐与导出

### 7.1 目标、输入与输出

- **目标**：把生成片段组织成清楚、有情绪、有留存的成片。
- **输入**：视频片段、台词、配音、音乐和字幕。
- **输出**：可发布母版。
- **门槛**：画面、声音和手机小屏三个维度分别检查均成立。

### 7.2 两种组装方式

| 方式 | 适用情况 |
| --- | --- |
| 一键合成 | 素材都在同一生产管线内，角色、配音和镜头基本过关 |
| 剪映手动拼接 | 视频、配音和音乐来自不同工具，或需要更精确控制 |

无论使用哪种方式，剪辑目标都是让观众“看得懂、看得爽、愿意多看一集”。

### 7.3 粗剪只做三件事

> 鹅城只干三件事：删空帧、排顺序、剪最有效部分。

1. 删除空帧、失败动作和明显崩坏镜头。
2. 按剧情因果和分镜顺序排列。
3. 每个镜头只保留动作最有效的部分。

例如冷笑镜头前一秒尚未进入状态，后一秒表情已经崩坏，只保留中间最稳定的 1.5 秒。

### 7.4 三次感官隔离检查

1. **无声检查**：关闭声音，只看画面，确认养老院被拆、顾默笙施压、老人受阻、林兰出现反压这一因果链仍然成立。
2. **声音检查**：闭眼只听旁白、台词和音乐。台词密集时主动降低或暂停音乐，让关键信息干净出现。
3. **手机小屏检查**：在最终竖屏尺寸下检查人脸、字幕大小、表情辨识度和封面文字。

单独关闭其他感官，可以更准确地发现画面叙事或声音层次的问题。

### 7.5 转场、调色、字幕与音乐

**转场**

- 日常对话可用 0.3–0.5 秒叠化或淡入淡出。
- 打脸、冲突和动作爆发优先硬切。
- 不要为了“高级感”给每个镜头加转场；硬切是常规叙事手段。

**调色**

- 先校正曝光、色温和对比度。
- 再轻调饱和度与锐化，使人物轮廓清楚。
- 目标是把不同批次生成的素材拉回同一个片场的视觉基调，而不是重新创造一种风格。

**字幕**

- 用剪映识别字幕后逐句校对。
- 专有名词、角色名和同音字必须人工检查。
- 字幕应以手机小屏可读为标准。

**音乐**

- 铺垫阶段可用舒缓、低沉的弦乐或偏小调氛围。
- 高潮和反击阶段提高节奏与强度。
- 关键台词出现时可以暂时停掉音乐。
- 优先使用平台授权素材或自己生成的免版权音乐。

### 7.6 导出参数

| 参数 | 建议 |
| --- | --- |
| 竖屏 | 1080 × 1920 |
| 横屏 | 1920 × 1080 |
| 4K | 3840 × 2160，仅在原始素材确实支持时使用 |
| 普通 1080P 码率 | 8–12 Mbps |
| 快速运镜或特效较多 | 12–16 Mbps |
| 格式 | MP4 |
| 编码 | H.264；需要较小体积时可考虑 H.265 |

不要在导出阶段强行放大低清素材。

## 八、封面、发布、变现与合规

### 8.1 封面是信息流中的一秒决策

**封面公式**

```text
核心角色 + 高能瞬间 + 画风统一 + 吸睛文字 + 强烈对比
```

1. 选择最有辨识度、情绪最强的正脸角色。
2. 使用对峙、打脸或危机等最高能瞬间。
3. 封面画风必须与正片一致。
4. 用主体亮、背景暗或冷暖对冲突出角色。
5. 在留白处加入大字号剧名或冲突文案。
6. 生成 3–5 个版本，发送到手机相册缩小比较。

**封面提示词**

```text
生成一张竖屏 AI 漫剧封面。

前景：林兰，参考图一，18 岁少女外貌，银白色头发，
眼神清冷，下巴微收，气场克制而强。

背景右侧：顾默笙，参考图二，年轻纨绔男性，
站在黑色轿车旁，表情轻蔑。

两人形成对峙关系，场景为晴岚养老院大门。
冷灰色自然光，现代都市写实风，强冲突氛围，
顶部留出清晰空白区域方便加标题。
不要真实品牌，不要明星脸，不要过度奇幻。
```

可测试的封面文案：

- 18 岁太奶杀回来了
- 纨绔重孙被太奶制服

最终选择标准不是电脑大图是否精致，而是手机小图中谁最醒目、冲突最清楚。

### 8.2 发布前检查

- [ ] 标题、封面和前 15 秒传达的是同一个承诺。
- [ ] 字幕、角色名和专有名词已校对。
- [ ] 音乐、字体、图片和素材拥有可用授权。
- [ ] 没有名人肖像、刻意模仿五官或真实品牌误用。
- [ ] 没有擦边、血腥和平台明令禁止的内容。
- [ ] 已保存无水印母版、封面源文件和发布版本。

### 8.3 课程讨论的变现路径

| 路径 | 作用 | 风险与前提 |
| --- | --- | --- |
| 免费平台流量分成 | 作为基础收入来源 | 取决于平台规则、播放质量和分账政策 |
| 创作激励 | 按平台计划获得奖励 | 需满足账号和内容门槛 |
| 广告植入 | 放大已有影响力 | 需要稳定受众和合规植入 |
| 付费解锁 | 用后续剧情变现 | 依赖平台能力与强留存 |
| 官方赛事 | 获得奖金和曝光 | 活动时间、规则和权益会变化 |

课程建议的闭环是：先通过免费平台流量分成打底，再同步发布到其他短视频平台扩大影响力，最后探索广告和其他收入。这里不是收益承诺，发布前必须核对最新平台政策。

### 8.4 发布后的复盘

| 指标 | 可能对应的问题 | 下一轮动作 |
| --- | --- | --- |
| 封面点击率低 | 封面冲突不清、角色不突出、文字不可读 | 重做 3–5 个封面版本 |
| 前 3 秒流失高 | 地点、危机或人物关系进入太慢 | 提前展示危机和高价值画面 |
| 15 秒留存低 | 冲突没有升级，台词解释过多 | 压缩背景，增加动作和悬念 |
| 集尾跳失 | 钩子太弱或答案已经给完 | 增加新危机、身份或代价 |
| 评论集中吐槽角色漂移 | 资产参考和绑定不稳定 | 回到资产库与分镜阶段修正 |
| 完播尚可但转化低 | 标题、合集、更新节奏或变现入口不清 | 调整发布包装与承接路径 |

复盘不是只看总播放量，而是定位“哪一道生产门禁失效”。

## 九、案例剧本完整拆解

### 9.1 核心设定

- **林清兰**：80 岁上海商人，从卖豆腐起家建立商业帝国。
- **前世危机**：家族产业被后代瓜分，顾家衰败，晴岚养老院被纨绔重孙顾默笙拿去抵债。
- **魂穿**：林清兰在 80 岁生日当天被气倒，醒来后成为 18 岁孤女林兰。
- **行动目标**：夺回养老院、整顿顾默笙、重振顾家。
- **角色反差**：18 岁少女的外貌与 80 岁家族掌舵者的经验和威严。

### 9.2 第一阶段：养老院门口建立冲突

顾默笙带施工队来到晴岚养老院，声称手续齐全、当晚必须清场。老人们阻拦无效，林兰出现，以家规和合同漏洞打断施工。

这一段承担四个任务：

1. 用拆迁危机交代地点和失败代价；
2. 用顾默笙压迫老人建立观众愤怒；
3. 用林兰熟知顾家家规制造身份悬念；
4. 用合同造假证据完成第一次反击。

可视化证据包括：捐赠地契的限制条款、印章版本与断点、施工授权和现场视频。其叙事作用是让林兰的反击来自能力，而不是突然开挂。

### 9.3 第二阶段：揭露赌债骗局

林兰判断顾默笙并非单纯败家，而是被赵家利用境外空壳公司、异常日期、假见证人和会所影像设局。她迫使对方交出视频、借据和假合同，并把事件从私人冲突升级为针对顾家的系统性阴谋。

这一阶段实现：

- 顾默笙从纯反派变成“犯错但可被拯救的人”；
- 林兰从救养老院转向重整顾家；
- 敌人从顾默笙升级为赵家；
- 结尾自然指向祠堂认亲。

### 9.4 第三阶段：祠堂相认与角色转化

林兰要求顾默笙先正衣冠、再跨门槛，并准确说出他八岁时在祠堂放炮、被罚抄家规的私密往事。顾默笙确认她就是太奶奶，但林兰先要求他认错，而不是立刻完成温情团聚。

角色弧光由此成立：

> 反派工具人 → 被打服 → 认识错误 → 获得接纳 → 忠犬战友

“先打服，再给糖”既提供爽感，也给亲情共鸣一个落点。

### 9.5 第四阶段：赵家债权会与第二季钩子

赵家宣布接管顾氏产业，林兰逐条指出赌债公司成立日期、借款合同和会所监控存在的问题，并以养老院捐赠地契继续反击。赵家暂时退场，却开始调查林兰与林清兰的关系。

结尾同时保留两条钩子：

- 外部危机：赵家仍会继续争夺顾氏。
- 身份危机：对手开始怀疑 18 岁林兰的真实身份。

### 9.6 案例为何适合 AI 漫剧

- 地点集中：养老院、会所、祠堂和债权会，资产可复用。
- 冲突具象：合同、地契、印章、债务和家规都能转成画面。
- 角色少而鲜明：林兰、顾默笙、赵家对手和老人群体。
- 情绪清晰：受压 → 反击 → 揭局 → 认亲 → 更大危机。
- 视觉反差强：年轻少女以家族长辈的姿态压制纨绔重孙。

## 十、提示词、检查表与最小可行 SOP

### 10.1 通用画面提示词骨架

```text
[角色与固定资产参考]
+ [场景与时间]
+ [单一动作]
+ [具体神态和身体语言]
+ [景别与一种主要运镜]
+ [光影、色调和画风]
+ [必须保留的空间关系与道具]
+ [禁止项]
```

示例：

```text
参考林兰角色资产与晴岚养老院场景资产。
林兰从施工队后方让开的通道中缓慢走出，
步伐均匀，背部挺直，眼神稳定直视顾默笙，
下巴微收，脸上没有笑意。
低角度中景，镜头缓慢推进。
现代都市写实风，冷灰色自然光。
保留老人、黑色轿车、合同和施工围栏的前后关系。
不要改变发色、服装、年龄和人物左右方向。
```

### 10.2 分阶段总检查表

**选题**

- [ ] 有平台、趋势和用户反馈三类证据。
- [ ] 标签组合明确，目标受众明确。
- [ ] 已完成对标结构拆解。

**剧本**

- [ ] 主线一句话可说清。
- [ ] 前 15 秒有冲突。
- [ ] 每集有钩子。
- [ ] 所有段落可转成画面。
- [ ] 合规风险已标记。

**资产**

- [ ] 首集必要角色、场景、声音和道具已建立。
- [ ] 角色年龄、服装、气质和剧情阶段正确。
- [ ] 场景地标、光影和画风统一。
- [ ] 没有为了“以后可能用”制造过多资产。

**分镜与画面**

- [ ] 去掉台词仍能看懂事件。
- [ ] 多人站位、视线和左右方向连续。
- [ ] 每个片段只有一个核心动作。
- [ ] 情绪已翻译为表情和身体语言。
- [ ] 每个镜头只使用一种主要运镜。

**后期与发布**

- [ ] 无声检查通过。
- [ ] 只听声音检查通过。
- [ ] 手机小屏检查通过。
- [ ] 字幕、专有名词和版权已核对。
- [ ] 封面有 3–5 个版本并在手机缩略图中测试。
- [ ] 保存母版和发布版本。

### 10.3 最小可行实践

第一次不要直接制作整季。用一个 20–60 秒片段验证全流程：

1. 选择一个已验证的题材组合。
2. 写一页 Brief。
3. 只写一个包含“压迫—反击—钩子”的场景。
4. 只建立两名核心角色、一个场景、一套声音。
5. 拆成 6–10 个分镜，每个镜头只做一个动作。
6. 用 3D 站位或草图先解决空间关系。
7. 先生成关键镜头，确认风格和角色稳定后再补齐。
8. 完成粗剪、三次检查、字幕、音乐和封面。
9. 发布后记录点击率、前 3 秒、前 15 秒、完播和评论。
10. 只修复数据暴露出的最大问题，再进入下一集。

### 10.4 完整 SOP

```text
平台与用户研究
→ 题材组合
→ 对标拆解
→ Brief
→ 分集剧本
→ 剧本门禁
→ 最小资产库
→ 分镜表
→ 空间调度
→ 智能分镜预演
→ 单动作片段生成
→ 粗剪
→ 无声/声音/小屏检查
→ 字幕、音乐、调色
→ 封面多版本测试
→ 发布与变现
→ 数据复盘
→ 回到选题、剧本或生产门禁修正
```

## 核心记忆口诀

| 口诀 | 用途 |
| --- | --- |
| 平台有需求，观众看得懂，AI 做得出 | 选题门禁 |
| 金钩泪爽转 | 剧本节奏 |
| 年轻的外表，老奶的内核 | 角色验收 |
| 构图 + 主体 + 风格 + 参数 | 场景提示词 |
| 紧张推进，离别拉远，爽点快切，泪点慢推 | 运镜选择 |
| 鹅城只干三件事 | 粗剪：删空帧、排顺序、剪有效部分 |
| 无声看、闭眼听、小屏验 | 成片三次检查 |

> [!success] 最终原则
> 不要把“生成了很多素材”误认为“完成了一部作品”。先用最小资产和最短样片跑通生产闭环，确认故事、角色和观众反馈成立，再扩大集数和资产规模。
