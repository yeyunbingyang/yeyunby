#### 二、知识小结

|   |   |   |   |
|---|---|---|---|
|知识点|核心内容|易混淆点/操作要点|难度系数|
|剪辑基础概念|剪辑本质是素材拼接，通过时间线排列实现内容组合|区分主轨（线性排列）与副轨（自由叠加）的功能差异|⭐|
|素材导入与管理|支持本地文件导入和在线素材库调用，可收藏常用素材|官方素材库需登录账号才能使用完整功能|⭐|
|时间线操作|使用播放头定位帧、Ctrl+B分割素材、删除冗余片段|主轨默认开启磁吸功能，关闭后可自由拖动（高阶设置）|⭐⭐|
|多轨道编排|主轨承载主线内容，副轨实现画中画/叠加效果|轨道层级决定画面显示优先级（下层被上层覆盖）|⭐⭐|
