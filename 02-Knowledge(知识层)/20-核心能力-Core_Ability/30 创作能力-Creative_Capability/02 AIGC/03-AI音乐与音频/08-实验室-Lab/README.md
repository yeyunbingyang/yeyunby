# 08-实验室-Lab

集中管理可复现实验。

实验室负责：

- 验证模型能力
- 验证 Prompt 与参数
- 记录对比实验
- 沉淀可复用方法

## 实验分类

```text
08-实验室-Lab/

├─ 01-MUSIC
│  └─ 音乐生成、编曲、风格控制实验
│
├─ 02-TTS
│  └─ 文本转语音、声音克隆、情绪控制实验
│
├─ 03-SFX
│  └─ 音效生成、环境音、Foley实验
│
└─ 04-AUDIO
   └─ 音频处理、增强、混音、质量评估实验
```

## 编号规范

统一使用：

```text
MUSIC-R001
TTS-R001
SFX-R001
AUDIO-R001
```

不再使用独立 `VOICE-Rxxx` 编号。

Voice Clone、角色声音、音色保持等归入：

```text
TTS-Rxxx
```

## 实验记录模板

每个实验必须包含：

```text
实验目标
模型/版本
环境
输入数据
Prompt/参数
生成结果
评价指标
结论
可复用规则
```

## 与知识层关系

```text
方法学习
→ 02-05 能力目录

需要验证
→ 08-实验室-Lab

验证成功
→ 回写能力目录

形成跨能力生产链
→ 07-工作流
```
