# 配乐生成：本机项目选型

## 需求定义

目标是生成不强调歌词和演唱的纯音乐内容，例如：

- 短视频、漫剧和剧情片段 BGM
- 游戏场景、战斗、探索和环境音乐
- 角色主题、仙侠、国风、悬疑或史诗 OST
- 循环音乐、片头、转场和氛围铺底
- 将已有配乐转换为另一种曲风

> [!important] 本机结论
> RTX 4060 Laptop 8GB 生成配乐时，首选 **Stable Audio 3 Medium**；如果希望先在 Windows 上快速跑通，或需要更长时长、BPM、调性和拍号控制，则先用 **ACE-Step 1.5 2B**。

## 项目对比

| 维度 | Stable Audio 3 Medium | ACE-Step 1.5 2B |
| --- | --- | --- |
| 核心定位 | 音乐与音频生成、编辑 | 完整音乐生成与编辑 |
| 纯配乐生成 | 强 | 强，可不使用歌词与人声 |
| 原配乐风格转换 | 原生 Audio-to-Audio | Cover 与参考音频 |
| 局部修改 | Inpainting | Repaint |
| 配乐续写 | Continuation | Complete / 长时生成 |
| 最长时长 | Medium 官方列出最长约 380 秒 | 官方支持 10 秒至 10 分钟 |
| 8GB 显存 | 官方峰值约 5.07～6.52GB，理论适配 | 官方提供 6～8GB 档配置，明确适配 |
| Windows 易用性 | Medium 依赖 Flash Attention 2，配置较复杂 | 有官方 Windows 便携包和启动脚本 |
| 当前排序 | 配乐质量与编辑能力首选 | 易部署与长时结构备选 |

## 方案一：Stable Audio 3 Medium

适合以下任务：

- 从文字直接生成新 BGM 或 OST
- 输入旧配乐，通过 Audio-to-Audio 转换风格和氛围
- 对某一时间段做局部重绘
- 续写片尾、过渡或循环段落

官方公布的峰值显存数据为：

| 生成时长 | 峰值显存 |
| --- | --- |
| 5 秒 | 约 5.07GB |
| 30 秒 | 约 5.49GB |
| 120 秒 | 约 6.49GB |
| 380 秒 | 约 6.52GB |

本机 8GB 显存理论可容纳 Medium；为避免 Windows 桌面占用造成显存不足，首次使用时建议：

- 生成 30～60 秒
- 批次设为 1
- 使用分块解码
- 关闭模拟器、游戏、视频与其他 GPU 应用
- 模型与缓存放到 X 盘或 F 盘

> [!warning] 部署难点
> Stable Audio 3 Medium 依赖 Flash Attention 2，官方 NVIDIA TensorRT 优化路线偏向 Linux。Windows 原生安装可能遇到编译与版本匹配问题，必要时改用 WSL2。

官方项目：[Stability-AI/stable-audio-3](https://github.com/Stability-AI/stable-audio-3)

## 方案二：ACE-Step 1.5 2B

适合以下任务：

- 希望使用官方 Windows 便携包快速开始
- 需要生成数分钟的连续配乐
- 希望显式控制 BPM、调性、拍号与时长
- 使用参考音频或 Cover 模式生成相同结构的新风格配乐
- 从人声自动生成伴奏

建议配置：

```text
DiT：2B turbo
LM：0.6B
后端：pt
量化：INT8
CPU offload：开启
批次：1
纯音乐开关：instrumental = true
歌词字段：[Instrumental]
```

官方项目：[ace-step/ACE-Step-1.5](https://github.com/ace-step/ACE-Step-1.5)

## 选择规则

```text
新生成纯音乐 / 编辑旧配乐
  └─ 优先 Stable Audio 3 Medium

Windows 快速部署 / 长时配乐 / BPM与调性控制
  └─ 优先 ACE-Step 1.5 2B

保留原唱，只更换配乐
  └─ Demucs 分离 → 生成新伴奏 → 混回原唱
```

## 配乐提示词骨架

```text
用途：【短视频 / 游戏 / 漫剧 / 角色主题 / 场景氛围】
曲风：【国风 / 仙侠 / 电子 / 史诗 / 悬疑 / 治愈】
情绪变化：【开场克制 → 中段推进 → 高潮爆发 → 结尾收束】
速度：【BPM】
调性：【大调 / 小调 / 具体调性】
配器：【古筝、笛子、弦乐、鼓组、合成器等】
时长：【秒或分钟】
结构：【Intro / Build / Climax / Outro / Loop】
明确要求：instrumental, no vocals, no spoken words
避免：【抢对白的高频旋律、突兀停顿、人声、过度压缩】
```

## 首轮测试计划

- [ ] 用同一提示词分别生成 30 秒配乐
- [ ] 对比目标风格、旋律完整性、动态范围和音质
- [ ] 测试 Stable Audio 3 对已有配乐的 Audio-to-Audio
- [ ] 测试 ACE-Step 对 BPM、调性和时长的遵循程度
- [ ] 记录显存峰值、生成速度和是否出现 OOM
- [ ] 选定主模型后再测试 2～3 分钟成品
