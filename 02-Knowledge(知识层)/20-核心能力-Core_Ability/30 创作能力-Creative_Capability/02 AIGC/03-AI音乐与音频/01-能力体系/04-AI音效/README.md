## 子目录职责

- `01-环境音/`：Ambience 与场景环境声音
- `02-UI音效/`：界面反馈与交互声音
- `03-动漫音效/`：动漫 / 漫剧动作、技能与夸张化声音设计
- `04-游戏音效/`：游戏交互、技能、战斗与系统声音
- `05-视频音效/`：Foley、转场、镜头事件与视频声音
- `06-提示词与模板/`：SFX / Foley Prompt、事件描述模板与模型控制写法

## 当前模型路线

- Stable Audio 3 Small-SFX：CPU 轻量、本地、最长 120s。
- TangoFlux：44.1 kHz、最长 30s、Text-to-Audio 快速生成。
- AudioGen：AudioCraft 内研究型 Text-to-Sound 基线。
- ElevenLabs Sound Effects：在线 API，支持时长、loop 和 prompt influence。

## 边界

项目技术卡、模型事实与 Prompt 都直接服务本能力，不再外置到 `06-工具与模型` 或 `09-提示词库`。

单一音效生成流程继续留在本目录。只有当 SFX 与 TTS、音乐、后处理、视频合成等能力组成已验证的完整生产链时，才进入 `07-工作流`。
