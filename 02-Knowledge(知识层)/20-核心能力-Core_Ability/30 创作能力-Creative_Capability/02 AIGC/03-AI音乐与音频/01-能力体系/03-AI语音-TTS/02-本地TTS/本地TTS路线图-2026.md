# 本地 TTS 路线图（2026-08）

## 快速分层

| 目标 | 优先候选 | 核心理由 |
|---|---|---|
| 高质量角色对白 | **IndexTTS-2.5** | 零样本、多语言、情绪/语速/发音控制、生产服务化 |
| 多语言/方言/实时交互 | **Fun-CosyVoice3** | 9 语言、18+ 中文方言/口音、双向流式、Instruct、服务化 |
| 固定角色音色 | **GPT-SoVITS** | few-shot/训练工具链成熟、角色克隆常用 |
| 轻量快速预览 | **Kokoro-82M** | 82M、CPU/端侧友好、快速试听 |

> 需要直接比较四个项目的**功能、语言、环境要求、Windows 支持、GPU/CUDA、训练/服务化与许可证**时，统一查看：[[本地TTS横向对比-功能与环境要求-2026]]。

## IndexTTS-2.5

官方在 **2026-08-10** 发布 IndexTTS-2.5，当前重点包括：

- 单参考音频零样本声音克隆
- 中文、英文、日文、西班牙文、阿拉伯文
- 音色与情绪解耦
- 情绪参考音频控制
- 8 维情绪向量控制
- `emo_alpha` 情绪强度控制
- `duration_factor` 语速/时长倍率控制（约 0.5x–2.0x）
- 中文拼音、英文 CMU phoneme、日文 Kana 发音控制
- 相比 IndexTTS-2 更快的推理
- vLLM 生产部署路线

注意：IndexTTS-2 旧版新闻中提到的“精确合成时长控制”曾在初始 release 中未启用；**2.5 当前公开的是 `duration_factor` 语速/时长倍率控制，不应直接等同于任意目标毫秒级精确对齐。**

详见：[[IndexTTS-2.5-项目笔记]]

## Fun-CosyVoice3

当前主模型为 `Fun-CosyVoice3-0.5B-2512`。其定位不只是“另一个声音克隆模型”，而是偏完整实时 TTS 平台：

- 9 种常用语言
- 18+ 中文方言/口音
- multi-lingual / cross-lingual zero-shot voice cloning
- 中文拼音、英文 CMU phoneme pronunciation inpainting
- 语言、方言、情绪、速度、音量等 Instruct 控制
- Text-in Streaming + Audio-out Streaming
- 官方说明最低约 150ms 延迟路线
- vLLM / FastAPI / gRPC / Docker / TensorRT-LLM 等服务路线
- 提供训练和推理脚本

详见：[[Fun-CosyVoice3-项目笔记]]

## GPT-SoVITS

优势在角色克隆与数据工具链，适合：

- 为固定角色准备参考音频
- 约 5 秒参考做 zero-shot 快速验证
- 少量数据 few-shot 微调
- 中文/日文/英文/韩文/粤语等角色语音实验
- 音频切片、ASR、标注、训练一体化流程

它更适合“长期维护角色声音资产”，而 IndexTTS-2.5 更适合“强可控的零样本生成”。

详见：[[GPT-SoVITS-项目笔记]]

## Kokoro-82M

Kokoro 是 82M 参数的轻量开放权重 TTS，适合作为：

- 文本编辑时快速试听
- CPU / 低资源设备预览
- 普通旁白草稿
- 端侧 / ONNX / 浏览器衍生路线研究

它支持多语言管线，并提供 `speed` 控制。它不替代角色高一致性克隆引擎，而是承担“快”。

详见：[[Kokoro-82M-项目笔记]]

## 选择原则

```text
先确定：这是草稿试听，还是正式角色声音？
→ 是否需要固定音色长期维护？
→ 是否需要多语言/方言/实时流式？
→ 是否需要强情绪、语速或发音控制？
→ 是否有可训练角色数据？
→ 是否需要服务化？
→ 最后再比较显存、速度与许可
```

## 推荐组合，而不是单模型统治

```text
对白草稿 / 文案试听
→ Kokoro-82M

快速角色原型
→ IndexTTS-2.5 / GPT-SoVITS Zero-shot

多语言 / 方言 / 实时对话
→ Fun-CosyVoice3

固定角色长期维护
→ GPT-SoVITS few-shot

高情绪 / 发音控制 / 视频对白
→ IndexTTS-2.5
```

## 四模型职责表

| 模型 | 最主要职责 | 不应强求它做什么 |
|---|---|---|
| IndexTTS-2.5 | 高质量强可控零样本角色对白 | 不必把它当数据集训练工作台 |
| Fun-CosyVoice3 | 多语言/方言/流式交互与服务平台 | 不必把它当极简试听器 |
| GPT-SoVITS | 固定角色、few-shot、训练资产 | 不必让它包办所有程序化情绪控制 |
| Kokoro-82M | 草稿、CPU、快速试听 | 不追求角色克隆上限 |
