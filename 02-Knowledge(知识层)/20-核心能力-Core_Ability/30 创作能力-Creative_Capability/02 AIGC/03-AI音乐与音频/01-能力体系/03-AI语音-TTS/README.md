## 子目录职责

- `01-浏览器TTS/`：浏览器原生语音与快速试听
- `02-本地TTS/`：本地模型技术卡、路线图、横向对比与部署方法
- `03-在线TTS/`：在线平台与 API
- `04-Voice-Clone/`：声音克隆、参考音频与身份一致性
- `05-角色语音/`：角色 Voice Profile、情绪和长期角色语音设计
- `06-提示词与控制模板/`：TTS Prompt、Instruct、情绪 / 语速 / 发音等控制模板

## 当前分工（2026-08）

```text
秒级预览 → Web Speech API / Kokoro
本地高质量 → IndexTTS-2.5 / Fun-CosyVoice3 / GPT-SoVITS
在线高质量 / 低运维 → ElevenLabs 等 API
固定角色 → Voice Clone + 角色 Voice Profile
正式比较 → 08-实验室-Lab/TTS实验
```

## 边界

模型版本、许可证、硬件与安装信息直接保存在对应 TTS 子目录，不再外置到“工具与模型”。

TTS Prompt 与控制模板也直接归入本目录，不再维护顶层 `09-提示词库`。

单一 TTS / Voice 的成熟流程继续留在本目录；只有当流程继续进入音频处理、视频合成、BGM / SFX 等多个能力并经过验证后，才进入 `07-工作流`。
