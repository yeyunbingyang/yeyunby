# 角色语音一致性设计

## 不要只保存“一个 wav”

真正可复用的角色语音资产应该是一个 Voice Profile。

```text
角色身份
├─ 身份参考音频
├─ 情绪参考音频
├─ 发音词典
├─ 常用语速
├─ 音高/韵律策略
├─ 引擎与版本
├─ 推理参数
└─ 后处理链
```

## Voice Profile 示例

```yaml
id: ZITANG_V01
language: zh-CN
age_impression: adult_25
voice_character: 冷清、柔和、克制
engine: IndexTTS2
identity_ref: voices/紫棠/neutral.wav
styles:
  gentle: voices/紫棠/gentle.wav
  cold: voices/紫棠/cold.wav
  angry: voices/紫棠/angry.wav
speed_default: 0.94
post:
  denoise: false
  loudness_target: project_default
```

## 台词生产流程

```text
台词
→ 文本规范化
→ 发音词典处理
→ 选择角色/情绪
→ 快速预览
→ 高质量合成
→ 人工试听
→ 轻量后处理
→ 进入时间轴
```

## 一致性风险

- 同引擎更新后音色漂移
- 情绪太强导致角色年龄/身份变化
- 长文本节奏逐渐失控
- 同一个参考音频不适合所有情绪
- 数字、英文缩写、人名读音不稳定

因此正式项目要固定：**模型版本 + Voice Profile + 发音规范 + 后处理链**。
