# 音频增强与响度标准化

## 正确顺序

```text
修复问题
→ EQ
→ 动态控制
→ 空间处理
→ 总线处理
→ Loudness / True Peak
→ 编码交付
```

不要一开始就套“AI Enhance + Master”并期待所有问题自动消失。

## EQ

优先做减法：

- 去除无意义超低频
- 清理浑浊频段
- 控制刺耳/齿音
- 给对白和 BGM 留空间

具体频率必须以素材为准，不应机械套固定频点。

## 动态

### Compressor
用于缩小动态差异、稳定对白或音乐轨。

### Limiter
用于控制最终峰值，不应承担所有响度提升。

### Automation
对 AI 生成中某一段突然过响/过轻，音量自动化通常比全局强压缩更自然。

## 响度标准化

先测量：

```bash
ffmpeg -i input.wav -filter_complex ebur128=peak=true -f null -
```

再按最终平台/工程目标处理。EBU R128 的 -23 LUFS 是广播参考，不是所有网络平台的统一答案。

FFmpeg `loudnorm` 可以执行 EBU R128 风格的响度归一流程；正式交付更建议先测量再做二次处理。

## AI 音频特别注意

- 生成伪影不能靠母带修复。
- “高频更多”不等于清晰。
- 强 Exciter 容易放大 AI 金属纹理。
- 人声克隆应避免过度改变声纹特征。
