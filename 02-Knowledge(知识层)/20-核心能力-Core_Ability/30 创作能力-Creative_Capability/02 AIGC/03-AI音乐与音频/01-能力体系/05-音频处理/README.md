## 推荐处理顺序

```text
输入素材
→ 源分离（按需）
→ 降噪 / 去混响 / 修复
→ 剪辑与结构处理
→ EQ / 动态 / 音频增强
→ 音色转换（按需）
→ 响度与峰值控制
→ 编码 / 封装 / 交付
```

ASR 通常作为独立分析支线，用于字幕、对齐、检索、说话人处理和自动化工作流。
