# 采样率、位深与声道

## 采样率 Sample Rate

常见值：16 kHz、24 kHz、44.1 kHz、48 kHz、96 kHz。

AI 语音模型常在 16–24 kHz 工作；音乐/视频生产更常见 44.1/48 kHz。最终项目建议统一到一个母版采样率，避免反复重采样。

### 实践选择

- 语音识别/轻量 TTS 中间过程：模型原生采样率优先。
- 音乐制作：44.1 kHz 常见。
- 视频制作：48 kHz 优先，便于与视频工程统一。
- 96 kHz 不应被当作“自动变好听”的按钮。

## 位深 Bit Depth

PCM 常见 16-bit、24-bit、32-bit float。

- 16-bit：最终消费级分发常见。
- 24-bit：音乐制作与素材交换更宽裕。
- 32-bit float：DAW/后处理中便于保留计算余量，但并不意味着原始录音凭空增加细节。

## 声道 Channel

- Mono：对白、语音、部分 SFX 素材。
- Stereo：音乐、环境声、最终视频声轨常见。
- 多声道/沉浸式：需要明确播放端和制作链，不要仅靠复制声道伪造空间。

## AI 输出检查

1. 检查模型原生采样率。
2. 检查导出文件实际采样率/位深，而不是只看扩展名。
3. 立体声模型要检查左右声道相关性和声像漂移。
4. 统一进入项目工程前再做一次受控重采样。

### FFprobe

```bash
ffprobe -v error -show_streams input.wav
```

重点看 `sample_rate`、`channels`、`channel_layout`、`sample_fmt`。
