# AI 音乐与音频开源项目索引（2026-08）

> 本表是跨能力生态入口，不按 Star 排名。具体项目技术卡直接归入其主要能力目录；Star、release 和许可证会变化，正式部署前以对应官方仓库为准。

## 音乐生成 / 编辑

| 项目 | 定位 | 当前用途 |
|---|---|---|
| [ACE-Step v1.5](https://github.com/ace-step/ACE-Step-1.5) | 本地音乐基础模型 | 歌曲、Cover、Repaint、长时音乐、LoRA |
| [Stable Audio 3](https://github.com/Stability-AI/stable-audio-3) | 音乐/音频生成编辑 | T2A、A2A、Inpaint、Continuation、SFX |
| [AudioCraft](https://github.com/facebookresearch/audiocraft) | Meta 音频研究工具箱 | MusicGen、AudioGen、JASCO、EnCodec 等 |
| [Magenta RealTime](https://github.com/magenta/magenta-realtime) | 实时音乐生成 | AI DJ、交互音乐、实时连续生成 |

| 项目 | 定位 | 知识卡 |
|---|---|---|
| [IndexTTS](https://github.com/index-tts/index-tts) | **IndexTTS-2.5**；零样本克隆、情绪/语速/发音控制、多语言、vLLM 服务化 | [[IndexTTS-2.5-项目笔记]] |
| [CosyVoice](https://github.com/QwenAudio/CosyVoice) | **Fun-CosyVoice3**；9 语言、18+ 中文方言/口音、双向流式、Instruct、训练/服务 | [[Fun-CosyVoice3-项目笔记]] |

### 当前 TTS 分工

```text
IndexTTS-2.5
  → 高质量零样本 + 情绪/语速/发音控制 + 生产推理

Fun-CosyVoice3
  → 多语言/方言 + 指令控制 + 双向流式 + 训练/服务平台

GPT-SoVITS
  → 固定角色 + few-shot 微调 + 数据集/训练完整工具链

Kokoro-82M
  → 轻量快速预览 / CPU / 端侧
```

## 许可证提醒

不能把“GitHub 能下载”理解为“可自由商用”。代码、模型权重、附加语音资产和训练数据可能是不同许可证。

当前 TTS 主线尤其要区分：

- IndexTTS-2.5：bilibili Model Use License Agreement
- CosyVoice 仓库：Apache-2.0
- GPT-SoVITS 仓库：MIT
- Kokoro：官方 README 明确说明权重为 Apache licensed weights

每次进入正式产品前应分别核验：

1. 代码许可证
2. 模型权重许可证
3. voice / speaker 资产许可证
4. 训练数据/输出限制
5. 上传素材与声音克隆授权
6. 二次分发条件
7. 企业规模或特定用途触发的额外授权条件
