# 混音、母带与 AI 音频验收

AI 生成完成 ≠ 音频生产完成。

## 六层验收

### 1. 内容

- 歌词/台词是否正确
- 结构与时长是否符合目标
- 音效事件是否按顺序发生

### 2. 模型伪影

- 金属声、相位感、颗粒化
- 人声双声、鬼影、口水音异常
- 音乐和弦/旋律突然漂移
- 环境底噪突然切换

### 3. 动态

- 是否过度压缩
- 瞬态是否被削平
- 前后段响度是否突然跳变

### 4. 频谱

- 低频浑浊
- 2–5 kHz 刺耳
- 齿音过重
- 高频“假空气感”

### 5. 空间

- 声像是否漂移
- 混响空间是否一致
- 多个 AI 片段拼接后是否像不同房间

### 6. 交付

- Sample Rate / Bit Depth / Channels
- LUFS / True Peak
- 无损母版是否保留
- 是否保留 Stem / 干声 / Prompt / Seed / 模型版本

## 推荐资产组合

```text
MASTER.wav
STEMS/
RAW_AI/
PROMPT.md
METADATA.yaml
PREVIEW.mp3
```

## 混音与母带分工

- 混音：处理各轨之间的平衡、频率、动态、空间。
- 母带：处理最终整体响度、频谱平衡、峰值和交付一致性。

AI 音频尤其要避免“生成后直接一键母带”掩盖源素材问题。先修伪影和结构，再做整体处理。
