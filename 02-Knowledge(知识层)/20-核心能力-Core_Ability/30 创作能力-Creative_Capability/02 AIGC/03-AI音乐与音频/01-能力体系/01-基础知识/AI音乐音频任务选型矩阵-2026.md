# AI 音乐 / 音频任务选型矩阵（2026-08）

| 任务 | 首先验证 | 备选/研究 | 核心判断 |
|---|---|---|---|
| 本地完整歌曲 | ACE-Step v1.5 | Suno/Udio 在线 | 长结构、歌词、编辑 |
| 原曲风格化 | ACE-Step Cover / Stable Audio 3 A2A | Udio upload/remix | 保留旋律/结构程度 |
| BGM / OST | Stable Audio 3 / ACE-Step | MusicGen/JASCO | 时长、结构、对白空间 |
| 本地 SFX | Stable Audio 3 Small-SFX / TangoFlux | AudioGen | 事件清晰、时长、loop |
| 在线 SFX | ElevenLabs SFX | — | API、loop、时长 |
| 浏览器秒级 TTS | Web Speech API / Kokoro | — | 速度优先，不保证跨设备音色 |
| 本地高质量 TTS | IndexTTS2 / Fun-CosyVoice3 | GPT-SoVITS | 情绪、语言、时长、身份 |
| 固定角色克隆 | GPT-SoVITS / IndexTTS2 | CosyVoice | 相似度与跨情绪一致性 |
| 音乐源分离 | Demucs 固定版本 | — | Stem 泄漏与伪影 |
| 语音降噪 | DeepFilterNet | FFmpeg 基础滤镜 | 语音细节损失 |
| ASR 字幕 | Whisper / FunASR | — | 多语言、中文、流式、时间戳 |
| Voice Conversion | RVC | Seed-VC 固定版本 / w-okada 客户端 | 延迟、身份、项目活跃度 |
| 实时音乐 | Magenta RealTime | — | 高显存工作站需求 |

## 选型顺序

```text
1. 任务是什么？
2. 输入条件是什么？文字 / 歌词 / 音频 / Voice Ref
3. 必须保留什么？旋律 / 结构 / 身份 / 时长
4. 本地还是在线？
5. 许可与上传权利是否允许？
6. 硬件能否稳定运行？
7. 最后才比较“最好听”。
```

## 一个重要原则

**生成模型和生产工具不是同一层。**

例如完成一段动漫视频声音可能同时需要：

```text
IndexTTS2          角色对白
Stable Audio 3     BGM
TangoFlux          技能 SFX
Demucs             源分离
DeepFilterNet      对白清理
FFmpeg             时间轴处理/转码
```

不应该寻找“一个模型全部完成”。
