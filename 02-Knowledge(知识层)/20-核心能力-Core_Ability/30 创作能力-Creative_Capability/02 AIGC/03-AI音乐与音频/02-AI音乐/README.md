## 当前判断（2026-08）

- 本地完整音乐/编辑主线：ACE-Step v1.5、Stable Audio 3。
- 研究型可控音乐：AudioCraft / MusicGen / JASCO。
- 实时连续音乐：Magenta RealTime，但本地 GPU 要求高。
- 在线生产：Suno、Udio 适合快速成歌和编辑，但上传素材必须注意权利边界。
