# 原音乐风格化改编：需求与模型选型

## 核心需求

目标不是“输入歌词，从零生成一首新歌”，而是：

> [!important] 目标定义
> 输入一首已有音乐，将其改编为另一种风格；根据具体任务，选择保留旋律、节奏、歌曲结构、人声或歌词中的一部分，再重做编曲、音色、氛围或演唱方式。

典型例子：

- 流行歌曲 → 国风、仙侠或古典编曲
- 抒情歌曲 → 摇滚、电子或史诗风格
- 保留原人声 → 更换伴奏风格
- 保留旋律与歌词 → 重新生成演唱和伴奏
- 纯音乐 → 转换乐器、节奏与空间氛围

## 先确定要保留什么

风格化之前必须定义约束，否则模型容易生成“相似的新歌”，而不是原曲改编。

| 约束维度 | 可选目标 |
| --- | --- |
| 旋律 | 严格保留 / 大体保留 / 允许重写 |
| 歌曲结构 | 保留主歌、副歌和桥段 / 仅保留时长与段落感 |
| 节奏与速度 | 保持 BPM / 允许改变律动与速度 |
| 人声 | 保留原唱 / 更换音色或唱法 / 去除人声 |
| 歌词 | 完全保留 / 局部改写 / 不需要歌词 |
| 编曲 | 全部重做 / 只替换部分乐器 |

## 模型选型结论

根据现有调研材料，优先级应围绕“是否支持音频条件、Remix 或 Audio-to-Audio”排序，而不是围绕从零生成完整歌曲的能力排序。

| 优先级 | 模型 | 与需求的匹配点 | 当前判断 |
| --- | --- | --- | --- |
| 1 | ACE-Step v1.5 | 材料称其支持音频条件、Remix、歌词编辑、声音克隆及人声/伴奏相关任务 | 最接近完整歌曲风格化工作流，优先实测 |
| 2 | Stable Audio 3 | 材料称其支持 Audio-to-Audio、局部重绘、续写和 LoRA | 更适合纯音乐、BGM、局部编辑与音色/氛围迁移 |
| 3 | MusicGen / AudioCraft | 支持旋律条件和风格参考，JASCO 可加入和弦、旋律、鼓等控制 | 适合研究、验证控制方式；模型权重许可需留意 |
| 4 | SongGeneration 2 / LeVo 2 | 支持音频提示和完整歌曲生成 | 可测试参考音频驱动，但需确认对原曲结构的保持程度 |
| 5 | YuE | 强项是歌词到完整歌曲 | 更适合保留歌词后重新创作，不是首选音频到音频方案 |

> [!warning] 待核验
> 上述版本、功能、硬件需求与许可证来自用户提供的 2026 年 8 月调研材料，尚未逐项对照官方仓库复核，因此本笔记暂定为“改进”。正式安装或商用前，应检查官方文档、模型权重许可证及输入音乐的版权边界。

## 推荐工作流

```text
原始音乐
  ↓
版权与授权确认
  ↓
人声/伴奏分离（按需）
  ↓
提取 BPM、调性、段落、旋律或和弦
  ↓
设定必须保留项 + 目标风格提示
  ↓
ACE-Step Remix 或 Stable Audio Audio-to-Audio
  ↓
与原曲对齐检查：旋律、结构、歌词、时长
  ↓
混音、母带与人工修正
```

如果需要保留原唱，可先使用 Demucs 等工具分离人声与伴奏，只对伴奏做风格化，再将原人声对齐混回；如果允许重唱，则可保留歌词、旋律与结构，让模型重新生成整首歌曲。

## 首轮验证计划

- [ ] 准备一段 30～60 秒、版权清晰的测试音乐
- [ ] 记录原曲 BPM、调性、段落和希望保留的元素
- [ ] 用 ACE-Step 测试 Remix：保留歌词与旋律，转换为目标风格
- [ ] 用 Stable Audio 测试 Audio-to-Audio：重点观察纯伴奏与音色迁移
- [ ] 对比旋律保持度、结构保持度、人声质量、可控性、显存与生成速度
- [ ] 核验最终候选模型的许可证和商用限制

## 提示词骨架

```text
目标：将输入音乐改编为【目标风格】。
必须保留：【主旋律 / 歌词 / 段落结构 / BPM / 原人声】。
允许改变：【配器 / 鼓组 / 和声 / 音色 / 唱法 / 氛围】。
新增元素：【目标乐器、空间感、情绪、制作年代】。
避免：【旋律漂移、歌词错位、结构重写、不需要的乐器】。
```
