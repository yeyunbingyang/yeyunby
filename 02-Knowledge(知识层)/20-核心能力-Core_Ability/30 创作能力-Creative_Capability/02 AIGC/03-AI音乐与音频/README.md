# AI音乐与音频

> `yeyunby` 知识库中的 AIGC 声音能力模块；**不是独立 GitHub 项目**。

本模块用于沉淀 AI 音乐、AI 语音/TTS、AI 音效与音频处理相关的知识、工具、实验、工作流和资产索引。

## 核心组织逻辑

**知识 → 工具/模型 → 方法 → 实验 → 工作流 → 资产**

## 目录

- `00-MOC/`：模块地图与核心导航
- `01-基础知识/`：数字音频、音乐与混音基础
- `02-AI音乐/`：音乐生成、改编、BGM 与风格研究
- `03-AI语音-TTS/`：TTS、浏览器/本地/在线语音、声音克隆与角色语音
- `04-AI音效/`：环境、UI、动漫、游戏与视频音效
- `05-音频处理/`：分离、降噪、增强、音色转换、ASR、FFmpeg
- `06-工具与模型/`：开源项目、在线平台、本地模型与横向对比
- `07-工作流/`：经过验证、可以复用的正式流程
- `08-实验室-Lab/`：模型、Prompt、音色与音质实验
- `09-提示词库/`：音乐、TTS、音效 Prompt 与模板
- `10-资产库/`：BGM、Voice、SFX、Presets、Samples 的资产索引与小型样例

## 归档规则

1. 基础概念和原理 → `01-基础知识`
2. 某项音乐/语音/音效能力的具体方法 → 对应能力目录
3. “某项目/模型是什么” → `06-工具与模型`
4. 实际测试与对照实验 → `08-实验室-Lab`
5. 已验证、可重复执行的方法 → `07-工作流`
6. Prompt 与可复制模板 → `09-提示词库`
7. 可复用声音资产或资产索引 → `10-资产库`

外部 GitHub 项目不再按“一个项目 = 一个大文件夹”平铺；项目介绍、能力实践、实验和工作流按职责拆分归档。
