# AI音乐与音频

> `yeyunby` 知识库中的 AIGC 声音能力模块；**不是独立 GitHub 项目**。

本模块用于沉淀 AI 音乐、AI 语音/TTS、AI 音效与音频处理相关的知识、模型/工具、实验、工作流和资产索引。

## 核心组织逻辑

**基础知识 → 能力领域（含模型/工具）→ 实验 → 工作流 → 资产**

模型和工具不再作为独立横向目录存在，而是直接归入它实际服务的能力领域。

## 目录

- `00-MOC/`：模块地图与核心导航
- `01-基础知识/`：数字音频、音乐与混音基础；跨音乐/语音/音效的生态索引、任务选型与通用部署知识
- `02-AI音乐/`：音乐模型/平台、歌曲生成、改编、BGM、OST 与风格研究
- `03-AI语音-TTS/`：浏览器/本地/在线 TTS、具体 TTS 模型、声音克隆与角色语音
- `04-AI音效/`：音效模型/平台、环境、UI、动漫、游戏与视频音效
- `05-音频处理/`：分离、降噪、增强、音色转换、ASR、FFmpeg，以及对应处理工具/模型
- `07-工作流/`：经过验证、可以复用的正式流程
- `08-实验室-Lab/`：模型、Prompt、音色与音质实验
- `09-提示词库/`：音乐、TTS、音效 Prompt 与模板
- `10-资产库/`：BGM、Voice、SFX、Presets、Samples 的资产索引与小型样例

> `06-工具与模型` 已取消。为避免大量历史链接与编号迁移，`07–10` 暂时保持原编号，不做整体重编号。

## 归档规则

1. 基础概念、标准、跨能力生态索引与通用部署知识 → `01-基础知识`
2. AI 音乐项目/模型/平台及具体方法 → `02-AI音乐`
3. TTS / Voice 项目/模型/平台及具体方法 → `03-AI语音-TTS`
4. AI 音效项目/模型/平台及具体方法 → `04-AI音效`
5. 音频处理项目/模型/工具及具体方法 → `05-音频处理`
6. 实际测试与对照实验 → `08-实验室-Lab`
7. 已验证、可重复执行的方法 → `07-工作流`
8. Prompt 与可复制模板 → `09-提示词库`
9. 可复用声音资产或资产索引 → `10-资产库`

外部 GitHub 项目不再进入单独的“工具与模型”仓库；项目技术卡直接放到其主要能力目录。一个项目横跨多个能力时，以**主要用途**确定主文档位置，其他能力通过双链引用，不重复复制项目卡。
