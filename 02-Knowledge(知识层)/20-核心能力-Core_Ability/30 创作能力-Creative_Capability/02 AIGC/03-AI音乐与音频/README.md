# AI音乐与音频

> `yeyunby` 知识库中的 AIGC 声音能力模块；**不是独立 GitHub 项目**。

本模块用于沉淀 AI 音乐、AI 语音/TTS、AI 音效与音频处理相关的知识、模型/工具、Prompt、实验、跨能力工作流和资产索引。

## 核心组织逻辑

**基础知识 → 能力领域（含模型 / 工具 / Prompt）→ 实验验证 → 跨能力工作流 → 资产**

模型、工具与 Prompt 不再建立独立横向仓库，而是直接归入它实际服务的能力领域。

## 目录

- `00-MOC/`：模块地图与核心导航
- `01-基础知识/`：数字音频、音乐与混音基础；跨音乐/语音/音效的生态索引、任务选型与通用部署知识
- `02-AI音乐/`：音乐模型/平台、Prompt、歌曲生成、改编、BGM、OST 与风格研究
- `03-AI语音-TTS/`：浏览器/本地/在线 TTS、具体 TTS 模型、Prompt/控制模板、声音克隆与角色语音
- `04-AI音效/`：音效模型/平台、Prompt、环境、UI、动漫、游戏与视频音效
- `05-音频处理/`：分离、降噪、增强、音色转换、ASR、FFmpeg，以及对应处理工具/模型/命令模板
- `07-工作流/`：经过验证、横跨两个以上能力的端到端生产流程
- `08-实验室-Lab/`：模型、Prompt、音色、音质与参数实验
- `10-资产库/`：BGM、Voice、SFX、Presets、Samples 的资产索引与小型样例

> `06-工具与模型` 与 `09-提示词库` 已取消。为减少历史链接与脚本迁移，`07`、`08`、`10` 暂时保持现有编号，不要求连续。

## 归档规则

1. 基础概念、标准、跨能力生态索引与通用部署知识 → `01-基础知识`
2. AI 音乐项目/模型/平台/Prompt 及具体方法 → `02-AI音乐`
3. TTS / Voice 项目/模型/平台/Prompt 及具体方法 → `03-AI语音-TTS`
4. AI 音效项目/模型/平台/Prompt 及具体方法 → `04-AI音效`
5. 音频处理项目/模型/工具/命令模板及具体方法 → `05-音频处理`
6. 实际测试与对照实验 → `08-实验室-Lab`
7. 单能力的成熟流程继续留在对应 `02–05`；只有跨两个以上能力、已验证且可重复的端到端流程 → `07-工作流`
8. 可复用声音资产或资产索引 → `10-资产库`

外部 GitHub 项目不再进入单独的“工具与模型”仓库；Prompt 也不再集中到总提示词库。一个项目或模板横跨多个能力时，以**主要用途**确定主文档位置，其他能力通过双链引用，不重复复制。
