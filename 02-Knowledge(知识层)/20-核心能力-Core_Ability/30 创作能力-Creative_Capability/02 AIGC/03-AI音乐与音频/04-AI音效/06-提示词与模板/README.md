# 06-提示词与模板

这里是 **AI 音效 / SFX / Foley Prompt 的主入口**。

记录：

- 环境音 Prompt
- UI 音效 Prompt
- 动漫 / 漫剧音效 Prompt
- 游戏音效 Prompt
- Foley 与转场 Prompt
- 单事件 / 多事件描述模板
- 时长、loop、强度、空间感与材质描述
- 针对 Stable Audio、TangoFlux、AudioGen、在线 SFX API 的控制写法

## 归档原则

```text
可复用 SFX / Foley Prompt
→ 本目录

具体声音设计方法
→ 01–05 对应音效子目录

Prompt / 参数对照实验
→ 08-实验室-Lab

验证后的稳定模板
→ 回写本目录
```

不要再同步复制到顶层 Prompt 总库；同一模板只维护一个主版本。
