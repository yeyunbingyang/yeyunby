# 07-工作流

只保存**经过验证、可重复执行、横跨两个以上能力的端到端生产流程**。

## 进入本目录的条件

一个流程只有同时满足以下条件，才进入 `07-工作流`：

1. 横跨至少两个能力目录，例如 TTS + 音频处理，或音乐 + 音效 + 混音；
2. 已经经过 `08-实验室-Lab` 或真实项目验证；
3. 可以重复执行，而不是一次性的临时方案；
4. 有明确输入、步骤、输出、依赖与验收标准。

## 应该放这里

```text
脚本 → TTS → 时长对齐 → 降噪 → FFmpeg 合成

角色对白 → BGM → SFX → 混音 → 最终视频声音

角色声音资产 → Voice Clone → 批量配音 → 后处理 → 导出

批量任务 → 多模型生成 → 自动质检 → 资产归档
```

## 不应该放这里

以下属于单能力流程，应继续放在对应 `02–05`：

```text
IndexTTS 安装与生成
→ 03-AI语音-TTS

GPT-SoVITS 数据准备与训练
→ 03-AI语音-TTS

ACE-Step 歌曲生成
→ 02-AI音乐

TangoFlux 音效生成
→ 04-AI音效

Demucs 人声分离
→ 05-音频处理
```

## 与实验室的关系

```text
方法 / Prompt / 参数
→ 放在 02–05

需要验证
→ 08-实验室-Lab

验证通过且仍是单能力
→ 回写 02–05

验证通过且形成跨能力生产链
→ 升格到 07-工作流
```

因此 `07` 是**生产链层**，不是“所有操作步骤”的总目录。
