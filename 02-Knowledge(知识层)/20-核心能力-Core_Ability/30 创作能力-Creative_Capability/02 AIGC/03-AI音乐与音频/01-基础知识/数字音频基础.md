# 数字音频基础

## 一句话模型

数字音频可以理解为：**随时间采样的振幅序列 + 采样格式 + 声道布局 + 编码/容器信息**。

```text
真实声波
  ↓ 麦克风/合成器
模拟电信号
  ↓ ADC
PCM 数字样本
  ↓ 编辑/生成/处理
PCM 或编码音频
  ↓ DAC
扬声器/耳机
```

## 需要区分的概念

| 概念 | 解决什么问题 |
|---|---|
| 采样率 | 每秒记录多少次波形状态 |
| 位深 | 每个样本的振幅精度/可表示范围 |
| 声道 | 单声道、立体声、多声道的空间组织 |
| 编码器 Codec | 如何压缩或表示音频数据 |
| 容器 Format/Container | 文件如何装载音频流与元数据 |
| 比特率 | 压缩后单位时间的数据量 |
| 响度 | 人耳感知到的整体音量水平 |
| True Peak | 重建波形可能出现的真实峰值 |

## 对 AI 音频最重要的判断

AI 输出“听起来更高清”不等于真实信息更多。模型可能生成新的高频纹理、混响或泛音，因此验收需要同时看：

- 是否有失真、爆音、金属伪影
- 人声齿音与呼吸是否自然
- 音乐瞬态是否糊掉
- 立体声是否稳定
- 是否有突变、断裂、相位问题
- 输出采样率是否只是上采样标签

## 推荐工作原则

- 生成阶段优先保留无损中间文件（WAV/FLAC）。
- 发布时再按平台需要编码 AAC/Opus/MP3。
- 不要用“码率越高=质量一定越高”替代实际试听与源质量判断。
- AI 生成结果必须保留原始输出，后处理另存版本。
