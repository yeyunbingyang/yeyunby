# AI 音乐与音频在线平台索引（2026-08）

## Suno

当前已不只是“一句 Prompt 生成歌曲”，其产品链包含：

- 歌曲生成
- Song Editor / Studio
- Stem 相关工作流
- Audio Upload
- Sample / Mashup
- Sounds（one-shot / loop）

适合：快速成歌、在线编辑、创作探索和无需本地部署的生产。

官方：[Suno Release Notes](https://suno.com/release-notes)

## Udio

官方支持上传你拥有权利的音频，并用于：

- Extend
- Inpaint
- Session
- Remix
- Style

它很适合研究“已有素材 → 继续生成/重混/风格化”工作流。上传素材前必须确认权利。

官方：[Udio Audio Upload](https://help.udio.com/en/articles/10754328-create-music-with-your-own-audio)

## ElevenLabs

### Text to Speech

在线 TTS / Streaming / Voice 路线，适合快速应用集成和高质量云端语音。

### Sound Effects

Text-to-SFX API 支持时长、loop 和 prompt influence，适合 Foley、环境、游戏和视频声音设计。

官方：
- [Text to Speech](https://elevenlabs.io/docs/overview/capabilities/text-to-speech)
- [Sound Effects](https://elevenlabs.io/docs/overview/capabilities/sound-effects)

## 在线平台统一评估

| 维度 | 必须检查 |
|---|---|
| 质量 | 长文本/长音乐，而非只听 Demo |
| 编辑 | Extend / Inpaint / Stem / Remix |
| API | 是否可批量、流式、异步 |
| 上传权利 | 是否允许上传第三方素材 |
| 数据策略 | 上传音频/声音如何处理 |
| 商用 | 当前计划与输出权利 |
| 成本 | 以使用当天官方价格为准 |
| 导出 | WAV/Stem/MIDI/采样率等 |

> 价格、套餐和商业条款属于高频变化信息，本知识库不硬编码长期价格数字。
