# 本地模型部署分层（2026-08）

> 下表混合了官方推荐/要求与项目公布的峰值数据，只用于初筛；不同驱动、Torch、量化、批次和桌面占用都会改变真实可用显存。

## CPU / 无独显优先

- Stable Audio 3 `small-music`：433M，CPU，最长 120s。
- Stable Audio 3 `small-sfx`：433M，CPU，最长 120s。
- Kokoro 82M：轻量 TTS，适合作为 CPU/浏览器预览。
- FFmpeg / DeepFilterNet 等工具可作为 CPU 音频链使用，具体实时性能看处理器。

## 6–8GB VRAM

### ACE-Step v1.5

官方显存分档中，6–8GB 建议：

```text
DiT: 2B turbo
LM: 0.6B
LM backend: PyTorch
必要时启用 INT8 / CPU offload
```

### Stable Audio 3 Medium

官方 Medium 1.4B 的 benchmark 峰值显存约：

- 30s：5.49GB
- 120s：6.49GB
- 380s：6.52GB

因此 8GB 卡理论上具备测试空间；但 Medium 依赖 CUDA / Flash Attention 2，Windows 环境仍需要认真处理依赖。Small 系列则更适合 CPU 轻量路线。

## 12GB+

ACE-Step XL 4B 官方建议至少 12GB 并结合 offload/quantization；如果不卸载，官方更建议约 20GB 级显存。

## 16GB+

AudioCraft / MusicGen Medium 官方文档曾建议约 16GB GPU 推理空间，适合作为研究与控制实验，不应强塞到 8GB 卡作为首选。

## 40GB 级

Magenta RealTime 本地 Docker GPU 路线注明需要约 40GB 显存级 GPU，属于工作站/云 GPU 级实时音乐研究。

## TTS 不建议硬编码统一显存值

IndexTTS2、CosyVoice、GPT-SoVITS 的实际占用受模型版本、推理后端、精度和上下文长度影响。知识库应记录：

```text
模型版本 + 后端 + 精度 + batch + 实测峰值
```

而不是永久写一个“最低显存”。
