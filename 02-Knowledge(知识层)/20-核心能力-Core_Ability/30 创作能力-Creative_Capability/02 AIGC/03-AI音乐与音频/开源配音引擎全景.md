# 开源配音引擎全景

## 一句话结论

开源 TTS/配音引擎可按「部署位置」分三类：本地 GPU 模型（高质量 / 声音克隆）、浏览器端（零安装或 WASM 本地推理）、视频配音整条流水线。动漫中文女声的完整方案通常是「本地主力 + 浏览器快速预览」组合。

## 分类总览

| 类别 | 代表引擎 | 特点 |
| --- | --- | --- |
| 浏览器端 | Web Speech API / Kokoro.js / sherpa-onnx WASM / transformers.js | 零安装，或浏览器内本地推理 |
| 本地模型·克隆 | GPT-SoVITS / CosyVoice / IndexTTS / Qwen3-TTS / Chatterbox / OpenVoice | 高质量、零样本克隆、情绪控制 |
| 对话短剧 | ChatTTS / dia | 多角色日常对话、一次生成 |
| 轻量端侧 | Kokoro / Piper / MeloTTS / KittenTTS / supertonic / sherpa-onnx | CPU / 嵌入式 / 端侧 |
| 视频配音流水线 | pyvideotrans / VideoLingo / KrillinAI / VoiceStudio / SmartSub | 翻译 + 配音 + 字幕整链 |

## 一、浏览器端 TTS

### Web Speech API（原生，零依赖）

浏览器内置的 `SpeechSynthesis`，无需下载模型或配置密钥。

- 优点：零成本、跨端、即开即用。
- 缺点：音色由操作系统决定，不同设备/浏览器不一致，不是「动漫女声」质量，且通常依赖系统在线语音。
- 代表库：[mdn/web-speech-api](https://github.com/mdn/web-speech-api)、[voice-elements](https://github.com/zenorocha/voice-elements)、[easy-speech](https://github.com/leaonline/easy-speech)、[react-speech](https://github.com/AndrewKeig/react-speech)。
- 适用：快速原型、无障碍朗读、非关键对白预览。

### 浏览器内本地模型（WASM / WebGPU / ONNX）

- [transformers.js](https://github.com/huggingface/transformers.js)：HuggingFace 官方，直接在浏览器里跑 Transformers，无需服务器，Apache-2.0。
- **Kokoro 82M**：Apache-2.0，约 82M 参数，支持普通话 `zh` 管线，可通过 kokoro.js / ONNX Runtime Web 在浏览器内 100% 本地跑。相关项目：[hexgrad/kokoro](https://github.com/hexgrad/kokoro)、[StreamingKokoroJS](https://github.com/rhulha/StreamingKokoroJS)、[HeadTTS](https://github.com/met4citizen/HeadTTS)（含时间戳与口型 viseme）。
- [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)：Apache-2.0，C++ / ONNX 跨端，支持 WASM 浏览器端与 Android / iOS / 树莓派 / 嵌入式，无网运行。
- [Parler-TTS WASM](https://github.com/danielclough/parler-tts-wasm)：Rust + WASM 在浏览器生成 Parler-TTS。
- 适用：HTML 预览器里本地高质量试听，不依赖后端服务。

### 在线但免密钥

- [edge-tts](https://github.com/rany2/edge-tts)：调用微软 Edge 在线 TTS，无需 Edge / Windows / API key；质量不错，但不是本地离线。

## 二、本地高质量 / 声音克隆（模型级）

| 引擎 | 主打 | 许可 | 备注 |
| --- | --- | --- | --- |
| [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS) | 约 1 分钟 few-shot 克隆，中/日/英/韩/粤，自带 WebUI | MIT | 固定角色音色首选 |
| [CosyVoice](https://github.com/QwenAudio/CosyVoice) | 多语言零样本克隆、流式、角色演绎 | Apache-2.0 | 对白演技与情绪 |

## 三、对话 / 短剧型

- [ChatTTS](https://github.com/2noise/ChatTTS)：面向日常对话的生成式语音，中英为主，适合短剧对白；注意 **AGPL-3.0**。
- [dia](https://github.com/nari-labs/dia)：一次生成多角色对话，适合场景对白。

## 六、针对本项目的选型建议

面向 OpenMontage / RTX 4060 Laptop 8GB / HTML 预览器：

- 本地主力：IndexTTS / CosyVoice / GPT-SoVITS，详见 [[配音生成-本机TTS引擎选型]]。
- 浏览器预览：先用 Web Speech API 做零依赖兜底；要本地高质量就用 Kokoro（transformers.js / ONNX Runtime Web）。
- 整条视频配音：pyvideotrans / VideoLingo / KrillinAI 可作字幕 + 配音流水线参考。
- 许可注意：ChatTTS 为 AGPL、VoiceStudio 为 AGPL、KrillinAI 与 pyvideotrans 为 GPL、F5-TTS 模型为 CC-BY-NC、IndexTTS / fish-speech / edge-tts 为 Other（非标准开源许可），商用前逐项查清。
