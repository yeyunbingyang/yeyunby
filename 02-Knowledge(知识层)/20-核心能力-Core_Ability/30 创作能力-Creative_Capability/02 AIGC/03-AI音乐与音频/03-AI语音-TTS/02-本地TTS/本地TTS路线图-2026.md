# 本地 TTS 路线图（2026-08）

## 快速分层

| 目标 | 优先候选 | 核心理由 |
|---|---|---|
| 高质量角色对白 | IndexTTS2 | 零样本、情绪与时长控制方向明确 |
| 多语言/情绪/训练部署 | Fun-CosyVoice3 | 官方当前主推 0.5B 系列 |
| 固定角色音色 | GPT-SoVITS | few-shot/训练工具链成熟、角色克隆常用 |
| 轻量快速预览 | Kokoro 82M | 模型小、Apache 权重、CPU/浏览器友好 |

## IndexTTS2

官方在 2025-09 发布 IndexTTS-2，重点是：

- 零样本 TTS
- 强情绪表达
- 将情绪与说话人身份解耦
- 精确时长控制方法（视频配音尤其重要）

注意：官方更新说明曾注明某些精确时长控制功能在初始公开 release 中尚未全部启用，因此实际项目要以当前代码/模型状态实测，而不是只看论文能力。

## Fun-CosyVoice3

CosyVoice 官方当前推荐 `Fun-CosyVoice3-0.5B`，并提供训练、推理、WebUI、vLLM 等路线。它适合作为“完整 TTS 平台”研究，而不仅是单个推理模型。

## GPT-SoVITS

优势在角色克隆与数据工具链。适合：

- 为固定角色准备参考音频
- 少量数据微调
- 中文/日文/英文等角色语音实验

项目更新频繁时应固定 release/commit，不要只记录“GPT-SoVITS”这个名字。

## Kokoro 82M

Kokoro 是轻量开放权重 TTS，适合作为：

- 文本编辑时快速试听
- CPU 预览
- 浏览器端/ONNX 路线

它不替代角色高一致性克隆引擎，而是承担“快”。

## 选择原则

```text
先确定是否需要固定音色
→ 是否需要强情绪
→ 是否需要视频时长对齐
→ 是否必须离线
→ 再比较显存、速度、许可和语言
```
