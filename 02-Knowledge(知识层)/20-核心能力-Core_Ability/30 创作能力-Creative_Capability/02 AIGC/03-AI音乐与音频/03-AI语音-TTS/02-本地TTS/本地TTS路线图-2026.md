# 本地 TTS 路线图（2026-08）

## 快速分层

| 目标 | 优先候选 | 核心理由 |
|---|---|---|
| 高质量角色对白 | **IndexTTS-2.5** | 零样本、多语言、情绪/语速/发音控制、生产服务化 |
| 多语言/情绪/训练部署 | Fun-CosyVoice3 | 官方当前主推 0.5B 系列 |
| 固定角色音色 | GPT-SoVITS | few-shot/训练工具链成熟、角色克隆常用 |
| 轻量快速预览 | Kokoro 82M | 模型小、CPU/浏览器路线友好 |

## IndexTTS-2.5

官方在 **2026-08-10** 发布 IndexTTS-2.5，当前重点包括：

- 单参考音频零样本声音克隆
- 中文、英文、日文、西班牙文、阿拉伯文
- 音色与情绪解耦
- 情绪参考音频控制
- 8 维情绪向量控制
- `emo_alpha` 情绪强度控制
- `duration_factor` 语速/时长倍率控制（约 0.5x–2.0x）
- 中文拼音、英文 CMU phoneme、日文 Kana 发音控制
- 相比 IndexTTS-2 更快的推理
- vLLM 生产部署路线

注意：IndexTTS-2 旧版新闻中提到的“精确合成时长控制”曾在初始 release 中未启用；**2.5 当前公开的是 `duration_factor` 语速/时长倍率控制，不应直接等同于任意目标毫秒级精确对齐。**

详见：[[IndexTTS-2.5-项目笔记]]

## Fun-CosyVoice3

CosyVoice 官方当前推荐 `Fun-CosyVoice3-0.5B`，并提供训练、推理、WebUI、vLLM 等路线。它适合作为“完整 TTS 平台”研究，而不仅是单个推理模型。

> 待补：独立项目知识卡与 Windows 部署笔记。

## GPT-SoVITS

优势在角色克隆与数据工具链，适合：

- 为固定角色准备参考音频
- 约 5 秒参考做 zero-shot 快速验证
- 少量数据 few-shot 微调
- 中文/日文/英文/韩文/粤语等角色语音实验
- 音频切片、ASR、标注、训练一体化流程

它更适合“长期维护角色声音资产”，而 IndexTTS-2.5 更适合“强可控的零样本生成”。

详见：[[GPT-SoVITS-项目笔记]]

## Kokoro 82M

Kokoro 是轻量开放权重 TTS，适合作为：

- 文本编辑时快速试听
- CPU 预览
- 浏览器端/ONNX 路线

它不替代角色高一致性克隆引擎，而是承担“快”。

## 选择原则

```text
先确定是否需要固定音色
→ 是否有可训练的角色数据
→ 是否需要强情绪
→ 是否需要视频时长/语速控制
→ 是否必须离线
→ 是否需要服务化
→ 再比较显存、速度、许可和语言
```

## 推荐组合，而不是单模型统治

```text
快速角色原型
→ IndexTTS-2.5 / GPT-SoVITS Zero-shot

固定角色长期维护
→ GPT-SoVITS few-shot

高情绪 / 多语言 / 视频对白
→ IndexTTS-2.5

轻量试听
→ Kokoro
```
