# 附录A：提示词库

> [!important] 使用方法
> 先填公共变量，再选择一个任务模板和一个工具适配。一次只生成一张独立母资产；负面词只约束当前风险，不堆叠互相冲突的审美词。

## 公共变量

```text
角色编号：{角色ID}
身份参考：{正面母版/多角度图及职责}
身体参考：{冻结身体母版}
风格参考：{动漫正面母版或抽象视觉模块}
目标角度：yaw={值}，pitch={值}，roll={值}
表情：平静、闭嘴、不露齿
镜头：85mm长焦感，视平线稳定，低透视畸变
输出：{分辨率/画幅/独立图或展示板}
冻结项：脸型、眼距、眼型、鼻梁鼻尖、嘴唇、下颌、年龄、肤色、发际线、发缝、发色、发长、身体比例
可变项：{本轮唯一变量}
```

## 1. 身份母版

### GPT模板

```text
使用我提供的全部已授权人物图作为同一成年角色的身份证据。以清晰正面图为主要几何锚点，其他角度只补充被遮挡结构，不平均、不拼接、不重新设计面孔。

生成一张标准正面0°身份母版：头部无倾斜，双眼平视，表情平静，嘴巴轻闭，不露齿；补全头顶、双耳、下巴和肩部。严格保留脸型与下巴、眼距与眼型、眉形、鼻梁与鼻尖、嘴唇厚度与嘴角、年龄感、肤色、发际线、发缝、发色、发长及妆容。浅灰影棚背景，85mm人像摄影感，柔和均匀光线，真实皮肤纹理。

禁止美化、幼化、尖下巴、放大眼睛、缩小鼻子、改变发缝、左右拼脸、双重五官、文字和多格排版。只输出一张独立正面图。
```

### 即梦适配（待实测）

将最清晰正面图设为身份主参考，其余图标注为“同一人物的结构补充”；身份权重高，风格权重低。提示中明确“单图输出、正面0°、不拼图”。若平台支持局部重绘，先修轮廓和眼睛，不同时改变妆容。

## 2. 人脸多角度

### 通用单角度模板

```text
以通过验收的正面身份母版作为唯一身份锚点，生成同一人物的{目标角度}独立头像。头部姿态必须由真实三维旋转产生，不只改变眼神。保留全部冻结身份特征、年龄、肤色、妆容和发型；保持相同镜头、光线、白平衡、背景、头部大小和肩部裁切。

目标：yaw={yaw}°，pitch={pitch}°，roll=0°。嘴巴轻闭，不露齿。禁止镜像复制、重新设计远侧五官、双重轮廓、多格板和文字。
```

严格90°追加：`远侧眼不得完整可见，鼻梁、鼻尖、嘴唇和下巴形成准确侧面轮廓，耳位与颅骨透视自然。`

俯视追加：`角度来自头颅向下旋转，能够看到更多头顶，不能只向下看。`

## 3. 真人全身三视图与身体比例

### 正面合成身体母版

```text
将已通过验收的真人脸部母版用于一个明确标注为“合成身体”的成年女性全身正面建模参考。标准A-Pose，双脚与肩同宽，手臂离躯干约25°，掌心朝大腿，赤脚。穿深灰色不透明长袖贴身上衣与及踝贴身裤，不使用裸露或透视材质。

自然成人比例，头顶至脚底完整，重心稳定。冻结脸部身份、肩宽、胸廓、腰、骨盆、四肢粗细、手脚大小。浅灰背景，长焦低畸变，镜头与骨盆同高。只输出一张正面0°独立图。
```

### 侧面/背面

```text
同时参考冻结脸部母版和已通过的全身正面身体母版，仅将角色旋转到{严格左侧90°/背面180°}。不得改变身高、头身比、肩宽、腰臀、腿长、发长、服装、光线和镜头。保持头顶线、脚底基线及画布占比一致。只输出一张独立图。
```

### 比例控制

```text
仅将头身比调整为{7.5/8.0/8.2}头身，其余全部冻结。不可通过拉长画布、颈部、躯干或单独拉长小腿伪造比例；头、胸廓、骨盆、膝、踝必须按整体骨架协调变化。
```

男性示例（未实测）：将性别、肩胯关系、肌肉量和服装参数替换为成年男性规格，但继续使用自然比例、A-Pose和独立视图门禁。

## 4. 动漫化与风格母版

```text
以真人正面身份母版和冻结身体母版为身份与比例真值，将角色转换为{风格模块}。这是同一人物的风格化版本，不是新角色。绝对保留脸型与下巴、眼距与眼型、鼻梁鼻尖、嘴唇、年龄、肤色、发际线、发缝、发色、发长及妆容关系。

允许：眼睛视觉放大{0～12%}；减少皮肤毛孔；将鼻部纹理简化为结构清晰的体块；轻微图形化发量。禁止：尖化下巴、幼化年龄、缩鼻、机械对称双眼、无毛孔塑料脸、改变身体比例。

场景为{背景场景}，服装为{符合世界观、职业、天气与动作的服装}。背景必须有空间层次和叙事信息，不使用纯色证件照背景；人物轮廓需与背景有明度或色相分离。只输出正面0°独立全身图。
```

风格模块应写可观察属性，例如“清晰赛璐璐分层、稳定外轮廓、有限高光、低饱和夜景与局部霓虹反射”，不要只写作品名或在世艺术家姓名。中日韩18类模块见[[风格与作品研究]]。

## 5. 动漫三视图

```text
身份由真人正面母版决定，身体和目标角度由对应真人三视图决定，比例由冻结全身正面决定，风格由已通过的动漫正面母版决定。生成{正面0°/严格侧面90°/背面180°}独立全身图。

严格保持8项：动漫脸部身份、自然头身比、肩腰胯、发型发缝、服装版型、材质渲染、背景职责、镜头与脚底基线。不得把背面改成回头露脸，不得让侧面出现完整远侧眼，不得因风格化拉长身体。
```

## 6. 表情与换装

### 表情

```text
保持动漫身份母版的全部结构，只将表情改为{喜/怒/哀/惊/冷静}。表情来自眉、眼睑、嘴角和面部肌肉的协调变化；不改变眼睛尺寸、鼻型、脸宽、年龄、发型或镜头。每次只生成一种表情。
```

### 换装

```text
保持身份、身体比例、姿态、角度、发型和镜头完全不变，仅将服装替换为{服装描述}。服装必须符合{世界观/职业/季节/天气/动作/场景}，布料受力与身体结构一致。禁止通过紧身、厚底鞋、长裙摆或高腰线改变视觉头身比。
```

## 7. 四格场景效果板

四格必须先分别生成，再排版。

1. 近景：`胸像近景，背景有可识别环境虚化，重点验证脸部与光线。`
2. 全身：`完整场景中的全身动作，服装、身体比例、脚部接地正确。`
3. 环境：`人物占比低，广角展示建筑、植被、天气、材质和空间层次。`
4. 动作：`叙事高潮镜头，动作与服装结构合理，运动方向清晰。`

统一追加：

```text
四张图必须属于同一世界观、同一角色和同一时间段；服装与背景场景一致。不要在单张图内生成拼图、边框、标签或重复人物。通过验收后再用固定模板排成2×2展示板。
```
