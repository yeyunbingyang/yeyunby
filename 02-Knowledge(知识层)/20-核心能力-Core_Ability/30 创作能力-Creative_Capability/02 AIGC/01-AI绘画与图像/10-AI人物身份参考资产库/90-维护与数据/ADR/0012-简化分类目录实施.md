# 简化分类目录实施

## 决策

取消 `00-导航与说明`，将唯一项目 MOC 放在资产库根目录。取消独立的“风格与作品研究”一级目录，将其作为可复用知识并入 `01-方法与提示词`。角色正文与实验按角色聚合，媒体仍区分过程、失败和最终交付状态。

## 路径语义

- Wikilink 以知识库根解析；带职责目录的路径按项目根兼容解析。
- Markdown 的 `./`、`../` 相对当前文件解析。
- JSON 中 HTTP(S) 地址为外部链接；本地媒体路径按项目根解析。
- 所有媒体移动后必须同步改写 Markdown 嵌入与 JSON 本地路径。

## 删除边界

不删除正文、JSON 或媒体。只在文件完成迁移、引用修复和对账后移除空的旧目录。

## 实施结果

- 根目录只保留 `AI人物身份参考资产库-MOC.md` 作为项目入口，原内容摘要已合并并归档。
- 活跃内容已收敛为方法与提示词、角色与实验、过程资产、失败与版本、最终交付物五类；术语、JSON、ADR和验证报告统一进入维护区。
- 旧分区导航页已经归档，归档区所有 Markdown 均使用 `status: 归档`。
- 所有媒体、JSON和正文均完成实体迁移；迁移后移除了确认无文件的旧目录树。
- 活跃正文、历史嵌入和 JSON 本地路径已改写为新路径；ADR 和验证报告中的旧路径保留为历史决策证据。
