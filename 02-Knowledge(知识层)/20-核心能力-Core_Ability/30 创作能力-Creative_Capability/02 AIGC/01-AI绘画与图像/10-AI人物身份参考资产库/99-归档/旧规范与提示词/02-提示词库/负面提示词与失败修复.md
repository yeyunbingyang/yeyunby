# 负面提示词与失败修复

## 十、失败修复提示词

### 身份漂移

```text
当前结果不是身份母版中的同一人物。
不要重新生成或美化面孔。
以图1为唯一身份真值，恢复脸型、眼间距、眉眼比例、鼻部结构、
唇形、下巴、下颌和年龄。
只保留当前图的姿态、角度和构图。
```

### 侧面不够90°

```text
将整个头骨和颈部继续旋转到严格90°。
鼻尖朝画面[左/右]；
远侧眼睛不能完整可见；
额头、鼻梁、鼻尖、人中、嘴唇和下巴形成连续侧面剪影。
保持身份、相机、光线和裁切不变。
```

### 俯视只改变眼神

```text
不要改变眼神来伪造俯视。
让整个头骨真实低头[pitch数值]：
额头可见面积增加，下巴可见面积减少；
眼睛、鼻尖、嘴唇、耳朵和下颌产生合理垂直透视；
颈部与下巴连接随低头自然变化。
```

### 左右被镜像

```text
禁止水平镜像。
生成角色真实的另一侧视角。
保留发缝方向、刘海落点、自然面部轻微不对称和耳朵细节；
根据真实三维头部结构重新计算遮挡与透视。
```

### 换装后换脸

```text
服装参考图中的模特身份污染了结果。
恢复图1角色的完整人脸、发型、年龄和肤色；
只从服装素材提取衣服，不继承服装模特的任何人体特征。
```

### 换装后身材改变

```text
恢复图2中的原始身高、头身比、肩宽、腰线、胸廓、骨盆、
四肢长度和关节位置。
服装必须适配人物，不能让人物适配服装。
```

### 三视图透视不一致

```text
统一为长焦、远距离、低透视畸变的建模参考效果。
保持相同人物高度、头部尺寸、脚底基线和相机距离；
相机位于腰腹高度，不俯拍、不仰拍；
禁止头大脚小、近大远小和广角拉伸。
```

## 十一、负面提示词

## 基础负面约束

```text
禁止换脸、身份美化重设计、年龄变化、发缝反转、机械镜像脸、眼睛高低差扩大、两眼尺寸明显不等、斜视、瞳孔错位、双重五官、额外耳朵、露齿、张嘴、头顶或脚底裁切、广角畸变、透视夸张、耸肩、叉腰、弯肘、双腿交叉、高跟鞋、裙装、半透明服装、额外手指、粘连手指、脚部融合、重心偏移、复杂背景、文字、水印、拼图。
```

## 单项修复模板

```text
编辑当前图，只修复【可观察失败变量】。必须冻结人物身份、头部方向、表情、发型与发缝、身体比例、姿势、服装、镜头、灯光、背景、裁切和分辨率。不得重新设计整张图，不得顺带美化其他区域。
```

### 眼睛不对称

```text
仅校正新增的眼睛结构错误：使双眼中心线符合原身份参考的自然不对称基线，瞳孔注视同一点，两眼可见宽高差不得比参考新增超过10%。保持眼型、眼距、眼妆和眉形，不做机械左右镜像。
```

### 全身小脸两级锚定

```text
参考图A是已验收的高分辨率同风格头肩脸母版，只决定脸型、双眼、瞳孔、眼睑、眼距、鼻唇、年龄、发缝与妆容；参考图B只决定冻结身体、姿势、服装、镜头和画幅。将A中完整清晰的脸部结构准确下采样到B的全身小脸中，不得重新随机设计眼睛。两眼各只有一个清晰瞳孔，注视同一目标；保留身份参考天然不对称，但不得新增眼裂高低差或宽高差。禁止改变身体、头身比、姿势、服装、背景和裁切。
```

> [!important] 使用条件
> 当全身图面部宽度较小、一次局部修复仍有眼裂塌缩或瞳孔模糊时，停止直接修小脸，先建立高分辨率同风格脸母版。

### 严格侧面

```text
仅修复头部与躯干的侧向角度为严格90°；鼻梁、嘴唇和下巴形成清晰侧面轮廓，远侧眼不得完整可见。冻结身份、身高、服装、A-Pose和脚底基线。
```
