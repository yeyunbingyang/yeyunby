# 原创四格风格效果板提示词与操作

## 正确工作流

```text
文字身份规格
→ 生成人脸母版
→ 生成自然7.5头身身体母版
→ 为每种风格确定一套场景服装
→ 近景、全身、环境、动作分别生成
→ 单格验收与单项修复
→ 本地确定性2×2排版
```

> [!important] 两种服装不可混用
> 深灰建模服用于身体比例基准；正式效果板必须使用与场景匹配的服装，但同一风格四格必须是同一套服装。

## 研究角色 S01 身份块

```text
成年东亚女性，约25岁；窄椭圆脸，柔和下颌；中等眼距，杏仁形深棕眼；直鼻梁、圆润鼻尖；中等厚度闭合嘴唇；浅暖肤色；深棕侧分及胸长发；自然克制妆容；自然7.5头身。保持年龄、脸型、眼距、眼型、鼻尖、唇形、发缝和发长一致。
```

## 四个独立分格模板

### 1. 人物近景

```text
使用身份母版锁定脸和头发。生成且只生成一张正面0°头肩近景。背景为与目标世界观一致的真实场景，并使用浅景深弱化；不可使用纯色或影棚背景。两眼中心线水平、瞳孔方向一致、嘴巴闭合。服装领口必须属于本风格已冻结的场景服装。
```

### 2. 全身设计

```text
使用脸部母版决定身份、身体母版决定自然7.5头身。标准A-Pose，手臂离躯干约25°，全头和鞋底完整，长焦低畸变。穿本风格已冻结的场景服装，脚部与地面真实接触，人物光色与背景一致。
```

### 3. 环境与材质

```text
生成且只生成一张连续宽幅环境画面；禁止拼图、分屏和重复人物。人物作为较小但可识别的全身角色出现，固定身份、7.5头身和同套场景服装。重点展示建筑、材质、空气透视、天气和主辅光，保持正确透视与脚底接触。
```

### 4. 动作与镜头

```text
生成且只生成一个动作瞬间，不得生成动作分解图或四宫格。人物穿同套场景服装，在完整叙事背景中完成一个可读动作；两臂两腿、手指和关节正确，身体重心与地面关系可信，脸仍可识别。
```

## 失败修复词

### 服装与背景不匹配

```text
只修复服装。保留人物身份、7.5头身、姿势、构图、背景、光照和镜头不变；替换为已冻结的场景服装，并使材质、鞋履和受光与当前环境一致。禁止新增首饰、铠甲、长袍或品牌标记。
```

### 环境格误生成拼图

```text
生成一张单一、连续、无边框的宽幅环境画面。绝对禁止拼图、分屏、画中画、重复人物和多机位。画面中只出现一个人物。
```

### 身体过长

```text
只缩短躯干和腿长，使头顶到脚底为自然7.5头身，误差不超过±0.1头；保持肩宽、脸、服装、姿势、背景和镜头不变，禁止缩小头部来伪造比例。
```

### 眼睛不对称

```text
只校正新增的眼睛结构错误：双眼中心线水平，瞳孔大小与视线一致，眼裂宽高差不超过身份母版的自然差异；保留原生轻微不对称，禁止机械镜像另一只眼，其他内容不变。
```

## 即梦操作映射（未实测）

1. 先用文字生成正面身份母版并选定一张。
2. 后续将身份母版设为人物参考，将身体母版设为姿态/体型参考。
3. 每次只生成一个分格；环境格和动作格仍引用身份母版。
4. 风格参考只决定线条、材质和光色，不得覆盖人物参考。
5. 将“同套场景服装”和负面提示词重复写入每次调用。
