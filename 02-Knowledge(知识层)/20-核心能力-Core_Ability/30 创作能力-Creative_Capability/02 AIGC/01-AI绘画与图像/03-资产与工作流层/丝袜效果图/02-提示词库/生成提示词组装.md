# 生成提示词组装

> [!important] 表达边界
> 本文只把已确认参数翻译成模型指令。编号、权重和效果事实来自 [[生成参数库]]；本文不得建立平行参数体系。

## 组装顺序

```text
任务目标 → 商品锁定块（B＋可选E） → 展示策略 → 模特 → 造型 → 姿势 → 构图场景 → 人体合规 → 负面约束 → 平台适配
```

## 通用核心模板

```text
【任务】
生成{数量}张丝袜商品图；展示模式为{基础展示/扩展展示}，展示策略为{D-BASE/D-CATALOG/D-DETAIL/D-LIFESTYLE}。

【商品锁定】
基础色系：{B-C编号＋名称＋视觉定义}
基础厚度：{B-D编号＋D数＋视觉定义}
基础透明度：{B-T编号＋名称＋参考可见度}
扩展效果：{基础展示填写“无”；扩展展示填写唯一E编号＋名称}
必须可见：{E条目的必须可见特征；基础展示填写当前变化轴}
禁止误读：{E条目的禁止误读；基础展示禁止任何E信息}
标签：{功能/文化/题材/风格/季节/场景，仅作筛选，不产生第二个效果}

【展示参数】
模特：{默认亚洲成年女性M-REAL-01/02/03/07/08；欧美M-REAL-04/05/06与VM-ANIME仅用户手动指定；同页不得混排}
造型：{O编号＋核心服装＋鞋履}
姿势：{姿势编号＋支撑腿＋腿部前后关系＋接触面}
构图：{构图编号＋镜头}
景别裁切：{默认H01下半身商品构图；或用户指定H02/F01/H03}
背景道具：{BG编号＋PR编号}
版式：{分类批量填写PL编号＋大标题＋子标题＋页码＋01—12编号＋短名称＋短描述＋底部说明，并与宫格画面同次生成；锁商品单图填写单图版式或“无宫格版式”}
光线：{方向＋软硬＋色温}
输出：{用途＋比例}

【商品可见性】
丝袜从袜口到脚尖完整可辨；服装、鞋履和道具不得遮挡必须可见特征。
默认H01：画面上缘从腰部或胯部开始，向下完整保留双腿、袜口、脚踝、脚尖、后跟和鞋履；禁止在大腿、膝盖、小腿、脚踝或脚部中途截断，禁止普通上半身裁切。
展示变量只负责呈现，不得改变色系、厚度、透明度或扩展效果。

【人体与合规】
明确成年、完全着装、非挑逗性的商业时装表达。
恰好两条腿、两个膝盖、两个小腿、两个脚踝、两只脚和两只鞋；关节方向、重心和接触真实。
使用虚构身份，禁止未成年或幼态、真人复刻、名人、品牌和校徽。

【负面约束】
禁止多肢、融合腿、双重膝盖、脚踝断裂、鞋脚分离、悬空鞋、道具穿模；
禁止纹理漂浮、丝袜变紧身裤、颜色漂移、左右腿无意不一致、叠加第二个E；
禁止乱码、水印、品牌标志和图片内长段落；分类批量只允许版式规定的大标题、子标题、编号、短名称、单行短描述和底部短说明。
```

## 展示策略附加块

### D-BASE

```text
这是严格技术对照策略。只允许{色系/厚度/透明度}变化，另外两个基础维度按基准锁定或物理联动。
固定构图、姿势、服装、鞋履和主光；禁止E。仅当任务明确为“分类批量基础页”时，不直接使用本展示策略，而是使用D-CATALOG展示策略并附加“B轴单变量商品门禁”。
```

### D-DETAIL

```text
这是扩展效果准确展示。优先保证“必须可见特征”，按效果选择稳定站姿、坐姿、前后对比或局部特写。
背景保持低干扰，不要求站、坐、躺、创意四类全覆盖。
```

### D-CATALOG

```text
这是分类批量图鉴。商品层只变化当前主分类，每格按商品重新匹配亚洲成年女性模特、服装、姿势、构图、背景、道具和光线。
12格执行S5＋C3＋L2＋P2：站立/行走5格、坐姿3格、躺卧/休息2格、创意互动2格；允许与商品和场景匹配的复杂道具，但不得遮挡、复制或冒充丝袜效果。
必须逐格写入姿势编号和动作事实，不得只写“多种姿势”或“姿势随机”。
基础主类的主展示策略仍为D-CATALOG，同时附加“B轴单变量商品门禁”；不得把D-BASE的固定姿势、构图和服装要求带入分类批量基础页。扩展主类附加D-DETAIL必须可见特征门禁。
```

### D-LIFESTYLE

```text
这是传播场景图。允许变化服装、姿势、背景和道具，但商品锁定块保持不变。
商品效果必须仍然清晰可辨，传播表现不得覆盖技术事实。
```

## 姿势控制块

```text
动作名称：{姿势动作参数中的动作事实}
支撑腿：{左/右/双腿}
非支撑腿：{位置和弯曲程度}
膝盖方向：{明确方向}
脚与鞋：两只鞋分别连接对应脚掌，并真实接触地面或道具。
```

## 多格差异规则

- D-BASE 不追求姿势和场景多样，只保证单一变量对比。
- D-DETAIL 相邻格的 E、姿势或构图至少有两项不同。
- D-LIFESTYLE 相邻格在姿势、服装、背景中至少两项不同；不强制四类姿势全覆盖。
- 每格保存完整参数快照。分类批量原生宫格失败时整页重做；锁商品逐图生产失败时只重做失败图。

## 分类批量原生宫格提示词预检

调用生图前必须逐项确认：

- 全页12格均已写出商品取值、姿势编号、动作事实、构图、H01半身景别和格位文案；同一条提示词装载完整12格映射。
- 姿势编号计数精确为S组5个、C组3个、L组2个、P组2个；同页无重复编号。
- L组必须保持成年、完全着装和商品完整可见；P组与复杂道具必须写明用途、接触面及无遮挡要求。
- 提示词明确写出：exactly 12 panels、4 columns by 3 rows、one native designed contact sheet、all panels and typography generated together、no post-assembly、no watermark。
- 标题、页码、01—12编号、短名称、单行短描述和底部短说明必须进入同一图片提示词；禁止图片内长段落。
- 任一项未满足时停止调用，补齐后再生成。

## 平台适配层

- **ChatGPT**：保留分块标题和硬约束。分类批量固定一次尝试生成原生12格及内嵌版式，不使用4–8格拆批；若当前环境无法直出12格，则记录该环境不适用，不得静默改为子图拼接。锁商品多图按单张顺序生成。
- **Gemini**：商品锁定、身份参考和比例前置；减少重复否定句。
- **即梦**：精简为主体、材质、构图、光线、负面词五段。
- **豆包**：使用明确自然语言，不依赖专用权重符号。
