# 格子图版式参数

> [!important] 原生宫格与短文字同图生成
> 分类批量必须把12格画面、版式和全部规定短文字合并进同一个整页提示词，由图片模型在一次生成尝试中直接输出成板宫格。文字只允许使用下列固定字段，禁止自由扩写长段落；若画面或文字不合格，整页重生，不得拆格拼接或后期替换文字。锁商品任务按锁商品模式执行，默认是单图，不继承分类批量的12格要求。

## 01 固定信息层级

| 层级 | 元素 | 必填 | 内容限制 | 默认位置 |
|---|---|---|---|---|
| L1 | 大标题 | 是 | 6–14个中文字符，只写当前主类 | 顶部标题区 |
| L2 | 子标题 | 是 | 12–28个中文字符，说明本页比较范围 | 大标题下方 |
| L3 | 主类编号／页码 | 是 | 如 `B-C · 01/09` | 标题区右上 |
| L4 | 格位编号 | 是 | 固定 `01–12`，两位数字 | 每格左上角 |
| L5 | 子类短名称 | 是 | 2–8个中文字符 | 每格底部信息条第一行 |
| L6 | 格位描述 | 是 | 默认8–18个中文字符；PL-02压缩为6–10字 | 每格底部信息条第二行或PL-02底部编号图例 |
| L7 | 底部简略说明 | 是 | 24–48个中文字符，说明抽取和阅读方式 | 页面底部说明区 |
| L8 | 图例／参数摘要 | 可选 | 最多3项，如B规则、E唯一性、姿势配额 | 底部说明区或侧栏 |
| L9 | 版本／日期 | 可选 | 如 `v1 · 2026-08-03` | 底部右侧 |

### 默认文案格式

```text
大标题：{主分类中文名称}
子标题：12种代表效果 · 亚洲成年女性商业展示
主类编号：{B-C / B-D / B-T / E-01…E-06} · {页码}/09

格位：{01}
短名称：{子类或条目短名称}
描述：{必须可见特征的压缩表达}

底部说明：每格独立抽取商品与展示参数；编号用于分类索引，具体效果以参数快照为准。
```

## 02 固定版式方案

### PL-01 标准完整目录版（默认）

| 参数 | 规则 |
|---|---|
| 画幅 | 竖版9:16，推荐2160×3840 |
| 图片矩阵 | 4列×3行，共12格 |
| 标题区 | 顶部约10% |
| 宫格区 | 中部约82% |
| 底部说明区 | 底部约8% |
| 单格信息 | 编号＋短名称＋一行描述 |
| 风格 | 暖白或浅灰底、深灰文字、细分隔线 |
| 适用 | 默认全量分类图鉴、移动端查看、信息完整交付 |

### PL-02 紧凑商品目录版

| 参数 | 规则 |
|---|---|
| 画幅 | 竖版3:4，推荐2400×3200 |
| 图片矩阵 | 4列×3行，共12格 |
| 标题区 | 顶部半透明或纯色窄条，叠加在安全区内 |
| 底部说明 | 单行窄条，不超过32字 |
| 单格信息 | 编号＋2–6字短名称＋6–10字单行描述；空间不足时将描述移入底部编号图例，不得取消 |
| 风格 | 高密度、低装饰、图片优先 |
| 适用 | 平台只支持3:4、预览图、快速翻阅 |

### PL-03 编辑杂志卡片版

| 参数 | 规则 |
|---|---|
| 画幅 | 竖版3:4或9:16 |
| 图片矩阵 | 4列×3行，卡片间距加宽 |
| 标题区 | 左对齐大标题＋细分隔线＋右侧页码 |
| 单格信息 | 白色卡片底、编号突出、名称和描述分层 |
| 风格 | 时装编辑、克制衬线标题＋无衬线正文 |
| 适用 | E-02图案、E-03材质、E-05染色等视觉专题 |

### PL-04 深色高级材质版

| 参数 | 规则 |
|---|---|
| 画幅 | 竖版3:4或9:16 |
| 图片矩阵 | 4列×3行 |
| 背板 | 深灰、炭黑或深藏青，禁止纯黑吞噬丝袜边缘 |
| 文字 | 暖白正文＋低饱和金属色编号 |
| 单格信息 | 底部深色渐变条，保持腿部主体无遮挡 |
| 适用 | 黑色系、金属、珠光、晚宴、视觉构造 |

### PL-05 社媒封面叙事版

| 参数 | 规则 |
|---|---|
| 画幅 | 竖版9:16 |
| 标题区 | 约15%，标题可换行两行 |
| 图片矩阵 | 4列×3行；前4格只通过强调色编号、较高信息条对比度或细边框提高视觉权重，格子尺寸和编号顺序不变 |
| 底部 | 一句阅读提示＋系列页码 |
| 风格 | 标题醒目、信息较少、适合滑动连续发布 |
| 适用 | 社媒系列封面、分类合集首图 |

### PL-06 横向技术对照版

| 参数 | 规则 |
|---|---|
| 画幅 | 横版4:3或16:9 |
| 图片矩阵 | 4列×3行或6列×2行 |
| 标题区 | 左侧或顶部窄条 |
| 单格信息 | 编号＋参数值优先，描述可进入底部图例 |
| 风格 | 白底、网格线清楚、控制变量表达 |
| 适用 | 桌面汇报、B-C/B-D/B-T严格技术对照 |

## 03 默认选型

| 内容 | 默认模板 | 可选模板 |
|---|---|---|
| B-C 色系 | PL-01 | PL-02、PL-06 |
| B-D 厚度 | PL-01 | PL-02、PL-06 |
| B-T 透明度 | PL-01 | PL-02、PL-06 |
| E-01 纹理与织造 | PL-01 | PL-03 |
| E-02 图案与纹样 | PL-03 | PL-01、PL-05 |
| E-03 材质与表面 | PL-03 | PL-04 |
| E-04 商品结构与款式 | PL-01 | PL-06 |
| E-05 染色与显色工艺 | PL-03 | PL-04、PL-05 |
| E-06 视觉构造 | PL-04 | PL-03、PL-05 |

默认优先级固定为：用户手动指定最高；完整九张套图未指定时全部统一使用PL-01；只生成单个主类且未指定时，使用上表的主类默认模板。不得在同一套图中无理由混用多个模板。专题传播版可在完整目录交付后另行派生。

## 04 栅格与安全区

- 12格固定按从左到右、从上到下编号，禁止蛇形编号。
- 外边距不小于短边的4%；格间距为短边的0.8%–1.2%。
- 标题、编号和信息条不得覆盖袜口、膝盖、脚踝、脚尖、后跟或E关键特征。
- 编号与短名称的对比度不低于4.5:1；说明文字不低于3:1。
- 每格图片裁切方式统一，但允许为商品结构保留必要安全空间。
- 九张主类图的大标题基线、宫格起点、格位尺寸、页码和底部说明位置必须一致。

## 05 视觉令牌

| 令牌 | 默认值 |
|---|---|
| 圆角 | 0–16px；技术版默认0，编辑版8–16px |
| 分隔线 | 1–2px，中性灰或低透明白 |
| 标题字重 | 600–700 |
| 子标题字重 | 400–500 |
| 编号字重 | 700，使用等宽数字 |
| 描述行数 | 最多2行，默认1行 |
| 强调色 | 每页最多1种，从主类视觉中提取，不用于商品区域 |
| 阴影 | 默认无；卡片版只允许轻微软阴影 |

## 06 禁止项

- 禁止图内长段落、自由发挥的营销文案或未在整页提示词中逐项给出的文字；规定的大标题、子标题、编号、短名称、短描述、页码和底部说明必须与宫格同次生成并整页验收。
- 禁止每格使用超过两行描述或堆叠参数表。
- 禁止为装饰改变格位顺序、大小或子类覆盖关系。
- 禁止使用高饱和边框污染丝袜颜色判断。
- 禁止底部说明写入无法从参数快照验证的功能宣称。
- 禁止在同一页同时使用多套字体、多个强调色或强装饰纹理。
