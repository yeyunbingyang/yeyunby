# 效果编号迁移表

> [!warning] 只读历史索引
> 本表只用于追踪旧图片、实测和参数快照。旧编号不参与新任务抽取，不得作为新编号 alias。

## 范围处置

| 旧范围 | 旧职责 | 新处置 |
|---|---|---|
| E001–E020 | 色系与肤感 | 迁入 [[基础商品参数#B-C 色系]]；重复色合并 |
| E021–E040 | 透明度与厚度 | 迁入 B-D/B-T；雾面、裸感等分别归E-03或删除 |
| E041–E060 | 纹理与编织 | 审查后重编号到 [[E-01-纹理与织造]] |
| E061–E080 | 图案与艺术 | 审查后重编号到 E-01或[[E-02-图案与纹样]] |
| E081–E100 | 材质、功能与场景 | 材质进E-03；可视结构进E-04；显色进E-05；场景和不可视功能退出E |
| E101–E120 | 袜口、脚尖与拼接 | 重编号到 [[E-04-商品结构与款式]] |
| E121–E140 | 染色与色彩工艺 | 重编号到 [[E-05-染色与显色工艺]] |
| E141–E160 | 视觉错觉 | 重编号到 [[E-06-视觉构造]] |
| E161–E180 | 文化与装饰艺术 | 视觉母题进E-02/E-06；文化与风格改为标签 |
| EXT-* | 工艺、袜长、场景、动漫等混合扩展 | 工艺/袜长进对应E；场景改标签；动漫改VM-ANIME |
