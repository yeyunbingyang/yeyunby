# ADR 0004：编号按库上下文解析

## 状态

已接受（2026-08-02 实施）。

## 决策

编号前缀允许在各自库内重载：`S01` 同时存在构图与姿势，`P01` 同时存在商品效果资产与姿势，`E01` 是构图而 `E001` 是商品效果，`C01` 同时存在预设案例与姿势，`T01` 同时存在构图与实测批次。引用时必须带库名限定（如“构图 S02”“姿势 S02”“预设案例 C05”），不进行全局重命名，也不新增跨库冲突的前缀。

## 背景

多效果 SOP 同时维护构图、姿势、背景、道具和效果编号，单产品 SOP 又引入预设案例编号，前缀字符被多个库复用。若不加限定，读者和模型都无法判断一个编号指哪个库。

## 权衡

- 备选：全局重命名冲突编号。
- 拒绝理由：现有提示词示例、参数快照和大量文档已依赖这些编号，重命名成本高且收益低；提示词中带库名限定已足够消歧。
- 代价：引用编号时必须多写库名，消歧职责由 [[CONTEXT]] 承担。
