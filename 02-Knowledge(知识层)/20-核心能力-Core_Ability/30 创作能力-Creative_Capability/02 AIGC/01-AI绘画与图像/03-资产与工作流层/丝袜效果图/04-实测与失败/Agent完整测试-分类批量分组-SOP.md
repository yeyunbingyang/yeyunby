# Agent完整测试-分类批量分组-SOP

## 测试范围与证据

本轮由独立子代理执行，只读测试核心SOP与参数文件，不修改生产规则。覆盖：

- B-C、B-D、B-T及E-01至E-06，共9个主类、108个格位。
- 参数抽取、D-CATALOG、默认模特池、造型、姿势、构图、图片生成、失败格返修、PL-01拼版、文字和六层验收。
- 复用 [[Agent实测-分类批量九主类-12格母图]] 及九张真人母图作为模型服从性证据。
- 选择E-02图案与纹样，建立一张完整12行生产单作桌面推演。

本轮没有再次生成九张整图，也没有修改图片。原因是现有九页已完成整图压力测试；当前缺口是验证正式“逐格生产—逐格验收—确定性拼版”流程，而非重复证明整图生成的不确定性。

## 总结判定

| 维度 | 分数 | 判定 |
|---|---:|---|
| 目标与九主类覆盖 | 19/20 | 9张图与108格定义清楚 |
| 参数与配额逻辑 | 18/20 | 全部子类可分配，唯一E成立 |
| 展示变量联动 | 17/20 | 配额可排，但复杂结构需按格改景别 |

| 拼版、文字与交付 | 18/20 | PL-01和必填字段完整 |
| 六层验收闭环 | 18/20 | 门禁齐全，少数规则分散在多份文件 |
| **综合** | **88/100** | **可进入逐格正式试生产，不可把整图母图直接视为交付** |

正式可用判定：**有条件通过**。文档层面不存在阻断九主类生产的硬冲突；执行层必须坚持每格独立生成、逐格验收和后期确定性拼版。现有九张母图只能证明分类视觉方向，不能证明正式交付已通过。

## 四、现有九页样张复核

抽查B-C、E-02、E-05并结合原九页报告：

- B-C可见服装、场景和姿势随色系联动，证明“分类图鉴不是复制换色”的方向成立；但整图模型不能锁定4位身份各3格。
- E-02图案覆盖和织物贴合度较好，是九页中最适合进入逐格试生产的代表主类；部分相邻图案仍有语义近似。
- E-05视觉显色强，但原母图出现13格，直接证明4×3必须由排版工具而不是图片模型负责。
- 九张母图均非PL-01竖版9:16，且没有标题、编号、描述和底注；按六层门禁均不能进入正式交付。
- 现有样张中的亚洲成年女性门禁基本成立，未发现动漫自动回退；但仅凭无参考图的脸部外观，不能证明模型身份编号准确。

## 六、问题分级

### 阻断问题

当前未发现文档逻辑上阻断9页生产的问题。

若执行者绕过逐格流程、直接使用整图母图，则会立即产生三个交付阻断：格数不确定、PL-01比例不成立、失败格无法单独返修。这属于违反SOP，不是SOP本身不可执行。

### 一般问题

1. 扩展页只规定“D-DETAIL 8格＋D-LIFESTYLE 4格”，没有像基础页一样映射到具体构图编号；不同执行者会产生不同页面节奏。
2. [[参数组合规则]] 的“展示变量联动”公式漏写模特，而分类SOP和提示词组装包含模特；权威执行时应以分类SOP为准。
3. E-04的腰头、后缝和足部结构无法都由默认H01最佳呈现，实际生产必须按格使用H02/F01/H03，并为H03安排对应全貌格。
4. “4位身份各3格”只有参数排法，没有参考图服从度量化标准。模型可能生成12张相似但并非同一身份的脸。
5. 参数快照模板能容纳所需字段，但批量任务没有独立的机器可读生产单格式；108格手工复制时容易漏字段。
6. 六层门禁中“同一姿势编号整页只出现1次”比分类SOP的“相邻格不同”更严格。两者不冲突，但执行者必须读取质检SOP才知道完整约束。

## 七、正式执行建议

```text
九页配额表
→ 每页建立12行生产单
→ 每格独立抽取兼容B＋唯一E
→ 按身份/造型/姿势/构图联动筛选
→ 生成无文字纵向单格
→ 六层中的前四层逐格验收
→ 只返修失败格
→ 4×3确定性拼版
→ 全套统一PL-01加入中文信息
→ 文字层与版式层整页验收
→ 交付9页＋108份快照＋返修记录
```

建议首个正式逐格试生产选择E-02：其现有母图表现最好，且本报告已提供完整12行生产单。首轮通过后再测试最难的E-04，以验证多景别结构展示和失败格返修能力。

## 最终结论

分类批量SOP已经形成完整生产闭环，配额、默认亚洲成年女性、欧美/动漫禁用、姿势比例、唯一E、逐格返修、PL-01优先级和六层验收均能落地。现阶段可按SOP启动正式逐格试生产；在至少完成一页“12张独立生成＋后期PL-01成板”的真实验证前，状态应保持“有条件通过”，不应宣称整个九页正式交付已经稳定。
