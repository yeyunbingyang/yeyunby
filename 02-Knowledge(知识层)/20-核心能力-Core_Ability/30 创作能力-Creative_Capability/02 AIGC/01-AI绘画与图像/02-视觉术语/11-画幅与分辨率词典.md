# 11-画幅与分辨率词典

> [!info] 笔记关系
> **常用**

## 效果图示例

> [!tip] 先看图，再看文
> 这张图用于直观区分“画幅看形状、分辨率看尺寸”，也是最容易混淆的一组概念。

![[画幅与分辨率词典_效果图示例.png]]


> [!abstract] 小白一句话
> **画幅是画布形状，分辨率是画布里有多少像素。** 3:4 可以是 768×1024，也可以是 1536×2048；比例相同，文件大小不同。

## 一、六个必须分开的概念

| 概念 | 白话解释 | 示例 |
|---|---|---|
| 画幅比例 | 宽和高的关系 | 1:1、3:4、16:9 |
| 像素尺寸 | 图片实际有多少像素 | 1024×1024、1536×2048 |
| 细节质量 | 结构、边缘、纹理是否生成正确 | 手指、文字、发丝是否清楚 |
| 文件格式 | 图片保存方式 | PNG、JPEG、WebP |
| 压缩质量 | 文件被压缩多少 | JPEG 质量 85 |
| 透明通道 | 背景是否真的透明 | 带 Alpha 的 PNG/WebP |

> [!warning] 重点
> “超高清、4K、8K、masterpiece”不能代替平台真实尺寸和质量设置，也不能自动修复错误结构。

## 二、常用画幅比例


![[画幅与分辨率词典_常用比例对照.png]]
| 比例 | 形状 | 常见用途 | 构图提醒 |
|---|---|---|---|
| 1:1 | 正方形 | 头像、方形帖子、商品主图、纹理 | 居中稳定，横向叙事空间少 |
| 4:3 | 稍宽或稍竖 | 展示板、设定图、传统屏幕 | 适合多视图和信息布局 |
| 3:4 | 常规竖版 | 全身人物、角色设定、摄影 | 注意头顶和脚下空间 |
| 4:5 | 社交竖版 | 电商、海报、社交媒体 | 兼顾人物与文字区 |
| 2:3 | 传统照片竖版 | 海报、封面、人物摄影 | 比 3:4 更修长 |
| 9:16 | 手机全屏竖版 | 短视频封面、手机壁纸 | 顶部和底部常有 UI 遮挡 |
| 16:9 | 标准横版 | 视频、故事板、场景、桌面壁纸 | 适合人物关系和环境 |
| 3:2 | 照片横版 | 摄影、风景、商品场景 | 自然相机比例感 |
| 21:9 | 超宽横版 | 电影感场景、游戏背景 | 视觉中心容易太小 |
| 2.39:1 | 电影宽银幕 | 电影镜头、史诗场景 | 需明确左右焦点和主体占比 |
| A 系列纸张比例 | 约 1:1.414 | 文档、印刷海报、页面 | 真实印刷需后期排版和出血 |

## 三、方向词

| 词条 | 白话解释 |
|---|---|
| 竖版 portrait orientation | 高大于宽 |
| 横版 landscape orientation | 宽大于高 |
| 方形 square format | 宽高相等 |
| 超宽幅 panoramic / ultrawide | 横向特别长 |
| 全景图 panorama | 通常为很宽的环境图，可能包含拼接视野 |

## 四、像素、清晰度和放大

| 词条 | 白话解释 | 小白提醒 |
|---|---|---|
| 像素 pixel | 图片最小的颜色点 | 像素多不等于内容一定正确 |
| 分辨率 resolution | 常指宽×高像素 | 需看平台实际输出 |
| 上采样 upscale | 增加像素尺寸 | 能放大，但不能凭空恢复真实文字和结构 |
| 超分辨率 super-resolution | 用算法推测更多细节 | 可能产生假纹理 |
| 锐化 sharpening | 加强边缘对比 | 过度会出现白边和噪点 |
| 降噪 denoising | 减少颗粒和杂点 | 过度会抹掉皮肤和材质细节 |
| 重采样 resampling | 改变图片像素数量 | 会影响细节和文件大小 |

## 五、PPI、DPI 和印刷

| 词条 | 正确含义 | 小白提醒 |
|---|---|---|
| PPI | 每英寸显示多少像素 | 与像素尺寸和实际打印尺寸共同决定清晰度 |
| DPI | 打印设备每英寸墨点数量 | 常被口语化混用，但不等于图片像素 |
| 出血 bleed | 裁切线外多留的图像区域 | 印刷海报和包装需要 |
| 安全区 safe area | 重要内容不要超出的区域 | 防止裁切或 UI 遮挡 |
| 裁切线 trim line | 成品最终切下来的边缘 | 文字和 Logo 不能贴太近 |
| 色彩模式 | RGB 用于屏幕，CMYK 常用于印刷流程 | AI 生图通常先得到 RGB，正式印刷需后期转换和校色 |

## 六、文件格式


![[画幅与分辨率词典_像素PPI文件格式.png]]
| 格式 | 白话特点 | 适合 | 不适合 |
|---|---|---|---|
| PNG | 无损、边缘清楚，可支持透明通道 | 图标、抠图、文字边缘、后期合成 | 文件通常较大 |
| JPEG/JPG | 压缩高、文件小、不支持透明 | 照片、网页预览、社交发布 | 多次保存会损失细节 |
| WebP | 文件较小，可有损或无损，也可支持透明 | 网页、应用、资源交付 | 某些旧软件兼容性较差 |
| TIFF | 可保存高质量和专业信息 | 印刷、存档、后期 | 文件大，日常分享不便 |
| SVG | 矢量格式，可无限缩放 | 图标、Logo、简单图形 | 普通 AI 位图生图不能直接等同真正矢量 |
| PSD | 分层编辑文件 | Photoshop 后期 | 生图通常不会自动得到可靠分层 |
| EXR | 高动态范围专业格式 | 影视、三维合成 | 日常 AI 生图少用 |

## 七、透明背景到底是什么

“白色背景”“纯色背景”“看起来没有背景”和“真正透明”不是一回事。

真正透明需要文件含 **Alpha 通道**。推荐描述：

```text
主体边缘完整，背景透明，输出为支持 Alpha 通道的 PNG；不保留白底、地面和环境阴影。
```

但是否真的支持透明输出，以当前平台和具体模型为准。

## 八、裁切、扩图和安全区



![[画幅与分辨率词典_裁切扩图安全区.png]]
| 词条 | 白话解释 |
|---|---|
| 裁切 crop | 把画面边缘切掉 |
| 扩图 outpainting / canvas expansion | 向原图外补画新区域 |
| 重新构图 reframe | 改变主体在新画幅中的位置 |
| 保护区 | 不希望被裁切或覆盖的核心区域 |
| 文字安全区 | 后期放标题、Logo 或字幕的干净区域 |
| UI 安全区 | 手机平台按钮、头像和字幕不会遮挡的区域 |

### 9:16 常见安全提醒

- 顶部可能有账号名或状态栏；
- 底部可能有字幕、按钮和进度条；
- 人脸和商品卖点不要贴边；
- 文字区最好单独指定位置和低细节背景。

## 九、可直接复制的输出规格写法

### 社交海报

```text
单张独立图，4:5 竖版，用于社交媒体海报；主体位于左侧，右侧保留低细节文字安全区，重要内容距离边缘留足空间。
```

### 手机封面

```text
9:16 竖版，人物面部位于画面中上区域但避开顶部 UI，底部保留字幕和按钮安全区，不裁切头顶和手部。
```

### 透明素材

```text
单个主体居中，边缘完整，背景透明，输出为支持 Alpha 通道的 PNG；不生成地面、白底、阴影和额外装饰。
```

### 多视图板

```text
4:3 横版展示板，三列等宽布局，依次为正面、侧面、背面；各格人物尺度一致，头顶和脚底对齐，格间距均匀。
```

## 十、相近概念区别

| 容易混淆 | 正确区别 |
|---|---|
| 画幅 vs 像素 | 画幅是比例；像素是实际宽高数量 |
| 分辨率 vs 清晰度 | 分辨率高不保证手、脸、文字生成正确 |
| PNG vs 透明背景 | PNG 可以有透明，也可以没有；要看是否带 Alpha |
| 放大 vs 重绘 | 放大增加像素；重绘可能改变内容 |
| 矢量感 vs 真矢量 | 图像看起来像矢量，不等于得到可编辑 SVG 路径 |
| 4K vs 4:5 | 4K 是分辨率类别；4:5 是画幅比例 |

## 十一、常见翻车与修复

- **写 16:9 但平台仍出方图**：必须在平台尺寸或画幅设置中同步选择。
- **透明背景得到白底**：确认平台支持 Alpha，并检查导出格式。
- **先出方图再裁竖版，头脚被切**：直接按最终画幅生成或先扩图再裁切。
- **放大后文字更错误**：文字应重做或后期排版，不能依赖上采样修复。
- **印刷图只看 DPI 不看像素**：先根据成品尺寸计算所需像素，再做后期校色。
- **多图拼版被当成多张输出**：明确“单张多格”或“多张独立文件”。

## 十二、填入五槽位

数量、画幅、像素、版式、格式、透明背景、用途和安全区统一放在 **输出规格**。不得用“8K、高清”替代真实参数。
