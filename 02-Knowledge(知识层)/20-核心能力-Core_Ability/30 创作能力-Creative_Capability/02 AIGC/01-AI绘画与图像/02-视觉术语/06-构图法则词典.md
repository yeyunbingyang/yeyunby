# 06-构图法则词典

> [!info] 笔记关系
> **常用**

> 这张图把常见构图方式做成直观对照，适合先看视觉中心和视线动线，再读术语说明。

![[构图法则词典_效果图示例.png]]


> [!abstract] 小白一句话
> 构图就是“把东西放在画布哪里”。它决定观众第一眼看什么、接着看哪里，以及画面会不会挤、歪、散或没有重点。

## 一、构图先回答五个问题



![[构图法则词典_构图五问.png]]
1. 主体在左、中还是右？
2. 主体朝哪里看或移动？
3. 第一视觉焦点是什么？
4. 哪里需要留白，留给什么？
5. 前景、中景、背景如何分层？

## 二、核心构图法则

| 构图 | 英文参考 | 白话解释 | 适合 | 风险 |
|---|---|---|---|---|
| 中心构图 | centered composition | 主体放正中，直接稳定 | 商品主图、证件感角色、图标 | 容易呆板 |
| 三分法 | rule of thirds | 把画面想成九宫格，主体放交点附近 | 人物、风景、海报 | 不是简单塞到角落 |
| 对称构图 | symmetrical composition | 左右或上下像镜子一样平衡 | 建筑、仪式感、奢华视觉 | 小误差会显得更明显 |
| 不对称平衡 | asymmetrical balance | 两边不同，但视觉重量相当 | 海报、社交视觉、动态场景 | 容易一边过重 |
| 对角线构图 | diagonal composition | 主体或动作沿斜线展开 | 运动、动作、商品斜放 | 太多斜线会乱 |
| 三角构图 | triangular composition | 人或物形成三角形关系 | 三人群像、静物 | 人数和位置需明确 |
| 引导线 | leading lines | 道路、栏杆或光线把眼睛带向主体 | 建筑、街景、场景 | 引导线不能带出画面 |
| 框景 | frame within a frame | 用门窗、树枝、前景包住主体 | 电影感、空间纵深 | 前景可能遮挡主体 |
| 负空间 | negative space | 有意保留大片空白 | 海报、封面、极简人物 | 空白方向不明会显空洞 |
| 前中后景 | foreground–midground–background layering | 把空间分成三层 | 风景、电影场景、环境人像 | 前景不要挡脸和 Logo |
| 重复与节奏 | repetition and rhythm | 重复形状形成秩序 | 建筑、商品阵列、品牌图形 | 机械重复、缺少变化 |
| 放射构图 | radial composition | 线条从中心向外扩散 | 奇观、海报、图案 | 中心容易过于拥挤 |
| S 形构图 | S-curve composition | 河流、道路形成 S 形，引导视线 | 风景、人体姿态、产品曲线 | 模型未必准确理解字母形状 |
| 黄金螺旋 | golden spiral composition | 视线从大范围旋向重点 | 艺术、静物、自然场景 | 不必与三分法同时堆叠 |
| 满版构图 | full-bleed composition | 图像铺满画面，几乎无空白 | 纹理、包装、背景素材 | 边缘元素易被裁切 |

## 三、版式与空间常用词


![[构图法则词典_留白与安全区.png]]
| 词条 | 白话解释 | 使用场景 |
|---|---|---|
| 视觉中心 | 第一眼最想让观众看的位置 | 人脸、商品、标题区 |
| 视觉重量 | 大、亮、深色或高对比元素看起来更“重” | 平衡左右画面 |
| 留白 | 有目的地不放东西 | 标题、Logo、呼吸感 |
| 头部空间 | 人头顶到画面边缘的距离 | 人像避免压顶 |
| 视线空间 | 人物视线前方留下的空间 | 人物看左时左侧多留空 |
| 运动空间 | 运动方向前方留下空间 | 跑步、汽车、飞行动作 |
| 安全区 | 重要内容不要靠近裁切边缘 | 海报、短视频封面、头像 |
| 地平线 | 天空与地面分界位置 | 风景和建筑稳定感 |
| 消失点 | 平行线在远处汇聚的位置 | 建筑、道路、室内纵深 |
| 切线干扰 | 边缘刚好贴住主体，像黏在一起 | 应避免树枝从头顶长出等现象 |

## 四、如何选择构图

| 目标 | 推荐构图 |
|---|---|
| 主体必须一眼看清 | 中心构图、对称构图 |
| 想自然不僵硬 | 三分法、不对称平衡 |
| 想要速度和张力 | 对角线、S 形、引导线 |
| 想突出秩序和高级感 | 对称、重复节奏、留白 |
| 想为文字留位置 | 负空间、左右分栏、上下分区 |
| 想增强空间纵深 | 前中后景、框景、引导线 |
| 多人物关系 | 三角构图、左右对话构图 |
| 纹理或背景素材 | 满版构图、重复节奏 |

## 五、可直接复制的提示词写法

### 人物留白

```text
人物位于画面右侧三分之一，身体和视线朝向左侧；左侧保留干净负空间，用于后期添加标题。
```

### 建筑中轴

```text
中心对称建筑构图，摄影机位于空间中轴线上，左右结构平衡，垂直线保持竖直，人物只作为尺度参照。
```

### 电影纵深

```text
前景有轻微虚化的门框，中景人物为视觉中心，远景灯光和街道形成纵深；引导线最终指向人物，不遮挡面部。
```

### 商品广告

```text
商品位于左下三分点，右上保留标题和卖点区域，背景元素沿对角线延伸，但不得压过商品轮廓。
```

### 动作场景

```text
人物从左下向右上运动，使用对角线构图，运动方向前方保留空间，背景线条共同指向动作方向。
```

## 六、画幅如何影响构图

| 画幅 | 适合构图 | 小白提醒 |
|---|---|---|
| 1:1 | 中心、对称、四宫格 | 横向空间少，不适合长距离运动 |
| 3:4 / 4:5 | 全身人物、海报、上下层次 | 注意头顶和脚下安全区 |
| 9:16 | 竖向引导、人物全身、手机封面 | 顶部和底部常被 UI 覆盖 |
| 16:9 | 人物关系、场景、故事板 | 防止人物都挤在中央 |
| 2.39:1 | 电影宽银幕、横向叙事 | 主体容易显小，要明确视觉中心 |

## 七、相近概念区别

| 容易混淆 | 正确区别 |
|---|---|
| 三分法 vs 留白 | 三分法决定主体位置；留白决定哪里有意空出 |
| 对称 vs 中心 | 中心只要求主体居中；对称要求两侧结构对应 |
| 前景遮挡 vs 框景 | 框景是有意围住主体；随意遮挡可能只是干扰 |
| 构图 vs 版式 | 构图偏图像内部关系；版式还包括标题、Logo、网格和文字层级 |
| 负空间 vs 空洞 | 负空间有明确用途和视觉平衡；空洞没有目的 |

## 八、常见翻车与修复

- **主体放右边却看向右边，画面很堵**：在视线方向前方留空间。
- **留白被模型填满装饰**：写“纯净、低细节、不得添加额外对象”。
- **前景植物挡脸**：控制规则补“不得遮挡眼睛、脸和关键卖点”。
- **三分法导致主体贴边**：增加安全区和主体占比。
- **海报文字区仍复杂**：写“均匀低对比背景，不生成文字，后期排版”。
- **多个构图词互相冲突**：只保留一个主构图和一个辅助关系。

## 九、填入五槽位

- **目标画面设计 → 镜头与构图**：主体位置、视觉流向、前中后景；
- **输出规格**：画幅、文字安全区、拼版、出血；
- **控制规则**：不遮挡、不贴边、不填满留白区。
