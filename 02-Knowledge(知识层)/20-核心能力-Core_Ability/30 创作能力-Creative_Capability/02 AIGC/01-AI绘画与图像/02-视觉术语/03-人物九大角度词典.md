# 03-人物九大角度词典

> [!info] 笔记关系
> **常用**

## 效果图示例

> [!tip] 先看图，再看文
> 这张图把常见人物角度做成一页总览，适合先快速分辨“正面、侧面、四分之三侧、俯视、仰视”。

![[人物角度词典_效果图示例.png]]


> [!abstract] 小白一句话
> “侧面人物”仍然可能有很多种：身体侧着但脸看镜头、身体正面但眼睛看旁边、镜头从上往下拍。最稳的方法是把**身体、脸、眼睛、摄影机**分别说明。

## 一、人物角度的四个独立开关



![[人物角度词典_四个独立开关.png]]
| 开关 | 它回答什么 | 示例 |
|---|---|---|
| 身体朝向 | 胸口和骨盆朝哪里 | 身体正对镜头、身体向右转 45° |
| 面部朝向 | 鼻尖和脸朝哪里 | 面部正面、严格左侧脸 |
| 视线方向 | 眼睛看哪里 | 看向镜头、看向画面左侧、低头看书 |
| 摄影机机位 | 镜头从哪里拍 | 平视、俯视、仰视 |

> [!warning] 常见错误
> “人物侧面看镜头”并不矛盾：身体可以侧面，脸转回镜头。需要明确写成“身体侧向右，面部转回镜头”。

## 二、九种最常用人物视图

| 中文名 | 英文参考 | 白话解释 | 适用任务 |
|---|---|---|---|
| 全身正面 | full-body front view | 人和脸都正对镜头，头到脚完整 | 角色基准、服装展示 |
| 全身四分之三 | full-body three-quarter view | 身体轻侧约 30°–60°，能看到正面和侧面 | 展示体积、常规立绘 |
| 全身严格侧面 | full-body strict side view | 身体和脸接近 90° 侧面 | 三视图、轮廓和姿态 |
| 全身背面 | full-body back view | 背对镜头，展示后脑和服装背部 | 发型、服装背部结构 |
| 半身正面 | waist-up front view | 腰部以上，正面看镜头 | 人像、上衣、直播视觉 |
| 半身四分之三 | waist-up three-quarter view | 腰部以上，身体轻侧 | 最自然常用的人像角度 |
| 胸像正面 | bust portrait, front view | 胸部以上，面部正面 | 身份、表情、头像 |
| 面部严格侧面 | strict profile portrait | 鼻尖指向侧方，脸约 90° | 鼻梁、唇形、下颌分析 |
| 面部四分之三 | three-quarter portrait | 既能看正面，也能看侧面轮廓 | 保留辨识度和立体感 |

## 三、扩展常用角度

| 角度 | 英文参考 | 白话说明 | 风险 |
|---|---|---|---|
| 七分侧/轻侧脸 | slight three-quarter view | 只轻轻转脸，比四分之三更接近正面 | 模型可能直接生成正面 |
| 背面回眸 | back view, looking over shoulder | 身体背对镜头，脸从肩上回看 | 肩颈容易扭曲 |
| 过肩视角 | over-the-shoulder view | 镜头越过人物肩膀看前方 | 肩膀可能挡脸或主体 |
| 顶视 | top-down view | 摄影机几乎在正上方 | 人体比例被压缩 |
| 虫视/极低机位 | worm's-eye view | 镜头贴近地面向上看 | 腿、下巴和鼻孔容易夸张 |
| 荷兰角 | Dutch angle | 画面地平线倾斜 | 适合紧张感，不适合标准设定图 |
| 镜面视角 | mirror-view composition | 人物与镜中反射同时出现 | 镜像结构和手部易错 |

## 四、摄影机机位


![[人物角度词典_机位高度与视线.png]]
| 机位 | 英文参考 | 视觉效果 | 小白理解 |
|---|---|---|---|
| 平视 | eye-level view | 中性、自然、变形少 | 镜头与眼睛差不多高 |
| 轻微俯视 | slight high-angle view | 人物显轻盈，头部稍突出 | 镜头略高于眼睛 |
| 俯视 | high-angle view | 人物显小，地面变多 | 从上往下看 |
| 顶视 | top-down / overhead view | 平面化、图案感强 | 接近正上方拍摄 |
| 轻微仰视 | slight low-angle view | 更有力量感，畸变温和 | 镜头略低于胸口或眼睛 |
| 仰视 | low-angle view | 戏剧、强势、腿显长 | 从低处往上看 |
| 极低机位 | worm's-eye view | 夸张、英雄化、空间高耸 | 镜头接近地面 |

## 五、视线方向词

| 写法 | 英文参考 | 视觉作用 |
|---|---|---|
| 直视镜头 | direct eye contact | 与观众建立强联系 |
| 看向画外 | looking off-camera | 更自然、像抓拍或剧情画面 |
| 低头 | looking downward | 安静、内省，也适合看书或手机 |
| 抬头 | looking upward | 希望、惊讶或观察高处 |
| 闭眼 | eyes closed | 平静、沉浸、睡眠或感受光线 |
| 回眸 | looking back over shoulder | 动态、优雅、带叙事感 |

## 六、三视图和设定图的标准写法

三视图不是“三个不同角度的漂亮姿势”，而是用于比较结构的标准视图：

```text
同一人物、同一服装、同一发型、同一自然站姿、同一尺度和同一平视机位。
依次展示：正面、严格 90° 侧面、背面。
每格人物头顶和脚底对齐，背景简洁，不添加动作变化。
```

## 七、可直接复制的组合句式

### 自然人像

```text
腰部以上的四分之三人物视图，身体向右转约 45°，面部轻转回镜头，双眼直视镜头，平视机位。
```

### 严格侧脸

```text
胸部以上的严格左侧脸，面部接近 90°，鼻尖指向画面左侧，另一侧眼睛不可见，平视机位。
```

### 背面回眸

```text
全身背面视图，身体背对镜头，人物从右肩上方自然回眸，肩颈转动合理，头到脚完整可见。
```

### 轻微仰视英雄感

```text
全身四分之三视图，轻微仰视机位，镜头低于胸口但不过度夸张下颌和腿部透视。
```

## 八、常见翻车与修复

- **写“侧脸”却得到半侧脸**：补“严格 90°，另一侧眼睛不可见”。
- **身体和脸都被转走**：分别写“身体朝向”和“面部朝向”。
- **仰视出现鼻孔和大下巴**：改成“轻微仰视，保持自然面部透视”。
- **背面图仍露出正脸**：写“背面视图，脸不转向镜头”。
- **回眸肩颈扭曲**：降低回头角度，并写“自然肩颈连接”。
- **三视图每格姿势不同**：补“统一中性站姿、同一尺度、同一机位”。

## 九、填入五槽位

- **目标画面设计 → 镜头与构图**：人物朝向、面部朝向、视线和机位；
- **保留项**：图生图要求保持原姿势或原角度时填写；
- **输出规格**：三视图的格数、顺序和每格职责。
