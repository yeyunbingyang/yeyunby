# 08-色彩与调色词典

> [!info] 笔记关系
> **常用 · 新增（2026-08-05）**

## 一、先分清四个基础变量


![[色彩与调色词典_色相明度饱和度.png]]
| 变量 | 含义 | 提示词写法示例 |
|---|---|---|
| 色相 | 红、橙、黄、绿、青、蓝、紫等颜色类别 | 蓝绿色主调、暖橙色点缀 |
| 明度 | 颜色看起来有多亮或多暗 | 高明度背景、深色低调画面 |
| 饱和度 | 颜色鲜艳或灰柔的程度 | 低饱和肤色、局部高饱和强调 |
| 色温 | 视觉上的冷暖倾向 | 冷色环境光、暖色窗光 |

> [!warning] 常见混淆
> “冷色”不等于“低饱和”，“暗色”不等于“低对比”，“电影感”也不是一种固定配色。

## 二、配色关系


![[色彩与调色词典_配色关系.png]]
| 关系 | 视觉效果 | 适合场景 |
|---|---|---|
| 单色 | 统一、克制，依靠明暗和材质变化 | 产品图、极简海报、情绪人像 |
| 邻近色 | 和谐、自然、过渡柔和 | 风景、生活方式、清透插画 |
| 互补色 | 对比强、主体突出 | 商业广告、动作场景、夜景霓虹 |
| 冷暖对比 | 空间和情绪层次明显 | 电影光影、室内窗光、黄昏场景 |
| 主辅点缀 | 主色稳定，少量点缀形成视觉中心 | 品牌视觉、人物服装、商品陈列 |

## 三、常用调色表达


![[色彩与调色词典_明度饱和度矩阵.png]]
### 高调与低调

- **高调**：整体明亮、阴影轻、留白多；不等于过曝。
- **低调**：暗部占比高、亮部受控；不等于所有细节消失。

### 高饱和与低饱和

- **高饱和**：颜色鲜明，适合强调活力和视觉冲击。
- **低饱和**：颜色偏灰柔，适合克制、复古、电影化或高级商业画面。

### 色彩分级

色彩分级通常描述成片整体关系，可拆成：

```text
主色倾向 + 阴影色偏 + 高光色偏 + 饱和度 + 对比度 + 肤色保护
```

示例：

```text
青蓝色阴影，暖金色高光，中低饱和，受控对比，人物肤色保持自然不过度偏橙。
```

## 四、肤色保护

- 明确肤色需要自然，不因环境色完全染色。
- 允许环境光在阴影和边缘产生轻微色偏。
- 避免“纯白皮肤”“无色差”等塑料化表达。
- 商品或服装颜色必须准确时，应降低环境色污染并在生成后校色。

## 五、模糊词改写

| 模糊说法 | 更可执行的表达 |
|---|---|
| 高级配色 | 深蓝灰主色、低饱和、少量暖金点缀、留白充足 |
| 电影调色 | 青蓝阴影、暖色高光、中等对比、肤色自然、轻微空气感 |
| 日系清透 | 高明度、低至中饱和、浅青与米白主色、柔和自然光 |
| 复古色调 | 暖棕与暗绿、降低饱和度、黑位微抬、轻微胶片色偏 |
| 梦幻色彩 | 粉紫与浅蓝渐变、柔和高光、低对比、局部薄雾 |

## 六、验收问题

1. 主体与背景是否有足够色彩分离？
2. 肤色和商品色是否被环境色严重污染？
3. 主色、辅助色、点缀色是否有明确层级？
4. 饱和度是否集中在视觉中心，而不是全画面同时抢眼？
5. 明暗与色彩是否共同服务于画面目的？
