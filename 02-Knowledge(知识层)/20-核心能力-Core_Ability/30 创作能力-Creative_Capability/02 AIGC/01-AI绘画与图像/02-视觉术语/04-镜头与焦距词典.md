# 04-镜头与焦距词典

> [!info] 笔记关系
> **常用**

## 效果图示例

> [!tip] 先看图，再看文
> 同一主体在不同焦距下的透视、背景压缩和环境占比差异，可以先通过这张图直观看懂。

![[镜头与焦距词典_效果图示例.png]]


> [!abstract] 小白一句话
> 焦距可以理解为“空间看起来被拉开还是被压扁”：**广角让近处更大、远处更小；长焦让前后距离看起来更近**。

## 一、先理解：焦距不是“把画面放大”这么简单

现实摄影中，改变焦距时摄影师通常也会移动位置。真正影响脸型和空间感觉的，是**摄影机与主体的距离 + 焦距共同作用**。

在 AI 生图里：

- `24mm`、`50mm`、`85mm` 多数时候是视觉倾向；
- 模型不一定严格模拟真实相机；
- 与其只写毫米数，不如补充“自然面部透视”“背景轻度压缩”“避免边缘拉伸”。

## 二、核心镜头类型

| 镜头感觉 | 英文参考 | 白话解释 | 适合 | 常见风险 |
|---|---|---|---|---|
| 鱼眼 | fisheye lens look | 画面像球面，直线大幅弯曲 | 实验视觉、运动、夸张空间 | 人脸和建筑严重变形 |
| 超广角 14–20mm 等效 | ultra-wide lens look | 看得特别宽，近处被夸大 | 建筑、狭小空间、强动态 | 边缘拉伸、四肢变形 |
| 广角 24–35mm 等效 | wide-angle lens look | 环境多，空间显开阔 | 街景、环境人像、室内 | 靠太近会显大鼻子或大手 |
| 标准 45–60mm 等效 | normal-lens perspective | 看起来较自然、不夸张 | 日常人物、商品、纪录感 | 戏剧感较弱 |
| 中长焦 70–105mm 等效 | short-telephoto portrait look | 脸部更柔和，背景靠近主体 | 头肩像、半身人像、美妆 | 环境信息减少 |
| 长焦 135–200mm 等效 | telephoto compression | 前后空间被压缩，背景显近 | 舞台、远距离人物、山景 | 空间可能显平、主体像贴在背景上 |
| 超长焦 | super-telephoto look | 远处对象被拉近，背景压缩强 | 野生动物、体育、远景细节 | 画面层次容易单薄 |
| 微距 | macro lens look | 看清非常小的细节 | 珠宝、眼睛、纹理、接口 | 清晰范围过窄、失去整体结构 |
| 移轴建筑感 | tilt-shift / architectural lens look | 尽量保持建筑垂直线竖直 | 建筑外观、室内 | 不等于工程级几何准确 |
| 等距视角 | isometric view | 没有明显近大远小，像游戏地图 | UI、建筑示意、图标 | 不适合自然摄影感 |

## 三、广角和长焦到底差在哪里



![[镜头与焦距词典_广角标准长焦空间关系.png]]
### 广角感觉

- 近处物体显得更大；
- 前后距离显得更远；
- 环境信息更多；
- 边缘容易拉长。

白话比喻：像你把手机贴得很近拍人，鼻子和手会显大。

### 长焦感觉

- 人脸透视更平缓；
- 背景看起来更靠近人物；
- 环境范围更少；
- 画面更集中。

白话比喻：像在远处用变焦镜头拍，脸更平，背景被“拉近”。

## 四、常见用途选择


![[镜头与焦距词典_任务选择矩阵.png]]
| 任务 | 建议镜头感觉 | 原因 |
|---|---|---|
| 自然头肩人像 | 70–105mm 中长焦感 | 面部透视温和 |
| 环境人像 | 28–50mm 广角到标准 | 保留人物和环境关系 |
| 全身穿搭 | 35–70mm | 兼顾比例和环境，避免腿部过度拉伸 |
| 室内空间 | 20–28mm 广角感 | 能容纳更多空间，但需防边缘变形 |
| 建筑外观 | 24–50mm + 垂直线受控 | 减少建筑倾斜 |
| 商品主图 | 50–100mm 标准到中长焦 | 结构更稳定、透视较自然 |
| 珠宝或纹理 | 微距镜头感 | 放大细节 |
| 宏大风景 | 广角或长焦都可 | 广角强调纵深，长焦强调层叠压缩 |

## 五、镜头相关扩展术语

| 术语 | 白话解释 | 提示词用途 |
|---|---|---|
| 透视畸变 | 靠近镜头的部位被夸大 | 写“避免面部和边缘畸变” |
| 背景压缩 | 远处背景看起来更靠近主体 | 写“轻度长焦压缩” |
| 垂直线校正 | 建筑竖线保持竖直 | 建筑和室内任务常用 |
| 边缘拉伸 | 广角画面边缘的人或物变长 | 写“避免边缘人物拉伸” |
| 镜头眩光 | 强光进入镜头形成光斑或光雾 | 可制造逆光氛围，容易过度 |
| 色差 | 高反差边缘出现彩边 | 通常应避免，复古效果除外 |
| 暗角 | 四角比中心暗 | 可聚焦主体，但商品图慎用 |
| 桶形畸变 | 直线向外鼓 | 常见于广角或鱼眼感 |
| 枕形畸变 | 直线向内弯 | 常见于某些长焦视觉 |

## 六、可直接复制的提示词写法

### 自然人像

```text
中近景，平视，85mm 等效的中长焦人像镜头感，面部透视自然，背景轻度压缩，避免鼻子和脸缘夸张。
```

### 环境人像

```text
35mm 等效的环境人像视角，人物与周围街景关系清楚，空间有纵深，边缘人体不被拉伸。
```

### 室内建筑

```text
约 24–28mm 等效的室内广角视角，摄影机保持水平，垂直线尽量竖直，避免边缘家具和人物变形。
```

### 商品

```text
70mm 等效的自然产品透视，商品结构和比例准确，边缘无广角变形，背景轻度压缩但仍保留空间层次。
```

### 微距

```text
微距细节镜头，焦点在材质纹理和接口边缘，关键结构清楚，避免只有一点清晰而整体无法辨认。
```

## 七、相近概念区别

| 容易混淆 | 正确区别 |
|---|---|
| 焦距 vs 景别 | 焦距决定透视倾向；景别决定画面裁到哪里 |
| 焦距 vs 景深 | 焦距不单独决定虚化；还与距离、光圈和画面意图有关 |
| 广角 vs 远景 | 广角也能拍近景；远景也能用长焦 |
| 85mm vs 高质量人像 | 85mm 只表达透视风格，不保证脸、皮肤或手正确 |
| 移轴 vs 微缩景观 | 移轴可校正建筑，也可制造微缩感，需明确用途 |

## 八、常见翻车与修复

- **脸被拍得鼻大脸长**：减少广角感，增加拍摄距离，写“自然面部透视”。
- **室内边缘家具变形**：降低超广角程度，补“垂直线竖直、避免边缘拉伸”。
- **长焦画面像平面贴图**：增加前景遮挡或空气层次，降低压缩程度。
- **只写 85mm 没变化**：补景别、机位、主体距离和期望的透视效果。
- **微距只剩一小块清楚**：明确“关键结构整体仍可辨识”。

## 九、填入五槽位

放在 **目标画面设计 → 镜头与构图**。真实输出尺寸、图片比例和文件格式不属于焦距，放在 **输出规格**。
