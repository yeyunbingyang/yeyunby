## 不可变特征

| 类别 | 冻结内容 |
|---|---|
| 面部 | 清秀、偏中性、冷静表情；真实亚洲面部比例；脸型与五官以唯一身份真值为准 |
| 发型 | 黑色短发、发尾自然微乱、额前碎发 |
| 发辫 | 后颈一条细长发辫，约 15 厘米，以深色细绳松散固定 |
| 上装 | 黑色交领长袍，外罩半透明黑纱，暗纹位置和层级保持稳定 |
| 腰部 | 黑色宽腰带，中央银色圆形腰扣 |
| 手臂 | 银纹护腕，不增加护肩或铠甲 |
| 下装 | 黑色长袍内层、银饰黑靴，不改变衣摆层级 |
| 饰品 | 胸前银饰、流苏与珠串数量和位置保持稳定 |
| 身体 | 身高感约 178 厘米，约 1:7.8 头身，肩宽和四肢比例不重算 |
| 配色 | 发色 `#0A0A0A`，主色 `#1A1A1A`，辅色 `#2F2F2F`，镶边 `#C0C0C0`，特效色 `#708090` |

## 禁止变化项

- 不改变脸型、五官、年龄感或身份。
- 不把短发和发辫改成长发、马尾或新增飘带。
- 不增加武器、披风、铠甲、头冠或其他人物。
- 不删除银色腰扣、护腕、流苏、珠串和发辫。
- 不增加露肤范围，不改变交领与衣摆结构。
- 不用多张参考图平均或重算面部。
