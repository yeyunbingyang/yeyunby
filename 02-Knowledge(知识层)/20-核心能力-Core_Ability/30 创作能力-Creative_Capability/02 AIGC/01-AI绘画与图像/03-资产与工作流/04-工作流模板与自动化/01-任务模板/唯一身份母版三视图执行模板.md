# 唯一身份母版三视图执行模板

> [!abstract] 核心结论
> 三视图一致性的关键不是“让所有参考图权重平均”，而是明确职责：`A = Identity`，`B/C = Geometry Evidence`，并在生成前固定统一转向。身份不平均、转向不混用、角度不独立重绘、修错时尽量只修有问题的视图；身份与结构稳定后，才允许对最终成品图做可选画质修复。

## 一、项目身份定义

| 图像 | 标识 | 职责 | 权重 |
|---|---|---|---|
| 图 A | `CHARACTER_MASTER_01` | 唯一身份母版，决定“这个人是谁” | 最高 |
| 图 B | `ANGLE_REF_45` | 补充 45° 三维几何，不参与身份定义 | 辅助 |
| 图 C | `ANGLE_REF_90` | 补充 90° 侧面几何，不参与身份定义 | 辅助 |

身份权重：`A >>> B ≈ C`

图 A 锁定脸型、头部长宽比、眉眼关系、眼距、眼裂、鼻部结构、嘴宽、唇形、人中、颧骨、下颌、下巴、发际线和年龄感。判断标准不是“哪张更漂亮”，而是“是不是图 A 这个人”。

## 二、系统规则

1. **身份不平均**：多张参考图不能平均融合五官；辅助图与图 A 发生五官比例冲突时，以图 A 为准。
2. **角度不独立重绘**：0°、45°、90° 必须来自同一个连续 3D 头模，而不是三个独立角色。
3. **修错最小化**：已稳定的角度冻结，优先只修改出现问题的视图。
4. **模板固定左转**：所有项目统一使用 `0° 正面 → 向画面左侧转 45° → 向画面左侧转严格 90°`，不再为单个项目选择右转版本。
5. **辅助图职责可声明**：默认只取几何；如果本轮目标是提高某个角度与原参考图的相似度，必须明确将该参考图升级为该视图的“外观/相似度参考”，但仍受 A 的身份约束。
6. **画质修复后置**：画质修复是成品优化，不是身份修复；只有身份、转向和几何验收通过后才可执行，而且不能替换稳定资产的原始通过版。

## 三、模板固定转向

本模板的转向不是项目变量，而是固定规范。所有新人物、所有三视图任务都统一使用左转。转向以**画面中鼻尖指向的方向**定义，不依赖模型对正负 yaw 的理解。

| 固定转向 | 0° | 45° | 90° | 侧面判定 |
|---|---|---|---|---|
| `TURN_LEFT` | 正面 | 鼻尖朝画面左侧 | 鼻尖朝画面左侧 | 后脑位于鼻尖右侧 |

模板固定值：`TURN_LEFT`。

> [!warning] 禁止改写模板转向
> 不要因为某张参考图本身朝右，就把该项目改成右转；参考图只负责身份、外观相似度或几何证据。若参考图方向相反，生成时仍需转换为模板规定的左转方向，不能把左右镜像图直接混入三视图。

### 固定转向提示词模块

```text
固定三视图转向为 TURN_LEFT：
0° 正面 → 向画面左侧转 45° → 向画面左侧转严格 90°。

45° 与 90° 的鼻尖必须都指向画面左侧，不能一张向左、一张向右，不能水平镜像后混入三视图。
三张图必须是同一个连续 3D 头模的连续转向：
正面 → 左转45° → 左转90°。

这是执行模板的固定方向，所有人物项目都使用 TURN_LEFT，不提供 TURN_RIGHT 变体。
```

### 转向验收

- 观察鼻尖方向：45° 与 90° 必须同向。
- 观察后脑方向：90° 的后脑必须位于鼻尖相反一侧。
- 观察耳位和发缝：不能因水平镜像导致耳饰、发缝或头发方向突然反转。
- 发现转向错误时，不要只把错误图水平翻转后直接交付；按模板固定的 `TURN_LEFT` 重做受影响视图。

## 四、执行流程

```text
原始多图
↓
选唯一正面身份母版 A
↓
补 45° 结构 B
↓
生成初版正面 / 45° / 90°
↓
补 90° 真实参考 C
↓
只修有问题的 90°
↓
如仍不稳定：A + B + C 重新稳定化
↓
固化最终三视图资产
```

### 阶段 1：锁定唯一身份母版

```text
图A是唯一身份母版 CHARACTER_MASTER_01。

最高优先级锁定：
脸型、头部长宽比、眉眼关系、眼距、眼裂、鼻根、鼻梁、鼻尖、鼻翼、嘴宽、唇形、人中、颧骨、下颌、下巴、发际线、年龄感。

后面无论加入多少参考图，都不能覆盖图A。
判断标准不是“更漂亮”，而是“是不是图A这个人”。
```

### 阶段 2：补充 45° 几何

```text
图B定义为 ANGLE_REF_45。

默认补充图A正面无法充分判断的三维信息：
鼻梁高度、鼻尖投影、眼窝深度、颧骨深度、面中前后关系、嘴部前突、下颌转折、头颈连接。

固定使用模板规定的 `TURN_LEFT`，并与 90° 使用同一方向。
图B如果和图A五官比例发生冲突，仍然以图A为准。
```

如果本轮目标是提高 45° 与原始 45° 参考图的相似度，改用以下职责声明：

```text
图B定义为 ANGLE_REF_45，同时作为 45° 视图的外观与相似度参考。

中间 45° 应尽量继承原参考图的脸部形态、眉眼关系、眼神、颧骨与面中结构、鼻梁与鼻尖特征、唇形、嘴部前后关系、下颌轮廓和发型框架。

图A仍然是最高身份约束；当原45°参考图与图A发生“是不是同一个人”的冲突时，以图A为准。
不复制原参考图的背景、动作、服装、水印或其他人物。
```

### 阶段 3：生成第一版头肩三视图

```text
以 CHARACTER_MASTER_01 为唯一身份母版，输出第一版头肩三视图：正面 / 45° / 严格90°。

三张图来自同一个连续 3D 头模，不是三个独立角色。
统一中性表情、头肩构图、白/浅灰背景、真实摄影质感、相似焦距、相似头部尺寸、相似光线、相同发型与服装。

本阶段主要检查身份连续性，不追求最终美观。
```

### 阶段 4：加入 90° 真实参考

```text
后续侧脸图定义为 ANGLE_REF_90。

90° 图重点负责额头→鼻根→鼻梁→鼻尖→鼻基底→人中→嘴唇→下巴的连续侧面曲线，以及耳位、下颌、后脑、头颈连接。

不能直接复制侧脸参考。90° 原图可能存在表情、仰俯、焦距、发型和画质差异；只取它的几何，不取它对身份的重新定义。
同时必须继承模板固定的 `TURN_LEFT`，不能因为原始侧脸照片朝向相反而改变执行方向。
```

### 阶段 5：只修复有问题的 90°

```text
当前 0° 和 45° 已经比较稳定，不重新生成全部三视图，只修改 90°。

修复逻辑：图A身份 + 图B过渡结构 + 图C侧面轮廓。

重点检查：
鼻子是否突然变长或变高、嘴唇前突是否异常、下巴是否变尖、额头是否变化、眼球位置是否合理、后脑和脖子是否自然。

目标不是生成更漂亮的侧脸，而是让 90° 变回 CHARACTER_MASTER_01 本人。
```

### 阶段 6：必要时整体重新稳定化

单独修复 90° 仍然不稳定时，重新使用 `CHARACTER_MASTER_01 + ANGLE_REF_45 + ANGLE_REF_90` 生成新的稳定三视图，但身份权重仍保持：

```text
A = Identity
B/C = Geometry Evidence
A >>> B ≈ C
```

不是 `A + B + C` 平均融合；三个视图仍必须来自同一个连续三维头模。

## 五、稳定资产升级

三视图基本稳定后，停止频繁回到所有原始照片，将稳定结果升级为：

| 资产标识 | 用途 |
|---|---|
| `CHARACTER_MASTER_01` | 原始唯一身份母版 |
| `FACE_FRONT_STABLE_01` | 稳定正面视图 |
| `FACE_45_STABLE_01` | 稳定 45° 视图 |
| `FACE_90_STABLE_01` | 稳定 90° 视图 |

后续进行 3D 国漫化、服装设计、全身三视图、表情变化或视频角色一致性时，统一使用这一组稳定资产，不再回到未经筛选的原始参考图。

## 六、最终成品图可选画质修复

画质修复是稳定资产通过后的可选后处理阶段，不是重新生成身份或重新设计角度。它可以用于最终交付图，但不应成为三视图结构验收的前置条件。

### 可修复内容

- 分辨率、锐度、轻微失焦和压缩痕迹。
- 头发边缘、皮肤纹理、睫毛和衣物细节的清晰度。
- 小面积生成瑕疵、噪点、断发、边缘脏点和轻微接缝。

### 不得改变内容

- 身份、脸型、五官比例、年龄感和表情。
- 0° / 45° / 90° 的固定转向与头部角度。
- 鼻唇下巴曲线、耳位、发际线、头颈连接。
- 发型轮廓、服装主体、背景构图和头肩比例。

### 执行规则

1. 先保留已通过的原图作为 `PASS` 版本，再生成画质修复副本。
2. 优先逐视图修复，不要为了提升清晰度而重新生成整组三视图。
3. 画质修复只允许一个主要变量，例如“提高清晰度”或“修复发丝边缘”，不要同时改脸、光线和风格。
4. 修复后重新检查身份、转向和几何；任何五官漂移都视为修复失败，回退到原 `PASS` 版本。
5. 修复版只有在复检通过后，才能登记为新的交付候选；不能自动覆盖 canonical 稳定资产。

### 可直接复制的画质修复提示词

```text
这是已经通过身份与几何验收的稳定资产，只做最终画质修复。

允许：提高清晰度、分辨率、皮肤与头发细节，修复轻微噪点、压缩、断发和边缘瑕疵。

严格保持不变：人物身份、脸型、五官比例、年龄感、表情、固定转向、头部角度、鼻唇下巴曲线、耳位、发际线、发型轮廓、服装、背景和构图。

禁止重新设计人物，禁止改变 0° / 45° / 90° 视图关系，禁止换脸、镜像、过度磨皮或新增细节。
输出画质修复副本，不覆盖原始 PASS 资产。
```

## 七、执行验收卡片

```text
① 选 A：唯一正面身份母版
② 固定模板转向：TURN_LEFT（所有项目统一左转）
③ 补 B：45° 几何参考；如有需要，声明为外观/相似度参考
④ 生成初版正面 / 45° / 90°
⑤ 补 C：90° 几何参考，并继承同一转向
⑥ 检查三视图朝向是否一致
⑦ 只修有问题的视图，冻结已通过视图
⑧ 仍不稳 → A+B+C 重新稳定化
⑨ 固化 FACE_FRONT/45/90_STABLE_01
⑩ 可选：对最终成品图做画质修复，保留 PASS 原图
⑪ 后续任务使用稳定资产，不再回原始图
```

### 最终门禁

- [ ] A、B、C 的职责已明确，身份权重为 `A >>> B ≈ C`
- [ ] 已按模板固定值 `TURN_LEFT` 执行，45° 与 90° 都向画面左侧
- [ ] 三个角度像同一个连续 3D 头模，而非三个独立角色
- [ ] 45° 如需提高相似度，已明确使用原 45° 图作为外观/相似度参考
- [ ] 0° 与 45° 稳定后，修复 90° 未牵连已通过视图
- [ ] 90° 的额鼻唇下巴侧面曲线自然，耳位、后脑和头颈连接无明显断裂
- [ ] 稳定结果已登记为 `FACE_FRONT/45/90_STABLE_01`
- [ ] 画质修复（如执行）未改变身份、转向、角度和结构，并保留原始 PASS 版本
- [ ] 后续生成调用稳定资产，而不是未经筛选的原始照片
