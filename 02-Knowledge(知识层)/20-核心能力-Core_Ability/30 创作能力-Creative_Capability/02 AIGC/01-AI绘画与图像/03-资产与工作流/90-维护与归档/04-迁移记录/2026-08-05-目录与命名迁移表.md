# 目录与命名迁移表

| 原路径或名称 | 新路径或名称 |
|---|---|
| `01-素材图库` | `01-公共资产库` |
| `02-人物资产` | `02-角色资产库` |
| `03-专项资产库` | `03-专项生产库` |
| 根目录规范文件 | `00-入口与规范` |
| 根目录日期报告 | `90-维护与归档/02-审计报告/2026` |
| 通用维护脚本 | `04-工作流模板与自动化/03-生成与检查脚本` |
| `Pasted image ...` | 语义化 SOP 与示例名称 |
| 单位版本 `v1/v2` | 两位版本 `v01/v02` |

## 实施原则

- 本次没有将数百张人物过程图强制搬入角色目录；通过角色 MOC 建立跨阶段导航。
- 文件内容未因单纯移动而升级资产版本。
- 所有旧路径引用在知识包内批量重写，并进行完整性检查。
