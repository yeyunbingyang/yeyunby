# 资产注册表字段说明

## 两类清单

| 文件 | 职责 |
|---|---|
| `资产清单.json` | 全量技术清单：路径、类型、大小、哈希和重复关系，用于校验 |
| `资产注册表.json` | 核心语义资产：MOC、关键方法、模板、变量库、视觉索引和交付资产，用于生产与维护 |
| `99-归档/资产注册表-全量自动推断-v01.json` | 第一轮自动推断结果，仅供迁移追溯 |

## 关键字段

- `asset_id`：稳定唯一ID，不随文件名轻易变化。
- `canonical`：是否是该职责当前权威资产。
- `status`：生命周期，使用 `draft / active / deprecated / archived`。
- `maturity`：成熟度，使用 `idea / testing / usable / stable`。
- `source_status`：来源是否已确认；`unconfirmed` 需要人工补充。
- `license_status`：授权是否已确认；关键交付不得长期保持 `unconfirmed`。
- `replaces`：替代的旧资产ID。
- `used_by`：依赖该资产的项目或交付物。


## 来源与授权字段

| 字段 | 说明 |
|---|---|
| `source_type` | 自制、AI生成、已授权第三方或未知 |
| `source_reference` | 来源文件、网址、合同或生成记录 |
| `rights_status` | self_created / licensed / study_only / restricted / unknown |
| `commercial_use` | allowed / prohibited / unconfirmed / not_applicable |
| `identity_consent` | 真人或身份素材的授权状态 |
| `usage_scope` | 允许的使用范围 |
| `rights_reviewed_by` | 人工审核人 |
| `rights_reviewed_at` | 最近审核日期 |
