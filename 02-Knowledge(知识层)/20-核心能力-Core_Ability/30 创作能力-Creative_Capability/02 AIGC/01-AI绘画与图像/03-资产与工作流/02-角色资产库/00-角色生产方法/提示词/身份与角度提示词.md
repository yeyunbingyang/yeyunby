# 身份与角度提示词

## 公共变量

```text
角色编号：{角色ID}
身份参考：{正面母版/多角度图及职责}
身体参考：{冻结身体母版}
风格参考：{动漫正面母版或抽象视觉模块}
目标角度：yaw={值}，pitch={值}，roll={值}
表情：平静、闭嘴、不露齿
镜头：85mm长焦感，视平线稳定，低透视畸变
输出：{分辨率/画幅/独立图或展示板}
冻结项：脸型、眼距、眼型、鼻梁鼻尖、嘴唇、下颌、年龄、肤色、发际线、发缝、发色、发长、身体比例
可变项：{本轮唯一变量}
```

## 身份母版

### GPT模板

```text
使用我提供的全部已授权人物图作为同一成年角色的身份证据。以清晰正面图为主要几何锚点，其他角度只补充被遮挡结构，不平均、不拼接、不重新设计面孔。

生成一张标准正面0°身份母版：头部无倾斜，双眼平视，表情平静，嘴巴轻闭，不露齿；补全头顶、双耳、下巴和肩部。严格保留脸型与下巴、眼距与眼型、眉形、鼻梁与鼻尖、嘴唇厚度与嘴角、年龄感、肤色、发际线、发缝、发色、发长及妆容。浅灰影棚背景，85mm人像摄影感，柔和均匀光线，真实皮肤纹理。

禁止美化、幼化、尖下巴、放大眼睛、缩小鼻子、改变发缝、左右拼脸、双重五官、文字和多格排版。只输出一张独立正面图。
```

### 即梦适配（待实测）

将最清晰正面图设为身份主参考，其余图标注为“同一人物的结构补充”；身份权重高，风格权重低。提示中明确“单图输出、正面0°、不拼图”。若平台支持局部重绘，先修轮廓和眼睛，不同时改变妆容。

## 人脸多角度

### 通用单角度模板

```text
以通过验收的正面身份母版作为唯一身份锚点，生成同一人物的{目标角度}独立头像。头部姿态必须由真实三维旋转产生，不只改变眼神。保留全部冻结身份特征、年龄、肤色、妆容和发型；保持相同镜头、光线、白平衡、背景、头部大小和肩部裁切。

目标：yaw={yaw}°，pitch={pitch}°，roll=0°。嘴巴轻闭，不露齿。禁止镜像复制、重新设计远侧五官、双重轮廓、多格板和文字。
```

严格90°追加：`远侧眼不得完整可见，鼻梁、鼻尖、嘴唇和下巴形成准确侧面轮廓，耳位与颅骨透视自然。`

俯视追加：`角度来自头颅向下旋转，能够看到更多头顶，不能只向下看。`
