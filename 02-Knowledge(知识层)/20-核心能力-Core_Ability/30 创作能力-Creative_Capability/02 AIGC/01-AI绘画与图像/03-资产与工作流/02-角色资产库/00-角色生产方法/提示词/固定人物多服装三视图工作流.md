# 固定人物多服装三视图工作流

> [!abstract] 核心结论
> 人脸参考负责身份，身材参考负责身体比例，服装参考只负责服装；每套服装都直接读取原始人脸和原始身材，不能把上一轮生成图当作下一轮身份参考。

## 适用目标

为同一位成年人物依次更换多套服装，每套服装生成一张独立图片，每张包含：

- 正面全身
- 45° 侧面全身
- 背面全身

多套服装不得拼在同一张大图中。

## 参考图职责

| 参考图 | 负责内容 | 不得继承 |
|---|---|---|
| 人脸三视图 | 脸型、骨骼、五官、下颌、刘海、发型、侧脸轮廓 | 身材、服装 |
| 身材参考 | 肩宽、胸腰胯、躯干、腰线、臀部、腿长、上下身比例 | 脸、发型、五官、服装 |
| 当前服装参考 | 版型、材质、颜色、裁片、刺绣、系带、配饰、鞋袜 | 人物身份、腿长、腰臀比例 |

人脸三视图中，各角度还有不同职责：

- 正面：正面脸型、眼眉鼻唇、下颌、刘海与五官比例。
- 45°：鼻梁、颧骨、下巴、面部纵深及眼窝关系。
- 90°：额头—鼻梁—鼻尖曲线、唇部突出度、下颌线、后脑和发型侧面结构。

## 正确的生成拓扑

```text
原始人脸 + 原始身材 + 服装 A → 图片 A
原始人脸 + 原始身材 + 服装 B → 图片 B
原始人脸 + 原始身材 + 服装 C → 图片 C
原始人脸 + 原始身材 + 服装 D → 图片 D
原始人脸 + 原始身材 + 服装 E → 图片 E
```

禁止使用链式生成：

```text
原始人脸 → 图片 A → 图片 B → 图片 C
```

链式参考会逐轮积累小误差，使人物从“原始人物”漂移成“相似人物”，最后变成另一个人。

## 标准流程与门禁

1. **身份基准图**：用原始人脸三视图确认脸型、五官、发型和各角度身份一致。
2. **身材基准图**：加入身材参考和简单基础服装，确认肩宽、腰臀、腿长及上下身比例。
3. **逐套换装**：每套服装作为独立任务，重新输入原始人脸、原始身材和当前服装。
4. **逐张验收**：先验收身份和身体，再验收服装结构；失败时回到原始参考重生成，不沿用失败图修补下一套。

推荐顺序：

```text
身份基准图 → 身材基准三视图 → 服装 1 → 服装 2 → 服装 3 → 服装 4 → 服装 5
```

## 完整提示词模板

```text
【任务】
根据参考图生成同一位成年人物的全身服装三视图。
本次只改变服装，保持人物身份、脸型五官、发型和身体比例一致。

【参考图职责】
人脸三视图是最高优先级身份参考。
严格保持原人物的脸型、面部骨骼、眼型、眉形、鼻型、鼻梁高度、唇形、下巴、下颌线、五官比例、刘海、发型、发际线和人物辨识度。
正面人物参考正面人脸；45°人物参考45°人脸结构；侧脸结构参考90°侧面人脸。
不要重新设计或美化人物面部，不要改变眼睛大小、鼻型、脸型、下巴和年龄感。

身材参考图只用于身体比例。
保持肩宽、胸腰胯比例、腰线、躯干长度、臀部轮廓、腿长、上下身比例和整体体型。
不要根据服装参考图改变人物身材。

服装参考图只负责服装设计。
准确还原版型、领口、肩部、胸前、腰部、下摆、裁片、系带、开口、刺绣、面料、颜色、配饰和鞋袜。

【三视图】
从左到右依次为：完全正面的全身站立视图、身体转约45°的侧面全身视图、完全背面的全身站立视图。
三个视图必须是同一人物、同一服装和同一身体比例。

【姿势与摄影】
自然直立，双臂自然垂下，双腿自然站立；不要夸张动作、扭腰或摆拍。
专业服装 Lookbook / 商品摄影，全身从头顶到鞋底完整入画。
三个视图使用相同摄影高度、焦距、人物缩放比例和站立基准线。
纯白或浅灰白背景，柔和棚拍灯光，真实自然皮肤质感，服装材质清晰。

【避免】
避免人脸漂移、五官重设计、三视图成为不同人物、身材变化、腰臀比例变化、腿长变化、发型变化、服装结构改变、背面凭空增加结构、系带不一致、刺绣位置随机变化、视图比例不同和透视畸变。

【输出】
一张图片只展示当前这一套服装，包含正面、45°侧面和背面。
不要加入其他服装，不要把多套服装拼成一张图。
多套服装分别独立生成多张图片。
```

## 最小可用提示词

```text
使用参考人物生成当前服装的全身三视图，只改变服装。

人脸三视图是最高优先级身份参考，保持原脸型、眼型、鼻型、唇形、下颌、刘海、发型和人物辨识度。
身材图只负责肩宽、胸腰胯、腰线、臀部、腿长和上下身比例。
服装图只负责服装结构、颜色、材质、刺绣、系带、鞋袜和配饰。

画面从左到右为正面、45°侧面、背面；同一人物、同一身体比例、同一服装，自然直立，全身完整展示，浅灰白棚拍背景，专业服装 Lookbook 摄影。

避免人脸漂移、五官重设计、三视图不同人、身材变化和服装结构变化。
一套服装一张图片，多套服装分别生成，不合并。
```

## 多套服装的结构化变体

多套设计不能只换颜色，还应改变结构语言。例如：

| 套装 | 上衣变化 | 下装变化 | 主色 |
|---|---|---|---|
| 01 | 经典倒三角肚兜 | 不对称裙裤 | 黑金 |
| 02 | 水滴领肚兜 | 侧系带短裙 | 象牙白金 |
| 03 | 交叉颈带肚兜 | 开衩裙裤 | 酒红金 |
| 04 | 盘扣高领肚兜 | 斜襟短裙 | 青瓷绿 |
| 05 | 蝶结挂脖肚兜 | 双层围裹裙裤 | 淡粉 |

## 新中式肚兜附加模块

```text
现代改良中式肚兜套装。

上衣采用中式肚兜式挂脖结构，正面为倒三角或尖角下摆，侧腰适度露空，后背大面积开放，以颈后和后腰细系带固定，可加入流苏或盘扣。

材质为真丝或缎面，具有柔和光泽和精细东方刺绣，可使用花枝、梅花、牡丹或传统纹样。

下装采用低腰或中腰短裙 / 裙裤，与上衣材质统一，可加入侧系带和流苏；结构完整、自然可穿。

整体是具有东方元素的现代新中式时装，不是古装或旗袍。
```

## 常见失败与修复

| 失败表现 | 原因 | 修复方式 |
|---|---|---|
| 眼睛变大、鼻型变细、下巴变尖 | 模型重新设计或美化面部 | 强化原始人脸为最高优先级，明确禁止重设计 |
| 45°侧脸不像本人 | 未给角度专属身份信息 | 分别指定正面、45°和90°人脸的职责 |
| 越生成越不像 | 使用上一张生成图传递身份 | 每套都回到原始人脸和原始身材 |
| 身材随服装改变 | 服装参考中的模特轮廓污染身体 | 明确服装参考只负责服装结构 |
| 五套仅有颜色差异 | 设计变量只描述色彩 | 同时改变领型、裁片、开口、下装和系带结构 |

> [!warning] 能力边界
> 提示词只能提高一致性，不能保证生成模型精确复现真实人物或不可见角度；用于正式角色资产时，应继续按[[验收与失败修复规范]]逐张检查。
