# 3D半写实角色三视图生产流程

> [!abstract] 核心逻辑
> **解耦风格生成与身份约束，降低单轮生成的认知负荷。** 每一层只解决一个问题，禁止跨层混修：风格层管"材质语言对不对"，身份层管"是不是这个人"，二者分开建立，再融合校正。

## 一、流程总览

```text
Step 1 风格母版建立 → Step 2 身份几何包准备 → Step 3 风格×身份融合 → Step 4 局部视角校正
      (Style Model)      (Identity Geo)        (Fusion)           (Correction)
      输出:材质语言         输出:骨相数据         输出:三视图草稿      输出:定稿
```

**核心原则**：每一层只解决一个问题，禁止跨层混修。

## 二、Step 1：风格母版建立

### 2.1 目标
建立一套可复用的**视觉材质系统**，不绑定任何具体人物。此阶段**完全不在意"像不像"**，只在意"材质语言对不对"。

### 2.2 需要锁定的维度

| 维度 | 关键指标 | 验收标准 |
|---|---|---|
| **风格层** | 3D国漫半写实、真实比例、电影级光影 | 无纯二次元特征，无过度美型 |
| **皮肤层** | 瓷感+自然纹理、柔和SSS、干净透亮 | 放大看有毛孔/纹理，但整体不糙 |
| **头发层** | 清晰3D发丝、发束逻辑、发际线自然、半透明边缘高光 | 发丝可数，不发片，不塑料 |
| **眼睛层** | 虹膜结构、睫毛材质、眼球高光、半写实比例 | 非二次元大眼，有真实折射感 |
| **服装/发饰** | PBR材质、金属/布料/冰晶质感区分 | 材质语义清晰，不糊 |
| **光影层** | 柔光主灯+轮廓光、电影级布光 | 无平光，无过度曝光 |

### 2.3 推荐操作方式
- 先用**通用描述**生成多组三视图（不指定具体人物）
- 从中挑选最满意的一张作为**风格母版基准图**
- 记录该图的种子值/风格参考ID，后续固定使用

### 2.4 风格母版提示词模板

```markdown
【风格锁定 - 母版专用】
高品质3D国漫半写实风格，真实人物比例基础上的适度动漫美型，
高细节CG角色渲染，细腻皮肤Shader，柔和SSS次表面散射，
轻微瓷感但保留自然皮肤纹理，干净透亮、不过曝，
清晰3D发丝，发束结构明确，发际线自然，半透明边缘高光，
高质量虹膜与眼球反光，细致睫毛，电影级柔光，PBR材质，
国产高品质3D动画角色质感，正面/45°/90°三视图，白色背景。
```

## 三、Step 2：身份几何包准备

### 3.1 目标
提取目标人物的**纯几何信息**，剥离一切风格/材质/光影干扰。

### 3.2 必备素材

| 视角 | 用途 | 关键验收点 |
|---|---|---|
| **正面** | 五官比例、脸宽、眼距、颧骨 | 左右对称基准 |
| **45°** | 鼻梁高度、眉弓、面颊转折 | 确认旋转关系自然 |
| **90°严格侧脸** | 鼻-唇-颏轮廓、下颌线、下巴形态 | **最容易崩，需最严格** |

### 3.3 身份几何包提取清单

```
□ 脸型：长宽比、颧骨位置、下颌角角度
□ 额头：高度、饱满度、发际线形状
□ 眉弓：突出程度、眉形走向
□ 眼型：内外眼角高度差、眼裂长度、双眼皮形态
□ 鼻型：鼻梁高度、鼻尖形态、鼻翼宽度、鼻唇角
□ 唇形：上下唇厚度比、唇峰、嘴角走向
□ 下巴：长度、翘度、圆润度/尖度
□ 下颌线：清晰度、与颈部过渡方式
□ 90°轮廓：鼻尖最前 → 嘴唇次之 → 下巴微后收（关键！）
```

### 3.4 禁止事项
- 此阶段**不要**给风格描述
- 此阶段**不要**给材质描述
- 此阶段**不要**给光影描述
- 只给"这是谁，长什么样"的纯几何信息

## 四、Step 3：融合生成

### 4.1 融合公式

```text
Result = Style Model(材质/光影/质感) × Identity Model(脸型/五官/骨相)
```

### 4.2 优先级约定

| 优先级 | 来源 | 控制内容 |
|---|---|---|
| **P0-最高** | 身份三视图 | 脸型、五官比例、额头、颧骨、眼型、鼻型、唇形、下巴、下颌线、朝向关系 |
| **P1-次高** | 风格母版 | 皮肤Shader、头发质感、发饰材质、光影系统、服装材质、整体渲染气质 |

### 4.3 融合提示词模板

```markdown
【风格层 - 引用母版】
引用风格母版：[母版种子/参考图]
高品质3D国漫半写实渲染，真实比例，电影级柔光，PBR材质，
细腻皮肤Shader，柔和SSS，轻微瓷感保留自然纹理，
清晰3D发丝，发束结构明确，发际线自然，半透明边缘高光，
高质量虹膜与眼球反光，细致睫毛。

【身份层 - 严格约束】
以身份三视图为唯一人物几何参考，
严格保持原人物脸型、脸部长宽比例、额头、颧骨、眼型、鼻型、唇形、下巴、下颌线与人物辨识度。
正面、45°、90°必须是同一人物的真实旋转关系。
90°严格保持原始侧脸的鼻—唇—颏轮廓：
鼻尖最前，嘴唇次之，下巴轻微后收；
下巴短小圆润，不拉长，不前翘，不尖化。

【输出要求】
正面 + 45° + 90°严格侧脸，三视图排列，同一角色，白色背景。
```

## 五、Step 4：局部视角校正

### 5.1 校正顺序（重要！）
按**从难到易**的顺序修，避免简单视角修完后被连带崩坏：

```text
1. 90°侧脸（最难，最容易风格化变形）
2. 45°侧脸（验证旋转一致性）
3. 正面（最后确认整体统一性）
```

### 5.2 校正检查清单

| 检查项 | 合格标准 | 常见错误 |
|---|---|---|
| **90°鼻唇颏** | 鼻尖最前 → 嘴唇 → 下巴微后收 | 下巴前翘或过度后缩 |
| **90°下颌线** | 与身份图一致，不重新美型 | 下颌角被磨平或过度突出 |
| **45°旋转逻辑** | 正面到90°的过渡自然 | 像两个人拼接 |
| **发饰遮挡** | 与发型/视角关系合理 | 发饰漂浮或穿透 |
| **朝向一致性** | 三视图瞳孔/鼻尖朝向统一 | 左右脸像不同人 |
| **下巴形态** | 短小圆润，不拉长不尖化 | 被风格母版带成网红下巴 |

### 5.3 修复提示词模板（针对90°）

```markdown
【90°局部修复专用】
保持已确定的3D半写实风格与材质系统不变，
仅修正90°侧脸几何：
- 严格匹配参考侧脸的鼻—唇—颏垂直轮廓
- 下巴保持短小圆润，禁止拉长/前翘/尖化
- 下颌线保持原始角度，禁止磨平或过度切割
- 鼻尖为面部最前点，嘴唇次之，下巴微后收
- 仅修改轮廓几何，不修改皮肤/头发/光影材质。
```

## 六、版本管理建议

建立**同身份多风格**的扩展能力：

```text
项目文件夹/
├── 01_风格母版/
│   ├── 母版_A_冰蓝发.zip
│   ├── 母版_B_银白发.zip
│   └── 母版_C_黑发冰饰.zip
├── 02_身份几何包/
│   ├── 正面_参考.png
│   ├── 45°_参考.png
│   └── 90°_参考.png
├── 03_融合输出/
│   ├── 冰蓝发_三视图_v1.png
│   ├── 银白发_三视图_v1.png
│   └── ...（同一身份，不同风格母版）
└── 04_校正定稿/
    └── 最终版本
```

这样可以：
- 换发色/发饰时，**只换 Step 1 的风格母版**，身份几何不变
- 修 90° 时，**只动 Step 4**，不污染已锁定的风格
- 每个版本都是**同一个人**，只是**不同风格皮肤**

## 七、快速检查表（每次生成前过一遍）

```text
□ Step 1：风格母版是否已确定并固定？
□ Step 2：身份三视图是否覆盖正/45°/90°？
□ Step 3：提示词是否分"风格层"和"身份层"两段写？
□ Step 3：是否明确声明"90°严格保持原始侧脸轮廓"？
□ Step 4：是否先修90°，再修45°，最后确认正面？
□ Step 4：是否禁止在修正阶段修改材质/光影？
```
