# 角色设定规范板-提示词案例

## 古典温婉大家小姐
![[03-资产与工作流/02-角色资产库/02-过程资产/通用参考/角色设定案例/角色设定案例-03.png]]

人物形象提示词：（三视图）

1.主视觉区 (上方)以 "正面 + 侧面 + 背面" 三个核心视角为主体，直观呈现角色的整体身形、服饰搭配和标志性特征，是制作人员对人物 "整体造型" 的参考基础。

2.补充信息区 (左侧)拆分出 "面部特写" 和 "配色板"(明确毛发、服饰的色值)，补充主视角没覆盖的细节与色彩标准。

3.局部细节区 (底部)用小模块单独展示关键部件的设计 (配饰、点缀、关键身份识别元素)，把主视角里的 "模糊细节" 拆分为精准的制作参考，方便导演确认。

4.全身照比例照 (右侧)使用黄金比例参考物和人物身高形成对比。

5.背景为白色，最高品质细节丰富。

6【真人写实】超写实国风，现代风格，写实风格，质感光照，自然光线，质感十足，8K高清纹理，布料褶皱自然，艺术写实风格，营造出震撼的视觉效果。人物外观设定

古典温婉大家小姐，年约十六七岁，面容清丽柔和，眉如远山含黛，眼似秋水横波，唇点浅豆沙色，发髻梳成温婉的垂挂髻，簪着一支珍珠步摇，鬓边簪两朵新鲜白茉莉。身着月白色暗纹襦裙，外罩一件水绿色半臂，领口袖口绣着精致的缠枝莲纹样，裙摆垂落如流云。手中轻拈一方绣着兰草的素色丝帕，身姿娴静，正面站立，眼神清澈温和，带着浅浅笑意，气质娴雅温婉，尽显大家闺秀的端庄柔美。裙摆拖地，遮住了小巧秀美的软香绣花鞋。





## 第七舰队 的 K-7
![[03-资产与工作流/02-角色资产库/02-过程资产/通用参考/角色设定案例/角色设定案例-02.png]]
![[03-资产与工作流/02-角色资产库/02-过程资产/通用参考/角色设定案例/角色设定案例-04.png]]
为 第七舰队 的 K-7 创作一张 专业级角色设定
规范页 / character design sheet / sci-fi concept art sheet，整体为 高真实感军事科幻机甲风格，强调 电影级概念艺术质感、工业设计展示逻辑、真实材质表现、统一比例三视图。

角色核心设定

角色名称：K-7
所属：第七舰队
身份：机甲驾驶员
性别气质：成年男性，冷峻、克制、专业
身高：185厘米
头身比：1:8
外貌：锐利眼神，直鼻，薄唇，棱角分明的下颌线，短款银色头发，偏冷灰银色；左耳后有 神经接口端口。
角色整体应具有 现实人类比例和真实面部骨骼结构，避免二次元感、避免卡通化。

关键强制特征

机械左臂必须在所有视图中清晰可见，并保持完全一致：

机械左臂
外露液压管线
金属关节与活塞结构
局部蓝色微光能源节点
精密机械手指
背面可见机械左臂与背部装甲的接口连接结构

该机械左臂是角色最重要识别点，不能遗漏，不能在不同视图中发生结构漂移。

服装与装备设计

K-7 穿着 未来军事机甲驾驶员战术装备，风格接近 近未来特种部队 + 轻量外骨骼装甲，不是中世纪铠甲，不是奇幻服装。
装备应包含：

黑色或深蓝黑色贴身战术内层
模块化胸甲、肩甲、臂甲、腿甲
磨砂碳纤维装甲面板
钛合金或银灰色边缘强化件
多处细密面板线
机械连接件、螺丝、导线、接口、装甲锁扣
战术腰带、挂载点、功能性护膝、战术靴
整体质感偏 真实军工装备，而非幻想盔甲

材质表现要真实：

碳纤维纹理
阳极氧化金属
轻微磨损和使用痕迹
精密机械加工痕迹
金属高光与边缘反射
战术橡胶、织物补强区、硬质装甲混合材质
版式结构（严格）

整张图是一页 专业角色设定规范页，背景为 深灰或黑色，带 细微网格纹理 和少量 HUD / 工程技术线框装饰，但要整洁，不要杂乱。

顶部区域（占 8%）
居中主标题：“第七舰队”
使用 未来科技字体
具有 全息蓝白发光效果
字体造型带 几何锐角设计
副标题：“机甲驾驶员·设定图”
顶部整体像军事科技档案页的页眉
中央区域（占 52%）

制作 三视图 T 字站姿角色展示，要求绝对规范：

正面视图：全身完整，双脚位于同一基线，展示机械左臂
右侧面 90° 视图：同比例，基线完全对齐，清晰展示轮廓与机械左臂侧面结构
背面视图：同比例，基线完全对齐，展示背部装甲细节和机械左臂背部接口

中央三视图必须满足：

三个视图比例完全一致
身高一致
头身比一致
装备细节一致
面部身份一致
机械左臂结构一致
站姿规范
线条与渲染风格统一
不允许身份漂移，不允许不同人脸，不允许肢体变化
左侧区域（占 18%）

做一个 面部特写肖像框：

正面近景半身或头肩像
中性表情
柔和但清晰的打光
突出锐利眼神、直鼻、薄唇、棱角下颌线
银色短发细节清楚
左耳后神经接口端口可见
真实皮肤质感，但整体仍然维持概念设计板风格
右侧区域（占 18%）

制作 比例参考图：

全身轮廓图
带头身比标记线
标明：身高 185 厘米
标明：头身比 1:8
有 装甲肩宽标注线
呈现工业设计参考图的理性、技术化表达
底部区域（占 22%）

底部严格分成 六格细节拆解，每格边界清晰，彼此不重叠，格子之间留窄分隔线。
六格内容固定如下：

[A] 仅展示：肩甲液压关节结构
[B] 仅展示：磨砂碳纤维，电路纹路
[C] 仅展示：全息 HUD 投影界面
[D] 仅展示：战术目镜，反光涂层
[E] 仅展示：第七舰队舰队编号铭牌
[F] 仅展示：机械左臂液压管线特写

六格要求：

每格内容独立
不能互相重叠
内容必须明确单一
类似专业概念图中的零部件拆解栏
配色板

页面中加入一组 配色板 / color palette，并标注文字与色值：

发色：#0D1B2A
主色：#1B3A5C
辅色：#2E5C8A
镶边：#C0C0C0
特效：#00BFFF

色彩整体应以：

深蓝黑
冷灰银
科技蓝微光
为主，形成 高对比科技配色 + 霓虹点缀光。
视觉风格与质感

整体风格要求：

精确技术线稿
面板线丰富
机械细节密集
硬边赛璐珞阴影
金属高光
高真实感科幻 / 赛博朋克 / 机甲美学
电影级概念艺术品质
专业角色设定板
对称构图
高分辨率
整洁清晰
像 AAA 游戏 / 电影前期设定图
更偏真实摄影质感与军工装备真实度，而非插画卡通感

真实感重点强化：

写实人脸结构
真实光影逻辑
真实材料反射
轻微磨损、划痕、制造痕迹
冷调摄影棚布光
高端工业产品拍摄感
不要塑料玩具感
不要明显 3D 渲染假感
负面提示词

Negative Prompt：

模糊线稿，低细节，低清晰度，卡通风，动漫风，Q版，夸张比例，幼态脸，照片拼贴感，3D 游戏模型感，廉价 CGI 感，塑料材质感，中世纪铠甲，天然面料服装，奇幻元素，有机怪物元素，魔法元素，女性化脸型，多余肢体，缺失身体部位，错误手指，机械左臂缺失，三视图比例不一致，三视图不是同一角色，面部漂移，左右不对称，站姿不规范，构图杂乱，背景杂乱，过曝，过度发光，信息面板重叠，底部六格混乱，文字错误，解剖错误，肢体扭曲，低真实感。

## 真人面部设计（重点强化）

必须呈现真实东方男性面孔：

- 高挺鹰钩鼻，真实鼻骨结构
- 锐利深邃眼窝
- 突出的颧骨
- 清晰下颌线
- 薄唇，嘴角带若有若无的冷笑
- 苍白但有血色层次的真实皮肤
- 毛孔、细微皮肤纹理、自然阴影可见
- 真实睫毛、眉毛、发丝

眼睛强制特征：

**右眼：血红色竖瞳，如蛇类瞳孔，猩红虹膜，细长黑色瞳孔，具有魔性光泽。**

**左眼：正常黑色瞳孔，保持人类状态。**

所有视图：
正面、侧面、背面必须保持：

- 同一张脸
- 同一发型
- 同一眼睛设定
- 右眼血红竖瞳始终存在
