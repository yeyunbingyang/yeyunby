# 真人仙侠角色设定板提示词调教实验

> [!success] 核心结论
> “明确少量身份不变量 + 限制面板数量”比反复强调“严格保持”或编写百分比权重更有效；若追求真人感，应把机械正交三视图改写为真人演员定妆摄影式多角度观察，并允许各视图采用不同的自然重心。

## 实验目标

使用一张成年人物近正面照片作为唯一身份参考，在同一张横向设定板中生成：

- 正面全身；
- 左 45° 全身；
- 背面全身；
- 人脸近景；
- 眼睛、猫耳发饰、衣料与腰饰细节。

测试重点不是单纯追求画面华丽，而是比较以下指标：

1. 人脸身份相似度；
2. 跨视图角色与服装一致性；
3. 版式执行率；
4. 真人感与假人感；
5. 局部细节对主视图的对应程度。

## 输入边界

本次只有一张近正面参考图，因此：

- 正面与轻微 45° 只能验证近似身份一致性；
- 严格侧脸、后脑结构、全身比例均由模型补全；
- 生成结果不能作为真实人物侧脸或身材资料；
- 原始身份参考图不归档到本知识库，本页只保留生成结果。

## 三轮测试

### 第一轮：结构化长提示词

策略：依次明确身份、风格、版式和约束，并列举较多面部特征。版式压缩为四个主视图和四个细节框。

![[03-资产与工作流/02-角色资产库/02-过程资产/正式角色/真人仙侠角色/01-结构化长提示词.png]]

观察：

- 版式、风格和英文标签执行良好；
- 正面、45°与背面服装基本统一；
- 人脸仍被理想化，鼻部、下颌、眼型和牙齿细节发生变化；
- 局部饰品与全身图不能完全一一对应。

结论：结构化分区有效，但长篇五官枚举和“身份权重百分比”不能形成真实参数控制。

### 第二轮：精简提示词

策略：删除虚构权重，压缩重复的五官枚举，只保留少量高辨识度不变量，并保持第一轮版式规模。

![[03-资产与工作流/02-角色资产库/02-过程资产/正式角色/真人仙侠角色/02-精简提示词.png]]

观察：

- 版式要求没有因提示词精简而丢失；
- 人脸相似度略有提升，眼型、刘海、笑容和年龄感更接近参考；
- 三个全身视图仍呈完全对称、僵直手臂和统一空表情；
- 结果更像服装目录中的游戏建模假人。

结论：精简提示词不会天然降低执行率；假人化主要由“统一比例、正交视角、同基线、标准站姿”等约束共同触发，而非身份描述不足。

### 第三轮：自然姿态修正

策略：把“严格机械三视图”改为“同一真人演员完成的角色定妆摄影”，保留可比较角度，但允许不同自然重心、手部动作、肩部角度和头部方向。

![[03-资产与工作流/02-角色资产库/02-过程资产/正式角色/真人仙侠角色/03-自然姿态修正版.png]]

观察：

- 肩颈、手臂和手部明显更放松；
- 45°视图出现自然转身与回望；
- 背面具有身体转角，不再像机械旋转模型；
- 布料褶皱随姿势发生变化；
- 仍保留摄影棚服装展示感，但假人感显著下降。

结论：真人感与工程制图式三视图存在天然冲突。允许微小姿态差异能提升生命力，但会牺牲一部分严格正交和结构对照精度。

## 最终可复用提示词

```text
图1是唯一的人物身份参考。只参考人物的面部、发型和固定外观特征；不参考背景、原服装、姿势和原始光线。

把图1中的同一位成年人物设计成真实可信的东方仙侠游戏角色。所有画面必须像同一位真人演员完成的角色定妆摄影与服装设定拍摄，而不是3D假人、服装模特人台或僵硬的游戏建模转面图。

身份优先：保留整体脸型与面部比例、眼型和眼距、眉眼关系、鼻部与嘴唇的主要比例、下巴轮廓、自然神态、发型和固定识别特征。保持自然的年龄感与族裔外观，保留真实皮肤纹理、毛孔、轻微肤色变化和自然眼神。不要磨皮成塑料皮肤，不要改成通用网红脸，不要夸张动漫化。

人物自然感要求：
- 每个视图都采用放松、可信的人体站姿，不使用T-pose或A-pose；
- 肩膀自然下沉，手肘微弯，手指自然分开，颈部和腰部不僵直；
- 身体重心自然落在一条腿上，膝盖不过度锁死；
- 正面保持自然神态与有生命力的眼神；
- 45度视图允许头部轻微回望镜头，姿态与正面不同但服装结构一致；
- 背面采用自然站姿，头部略微侧转但不要露出虚构的完整侧脸；
- 保留细微人体不对称、头发散丝、衣料重力、褶皱和布料受力；
- 不要复制粘贴同一套四肢姿势，不要像蜡像、机器人、纸片人或橱窗模特。

角色风格：高品质写实东方仙侠真人角色概念设计；[主色]、[辅色]与[点缀色]；[服装结构]、[发饰]、[纹样]和[腰饰]。材质必须具有真实重量，不要过度华丽堆砌。

版式：横向、白色或极浅暖灰影棚背景，柔和真实棚拍光线。上半区包含三个较大的真人角色视图：自然正面站姿、自然左45度站姿、自然背面站姿；右侧放一个更大的人脸近景。三个全身视图用于观察服装与角色，不要求完全正交，也不要画成机械式三视图。下半区只放三个细节框：[面部细节]、[固定识别特征]、[服装与饰品细节]。各区域不重叠，脚部完整。

禁止额外人物、僵硬对称姿势、塑料皮肤、无神眼睛、重复肢体、多余手指、漂浮饰品、乱码、大段文字、水印和品牌标志。若版式整齐与人物自然感冲突，优先人物自然感。
```

## 经验知识规划

### 已验证，可进入模板

- 输入图必须逐张声明职责，身份图不能同时被默认作为服装、背景和光线参考。
- 身份描述保留少量高辨识度特征即可，重复拆分鼻翼、鼻尖等细项没有稳定增益。
- 百分比权重只适合表达人类阅读顺序，不是模型可执行的参数。
- 单板控制在 3～4 个主视图和 3～4 个细节框，比一次塞入十余面板更稳定。
- 负面提示词应针对可观察失败现象，如僵硬对称、塑料皮肤和无神眼睛。
- “同一角色与服装”不等于“复制同一姿势”；允许自然姿态差异可以显著降低假人感。

### 需要区分的两类资产

| 资产 | 核心目标 | 姿态策略 | 适用下游 |
|---|---|---|---|
| Character Turnaround | 结构、比例、服装前后关系 | 中性、可对照，允许轻微自然重心 | 建模、服装拆解、结构确认 |
| Character Performance Sheet | 真人感、气质、表演可信度 | 行走、整理衣袖、侧身回望等自然动作 | 宣传图、视频首帧、角色气质确认 |

> [!warning] 不应混为一个验收门禁
> Turnaround 越追求严格正交和完全一致，越容易产生人台感；Performance Sheet 越自然，越不适合作为精确建模尺寸依据。最终 Character Bible 可以同时收录两类资产，但应分别生成、分别验收。

### 后续实验计划

- [ ] 补充同一人物正面中性表情、左右 45°和左右侧面输入，验证多图是否降低身份臆造。
- [ ] 将 Turnaround 与 Performance Sheet 分别生成，再进行最终排版合成。
- [ ] 对比“自然站姿”“整理衣袖”“轻微行走”“侧身回望”四种动作的身份保持率。
- [ ] 建立真人感评分项：眼神、肩颈、重心、手部、皮肤、头发、布料受力。
- [ ] 验证独立生成主视图后再拼版，是否优于一次生成完整设定板。
- [ ] 验证不同模型或版本后再将结论升级为跨模型通用规则。

## 第二阶段：身份与设计双参考生产链

### 目标与输入职责

第一阶段证明单张人脸参考可以稳定角色类型和版式，却不能冻结具体服装与饰品。第二阶段改用职责分离：

| 输入 | 负责 | 不负责 |
|---|---|---|
| 原始人脸图 | 身份、年龄感、五官与自然神态 | 服装和版式 |
| 选定的角色设定母版 | 服装、猫耳、发饰、配色与刺绣 | 替代原始身份 |
| 已通过的头肩身份母版 | 角色化后的高分辨率面部实现 | 身体和全身服装 |
| 已通过的正面母资产 | 身体、实际服装实现和摄影条件 | 重新设计身份 |

> [!important] 双真相原则
> 原始人脸是“身份真相”，角色设定母版是“设计真相”。发生冲突时，脸采用身份图，服装与饰品采用设计母版；提示词只定义本轮允许变化的角度、姿态和布料受力。

### 生产结果

#### 头肩身份母版

![[03-资产与工作流/02-角色资产库/02-过程资产/正式角色/真人仙侠角色/第二阶段母资产/01-头肩身份母版.png]]

结论：相比直接在全身图中修脸，高分辨率头肩任务能更好保留脸型、眼距、鼻部、笑容和牙齿观感；通过后再作为角色化面部锚点。

#### 正面角色母资产

![[03-资产与工作流/02-角色资产库/02-过程资产/正式角色/真人仙侠角色/第二阶段母资产/02-正面角色母资产.png]]

结论：身份、服装、自然姿态与全身完整性通过，可作为后续角度生产的主要设计锚点；生成式编辑仍不能做到非面部像素级冻结。

#### 自然左45°母资产

![[03-资产与工作流/02-角色资产库/02-过程资产/正式角色/真人仙侠角色/第二阶段母资产/03-左45度角色母资产.png]]

结论：使用原始身份、头肩母版和正面母资产三重锚点后，45°面部、领型、腰封、腰饰和配色保持良好，姿态自然且没有机械转面感。

#### 自然背面母资产

![[03-资产与工作流/02-角色资产库/02-过程资产/正式角色/真人仙侠角色/第二阶段母资产/04-背面角色母资产.png]]

结论：后脑、猫耳、长发、腰封、袖型与裙摆关系合理；未知背面细节采用最简单连续结构，没有把正面腰扣复制到背部，也没有强行展示虚构侧脸。

#### 最终角色设定板

![[03-资产与工作流/02-角色资产库/02-过程资产/正式角色/真人仙侠角色/第二阶段母资产/05-最终角色设定板.png]]

结论：先独立生成并验收各母资产、最后仅执行排版，明显优于一次生成全部视图。最终板的版式、自然姿态、身份和服装大结构通过，但生成式排版仍会轻微重绘输入资产，不应作为像素级源文件。

### 第二阶段验证结论

- [x] 双参考职责分离能稳定具体角色设计，而不只是稳定风格类别。
- [x] 高分辨率头肩身份母版比全身图直接修脸更有效。
- [x] 以已通过正面资产逐步派生45°与背面，比一次性三视图更稳定。
- [x] 背面未知区域应采用最简单连续结构，禁止模型主动增加设计。
- [x] 最终板应位于生产链末端，只承担展示，不承担母资产职责。
- [ ] 若要求像素级冻结，应使用确定性图像编辑与排版，而不是再次生成。

### 推荐生产链

```text
原始人脸身份图 + 角色设计母版
              ↓
        头肩身份母版
              ↓
        正面角色母资产
              ↓
     左45°母资产 + 背面母资产
              ↓
     独立细节图与表演姿态资产
              ↓
        最终 Character Bible
```

## 验收清单

- [ ] 特写与全身正面能立即辨认为同一人物。
- [ ] 正面与 45°的眼型、鼻部、下颌和年龄感没有明显漂移。
- [ ] 三个视图服装结构一致，允许褶皱随姿态变化。
- [ ] 肩颈放松，身体存在可信重心，不是完全左右对称。
- [ ] 手肘、手腕和手指自然，没有复制粘贴感。
- [ ] 眼睛有聚焦，皮肤不是塑料或蜡像质感。
- [ ] 头发有散丝，衣料有重力与受力变化。
- [ ] 背面不生成没有依据的完整侧脸。
- [ ] 细节框与主视图的发饰、纹样和腰饰能够对应。
- [ ] 标签无乱码，画面无额外人物、重复肢体和裁切脚部。
