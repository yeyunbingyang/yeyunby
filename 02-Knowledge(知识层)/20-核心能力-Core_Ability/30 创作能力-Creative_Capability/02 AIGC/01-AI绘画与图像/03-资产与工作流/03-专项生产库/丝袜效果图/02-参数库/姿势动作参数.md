# 姿势动作参数

## 动作库

| 组 | 编号与动作 |
|---|---|
| 站立行走 S | S01正面平行、S02单腿承重、S03小步行走、S04回身错步、S05脚尖轻交叉、S06侧向跨步、S07台步定格、S08轻踢回勾 |
| 椅凳坐姿 C | C01高凳端坐、C02椅边伸腿、C03侧坐斜腿、C04脚踝轻叠、C05台阶高低腿、C06长凳转向坐、C07单腿前探、C08双腿延伸 |
| 沙发地面 L | L01贵妃榻侧卧、L02沙发屈膝、L03半躺伸腿、L04脚凳抬腿、L05地毯侧坐、L06倚靠屈腿、L07横向休息、L08抬膝构图 |
| 道具互动 P | P01靠墙屈膝、P02扶栏侧跨、P03台阶回望、P04展台倚坐、P05长伞支撑、P06箱旁迈步、P07镜框交叉、P08长凳回勾 |

## 展示策略边界

- `D-BASE`：优先 S01、S02、C01；分类批量页可按S5＋C3＋L2＋P2使用躺姿和道具互动，但不得削弱技术对比。
- `D-DETAIL`：按效果可见性选择 S/C 或局部特写，不强制四类覆盖。
- `D-LIFESTYLE`：允许 S/C/L/P 多样化；相邻格动作不同即可。
- `分类批量基础页`：12格按S组5格、C组3格、L组2格、P组2格抽取；相邻格动作编号不同。
- `分类批量扩展页`：同样按S组5格、C组3格、L组2格、P组2格抽取，再按E可见性筛选组内动作。
- L/P组先在本组兼容池重抽；复杂道具允许进入P组，但必须记录用途、接触关系与商品无遮挡要求。无法兼容时必须记录并整页调整生产单，不得静默改成重复站姿。

## 适配规则

| 商品特征 | 优先动作 | 理由 |
|---|---|---|
| 基础透明度和厚度 | S01、S02、C01 | 受光和展示面积稳定 |
| 后缝、竖纹、渐变 | S05、C02、C08、L03 | 腿部延展充分 |
| 网格、印花、几何纹 | S07、C04、L07、P05 | 能观察图案拉伸 |
| 珠光、金属、偏光 | S04、S06、C07、P04 | 角度变化产生反射差异 |
| 厚袜、针织、绒面 | S03、C05、C06、L02 | 屈膝状态体现厚度与弹性 |
| 袜口、脚尖、后跟 | S01、S05、C02、T04构图 | 局部结构可见 |

## 动作事实字段

每个姿势执行时必须补齐：支撑腿、非支撑腿、膝盖方向、腿部前后关系、脚与鞋关系、地面或道具接触面。完整自然语言控制词由 [[生成提示词组装]] 生成。

## 人体门禁

- 恰好两条腿、两个膝盖、两个小腿、两个脚踝、两只脚和两只鞋。
- 关节弯曲方向真实，鞋与脚准确连接。
- 禁止悬空鞋、腿部融合、道具穿模和不明支撑。
- L/P 组只用于成年、完全着装、非挑逗的商业或概念表达。
