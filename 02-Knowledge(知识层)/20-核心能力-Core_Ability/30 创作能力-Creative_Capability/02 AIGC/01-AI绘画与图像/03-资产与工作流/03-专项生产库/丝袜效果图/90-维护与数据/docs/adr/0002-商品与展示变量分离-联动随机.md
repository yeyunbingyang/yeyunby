# ADR 0002：商品与展示变量分离并联动随机

## 状态

已接受（2026-08-02 实施）。

## 决策

商品变量（由 `E001–E200` 定义的丝袜本体差异）与展示变量（模特、服装、姿势、鞋履、背景、道具、场景、光线、镜头、构图、输出比例）分开管理。展示变量按“丝袜效果 → 服装 → 姿势/构图 → 背景 → 道具 → 光线”顺序逐层筛选候选池后联动随机，不允许全字段独立乱抽。

## 背景

实测 T03-v2 出现展示变量退化：为规避安全误判，提示词把全部格子压成统一站姿、灰黑职业裙、纯色棚景和无道具方案。旧规则同时要求“随机展示变量”和“统一背景/鞋款”，模型倾向取最安全的公约数。SOP 因此新增 BG01–BG08、PR00–PR08 兼容池，并固定依赖顺序。

## 权衡

- 备选一：全字段独立乱抽，模型产出不兼容的服装、姿势、背景组合。
- 备选二：统一模板，视觉单调且无法证明不同效果之间的差异。
- 代价：需要维护兼容池和筛选顺序，参数生成复杂度高于简单随机；失败时按依赖链逐级回退重抽。
