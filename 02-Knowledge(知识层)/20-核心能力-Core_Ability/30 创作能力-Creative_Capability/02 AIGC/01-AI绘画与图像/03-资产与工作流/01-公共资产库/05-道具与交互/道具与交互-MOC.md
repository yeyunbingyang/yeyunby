# 05-道具与交互

![[道具与交互-视觉索引-v01.jpg]]

> [!abstract] 当前可用范围
> 已将原有组合级道具拆分成 **4 类独立选择器、共 48 个道具变量**。每个道具记录中文名称、英文提示词、视觉作用和推荐位置。

## 四类选择器

### 办公场景

![[办公场景-道具选择器.png]]

适合：商务肖像、数字工作、设计师、行政、会议与通勤主题。

### 居家场景

![[居家场景-道具选择器.png]]

适合：生活方式、亲和人像、居家办公、轻叙事和软装氛围。

### 咖啡店场景

![[咖啡店场景-道具选择器.png]]

适合：社交、约会、远程工作、慢生活与城市日常。

### 街道场景

![[街道场景-道具选择器.png]]

适合：街拍、通勤、雨景、城市电影感和环境人像。

## 正确使用方式

道具选择遵循：

```text
1 个主道具
+ 2–4 个辅助道具
+ 0–2 个人物交互道具
+ 1 个空间结构道具
```

例如“咖啡店远程工作”：

```text
主道具：笔记本电脑
辅助道具：咖啡杯、菜单、小花束
交互道具：人物一手触控板，另一手持杯
空间结构：临窗座位或远景吧台
```

## 道具与场景氛围的区别

| 控制项 | 回答的问题 | 示例 |
|---|---|---|
| 道具 | 画面里放什么 | 沙发、杯子、电脑、路灯 |
| 空间 | 人在哪里 | 客厅、开放办公室、街角咖啡店 |
| 氛围 | 什么光线与情绪 | 暖窗光、冷调商务、雨夜霓虹 |
| 交互 | 人怎么使用道具 | 手持杯、翻菜单、倚靠桌面 |

不要把四类信息混成一句“高级氛围感场景”。模型可能生成漂亮背景，却无法稳定控制具体物件。

## 道具密度

| 密度 | 数量建议 | 适用 |
|---|---:|---|
| 极简 | 1 主 + 1 辅 | 商品目录、身份照、留白人像 |
| 标准 | 1 主 + 2–4 辅 | 生活方式、商业人像 |
| 丰富 | 1 主 + 5–7 辅 | 环境叙事、室内设计展示 |
| 高密 | 8 个以上 | 仅适合广角环境图；人物图容易变乱 |

## 通用提示词骨架

```text
场景位于【空间类型】，主道具为【主道具】，
辅助道具包括【道具 1、道具 2、道具 3】，
人物与【交互道具】进行【动作】，
【空间结构道具】位于【前景/中景/后景】，
道具数量克制、位置清晰、不遮挡人物脸部和关键服装区域，
整体采用【光线】和【情绪】。
```

英文结构：

```text
set in a [space], featuring [hero prop],
with [supporting props], the subject [interaction with prop],
[structural prop] placed in the [depth layer],
controlled prop density, clear object separation,
no clutter, no floating objects, no face obstruction.
```

## 常见冲突

- 办公桌、咖啡桌和边桌同时作为主道具，会造成桌面结构混乱。
- 多个强竖向道具同时贴近人物头部，如路灯、站牌、吊灯，会形成“头顶长杆”。
- 花瓶、绿植、杯子和甜点盘堆在同一区域，会互相融合。
- 玻璃隔断、橱窗和镜面同时出现，容易产生错误反射与重复人物。
- 道具在提示词中出现，但没有写位置，容易漂浮或挡脸。

## 验收清单

- [ ] 主道具一眼可识别。
- [ ] 辅助道具没有抢人物主体。
- [ ] 道具与人物接触关系自然，没有穿手、漂浮或尺寸异常。
- [ ] 道具不遮挡脸、手、服装重点和商品展示区域。
- [ ] 同类道具数量合理，没有无意复制。
- [ ] 反射面没有出现重复人物或错误空间。
- [ ] 道具风格、年代和材质与场景统一。

## 使用边界

- 独立道具选择器负责“放什么”，[[场景与氛围-MOC|场景与氛围]] 负责“在哪里、什么构图和光线”。
- 专项项目需要的商品、包装、品牌标识和专属家具仍应留在项目目录，不直接进入公共图库。
