# 构图与镜头

## 五个变量槽

| 槽位 | 常用值 |
|---|---|
| 景别 | 特写、近景、中景、全身、远景 |
| 机位高度 | 低机位、腰平、胸平、眼平、高机位 |
| 视角 | 正面、侧面、3/4、俯拍、仰拍、顶视 |
| 主体位置 | 居中、三分线、偏左、偏右、前后层次 |
| 镜头意图 | 目录展示、生活方式、时装编辑、电商社媒、电影叙事 |

## 推荐写法

```text
[景别] + [机位高度] + [视角] + [主体位置] + [镜头意图]
```
