## 读图方法

每张图卡统一按以下顺序阅读：

```text
1. 人数：确认画面需要几个人
2. 主角位置：先固定唯一视觉焦点
3. 朝向：人物看向镜头、彼此或画外
4. 间距：用肩宽、手臂长度、身位描述
5. 深度：决定谁在前景、中景、后景
6. 镜头：最后选择平视、俯拍、低机位与焦段
```

> [!tip] 稳定原则
> 多人物生成最容易失败的原因不是“提示词不够长”，而是同时缺少主角、站位、遮挡和深度约束。先把四项写清楚，再补服装、场景和风格。

## 通用提示词骨架

```text
[人数与关系]，采用 [站位编号/站位名称]，
主角位于 [位置]，其他人物位于 [前后左右关系]，
人物朝向 [镜头/彼此/画外]，相邻间距约 [肩宽/手臂长度/身位]，
保持清晰前中后景，所有脸部可见，四肢不交叠，
使用 [镜头高度]、[景别]、[焦段倾向]，
整体情绪为 [情绪]。
```

英文结构：

```text
[number and relationship], using [formation],
lead character at [position], supporting characters [spatial relationship],
clear facing directions, controlled spacing, visible faces,
clean foreground-midground-background separation,
no merged bodies, no duplicated faces, no limb intersections,
[camera height], [shot size], [lens tendency].
```

## 负面约束

```text
人物身体融合，四肢交叉穿插，脸部遮挡，重复脸，重复肢体，
所有人物完全同高同姿势，人物比例远近反转，主角不明确，
队形贴边，群像被裁切，随机散点，没有前中后景层次
```

## 验收清单

- [ ] 主角能在 1 秒内被识别。
- [ ] 所有人脸均可见，且没有头部重叠。
- [ ] 人物之间不存在身体融合、穿插或多余肢体。
- [ ] 前后人物的尺寸符合透视关系。
- [ ] 间距与情绪一致：亲密可近，正式与冲突应适当拉开。
- [ ] 镜头没有把边缘人物或脚部意外裁掉。
- [ ] 多人物身份没有互相污染或变成同一张脸。

## 使用边界

- 本库解决“人放在哪里”，不解决具体人物身份和服装。
- 具体脸型、发型、服装和一致性控制应进入 [[角色资产库-MOC]]。
- 复杂群像建议先生成无身份的站位底图，再分阶段注入人物身份；不要一次性要求大量固定脸。
