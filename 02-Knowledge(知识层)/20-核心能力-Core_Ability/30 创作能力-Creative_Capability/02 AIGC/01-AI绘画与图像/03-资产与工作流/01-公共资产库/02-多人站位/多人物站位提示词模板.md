# 多人物站位提示词模板

## 模板 A｜文生图

```text
画面包含【人数】名人物，他们的关系是【关系】。
采用【站位编号 + 名称】，主角位于【位置】，配角位于【空间关系】。
主角朝向【方向】，配角朝向【方向】，人物间距为【距离单位】。
保持【前景/中景/后景】层次，确保所有人物面部清晰可见。
镜头为【机位】、【景别】、【焦段】，画面情绪为【情绪】。
避免人物身体融合、四肢交叉、脸部遮挡、重复脸和透视比例错误。
```

## 模板 B｜图生图，只改站位

```text
编辑原图，只调整多人物站位与空间关系。
保持每个人物身份、脸型、五官、发型、服装、表情、场景、美术风格和光线不变。
将站位调整为【站位编号 + 名称】：【主角位置】，其他人物【空间关系】；
人物朝向【方向】，间距【距离】，保持清晰前中后景和无遮挡脸部。
不得新增或删除人物，不得交换人物身份，不得改变身体比例。
```

## 模板 C｜多人身份一致性

```text
人物 A 使用【身份参考 A】，固定在【位置 A】；
人物 B 使用【身份参考 B】，固定在【位置 B】；
人物 C 使用【身份参考 C】，固定在【位置 C】。
禁止身份互换、五官融合、发型互换和服装串色。
先满足人物身份与站位，再满足场景和艺术风格。
```

## 权重顺序

```text
人数与身份
→ 主角位置
→ 站位与遮挡
→ 朝向与视线
→ 间距与深度
→ 镜头
→ 动作
→ 场景道具
→ 风格与质感
```

把风格词放在站位之前，容易出现“画面很漂亮但人物乱站”；把大量动作词同时施加给所有人物，容易出现肢体融合。
