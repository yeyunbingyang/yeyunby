# 四格漫画提示词模板


## 多图一致性提示

> [!tip] 先做锚点图
> 系列图不要每张从零开始。先固定身份、结构、配色、版式或场景基调；出现新服装、新道具或新场景时，先为新元素建立代表图，再批量生成后续画面。

![](../示意图/多图一致性流程图_先立锚点后生成.png)

> [!abstract] 定位
> 四格漫画同时包含**连续角色、四个叙事时刻和 2×2 版式**。一次生成可能出现格数错误、换人、重复画面和乱码。高可靠流程是：先写四格脚本 → 生成无字画面 → 必要时逐格修复或独立生成 → 后期加入气泡与文字。

## 一、适用类型

| 类型 | 四格结构 | 适合用途 |
|---|---|---|
| 起承转合 | 引入 → 发展 → 转折 → 结局 | 故事漫画、科普漫画 |
| 同场景序列 | 时间或动作连续推进 | 情绪变化、产品使用流程 |
| 效果对比 | 同一主体的四种变量 | 风格、服装、材质、灯光对比 |
| 教程步骤 | 步骤 1–4 | 操作说明；准确文字后期排版 |

## 二、输入准备

- 固定角色卡：脸型、发型、服装、配色、身体比例；
- 四格脚本：每格只写一个动作和一个叙事功能；
- 场景连续性：时间、天气、道具状态和人物进出方向；
- 对白策略：无字版、只留气泡，或允许草稿级短文字；
- 版式：2×2、格间距、阅读顺序和最终比例。

## 三、五槽位四格母版


> [!image-plan]- 教学图规划｜四格漫画连续性检查
> - **图型**：四格标注图
> - **学习目标**：理解人物身份、场景轴线、时间推进和文字区域的一致性。
> - **画面结构**：四格漫画示例，格间用箭头连接；人物脸、服装、道具各用同色圈注。
> - **圈注重点**：标出每格只推进一个剧情节点，镜头变化不能破坏身份。
> - **建议文件名**：`四格漫画_连续性检查图.png`
> - **建议位置**：本子标题的概念说明之后、详细表格或模板之前。
> - **状态**：待生成；生成后存入当前目录的 `示意图/`，再替换本规划块或在其下方嵌入图片。

```text
【任务与变化范围】
任务类型：{起承转合 / 场景序列 / 效果对比 / 教程步骤}
目标：{四格主题}
每格只改变：{动作、表情、时间或指定变量}

【保留项与参考职责】
跨格保持：{角色身份、服装、场景、画风、光线或商品本体}
参考 R1：负责{角色/商品}
参考 R2：只负责{画风/场景，可选}

【目标画面设计】
格 1：{地点、人物位置、动作、表情、景别、叙事功能}
格 2：{同上}
格 3：{同上}
格 4：{同上}
统一风格：{线条、上色、色彩、光影}

【控制规则】
连续性优先：主体一致 > 格数和阅读顺序 > 动作因果 > 画风 > 装饰
避免：跨格换人、重复画面、格子重叠、角色跨出格线、随机文字

【输出规格】
版式：2×2 四格，阅读顺序从左到右、从上到下
画幅：{1:1 / 4:5}
文字：{无字 / 只留气泡 / 后期排版}
```

## 四、可直接复制模板

### 4.1 起承转合无字四格

```text
生成一张 2×2 四格漫画，阅读顺序从左到右、从上到下，不添加任何文字。

固定角色：同一{人物描述}；四格保持同一脸型、发型、服装、身体比例和画风。
固定场景：{地点、时间、天气}。

格 1（起）：{建立人物、地点和事件}；{景别和机位}。
格 2（承）：{人物采取行动，承接上一格}；{景别和机位}。
格 3（转）：{出现意外或信息反转}；{景别和机位}。
格 4（合）：{结果或笑点}；{景别和机位}。

风格：{漫画画法、线条、上色、色彩}。
版式：2×2 等距四格，格间留白，每格独立构图，角色不跨出格线。
避免五格或三格、重复画面、跨格换人、随机文字和错误气泡。
```

### 4.2 同主体四种效果对比

```text
生成一张 2×2 四格效果对比图。

所有格固定：同一{人物/商品}、同一姿势、同一镜头、同一构图、同一背景和同一主体尺度。
唯一变量：{艺术风格 / 光线 / 材质 / 服装}。
左上：{版本 A}
右上：{版本 B}
左下：{版本 C}
右下：{版本 D}

每格只应用对应变量，不互相混合；不添加标签文字，后期统一标注。
```

## 五、验收清单

- 是否正好四格，顺序清楚且格子不重叠；
- 同一角色或商品是否跨格保持；
- 每格动作是否与上一格存在因果；
- 道具状态、时间和人物进出方向是否连续；
- 对比图是否只改变预设变量；
- 是否需要拆成四张独立图片后重新排版。

## 六、问题诊断

| 现象 | 原因 | 修复 |
|---|---|---|
| 格数错误 | 版式要求与剧情混在一起 | 强化 2×2 和阅读顺序，或逐格生成后排版 |
| 跨格换人 | 角色固定信息不足或变化过多 | 使用统一主参考，减少服装和场景变化 |
| 剧情跳跃 | 每格只有画面描述，没有因果 | 写“上一格结果 → 下一格动作” |
| 对白乱码 | 同时要求复杂图像与准确文字 | 生成无字版，后期添加气泡和文字 |
| 对比变量混合 | 四版差异边界不清 | 固定共同项，每格只写一个变量 |
