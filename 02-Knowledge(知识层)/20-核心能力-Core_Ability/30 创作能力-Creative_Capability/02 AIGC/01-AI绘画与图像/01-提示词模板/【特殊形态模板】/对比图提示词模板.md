# 对比图提示词模板

> [!abstract] 定位
> 对比图的核心不是“一张图里放很多漂亮版本”，而是建立**共同基准 + 唯一变量**。只有其他条件尽量一致，才能判断风格、材质、光线或提示词修改真正带来的差异。

## 一、适用类型

- 半写实动漫细分风格对比；
- 同一人物服装、发型或妆容对比；
- 商品材质、背景或布光对比；
- 场景时间、天气和色调对比；
- 提示词 A/B 测试结果展示。

## 二、输入准备

1. 明确唯一测试维度；
2. 写共同基准：主体、姿势、表情、镜头、构图、背景、光线或材质；
3. 每个版本用同一颗粒度描述，避免 A 写得很细、B 只写一个词；
4. 决定独立输出还是拼版；实验分析优先独立输出，展示汇报可后期拼版。

## 三、五槽位对比母版


> [!image-plan]- 教学图规划｜公平对比的单变量原则
> - **图型**：错误正确对照图
> - **学习目标**：展示对比图为什么必须固定主体、构图、光线和输出。
> - **画面结构**：左侧错误对比同时换主体/机位，右侧正确对比只换风格或材质。
> - **圈注重点**：圈出被偷偷改变的变量，并给出固定清单。
> - **建议文件名**：`对比图_单变量原则.png`
> - **建议位置**：本子标题的概念说明之后、详细表格或模板之前。
> - **状态**：待生成；生成后存入当前目录的 `示意图/`，再替换本规划块或在其下方嵌入图片。

```text
【任务与变化范围】
任务：生成{N}个对比版本
唯一变量：{风格 / 服装 / 光线 / 材质 / 场景时间}

【保留项与参考职责】
所有版本固定：{主体身份、姿势、表情、服装/商品、镜头、构图、背景、主体尺度}
参考 R1：负责共同主体

【目标画面设计】
版本 A：{变量值和可观察特征}
版本 B：{变量值和可观察特征}
版本 C：{变量值和可观察特征}
……
共同质感：{不参与测试的画面特征}

【控制规则】
除唯一变量外，不改变其他维度。
版本之间不得混合特征；不要自动增加标签文字。

【输出规格】
方式：{每版独立输出 / 2×2 / 横向 N 格}
画幅：{比例}
标签：后期统一添加
```

## 四、半写实动漫五风格对比示例

```text
生成同一人物的五个半写实动漫风格版本。

所有版本固定：人物身份、脸型五官、年龄感、发型、姿势、表情、服装、背景、镜头、构图和光线方向。
唯一变量：半写实动漫的风格化程度和视觉语言。

A 轻度半写实动漫：接近真人比例，轻微动漫化眼型，自然皮肤和发丝，摄影光影。
B 标准半写实动漫：真实比例与动漫五官平衡，眼睛细节增强，面部体积清楚，精致数字插画。
C 美型增强半写实动漫：脸部轮廓更精致，眼睛和睫毛适度增强，保持身份辨识，不幼化。
D 日系清透半写实动漫：清透上色，柔和高明度色彩，轻薄线条，明亮自然光。
E 游戏角色型半写实动漫：高精度角色渲染，清晰材质，电影级轮廓光，真实体积与细节。

每个版本独立输出，不混合风格，不添加文字标签。
```

## 五、验收与记录

| 检查项 | 判断 |
|---|---|
| 共同主体 | 身份、姿势、构图是否基本一致 |
| 唯一变量 | 是否只有测试维度发生变化 |
| 描述公平 | 各版本提示词颗粒度是否接近 |
| 可比性 | 光线、画幅、主体尺度是否一致 |
| 结论 | 哪个版本最符合目标，为什么 |

将正式实验记录写入 [[提示词A-B测试日志]]，不要仅凭一次随机结果下结论。

## 六、问题诊断

| 现象 | 修复 |
|---|---|
| 各版人物不同 | 使用同一主参考，减少风格强度，独立生成 |
| 构图和姿势变化 | 将镜头、构图和姿势写入共同固定项 |
| 风格差异不明显 | 把风格拆成造型、线条、上色、材质和光影 |
| 版本特征混合 | 每次只生成一个版本或明确独立分区 |
| 拼版格数错误 | 独立输出后在设计软件排版 |
