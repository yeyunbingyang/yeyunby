# GPT 图像生成执行模板

> [!important] 使用方式
> 这是 **GPT 平台执行模板**——从母版 [[提示词模板设计方法]] 派生，已落为 GPT 可直接粘贴的提示词。**复制下方任一完整提示词 → 替换方括号内容 → 粘贴到 GPT 即可**。

## 一、GPT 语法要点（执行前必读）

- **完整句子**：GPT 更吃结构化自然语言，不用关键词堆叠。
- **文字渲染**：精确文字放引号内 + 加"反文字负面词"（无文字/无乱码）。
- **迭代限制**：同一提示词迭代 ≤3 次，否则退化；第 4 次起应简化或换参考。
- **无显式权重**：GPT 不认 `100%`/`70%` 权重语法——用**语序 + 重复强调 + 职责声明**表达优先级（最重要放最前，多用"唯一/必须/不得"）。
- **负面词**：写进正文尾部即可（GPT 无独立负面框）。

## 二、文生图（从零生成）可直接粘贴

> 场景：无参考图，一次生成。替换 `{...}` 后复制。

```text
请生成一张 {人物创作/商品视觉/氛围创意} 图片。

主体（必须保持）：{主体描述，如：一位圆脸杏眼的年轻女性，肤色偏白}
本轮核心：{唯一变化点，如：米色针织毛衣，半高领}（其他元素次要）

构图与镜头：{景别/机位/构图，如：正面半身像，人物居中，浅景深}
光线与质感：{光影 + 正向质感，如：暖调咖啡店灯光，皮肤有自然纹理，布料褶皱真实}

禁止：{结构负面：多指、肢体扭曲}、{身份负面：换脸}、{渲染负面：模糊、塑料感}、{版式负面：裁头}、无文字、无水印

输出：单张，{画幅如 3:4}，竖构图。
```

## 三、图生图（有参考图）可直接粘贴

> 场景：上传参考图，锁定主体做编辑。

### 3.1 换装编辑（★ 固定人脸换衣物）

```text
以上传参考图的{脸部}为唯一身份依据，最高保留优先级：
不得重新设计：脸型、五官、头部角度、发型轮廓。
允许在衣领与身体交界处做最小自然适配。

本轮只修改：服装与配饰——
上衣：黑色西装外套，白色衬衫，正式商务风
配饰：金色细项链
除此之外的画面保持参考图原样，不得改动。

保持：原图的光线方向、背景、整体色调。

禁止：换人、换脸、改年龄、改眼型；多指、肢体扭曲；模糊、塑料肤感；无文字。

输出：与参考图同比例的单张图片。
```

### 3.2 换景编辑（商品换场景）

```text
以上传参考图的{商品本体}为唯一依据，最高保留优先级：
不得重新设计：商品外观、配色、品牌元素、材质。

本轮只修改：使用场景——
场景：清晨办公桌，木色桌面 + 笔记本电脑 + 咖啡，暖调晨光。

保持：商品的形状、比例、LOGO 完全一致。

禁止：商品变形、多余标签、错字；商品漂移、LOGO 变形；模糊、过硬阴影；无文字。

输出：单张，{画幅如 3:4}，商品居中，留白供文案。
```

### 3.3 扩图（向外延伸）

```text
整张参考图为最高保留优先级，内容、风格、光线一律不得重新设计。
仅向{左侧}扩展画面：{扩展内容，如：延伸的木质桌面 + 窗外街景}。

扩展区域必须与原图无缝衔接：风格、光线、色调、纹理完全一致，无接缝、无断层。
原图内的主体、构图保持原样。

禁止：改变原图主体、色调偏移、接缝可见、边缘断裂；无文字。

输出：新画幅 {如从 3:4 扩到 16:9}，扩展部分自然融入。
```

## 四、组合建议

- **人物创作 + 换装**：用 §3.1（锁定脸 + 换衣物）。
- **商品视觉 + 换景**：用 §3.2（锁定商品 + 换场景）。
- **从零到成品**：用 §二，再按需迭代。
- **想按任务直接找模板**：先看 [[生图任务模板库]]（A-H 任务分类入口）。
- **失败排查**：生成不对 → 看母版 §4.2"问题→槽位"表，定位调整后重试（≤3 轮）。
- **平台切换**：需要即梦 → 用 [[即梦图像生成执行模板]]。
