# AI生图场景分类

> [!abstract] 用途
> 从需求出发的场景导航：先确定"我要做什么"（场景）→ "怎么做"（操作）→ "多难"（控制难度）→ 再选对应模板。它是模板的**入口层**，槽位协议是**执行层**。

> [!important] 核心原则
> **场景类型决定固定对象，操作方式决定可变项，控制等级决定约束数量，输出形式决定规格。** 四个维度正交，独立决定提示词怎么写。

## 一、一级分类：按生成目标分 7 类场景

### 01 人物视觉
核心对象是"人"。子场景：从零创作 / 身份保持 / 风格转换 / 换装与局部编辑 / 姿势与表情 / 角色资产生产。
- 固定项：性别、年龄段、脸部结构、身份辨识度。
- 常见任务：[[人物创作提示词模板]]、换装（见母版 §3.7）、三视图（见视图模板）。

### 02 商品与商业视觉
核心对象是商品/包装/品牌，重点是信息准确。子场景：商品白底图 / 商品场景图 / 卖点图 / 商业海报 / 包装与品牌 / 商品批量变体。
- 固定项：商品本体、品牌元素、材质、配色。
- 常见任务：[[商品视觉提示词模板]]、丝袜效果图（见 03 资产层）。
- 注意：AI 对准确文字/Logo 能力有限，文案后期排版。

### 03 场景与概念设计
核心对象是空间/世界/情绪。子场景：自然场景 / 城市建筑 / 室内空间 / 影视氛围 / 世界观设计。
- 固定项：场景基调、情绪、世界规则。
- 常见任务：[[氛围创意提示词模板]]。

### 04 插画与艺术创作
强调艺术表达（区别于氛围的"场景情绪"）。子场景：角色插画 / 叙事插画 / 小说封面 / 漫画分镜 / 艺术风格实验。
- 固定项：主题、视觉风格、色彩体系。
- 关联：[[四格漫画提示词模板]]、[[角色设定图提示词模板]]。

### 05 平面与品牌设计
目标是可用的设计视觉。子场景：海报 / 封面 / 社交媒体视觉 / UI 插图 / 信息视觉。
- 关注：信息层级、留白、文字区域、品牌色、输出尺寸。
- 建议：AI 生成视觉主体 + 设计工具完成准确文字与排版。

### 06 建筑与空间设计
有较强空间结构要求，不宜归入氛围。子场景：建筑概念 / 室内效果 / 商业空间 / 展陈舞台 / 景观设计。
- 区分：**概念视觉**（允许艺术化）vs **施工参考**（要求尺寸/结构准确，普通生图模型不适合直接当施工图）。

### 07 素材与制作辅助
目标是后续制作的素材。子场景：背景素材 / 透明主体 / 纹理材质 / 特效元素 / 视频首帧 / 后期合成素材。
- 输出规格很重要：纯色/透明背景、主体居中、边缘清晰、方便抠图。

## 二、二级分类：按操作方式分 7 种

操作方式决定**可变项**怎么填：

| 操作 | 固定什么 | 变什么 | 关联模板 |
|---|---|---|---|
| **文生图** | 文字锚点 | 全部 | 母版变体 A |
| **图生图** | 参考图职责 | 换变量 | 母版变体 B |
| **局部重绘** | 非编辑区保持 | 编辑区 | 母版 §3.7① |
| **扩图** | 整张原图 | 扩展区 | 母版 §3.7② |
| **主体替换** | 姿势/场景/构图 | 主体身份 | 母版 §3.7（身份替换） |
| **风格转换** | 身份/构图 | 艺术风格 | 母版变体 B |
| **批量变体** | 所有版本一致项 | 每格变量 | 母版变体 C |

## 三、三级分类：按控制难度分 L1-L5

控制等级决定**约束数量**：

| 难度 | 含义 | 示例 | 需要的控制 |
|---|---|---|---|
| **L1 自由创意** | 结果有氛围即可 | 未来城市、梦幻森林 | 提示词可偏描述性 |
| **L2 单主体控制** | 一个主要对象稳定 | 一个人物/商品/建筑 | 主体结构与清晰度 |
| **L3 参考一致性** | 与参考图明显一致 | 同人换装、同商品换景 | 身份/本体保持 |
| **L4 多参考融合** | 多参考各管一块 | 人脸+姿势+服装+风格 | 参考职责表（母版 §3.6） |
| **L5 复杂编辑/连续资产** | 多角度一致、连续角色 | 三视图一致、多镜头首帧 | 需蒙版/姿势控制/LoRA/固定种子/专用工作流 |

> 仅靠提示词通常止步于 L4；L5 需要额外控制手段（蒙版、ControlNet、LoRA、固定种子、多轮合成）。

## 四、如何用这套分类选模板

```text
用户需求 → ① 确定场景（7 类之一）
        → ② 确定操作（7 种之一）
        → ③ 评估难度（L1-L5）
        → ④ 选模板：母版槽位协议 + 平台执行模板（GPT/即梦）
        → ⑤ 填充：场景决定固定对象，操作决定可变项，难度决定约束，输出决定规格
```
