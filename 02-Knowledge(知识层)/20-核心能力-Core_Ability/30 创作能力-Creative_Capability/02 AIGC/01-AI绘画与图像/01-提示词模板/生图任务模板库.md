# 生图任务模板库

> [!abstract] 本文档定位
> 本文档**只提供可直接复制使用的提示词模板**。找到对应任务 → 替换 `{空位}` → 直接提交给图像模型。**七槽位、双轴、优先级和诊断方法不在本文档展开**（维护者才需要，见 [[提示词模板设计方法]]）。

> [!important] 使用方式
> 1. 在 §一 找到你的任务；
> 2. 复制对应模板（A-H）到生成平台；
> 3. 替换 `{空位}`，删除不需要的段落；
> 4. 生成后看效果，出问题查 [[提示词模板设计方法]] §四"问题→槽位"表调整。

## 二、任务模板（A-H）

### 模板 A：通用文生图

适用于没有参考图、从零生成图片。

```text
生成一张用于{使用用途}的图片。

主体：
{人物、商品、动物、建筑或主要画面对象}

动作与状态：
{姿势、动作、表情、运动状态或静止状态}

环境与背景：
{地点、时间、天气、背景元素、空间氛围}

艺术风格：
{真实摄影、半写实动漫、电影级数字人、插画、油画、商业视觉等}

光线与色彩：
{光源方向、光线软硬、时间氛围、主色调、明暗关系}

镜头与构图：
{景别}，{平视/俯拍/仰拍}，{正面/侧面/背面}，
{居中构图/三分法/引导线构图}，{焦距或景深要求}

材质与细节：
{皮肤、发丝、服装、金属、玻璃、布料、环境纹理等}

输出要求：
生成{数量}张，画幅比例为{比例}，
画面用于{头像、海报、封面、电商主图、概念设计等}。

避免：
{只填写当前任务中确实需要避免的问题}
```

**极简写法**：

```text
{主体}，{动作}，位于{场景}，
{艺术风格}，{光线与色彩}，
{景别和构图}，{关键材质细节}，
画幅{比例}。
```

> **平台差异**：GPT 用完整句子、负面词写正文尾部；即梦用模块化公式、负面词填独立输入框（详见 [[GPT 图像生成执行模板]] / [[即梦图像生成执行模板]]）。
> **负面词库**：[[负面提示词通用库]]（基础包 + 对象包 + 风格包）。

### 模板 B：人物身份保持

适用于以人物照片作为参考，改变服装、姿势、场景或风格，同时保持人物身份。

```text
以参考图 R1 作为人物身份参考。

必须保持：
人物身份、脸型、五官结构、眼型、鼻型、嘴型、
下颌线、肤色、发际线和整体辨识度。
不得主动重新设计人物面部。

本轮改变：
{服装 / 姿势 / 表情 / 场景 / 光线 / 艺术风格}

具体要求：
{详细描述本轮需要改变的内容}

允许的最小适配：
允许根据新的姿势、服装和光线，
对发丝边缘、衣物交界、遮挡关系和局部阴影进行自然调整，
但不得因此改变人物身份。

镜头与构图：
{沿用参考图 / 指定新的景别、角度和构图}

画面质感：
{真实皮肤纹理、自然发丝、半写实动漫质感、电影光影等}

输出要求：
生成{数量}张，画幅比例为{比例}。

避免：
换人、换脸、年龄明显变化、脸型变化、五官比例变化、
身份辨识度下降。
```

> **人物专属细节**：[[人物创作提示词模板]] §二（身份固定项/参考图职责/镜头角度）。

### 模板 C：人物换装

适用于只更换人物衣物或配饰。

```text
编辑参考图，仅修改人物的衣物和指定配饰。

保持不变：
人物身份、脸部、五官、发型、发色、表情、身体姿势、
手部位置、头部角度、摄影机位、构图、背景和整体光线。

将原有服装更换为：
{服装名称}

服装设计：
- 款式：{款式}
- 颜色：{颜色}
- 面料：{面料}
- 版型：{宽松、修身、收腰等}
- 长度：{长度}
- 配饰：{配饰，没有则填写无}

服装必须自然贴合人物身体和当前姿势。
衣领、袖口、腰部、裙摆和遮挡边缘应完整连贯。
布料褶皱、受力方向和阴影应符合人物动作。

允许调整：
仅允许调整衣物与身体、头发和背景交界处的局部边缘与阴影。

不得修改：
人物身份、脸型、五官、年龄、身材比例、姿势、背景和镜头。

输出：
保持参考图原始画幅和构图，生成一张完整单图。
```

> **已有可复制版本**：[[GPT 图像生成执行模板]] §3.1（完整句子）/ [[即梦图像生成执行模板]] §3.1（模块化公式）。
> **负面重点**：换衣最易连带换脸——身份负面重点防（换人/换脸/改年龄/改眼型）。

### 模板 D：局部编辑与修复

适用于修复服装、手部、背景、物体缺失、结构断裂等局部问题。

```text
编辑参考图，仅修复以下区域：

编辑区域：
{明确描述需要修改的位置和对象}

修复目标：
{说明正确状态应当是什么样}

必须保持：
除编辑区域外，其余画面内容保持不变，
包括人物身份、脸部、发型、表情、身体姿势、
摄影角度、背景、构图、色调和光线氛围。

修复要求：
- 补全缺失或断裂结构
- 保持正确的透视关系
- 保持合理的遮挡关系
- 保持原图材质和纹理
- 保持原图光线方向和阴影
- 编辑区域与周围画面自然衔接
- 不留下明显接缝或重绘痕迹

允许调整：
仅允许在编辑区域边缘进行必要的最小过渡。

不得修改：
{列出本次绝对不需要改变的内容}

输出：
保持原图画幅、构图和清晰度，生成一张完整图片。
```

> **方法**：固定项 = "最高保留优先级"而非"绝对冻结"，编辑区边缘允许最小适配（见 [[提示词模板设计方法]] §3.7）。

### 模板 E：扩图

适用于向左、右、上、下扩展图片，或改变画幅比例。

```text
对参考图进行扩图。

原图保留要求：
完整保留原图中的人物、物体、背景、构图中心、
艺术风格、色调、光线方向和材质纹理。
不得重新设计原图内部内容。

扩展方向：
{向左 / 向右 / 向上 / 向下 / 四周}

目标画幅：
从{原比例}扩展为{目标比例}。

扩展区域内容：
{描述新增区域应该出现的背景、环境或物体}

衔接要求：
新增区域必须自然延续原图的空间结构、透视关系、
光线方向、景深、色彩、材质和环境氛围。
原图边缘与扩展区域之间不得出现接缝、断层、
重复纹理或明显风格差异。

人物补全要求：
{没有人物补全则删除本段}
根据原有人体结构自然补全{腿部、脚部、手臂或服装}，
保持合理的人体比例、姿势受力和遮挡关系。

输出：
生成一张完整单图，画幅比例为{目标比例}。
```

> **已有可复制版本**：[[GPT 图像生成执行模板]] §3.3 / [[即梦图像生成执行模板]] §3.3。

### 模板 F：风格转换

适用于保持人物身份、姿势和构图，只改变艺术风格。

```text
将参考图转换为{目标艺术风格}。

必须保持：
人物身份、脸型、五官结构、人物辨识度、发型结构、
表情、身体姿势、服装轮廓、摄影角度和整体构图。

只改变：
艺术表现形式、绘制方式、材质表现、光影渲染和画面质感。

目标风格特征：
{详细描述目标风格}

人物处理：
保持真实合理的人体比例。
五官可以根据目标风格进行适度艺术化，
但不得改变人物身份和核心面部结构。

光线与质感：
{电影级光影、细腻皮肤、真实发丝、清透色彩、CG渲染等}

风格化程度：
{轻度 / 标准 / 明显}

避免：
换脸、改变年龄、改变脸型、过度放大眼睛、
完全真人化、完全卡通化、身份辨识度下降。

输出：
保持参考图画幅和构图，生成一张完整图片。
```

> **风格可选值**：[[艺术风格词典]]。
> **风格包负面词**：[[负面提示词通用库]] §三（写实排除动漫 / 动漫排除写实 / 半写实注意）。

### 模板 G：商品换景

适用于保持商品外观，只改变背景、场景、道具或光线。

```text
以参考图 R1 作为商品本体参考。

必须保持：
商品外形、尺寸比例、结构、颜色、材质、
表面纹理、品牌标识、文字和包装细节。
不得重新设计商品。

本轮改变：
商品所处的背景、使用场景、辅助道具和环境光线。

目标场景：
{场景描述}

辅助道具：
{道具描述，没有则填写无}

构图：
商品位于{画面位置}，
使用{特写、近景、中景}，
采用{平视、微俯拍、微仰拍}，
为{文案、价格或品牌信息}保留适当空间。

光线：
{商业棚拍光、自然窗光、暖色晨光、冷色科技光等}

材质表现：
商品表面应呈现{金属、玻璃、塑料、织物等}的真实质感，
高光、反射和阴影符合材质属性。

避免：
商品变形、颜色变化、品牌标识错误、文字错误、
多余标签、商品被遮挡、材质塑料化。

输出：
生成{数量}张，画幅比例为{比例}，
用于{电商主图、详情页、海报、社交媒体等}。
```

> **已有可复制版本**：[[GPT 图像生成执行模板]] §3.2 / [[即梦图像生成执行模板]] §3.2 / [[商品视觉提示词模板]] §3.1。
> **商品专属细节**：[[商品视觉提示词模板]] §二（固定项/限制项/优先级）。

### 模板 H：多参考融合

适用于分别使用人脸、姿势、服装、场景或风格参考图。

```text
使用以下参考图共同生成画面。

参考图职责：
- R1：只负责人脸和人物身份，最高保留优先级
- R2：只负责身体姿势和动作结构
- R3：只负责服装款式和材质
- R4：只负责场景、构图或光线
- R5：只负责艺术风格

冲突处理：
人物身份以 R1 为准。
姿势不得改变 R1 的人物身份。
服装不得覆盖或改变人物面部。
场景和风格不得改变人物核心结构。
任何低优先级参考图都不得覆盖高优先级参考图的职责。

目标画面：
{完整描述最终希望得到的画面}

人物：
保持 R1 的脸型、五官结构、肤色和人物辨识度。

姿势：
采用 R2 的{具体姿势}。

服装：
采用 R3 的{具体服装特征}。

场景与光线：
采用 R4 的{场景、构图和光线特征}。

艺术风格：
采用 R5 的{风格特征}。

输出：
生成{数量}张，画幅比例为{比例}。

避免：
参考职责混淆、身份漂移、姿势覆盖人脸、
服装改变身体比例、风格导致人物换脸。
```

> **方法**：参考图职责表 + 最小充分参考集（见 [[提示词模板设计方法]] §3.6 变体 B）。
> **失败处理**：参考职责混淆 → 减参考图数量（先 R1 后逐个加）。

## 三、使用原则

1. **先选任务模板，不要从母版开始填写**——本文档就是入口。
2. 模板中不需要的段落可以直接删除。
3. 没有发生的问题，不提前堆积负面词。
4. 一次生成包含多个变化时，先保证人物或商品主体稳定。
5. 连续编辑导致主体漂移时，返回原始参考图重新执行，不在漂移图片上持续修补。
6. 多参考任务首轮使用最少数量的参考图，确认冲突来源后再增加参考。
