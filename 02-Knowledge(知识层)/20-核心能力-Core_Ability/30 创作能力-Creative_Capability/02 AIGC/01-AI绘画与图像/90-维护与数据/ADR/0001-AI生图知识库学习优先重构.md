# AI生图知识库学习优先重构

> [!warning] 当前有效性
> 本文保留原决策结构，用于说明知识库为何这样设计。`03-资产与工作流层` 是目标规划，当前压缩包未包含；平台行为与提示词写法以 `01-提示词模板/【平台执行模板】` 的现行内容为准。
>
> **后续演进**：当前执行层已收敛为五槽位，七槽位仅保留为问题诊断维度；用途模板已补齐七类场景。本文后续出现的旧槽位或三类用途名称按历史语境理解。

## 决策

AI 绘画与图像领域从"可参考的知识库"重构为"**可学习 + 可参考**"的知识库，主目标是**学会 AI 生图提示词及相关操作**，知识库是支撑学习的手段。

## 目标结构

```text
01-AI绘画与图像/  （领域根）
├── AI绘画与图像-MOC.md          ← 总入口
├── 01-提示词模板/               ← 最顶层：使用的提示词 + 方法论总结
├── 02-专业名词速查/             ← 九大维度词典
├── 03-资产与工作流层/           ← 目标规划；当前压缩包未包含
├── 04-实验与迭代层/             ← 学习路径菜单 / A-B测试 / 风格研究 / 归档
├── 90-维护与数据/               ← ADR / CONTEXT / PRD / 目录重构规划
└── 提示词/                     ← 原两篇，迁移并入 01
```

## 关键决策点

### 1. 撤销独立"平台规则层"
平台差异不单独成层，**下沉为模板内嵌注释**（`GPT: …` / `即梦: …`）。通用模板（人物创作/氛围创意）内嵌注释；结构差异大的模板（商品视觉/故事板）提供**平台双版本**。

### 2. 模板层 = 母版 + 平台执行模板 + 用途/特殊形态模板
- **方法论母版**（[[提示词模板#二、提示词模板设计方法|提示词模板设计方法]]）：五主槽（固定项/可变项/优先级/限制项/输出规格）+ **镜头与构图槽** + **渲染与质感（可选正向槽）**，验收移出正文。**不直接执行**，是协议。
- **平台执行模板**：从母版派生，落为平台可直接粘贴的提示词（GPT / 即梦）。日常使用者直接用执行模板。
- **用途模板**（按生成内容）：人物创作 / 商品视觉 / 氛围创意，按**方案 B** 划分。
- **特殊形态模板**（按输出版式）：视图 / 角色设定图 / 四格漫画 / 故事板。
- 均建立在母版协议之上；每个模板配 **1-2 个填好的完整示例**。

### 3. 专业名词速查 = 九大维度
画幅与分辨率 / 景别（新增）/ 镜头与焦距 / 构图法则 / 人物九大角度（取景×机位，新增）/ 光影与布光 / 景深与焦点 / 艺术风格（拆分）/ 材质与质感（拆分）。种子集 40 词起步，随用随建，标难度阶梯。

### 4. 素材图库 = "媒体跟随项目"的显式例外
`03/素材图库`（人物姿势 / 多主体站位 / 场景氛围 / 道具）服务多用途**可变项槽**填充，是 **"媒体跟项目"铁律的显式例外**。只收"跨用途可复用"图；项目专属媒体仍跟随项目。此例外记入本 ADR。

### 5. 学习闭环驱动，而非存储驱动
```text
理解概念 → 选模板（照抄示例）→ 生成 → 人工看图
   ↑                                        ↓
   └── 反哺（同类修复被重复验证有效后→补词条/素材） ← 查"问题→槽位"表调整
```

### 6. "问题→槽位调整"对照表 = 全库最高价值资产
用户最痛是"生成不对不知道怎么改"。对照表（问题→根因→调整动作→槽位）置于通用模板方法论第一部分，随实验增量扩充。

### 7. AI 可读结构
模板/词典用结构化 frontmatter（用途/参数槽/平台差异/验收标准），支持 AI 读取并辅助填槽、诊断、建议——使库成为"AI 学习教练工作台"。

### 8. 填空式槽位协议 + 内容要素融入（★ 简化与命名）
- 模板正文为**填空式骨架**：带 `{空位}` 的提示词，复制替换即可生成，无需理解协议术语。
- 槽位**重新命名**为填空友好并扩充：① 固定项（原锚点）② 可变项（原变量）③ 优先级 ④ 限制项（原约束）⑤ 镜头与构图 ⑥ 输出规格（原输出）⑦ 渲染与质感（可选）。原协议名仅作对照参照。
- **验收完全移出模板正文**（原第六槽），归方法论（人工看图→查对照表→调槽）。
- **内容要素融入各槽位**：主体→固定项；环境/风格→可变项；视角→镜头与构图；精度→渲染与质感（正向）+ 限制项（反向）；专业名词（九大维度）= 填空位可选值。废弃"七段式"概念。

### 9. 现有资产归位
- **AI人物身份参考资产库拆分**：方法/提示词提炼并入 `01-提示词模板`，资产保留为 `03/人物资产`。
- **丝袜商品效果图生成 → 重命名 `丝袜效果图`**，归入 `03`；提示词库/参数库提炼进商品视觉模板，SOP/生产资产留项目。

### 10. 外部审查采纳（★ 方法论层优秀，执行层改进）
模板定位为"**方法论母版 + 平台执行模板**"两层。具体修正：
- **单变量原则**：区分"诊断模式（一次一变量）/ 正式生成模式（变量组）"。
- **"换主体"改名**：→ 主体保留型局部编辑（换装/换景/身份替换三态）。
- **参考图权重改为参考职责与逻辑优先级**：明确每张参考图负责身份、服装、姿势或场景；不虚构平台并未提供的数值权重。
- **镜头与构图独立成槽**：视角改变画面内容，不固定塞输出。
- **渲染与质感正向槽**：精度不只靠负面词，更靠正向质感描述。
- **限制项按需填写**：每条限制都应对应实际高频失败问题，不设置通用的固定词数上限。
- **半写实动漫**：不排除 realistic，改为控制"适度写实"。
- **"冻结全部"改为"最高保留优先级 + 允许最小局部适配"**。

### 11. 三层场景分类（★ 场景=固定对象，操作=可变项，难度=约束）
新增 [[提示词模板#一、AI 生图场景分类|AI 生图场景分类]] 导航作为需求入口，三层正交维度：
- **一级·7 类场景**（按生成目标）：人物 / 商品与商业 / 场景与概念 / 插画与艺术 / 平面与品牌 / 建筑与空间 / 素材与制作辅助。
- **二级·7 种操作**（决定可变项）：文生图 / 图生图 / 局部重绘 / 扩图 / 主体替换 / 风格转换 / 批量变体。
- **三级·L1-L5 难度**（决定控制强度与验收成本）：自由创意 / 单主体 / 参考一致性 / 多参考融合 / 复杂编辑与连续资产。L5 通常需要更明确的区域控制、参考职责、分步编辑或后期合成；具体工具取决于平台能力。
- 原则：**场景决定主要对象，操作决定变化范围，难度决定控制与验收强度，输出决定规格**。分类导航是入口层，母版槽位协议是执行层。
