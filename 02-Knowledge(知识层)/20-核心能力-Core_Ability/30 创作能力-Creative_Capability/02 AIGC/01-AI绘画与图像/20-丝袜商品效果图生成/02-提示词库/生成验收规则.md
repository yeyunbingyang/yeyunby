# 生成验收规则

```text
验收结果 = 当前B/E条目事实 ＋ 通用质量门禁
```

条目事实保存在参数库；本文只保存通用门禁。

## 01 商品层

- [ ] 基础展示只有 B，没有 E 或旧 A 信息。
- [ ] 扩展展示包含完整 B 和恰好一个 E。
- [ ] 色系、厚度、透明度与参数快照一致。
- [ ] E 的必须可见特征成立，且未触发禁止误读。
- [ ] 标签没有生成第二个扩展效果。
- [ ] 丝袜没有变成裤装、裸腿、鞋面纹理或背景纹理。

## 02 人体层

- [ ] 恰好两条腿、两个膝盖、两个小腿、两个脚踝、两只脚、两只鞋。
- [ ] 关节弯曲、腿部前后关系和重心真实。
- [ ] 鞋脚连接和接触成立，无融合腿、悬空鞋和道具穿模。

## 03 展示层

- [ ] 未指定景别时使用H01：画面从腰部或胯部向下完整展示双腿、袜口、脚踝、脚尖、后跟和鞋履。
- [ ] 画面没有在大腿、膝盖、小腿、脚踝或脚部中途截断，也没有误用看不到丝袜主体的普通上半身构图。
- [ ] H03局部细节没有代替商品全貌；同组另有H01、H02或F01完整展示商品。
- [ ] 袜口、脚尖、后跟和效果关键区域未被遮挡。
- [ ] 严格技术对照任务使用D-BASE：只变化一个基础维度，构图、服装、光线和姿势稳定。
- [ ] 分类批量基础页使用D-CATALOG展示策略＋B轴单变量商品门禁，不套用D-BASE的固定姿势和构图要求。
- [ ] D-CATALOG只变化当前丝袜主分类，并按S5＋C3＋L2＋P2覆盖姿势；躺姿保持成年、完全着装与商品完整可见；复杂道具没有遮挡、复制或冒充商品效果。
- [ ] 分类批量图的服装按丝袜色系或效果联动搭配，未遮挡丝袜、未生成第二个商品效果，也未抢夺分类主体。
- [ ] D-CATALOG的模特、服装、姿势和构图已按配额变化；除严格技术对照外，没有退化成同图复制换色。
- [ ] D-DETAIL 优先保证扩展效果可辨。
- [ ] D-LIFESTYLE 的场景与造型没有改变商品事实。

## 04 一致性层

- [ ] 锁商品需要保持同一人物时，脸、肤色、发型、年龄和体型未漂移。
- [ ] 分类批量H01不显示完整脸部，因此M-REAL编号只作为成年亚洲女性的年龄、体型、肤色和造型参数来源，不以人脸识别具体身份；画面可验证为成年亚洲女性商业时装表达即可。
- [ ] 默认任务只出现亚洲成年女性M-REAL-01、02、03、07、08；欧美身份或VM-ANIME仅在用户手动指定时出现。
- [ ] 左右腿的非设计性颜色、透明度和纹理保持一致。
- [ ] 对比页主光方向、色温和摄影品质一致。

## 05 文字与合规层

- [ ] 图片内无长段落、乱码、水印、品牌和校徽；分类批量允许PL版式规定的大标题、子标题、页码、编号、短名称、单行短描述和底部短说明。
- [ ] 明确成年、完全着装、非挑逗。
- [ ] 无未成年或幼态、真人复刻、名人身份。
- [ ] 动漫概念图没有进入正式商品目录候选池。

## 06 宫格板版式层

- [ ] 使用 [[格子图版式参数]] 中已登记的PL模板，整套九张没有无理由混用模板。
- [ ] 大标题、子标题、主类编号与页码、01–12格位编号、短名称、描述和底部说明完整。
- [ ] 编号按从左到右、从上到下连续排列，没有蛇形、重复或跳号。
- [ ] 标题和信息条未遮挡袜口、膝盖、脚踝、脚尖、后跟或E关键特征。
- [ ] 格位描述只写参数库可验证的可见特征，没有功能夸大或新增商品效果。
- [ ] 分类批量正式中文与原生宫格同次生成，关键标题、页码、01—12编号和短名称可读且正确；不得后期替换文字区或拼接子图。

## 返修规则

### 分类批量原生宫格

1. 记录整页失败症状和所属门禁。
2. 一次只修改一个主要失败原因，保留其余生产单。
3. 每次尝试重新生成整张原生12格宫格及内嵌版式，禁止替换失败格、子图拼接或后期替换文字区。
4. 每页默认最多3次尝试，即首次1次＋返修2次；达到上限仍失败时记录失败页并继续下一主类。

### 锁商品单图或多图

1. 保持商品锁定块和已通过图片不变。
2. 一次只修改失败图的一个主要原因，只重做失败图。
3. 锁商品明确要求格子图时，按该任务选定的原生宫格或逐图成板方式验收，不套用分类批量的返修单位。
