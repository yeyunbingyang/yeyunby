# 通用提示词组装

## 参数结构

```text
任务类型：单产品 / 多效果
效果块：{丝袜效果提示词库}
构图块：{构图与光线提示词库}
姿势块：{姿势匹配提示词库}
模特服装块：{模特与服装提示词库}
背景块：{BG编号＋兼容理由}
道具块：{PR编号＋交互方式；可为PR00}
输出：数量、网格、比例、平台、用途
固定项：
随机项：
随机种子：
```

## 单图模板（默认；单商品主图）

> 锁商品默认用本节模板产出 1 张主图；格子预览仅在明确要求时使用。

```text
生成一张高级、写实、可用于商业目录的成年女性丝袜商品图。
{效果块}
{模特服装块}
{姿势块}
{构图块}
输出：{比例、用途、平台适配}。
严格保持两条腿、两个膝盖、两个脚踝、两只脚和正确连接的鞋履；丝袜贴合腿部且纹理连续。无文字、无水印、无品牌。
```

## 直接格子预览模板（可选，仅在明确要求时使用）

```text
生成{R}列×{C}行、共{K}格的丝袜效果预览。每格按参数表生成不同主效果，展示变量按“丝袜效果 → 服装 → 姿势/构图 → 背景 → 道具 → 光线”逐层筛选后随机。同页统一目录版式、色彩管理和卡片尺寸，但不统一具体服装、背景、道具或姿势；同页至少出现3种背景、3种服装和4种姿势。相邻格不得重复完整组合。只显示三位编号和短名称，不生成长说明。
参数表：{表格}
```

## 负面约束

```text
禁止未成年或幼态描述、男性或混合性别、裸露、肢体融合、多腿、多脚、反折关节、鞋脚分离、纹理漂浮、丝袜变成紧身裤、商品属性漂移、编号遗漏、中文长文乱码、水印和品牌标志。
```
