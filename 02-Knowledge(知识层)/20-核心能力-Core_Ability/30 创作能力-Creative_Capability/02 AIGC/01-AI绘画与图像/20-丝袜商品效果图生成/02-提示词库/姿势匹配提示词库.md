# 姿势匹配提示词库

完整 32 种姿势见 [[生成参数库#参数4：姿势库及匹配]]。

| 效果目标 | 优先姿势 | 避免 |
|---|---|---|
| 颜色、透明度、厚度 | 双腿平行、自然错步、单腿承重 | 强交叠、躺姿 |
| 纵向纹理、渐变 | 站立、迈步、双腿延伸 | 膝部大幅折叠 |
| 小图案 | 轻微交叉、坐姿轻叠 | 远景、强透视 |
| 大图案、空间图形 | 正面平行、轻侧站 | 腿部互相遮挡 |
| 袜口与拼接 | 能露出目标结构的站姿或坐姿 | 长上衣遮挡袜口 |
| 脚尖与足底 | 抬脚、坐姿延伸、脚凳 | 鞋履完全遮挡 |
| 光泽与珠光 | 单腿承重、侧向跨步 | 完全平光 |

## 格间四大类（多效果同页）

姿势按**站（S）/ 坐（C）/ 躺（L）/ 创意（P）**四类分组。多效果同页时保证格间姿势明显不同：

- **四大类全覆盖（强制）**：任何格数的每页格子图都必须覆盖全部 4 类，每类至少 1 格；不得整页只有站姿或只出站坐。
- **站坐主导**：站（S）＋坐（C）合计 ≥ 总格数的 2/3，躺（L）＋创意（P）合计 ≤ 总格数的 1/3。基准比例 `站:坐:躺:创意 ≈ 3:3:1:1`（6 格→2:2:1:1；8 格→3:2:2:1；12 格→4:4:2:2）。
- **相邻格不重复同一大类**（如相邻两格不得都是 S 组）；同大类最多连续出现 1 格。
- 每格先从"姿势与丝袜设计匹配规则"取候选组，再从候选组抽编号；候选组优先于大类均匀化。
- **躺姿（L）与创意（P）直接进批量**，必须带安全限制词（成年、完全着装、非挑逗、艺术表达）；首用可先单图预验收以降低失败率，但不作为进批量的前置门槛。

完整抽取规则见 [[生成参数库#格间姿势抽取规则（多效果同页）]]。

## 姿势控制块

```text
姿势：{编号＋动作}
重心：{支撑腿与非支撑腿}
腿部关系：两腿分离清晰，膝盖与脚踝方向符合动作
接触关系：鞋与脚、身体与座椅/地面/道具接触自然
展示要求：目标丝袜部位无遮挡，纹理沿腿部曲面连续
```

相邻格不得重复同一姿势。坐卧、地面和道具动作可直接进批量，但必须带安全限制词（成年、完全着装、非挑逗、艺术表达）；首用可先单图预验收以降低失败率。
