# 01-教学图治理规范

> [!info] 笔记关系
> **常用 · 合并优化（2026-08-06）**

本目录存放跨笔记复用的流程图、完整示范图、诊断图、学习路径图和建设索引。图片中的短说明只用于快速理解，完整规则以对应 Markdown 笔记为准。

## 一、配图职责

| 类型 | 用途 |
|---|---|
| COVER | 章节封面和目录缩略图 |
| OVERVIEW | 全文结构和流程总览 |
| ANNOTATION | 概念或画面局部标注 |
| COMPARE | 单变量、前后或正误对比 |
| PROCESS | 操作步骤和生产流程 |
| MATRIX | 参数与变量矩阵 |
| ERROR | 失败问题和修复定位 |
| QUICKREF | 结论速查卡 |
| INDEX | 资产缩略图索引 |

## 二、存放与复用

- 只服务一个模块的图片跟随该模块。
- 被两个以上模块复用的图片进入共享入口附件。
- MOC 使用总览图或索引图；SOP 使用流程图；参数库使用矩阵；失败记录使用标注或对比图。
- 每张图只回答一个主要学习问题，正文负责完整解释。
- 同一图片保留一个事实源，通过链接和索引复用，不复制出多个“最新版”。

## 三、文件名与版本

```text
主题-类型-变量-v01.png
```

示例：`人物一致性-COMPARE-写实度-v02.png`。

- 主题明确，类型使用本规范中的英文代码。
- 只有内容实质变化时递增版本。
- 临时草图、生成中间图不进入正式索引。

## 四、图中文字与校对

AI 适合生成布局、图标、示意画面和基础卡片。正式中文标题、编号和说明应人工校对；重要教学图建议在 PPT、Figma、Canva 或图像编辑软件中二次排版。

## 五、准入检查

- [ ] 与对应笔记存在明确链接；
- [ ] 图片职责唯一，不是纯装饰；
- [ ] 中文、编号和术语已复核；
- [ ] 文件名和版本符合规范；
- [ ] 来源、人物授权和商业使用范围已记录；
- [ ] 已登记到 [[90-维护与归档/05-媒体与教学图治理/02-教学图总索引与建设看板|教学图总索引与建设看板]]。
