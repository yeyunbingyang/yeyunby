## 图解总览

![[教学图设计_五步法.png]]


> [!abstract] 核心定位
> 教学图不是"正文配图"，而是一个**降低理解难度、引导注意力、展示关系或演示过程的教学工具**。它服务于单一学习目标，图片负责展示关系，正文负责完整解释。

## 一、核心原则（研究结论 → 设计原则）

基于学习科学研究的六条原则，每一条都直接约束教学图的设计决策：

| # | 研究结论 | 设计原则 |
|---|---|---|
| 1 | **图片必须承担明确功能**：精心设计的插图提高理解与记忆，装饰性图片帮助有限 | 每张图回答一个明确的学习问题；不做装饰性配图 |
| 2 | **视觉信号有效但有上限**：圈注、箭头、颜色提示能引导注意，标注过多反而失效 | 圈注克制，只标关键区域；一张图标注 3–6 个观察点 |
| 3 | **文字靠近对应画面**：图文分离增加认知负担（重要原则而非绝对规律） | 说明文字放图内对应位置，长解释放正文 |
| 4 | **去掉不服务学习目标的装饰**：一致性原则——删除无关内容优于添加装饰 | 只保留服务本图学习目标的元素 |
| 5 | **小白更需要完整示范**：完整案例（需求→步骤→成品）比抽象规则更有效 | 优先做"需求→五段式→最终提示词→检查表"的完整示范图 |
| 6 | **多张图不等于更好**：多表现只有各担其职且读者理解对应关系才有价值 | 控制总量，每图独立功能，不堆叠重复图 |

> [!important] 对知识库的最直接启示
> 当前已有较多"术语对比图"和"流程总览图"，**真正最值得增加的是：完整示范图和错误诊断图**——从实际任务到最终提示词的完整教学案例，以及"为什么翻车、应该改哪里"的诊断。

## 二、八类教学图

| 教学图类型 | 解决的问题 | 适合的知识库内容 |
|---|---|---|
| **标注示意图** | "这个词具体指哪里？" | 景别、人物角度、材质、光影、构图 |
| **同条件对比图** | "两个概念到底差在哪？" | 焦距、景深、风格、柔光与硬光 |
| **流程图** | "应该按照什么顺序做？" | 图生图、扩图、多图一致性、迭代流程 |
| **决策图** | "我该选择哪个模板？" | 七类场景、平台选择、任务类型 |
| **结构关系图** | "这些概念是什么关系？" | 五段式、七维诊断、提示词层级 |
| **完整示范图** | "规则实际怎么使用？" | 需求 → 槽位填写 → 最终提示词 → 结果 |
| **错误诊断图** | "为什么翻车，应该改哪里？" | 换脸、姿势漂移、结构错误、材质失真 |
| **速查卡** | "使用时快速查什么？" | 比例、尺寸、平台参数、镜头术语 |

## 三、知识库教学图精简规划（约 27 张）

> [!warning] 不建议扩展到 46 张
> 教学图规划应以"每张图只回答一个学习问题"为准，不是图越多越好。建议收敛到约 **27 张有效教学图**。

| 类别 | 数量 | 内容 |
|---|---|---|
| **专业词典主图** | 9 张 | 每词典一张（同主体展示术语差异：景别/人物角度/焦距/景深/构图/光影/材质/风格/画幅） |
| **提示词核心结构图** | 3 张 | 五段式结构图（已有）、提示词顺序与优先级图、完整填写示范图 |
| **场景迷你案例卡** | 7 张 | 每类场景一张小型完整示范卡 |
| **特殊形态示范图** | 4 张 | 视图/角色设定图/四格漫画/故事板各一张 |
| **失败诊断与实验图** | 4 张 | 图生图失败诊断、多参考冲突诊断、A/B 单变量实验、失败诊断方法 |

### 3.1 优先新增的六类图（★）

1. **提示词顺序与权重**：任务目标→本轮变化→保持项→目标画面→冲突规则→输出规格；并标注"前置≠固定权重、逻辑优先级≠平台参数、重复三次≠权重增加"。
2. **五段式完整填写案例**：一个实际任务（如"保持人物不变，换成黑色礼服"）展示 原始需求→五段式填写→完整提示词→生成结果检查表。
3. **图生图失败诊断**：现象→可能原因（参考职责冲突/改变项过多/身份要求过晚/风格覆盖身份）→调整动作。
4. **多参考图冲突诊断**：R1 身份被 R2/R3 覆盖时如何排查、如何减参考。
5. **七类场景迷你案例**：每类场景一张小型完整示范卡（不是整页海报）。
6. **A/B 单变量实验**：核心目标前置 vs 末尾的对比，比较身份保持/目标完成度/结构准确性/风格一致性。

### 3.2 各模块规划要点

**① 提示词模板主文件（保留 3 张核心图）**
- 五段式结构图：已有，保留。
- 提示词顺序与优先级图：**新增**，展示填写顺序 + 三个"不等于"警示。
- 完整填写示范图：**新增**，用实际任务展示 需求→五段式→完整提示词→检查表。

**② 专业名词词典（每词典 1 张主图）**
- 各词典保留一张"同主体不同条件"的效果图即可。
- **不建议**给每个小标题都生成一张图——同一概念被拆散，读者需多图间来回比对。

**③ 七类场景模板（不需要 7 张复杂海报）**
- 一张"七类场景选择图"（已有）。
- 每类场景加一张**迷你完整示范卡**。例（人物视觉）：
  ```text
  任务：人物身份保持换装
  固定：人物脸部和原姿势
  变化：黑色连衣裙
  画面：室内自然光、半身
  规则：身份 > 结构 > 服装 > 背景
  输出：3:4 单图
  ```
  商品视觉则换成商品换景示范。

**④ 平台差异（只画稳定结构，不画易变参数）**
- 图片只表达相对稳定的结构：四个入口各自"适合什么"。
- 具体模型名称、尺寸、格式、参考图数量等易变信息放正文，并标注更新时间。

**⑤ 实验与迭代层（最适合研究型图片）**
- A/B 对比图、单变量实验图、失败诊断图——既是教学材料，也是实测证据。

## 四、圈注与标注规范

圈注、箭头、颜色提示属于学习研究中的**视觉信号提示**。统一规范：

| 元素 | 用途 |
|---|---|
| **圆圈** | 指出具体观察区域 |
| **引线** | 连接区域与说明 |
| **箭头** | 表示方向、顺序或变化 |
| **虚线** | 表示构图线、边界或不可见关系 |
| **颜色** | 区分不同概念类别 |
| **编号** | 表示阅读或操作顺序 |

### 一张图的标注层级

```text
标题
一句话学习目标
示例画面
局部圈注
短说明
底部判断口诀
```

### 标注说明要短

- 推荐："背景压缩更明显""面部透视更自然"
- 不推荐："使用较长焦距会让背景在空间视觉关系上产生明显压缩……"
- **长解释放 Markdown 正文，不塞进图片。**

## 五、AI 生成流程（人工校验五步法）

> [!important] 教学图是"正确性敏感内容"
> 中文文字、数字参数、比例尺寸、流程顺序、箭头对应、人体角度、光线方向、焦距透视、平台功能——这些都可能出错。**完全依赖生成前提示词，可预测性和正确性较弱**；生成后的直接检查与修改比生成前堆词更可靠。

```text
第一步：AI 生成无文字或少文字的视觉底图
第二步：人工核对概念和视觉关系
第三步：在 Figma / Canva / PowerPoint 中添加中文标注
第四步：检查圈线、箭头和说明是否一一对应
第五步：再嵌入 Markdown 笔记
```

> 比让图像模型一次性生成全部中文长文案更可靠。
