# 06-提示图与知识图解提示词模板

> [!important] 五段式继承
> 本文遵循 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]；外层统一为【任务】【保持】【画面】【限制】【输出】。本页只增加本场景需要的专业字段。


![[06-提示图与知识图解提示词模板-配图-v01.png]]


## 一、特殊形态图谱

> [!abstract] 定位
> 本模板用于生成“看图就能理解”的知识讲解图。它适合嵌入词典、提示词模板、平台执行说明、学习路径和实验记录。

![[特殊形态提示图模板图谱.png]]

## 二、适用类型


![[教学图设计_五步法.png]]

| 类型 | 适合内容 | 核心结构 |
|---|---|---|
| **术语词典效果图** | 景别、焦距、构图、光线、材质、风格 | 同一主体多格对照 + 圈注 + 底部判断口诀 |
| **对比图** | A/B 风格、材质、参数或方案差异 | 固定对比对象 + 单变量变化 + 相同版式 |
| **流程图** | 工作流、教程、生成步骤 | 编号步骤 + 箭头流向 + 输入/输出 + 易错点 |
| **决策图** | 场景选择、平台选择、任务分流 | 判断问题 + 分支条件 + 最终入口 |
| **参考职责图** | 多图输入、多参考融合 | R1/R2/R3 职责卡 + 冲突规则 + 记忆口诀 |
| **平台差异图** | ChatGPT/API/即梦等入口差异 | 平台列 + 能力行 + 注意事项 + 迁移步骤 |
| **参数速查卡** | 画幅、景深、焦距、输出规格 | 分类按钮/卡片 + 适用场景 + 避坑说明 |
| **多视图/故事板** | 三视图、四格漫画、镜头连续图 | 固定主体 + 视图或分镜编号 + 一致性要求 |

## 三、输入准备

生成前先准备：

```text
主题：{要讲清楚的知识点}
受众：{零基础 / 进阶 / 专业}
图的类型：{术语图 / 对比图 / 流程图 / 决策图 / 速查卡}
核心条目：{3–9个，避免一页过载}
对比对象：{同一人物 / 同一商品 / 同一场景 / 同一图形}
必须标注：{需要圈出的局部和说明文字}
结论口诀：{底部一句话总结}
画幅：{竖版3:4 / 横版16:9 / 方形1:1}
```

## 四、五段式提示图母版

```text
【任务】
任务类型：生成知识讲解型提示图。
主题：{主题}。
受众：{零基础用户}。
本轮目标：通过{多格对比 / 流程 / 决策树}解释{核心概念}。

【保持】
所有示例保持：{同一主体、同一服装、同一场景基调、统一版式}。
参考 R1：负责{主体或示例对象}。
参考 R2：负责{版式风格或品牌视觉}。
除目标变量外，其他条件尽量一致。

【画面】
版式：清晰的中文信息图，分区明确，阅读顺序从上到下、从左到右。
标题区：主标题 + 一句副标题。
示例区：{N} 个编号卡片，每格展示{术语/步骤/选项}。
标注：使用细线、圆圈或局部放大框，准确指向{关键部位}。
文字：每格只保留术语、白话解释和1–3个关键特征。
底部：加入“怎么看 / 怎么选 / 一句话记忆”总结栏。
风格：干净、教学型、留白充分、图文层级清楚。

【限制】
优先级：知识正确 > 对比公平 > 标注对应 > 可读性 > 装饰。
必须保持：各格示例对象一致，编号顺序明确，标注线不遮挡主体。
避免：文字拥挤、圈注错位、箭头指错、示例条件不一致、重复标题、随机Logo、水印。
中文文字可能出现错误，生成后必须逐字验收；重要文字可后期排版。

【输出】
数量：1张。
画幅：{3:4竖版 / 16:9横版}。
版式：{2×3 / 3×3 / 单列流程 / 双栏对比}。
用途：嵌入 Markdown 笔记、知识库、课程或社交媒体。
留白：四周保留安全区，标题和底部总结不得贴边。
```

## 五、可直接复制模板

### 5.1 术语词典效果图

```text
创建一张中文教学信息图，主题为“{术语类别}词典｜效果图示例”。
使用同一{人物/商品/场景}展示{6}种术语差异：{条目1、条目2……}。
每格包含编号、术语名称、白话解释和可观察特征。
使用细线、圆圈和局部放大标出关键差异，标注必须准确指向对应部位。
底部增加“怎么看{术语类别}？”总结栏，从{观察维度1、维度2、维度3、维度4}进行判断。
保持所有格子的主体身份、服装和整体场景一致，只改变目标变量。
采用干净、浅色、专业但小白友好的中文知识卡片版式，3:4竖版。
避免文字过密、标注错位、示例条件不同、重复人物和随机水印。
```

### 5.2 工作流流程图

```text
创建一张中文流程图，解释“{工作流主题}”。
使用5个从上到下的编号步骤：{步骤1} → {步骤2} → {步骤3} → {步骤4} → {步骤5}。
每步包含简短标题、1–2句白话说明和一个清晰图标或小示例图。
右侧增加“适合哪些任务”和“最容易翻车的地方”两个提示栏。
底部用四个图标总结整个流程，并加入一句记忆口诀：{口诀}。
版式清晰，箭头方向唯一，步骤不能跳号，3:4竖版。
```

### 5.3 决策选择图

```text
创建一张中文决策图，主题为“{如何选择任务/平台/模板}”。
先展示{5–7}个主要选项，每个选项包含：核心对象、常见任务、首先固定什么。
底部设置三个判断问题：主角是谁？结果拿去做什么？最不能出错的是什么？
对于混合任务，突出规则：先选一个主要类型，辅助类型只补充风格、版式或输出要求。
采用卡片式信息图，颜色区分选项但保持统一视觉体系，文字简短可读。
```

### 5.4 平台差异速览图

```text
创建一张中文平台能力对比信息图，对比：{平台/入口1、2、3、4}。
每个平台按相同项目说明：适合做什么、提示词怎么写、参考图/编辑方式、主要注意点。
底部增加“不要混淆”栏和“迁移提示词三步法”。
只比较已确认的稳定能力；不确定或随版本变化的项目写“以当前界面为准”。
```

## 六、标注系统规范


### 圈注和连线

- 圈只包围需要观察的局部，不要圈住整张图。
- 连线尽量短，避免交叉；一条线只对应一条说明。
- 局部过小时使用放大框，不要靠超长文字描述。
- 同一页面中，圈、线、箭头的粗细和颜色规则保持一致。

### 文案层级

```text
主标题：这张图讲什么
副标题：为什么要看这张图
卡片标题：术语 / 步骤 / 选项
白话说明：它是什么
关键特征：看哪里
底部总结：怎么选 / 一句话记忆
```

### 文字准确性

图像模型生成中文可能出现错字、断字和版式漂移。正式使用时建议：

1. 先生成无字或少字版示例图；
2. 在设计软件中覆盖正式文字；
3. 对所有编号、箭头、圈注和术语逐项验收；
4. 不把模型生成的小字直接视为可发布终稿。

## 七、验收清单

- [ ] 一眼能看出主题和阅读顺序。
- [ ] 每个示例只改变目标变量。
- [ ] 圈注、连线和文字指向正确。
- [ ] 示例图与说明文字互相对应。
- [ ] 卡片数量适中，没有一页塞入过多知识点。
- [ ] 中文术语、编号和标点已人工复核。
- [ ] 底部有明确的选择方法或记忆口诀。
- [ ] 图片路径适合嵌入 Markdown 笔记。

## 八、问题诊断

| 问题 | 原因 | 修复方式 |
|---|---|---|
| 圈注指错位置 | 一次要求过多标注 | 减少每格标注数量，分两张生成 |
| 各格主体不同 | 没有固定共同参考 | 先生成锚点图，各格明确“同一主体” |
| 对比不公平 | 同时改变多个变量 | 固定构图、服装、光线，只改变目标术语 |
| 文字不可读 | 一页信息过载 | 缩减条目，重要文字后期排版 |
| 流程箭头混乱 | 多条路径同时出现 | 规定单一阅读方向，复杂流程拆成决策图 |
| 画面像普通海报 | 缺少知识结构 | 明确示例区、圈注区、判断栏和底部口诀 |


## 九、子标题教学图模板

> [!abstract] 定位
> 子标题教学图不是整篇笔记的封面，而是紧跟某个二级或三级标题，用一张图解决该小节最难理解的一个问题。它应当**范围小、信息密度适中、与上下文强绑定**。

### 9.1 什么时候需要子标题教学图

- 概念之间容易混淆，例如景别与焦距、焦点与景深；
- 文字需要反复解释空间关系、流程或先后顺序；
- 同一主体存在多种视觉差异，适合 A/B 或多格对照；
- 需要指出局部细节，适合圈注、连线或放大框；
- 表格信息很多，但小白仍难以形成视觉印象；
- 小节包含操作步骤、判断条件或失败修复路径。

### 9.2 子标题教学图规划槽位

```text
对应文件：{笔记文件名}
插入标题：{二级或三级标题}
图的任务：{本图只讲清楚什么}
图型：{对照图 / 流程图 / 圈注图 / 决策图 / 分层图 / 参数卡}
示例对象：{同一人物 / 商品 / 场景 / 界面 / 抽象图标}
画面结构：{2栏 / 3栏 / 2×3 / 单列流程 / 中心辐射}
必须标注：{3–6个观察点}
一句话结论：{底部记忆口诀}
建议文件名：{与小节标题对应的中文名}.png
状态：{待生成 / 已生成 / 已嵌入 / 待复核}
```

### 9.3 可直接复制提示词

```text
创建一张用于 Markdown 笔记子标题下方的中文教学图。
对应小节：{小节标题}。
本图只讲清楚：{单一学习目标}。
受众：零基础用户。

采用{对照图/流程图/圈注图/决策图}结构，画面包含{2–6}个核心示例或步骤。
示例对象保持一致，只改变与本小节有关的变量。
使用清晰的编号、短标签、细线圈注和局部放大框，重点标出：{观察点1、2、3}。
每个说明控制在一行或两行，不写长段落。
底部加入一句记忆口诀：{结论}。
整体版式干净、浅色、教学型，适合嵌入 Obsidian/Markdown 笔记正文。

优先级：知识正确 > 示例公平 > 标注准确 > 文字可读 > 装饰。
避免：文字过密、箭头交叉、圈注错位、同时改变多个变量、与本小节无关的内容。
输出：{16:9横版 / 4:3横版 / 3:4竖版}，四周保留安全区。
```

### 9.4 推荐插入顺序

```text
子标题
→ 1–3句概念导语
→ 教学图
→ 术语表 / 模板 / 详细解释
→ 常见误区与修复
```

> [!tip] 一张子标题教学图只解决一个核心难点。若需要同时解释定义、分类、流程和参数，应拆成多张，而不是做成一张信息过载的大海报。
