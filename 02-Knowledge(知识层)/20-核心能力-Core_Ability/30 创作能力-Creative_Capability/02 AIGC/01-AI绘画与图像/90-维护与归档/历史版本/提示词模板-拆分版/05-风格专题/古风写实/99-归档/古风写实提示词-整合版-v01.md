## 六、参数设置建议

### 6.1 Midjourney

| 参数 | 建议值 | 说明 |
|------|--------|------|
| --ar | 2:3 / 3:4 / 9:16 | 竖版人像 |
| --s / --stylize | 250-750 | 风格化程度，越高越艺术 |
| --c / --chaos | 0-25 | 随机性，0更稳定 |
| --q / --quality | 2 | 最高质量 |
| --v | 6.1 / 7 | 最新版本 |
| --niji | 6 | 动漫风格（如需） |
| --style raw | - | 减少默认美化，更忠于提示词 |

**示例**：
```
[提示词] --ar 2:3 --s 500 --q 2 --v 6.1 --style raw
```

### 6.2 Stable Diffusion

| 参数 | 建议值 |
|------|--------|
| 采样器 | DPM++ 2M Karras / Euler a |
| 采样步数 | 30-50 |
| CFG Scale | 7-9 |
| 分辨率 | 512x768 或 768x1024（基础），可高清修复 |
| 高清修复 | 2x 或 4x，重绘幅度 0.3-0.5 |

**推荐模型**：
- 写实古风：麦橘写实、墨心、国风3
