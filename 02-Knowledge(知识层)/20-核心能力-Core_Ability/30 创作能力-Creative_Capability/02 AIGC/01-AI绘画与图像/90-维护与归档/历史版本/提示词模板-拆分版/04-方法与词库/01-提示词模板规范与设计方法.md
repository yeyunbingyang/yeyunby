# 01-提示词模板规范与设计方法

> [!important] 规范结论
> 所有现行提示词模板统一继承 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]。新增模板不得另起平行主结构。

## 一、统一规范

### 一、固定外层结构

```text
【任务】→【保持】→【画面】→【限制】→【输出】
```

顺序默认固定；某段没有内容时可以删除，但不能换成另一套外层框架。

### 二、各类模板的扩展边界

| 模板类型 | 允许扩展 | 不应做的事 |
|---|---|---|
| 任务模板 | 任务类型、变化范围、参考职责 | 新建另一套主标签 |
| 用途模板 | 专业保持项、画面字段和风险项 | 把行业术语堆成无结构长文 |
| 输出模板 | 视图、版式、顺序、标签、安全区 | 改变人物或商品的事实定义 |
| 平台模板 | 平台语气、参数、选区和上传方式 | 把平台参数混入视觉描述 |
| 风格专题 | 【画面】中的媒介、渲染、色彩和材质模块 | 取代【任务】【保持】【输出】 |
| 限制词库 | 【限制】中的1–4个高风险问题 | 整库复制、固定必加 |

### 三、模板笔记固定结构

1. 适用范围；
2. 五段式可复制模板；
3. 本模板专属填写说明；
4. 示例；
5. 常见失败与修复；
6. 可选扩展；
7. 相关入口。

### 四、元数据要求

现行模板至少包含：

```yaml
template_standard: five_part_minimum_v1
canonical_template: "[[01-提示词/01-通用提示词模板]]"
template_role: task | purpose | output | platform | style_module | restriction
```

### 五、验收清单

- [ ] 外层能映射到五段；
- [ ] “只改变”和“保持不变”没有冲突；
- [ ] 每张参考图只有明确职责；
- [ ] 风格模块放在【画面】，不是独立母版；
- [ ] 限制项只包含当前任务风险；
- [ ] 输出数量、比例、要求和用途明确；
- [ ] 没有绝对一致、固定成功率或伪参数承诺。

### 六、历史内容处理

历史笔记可以保留旧结构作为证据，但必须标为 `archived` 或明确注明“历史结构，不作为当前模板”。活动模板中的旧标签迁移为：任务、保持、画面、限制、输出。

## 二、提示词模板设计方法

![[提示词顺序与权重_正确错误对照.png]]

### 2.1 核心结构：五段式执行 × 七维度诊断

日常提示词不需要把所有控制因素拆成七段。推荐使用五段式：

| 五段 | 回答的问题 | 是否通常必填 |
|---|---|---|
| **【任务】** | 本轮做什么、只改什么 | 是 |
| **【保持】** | 什么必须保持、每张参考图负责什么 | 图生图必填，文生图可简化 |
| **【画面】** | 最终画面应该长什么样 | 是 |
| **【限制】** | 冲突时先保什么、避免什么 | 复杂任务建议填 |
| **【输出】** | 数量、画幅、版式和用途 | 是 |

原七槽位保留为后台诊断维度：

1. 固定项；
2. 可变项；
3. 优先级；
4. 限制项；
5. 镜头与构图；
6. 输出规格；
7. 渲染与质感。

#### 五段式与七维度对应

| 五段式 | 包含的七维度 |
|---|---|
| 【任务】 | 可变项 |
| 【保持】 | 固定项 |
| 【画面】 | 可变项 + 镜头与构图 + 渲染与质感 |
| 【限制】 | 优先级 + 限制项 |
| 【输出】 | 输出规格 |

> [!tip]
> 五段式解决“怎么写得短而完整”，七维度解决“结果为什么出错”。两者不是互相替代，而是前台执行与后台诊断的关系。

### 2.2 双轴原则：保持什么 × 改变什么

复杂图像编辑的核心不是堆风格词，而是清晰区分：

```text
恒定轴：本轮必须保持的内容
可变轴：本轮允许改变的内容
```

例如换装任务：

```text
恒定轴：人物身份、脸部、发型、姿势、摄影角度、背景和原有光线
可变轴：服装及与服装直接相关的褶皱、遮挡和材质反光
```

- **诊断模式**：一次只改一个变量，用于定位问题；
- **正式生成**：可以修改一个逻辑变量组，例如“服装+匹配配饰”；
- **高风险组合**：同时更换身份、姿势、服装、场景和风格，通常会显著降低一致性。

### 2.3 五段式通用母版

```text
【任务】
任务类型：{文生图 / 图生图 / 局部编辑 / 扩图 / 主体替换 / 风格转换 / 批量变体}
本轮目标：{一句话描述任务结果}
只生成或改变：{单一变量或合理变量组}
编辑区域：{无 / 具体位置 / 蒙版区域}

【保持】
必须保持：{身份、结构、姿势、构图、背景、品牌信息等}
参考 R1：负责{身份 / 商品本体 / 原图结构}
参考 R2：负责{姿势 / 服装 / 材质}
参考 R3：负责{风格 / 场景 / 光线}
参考冲突时：以{主参考或核心目标}为准

【画面】
主体：{人物、商品、建筑、场景或素材}
动作与状态：{姿势、表情、运动状态或使用状态}
环境与背景：{地点、时间、天气、空间元素}
风格与媒介：{摄影、动漫、插画、CG、平面设计等}
镜头与构图：{景别、机位、角度、焦距、构图}
光线与色彩：{光向、光质、主色、影调}
材质与细节：{皮肤、发丝、布料、金属、玻璃、纹理等}

【限制】
冲突顺序：{最重要} > {次重要} > {一般要求}
必须保持：{最关键的 2-5 项}
允许自然适配：{与动作、光线、透视相关的合理变化}
避免：{只列当前任务最可能出现的风险}

【输出】
数量：{N}
画幅或尺寸：{1:1 / 3:4 / 4:5 / 16:9 / 自定义}
版式：{单图 / 拼版 / 三视图 / 素材表}
用途：{头像 / 主图 / 海报 / 视频首帧 / 后期素材}
文字区域：{无 / 左侧留白 / 顶部留白 / 指定安全区}
```

### 2.4 三档使用深度

#### 极简版：自由文生图

```text
{主体}，{动作或场景}，{风格}，{镜头与构图}，{光线与色彩}，{画幅}。
```

示例：

```text
一只橘猫坐在雨夜窗边，望向玻璃上的雨滴，电影摄影，室内近景，
柔和暖色灯光与窗外冷蓝色形成对比，浅景深，3:4。
```

#### 标准版：单主体或普通参考图

填写：

- 【任务】；
- 【保持】；
- 【画面】；
- 少量【限制】；
- 【输出】。

#### 专业版：多参考、局部编辑或连续资产

在标准版基础上增加：

- 每张参考图的唯一职责；
- 编辑区域和非编辑区域；
- 冲突顺序；
- 系列统一项；
- 可量化验收标准。

### 2.5 内容要素放在哪里

| 内容要素 | 推荐槽位 |
|---|---|
| 主体身份、商品本体、空间结构 | 【保持】 |
| 本轮要改什么 | 【任务】 |
| 动作、表情、场景、风格 | 【画面】 |
| 镜头、构图、焦距 | 【画面】 |
| 光线、颜色、材质和表面细节 | 【画面】 |
| 保留优先级、允许适配和排除项 | 【限制】 |
| 数量、比例、版式和用途 | 【输出】 |

### 2.6 五段式 × 七类场景填空映射（★ 核心）

七类场景共用同一五段式。场景类型只决定每个槽位填写什么，不重新发明模板结构。

#### 2.6.1 七类场景总映射

| 场景 | 【任务】 | 【保持】 | 【画面】 | 【限制】 | 【输出】 |
|---|---|---|---|---|---|
| **人物视觉** | 创作、换装、姿势、表情、风格或局部修复 | 身份、脸部、体型、发型；参考图分别负责脸、姿势、服装 | 动作、服装、环境、镜头、光线、皮肤与发丝 | 身份 > 结构 > 修改目标 > 材质 > 背景；避免换脸和肢体错误 | 头像、半身、全身、三视图、动作板 |
| **商品与商业视觉** | 白底、换景、卖点、包装展示或批量变体 | 商品结构、比例、包装、品牌色和材质 | 使用场景、道具、机位、布光、材质和卖点 | 商品准确 > 品牌 > 卖点 > 材质 > 场景；避免变形和错字 | 主图、详情图、海报、广告图、批量系列 |
| **场景与概念设计** | 新建世界、替换时间天气、扩展环境或氛围变体 | 世界规则、时代、空间逻辑、核心地标和色彩基调 | 地形、建筑、时间、天气、活动、镜头和空气感 | 世界规则 > 空间 > 地标 > 焦点 > 氛围；避免尺度和时代冲突 | 环境概念图、氛围图、建立镜头、视频首帧 |
| **插画与艺术创作** | 角色插画、叙事画面、封面、漫画或媒介转换 | 主题、故事节点、角色关系、画风和色彩体系 | 动作、场景、构图、笔触、媒介和装饰细节 | 叙事 > 角色关系 > 构图 > 风格 > 细节；避免画风漂移 | 单幅、封面、四格、分镜、系列插画 |
| **平面与品牌设计** | 海报、封面、主视觉、社交图或 UI 插图 | 品牌定位、品牌色、信息层级、Logo 区域和网格 | 主视觉、背景图形、留白、视觉流向和表面效果 | 信息 > 品牌 > 可读性 > 主视觉 > 装饰；避免拥挤和错字 | 海报、封面、横幅、社交媒体图和指定尺寸 |
| **建筑与空间设计** | 建筑概念、室内改造、材料替换、景观或灯光方案 | 功能、结构、尺度、动线、门窗和主要材料 | 建筑风格、家具、景观、视角、采光和材质 | 空间逻辑 > 结构 > 功能 > 尺度 > 材料 > 氛围 | 外观、室内、鸟瞰、轴测和多视角方案 |
| **素材与制作辅助** | 透明主体、纹理、背景、特效、首帧或系列素材 | 素材轮廓、背景规则、边缘、固定机位和系列一致性 | 形态、颜色、密度、方向、表面和光线 | 可用性 > 完整度 > 边缘 > 一致性 > 美观；避免裁切和污染 | PNG、无缝纹理、背景图、特效元素、素材表 |

#### 2.6.2 01 人物视觉填空模板

```text
【任务】
本轮任务：{人物文生图 / 身份保持 / 换装 / 姿势调整 / 风格转换}
只改变：{服装、姿势、表情、场景或风格}

【保持】
保持：{人物身份、脸型、五官比例、体型、发型、原姿势或构图}
R1 负责人物身份；R2 负责{姿势/服装}；R3 负责{风格/场景}。

【画面】
人物：{年龄段、外貌、体型和气质}
动作与表情：{具体姿势与情绪}
服装与配饰：{款式、材质、颜色和结构}
环境：{场景、时间和背景}
镜头：{头像/半身/全身，角度，构图，焦距}
光线与质感：{皮肤、发丝、布料和人像光}

【限制】
人物身份 > 人体结构 > 本轮修改目标 > 服装材质 > 背景。
允许服装褶皱和遮挡随姿势自然适配。
避免身份漂移、年龄变化、错误肢体、异常手指和意外裁切。

【输出】
{数量、画幅、单图/三视图/动作板、用途}
```


#### 2.6.6 05 平面与品牌设计填空模板

```text
【任务】
本轮任务：{海报 / 封面 / 活动主视觉 / 横幅 / 社交媒体图 / UI插图}
本轮改变：{主视觉、图形语言、背景素材或版式方向}

【保持】
保持：{品牌定位、品牌色、信息层级、Logo安全区、网格和留白规则}
R1 负责品牌视觉；R2 负责{主视觉素材/风格参考}。

【画面】
主题：{活动或传播主题}
主视觉：{人物、商品、抽象图形或场景}
版式：{居中、网格、分栏、不对称或大留白}
视觉流向：{阅读顺序和焦点位置}
质感：{扁平、渐变、3D、拼贴、纸张、印刷颗粒等}

【限制】
信息层级 > 品牌一致 > 可读性 > 主视觉 > 装饰。
避免文字错误、Logo变形、元素拥挤、对齐混乱和超出安全区。

【输出】
```

### 2.7 混合场景规则

一项任务可能同时涉及两类场景，例如：

- 人物视觉 + 插画艺术；
- 商品视觉 + 平面品牌；
- 建筑空间 + 场景概念；
- 人物视觉 + 素材制作。

不要把两套模板完整叠加。使用下面的规则：

```text
主要场景：决定保留项、优先级和核心限制。
辅助场景：只补充风格、版式、材质或输出要求。
```

示例：护肤品社交媒体广告

```text
主要场景：商品与商业视觉
保持：瓶身结构、包装、品牌色和Logo区域
优先级：商品准确 > 品牌信息 > 卖点 > 装饰

辅助场景：平面与品牌设计
补充：右侧预留标题区，品牌网格，4:5社交媒体版式
```

### 2.8 七维度诊断表

![[生成失败_七维诊断路线.png]]


当结果不理想时，不要立刻重写整段提示词。先判断属于哪个维度：

| 现象 | 主要诊断维度 | 优先调整 |
|---|---|---|
| 人物换脸、商品变样 | 固定项 | 减少参考图；明确主参考；列出关键保留特征 |
| 没有完成本轮修改 | 可变项 | 把“只改变什么”前置并写得具体 |
| 背景或风格压过主体 | 优先级 | 缩短次要描述；明确主体或商品优先 |
| 多指、错字、额外对象 | 限制项 | 加入与当前错误直接相关的少量限制 |
| 角度、景别或透视错误 | 镜头与构图 | 单独写景别、机位、角度和构图 |
| 比例、数量或版式错误 | 【输出】 | 使用平台尺寸参数，并在提示词中说明版式 |
| 塑料感、材质假、光线平 | 渲染与质感 | 用正向材质、表面和布光描述替代泛化“高质量” |

### 2.9 特殊操作规则

#### 文生图

- 不需要写“保持原图”；
- 主体、动作、环境、风格和镜头是主要信息；
- 极简任务不必套完整五段式。

#### 图生图

- 先写本轮任务，再写保留项；
- 每张参考图只承担一个主要职责；
- 不要同时要求“完全保持”和“大幅改变”同一维度。

#### 局部编辑

- 明确编辑区域与非编辑区域；
- 描述修复后的正确结构，不只描述“删除错误”；
- 允许编辑区域的光影、遮挡和材质随周边自然衔接。

#### 扩图

- 固定原图内容、透视、机位、光线和色调；
- 只描述新增区域需要延续什么；
- 不要要求模型重绘中心主体。

#### 风格转换

- 写清“只改变艺术表现方式”；
- 身份、结构、姿势、构图和主要颜色按任务决定是否保持；
- 风格词不宜同时选择相互矛盾的媒介。

#### 多参考融合

- 使用最少参考集；
- 一张主参考负责身份或商品本体；
- 其他参考分别负责姿势、服装、场景或风格；
- 若参考冲突，先移除最低价值参考再测试。

#### 批量变体

- 单独列出全系列固定项；
- 每张只改变一个变量或一个变量组；
- 统一机位、画幅、布光、背景规则和命名方式。
