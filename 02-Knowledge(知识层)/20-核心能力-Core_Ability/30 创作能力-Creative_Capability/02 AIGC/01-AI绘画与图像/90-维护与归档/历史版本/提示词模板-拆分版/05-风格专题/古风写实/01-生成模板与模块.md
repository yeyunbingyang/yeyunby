# 古风写实-生成模板与模块

> [!important] 五段式继承
> 本文遵循 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]；外层统一为【任务】【保持】【画面】【限制】【输出】。本页只增加本场景需要的专业字段。


> 本文提供可插入【画面】段的古风写实模块。先使用五段式母版，再按需选择人物、服装、镜头和光线模块。

## 五段式调用示例

古风内容仅替换【画面】中的风格、服装、材质和光线字段。

```text
【任务】
任务类型：{生成 / 编辑 / 风格转换}
目标：{古风人物或场景目标}
只改变：{本轮允许变化的内容}

【保持】
保持不变：{身份、姿势、构图或商品结构}
参考图职责：{如有}

【画面】
主体与动作：{人物与动作}
场景与风格：{从本文选择古风人物、服装和风格模块}
镜头与光线：{从本文选择构图、镜头和光影模块}

【限制】
避免：{身份漂移、服装结构错误、时代元素混杂等}
优先级：{身份或结构 > 指定风格 > 装饰细节}

【输出】
数量：{数量}
比例：{比例}
要求：{全身、半身、设定页等}
用途：{用途}
```

## 第一部分：画面模块公式

```
[构图模块] + [人物外貌模块] + [发型发饰模块] + [服装配色模块] + [妆容细节模块] + [光影效果模块] + [风格画质模块]
```
