# 04-平面与品牌设计提示词模板

> [!important] 五段式继承
> 本文遵循 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]；外层统一为【任务】【保持】【画面】【限制】【输出】。本页只增加本场景需要的专业字段。


![[04-平面与品牌设计提示词模板-配图-v01.png]]


> [!abstract] 定位
> 生图模型适合生成**主视觉、背景图形和构图草案**，不适合承担最终准确排版。模板应明确品牌规则、信息层级和文字安全区，并把正式文案和 Logo 留给设计软件。

## 一、先选择任务


![[平面品牌_五槽位完整示范.png]]

| 子任务 | 固定核心 | 模型主要生成 | 后期完成 |
|---|---|---|---|
| 活动海报 | 品牌色、主题、信息层级 | 主视觉、背景、构图草案 | 标题、日期、Logo、二维码 |
| 封面 | 主题、书名区、书脊安全区 | 插画/摄影主视觉 | 正式文字与印刷规范 |
| 社交媒体视觉 | 品牌调性、比例、CTA 区 | 背景、主体、装饰 | 文案和按钮 |
| Banner | 尺寸、主体位置、留白方向 | 横向视觉和氛围 | 精确文字与适配裁切 |
| UI 插图 | 产品风格、色彩、图形语言 | 插图主体 | 组件、文字和交互 |

## 二、输入准备

- 品牌定位、主色、辅助色和禁用色；
- 标题、副标题、Logo、CTA 等真实信息层级；
- 最终尺寸、出血、安全区和多端裁切要求；
- 主视觉主题和需要留白的方向；
- 哪些元素必须后期使用真实矢量文件。

## 三、五段式平面设计母版


```text
【任务】
任务类型：{海报 / 封面 / Banner / 社交媒体视觉 / UI 插图}
本轮目标：{主视觉草案或背景素材}
只生成：{主体、背景图形、装饰和留白结构}

【保持】
保持：{品牌定位、品牌色、信息层级、网格、Logo 安全区}
参考 R1：负责{品牌风格 / 主视觉}
参考 R2：只负责{版式 / 色彩，可选}

【画面】
主题与主视觉：{核心符号或主体}
视觉层级：{第一、第二、第三层}
版式：{网格、对齐、分区、视觉流向}
留白：{标题、正文、Logo、CTA 的位置}
图形语言：{扁平、几何、拼贴、3D、渐变等}
色彩与质感：{品牌色、对比、纸张或屏幕质感}

【限制】
优先顺序：信息层级 > 品牌一致 > 可读性与安全区 > 主视觉 > 装饰
避免：{随机文字、Logo 变形、拥挤、对齐混乱、关键元素超出安全区}

【输出】
尺寸/画幅：{真实规格}
版式：{单张 / 系列}
文字区域：{位置与范围}
交付：{背景草案 / 主视觉素材 / 完整视觉草案}
```

## 四、可直接复制模板

### 4.1 活动海报主视觉

```text
生成一张{活动类型}海报主视觉草案，不生成准确活动文字和 Logo。

品牌规则：主色{颜色}，辅助色{颜色}，整体调性{关键词}。
主题：{活动主题}。
主视觉：{主体和象征元素}。
信息层级：主视觉第一，标题区第二，辅助信息区第三。
版式：{竖版/横版}，使用{网格或构图}；顶部保留标题区，底部保留日期、地点、Logo 和二维码安全区。
图形语言：{几何、拼贴、3D、摄影或插画}。

避免随机文字、假 Logo、复杂细小符号、元素挤入安全区和无关色彩。
输出：{尺寸或比例}，供设计软件后期排版。
```

### 4.2 社交媒体系列视觉

```text
生成同一品牌活动的三张系列背景视觉。

所有版本固定：品牌色、图形语言、网格、主视觉尺度、标题留白和光影。
变量：每张只更换{主题元素/场景/产品颜色}。
A：{内容}
B：{内容}
C：{内容}

不生成准确文案和 Logo；每张独立输出，画幅 4:5，顶部和右下角保留排字空间。
```

### 4.3 UI 空状态插图

```text
为{产品类型}设计一张空状态插图。
主题：{无数据/无搜索结果/上传成功等}。
图形语言：简洁几何、少量层次、圆角形状、与品牌色一致。
主体居中，背景透明或纯色，四周保留界面布局空间。
避免复杂文字、写实噪点、过多小物件和不符合产品调性的装饰。
输出：1:1 或指定组件比例，供 UI 后期布局。
```

## 五、验收清单

- 信息层级是否清楚，即使尚未排字也能看到标题区和主体区；
- 品牌色和图形语言是否统一；
- 文字、Logo、二维码和裁切安全区是否真实可用；
- 主视觉是否能在缩略图下识别；
- 是否避免把模型生成的伪文字误当成终稿；
- 系列视觉的网格、色彩和主体尺度是否一致。

## 六、问题诊断

| 现象 | 首查维度 | 调整动作 |
|---|---|---|
| 画面拥挤 | 构图/输出 | 减少元素，明确网格和留白区 |
| 品牌感不一致 | 保留项 | 固定品牌色、图形语言和形状规则 |
| 文字乱码 | 【限制】 | 不生成正式文字，后期排版 |
| 系列图不统一 | 变化范围 | 固定网格、主体尺度和色彩，只改一个变量 |
| 缩略图不突出 | 目标画面 | 增大主视觉，强化一处主要对比 |
