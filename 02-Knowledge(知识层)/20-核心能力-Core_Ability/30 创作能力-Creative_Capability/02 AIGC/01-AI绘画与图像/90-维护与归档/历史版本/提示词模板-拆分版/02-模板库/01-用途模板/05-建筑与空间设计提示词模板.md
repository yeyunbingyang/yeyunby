# 05-建筑与空间设计提示词模板

> [!important] 五段式继承
> 本文遵循 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]；外层统一为【任务】【保持】【画面】【限制】【输出】。本页只增加本场景需要的专业字段。


![[05-建筑与空间设计提示词模板-配图-v01.png]]


> [!warning] 使用边界
> 本模板用于**概念探索和效果表现**。生成结果不能直接替代平面图、施工图、结构计算、规范审查、尺寸验证或工程审批。

## 一、先选择任务


![[建筑空间_五槽位完整示范.png]]

| 子任务 | 首要固定 | 主要变化 | 关键 |
|---|---|---|---|
| 建筑外观 | 体块、层数、开口、入口和环境关系 | 立面风格、材料、时间天气 | 垂直线、尺度和结构可信 |
| 室内效果 | 墙体、门窗、功能区、层高和动线 | 家具、软装、材料、灯光 | 功能与尺度优先 |
| 空间改造 | 原始结构与不可拆项 | 风格、陈设、局部材料 | 不让模型重构空间 |
| 景观设计 | 地形、路径、水体和使用节点 | 植物、铺装、设施、季节 | 生态与人流逻辑 |
| 展陈/舞台 | 场地、入口、展项位置和视线 | 主题、灯光、装置 | 人流、消防与尺度需另行验证 |

## 二、输入准备

- 已知空间结构、功能、不可改变项和尺度基准；
- 主视角与需要保持的透视关系；
- 材料清单、家具或设备清单；
- 白天/夜晚和自然/人工光照要求；
- 概念图、汇报图还是方案对比图。

## 三、五段式建筑母版


```text
【任务】
任务类型：{建筑概念 / 室内效果 / 空间改造 / 景观 / 展陈}
本轮目标：{表现或改造什么}
只改变：{材料、家具、软装、灯光、景观或风格}

【保持】
保持：{墙体、门窗、楼层、体块、动线、功能区、尺度和机位}
参考 R1：负责{空间结构 / 原图}
参考 R2：只负责{材料 / 家具 / 风格，可选}

【画面】
空间功能：{谁使用、做什么}
结构与布局：{体块、墙体、门窗、路径、区域}
家具/景观/展项：{位置、尺寸关系、数量}
材料：{木、石、玻璃、金属、混凝土等}
镜头：{人眼平视、两点透视、鸟瞰、轴测、焦距感}
光线：{采光方向、灯具类型、时间、色温}
空间质感：{尺度、反射、阴影、空气感}

【限制】
优先顺序：空间逻辑 > 结构与尺度 > 功能动线 > 材料 > 氛围
避免：{结构悬浮、门窗错位、透视错误、比例异常、动线堵塞}

【输出】
数量：{N}
画幅：{比例}
视角：{入口 / 主空间 / 鸟瞰 / 立面等}
用途：{概念汇报 / 效果参考 / 方案比较}
```

## 四、可直接复制模板

### 4.1 室内空间改造

```text
编辑室内参考图，只改变家具、软装、表面材料和灯光氛围。

保持原始墙体、门窗、柱体、吊顶高度、地面边界、空间动线、摄影机位和透视关系。
目标功能：{客厅/酒店大堂/展厅等}。
家具布局：{主要家具及位置关系}，尺寸符合成年人和现有空间尺度。
材料：{墙面、地面、顶面、家具材质}。
灯光：{自然采光方向}，配合{灯具类型和色温}；阴影和反射符合真实空间。
风格：{现代、侘寂、工业、轻奢等}，用材料和形状描述，不只写标签。

优先：空间结构与动线 > 尺度 > 功能 > 材料 > 氛围。
不要新增或删除门窗和墙体，不改变机位，不生成悬浮家具、错位透视和不合理尺度。

输出：单张，保持原图画幅，用于概念效果参考。
```

### 4.2 建筑外观概念

```text
设计一座{建筑类型}的外观概念图。
场地：{城市/滨水/山地/校园等}。
体块：{层数、主次体块、入口、公共空间}。
立面语言：{开窗规律、遮阳、结构节奏}。
材料：{混凝土、玻璃、木材、金属、石材}，表现真实连接和表面差异。
镜头：两点透视，人眼高度，{广角或标准镜头感}，垂直线尽量保持竖直。
环境：{时间、天气、景观、人群尺度}。

避免漂浮结构、无支撑大跨度、随机门窗、重复纹理、人物与建筑比例错误。
输出：16:9 建筑概念效果图。
```

### 4.3 多方案材料对比

```text
基于同一空间结构和同一机位生成三种材料方案。

固定：墙体、门窗、家具布局、镜头、时间、光源方向和画幅。
唯一变量：主要材料体系。
A：浅木、米白石材、亚麻。
B：深色木饰面、灰色石材、黑色金属。
C：清水混凝土、透明玻璃、浅灰织物。

每个方案独立输出，不改变结构和家具位置。
```

## 五、验收清单

- 墙体、门窗、体块和机位是否保持；
- 尺度是否符合人物、家具和建筑常识；
- 动线、入口和功能区是否可读；
- 垂直线、消失点和地面接触是否合理；
- 材料反射、粗糙度、接缝和阴影是否可信；
- 是否清楚标记为概念表现，而非工程成果。

## 六、问题诊断

| 现象 | 首查维度 | 调整动作 |
|---|---|---|
| 空间被重构 | 保留项/变化范围 | 明确墙体、门窗和机位不可改变，缩小编辑范围 |
| 家具比例异常 | 目标画面 | 加入人物尺度和具体家具尺寸关系 |
| 透视变形 | 镜头与构图 | 指定两点透视、垂直线和较温和焦距 |
| 材料像贴纸 | 渲染与质感 | 描述厚度、接缝、粗糙度、反射和边缘 |
| 动线堵塞 | 【限制】 | 减少家具，明确入口、通道和功能区域 |
