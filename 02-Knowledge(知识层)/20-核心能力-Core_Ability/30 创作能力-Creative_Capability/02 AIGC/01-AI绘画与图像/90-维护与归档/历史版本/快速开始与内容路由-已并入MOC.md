# 01-快速开始与内容路由

> [!info] 笔记关系
> **常用 · 合并优化（2026-08-06）**

## 一、按需求进入

| 需求 | 入口 |
|---|---|
| 直接写或改提示词 | [[01-提示词/01-通用提示词模板|最小可用提示词模板]] · [[01-提示词/01-通用提示词模板|提示词快速使用]] |
| 不理解镜头、光影、材质、色彩等术语 | [[02-视觉术语/00-视觉术语速查|专业名词速查]] |
| 查姿势、角色、场景、参数或生产流程 | [[资产与工作流-MOC]] |
| 做 A/B 测试或沉淀跨项目结论 | [[04-实验与结论/01-实验方法与模板|研究与验证]] |
| 查看当前版本、变更和健康状态 | [[90-维护与归档/CURRENT|CURRENT]] |

## 二、标准工作流

```text
明确任务 → 选择术语与资产 → 组合提示词 → 生成与验收 → 记录实验 → 交付与归档
```

## 三、内容路由

| 内容 | 放置层级 | 判断标准 |
|---|---|---|
| 通用提示词方法和可复制模板 | `01-提示词模板` | 不绑定具体角色或项目，回答“如何表达” |
| 视觉词义和选择提醒 | `02-视觉术语` | 解释“词是什么意思、何时用” |
| 人物、姿势、场景、参数、过程和交付 | `03-资产与工作流` | 可调用或可追溯的生产事实 |
| A/B 测试、跨项目验证和结论 | `04-实验与结论` | 回答“这个规律是否成立” |
| 当前状态、ADR、审计、发布与历史规划 | `90-维护与归档` | 治理知识库本身 |

## 四、冲突处理

1. **通用规则与项目经验冲突**：项目记录保留事实，通用规则进入研究层复核。
2. **历史规划与当前结构冲突**：以 [[90-维护与归档/CURRENT|CURRENT]] 为准。
3. **平台说明与实际能力冲突**：记录复核日期，避免把平台经验写成永久标准。
4. **同一媒体被多处使用**：保留单一事实源，通过链接和索引复用。
5. **学习可用与商业可用冲突**：以来源和授权字段为准，未知状态不得默认商业使用。
