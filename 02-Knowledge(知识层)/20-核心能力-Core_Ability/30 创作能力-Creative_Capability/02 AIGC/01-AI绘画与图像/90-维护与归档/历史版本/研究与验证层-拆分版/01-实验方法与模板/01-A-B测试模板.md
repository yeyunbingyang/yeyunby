# 01-A-B测试模板

> [!info] 笔记关系
> **常用 · 新增（2026-08-05）**

> [!abstract] 原则
> A/B 测试必须有共同基准和唯一变量。随机种子不可控的平台应进行多次生成或明确“仅为单次观察”，不能把一次偶然结果写成稳定规律。

## 一、实验卡模板


![[AB测试_单变量设计.png]]

```text
实验 ID：{日期-场景-序号}
问题：{想验证什么}
假设：{为什么认为 B 会优于 A}
场景：{七类场景}
任务类型：{文生图/编辑/扩图/多参考等}
平台与入口：{ChatGPT Images / OpenAI API / 即梦图片生成 / 即梦智能画布}
模型/版本：{如可见}
参数快照：{尺寸、质量、格式、其他可见设置}
参考图：{R1/R2...及职责}
共同固定项：{主体、构图、场景、光线等}
唯一变量：{只改变什么}
生成次数：{每版次数}
成功标准：{可观察标准}
```

```text

```

## 六、反模式

- A 和 B 同时改变风格、镜头、光线和负面词；
- 两版使用不同参考图却归因于提示词；
- 参数或画幅不同但未记录；
- 只挑最佳一张，不记录生成批次；
- 一次结果就写成“平台固定规则”；
- 只记录胜者，不记录失败表现和适用边界。
