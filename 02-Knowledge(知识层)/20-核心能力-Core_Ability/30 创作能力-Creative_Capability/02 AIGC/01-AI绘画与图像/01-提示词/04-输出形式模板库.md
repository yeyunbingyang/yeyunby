## 视图生成提示词模板

> [!important] 五段式继承
> 本文遵循 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]；外层统一为【任务】【保持】【画面】【限制】【输出】。本页只增加本场景需要的专业字段。





### 多图一致性提示

> [!tip] 先做锚点图
> 系列图不要每张从零开始。先固定身份、结构、配色、版式或场景基调；出现新服装、新道具或新场景时，先为新元素建立代表图，再批量生成后续画面。

![[多图一致性流程图_先立锚点后生成.png]]

> [!abstract] 定位
> 三视图不是“同一人物画三遍”，而是要求同一设计在正面、严格侧面和背面保持结构对应。一次拼版方便预览，但容易换脸、重复角度和细节漂移；需要制作级参考时，优先逐视图生成。

### 一、视图类型


| 类型 | 视图组成 | 用途 |
|---|---|---|
| 标准三视图 | 正面、严格 90° 侧面、背面 | 结构与服装正背参考 |
| 四分之三展示 | 正面、左右 3/4、背面 | 宣传展示和设计沟通 |
| 商品多视图 | 正面、侧面、背面、顶视、细节 | 商品结构和建模参考 |
| 九宫格视角研究 | 预先定义的九个角度 | 观察角度变化，不等同于工程正交图 |

### 二、输入准备

- 主体身份或商品结构参考；
- 正面和背面不可见结构说明；
- 统一服装、配色、材质和比例；
- 是否要求正交感、严格侧面或展示型透视；
- 一次拼版还是逐视图输出。

### 三、五段式视图母版

```text
【任务】
任务类型：{三视图 / 多视图 / 九宫格视角}
目标：{主体及用途}
只改变：摄影机观察角度；主体设计不变

【保持】
保持：{身份、比例、服装/商品结构、配色、材质、发型、道具}
参考 R1：负责{主体身份或本体}
参考 R2：负责{服装正背或结构细节，可选}

【画面】
视图 1：{正面全身/正面商品}
视图 2：{左侧严格 90°}
视图 3：{背面}
统一：平视机位、主体尺度、站姿/摆放、背景、光线和渲染

【限制】
优先顺序：主体一致 > 结构对应 > 角度准确 > 版式 > 渲染
避免：换脸、结构随机变化、角度重复、侧面变 3/4、主体裁切、格子重叠

【输出】
流程：{一次拼版 / 每视图独立输出}
版式：{横向三格 / 纵向三格 / 3×3}
画幅：{比例}
背景：{纯色 / 工作室}
```

### 四、可直接复制模板

#### 4.1 一次生成三视图草案

```text
生成同一{成年人物/商品}的三视图概念参考板。

保持同一{身份或商品结构}、比例、服装/包装、配色、材质和细节。
视图 1：正面，完整可见。
视图 2：左侧严格 90°，不是三分之四视角。
视图 3：背面，展示真实背部结构。

三个视图统一平视机位、主体尺度、自然标准站姿/摆放、浅灰背景和柔和均匀光。
横向三格，格间留白，不重叠，不添加文字和装饰。
避免不同视图换脸、服装细节随机变化、角度重复、侧面不准和主体裁切。
输出：单张 4:3 三视图板。
```

#### 4.2 制作级逐视图流程

```text
先生成基准正面图：{完整主体描述}。

后续每张都使用同一基准参考，只改变观察角度：
A：正面，全身，平视。
B：左侧严格 90°，全身，平视。
C：背面，全身，平视。

每张保持同一主体比例、服装/包装结构、配色、材质、光线、背景和主体尺度；独立输出，不拼版。完成后人工比对结构，再统一排版。
```

### 五、验收清单

- 各视图是否是同一主体；
- 正、侧、背的轮廓和结构能否互相对应；
- 严格侧面是否真为 90°；
- 主体尺度、脚底线、背景和光线是否统一；
- 背面结构是否由明确设计而非随机补全；
- 一次拼版失败时是否切换为逐视图生成。

### 六、问题诊断

| 现象 | 原因 | 修复 |
|---|---|---|
| 各视图不同人/物 | 单图多主体一致性不足 | 逐视图生成，使用同一基准参考 |
| 侧面不够 90° | 角度边界模糊 | 单独写严格 90° 侧面并独立生成 |
| 背面随机 | 未提供背部设计 | 补背面参考或明确结构 |
| 服装/包装变化 | 固定项不足 | 写正背结构、材质、配色和显著部件 |
| 版式重叠 | 一次输出过多格 | 减少格数，后期排版 |

### 一、设定板类型

| 类型 | 内容 | 推荐方式 |
|---|---|---|
| 基础人设板 | 主立绘 + 角色摘要 + 配色 | 可一次草案，文字后期 |
| 结构设定板 | 正面、侧面、背面 | 逐视图生成 |

| 服装设定页 | 正背面、局部结构、配件 | 分资产生成后排版 |
| 综合设定板 | 主图 + 视图 + 表情 + 细节 | 必须分阶段 |

- 角色基准卡：年龄、脸型五官、发型、体型、服装、配色、身份气质；
- 角色基准图 R1；
- 服装正背结构和配件清单；
- 表情列表及强度；
- 页面布局草图和文字安全区。

### 角色身份设定：脸部特写3视图

> [!important] 核心原则
> **身份特征与动漫化程度是两个独立变量，必须分层控制。**先锁定真人骨相与五官，再递进风格；不要直接从真人图反复生成不同画风。==Level 2 半写实 3D 脸模是唯一身份母版==，后续换服装、发型、世界观、动作和画风都从该母版出发。

#### 四阶段生产流程

```text
真人多角度参考
    ↓
Phase 0：身份锁定（Identity Lock）
    ↓
Phase 1：脸模标准化（Level 2 半写实 3D 脸模）
    ↓
Phase 2：风格递进（Level 2 → Level 3，按需继续）
    ↓
Phase 3：角色资产化（发型、服装、表情与最终漫剧资产）
```

#### Phase 0：身份锁定层

输入真人正面、左右 45°、左右严格 90° 等多角度照片，先提取并冻结以下身份不变量：

| 类别 | 必须锁定的特征 |
|---|---|
| 骨骼结构 | 脸型、额头比例、颧骨高度、下颌宽度、下巴长度、头骨比例 |
| 五官结构 | 眉形、眼裂长度、眼距、眼尾角度、鼻梁高度、鼻头形态、唇峰、嘴角 |
| 表面特征 | 肤色、肤质、痣、发际线 |

> [!warning] 常见漂移
> 动漫化容易重塑五官，3D 化容易生成通用游戏脸，美化容易换人，侧脸生成容易改变鼻梁、嘴凸关系和下颌轮廓。发现漂移时先回退身份层，不要继续叠加风格词。

#### Phase 1：Level 2 脸模母版

风格定义：`Semi-Realistic Anime Character Face Base + AAA Game Character Facial Scan`。其中 `Facial Scan` 与 `Human Anatomy` 用于保持真人骨相，`Semi-Realistic Anime` 只负责轻度视觉整理。

```text
【任务】
基于全部参考照片，创建同一人物的半写实动漫 3D 脸模母版。
这是角色身份资产创建，不是重新设计人物。

【保持】
最高优先级是人物身份一致。
严格锁定脸型比例、额头比例、颧骨高度、眉眼结构、眼距、眼尾角度、鼻梁高度、鼻头形态、嘴唇轮廓、下颌线、下巴长度、发际线和头骨比例。
保留可识别的肤色、肤质、痣等表面特征。

【画面】
半写实动漫 3D，真人扫描级面部结构，AAA 游戏角色脸模，影视 CG 人物渲染，国漫 3D 角色质量。
保持真实人体解剖与真人骨相，仅做自然、克制的动漫增强。
皮肤具有真实纹理、柔和毛孔、自然血色和次表面散射。
眼睛仅轻微动漫化，保留真实眼球结构与自然高光。
头发使用真实发丝和 3D 毛发系统，具有自然重量感。

【限制】
禁止改变脸型、年龄、五官比例、鼻梁与鼻头、下颌宽度和下巴长度。
禁止美化成另一个人、生成相似角色、通用网红脸或通用游戏脸。
禁止大眼、小鼻、尖脸、幼态化和过度磨皮。
不同视图不得改变发际线、肤色和身份识别特征。

【输出】
同一角色的脸部特写 3 视图：正面 0°、左前 45°、左侧严格 90°。
三格保持同一焦距、同一机位高度、同一中性表情、同一灯光和同一裁切尺度。
纯白背景，无文字、无装饰；建议先逐视图独立生成并验收，再统一拼版。
```

> [!tip] 对称角度扩展
> 基础 3 视图通过后，再补右前 45° 与右侧严格 90°。侧脸必须重点核对眉骨—鼻梁—鼻头—人中—嘴唇—下巴的连续轮廓，以及耳位、后脑勺和下颌角。

#### 五级动漫化控制

比例只用于内部标尺，执行时优先使用视觉控制词，不要只写“真人 70%、动漫 30%”。

| 等级 | 视觉控制词 | 主要用途 | 风险 |
|---|---|---|---|
| Level 1 真人增强 | `subtle anime style, realistic human face, minimal stylization` | 身份扫描与真人增强 | 低 |
| Level 2 半写实国漫 | `semi-realistic anime, natural anime enhancement, human anatomy, facial scan` | **唯一身份母版、脸部三视图** | 低 |
| Level 3 国漫 3D | `high-quality Chinese anime 3D character, cinematic anime rendering` | 漫剧最终角色 | 中 |
| Level 4 游戏角色化 | `idealized beauty, stylized facial features, larger eyes` | 宣传海报 | 高，易小鼻尖脸与年龄漂移 |
| Level 5 纯动漫 | `strong anime stylization, identity impression` | 头像、表情包 | 很高，不可作为母版 |

#### 标准节点

| 阶段 | 固定等级 |
|---|---|
| 身份扫描与真人增强 | Level 1 |
| 脸部特写 3 视图与身份母版 | **Level 2** |
| 漫剧角色 | Level 3 |
| 宣传海报 | Level 4 |
| 头像与表情包 | Level 5 |

```

#### 脸部特写3视图验收

- [ ] 三个视图能明确识别为同一人，而非仅有相似气质；
- [ ] 正面脸宽、眼距、鼻翼宽度和下颌宽度未被美化重塑；
- [ ] 45° 视图的远侧眼、鼻翼和嘴角位置符合真实透视；
- [ ] 90° 侧面的额头、鼻梁、鼻头、人中、唇部和下巴轮廓连续；
- [ ] 耳位、发际线、颧骨高度、下颌角和后脑勺在各视图间对应；
- [ ] 年龄感、肤色、痣、发型、表情、光线、焦距和裁切保持一致；
- [ ] Level 2 母版通过后才允许进入 Level 3，不从真人图直接跳级。

### 四、推荐分阶段流程


#### 阶段 1：角色基准图

```text
生成角色的正面全身标准立绘，建立身份、发型、体型、服装、配色和画风基准。背景简洁，平视，自然站姿，完整可见。
```

#### 阶段 2：视图与表情

```text
使用角色基准图作为唯一身份参考。
视图组：正面、左侧严格 90°、背面，独立输出。
表情组：平静、轻微微笑、惊讶、愤怒；只改变眉眼和嘴部表情，不改变脸型、发型和年龄感。
```

#### 阶段 3：服装与配件细节

```text
生成角色服装的正面结构、背面结构、鞋靴、腰带、包袋和关键纹样细节。保持同一配色、材质和设计语言；每项独立、背景简洁、便于后期排版。
```

#### 阶段 4：排版

在设计软件中统一：格线、标题、角色信息、色卡、箭头和文字标签。

### 五、一次生成草案模板

```text
生成一张角色设定板草案。

角色核心：{年龄、脸型五官、发型、体型、服装、配色、气质}。
版面内容：
- 主图：正面全身标准站姿，占页面约一半；
- 副图 1：左侧严格 90° 全身；
- 副图 2：背面全身；
- 表情：平静、轻微微笑、惊讶；
- 细节：{一个配件或材质特写}。

统一浅灰背景、平视机位、柔和工作室光和{画风}。
格间留白，不添加正式文字和随机标签。
避免跨格换脸、年龄和发色变化、服装主色漂移、比例变化、重复视图和格子重叠。
输出：单张 4:3 草案；生成后逐格验收。
```

### 六、验收清单

- 主图是否足以作为后续身份基准；
- 各视图、表情和细节是否属于同一角色；
- 表情变化是否改变了脸型或年龄；
- 服装正背结构和配件是否互相对应；
- 页面是否有足够留白供后期排字；
- 是否需要拆分失败分区单独重做。

### 七、问题诊断

| 现象 | 原因 | 修复 |
|---|---|---|
| 各格人物不同 | 一次任务过载 | 分离主图、视图、表情和细节 |
| 表情像换脸 | 表情强度过大 | 降低强度，明确只改眉眼和嘴部 |
| 服装正背矛盾 | 背部设计未定义 | 提供正背结构说明或服装参考 |
| 标签乱码 | 让模型负责最终排字 | 只留空位，设计软件排版 |
| 主图不稳定 | 基准角色未先确定 | 先完成单张正面基准图 |

![[03-四格漫画提示词模板-配图-v01.png]]



### 多图一致性提示

> [!tip] 先做锚点图
> 系列图不要每张从零开始。先固定身份、结构、配色、版式或场景基调；出现新服装、新道具或新场景时，先为新元素建立代表图，再批量生成后续画面。

![[多图一致性流程图_先立锚点后生成.png]]

> [!abstract] 定位
> 四格漫画同时包含**连续角色、四个叙事时刻和 2×2 版式**。一次生成可能出现格数错误、换人、重复画面和乱码。高可靠流程是：先写四格脚本 → 生成无字画面 → 必要时逐格修复或独立生成 → 后期加入气泡与文字。

### 一、适用类型

| 类型 | 四格结构 | 适合用途 |
|---|---|---|
| 起承转合 | 引入 → 发展 → 转折 → 结局 | 故事漫画、科普漫画 |
| 同场景序列 | 时间或动作连续推进 | 情绪变化、产品使用流程 |
| 效果对比 | 同一主体的四种变量 | 风格、服装、材质、灯光对比 |
| 教程步骤 | 步骤 1–4 | 操作说明；准确文字后期排版 |

### 二、输入准备

- 固定角色卡：脸型、发型、服装、配色、身体比例；
- 四格脚本：每格只写一个动作和一个叙事功能；
- 场景连续性：时间、天气、道具状态和人物进出方向；
- 对白策略：无字版、只留气泡，或允许草稿级短文字；
- 版式：2×2、格间距、阅读顺序和最终比例。

### 三、五段式四格母版


```text
【任务】
任务类型：{起承转合 / 场景序列 / 效果对比 / 教程步骤}
目标：{四格主题}
每格只改变：{动作、表情、时间或指定变量}

【保持】
跨格保持：{角色身份、服装、场景、画风、光线或商品本体}
参考 R1：负责{角色/商品}
参考 R2：只负责{画风/场景，可选}

【画面】
格 1：{地点、人物位置、动作、表情、景别、叙事功能}
格 2：{同上}
格 3：{同上}
格 4：{同上}
统一风格：{线条、上色、色彩、光影}

【限制】
连续性优先：主体一致 > 格数和阅读顺序 > 动作因果 > 画风 > 装饰
避免：跨格换人、重复画面、格子重叠、角色跨出格线、随机文字

【输出】
版式：2×2 四格，阅读顺序从左到右、从上到下
画幅：{1:1 / 4:5}
文字：{无字 / 只留气泡 / 后期排版}
```

### 四、可直接复制模板

#### 4.1 起承转合无字四格

```text
生成一张 2×2 四格漫画，阅读顺序从左到右、从上到下，不添加任何文字。

固定角色：同一{人物描述}；四格保持同一脸型、发型、服装、身体比例和画风。
固定场景：{地点、时间、天气}。

格 1（起）：{建立人物、地点和事件}；{景别和机位}。
格 2（承）：{人物采取行动，承接上一格}；{景别和机位}。
格 3（转）：{出现意外或信息反转}；{景别和机位}。
格 4（合）：{结果或笑点}；{景别和机位}。

风格：{漫画画法、线条、上色、色彩}。
版式：2×2 等距四格，格间留白，每格独立构图，角色不跨出格线。
避免五格或三格、重复画面、跨格换人、随机文字和错误气泡。
```

#### 4.2 同主体四种效果对比

```text
生成一张 2×2 四格效果对比图。

所有格固定：同一{人物/商品}、同一姿势、同一镜头、同一构图、同一背景和同一主体尺度。
唯一变量：{艺术风格 / 光线 / 材质 / 服装}。
左上：{版本 A}
右上：{版本 B}
左下：{版本 C}
右下：{版本 D}

每格只应用对应变量，不互相混合；不添加标签文字，后期统一标注。
```

### 五、验收清单

- 是否正好四格，顺序清楚且格子不重叠；
- 同一角色或商品是否跨格保持；
- 每格动作是否与上一格存在因果；
- 道具状态、时间和人物进出方向是否连续；
- 对比图是否只改变预设变量；
- 是否需要拆成四张独立图片后重新排版。

### 六、问题诊断

| 现象 | 原因 | 修复 |
|---|---|---|
| 格数错误 | 版式要求与剧情混在一起 | 强化 2×2 和阅读顺序，或逐格生成后排版 |
| 跨格换人 | 角色固定信息不足或变化过多 | 使用统一主参考，减少服装和场景变化 |
| 剧情跳跃 | 每格只有画面描述，没有因果 | 写“上一格结果 → 下一格动作” |
| 对白乱码 | 同时要求复杂图像与准确文字 | 生成无字版，后期添加气泡和文字 |
| 对比变量混合 | 四版差异边界不清 | 固定共同项，每格只写一个变量 |

## 故事板提示词模板

> [!important] 五段式继承
> 本文遵循 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]；外层统一为【任务】【保持】【画面】【限制】【输出】。本页只增加本场景需要的专业字段。


![[04-故事板提示词模板-配图-v01.png]]



### 多图一致性提示

> [!tip] 先做锚点图
> 系列图不要每张从零开始。先固定身份、结构、配色、版式或场景基调；出现新服装、新道具或新场景时，先为新元素建立代表图，再批量生成后续画面。

![[多图一致性流程图_先立锚点后生成.png]]

> [!abstract] 定位
> 故事板由两类资产组成：**视觉关键帧**和**镜头表**。静态图只能表现某个瞬间，不能真正执行“推、拉、摇、移”和时长；运镜应转译为起始帧/结束帧构图，并记录在镜头表中。

### 一、推荐工作流


1. 写场景连续性卡：人物、服装、道具、时间、天气、光线和空间轴线；
2. 写镜头表：镜头号、动作、景别、机位、时长、运镜、声音；
3. 每个镜头提炼一个明确关键时刻；
4. 连续性要求高时逐张生成，使用同一主参考和上一镜头结果；
5. 后期统一加镜头号、箭头、对白和备注。

### 二、输入准备

- 角色与道具状态表；
- 场景平面关系和人物运动方向；
- 每镜头的叙事目的；
- 起始帧、结束帧或单一关键帧；
- 画幅、镜头数量和交付格式。

### 三、五段式故事板母版

```text
【任务】
任务类型：{关键帧组 / 起止帧 / 连续分镜}
目标：{场景与叙事段落}
每帧只表现：{一个明确时刻}

【保持】
跨帧保持：{角色、服装、道具状态、场景、时间、天气、光线方向}
空间轴线：{人物和摄影机位关系}
参考 R1：负责{角色身份}
参考 R2：负责{场景或姿势，可选}

【画面】
镜头 1：{景别、机位、人物位置、动作、视线、叙事信息}
镜头 2：{同上}
……
统一风格：{写实分镜 / 线稿 / 灰阶 / 彩色概念帧}

【限制】
连续性优先：角色与状态 > 空间方向 > 关键动作 > 镜头变化 > 风格
避免：随机换装、道具复原、时间跳变、左右方向混乱、把镜头表文字画进图

【输出】
关键帧：{N} 张独立图片，统一画幅{比例}
镜头表字段：镜头号 | 画面 | 景别 | 机位 | 动作 | 对白 | 时长 | 运镜 | 声音 | 连续性备注
```

|---|---|---|---|---|---|---|---|---|---|
| 01 | {目的} | {瞬间} | {景别} | {机位} | {动作} | {秒} | {运镜} | {内容} | {道具/方向} |

### 五、可直接复制模板

#### 5.1 三镜头连续关键帧

```text
生成三张独立的{16:9 / 9:16}故事板关键帧。

跨镜头保持：同一{角色描述}、{服装}、{道具状态}、{场景}、{时间天气}和{光线方向}。
空间方向：角色从画面左侧进入，最终向画面右后方离开；背景地标位置保持合理。

镜头 1：{中景，平视}，角色{动作}，位于{画面位置}，视线朝{方向}。
镜头 2：{中近景，微仰}，角色{动作}，道具状态为{状态}。
镜头 3：{远景，微俯}，角色{动作结果}，运动方向延续前两镜头。

每张只表现一个明确时刻；统一{写实电影/灰阶线稿}风格。
不要添加镜头号、对白、时长、运镜箭头或随机文字。
```

#### 5.2 推近镜头的起止帧

```text
生成同一镜头的起始帧和结束帧，两张独立图片。

固定：同一角色、表情变化逻辑、场景、光线、摄影机轴线和画幅。
起始帧：{中景}，角色位于{位置}，环境信息较多。
结束帧：{近景}，摄影机沿同一轴线推近，角色面部和关键动作更突出；背景关系不跳变。

不要把“推镜头”画成速度线，不随机改变人物姿势、机位方向和环境结构。
```

### 六、验收清单

- 每帧是否只表达一个明确叙事时刻；
- 人物、服装、道具和伤痕等状态是否延续；
- 左右方向、视线、入口和出口是否连贯；
- 景别变化是否服务叙事，而非随机变化；
- 起止帧是否保持同一摄影机轴线；
- 镜头表的时长、运镜和对白是否与图像分离维护。

### 七、问题诊断

| 现象 | 原因 | 修复 |
|---|---|---|
| 各帧角色不同 | 一次组图要求过多 | 逐张生成，使用同一主参考和状态卡 |
| 左右方向混乱 | 未定义空间轴线 | 写人物入画、出画、视线和地标位置 |
| 运镜不可见 | 将视频术语直接当静态画面 | 生成起止帧并在镜头表记录运镜 |
| 道具状态跳变 | 未维护连续性 | 增加状态字段，逐镜头验收 |
| 对白乱码 | 让模型排复杂文字 | 后期排版，图内不生成正式文字 |

## 对比图提示词模板

> [!important] 五段式继承
> 本文遵循 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]；外层统一为【任务】【保持】【画面】【限制】【输出】。本页只增加本场景需要的专业字段。


![[05-对比图提示词模板-配图-v01.png]]


> [!abstract] 定位
> 对比图的核心不是“一张图里放很多漂亮版本”，而是建立**共同基准 + 唯一变量**。只有其他条件尽量一致，才能判断风格、材质、光线或提示词修改真正带来的差异。

### 一、适用类型

- 半写实动漫细分风格对比；
- 同一人物服装、发型或妆容对比；
- 商品材质、背景或布光对比；
- 场景时间、天气和色调对比；
- 提示词 A/B 测试结果展示。

### 二、输入准备

1. 明确唯一测试维度；
2. 写共同基准：主体、姿势、表情、镜头、构图、背景、光线或材质；
3. 每个版本用同一颗粒度描述，避免 A 写得很细、B 只写一个词；
4. 决定独立输出还是拼版；实验分析优先独立输出，展示汇报可后期拼版。

### 六、标注系统规范


#### 圈注和连线

- 圈只包围需要观察的局部，不要圈住整张图。
- 连线尽量短，避免交叉；一条线只对应一条说明。
- 局部过小时使用放大框，不要靠超长文字描述。
- 同一页面中，圈、线、箭头的粗细和颜色规则保持一致。

#### 文案层级

```text
主标题：这张图讲什么
副标题：为什么要看这张图
卡片标题：术语 / 步骤 / 选项
白话说明：它是什么
关键特征：看哪里
底部总结：怎么选 / 一句话记忆
```

#### 文字准确性

图像模型生成中文可能出现错字、断字和版式漂移。正式使用时建议：

1. 先生成无字或少字版示例图；
2. 在设计软件中覆盖正式文字；
3. 对所有编号、箭头、圈注和术语逐项验收；
4. 不把模型生成的小字直接视为可发布终稿。

### 七、验收清单

- [ ] 一眼能看出主题和阅读顺序。
- [ ] 每个示例只改变目标变量。
- [ ] 圈注、连线和文字指向正确。
- [ ] 示例图与说明文字互相对应。
- [ ] 卡片数量适中，没有一页塞入过多知识点。
- [ ] 中文术语、编号和标点已人工复核。
- [ ] 底部有明确的选择方法或记忆口诀。
- [ ] 图片路径适合嵌入 Markdown 笔记。

### 八、问题诊断

| 问题 | 原因 | 修复方式 |
|---|---|---|
| 圈注指错位置 | 一次要求过多标注 | 减少每格标注数量，分两张生成 |
| 各格主体不同 | 没有固定共同参考 | 先生成锚点图，各格明确“同一主体” |
| 对比不公平 | 同时改变多个变量 | 固定构图、服装、光线，只改变目标术语 |
| 文字不可读 | 一页信息过载 | 缩减条目，重要文字后期排版 |
| 流程箭头混乱 | 多条路径同时出现 | 规定单一阅读方向，复杂流程拆成决策图 |
| 画面像普通海报 | 缺少知识结构 | 明确示例区、圈注区、判断栏和底部口诀 |


### 九、子标题教学图模板

> [!abstract] 定位
> 子标题教学图不是整篇笔记的封面，而是紧跟某个二级或三级标题，用一张图解决该小节最难理解的一个问题。它应当**范围小、信息密度适中、与上下文强绑定**。

#### 9.1 什么时候需要子标题教学图

- 概念之间容易混淆，例如景别与焦距、焦点与景深；
- 文字需要反复解释空间关系、流程或先后顺序；
- 同一主体存在多种视觉差异，适合 A/B 或多格对照；
- 需要指出局部细节，适合圈注、连线或放大框；
- 表格信息很多，但小白仍难以形成视觉印象；
- 小节包含操作步骤、判断条件或失败修复路径。

## 教学图设计方法

> [!important] 五段式继承
> 本文遵循 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]；外层统一为【任务】【保持】【画面】【限制】【输出】。本页只增加本场景需要的专业字段。


![[07-教学图设计方法-配图-v01.png]]


### 图解总览

![[教学图设计_五步法.png]]


> [!abstract] 核心定位
> 教学图不是"正文配图"，而是一个**降低理解难度、引导注意力、展示关系或演示过程的教学工具**。它服务于单一学习目标，图片负责展示关系，正文负责完整解释。

### 一、核心原则（研究结论 → 设计原则）

基于学习科学研究的六条原则，每一条都直接约束教学图的设计决策：

| # | 研究结论 | 设计原则 |
|---|---|---|
| 1 | **图片必须承担明确功能**：精心设计的插图提高理解与记忆，装饰性图片帮助有限 | 每张图回答一个明确的学习问题；不做装饰性配图 |
| 2 | **视觉信号有效但有上限**：圈注、箭头、颜色提示能引导注意，标注过多反而失效 | 圈注克制，只标关键区域；一张图标注 3–6 个观察点 |
| 3 | **文字靠近对应画面**：图文分离增加认知负担（重要原则而非绝对规律） | 说明文字放图内对应位置，长解释放正文 |
| 4 | **去掉不服务学习目标的装饰**：一致性原则——删除无关内容优于添加装饰 | 只保留服务本图学习目标的元素 |
| 5 | **小白更需要完整示范**：完整案例（需求→步骤→成品）比抽象规则更有效 | 优先做"需求→五段式→最终提示词→检查表"的完整示范图 |
| 6 | **多张图不等于更好**：多表现只有各担其职且读者理解对应关系才有价值 | 控制总量，每图独立功能，不堆叠重复图 |

> [!important] 对知识库的最直接启示
> 当前已有较多"术语对比图"和"流程总览图"，**真正最值得增加的是：完整示范图和错误诊断图**——从实际任务到最终提示词的完整教学案例，以及"为什么翻车、应该改哪里"的诊断。

### 二、八类教学图

| 教学图类型 | 解决的问题 | 适合的知识库内容 |
|---|---|---|
| **标注示意图** | "这个词具体指哪里？" | 景别、人物角度、材质、光影、构图 |
| **同条件对比图** | "两个概念到底差在哪？" | 焦距、景深、风格、柔光与硬光 |
| **流程图** | "应该按照什么顺序做？" | 图生图、扩图、多图一致性、迭代流程 |
| **决策图** | "我该选择哪个模板？" | 七类场景、平台选择、任务类型 |
| **结构关系图** | "这些概念是什么关系？" | 五段式、七维诊断、提示词层级 |
| **完整示范图** | "规则实际怎么使用？" | 需求 → 槽位填写 → 最终提示词 → 结果 |
| **错误诊断图** | "为什么翻车，应该改哪里？" | 换脸、姿势漂移、结构错误、材质失真 |
| **速查卡** | "使用时快速查什么？" | 比例、尺寸、平台参数、镜头术语 |

### 三、知识库教学图精简规划（约 27 张）

> [!warning] 不建议扩展到 46 张
> 教学图规划应以"每张图只回答一个学习问题"为准，不是图越多越好。建议收敛到约 **27 张有效教学图**。

| 类别 | 数量 | 内容 |
|---|---|---|
| **专业词典主图** | 9 张 | 每词典一张（同主体展示术语差异：景别/人物角度/焦距/景深/构图/光影/材质/风格/画幅） |
| **提示词核心结构图** | 3 张 | 五段式结构图（已有）、提示词顺序与优先级图、完整填写示范图 |
| **场景迷你案例卡** | 7 张 | 每类场景一张小型完整示范卡 |
| **特殊形态示范图** | 4 张 | 视图/角色设定图/四格漫画/故事板各一张 |
| **失败诊断与实验图** | 4 张 | 图生图失败诊断、多参考冲突诊断、A/B 单变量实验、失败诊断方法 |

#### 3.1 优先新增的六类图（★）

1. **提示词顺序与权重**：任务目标→本轮变化→保持项→目标画面→冲突规则→输出规格；并标注"前置≠固定权重、逻辑优先级≠平台参数、重复三次≠权重增加"。
2. **五段式完整填写案例**：一个实际任务（如"保持人物不变，换成黑色礼服"）展示 原始需求→五段式填写→完整提示词→生成结果检查表。
3. **图生图失败诊断**：现象→可能原因（参考职责冲突/改变项过多/身份要求过晚/风格覆盖身份）→调整动作。
4. **多参考图冲突诊断**：R1 身份被 R2/R3 覆盖时如何排查、如何减参考。
5. **七类场景迷你案例**：每类场景一张小型完整示范卡（不是整页海报）。
6. **A/B 单变量实验**：核心目标前置 vs 末尾的对比，比较身份保持/目标完成度/结构准确性/风格一致性。

#### 3.2 各模块规划要点

**① 提示词模板主文件（保留 3 张核心图）**
- 五段式结构图：已有，保留。
- 提示词顺序与优先级图：**新增**，展示填写顺序 + 三个"不等于"警示。
- 完整填写示范图：**新增**，用实际任务展示 需求→五段式→完整提示词→检查表。

**② 专业名词词典（每词典 1 张主图）**
- 各词典保留一张"同主体不同条件"的效果图即可。
- **不建议**给每个小标题都生成一张图——同一概念被拆散，读者需多图间来回比对。

**③ 七类场景模板（不需要 7 张复杂海报）**
- 一张"七类场景选择图"（已有）。
- 每类场景加一张**迷你完整示范卡**。例（人物视觉）：
  ```text
  任务：人物身份保持换装
  固定：人物脸部和原姿势
  变化：黑色连衣裙
  画面：室内自然光、半身
  规则：身份 > 结构 > 服装 > 背景
  输出：3:4 单图
  ```
  商品视觉则换成商品换景示范。

**④ 平台差异（只画稳定结构，不画易变参数）**
- 图片只表达相对稳定的结构：四个入口各自"适合什么"。
- 具体模型名称、尺寸、格式、参考图数量等易变信息放正文，并标注更新时间。

**⑤ 实验与迭代层（最适合研究型图片）**
- A/B 对比图、单变量实验图、失败诊断图——既是教学材料，也是实测证据。

### 四、圈注与标注规范

圈注、箭头、颜色提示属于学习研究中的**视觉信号提示**。统一规范：

| 元素 | 用途 |
|---|---|
| **圆圈** | 指出具体观察区域 |
| **引线** | 连接区域与说明 |
| **箭头** | 表示方向、顺序或变化 |
| **虚线** | 表示构图线、边界或不可见关系 |
| **颜色** | 区分不同概念类别 |
| **编号** | 表示阅读或操作顺序 |

#### 一张图的标注层级

```text
标题
一句话学习目标
示例画面
局部圈注
短说明
底部判断口诀
```

#### 标注说明要短

- 推荐："背景压缩更明显""面部透视更自然"
- 不推荐："使用较长焦距会让背景在空间视觉关系上产生明显压缩……"
- **长解释放 Markdown 正文，不塞进图片。**

### 五、AI 生成流程（人工校验五步法）

> [!important] 教学图是"正确性敏感内容"
> 中文文字、数字参数、比例尺寸、流程顺序、箭头对应、人体角度、光线方向、焦距透视、平台功能——这些都可能出错。**完全依赖生成前提示词，可预测性和正确性较弱**；生成后的直接检查与修改比生成前堆词更可靠。

```text
第一步：AI 生成无文字或少文字的视觉底图
第二步：人工核对概念和视觉关系
第三步：在 Figma / Canva / PowerPoint 中添加中文标注
第四步：检查圈线、箭头和说明是否一一对应
第五步：再嵌入 Markdown 笔记
```

> 比让图像模型一次性生成全部中文长文案更可靠。
