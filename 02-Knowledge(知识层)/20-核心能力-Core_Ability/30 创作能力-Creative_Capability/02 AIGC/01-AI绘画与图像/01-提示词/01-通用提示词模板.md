# 通用提示词模板

> [!info] 合并说明
> 本文由原拆分笔记合并而成；原文件保留在维护区的历史版本中，本文为当前唯一权威正文。

## 最小可用提示词模板

> [!important] 当前权威模板
> 本文是提示词层的**唯一外层母版**。最新可用模板、模板库、平台适配和后续新增模板必须能够映射到【任务】【保持】【画面】【限制】【输出】五段，不再另建平行主结构。

### 一、使用说明

简单任务优先使用以下五段。
没有参考图时删除“参考图职责”；没有特殊限制时删除“限制”部分。

### 二、五段式模板

```text
【任务】
任务类型：{生成 / 编辑 / 扩图 / 局部重绘 / 风格转换}
目标：{一句话说明本轮要完成什么}
只改变：{本轮允许变化的内容}

【保持】
保持不变：{人物身份 / 年龄感 / 脸型五官 / 商品结构 / 姿势 / 构图 / 背景等}
参考图职责：{参考图1负责身份，参考图2负责姿势，参考图3负责服装等；无参考图则删除}

【画面】
主体与动作：{谁，以什么姿势，在做什么}
场景与风格：{所在环境、服装、材质、视觉风格}
镜头与光线：{景别、拍摄角度、构图、焦段感、光线氛围}

【限制】
避免：{最可能出现的1–4个问题}
优先级：发生冲突时，优先保证{人物身份 / 商品结构 / 指定动作 / 画面完整性}

【输出】
数量：{1张 / 4张}
比例：{1:1 / 3:4 / 9:16 / 16:9}
要求：{全身完整 / 无文字 / 无水印 / 独立构图 / 对比版式}
用途：{头像 / 海报 / 电商图 / 视频首帧 / 风格测试}
```

### 三、删减规则

| 情况 | 可删除或简化 |
|---|---|
| 从零生成且无参考图 | 删除“参考图职责”；“保持不变”可改为核心主体要求 |
| 极简灵感图 | 保留【任务】【画面】【输出】即可 |
| 没有明确失败风险 | 删除整段【限制】 |
| 局部编辑 | 【任务】写明编辑区域，【保持】写明非编辑区 |
| 多参考融合 | 【保持】必须为每张参考图分配唯一职责 |
| 批量或连续资产 | 五段不变，在各段增加系列统一项和验收条件 |

### 四、继承关系

- **任务模板**：替换任务类型和变化范围，不改变五段顺序。
- **用途模板**：在【保持】与【画面】中增加人物、商品、建筑等专业字段。
- **输出模板**：主要扩展【输出】中的版式、视图和交付要求。
- **平台适配**：只调整表达方式和参数，不改变五段语义。
- **风格专题**：作为【画面】中的“场景与风格”模块插入，不另起完整母版。
- **限制词库**：只向【限制】提供与当前失败问题对应的少量条目。

### 五、旧标签迁移

| 旧标签 | 当前统一标签 |
|---|---|
| 任务与变化范围 | 【任务】 |
| 保留项与参考职责 | 【保持】 |
| 目标画面设计 | 【画面】 |
| 控制规则 / 避免 | 【限制】 |
| 输出规格 | 【输出】 |

### 三、判断操作与控制难度

#### 1. 操作方式

| 操作 | 保持什么 | 改变什么 |
|---|---|---|
| 文生图 | 文字定义的核心主体 | 整张画面 |
| 图生图 | 参考图指定的内容 | 指定变量 |
| 局部编辑 | 非编辑区域 | 蒙版或指定区域 |
| 扩图 | 原图内部 | 画布外区域 |
| 主体替换 | 姿势、构图或场景 | 人物或商品身份 |
| 风格转换 | 身份、结构、构图 | 媒介、渲染和色彩处理 |
| 批量变体 | 系列统一项 | 每张指定变量 |

#### 2. 控制难度

| 等级 | 适用情况 | 提示词与流程要求 |
|---|---|---|
| **L1 自由创意** | 氛围正确即可 | 主体、场景、风格、画幅 |
| **L2 单主体** | 单人物、单商品、单空间 | 补充结构、镜头和重点细节 |
| **L3 参考一致性** | 同人换装、商品换景 | 明确主参考、保留项和修改项 |
| **L4 多参考融合** | 脸、姿势、服装分别参考 | 为每张参考分配唯一职责 |
| **L5 连续资产** | 三视图、连续角色、批量商品 | 分步生成、局部修复、验收与归档 |

> [!important]
> 难度越高，不代表提示词应无限加长。L4–L5 更依赖参考图质量、区域控制、分步编辑和后期修复。

```text
【任务】→【保持】→【画面】→【限制】→【输出】
```

简单任务可以删除空段，但不另起平行结构。

### 五、风格添加与替换

基础提示词负责“画什么”，风格模块负责“怎样呈现”。

- **添加风格**：在画面段加入一个风格模块。
- **替换风格**：先删除旧媒介、渲染、笔触和色彩描述，再加入新风格。
- **继续保持**：主体身份、动作、服装结构、构图和画幅通常不随风格替换。
- **避免堆叠**：不要同时添加摄影、油画、动漫、3D 等互相冲突的完整风格。

### 七、生成后的快速验收

依次检查：

1. **主体是否正确**：人物身份或商品结构是否改变；
2. **变化范围是否正确**：是否改动了不应修改的区域；
3. **结构是否正确**：人体、透视、比例和遮挡是否合理；
4. **画面是否正确**：构图、镜头、光线和色彩是否符合目标；
5. **输出是否可用**：比例、裁切、留白、文字区域和文件规格是否满足用途。

> [!warning] 不要过度工程化
> 普通文生图通常只需要主体、场景、风格、镜头和画幅。身份保持、多参考融合、局部编辑或批量生产时，再增加参考职责、优先级和验收条件。
