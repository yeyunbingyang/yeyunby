# 即梦平台提示词总结

> [!abstract] 一句话结论
> 即梦优先吃清晰的中文视觉描述，核心是「主体＋风格＋镜头＋光影＋色彩＋材质」的排列组合；质量词（8K、32K、超高清）只是语义期待，真实分辨率、比例、模型用界面参数控制；多种风格混用时必须声明每种风格负责哪个层面，否则会产生风格冲突。

> [!info] 本文定位
> 本篇是即梦提示词写作要点的浓缩总结，可作快速查阅入口。统计证据与八类模板见 [[08-即梦热门图片提示词调研]]；执行模板、智能画布与多图参考见 [[05-GPT与即梦平台适配]]；逐条原始提示词见 [[09-即梦热门图片提示词案例集]]。

## 一、核心原则

1. **中文为主，术语按需补充**：中文已明确时，不要为“模型识别”堆英文同义词；英文只在镜头、材质或特定艺术媒介更精准时补充。
2. **五段式母版**：所有提示词统一继承 `【任务】【保持】【画面】【限制】【输出】`，即梦只改表达方式和参数，不改语义。
3. **提示词层与参数层分离**：模型、比例、质量、超清在界面选；提示词只写视觉任务。
4. **限制项单独写**：有独立负面词框就放少量排除项；没有就在正文写“不要”，不要附加长串英文负面词。

## 二、推荐写作顺序

【画面】段：

```text
主体与行为 → 环境与空间 → 风格与媒介 → 色彩与光影 → 镜头与构图 → 材质与细节 → 保持与避免 → 输出用途
```

## 三、高频有效表达

光影、构图、超高清、写实、特写、8K、发丝、插画、皮肤、古风、电影级、广角、32K、国风、低饱和。

复用要点：

- 从可观察主体开始（年龄感、服装、发型、材质、动作）；
- 镜头信息成组合：景别＋机位＋焦段/透视＋景深；
- 光影与材质配对：侧光塑造皮肤/丝绒/金属/玻璃；
- 色彩建立主次：主色＋辅色＋饱和度＋冷暖；
- 风格混合声明职责（见下方专题）。

## 四、常见问题

1. **同义质量词重复堆叠**：只加字数，不加约束。
2. **抽象词过多**：“高级、惊艳、氛围感、宿命感”这类词可验收信息不足。
3. **风格冲突**：同时要求写实、动漫、油画、CG、摄影却不说明各自作用（详见下方专题）。
4. **长度与互动不呈正相关**：高互动组平均提示词反而更短，信息密度比总字数更重要。

## 五、专题：风格冲突（重点）

### 问题本质

把“写实、动漫、油画、CG、摄影、厚涂、赛璐璐”当作平行风格词一股脑堆进去，模型不知道哪个是基调、哪个只负责局部，于是把互斥特征随机混合——例如真人脸配厚涂描边、油画笔触配摄影浅景深、CG 材质配手绘线条，最终画面不伦不类。

### 正确做法：给每种风格分配职责

写一个**主风格定基调**，其余风格词各负责一个**具体层面**，用“＋”连接。

| 层面 | 可交给哪种风格 |
|---|---|
| 皮肤 / 材质 | 写实：真实皮肤纹理、发丝 |
| 轮廓 / 边缘 | 厚涂：清晰描边、笔触 |
| 光影 | CG：体积光、渲染质感 |
| 构图 / 景深 | 摄影：电影机位、浅景深 |
| 配色 | 动漫：高饱和、赛璐璐色块 |

### 正反示例

反例（风格冲突）：

```text
写实，动漫，油画，CG，摄影，厚涂，赛璐璐，半写实……
```

正例（职责清晰）：

```text
半写实动漫，保留真实面部比例，自然皮肤纹理，真实发丝，
柔和电影侧光，浅景深。
```

正例拆解：「半写实动漫」定基调；「真实面部比例、皮肤纹理、发丝」由写实负责；「电影侧光、浅景深」由摄影负责。

再一例：

```text
真人皮肤＋厚涂边缘＋CG 光影
```

皮肤写实、边缘厚涂、光影 CG，三种媒介各管一摊，不打架。

### 判断自己有没有写对

写完读一遍，看每个风格词后面能不能补上“负责什么”：

- 能补 → 职责清楚，保留；
- 补不出来 → 要么删除，要么改成可观察描述。

## 六、两个入口要分开

| 需求 | 入口 | 提示词特点 |
|---|---|---|
| 从零生成完整画面 | 图片生成 / 智能参考 | 完整中文画面描述，多图参考逐张声明职责 |
| 局部重绘 / 消除 / 扩图 / 融合 / 抠图 | 智能画布 | 短而精确的区域指令，不粘贴长母版 |
