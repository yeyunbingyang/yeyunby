# 即梦热门图片提示词调研

> [!abstract] 一句话结论
> 2026-08-11 的 300 个公开案例显示，即梦自然推荐流主要依赖“主体＋风格＋镜头＋光影＋色彩＋材质”的中文描述；84% 使用 9:16，题材在扩充采样后明显分散，高互动样本的提示词仍比普通样本短，堆词不是效果或传播的充分条件。

完整原图、提示词和作品字段见 [[09-即梦热门图片提示词案例集]]。

## 调研方法

- 来源：即梦 AI 首页“发现”瀑布流公开作品。
- 时间：2026-08-11，横截面采样，不代表长期榜单。
- 样本：首批逐项打开作品详情，扩充批按首页自然推荐流的公开分页与预载顺序采集；只保留同时具有图片、完整提示词、模型和画幅的案例，按图片资源 ID 去重，最终得到 300 条有效记录。
- 批次：编号 001–100 为首批，101–300 为扩充批；扩充批保持自然推荐顺序，没有定向补齐类别。
- 保存：原始提示词不改写；图片下载到本地；分类与结构字段由关键词规则辅助统计后人工解释。
- 边界：社区展示能说明表达趋势，不能证明某个词对生成效果具有因果作用；互动量也会受到作者、发布时间、推荐机制和题材影响。

9:16 的绝对优势与人物、古风角色和移动端内容消费高度一致。商品方图、头像或版式实验才较多使用 1:1、2:3 等比例。

- 平均长度：311 字符；最短 43，最长 1541。

- 这组样本不支持“提示词越长，互动越高”；有效信息密度和视觉概念可能比总字数更重要。

> [!warning] 质量词的使用边界
> “8K、32K、超高清、杰作”在社区提示词中非常常见，但它们只是语义期待。实际分辨率、质量和画幅仍应使用即梦界面参数控制，不能把这些词当成技术参数。

## 提示词结构覆盖率

| 模块 | 覆盖案例数 | 覆盖率 |
|---|---:|---:|
| 风格与媒介 | 250 | 83.3% |
| 质量词 | 225 | 75% |
| 镜头与构图 | 215 | 71.7% |
| 场景与环境 | 208 | 69.3% |
| 光影 | 195 | 65% |
| 材质与肌理 | 193 | 64.3% |
| 色彩 | 182 | 60.7% |
| 主体显式描述 | 163 | 54.3% |
| 动作或姿态 | 77 | 25.7% |
| 限制与排除 | 18 | 6% |

社区提示词的常见顺序可以概括为：

```text
主体与身份 → 外观与服装 → 动作 → 场景 → 风格与媒介
→ 镜头与构图 → 光影与色彩 → 材质细节 → 质量期待 → 少量限制
```

与知识库现行五段式相比，社区案例普遍重视【画面】，但较少明确【任务】【保持】【限制】【输出】。这适合一次性灵感生成，不适合需要身份一致、精确编辑或稳定复现的生产任务。

## 优秀模式与常见问题

### 值得复用的模式

1. **从可观察主体开始**：年龄感、服装、发型、材质和动作比抽象气质更容易验收。
2. **镜头信息形成组合**：景别＋机位＋焦段或透视＋景深，比只写“电影感”更明确。
3. **光影与材质配对**：侧光塑造皮肤、丝绒、金属、玻璃等具体材质，而不是独立堆光效词。
4. **色彩建立主次**：主色、辅助色、饱和度和冷暖关系共同限定画面。
5. **风格混合说明职责**：例如“真人皮肤＋厚涂边缘＋CG 光影”，明确每种媒介负责什么。
6. **用空间关系制造叙事**：巨物与渺小人物、前景遮挡、雾层和纵深比单纯“史诗感”更可见。

### 常见问题

- 同义质量词重复堆叠，增加长度却没有新增约束。
- “高级、惊艳、氛围感、宿命感”等抽象词过多，可验收信息不足。
- 同时要求写实、动漫、油画、CG、摄影，却不说明各自作用，容易产生风格冲突。
- 大多数案例没有明确“不要什么”和冲突优先级，生产时容易出现结构漂移。
- 提示词写了 8K、32K，却没有把比例、模型和输出质量作为独立参数记录。
- 社区作品只展示成功结果，无法看到失败样本、筛选次数和后期处理，存在幸存者偏差。

## 八类可复用模板

以下模板继承 [[01-通用提示词模板|统一五段式提示词模板]]，不是新的平行母版。

### 1. 人物特写

```text
【任务】生成用于{头像/写真/海报}的人物特写。
【画面】{年龄感与身份}，{脸型、五官、发型、服装和配饰}；{表情与视线}。{近景/特写}，{平视/俯拍/仰拍}，{焦段或透视}，{浅景深与背景}。使用{主光方向与光质}塑造{皮肤、发丝、布料}，整体{主色、冷暖、饱和度}。
【限制】避免面部畸变、过度磨皮、首饰融合和无关文字。
【输出】{比例}，主体边缘完整，用于{用途}。
```

### 2. 古风角色

```text
【任务】生成{朝代/世界观}的古风角色。
【画面】{身份与年龄感}，身着{服装形制、主色、面料、传统纹样}，佩戴{发饰与配饰}，做出{动作}；场景为{建筑/山水/室内}。{景别与机位}，{国风写实/水墨/厚涂}，{光线与雾气}，突出衣料垂坠、发丝和传统工艺细节。
【限制】避免现代服装、错误文字、朝代元素无序混搭和肢体畸形。
【输出】9:16，角色完整，服装结构可辨。
```

### 3. 幻想概念场景

```text
【任务】生成具有叙事焦点的幻想概念图。
【画面】核心奇观为{巨型生物/遗迹/机甲/异象}，人物位于{位置}作为尺度参照；前景{元素}、中景{行动}、远景{环境}形成纵深。使用{广角/低角度}和{非对称/中心}构图，{主色与补色}，{轮廓光、雾层、体积光}塑造空间。
【限制】避免主体尺度不清、背景元素平均用力和视觉焦点分散。
【输出】{9:16/16:9}，保留叙事路径和清晰轮廓。
```

### 4. 商业产品

```text
【任务】为{产品}生成{电商主图/广告/社交媒体}视觉。
【保持】产品外形、结构、品牌色和包装布局保持。
【画面】产品位于{台面与位置}，搭配{少量道具}；{正面/45度/俯拍}，{焦段与构图留白}。使用{柔光箱/侧逆光/轮廓光}突出{玻璃、金属、织物、液体}材质，背景为{色彩与渐变}。
【限制】避免改变产品结构、伪造文字、增加无关配件和遮挡卖点。
【输出】{比例}，预留{文案位置}；准确 Logo 与文字后期合成。
```

### 5. 角色三视图

```text
【任务】生成同一角色的标准三视图设定表。
【保持】三个视角中的身份、身体比例、发型、服装结构、配色和配饰完全一致。
【画面】纯色无影背景，依次并排：正面全身、90°侧面全身、背面全身；标准站姿，正交视图，同一缩放比例和基线。
【限制】避免透视夸张、视角遗漏、服装变化、人物裁切、文字和装饰背景。
【输出】横版，三个人物完整且互不遮挡，用于角色建模与生产参考。
```

### 6. 动漫插画

```text
【任务】生成{用途}的动漫插画。
【画面】{角色外观与动作}，位于{场景}；采用{赛璐璐/厚涂/绘本/日系}表现，线条负责{轮廓职责}，上色负责{体积职责}。{景别、机位、动态构图}，{主色、辅色、强调色}，{光线和特效}围绕视觉焦点展开。
【限制】避免风格混杂、手部畸形、无意义特效和背景抢主体。
【输出】{比例}，轮廓清晰，适配{封面/立绘/分镜}。
```

### 7. 空间建筑

```text
【任务】生成{建筑/室内空间}概念视觉。
【画面】空间功能为{用途}，布局包含{主要区域与动线}；材质为{墙面、地面、家具、玻璃、金属}，风格为{现代/侘寂/未来/传统}。使用{广角焦段与视点高度}，保持垂直线，{自然光与人工光}共同塑造层次，配色为{主色体系}。
【限制】避免尺度失真、家具悬浮、透视线冲突、过度广角和通道阻塞。
【输出】16:9 或 3:2，空间结构完整，关键功能区可辨。
```

### 8. 暗黑电影感

```text
【任务】生成具有明确叙事事件的暗黑电影画面。
【画面】{人物/生物}正在{可观察动作}，环境为{地点、时间、天气}；{低角度/侧面/远景}构图，以{前景遮挡和空间层次}建立压迫感。低饱和{主色}，少量{强调色}；使用{伦勃朗光/轮廓光/顶光}，保留深黑阴影、局部高光、薄雾和胶片颗粒。
【限制】避免整体发灰、无焦点、局部过曝、装饰元素堆满和暗部完全丢失。
【输出】{比例}，主体轮廓可辨，明暗层级清楚。
```

## 实践建议

1. 先从案例集中选择与任务最接近的 3–5 条，拆解成主体、场景、镜头、光影、色彩和材质模块。
2. 删除重复质量词，把篇幅换成可观察细节、保持项和失败限制。
3. 比例、模型和质量在界面设置；提示词只负责视觉语义。
4. 一次只测试一个主要变量，保留模型、比例、参考图和提示词版本。
5. 社区提示词先作为灵感假设；经过自己的 A/B 测试后，稳定规律再进入 [[04-实验与结论/01-实验方法与模板|实验与结论]]。
