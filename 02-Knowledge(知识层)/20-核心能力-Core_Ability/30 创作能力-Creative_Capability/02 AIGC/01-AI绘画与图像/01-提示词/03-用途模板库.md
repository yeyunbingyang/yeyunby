## 人物创作提示词模板

> [!important] 五段式继承
> 本文遵循 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]；外层统一为【任务】【保持】【画面】【限制】【输出】。本页只增加本场景需要的专业字段。


![[01-人物创作提示词模板-配图-v01.png]]


> [!abstract] 定位
> 人物任务的核心是先区分：**从零设计一个人**，还是**编辑同一个人**。前者需要明确可观察的人物设定；后者需要明确主身份参考、编辑范围和允许自然适配的交界区域。

### 一、先选择任务


![[人物视觉_五槽位完整示范.png]]

| 子任务 | 必须保持 | 主要改变 | 推荐流程 |
|---|---|---|---|
| 从零创作 | 人设中的核心特征 | 整张画面 | 先确定身份特征，再补服装、场景和镜头 |
| 身份保持 | 脸型、五官比例、年龄感、发型轮廓 | 场景、服装、姿势或风格 | 清晰单一主参考，减少同时变化维度 |
| 换装 | 身份、姿势、构图、背景 | 服装与配饰 | 只编辑服装区域，允许领口、袖口、阴影适配 |
| 姿势/表情 | 身份与服装 | 骨架、动作或表情 | 姿势参考只负责姿势，不负责身份与体型 |
| 风格转换 | 身份、姿势、构图 | 媒介、线条、材质、光影 | 写明风格化程度，不只写风格名称 |
| 角色资产 | 身份、人设、服装、配色 | 角度、表情、动作 | 分视图生成优先于一次复杂拼版 |

### 二、输入准备

- **主身份参考 R1**：脸部无遮挡、清晰、表情不过度夸张；
- **辅助参考**：只有在确有必要时再加入姿势、服装或风格参考；
- **身份摘要**：只记录能确认且有辨识价值的脸型、眼型、鼻唇、年龄感、发型轮廓和显著特征；
- **变化清单**：写清本轮改什么，并删除不需要改变的维度；
- **输出用途**：头像、全身角色图、宣传图、角色设定或视频首帧。

> [!warning]
> “完全锁脸”“100%一致”“像素级保持”不是可靠提示词承诺。高一致性依赖清晰参考、有限变量、局部编辑、连续验收和必要的后期修复。

### 三、五段式人物母版


```text
【任务】
任务类型：{文生图 / 参考图编辑 / 局部编辑 / 风格转换}
本轮目标：{生成或修改什么}
只改变：{单一变量或相容变量组}

【保持】
保持：{人物身份、年龄感、脸型五官、发型、体型、姿势、构图等}
参考 R1：负责{人物身份}
参考 R2：只负责{姿势 / 服装 / 风格，可选}

【画面】
人物：{年龄段、身份特征、气质}
动作与表情：{姿势、手部、视线、表情强度}
服装与配饰：{款式、颜色、材质、结构}
环境：{地点、时间、背景}
风格：{摄影 / 半写实动漫 / 插画 / CGI}
镜头：{景别、机位、角度、构图、镜头感}
光线与质感：{光向、色调、皮肤、发丝、布料}

【限制】
优先顺序：人物身份 > 人体结构 > 本轮修改目标 > 材质 > 场景
必须保持：{关键保持项}
允许适配：{衣领、发丝边缘、接触阴影等}
避免：{与当前任务相关的少量风险}

【输出】
数量：{N}
画幅：{比例}
版式：{单图 / 设定板 / 表情板}
用途：{交付场景}
```

### 四、可直接复制模板

#### 4.1 从零生成人物

```text
【任务】
任务类型：人物文生图。
目标：设计一名{人物定位}，用于{用途}。

【保持】
核心人设固定为：{年龄段、脸型、五官、发型、体型、气质}。

【画面】
人物：{具体可观察的人物特征}。
服装：{款式、颜色、材质、层次}。
动作与表情：{姿势、手部位置、视线、表情}。
环境：{地点、时间、背景元素}。
风格：{主风格 + 风格化程度}。
镜头：{景别}，{机位}，{人物朝向}，{构图}。
光线与质感：{光线方向与光质}，自然皮肤纹理，清晰发丝，真实服装褶皱。

【限制】
优先保证人物结构、脸部协调和姿势自然。
避免幼化或老化、错误肢体、多余手指、不合理遮挡、随机文字和水印。

【输出】
单张，{画幅}，{用途}。
```

#### 4.2 身份保持换装

```text
编辑人物参考图，只更换服装与指定配饰。

【任务】
只改变：服装、配饰以及与服装接触区域的自然阴影。

【保持】
参考 R1 只负责人物身份。
尽量保持 R1 的脸型、五官比例、年龄感、肤色、发型轮廓、表情、姿势、头部角度和身体比例。

【画面】
新服装：{服装结构、长度、颜色、材质、细节}。
新配饰：{配饰，可选}。
保持原图镜头、构图、背景、色调和光线方向。
服装褶皱、袖口、领口、腰线和接触阴影应符合原姿势。

【限制】
人物身份 > 人体结构 > 新服装完整度 > 材质 > 背景。
允许服装交界、发丝遮挡和局部阴影做自然适配。
不要重新设计面部，不明显改变年龄、体型、姿势、机位或背景，不增加无关文字。

【输出】
保持原图画幅，输出一张完整图片。
```

#### 4.3 姿势参考融合

```text
使用两张参考图生成同一人物的新姿势图。

【任务】
目标：保持人物身份，将姿势调整为 R2 的动作骨架。
只改变：姿势、四肢位置以及为动作合理性所需的衣褶和重心。

【保持】
R1：只负责人物身份、年龄感、脸型五官、发型和体型。
R2：只负责姿势、肢体方向、重心和镜头关系；不负责脸、发型、服装和体型。

【画面】
服装：保持 R1 的{服装描述}。
动作：采用 R2 的{姿势摘要}，手脚完整可见，关节与重心自然。
镜头与背景：{保持 R1 / 采用明确新设计}。

【限制】
身份 > 人体结构与重心 > 姿势相似 > 服装材质 > 背景。
避免把 R2 的脸、体型、服装或环境带入结果。

【输出】
单张，{画幅}，{用途}。
```

#### 4.4 半写实动漫风格转换

```text
将人物参考图转换为{轻度 / 标准 / 美型增强}半写实动漫风格。

保持人物身份、脸型与五官关系、年龄感、发型轮廓、姿势、构图和可辨识特征。
只改变艺术表达方式，不重新设计人物。

目标风格：
动漫化五官但保持真实比例；{眼睛夸张程度}；自然面部体积；细腻但不过度磨皮的皮肤；清晰发丝；真实服装材质；{清透 / 电影级 / 游戏角色型}光影。

控制：
身份辨识 > 面部结构 > 人体结构 > 风格完成度 > 背景。
避免幼化、脸型模板化、眼睛过大、鼻口消失、塑料皮肤和过度锐化。

输出：单张，保持原图画幅。
```

### 五、验收清单

- 人物是否仍能被识别为同一人；
- 年龄感、脸型和五官关系是否漂移；
- 姿势重心、四肢、手指和遮挡是否合理；
- 服装结构是否完整，衣褶是否符合动作；
- 镜头、构图、背景是否发生非预期变化；
- 风格化是否改变了身份，而不仅是改变表现方式。

### 六、七维问题诊断

| 现象 | 首查维度 | 调整动作 |
|---|---|---|
| 人物不像 | 固定/保留 | 换清晰主参考，减少身份描述冲突，回到原始参考 |
| 换衣后脸变 | 变化范围 | 缩小编辑范围，只保留服装变量 |
| 姿势错误 | 目标画面/结构 | 简化动作，明确手脚位置、重心和遮挡 |
| 画面角度变化 | 镜头与构图 | 写明保持原机位，或单独生成所需角度 |
| 皮肤塑料感 | 渲染与质感 | 用自然纹理、轻微肤色变化和受控高光替代“无瑕” |
| 画幅或裁切错误 | 【输出】 | 写可见部位和真实画幅参数，必要时扩图修复 |

### 七、平台适配

- **ChatGPT Images**：使用自然语言完整说明“只改变/保持/允许适配”，多轮编辑时每轮只提交本轮增量；
- **OpenAI API**：尺寸、质量、格式用 API 参数控制，不塞进语义描述；局部编辑使用 mask，并保留完整上下文；
- **即梦图片生成/智能参考**：中文任务目标前置，多图时逐张声明职责；
- **即梦智能画布**：局部换装、面部或手部修复优先在目标区域操作，非编辑区域仍需验收。

## 商品视觉提示词模板

> [!important] 五段式继承
> 本文遵循 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]；外层统一为【任务】【保持】【画面】【限制】【输出】。本页只增加本场景需要的专业字段。


![[02-商品视觉提示词模板-配图-v01.png]]


> [!abstract] 定位
> 商品视觉先保证**商品可识别、结构可信、卖点清楚**，再追求氛围。凡是必须精确的 Logo、标签文字、规格数字、接口和包装结构，都应保留原图层或安排后期校对。

### 一、先选择任务


![[商品视觉_五槽位完整示范.png]]

| 子任务 | 首要保持 | 主要变化 | 关键风险 |
|---|---|---|---|
| 白底主图 | 商品形状、比例、包装和配色 | 背景与轻微接触阴影 | 商品漂移、悬浮、边缘光晕 |
| 商品换景 | 商品本体与品牌区 | 场景、道具、环境光 | 道具遮挡、环境反射污染 |
| 卖点图 | 商品与卖点结构 | 视觉强调、标注留白 | 模型虚构功能、文字错误 |
| 广告海报 | 商品和品牌调性 | 版式、背景、氛围 | 商品被装饰压过、Logo 变形 |
| 批量变体 | 商品主体与统一布光 | 色彩、场景或版本变量 | 各版本比例和机位不一致 |

### 二、输入准备

- 正面、侧面或三分之四视角的清晰商品参考；
- 必须准确的包装、接口、纹理、Logo 和标签区域清单；
- 目标渠道尺寸、留白方向和文字安全区；
- 材质说明：粗糙度、反射、透明度、织纹、拉丝、磨砂等；
- 明确哪些内容由模型生成，哪些内容后期排版。

### 三、五段式商品母版


```text
【任务】
任务类型：{白底图 / 商品换景 / 卖点图 / 广告海报 / 批量变体}
本轮目标：{具体任务}
只改变：{背景、道具、光线、机位或版式}

【保持】
保持：{商品形状、比例、结构、包装、配色、材质、品牌区域}
参考 R1：负责商品本体
参考 R2：只负责{场景 / 布光 / 版式，可选}

【画面】
商品展示：{角度、摆放、卖点可见性}
场景与道具：{环境、台面、辅助物}
镜头与构图：{景别、视角、留白、视觉中心}
光线与材质：{布光、反射、高光、阴影、表面纹理}

【限制】
优先顺序：商品结构与识别 > 品牌信息 > 核心卖点 > 材质 > 场景
必须保持：{关键结构和品牌区域}
避免：{变形、错字、多余标签、遮挡、悬浮、材质失真}

【输出】
数量：{N}
画幅/尺寸：{比例或平台参数}
版式：{单图 / 系列 / 海报}
用途：{电商主图 / 详情页 / 广告}
文字区域：{无 / 左侧 / 右侧 / 顶部}
```

### 四、可直接复制模板

#### 4.1 白底商品主图

```text
将参考商品制作成电商白底主图。

只改变背景和必要的接触阴影。
保持商品外形、比例、结构、配色、材质、包装布局和现有品牌区域。

商品居中，完整可见，正面或{指定角度}，边缘干净清晰。
背景为纯白不透明背景；底部保留非常轻微、方向合理的接触阴影，使商品自然落地。
高光受控，材质保持{拉丝金属 / 磨砂塑料 / 透明玻璃 / 织物}特征。

不要增加道具、装饰、标签、文字或水印；不要改变商品比例、接口和包装结构；不要出现光晕、悬浮和过曝。

输出：单张，1:1，用于电商目录。
```

#### 4.2 商品场景图

```text
编辑商品参考图，只更换背景、辅助道具和环境光线。

保持商品的{外形、比例、包装、配色、品牌区域和材质}。
目标场景：{具体地点、时间和使用情境}。
道具：{少量道具}，不得遮挡商品或核心卖点。
构图：商品位于{位置}，{景别和机位}，{方向}保留文案空间。
材质与布光：{主光方向、柔硬程度、轮廓光、反射控制}；商品底部有自然接触阴影。

优先顺序：商品准确 > 卖点可见 > 材质真实 > 场景氛围。
不要改变商品形状和包装，不生成无关文字或新标签，不让环境色污染商品主色。

输出：单张，{画幅}，用于{用途}。
```

#### 4.3 卖点特写图

```text
基于商品参考图制作卖点特写视觉。

保持商品结构与真实功能，不虚构接口、按钮、开孔或材料层。
重点展示：{卖点部位和功能}。
镜头：{微距 / 近景}，焦点位于{部位}，其他区域轻微虚化但仍可识别。
视觉强调：使用{光线、剖面、箭头留白或局部高光}突出卖点；准确说明文字由后期添加，画面内不生成随机文案。

避免结构虚构、比例夸张、材质错误、过度发光和复杂背景。
输出：{画幅}，{文字区域}留白。
```

#### 4.4 批量商品变体

```text
生成同一商品的{N}个系列视觉。

所有版本固定：商品比例、机位、主体尺度、构图、布光方向、背景结构和品牌区域。
唯一变量：{颜色 / 场景时段 / 背景材质 / 指定版本属性}。
变量表：
A：{变量值}
B：{变量值}
C：{变量值}

每个版本独立输出，不拼接；不得同时改变商品形状、机位和背景结构。
```

### 五、验收清单

- 商品轮廓、比例、接口、包装和品牌区域是否准确；
- 产品主色是否被环境光明显污染；
- 材质的反射、粗糙度和透明度是否可信；
- 商品是否被遮挡、裁切或悬浮；
- 卖点是否真实存在且可见；
- 文字、Logo 和规格是否需要回到原图层或后期排版。

### 六、七维问题诊断

| 现象 | 首查维度 | 调整动作 |
|---|---|---|
| 商品变形 | 固定/保留 | 缩小编辑范围，使用更清晰商品主参考 |
| 包装或 Logo 错 | 主体准确性 | 保留原商品图层，后期合成或逐区修复 |
| 商品像塑料 | 渲染与质感 | 补充粗糙度、反射、纹理和受控高光 |
| 商品悬浮 | 光线/构图 | 添加真实接触阴影，检查地面透视 |
| 卖点不突出 | 目标画面 | 减少道具，调整景别、焦点和留白 |
| 系列不一致 | 输出/变化范围 | 固定机位和光线，每轮只改一个变量 |

### 七、平台适配

- 对话式平台：把“保持商品本体”和“只改变背景”放在最前面；
- API：真实尺寸、质量和格式由参数控制，批量任务保存参数快照；
- 局部编辑：优先只框选背景或卖点区域，商品边缘仍需检查；
- 即梦智能画布：可用于换景、消除道具、扩图和局部材质修复，但精确品牌信息仍需后期。

## 插画与艺术创作提示词模板

> [!important] 五段式继承
> 本文遵循 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]；外层统一为【任务】【保持】【画面】【限制】【输出】。本页只增加本场景需要的专业字段。


![[03-插画与艺术创作提示词模板-配图-v01.png]]


> [!abstract] 定位
> 插画不是“主体 + 某位艺术家名字”。可复用的风格应拆成：**媒介、造型程度、线条、上色方式、色彩关系、光影和表面纹理**。叙事插画还需要明确人物关系和正在发生的动作。

### 一、先选择任务


![[插画创作_五槽位完整示范.png]]

| 子任务 | 核心固定 | 主要变化 | 关键 |
|---|---|---|---|
| 角色插画 | 人物设定、叙事身份 | 姿势、场景、构图 | 角色与背景主次 |
| 叙事插画 | 故事节点、人物关系 | 镜头、动作、环境 | 因果和视线关系 |
| 小说/专辑封面 | 主题、标题安全区、视觉符号 | 主视觉、色彩、媒介 | 留白与信息层级 |
| 绘本 | 角色和画风一致 | 场景与动作 | 年龄适配和连续性 |
| 漫画/分镜 | 角色、服装、空间轴线 | 每格动作与镜头 | 格数、顺序与对白后期 |
| 风格实验 | 主体与构图 | 媒介、线条、色彩 | 每轮只改变一个风格维度 |

### 二、输入准备

- 一句话主题与叙事瞬间；
- 主体关系、动作、视线和情绪；
- 主风格及拆解后的画法维度；
- 标题、书脊或文字安全区；
- 是否需要系列一致性、角色参考或后期排字。

### 三、五段式插画母版


```text
【任务】
任务类型：{角色插画 / 叙事插画 / 封面 / 绘本 / 风格实验}
本轮目标：{主题与故事节点}
只改变：{构图、媒介、色彩、动作或场景}

【保持】
保持：{人物设定、角色关系、主题符号、艺术方向、主色体系}
参考 R1：负责{角色 / 构图}
参考 R2：只负责{媒介 / 色彩 / 笔触，可选}

【画面】
主体与关系：{谁、在哪里、做什么、彼此关系}
叙事重点：{观众第一眼看到什么}
环境与象征：{场景、道具、视觉隐喻}
艺术风格：{媒介 + 造型 + 线条 + 上色方式}
镜头与构图：{景别、视角、构图、留白}
色彩与光影：{主色、辅助色、对比、光线}
表面质感：{纸张、颜料、笔触、颗粒}

【限制】
优先顺序：叙事重点 > 主体关系 > 构图 > 风格统一 > 装饰细节
避免：{角色数量错误、关系错位、画风漂移、肢体错误、随机文字}

【输出】
数量：{N}
画幅：{比例}
版式：{单幅 / 封面 / 漫画 / 系列图}
文字安全区：{无 / 位置}
```

### 四、可直接复制模板

#### 4.1 叙事插画

```text
主题：{一句话主题}。
故事瞬间：{人物正在做什么，动作前因或结果是什么}。
主体关系：{角色 A 与角色 B 的位置、视线、距离和情绪}。
环境：{地点、时间、天气、关键道具}。
叙事重点：观众第一眼看到{主体/动作/象征物}。

风格：{水彩 / 数字厚涂 / 赛璐璐 / 版画等}；{线稿特点}；{上色方式}；{纸张或颜料质感}。
构图：{景别、视角、构图法则}，{方向}保留呼吸空间。
色彩：{主色、辅助色、饱和度与冷暖关系}。
光线：{方向、光质、阴影特点}。

避免角色关系错误、无意义装饰抢主体、肢体错误、风格混杂和随机文字。
输出：单张，{画幅}。
```

#### 4.2 小说封面主视觉

```text
生成一张小说封面主视觉，不直接生成准确标题文字。

主视觉：{人物/物件/场景符号}，表达{情绪与故事暗示}。

风格：{媒介与画法}。
色彩：{色彩体系}。
光线与质感：{光影、纸张、颜料或数字质感}。

避免生成随机标题、作者名、出版社标识和复杂细小文字。

```

#### 4.3 风格 A/B 实验

```text
固定主体、姿势、构图、场景、镜头和画幅，仅测试{单一风格维度}。

版本 B：{媒介/线条/色彩/光影方案 B}

```

### 五、验收清单

- 主题和叙事动作能否仅通过画面理解；
- 人物关系、视线和位置是否正确；
- 主体、背景和装饰是否有清晰层级；
- 风格是否被拆成可见画法，而非只靠宽泛标签；
- 封面或海报是否保留真实排字空间；
- 系列插画的角色、色彩和画法是否一致。

### 六、问题诊断

| 现象 | 首查维度 | 调整动作 |
|---|---|---|
| 画面漂亮但无故事 | 任务/目标画面 | 加入明确动作、关系和叙事结果 |
| 风格不稳定 | 保留项/质感 | 固定媒介、线条、上色和色彩，不只写风格名 |
| 背景抢主体 | 构图/控制 | 降低背景对比和细节，增加主体尺度或光照 |
| 封面无法排字 | 【输出】 | 明确文字安全区，去除关键元素占位 |
| 人物关系错 | 目标画面 | 明确左右位置、视线、接触和距离 |

```text
设计一座{建筑类型}的外观概念图。
场地：{城市/滨水/山地/校园等}。
体块：{层数、主次体块、入口、公共空间}。
立面语言：{开窗规律、遮阳、结构节奏}。
材料：{混凝土、玻璃、木材、金属、石材}，表现真实连接和表面差异。
镜头：两点透视，人眼高度，{广角或标准镜头感}，垂直线尽量保持竖直。
环境：{时间、天气、景观、人群尺度}。

避免漂浮结构、无支撑大跨度、随机门窗、重复纹理、人物与建筑比例错误。
输出：16:9 建筑概念效果图。
```

#### 4.3 多方案材料对比

```text
基于同一空间结构和同一机位生成三种材料方案。

固定：墙体、门窗、家具布局、镜头、时间、光源方向和画幅。
唯一变量：主要材料体系。
A：浅木、米白石材、亚麻。
B：深色木饰面、灰色石材、黑色金属。
C：清水混凝土、透明玻璃、浅灰织物。

每个方案独立输出，不改变结构和家具位置。
```

### 五、验收清单

- 墙体、门窗、体块和机位是否保持；
- 尺度是否符合人物、家具和建筑常识；
- 动线、入口和功能区是否可读；
- 垂直线、消失点和地面接触是否合理；
- 材料反射、粗糙度、接缝和阴影是否可信；
- 是否清楚标记为概念表现，而非工程成果。

### 六、问题诊断

| 现象 | 首查维度 | 调整动作 |
|---|---|---|
| 空间被重构 | 保留项/变化范围 | 明确墙体、门窗和机位不可改变，缩小编辑范围 |
| 家具比例异常 | 目标画面 | 加入人物尺度和具体家具尺寸关系 |
| 透视变形 | 镜头与构图 | 指定两点透视、垂直线和较温和焦距 |
| 材料像贴纸 | 渲染与质感 | 描述厚度、接缝、粗糙度、反射和边缘 |
| 动线堵塞 | 【限制】 | 减少家具，明确入口、通道和功能区域 |

## 氛围创意提示词模板

> [!important] 五段式继承
> 本文遵循 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]；外层统一为【任务】【保持】【画面】【限制】【输出】。本页只增加本场景需要的专业字段。


![[06-氛围创意提示词模板-配图-v01.png]]


> [!abstract] 定位
> “宏大、孤独、电影感、高级”不能单独构成场景提示词。应把情绪转化为可观察证据：**空间尺度、人物大小、天气、光源数量、色温、前中后景和叙事道具**。

### 一、先选择任务


![[场景概念_五槽位完整示范.png]]

| 子任务 | 固定核心 | 主要变化 | 关键 |
|---|---|---|---|
| 自然环境 | 地貌、季节、生态逻辑 | 时间、天气、光线 | 空间深度和自然逻辑 |
| 城市概念 | 时代、建筑语言、城市功能 | 机位、人群、交通、天气 | 尺度与世界一致性 |
| 影视氛围 | 情绪、场景、叙事瞬间 | 光源、色彩、天气、镜头 | 情绪可视化 |
| 游戏环境 | 世界规则、玩法路径、地标 | 道具、敌我活动、时间 | 可读路径和视觉焦点 |
| 世界观主视觉 | 技术/魔法规则、文明与地理 | 场景元素、交通、服饰 | 内部一致性 |

### 二、输入准备

- 一句话世界规则；
- 核心地标或必须出现的空间元素；
- 时间、天气、色温和主要光源；
- 主视觉焦点与人物/物体尺度；
- 输出用途：概念探索、建立镜头、视频首帧或游戏场景参考。

### 三、五段式场景母版


```text
【任务】
任务类型：{环境文生图 / 场景改造 / 氛围变体 / 世界观设计}
本轮目标：{要呈现的场景和叙事瞬间}
只改变：{时间、天气、光线、环境元素或风格}

【保持】
保持：{时代、世界规则、空间基调、核心地标、主色体系}
参考 R1：负责{空间结构 / 场景基调}
参考 R2：只负责{光线 / 色彩 / 材质，可选}

【画面】
地点与空间：{环境、地貌、建筑、路径}
时间与天气：{时间、季节、天气、能见度}
叙事线索：{人物、车辆、道具、事件痕迹}
风格：{摄影 / 概念艺术 / 插画 / 3D 环境}
镜头：{景别、机位、焦距感、构图、视觉焦点}
光线与色彩：{主光、辅助光、色温、饱和度、对比}
空间质感：{前中后景、空气透视、材质、体积光}

【限制】
优先顺序：世界规则 > 空间逻辑 > 核心地标与焦点 > 氛围 > 装饰细节
避免：{时代错位、尺度异常、透视混乱、元素拥挤、光线矛盾}

【输出】
数量：{N}
画幅：{比例}
类型：{概念图 / 建立镜头 / 氛围图 / 视频首帧}
用途：{项目}
```

### 四、可直接复制模板

#### 4.1 影视氛围图

```text
【任务】
为{影片/短片}生成一张{情绪}的场景概念图。

【保持】
世界设定：{时代和地点}。
核心地标：{必须出现的元素}。

【画面】
场景：{具体空间}，{时间}，{天气}。
叙事瞬间：{人物或事件}；人物在画面中的尺度为{小/中/大}。
镜头：{16:9 大全景 / 中景等}，{机位}，以{道路/建筑/光源}形成视觉引导。
光线：{主光方向和色温}，{辅助点光源}，反射与阴影符合环境。
空间：前景{元素}，中景{主体}，远景{地标}；使用{雾、雨、尘埃}建立空气透视。
色彩：{主色 + 辅色}，{低/中/高}饱和，{低/高}对比。

【限制】
空间与叙事焦点优先；避免拥挤人群、随机招牌文字、透视错误、色彩失控和光线方向矛盾。

【输出】
单张，16:9，用于影视氛围参考。
```

#### 4.2 世界观主视觉

```text
世界规则：{文明建立在哪里、依赖什么能源、交通和建筑遵循什么规则}。
核心场景：{主岛、城市、宫殿、地下空间或自然奇观}。
叙事活动：{飞行船、商队、仪式、人群或环境事件}。
统一视觉语言：{建筑材料、技术/魔法符号、主配色}。
镜头：{鸟瞰大远景 / 地面建立镜头}，核心地标位于{构图位置}，交通或地形形成引导线。
光线与空间：{时间、天气、体积光、云雾、空气透视}。

优先顺序：世界规则 > 地理与建筑逻辑 > 地标 > 叙事活动 > 装饰。
避免混入不属于该时代或文明的元素、随意漂浮物、尺度冲突和过密细节。

输出：单张，{画幅}，用于世界观主视觉。
```

#### 4.3 同场景氛围变体

```text
基于同一场景结构生成四个独立氛围版本。

固定：建筑、道路、地标、机位、镜头、主体位置和画幅。
唯一变量：时间与天气。
A：清晨薄雾，冷暖交界光。
B：正午晴天，清晰硬光。
C：傍晚雨后，暖色低角度光。
D：深夜小雨，少量人工点光源。

每个版本独立输出，不改变空间结构和地标位置。
```

### 五、验收清单

- 世界规则和时代是否统一；
- 地标、路径、人物和建筑尺度是否合理；
- 主视觉焦点是否清楚；
- 前景、中景、远景是否有层次；
- 光源方向、天气、反射与阴影是否一致；
- 情绪是否由画面证据表达，而不是只依赖标题说明。

### 六、七维问题诊断

| 现象 | 首查维度 | 调整动作 |
|---|---|---|
| 氛围平淡 | 目标画面/质感 | 增加明确天气、光源、人物尺度与叙事道具 |
| 场景杂乱 | 构图/控制 | 删除无关元素，明确视觉焦点与留白 |
| 空间扁平 | 镜头/质感 | 补前中后景、空气透视、遮挡和尺度变化 |
| 世界观混乱 | 保留项 | 提炼一条世界规则和统一材料语言 |
| 光线矛盾 | 光影 | 减少主光源，明确方向、色温和阴影 |
| 变体结构漂移 | 变化范围 | 固定空间与机位，只改变时间天气 |

### 七、平台适配

- 对话式平台适合先生成基准场景，再通过多轮编辑改变天气或时间；
- API 批量变体应保存同一提示词骨架和参数，只替换变量字段；
- 即梦智能画布适合扩图、消除杂物、调整局部建筑和补充环境；
- 高精度空间结构不能只依赖提示词，必要时结合草图、深度/结构控制或后期合成。

## 素材与制作辅助提示词模板

> [!important] 五段式继承
> 本文遵循 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]；外层统一为【任务】【保持】【画面】【限制】【输出】。本页只增加本场景需要的专业字段。


![[07-素材与制作辅助提示词模板-配图-v01.png]]


> [!abstract] 定位
> 素材图的评价标准不是“像成片一样丰富”，而是**容易抠取、容易平铺、容易合成、容易保持系列一致**。提示词必须写清背景、边缘、阴影、机位和输出形态。

### 一、先选择任务


![[素材制作_五槽位完整示范.png]]

| 子任务 | 首要固定 | 关键要求 |
|---|---|---|
| 透明主体 | 轮廓、视角、边缘 | 无背景污染、阴影策略明确 |
| 纯色抠图素材 | 主体与统一光线 | 背景颜色与主体有足够分离 |
| 无缝纹理 | 材质尺度和表面规律 | 四边连续、无中心构图、无明显接缝 |
| 特效元素 | 形态、方向、强度 | 黑底/透明策略、边缘和发光范围 |
| 背景素材 | 画幅、透视、留白 | 不出现抢主体的视觉中心 |
| 视频首帧 | 主体、构图、运动方向 | 为后续运动和扩图留空间 |
| 素材表/精灵图 | 统一机位、尺度、光线 | 每格独立、边缘不重叠 |

### 二、输入准备

- 素材最终用途和合成软件；
- 背景需要透明、纯色还是完整环境；
- 是否保留投影、接触阴影、反射或发光；
- 统一机位、主体尺度、光线方向和边缘标准；
- 实际输出格式是否由平台支持；不支持时准备后期抠图。

### 三、五段式素材母版


```text
【任务】
任务类型：{透明主体 / 纹理 / 特效 / 背景 / 首帧 / 素材表}
本轮目标：{具体素材}
只改变：{颜色、形态、方向、密度、强度或版本}

【保持】
保持：{轮廓、结构、机位、主体尺度、光线、系列风格}
参考 R1：负责{主体或纹理结构}
参考 R2：只负责{风格或颜色，可选}

【画面】
主体/纹理：{形态、细节、材质}
视角：{正视、侧视、俯视、正交}
背景：{透明 / 纯色 / 满版}
边缘：{完整、清晰、无毛边、无污染}
光线与阴影：{均匀光 / 固定方向 / 是否保留阴影}
系列规则：{统一尺度、间距、方向、密度}

【限制】
优先顺序：制作可用性 > 结构和边缘完整 > 系列一致 > 质感 > 装饰
避免：{裁切、背景污染、阴影残留、接缝、重叠、随机文字}

【输出】
数量：{N}
画幅/尺寸：{比例或真实参数}
背景：{透明 / 纯色 / 完整环境}
版式：{单张独立 / 素材表 / 无缝平铺}
用途：{合成、贴图、UI、视频}
```

### 四、可直接复制模板

#### 4.1 独立主体抠图素材

```text
生成一个独立的{主体}素材。
主体完整居中，{正视/侧视/俯视}，轮廓清楚，所有边缘完整，不被画面裁切。
使用均匀柔光，避免环境色污染；{不保留阴影 / 只保留轻微接触阴影}。
背景：{透明背景，如当前入口支持 / 纯色高反差背景，便于后期抠图}。
不要增加道具、文字、水印、边框、光晕或背景场景。
输出：单张，1:1，用于后期合成。
```

#### 4.2 无缝纹理

```text
生成可无缝平铺的{材质}纹理。
正交俯视，无透视，无中心主体，无边框，无明显光照渐变。
纹理尺度：{细密/中等/粗大}；颜色：{颜色体系}；表面：{粗糙度、纤维、裂纹、颗粒等}。
四个边缘必须连续，重复单元自然分布，避免明显接缝、方向突变、文字、物体和强阴影。
输出：1:1 方形纹理；生成后仍需实际平铺检查。
```

#### 4.3 特效元素

```text
生成一个独立的{烟雾/火花/能量/水花/尘土}特效元素。
形态：{方向、速度感、密度、范围}。
中心亮度和边缘衰减自然，保留细小颗粒与透明层次。
背景：{纯黑用于屏幕混合 / 纯色用于抠图 / 透明如入口支持}。
不要出现实体物体、人物、文字和硬边矩形背景。
输出：单张，{画幅}，用于视频或平面合成。
```

#### 4.4 视频首帧

```text
生成一张{16:9 / 9:16}视频首帧。
主体：{人物或物体}，位于{位置}，朝{运动方向}运动或准备动作。
构图：在运动方向前方保留空间，画面边缘留出后续扩图余量。
环境：{场景、时间、天气}。
光线与质感：{统一主光、明确层次}。
避免主体紧贴边缘、动作方向与留白相反、随机文字和复杂小物件。
```

### 五、验收清单

- 主体和边缘是否完整，无裁切、光晕和背景污染；
- 阴影、反射和发光是否符合预定合成方式；
- 无缝纹理是否经过四向平铺检查；
- 素材表中各格是否独立、不重叠且尺度一致；
- 透明背景是否是平台真实支持的输出，而非仅提示词文字；
- 首帧是否为运动、扩图和字幕保留空间。

### 六、问题诊断

| 现象 | 首查维度 | 调整动作 |
|---|---|---|
| 边缘脏 | 背景/质感 | 改纯色高反差背景，减少环境反光，后期抠图 |
| 主体被裁切 | 构图/输出 | 写“完整可见”和边缘留白，增加画幅 |
| 纹理有接缝 | 目标画面 | 去除中心构图和光照渐变，实际平铺后再修复 |
| 系列素材角度漂移 | 保留项 | 固定机位、尺度和光线，每次只改一个变量 |
| 特效带矩形底 | 背景规则 | 指定黑底混合或纯色抠图，后期去底 |
