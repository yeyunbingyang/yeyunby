# 提示词设计与失败排查

> [!info] 合并说明
> 本文由原拆分笔记合并而成；原文件保留在维护区的历史版本中，本文为当前唯一权威正文。

## 提示词模板规范与设计方法

> [!important] 规范结论
> 所有现行提示词模板统一继承 [[01-提示词/01-通用提示词模板|五段式最小可用提示词模板]]。新增模板不得另起平行主结构。

### 一、统一规范

#### 一、固定外层结构

```text
【任务】→【保持】→【画面】→【限制】→【输出】
```

顺序默认固定；某段没有内容时可以删除，但不能换成另一套外层框架。

#### 二、各类模板的扩展边界

| 模板类型 | 允许扩展 | 不应做的事 |
|---|---|---|
| 任务模板 | 任务类型、变化范围、参考职责 | 新建另一套主标签 |
| 用途模板 | 专业保持项、画面字段和风险项 | 把行业术语堆成无结构长文 |
| 输出模板 | 视图、版式、顺序、标签、安全区 | 改变人物或商品的事实定义 |
| 平台模板 | 平台语气、参数、选区和上传方式 | 把平台参数混入视觉描述 |
| 风格专题 | 【画面】中的媒介、渲染、色彩和材质模块 | 取代【任务】【保持】【输出】 |
| 限制词库 | 【限制】中的1–4个高风险问题 | 整库复制、固定必加 |

#### 三、模板笔记固定结构

1. 适用范围；
2. 五段式可复制模板；
3. 本模板专属填写说明；
4. 示例；
5. 常见失败与修复；
6. 可选扩展；
7. 相关入口。

#### 四、元数据要求

现行模板至少包含：

```yaml
template_standard: five_part_minimum_v1
canonical_template: "[[01-提示词/01-通用提示词模板]]"
template_role: task | purpose | output | platform | style_module | restriction
```

#### 五、验收清单

- [ ] 外层能映射到五段；
- [ ] “只改变”和“保持不变”没有冲突；
- [ ] 每张参考图只有明确职责；
- [ ] 风格模块放在【画面】，不是独立母版；
- [ ] 限制项只包含当前任务风险；
- [ ] 输出数量、比例、要求和用途明确；
- [ ] 没有绝对一致、固定成功率或伪参数承诺。

#### 六、历史内容处理

历史笔记可以保留旧结构作为证据，但必须标为 `archived` 或明确注明“历史结构，不作为当前模板”。活动模板中的旧标签迁移为：任务、保持、画面、限制、输出。

### 二、提示词模板设计方法

![[提示词顺序与权重_正确错误对照.png]]

#### 2.1 核心结构：五段式执行 × 七维度诊断

日常提示词不需要把所有控制因素拆成七段。推荐使用五段式：

| 五段 | 回答的问题 | 是否通常必填 |
|---|---|---|
| **【任务】** | 本轮做什么、只改什么 | 是 |
| **【保持】** | 什么必须保持、每张参考图负责什么 | 图生图必填，文生图可简化 |
| **【画面】** | 最终画面应该长什么样 | 是 |
| **【限制】** | 冲突时先保什么、避免什么 | 复杂任务建议填 |
| **【输出】** | 数量、画幅、版式和用途 | 是 |

原七槽位保留为后台诊断维度：

1. 固定项；
2. 可变项；
3. 优先级；
4. 限制项；
5. 镜头与构图；
6. 输出规格；
7. 渲染与质感。

##### 五段式与七维度对应

| 五段式 | 包含的七维度 |
|---|---|
| 【任务】 | 可变项 |
| 【保持】 | 固定项 |
| 【画面】 | 可变项 + 镜头与构图 + 渲染与质感 |
| 【限制】 | 优先级 + 限制项 |
| 【输出】 | 输出规格 |

> [!tip]
> 五段式解决“怎么写得短而完整”，七维度解决“结果为什么出错”。两者不是互相替代，而是前台执行与后台诊断的关系。

#### 2.2 双轴原则：保持什么 × 改变什么

复杂图像编辑的核心不是堆风格词，而是清晰区分：

```text
恒定轴：本轮必须保持的内容
可变轴：本轮允许改变的内容
```

例如换装任务：

```text
恒定轴：人物身份、脸部、发型、姿势、摄影角度、背景和原有光线
可变轴：服装及与服装直接相关的褶皱、遮挡和材质反光
```

- **诊断模式**：一次只改一个变量，用于定位问题；
- **正式生成**：可以修改一个逻辑变量组，例如“服装+匹配配饰”；
- **高风险组合**：同时更换身份、姿势、服装、场景和风格，通常会显著降低一致性。

#### 2.3 五段式通用母版

```text
【任务】
任务类型：{文生图 / 图生图 / 局部编辑 / 扩图 / 主体替换 / 风格转换 / 批量变体}
本轮目标：{一句话描述任务结果}
只生成或改变：{单一变量或合理变量组}
编辑区域：{无 / 具体位置 / 蒙版区域}

【保持】
必须保持：{身份、结构、姿势、构图、背景、品牌信息等}
参考 R1：负责{身份 / 商品本体 / 原图结构}
参考 R2：负责{姿势 / 服装 / 材质}
参考 R3：负责{风格 / 场景 / 光线}
参考冲突时：以{主参考或核心目标}为准

【画面】
主体：{人物、商品、建筑、场景或素材}
动作与状态：{姿势、表情、运动状态或使用状态}
环境与背景：{地点、时间、天气、空间元素}
风格与媒介：{摄影、动漫、插画、CG、平面设计等}
镜头与构图：{景别、机位、角度、焦距、构图}
光线与色彩：{光向、光质、主色、影调}
材质与细节：{皮肤、发丝、布料、金属、玻璃、纹理等}

【限制】
冲突顺序：{最重要} > {次重要} > {一般要求}
必须保持：{最关键的 2-5 项}
允许自然适配：{与动作、光线、透视相关的合理变化}
避免：{只列当前任务最可能出现的风险}

【输出】
数量：{N}
画幅或尺寸：{1:1 / 3:4 / 4:5 / 16:9 / 自定义}
版式：{单图 / 拼版 / 三视图 / 素材表}
用途：{头像 / 主图 / 海报 / 视频首帧 / 后期素材}
文字区域：{无 / 左侧留白 / 顶部留白 / 指定安全区}
```

#### 2.4 三档使用深度

##### 极简版：自由文生图

```text
{主体}，{动作或场景}，{风格}，{镜头与构图}，{光线与色彩}，{画幅}。
```

示例：

```text
一只橘猫坐在雨夜窗边，望向玻璃上的雨滴，电影摄影，室内近景，
柔和暖色灯光与窗外冷蓝色形成对比，浅景深，3:4。
```

##### 标准版：单主体或普通参考图

填写：

- 【任务】；
- 【保持】；
- 【画面】；
- 少量【限制】；
- 【输出】。

##### 专业版：多参考、局部编辑或连续资产

在标准版基础上增加：

- 每张参考图的唯一职责；
- 编辑区域和非编辑区域；
- 冲突顺序；
- 系列统一项；
- 可量化验收标准。

#### 2.5 内容要素放在哪里

| 内容要素 | 推荐槽位 |
|---|---|
| 主体身份、商品本体、空间结构 | 【保持】 |
| 本轮要改什么 | 【任务】 |
| 动作、表情、场景、风格 | 【画面】 |
| 镜头、构图、焦距 | 【画面】 |
| 光线、颜色、材质和表面细节 | 【画面】 |
| 保留优先级、允许适配和排除项 | 【限制】 |
| 数量、比例、版式和用途 | 【输出】 |

#### 2.6 五段式 × 七类场景填空映射（★ 核心）

七类场景共用同一五段式。场景类型只决定每个槽位填写什么，不重新发明模板结构。

##### 2.6.1 七类场景总映射

| 场景 | 【任务】 | 【保持】 | 【画面】 | 【限制】 | 【输出】 |
|---|---|---|---|---|---|
| **人物视觉** | 创作、换装、姿势、表情、风格或局部修复 | 身份、脸部、体型、发型；参考图分别负责脸、姿势、服装 | 动作、服装、环境、镜头、光线、皮肤与发丝 | 身份 > 结构 > 修改目标 > 材质 > 背景；避免换脸和肢体错误 | 头像、半身、全身、三视图、动作板 |
| **商品与商业视觉** | 白底、换景、卖点、包装展示或批量变体 | 商品结构、比例、包装、品牌色和材质 | 使用场景、道具、机位、布光、材质和卖点 | 商品准确 > 品牌 > 卖点 > 材质 > 场景；避免变形和错字 | 主图、详情图、海报、广告图、批量系列 |
| **场景与概念设计** | 新建世界、替换时间天气、扩展环境或氛围变体 | 世界规则、时代、空间逻辑、核心地标和色彩基调 | 地形、建筑、时间、天气、活动、镜头和空气感 | 世界规则 > 空间 > 地标 > 焦点 > 氛围；避免尺度和时代冲突 | 环境概念图、氛围图、建立镜头、视频首帧 |
| **插画与艺术创作** | 角色插画、叙事画面、封面、漫画或媒介转换 | 主题、故事节点、角色关系、画风和色彩体系 | 动作、场景、构图、笔触、媒介和装饰细节 | 叙事 > 角色关系 > 构图 > 风格 > 细节；避免画风漂移 | 单幅、封面、四格、分镜、系列插画 |
| **平面与品牌设计** | 海报、封面、主视觉、社交图或 UI 插图 | 品牌定位、品牌色、信息层级、Logo 区域和网格 | 主视觉、背景图形、留白、视觉流向和表面效果 | 信息 > 品牌 > 可读性 > 主视觉 > 装饰；避免拥挤和错字 | 海报、封面、横幅、社交媒体图和指定尺寸 |
| **建筑与空间设计** | 建筑概念、室内改造、材料替换、景观或灯光方案 | 功能、结构、尺度、动线、门窗和主要材料 | 建筑风格、家具、景观、视角、采光和材质 | 空间逻辑 > 结构 > 功能 > 尺度 > 材料 > 氛围 | 外观、室内、鸟瞰、轴测和多视角方案 |
| **素材与制作辅助** | 透明主体、纹理、背景、特效、首帧或系列素材 | 素材轮廓、背景规则、边缘、固定机位和系列一致性 | 形态、颜色、密度、方向、表面和光线 | 可用性 > 完整度 > 边缘 > 一致性 > 美观；避免裁切和污染 | PNG、无缝纹理、背景图、特效元素、素材表 |

##### 2.6.2 01 人物视觉填空模板

```text
【任务】
本轮任务：{人物文生图 / 身份保持 / 换装 / 姿势调整 / 风格转换}
只改变：{服装、姿势、表情、场景或风格}

【保持】
保持：{人物身份、脸型、五官比例、体型、发型、原姿势或构图}
R1 负责人物身份；R2 负责{姿势/服装}；R3 负责{风格/场景}。

【画面】
人物：{年龄段、外貌、体型和气质}
动作与表情：{具体姿势与情绪}
服装与配饰：{款式、材质、颜色和结构}
环境：{场景、时间和背景}
镜头：{头像/半身/全身，角度，构图，焦距}
光线与质感：{皮肤、发丝、布料和人像光}

【限制】
人物身份 > 人体结构 > 本轮修改目标 > 服装材质 > 背景。
允许服装褶皱和遮挡随姿势自然适配。
避免身份漂移、年龄变化、错误肢体、异常手指和意外裁切。

【输出】
{数量、画幅、单图/三视图/动作板、用途}
```

```text
功能与空间：{用途、层高、开间和主要区域}
设计语言：{现代、极简、古典、工业、未来等}
材料：{木材、石材、玻璃、金属、混凝土等}
镜头：{人眼平视、两点透视、鸟瞰、轴测或室内广角}
光线：{自然采光、室内灯光、日夜状态和全局照明}

【限制】
空间逻辑 > 结构合理 > 功能与动线 > 尺度 > 材料 > 氛围。
避免悬浮结构、门窗错位、透视错误、尺度失常和垂直线异常。

【输出】
{外观/室内/鸟瞰/轴测/多视角方案，数量，画幅}
```

##### 2.6.8 07 素材与制作辅助填空模板

```text
【任务】
本轮任务：{透明主体 / 背景 / 无缝纹理 / 特效 / 贴图 / 视频首帧 / 素材组}
本轮改变：{颜色、形态、大小、密度、方向或变体参数}

【保持】
保持：{主体轮廓、背景规则、边缘、固定机位、光线方向和系列风格}
R1 负责素材结构；R2 负责{表面/风格/颜色}。

【画面】
素材：{具体对象或纹理}
角度：{正视、侧视、俯视、正交或满版}
背景：{透明、纯色或无缝铺满}
边缘和表面：{清晰轮廓、均匀光线、纹理细节}
系列变化：{每张只变化的参数}

【限制】
制作可用性 > 主体完整 > 边缘质量 > 系列一致 > 美观。
避免主体裁切、背景污染、阴影残留、水印、多余物体和纹理接缝。

【输出】
{透明PNG/纹理/背景/特效/首帧，数量，尺寸，是否无缝，版式}
```

#### 2.7 混合场景规则

一项任务可能同时涉及两类场景，例如：

- 人物视觉 + 插画艺术；
- 商品视觉 + 平面品牌；
- 建筑空间 + 场景概念；
- 人物视觉 + 素材制作。

不要把两套模板完整叠加。使用下面的规则：

```text
主要场景：决定保留项、优先级和核心限制。
辅助场景：只补充风格、版式、材质或输出要求。
```

示例：护肤品社交媒体广告

```text
主要场景：商品与商业视觉
保持：瓶身结构、包装、品牌色和Logo区域
优先级：商品准确 > 品牌信息 > 卖点 > 装饰

辅助场景：平面与品牌设计
补充：右侧预留标题区，品牌网格，4:5社交媒体版式
```

#### 2.8 七维度诊断表

![[生成失败_七维诊断路线.png]]


当结果不理想时，不要立刻重写整段提示词。先判断属于哪个维度：

| 现象 | 主要诊断维度 | 优先调整 |
|---|---|---|
| 人物换脸、商品变样 | 固定项 | 减少参考图；明确主参考；列出关键保留特征 |
| 没有完成本轮修改 | 可变项 | 把“只改变什么”前置并写得具体 |
| 背景或风格压过主体 | 优先级 | 缩短次要描述；明确主体或商品优先 |
| 多指、错字、额外对象 | 限制项 | 加入与当前错误直接相关的少量限制 |
| 角度、景别或透视错误 | 镜头与构图 | 单独写景别、机位、角度和构图 |
| 比例、数量或版式错误 | 【输出】 | 使用平台尺寸参数，并在提示词中说明版式 |
| 塑料感、材质假、光线平 | 渲染与质感 | 用正向材质、表面和布光描述替代泛化“高质量” |

#### 2.9 特殊操作规则

##### 文生图

- 不需要写“保持原图”；
- 主体、动作、环境、风格和镜头是主要信息；
- 极简任务不必套完整五段式。

##### 图生图

- 先写本轮任务，再写保留项；
- 每张参考图只承担一个主要职责；
- 不要同时要求“完全保持”和“大幅改变”同一维度。

##### 局部编辑

- 明确编辑区域与非编辑区域；
- 描述修复后的正确结构，不只描述“删除错误”；
- 允许编辑区域的光影、遮挡和材质随周边自然衔接。

##### 扩图

- 固定原图内容、透视、机位、光线和色调；
- 只描述新增区域需要延续什么；
- 不要要求模型重绘中心主体。

##### 风格转换

- 写清“只改变艺术表现方式”；
- 身份、结构、姿势、构图和主要颜色按任务决定是否保持；
- 风格词不宜同时选择相互矛盾的媒介。

##### 多参考融合

- 使用最少参考集；
- 一张主参考负责身份或商品本体；
- 其他参考分别负责姿势、服装、场景或风格；
- 若参考冲突，先移除最低价值参考再测试。

##### 批量变体

- 单独列出全系列固定项；
- 每张只改变一个变量或一个变量组；
- 统一机位、画幅、布光、背景规则和命名方式。

## 图片生成提示词最佳实践

> [!info] 笔记关系
> **常用**



![[提示词三类权重_不要混用.png]]

### 3.1 提示词是任务说明，不是程序指令

结构化提示词可以降低歧义，但不能像代码一样保证模型逐条执行。模型仍会综合：

- 文字提示；
- 参考图；
- 蒙版与编辑区域；
- 平台参数；
- 模型能力和随机性。

因此应把最重要的任务目标和保留项写清楚，而不是依赖 P0、权重百分比或“完全冻结”等伪精确表述。

### 3.2 先写目标，再写装饰

推荐顺序：

```text
任务目标
→ 保留与改变范围
→ 主体和画面设计
→ 镜头与光线
→ 少量限制
→ 输出规格
```

低效顺序通常是：先堆大量“高清、8K、杰作、最佳质量”，最后才说明要生成什么。


### 3.3 提示词顺序、强调与权重

> [!important] 核心结论
> **核心目标前置，保持与变化分离，冲突规则显式说明；只有平台明确支持时才使用原生数值权重。** 提示词顺序会影响理解，但不存在通用的“第一段自动占 50% 权重”。

#### 推荐顺序

```text
① 任务动作：生成、编辑、修复、扩图、转换还是替换？
② 核心变化：本轮到底生成或修改什么？
③ 【保持】：什么不能变？每张参考图负责什么？
④ 目标画面：主体、动作、环境、风格、镜头、光线、材质。
⑤ 冲突规则与关键排除项：冲突时优先谁？最可能翻车什么？
⑥ 输出维度：数量、画幅、版式、用途和留白。
```

五段式中的第一槽内部应继续保持：

```text
任务类型 → 本轮目标 → 只改变什么
```

#### 三类“权重”必须分开

| 类型 | 含义 | 通用模板怎么处理 |
|---|---|---|
| **逻辑优先级** | 冲突时先保护什么 | 用完整自然语言写明，适合 ChatGPT、GPT Image、即梦等入口 |
| **平台原生权重语法** | 平台规定的数值或符号语法 | 只有平台明确支持时使用，不能跨平台照搬 |
| **参考图或控制参数强度** | 图片参考、风格参考、重绘、结构控制等界面/API 参数 | 写入平台参数记录，不在通用模板中虚构百分比 |

#### 推荐强调方式

```text
本轮唯一修改目标：仅更换人物服装。

除服装及其自然褶皱、遮挡和反光外，
人物身份、脸型五官、发型、姿势、镜头和背景保持原图状态。

如果服装效果与人物身份、人体结构或原始姿势冲突，
优先保持人物身份、人体结构和姿势，服装自然适配。
```

#### 不可靠的伪权重写法

以下写法不能默认当作通用规则：

```text
人脸参考 70%，姿势参考 20%，风格参考 10%。
第一段权重最高，最后一段权重最低。
重复三次就会获得三倍权重。
大写、感叹号或括号一定增加权重。
P0 / P1 / P2 会被所有模型精确执行。
```

> 数值只有在平台提供真实参数或公开权重语法时才有明确意义。自然语言入口更有效的做法通常是减少矛盾、缩短竞争信息、明确编辑边界并分配参考职责。

### 3.4 使用具体可观察描述

尽量把低精度形容词改成可观察内容：

| 低精度词 | 更可执行的写法 |
|---|---|
| 漂亮 | 柔和鹅蛋脸、杏眼、自然眉形、协调五官比例 |
| 高级 | 克制配色、简洁构图、受控高光、真实材料表面 |
| 电影感 | 具体景别、光向、色彩对比、镜头和景深 |
| 真实 | 自然皮肤纹理、合理阴影、正确透视和材质反射 |
| 梦幻 | 柔雾、低对比高光、漂浮微粒、淡紫蓝渐变色调 |

### 3.5 参考图职责体系


> [!tip] 多参考图先分工
> 每张参考图只负责一类核心信息；冲突时优先保护身份或商品本体，避免所有参考图同时争夺同一属性。

![[参考图职责分配图_多图输入怎么写.png]]

推荐写法：

```text
R1：只负责人物身份，是主参考。
R2：只负责身体姿势，不覆盖 R1 的脸部特征。
R3：只负责服装款式和材质。
R4：只负责场景与光线。
```

原则：

- 主参考只设一个；
- 参考图越多，冲突概率越高；
- “融合所有参考”不等于模型能正确理解各自职责；
- 身份参考和风格参考冲突时，通常先保证身份，再降低风格强度。

### 3.6 正向描述优先，负面词按需

先告诉模型“正确结果长什么样”：

```text
自然手部结构，五指数量合理，关节弯曲符合动作。
真实布料褶皱，裙摆随坐姿自然垂落。
商品瓶身边缘笔直，玻璃反射清晰且受控。
```

只有出现稳定错误时，再增加对应排除项。一次添加大量负面词可能造成：

- 正向目标被稀释；
- 不同负面词互相冲突；
- 画面僵硬或失去细节；
- 难以判断到底是哪一条起作用。

### 3.7 允许合理适配

“保持人物姿势不变”不等于衣服褶皱、阴影和遮挡也要像素级不变。推荐区分：

```text
严格保持：身份、主体结构、非编辑区域、主要构图。
允许适配：服装褶皱、发丝摆动、接触阴影、材质反光和遮挡关系。
```

### 3.8 分阶段处理复杂任务

复杂任务建议拆分：

```text
阶段 1：先稳定主体或身份
阶段 2：调整姿势或服装
阶段 3：替换场景与光线
阶段 4：局部修复结构和细节
阶段 5：放大、排版和后期文字
```

不是所有任务都必须分五步，但当一次修改超过三个高耦合变量时，分步通常更容易收敛。

### 3.9 验收标准

提示词之外应保留人工验收。建议按顺序检查：

1. 主体身份或商品是否正确；
2. 人体、商品或空间结构是否合理；
3. 本轮修改目标是否完成；
4. 镜头、构图和裁切是否正确；
5. 光线、材质和风格是否符合要求；
6. 输出比例、版式和文字区域是否可用。

可量化项目示例：

```text
主体数量：1
人物完整度：头部至脚部均在画面内
Logo位置：与参考图一致
画幅：3:4
文字安全区：顶部保留约20%空白
系列机位：全部保持平视正面
```

> 百分比只适合描述版式和区域，不应伪装成模型内部的“身份权重百分比”。

### 3.10 迭代收敛方法

每轮只做一种调整：

- 删掉冲突信息；
- 强化一个保留项；
- 具体化一个变量；
- 增加一个必要限制；
- 调整一个镜头或输出参数。

记录：

```text
版本：V1 / V2 / V3
本轮只改：{一项}
结果改善：{是/否}
副作用：{出现了什么}
下一步：{保留/回退/继续测试}
```

连续数轮没有改善时，不要继续堆词。优先检查：

- 参考图是否冲突；
- 平台是否支持该控制；
- 是否应改用局部编辑、蒙版或结构参考；
- 是否应拆分任务；
- 是否需要后期完成文字、Logo 或精确结构。

### 3.11 常见误区

| 误区 | 修正方式 |
|---|---|
| 每次都填满所有槽位 | 根据任务复杂度使用极简、标准或专业版 |
| 负面词越多越好 | 只补当前实际出现的错误 |
| “8K、杰作”可以解决结构问题 | 用正确结构、材质、镜头和真实输出参数 |
| 多参考图一定更稳定 | 使用最小参考集并声明职责 |
| 一次修改越多越省时间 | 高耦合任务分阶段更容易收敛 |
| “完全不变”可以锁定所有像素 | 明确关键保留项，并允许光影和材质合理适配 |
| AI 海报文字可直接交付 | 生成主视觉，文字和 Logo 后期校对排版 |

## 负面提示词通用库

> [!info] 笔记关系
> **按需**



![[负面提示词使用图_什么时候该写.png]]

> [!tip] 负面词不是固定套餐
> 只写当前任务最容易出现的 3–8 个关键风险。自然语言平台优先写清任务边界；传统扩散模型再根据平台语法使用负面词字段。

![[负面提示词使用图_什么时候该写.png]]

> [!warning] 使用原则
> 负面词是纠错工具，不是每次必加的固定尾巴。优先使用正向描述，只有出现明确风险时才选择对应小包。

### 5.1 自然语言通用包

#### 结构问题

```text
避免额外肢体、手指数量异常、关节方向错误、结构断裂、主体重复和不合理遮挡。
```

#### 主体一致性

```text
不要改变人物身份、年龄段、脸部结构、商品形状、主要配色、包装结构或核心品牌元素。
```

#### 渲染与画质

```text
避免低清晰度、过度磨皮、塑料质感、蜡像感、脏污纹理、错误反射、平坦光线和过度锐化。
```

#### 构图与版式

```text
避免意外裁切、主体出框、无关拼版、重复画面、随机边框、错误留白、文字乱码和水印。
```

### 5.2 七类场景风险包

#### 人物视觉

```text
避免换脸、五官重塑、年龄漂移、性别变化、身体比例异常、额外手指、错误关节、眼神不一致和服装穿插。
```

#### 商品与商业视觉

```text
避免商品变形、比例变化、包装错位、错误接口、文字乱码、Logo漂移、标签增加、明显色差和廉价塑料感。
```

#### 场景与概念设计

```text
避免时代元素冲突、空间尺度失常、透视混乱、地标重复、无意义对象堆叠、焦点不清和远近层次缺失。
```

#### 插画与艺术创作

```text
避免角色数量错误、角色关系错位、画风漂移、线稿脏乱、颜色浑浊、叙事焦点不明和随机文字。
```

#### 平面与品牌设计

```text
避免信息拥挤、层级混乱、对齐不一致、Logo变形、品牌色偏移、文字乱码、超出安全区和装饰压过主信息。
```

#### 建筑与空间设计

```text
避免结构悬浮、门窗错位、尺度异常、垂直线弯曲、透视错误、家具穿插、动线堵塞和材料关系不合理。
```

#### 素材与制作辅助

```text
避免主体裁切、轮廓缺失、背景污染、阴影残留、透明边缘染色、无缝纹理接缝、多余对象和系列角度漂移。
```

### 5.3 传统扩散模型词组版

仅在平台明确支持传统负面提示词时使用，并根据实际错误选择：

```text
extra limbs, extra fingers, fused fingers, malformed hands,
deformed anatomy, duplicated subject, inconsistent face,
warped product, distorted logo, unreadable text,
blurry, low detail, plastic texture, waxy skin,
bad perspective, accidental crop, watermark, random border
```

> [!note]
> 词组版并不天然优于自然语言版。对话式图像模型通常更适合清晰的自然语言任务说明。

### 5.4 组合示例

#### 人物换装

```text
正向：保持人物身份、姿势、相机角度和背景，只更换黑色丝绒晚礼服；
裙摆与坐姿自然匹配，褶皱和接触阴影真实。

按需避免：换脸、体型变化、错误手指、服装穿插、裙摆断裂。
```

#### 商品换景

```text
正向：保持瓶身结构、包装、品牌色和Logo位置；
将背景替换为浅色天然石材台面，使用柔和侧逆光和受控玻璃反射。

按需避免：瓶身变形、包装错字、Logo漂移、多余标签和塑料质感。
```

#### 建筑室内

```text
正向：保持原空间墙体、门窗和动线，只更换木质软装与暖色灯光；
保持两点透视和真实材料尺度。

按需避免：墙体移动、门窗错位、家具穿插、透视错误和垂直线弯曲。
```

### 5.5 负面词精简方法

1. 首轮只写正向目标；
2. 出现稳定错误后，增加一个对应风险包；
3. 若错误消失，保留该项；
4. 若无改善，删除该项并检查参考图、蒙版或平台能力；
5. 不要同时加入互相否定的风格词，例如既排除“动漫感”又要求“半写实动漫”。
