### 模板 A：通用文生图

```text
【任务】
从零生成一张{人物 / 商品 / 场景 / 插画 / 建筑 / 素材}图像。
核心主题：{一句话主题}。

【保持】
无参考图。核心主体必须是：{主体定义和关键特征}。

【画面】
主体：{对象、外观和数量}
动作与状态：{动作、表情或状态}
环境：{地点、时间、天气和背景元素}
风格：{摄影 / 插画 / 动漫 / CG / 平面等}
镜头与构图：{景别、机位、角度、构图、焦距}
光线与色彩：{光向、光质、主色和影调}
材质与细节：{需要真实表现的表面和细节}

【限制】
重点顺序：{主体} > {结构} > {风格} > {环境细节}。
避免：{当前场景最可能出现的 1-4 个问题}。

【输出】
数量：{N}
画幅：{比例}
版式：{单图 / 拼版}
用途：{用途}
```

### 模板 B：人物身份保持

```text
【任务】
基于人物参考图生成新图。
本轮只改变：{姿势 / 表情 / 服装 / 场景 / 镜头中的一项或一个变量组}。

【保持】
R1 只负责人物身份，是主参考。
保持人物脸型、五官结构、年龄段、体型比例、肤色倾向和主要发型特征。
{其他参考图职责，如有}。

【画面】
动作与表情：{目标}
服装：{目标}
场景：{目标}
镜头与构图：{景别、机位和角度}
光线与质感：{人像光、皮肤、发丝和服装材质}

【限制】
人物身份 > 人体结构 > 本轮修改目标 > 风格与背景。
允许发丝、衣物褶皱和阴影随新场景自然适配。
避免换脸、年龄漂移、五官重塑、异常肢体和意外裁切。

【输出】
数量：{N}
画幅：{比例}
用途：{头像 / 写真 / 角色资产等}
```

### 模板 C：人物换装

```text
【任务】
编辑人物参考图，只更换人物的{服装 / 指定服装区域}。
编辑区域：{上衣 / 裙子 / 外套 / 鞋子 / 配饰 / 蒙版位置}。

【保持】
保持人物身份、脸部、发型、表情、身体姿势、摄影角度、背景和原有光线。
R1 负责人物与原图结构；R2 如有，只负责目标服装款式。

【画面】
目标服装：{款式、结构、长度、颜色、材质和细节}
穿着关系：{与身体、动作和遮挡如何匹配}
褶皱与边缘：{随姿势自然垂落、接缝完整、边缘连续}
光线与材质：{延续原图光向、阴影、反光和质感}

【限制】
人物身份和姿势 > 服装结构完整 > 材质与褶皱 > 背景。
非编辑区域保持不变。
允许服装褶皱、接触阴影和遮挡随身体姿势自然适配。
避免改变脸部、体型、姿势、相机角度或背景。

【输出】
保持原图画幅和构图；输出{数量}张独立图。
```

### 模板 D：局部编辑与修复

```text
【任务】
编辑原图，仅修复：{具体区域和问题}。
编辑区域：{位置、边界或蒙版范围}。
修复目标：{修复后应该呈现的正确结构}。

【保持】
保持非编辑区域、主体身份、整体姿势、原始构图、相机角度、背景和光线。
原图负责全部未修改内容。

【画面】
结构：{正确形状、连接、比例和遮挡}
材质：{与周边一致的表面、纹理和褶皱}
光影：{延续原图光向、亮度、阴影和反射}
边缘：{与周围自然衔接，无断裂和重复}

【限制】
非编辑区保持 > 主体结构 > 修复目标 > 材质细节。
只修改指定区域，不新增无关对象。
避免边界痕迹、重复纹理、结构断裂、颜色跳变和光线不一致。

【输出】
保持原图尺寸、画幅和构图；输出{数量}张。
```

### 模板 E：扩图

```text
【任务】
将原图向{上 / 下 / 左 / 右 / 四周}扩展。
只生成原画布之外的新增区域。

【保持】
保持原图内部主体、身份、姿势、构图、机位、透视、光线和色调不变。
原图是唯一结构与风格参考。

【画面】
新增区域：{需要延续或补充的场景元素}
空间关系：{地面、墙面、天空、家具或环境如何继续}
透视：延续原图消失点、尺度和视线高度。
光线与材质：延续原图光向、阴影、颜色和纹理密度。

【限制】
原图内部内容 > 透视连续 > 场景延续 > 新增细节。
避免重绘中心主体、改变原图比例、重复对象、接缝和光线断层。

【输出】
目标画幅：{比例或尺寸}
扩展方向：{方向}
输出：{数量}张独立图。
```

### 模板 F：风格转换

```text
【任务】
基于原图进行艺术风格转换。
只改变：艺术表现方式、媒介、笔触、渲染和色彩处理。

【保持】
保持主体身份、脸型五官、身体结构、姿势、主要构图和对象数量。
R1 负责原图内容；R2 如有，只负责目标风格。

【画面】
目标风格：{半写实动漫 / 水彩 / 油画 / 数字厚涂 / 电影级CG等}
风格强度：{轻度 / 标准 / 明显}
线条与表面：{线稿、笔触、皮肤、发丝、材质}
光线与色彩：{保留原光线 / 调整为指定氛围}

【限制】
身份与结构 > 构图 > 目标风格 > 装饰细节。
避免换脸、姿势变化、对象增加、构图重组和风格混杂。

【输出】
保持原图画幅，输出{数量}张{单图 / 对比图}。
```

### 模板 G：商品换景

```text
【任务】
保持商品本体不变，只更换商品背景和使用场景。

【保持】
R1 负责商品本体，是主参考。
保持商品形状、比例、包装、品牌元素、主配色、材质和可见文字区域。
R2 如有，只负责场景或布光。

【画面】
目标场景：{地点、台面、道具和环境元素}
商品状态：{摆放角度、是否打开、使用方式}
镜头与构图：{主图、四分之三、俯拍、微距、留白}
光线与材质：{商业棚拍、自然窗光、轮廓光、表面反射}

【限制】
商品结构和品牌 > 商品材质 > 卖点 > 场景与道具。
允许接触阴影和反射适应新场景。
避免商品变形、包装错字、Logo漂移、多余标签和无关配件。

【输出】
类型：{电商主图 / 场景图 / 海报}
数量：{N}
画幅：{比例}
文字留白：{无 / 位置}
```

### 模板 H：多参考融合

```text
【任务】
融合多张参考图生成一张新图。
本轮目标：{一句话结果}。
只改变：{变量或变量组}。

【保持】
R1：只负责{人物身份 / 商品本体}，是主参考。
R2：只负责{姿势 / 结构}。
R3：只负责{服装 / 材质}。
R4：只负责{场景 / 风格 / 光线}。
若参考冲突，以 R1 和本轮核心目标为准；其他参考不得覆盖主参考身份或商品结构。

【画面】
主体：{最终主体}
动作与状态：{最终动作}
服装或商品表现：{目标}
场景：{目标}
风格、镜头、光线和材质：{目标}

【限制】
主参考身份或本体 > 结构 > 本轮修改目标 > 风格和场景。
使用最少必要参考图。
避免平均混脸、商品结构混合、参考职责互相覆盖和无关元素继承。

【输出】
数量：{N}
画幅：{比例}
版式与用途：{说明}
```

### 4.2 模板精简规则

复制模板后：

1. 删除与当前任务无关的行；
2. 没有参考图时删除参考职责；
3. 简单文生图可合并为一个自然语言段落；
4. 负面项控制在当前风险范围；
5. 输出尺寸优先使用平台参数；
6. 不确定的细节不要编造为强制保留项。
