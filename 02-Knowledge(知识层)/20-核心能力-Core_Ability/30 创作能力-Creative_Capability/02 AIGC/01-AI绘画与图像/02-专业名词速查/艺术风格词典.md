# 艺术风格词典

## 效果图示例

> [!tip] 先看图，再看文
> 这张图用同一主体对比不同风格，适合先建立整体感知，再回头查具体术语。

![](示意图/艺术风格词典_六种风格效果示例.png)



> [!abstract] 小白一句话
> 风格不是一个标签，而是一套“怎么画”的规则。只写“日系、电影感、高级 CG”容易不稳定；最好说清**用什么媒介、人物有多夸张、有没有线稿、怎么上色、什么配色、怎样打光**。

## 一、六维风格公式


> [!image-plan]- 教学图规划｜风格六维控制面板
> - **图型**：雷达图 + 示例图
> - **学习目标**：理解风格不是单一标签，而是六个可独立调节的维度。
> - **画面结构**：左侧同一人物，右侧六维雷达与滑杆：媒介、造型、线条、上色、色彩、光影表面。
> - **圈注重点**：标出改变一个维度后的局部差异。
> - **建议文件名**：`艺术风格六维_控制面板.png`
> - **建议位置**：本子标题的概念说明之后、详细表格或模板之前。
> - **状态**：待生成；生成后存入当前目录的 `示意图/`，再替换本规划块或在其下方嵌入图片。

```text
媒介
+ 造型程度
+ 线条
+ 上色或渲染方式
+ 色彩体系
+ 光影与表面
```

示例：

```text
半写实动漫 + 接近真人比例 + 细薄线条 + 柔和数字厚涂
+ 高明度低饱和色彩 + 自然摄影光影和轻微纸张颗粒
```

## 二、先选大类：你想让它像什么

| 大类 | 白话理解 | 典型方向 |
|---|---|---|
| 摄影 | 像真实相机拍摄 | 人像摄影、商业棚拍、纪实、电影剧照 |
| 插画 | 明显由画师绘制 | 日系、赛璐璐、厚涂、绘本、编辑插画 |
| 传统绘画 | 模拟真实颜料和纸张 | 水彩、油画、水墨、粉彩、版画 |
| 三维渲染 | 像 3D 软件或游戏画面 | 写实 CGI、游戏角色、黏土、低多边形 |
| 平面设计 | 强调图形、文字区和版式 | 极简、几何、瑞士风格、复古海报 |
| 像素与图标 | 低分辨率或符号化视觉 | 像素画、等距图标、UI 插图 |

## 三、摄影类风格

| 风格 | 英文参考 | 白话特征 | 需要补充 |
|---|---|---|---|
| 写实摄影 | photorealistic photography | 像真实照片，材质和光影可信 | 镜头、时间、光线、肤质 |
| 纪实摄影 | documentary photography | 自然抓拍、不刻意摆拍 | 场景真实性、自然动作 |
| 商业棚拍 | commercial studio photography | 背景、反射和高光受控 | 布光、商品角度、留白 |
| 时尚摄影 | fashion editorial photography | 造型、姿态和视觉表达更强 | 服装、姿势、刊物感 |
| 电影剧照 | cinematic film still | 有叙事、层次、色彩和镜头语言 | 具体光线、景别、环境 |
| 复古胶片 | vintage film photography | 颗粒、柔和高光、色偏 | 胶片倾向、年代、不要过度损坏 |
| 即时成像 | instant-film look | 白边、低动态范围、生活感 | 构图和曝光 |
| 高端美妆 | beauty photography | 皮肤、妆容和眼神光精细 | 防过度磨皮和蜡像 |

## 四、动漫与数字插画

| 风格 | 英文参考 | 白话特征 | 常见风险 |
|---|---|---|---|
| 轻度半写实动漫 | lightly stylized semi-realistic anime | 很接近真人，只轻微动漫化五官 | 风格变化不明显 |
| 标准半写实动漫 | semi-realistic anime | 动漫五官与真实体积平衡 | 眼睛大小和皮肤需说明 |
| 美型增强半写实 | beauty-enhanced semi-realistic character | 五官更精致但保留真实比例 | 幼化、换脸、网红脸 |
| 日系清透插画 | luminous Japanese-style illustration | 细线、高明度、清透上色 | “日系”过泛、层次太淡 |
| 赛璐璐动漫 | cel-shaded anime illustration | 清晰线稿、少量块面阴影 | 过度平面、缺少体积 |
| 数字厚涂 | digital painterly rendering | 线稿弱、靠色块塑造体积 | 边缘糊、颜色脏 |
| 角色概念设计 | character concept art | 强调设定、材质、轮廓和功能 | 不等于最终宣传插画 |
| 编辑插画 | editorial illustration | 概念明确、图形化、适合文章 | 人物可能不追求写实 |
| 儿童绘本 | children's book illustration | 造型友善、色彩温暖、叙事清楚 | 不同年龄段风格差异大 |
| 漫画分镜 | comic panel art | 线条、格子、动作和阅读顺序 | 人物连续性和文字准确性 |

## 五、传统绘画与手工媒介

| 风格 | 英文参考 | 白话特征 | 提示词要点 |
|---|---|---|---|
| 水彩 | watercolor illustration | 透明叠色、纸张、边缘晕染 | 干湿边缘、留白、纸纹 |
| 水粉/不透明水彩 | gouache painting | 色块不透明、哑光、可覆盖 | 平涂和笔触 |
| 油画 | oil painting | 厚重颜料、画布、丰富明暗 | 古典/印象/写实方向 |
| 丙烯 | acrylic painting | 色彩鲜明、干得快、边缘清楚 | 厚涂或平涂倾向 |
| 彩铅 | colored pencil illustration | 细密排线、纸张颗粒 | 线条方向和叠色 |
| 铅笔素描 | graphite pencil sketch | 黑白线条、排线、明暗 | 纸张、线条粗细 |
| 炭笔 | charcoal drawing | 深黑、粉尘、粗犷边缘 | 高对比和擦抹 |
| 粉彩 | pastel illustration | 柔软粉末感、颜色轻柔 | 纸面颗粒和边缘 |
| 水墨 | Chinese ink wash painting | 墨色浓淡、留白、笔意 | 不只黑白，可有淡彩 |
| 工笔 | meticulous Chinese painting | 线条细密、设色克制、细节精致 | 轮廓线和传统材质 |
| 木刻/版画 | linocut / woodcut print | 高对比、刻线、纸张和油墨 | 颜色数量、刻线方向 |
| 拼贴 | collage art | 多种纸张和图像拼接 | 边缘、纸张层次、统一配色 |

## 六、三维与游戏风格

| 风格 | 英文参考 | 白话特征 | 常见风险 |
|---|---|---|---|
| 写实 CGI | photorealistic CGI | 真实三维材质和灯光 | 容易塑料感 |
| 高端游戏角色 | high-end game character rendering | 精细 PBR 材质、角色轮廓和电影灯光 | 不等于真人照片 |
| 风格化 3D | stylized 3D character | 比例和形状夸张但有三维体积 | 风格强度需说明 |
| 黏土风 | clay render / claymation look | 柔软手工黏土、指纹或塑形痕迹 | 变成光滑塑料 |
| 低多边形 | low-poly 3D render | 简化几何面、平面色块 | 细节过多会破坏风格 |
| 等距 3D | isometric 3D illustration | 固定等距视角、像游戏地图 | 透视不应突然变化 |
| 产品渲染 | product CGI rendering | 材质和反射高度受控 | 商品结构必须准确 |
| 建筑可视化 | architectural visualization | 空间、材料和全局照明 | 不可替代施工图 |

## 七、平面、图形和像素风格

| 风格 | 英文参考 | 白话特征 |
|---|---|---|
| 极简平面 | minimalist graphic design | 少元素、大留白、层级清楚 |
| 扁平插画 | flat vector illustration | 简单形状、少阴影、边缘干净 |
| 几何抽象 | geometric abstract design | 圆、方、线条组合成视觉 |
| 瑞士国际主义 | Swiss-style graphic design | 网格、无衬线字、理性留白 |
| 包豪斯风格 | Bauhaus-inspired design | 基础几何、原色、功能主义 |
| 复古海报 | retro poster design | 限制色、印刷颗粒、年代版式 |
| 丝网印刷 | screen-print poster | 平实色块、油墨叠印感 |
| 像素画 | pixel art | 清楚像素块、限制分辨率和色板 |
| 等距图标 | isometric icon illustration | 统一 30°/等距方向，适合 UI |
| 纸雕 | layered paper-cut illustration | 多层纸片、真实厚度和投影 |

## 八、半写实动漫五级


> [!image-plan]- 教学图规划｜半写实动漫五级连续谱
> - **图型**：五格渐变对比图
> - **学习目标**：展示从写实保留型到游戏角色型的造型、眼睛、皮肤和光影变化。
> - **画面结构**：五格使用同一人物、同一服装、同一构图，仅改变风格强度。
> - **圈注重点**：圈出眼睛比例、鼻嘴简化、皮肤纹理、发丝和光影渲染。
> - **建议文件名**：`半写实动漫五级_连续谱.png`
> - **建议位置**：本子标题的概念说明之后、详细表格或模板之前。
> - **状态**：待生成；生成后存入当前目录的 `示意图/`，再替换本规划块或在其下方嵌入图片。

| 级别 | 白话定义 | 推荐写法重点 |
|---|---|---|
| 1 轻度保留型 | 基本像真人，只稍微动漫化 | 真实比例、轻微眼型调整、自然皮肤 |
| 2 标准融合型 | 真人体积和动漫五官各占一半 | 细薄线条、柔和上色、眼睛不过大 |
| 3 美型增强型 | 明显美化轮廓和眼睛 | 保持身份、年龄，不幼化、不网红脸 |
| 4 日系清透型 | 更偏插画，轻线条和高明度 | 清透配色、柔光、纸张或数字插画感 |
| 5 游戏角色型 | 三维体积和精细材质最强 | CGI、PBR 材质、电影灯光、非真人照片 |

## 九、风格强度怎么写

| 强度 | 写法 |
|---|---|
| 轻度 | 仅轻微改变线条、色彩和表面，保留真实比例和身份 |
| 中度 | 明显改变画法，但保持主体结构和年龄 |
| 强度 | 允许形状、比例和材质大幅风格化 |

示例：

```text
轻度半写实动漫化，仅改变线条、上色和眼睛细节；保持原人物脸型、五官比例、年龄和真实身体比例。
```

## 十、可直接复制的提示词写法

### 标准半写实动漫

```text
标准半写实动漫，保持真实人物比例和身份辨识；眼睛精细但不过度放大，细薄线条，柔和数字厚涂，自然皮肤纹理，清晰发丝，电影级侧前光。
```

### 日系清透插画

```text
日系清透数字插画，轻薄线条，高明度低饱和配色，柔和透明上色，自然窗光，背景细节简化但保留空气感。
```

### 赛璐璐

```text
赛璐璐动漫风格，清晰稳定的轮廓线，两到三层块面阴影，颜色干净，光影方向统一，不使用写实皮肤毛孔或复杂照片纹理。
```

### 水彩

```text
透明水彩插画，冷压水彩纸纹理，湿画法背景与干画法主体边缘结合，颜色自然渗化，保留少量纸面留白。
```

### 高端游戏角色

```text
高端游戏角色渲染，真实三维体积，精细 PBR 服装和皮肤材质，受控电影灯光，轮廓清晰；保持角色身份，不呈塑料玩偶感。
```

## 十一、相近概念区别

| 容易混淆 | 正确区别 |
|---|---|
| 写实摄影 vs 写实 CGI | 摄影像真实相机；CGI 像三维渲染，即使很真实仍可能有数字感 |
| 半写实动漫 vs 游戏角色 | 前者可为二维插画；后者通常更强调三维材质和体积 |
| 水彩 vs 水粉 | 水彩透明；水粉更不透明、色块更厚 |
| 扁平插画 vs 赛璐璐 | 扁平插画更图形化；赛璐璐仍强调角色线稿和动漫阴影 |
| 复古 vs 做旧 | 复古是年代视觉语言；做旧只是添加磨损、颗粒或褪色 |
| 电影感 vs 电影剧照 | 电影感过泛；电影剧照还应有具体叙事、镜头和光线 |

## 十二、常见翻车与修复

- **只写“日系”效果不稳定**：补线条、上色、色彩和光线。
- **半写实动漫变成大眼幼童**：写“真实年龄、真实比例、眼睛不过度放大”。
- **CG 像塑料玩偶**：补皮肤粗糙度、微纹理、布料纤维和受控高光。
- **风格参考图覆盖人物身份**：明确参考图只负责画法，不负责脸和结构。
- **同时写水彩、油画、赛璐璐、摄影**：选择一个主媒介，最多加一个辅助表面效果。
- **用艺术家姓名代替说明**：改写为可观察的线条、色彩、媒介和构图特征。

## 十三、填入五槽位

- **目标画面设计 → 风格与媒介**：主风格、造型、线条、上色、色彩、表面；
- **保留项**：系列图必须保持同一画风时填写；
- **控制规则**：避免幼化、塑料感、风格混杂和身份覆盖。
