# 表达与沟通

将思想清晰、准确、有说服力地传达给他人的能力，是知识变现的最后一公里，也是影响力的核心来源。

## 学习路径

`结构化表达框架` → `写作基础` → `汇报与演讲` → `人际沟通技巧` → `语言能力`

## 核心知识点

### 结构化表达

**金字塔原理（麦肯锡）**
- 结论先行：先说结论，再给支撑论据
- 逻辑层次：每层观点是下层的总结，同层观点平行且互斥
- 结构类型：演绎推理（大前提→小前提→结论）/ 归纳分组（SCR 故事结构）

**PREP 法则**（口头表达）
- P（Point）：观点 → R（Reason）：理由 → E（Example）：例子 → P（Point）：重申

**SCR 故事结构**
- Situation（背景）→ Complication（冲突/问题）→ Resolution（解决/建议）

### 写作
- **核心原则**：一句话一个意思，段落主题句先行，少用形容词多用数据
- **写作流程**：大纲→初稿（关闭批判）→修改（开启批判）→精简（删去20%）
- **常见问题**：被动语态滥用、逻辑跳跃、术语堆砌不解释

### 汇报与演讲
- **三段式汇报**：背景+现状（30s）→ 核心结论/问题（1min）→ 建议行动（30s）
- **PPT 原则**：一页一观点；数据图表说话；少字多图
- **演讲焦虑**：充分准备（90%）+ 接受紧张（10%），焦虑不等于表现差

### 人际沟通
- **非暴力沟通（NVC）**：观察 → 感受 → 需要 → 请求（不评判，不命令）
- **积极倾听**：复述确认、追问细节、暂停反应而非立即回应
- **冲突处理**：对事不对人；分离立场与利益；寻找共同目标

### 语言能力（英语）
- 阅读：技术文档/英文书精读
- 写作：Email/技术文档/GitHub Issue 写作规范
- 口语：Shadowing 模仿法 + 刻意练习场景（会议/演示）
