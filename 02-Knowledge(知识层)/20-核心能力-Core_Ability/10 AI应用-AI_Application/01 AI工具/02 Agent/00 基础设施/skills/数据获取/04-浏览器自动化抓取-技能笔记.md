## 1. 总体架构

```
用户请求 → Claude Skill 调度 → 浏览器自动化引擎 → 目标页面 → JS/Regex 数据提取 → JSON/PowerShell 处理 → 本地文件
```

## 2. 工具链对比：Playwright CLI vs OpenCLI

| 维度 | Playwright CLI | OpenCLI |
|------|---------------|---------|
| 安装方式 | `npx @playwright/cli` | `npm install -g opencli` |
| 浏览器驱动 | 独立 Chromium 实例 | 复用用户 Chrome（Extension） |
| CF 穿透 | `--headed` | 自带（用户浏览器已登录） |
| 页面快照 | YAML (`snapshot`) | 紧凑文本树 (`state`) |
| 数据提取 | 正则解析 YAML | `eval` 直接返回 JSON |
| 内置提取 | 无 | `extract` → Markdown |
| 网络抓包 | tracing | `network` 拦截 XHR |
| 元素索引 | `@eN` (YAML ref) | `[N]` (紧凑索引) |
| 会话保持 | 单 browser 实例 | 命名 session 机制 |
| JSON 原生输出 | ❌ | ✅ |

## 3. OpenCLI 核心命令

```bash
# 健康检查
opencli doctor

# 打开页面（自动穿透 CF）
opencli browser <session> open "https://target.com"

# 获取页面状态（JSON 格式，元素带 [N] 索引）
opencli browser <session> state

# JS 执行（核心数据提取手段，返回 JSON）
opencli browser <session> eval "JSON.stringify({data: [...]})"

# 提取为 Markdown（长页自动分块）
opencli browser <session> extract

# 点击导航
opencli browser <session> click <N>
```

**架构**：
```
opencli daemon (port 19825) ←→ Chrome Extension (v1.0.20)
                ↕
         opencli CLI 命令
```

**关键优势**：
- `eval` 可在页面执行任意 JS 并返回 JSON，数据提取一步到位
- `state` 返回紧凑的文本树+元素索引，比 Playwright YAML 更易读
- 自带 `extract` 命令直接输出 Markdown
- 架构更轻量（Chrome Extension 复用用户日常浏览器，CF 穿透更稳定）

## 4. Playwright CLI 核心命令

```bash
# 启动（通过 wrapper）
PWCLI="$CODEX_HOME/skills/playwright/scripts/playwright_cli.sh"
"$PWCLI" open "https://target.com" --headed  # 有头模式穿透 CF

# 页面快照（YAML 格式的 accessibility tree）
"$PWCLI" snapshot

# 点击翻页
"$PWCLI" click e2083
```

**数据提取方式**：对 snapshot YAML 做正则匹配
```powershell
$pattern = '(?s)- link "([^"]+)" [ref=e\d+\] [cursor=pointer\]:\s+- /url: /target-path/\d+'
$matches = [regex]::Matches($content, $pattern)
```

**关键限制**：
- 元素 ref 在页面跳转后立即过期，必须重新 snapshot
- 无内置 Markdown 提取能力，需自行正则解析
- Cloudflare 验证必须在有头模式下等待浏览器自动完成 JS Challenge

## 5. 可复用爬虫模式

### 5.1 模式一：OpenCLI `eval` 一步提取（⭐ 推荐）

**一行命令 = 整页结构化 JSON**，无需解析 HTML/DOM/snapshot。

**通用模板**：
```js
opencli browser <session> eval "
(function() {
  const els = [...document.querySelectorAll('<CSS_SELECTOR>')];
  return JSON.stringify({
    source: location.href,
    count: els.length,
    data: els.map((el, i) => {
      const link = el.querySelector('a[href]');
      const title = link?.getAttribute('title')?.trim()
                 || link?.textContent?.trim() || '';
      const url = link?.getAttribute('href') || '';
      // 从文本中提取数字：/正则/
      const num = parseInt(el.textContent.match(/正则/)?.[1] || 0);
      return { id: i+1, title, url, num };
    })
  });
})()
"
```

**适用**：任何有规律的列表页（商品、文章、图片、排名），只要能找到稳定的 CSS 选择器。

**优点**：
- JS 原生 API 提取，零依赖
- 直接返回 JSON，无需二次解析
- `location.href` 自动记录来源 URL
- IIFE 包裹避免变量污染

### 5.2 模式二：Playwright snapshot + 正则提取

**适用于 JS 渲染后的 SPA 页面（React/Vue 动态列表）**，DOM 结构复杂但有固定 URL 模式。

```powershell
$content = Get-Content "snapshot.yaml" -Raw
# 关键：匹配 link 文本 + URL 路径的组合模式
$pattern = '(?s)- link "([^"]+)" [ref=e\d+\] [cursor=pointer\]:\s+- /url: (/target/\d+/.+)'
$matches = [regex]::Matches($content, $pattern)
foreach ($m in $matches) {
    $title = $m.Groups[1].Value
    $url = "https://domain.com" + $m.Groups[2].Value
}
```

**优点**：Playwright 生态兼容，适合已有 Playwright 基础设施的项目。

### 5.3 模式三：Cloudflare 穿透三板斧

| 优先级 | 方式 | 原理 | 成功率 |
|--------|------|------|--------|
| 1 | 复用已登录 Chrome | OpenCLI Chrome Extension 绑定用户日常浏览器，信任度最高 | ⭐⭐⭐⭐⭐ |
| 2 | 有头模式 + 等待 | `--headed` 真实窗口，JS Challenge 自动执行 | ⭐⭐⭐⭐ |
| 3 | 点击导航 | `click` 页码按钮翻页，保持 session 连续性 | ⭐⭐⭐ |

```bash
# OpenCLI 方式（自带 CF 穿透）
opencli browser sess open "https://target.com"

# Playwright 方式
"$PWCLI" open "https://target.com" --headed
sleep 15  # 等待 JS Challenge 完成
```

**翻页注意**：
- 翻页时 CF 可能重新验证，需要 `sleep 10-15` 等待
- 优先通过点击页码按钮导航（保持同一 session），而非直接 open 新 URL

### 5.4 模式四：去重对比框架

**跨数据源找差集**，标题先标准化再 HashSet 对比。

```powershell
$set = [System.Collections.Generic.HashSet[string]]::new()
foreach ($item in $sourceData) {
    $mainTitle = ($item.title -split '/')[0].Trim()
    $mainTitle = $mainTitle -replace '[\\/:*?"<>|\[\]]', ''
    $mainTitle = $mainTitle -replace '\s+', ''
    $set.Add($mainTitle.ToLower())
}
# 差集
$newOnes = $otherData | Where-Object {
    $t = ($_.title -split '/')[0].Trim() -replace '[\\/:*?"<>|\[\]]', '' -replace '\s+', ''
    -not $set.Contains($t.ToLower())
}
```

### 5.5 模式五：JSON 持久化 + 批量文件创建

```powershell
# 保存 JSON
$items | ConvertTo-Json -Depth 3 | Out-File -FilePath $path -Encoding UTF8

# 批量创建文件夹（编号+安全命名）
$num = 0
foreach ($item in $items) {
    $num++
    $name = ($item.title -split '/')[0].Trim() -replace '[\:*?"<>|]', '_'
    $folderName = "$($num.ToString('000')).$name"
    if ($folderName.Length -gt 240) { $folderName = $folderName.Substring(0, 240) }
    New-Item -ItemType Directory -Path "$targetDir\$folderName" -Force | Out-Null
}
```

## 6. 工具链选择速查

| 场景 | 推荐工具 | 原因 |
|------|---------|------|
| 有规律 CSS 选择器的列表页 | **OpenCLI + eval** | JS 一步到位，返回 JSON |
| SPA/动态渲染/无规律 DOM | Playwright + snapshot | 全量 a11y tree 后再解析 |
| 需要登录态 | OpenCLI（复用 Chrome） | 共享用户 Cookie/登录态 |
| 大量页面批量抓取 | Playwright 无头 | 更轻量，无 GUI 开销 |
| 反爬强的站 | OpenCLI（真 Chrome + Extension） | 降低被检测风险 |
| 仅需文本内容 | `opencli extract` | 直接输出 Markdown |
| 需要网络请求数据 | `opencli network` | 拦截 XHR/API 响应 |

**核心心法**：能用 `eval` 就不用 snapshot，能用 JS 原生选择器就不用正则，能复用浏览器登录态就不重新登录。

## 7. 最佳实践清单

1. **Cloudflare 穿透**：有头模式 + 等待 10-15s，让浏览器自动完成 JS Challenge
2. **翻页策略**：优先通过点击页码按钮导航（保持同一 session），而非直接 open 新 URL
3. **数据提取**：
   - OpenCLI: `eval` + IIFE 返回 JSON（推荐，一步到位）
   - Playwright: `snapshot` + 正则匹配 URL 模式
4. **变量隔离**：`eval` 中使用 IIFE `(function(){...})()` 避免重复声明报错
5. **去重**：标题标准化（去斜杠、去特殊字符、小写化）+ HashSet 差集
6. **命名安全**：文件夹名将 `\ / : * ? " < > |` 替换为 `_`
7. **元素引用过期**：snapshot/state 的 ref 在页面跳转后立即过期，每次导航后必须重新获取
