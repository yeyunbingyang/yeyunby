# os 模块 — 操作系统接口

## 一句话结论

> `os.path.join()` 跨平台拼接路径，`os.makedirs()` 递归建目录，`os.walk()` 遍历目录树——这三个是 os 模块最高频的 API。

---

## 一、路径与目录操作⭐

| 函数 | 描述 | 常用程度 |
|------|------|---------|
| `os.getcwd()` | 获取当前工作目录 | ⭐⭐⭐⭐⭐ |
| `os.chdir(path)` | 改变当前工作目录 | ⭐⭐⭐⭐ |
| `os.listdir(path='.')` | 列出目录内容 | ⭐⭐⭐⭐⭐ |
| `os.mkdir(path)` | 创建单个目录 | ⭐⭐⭐⭐ |
| `os.makedirs(path, exist_ok=False)` | 递归创建多层目录 | ⭐⭐⭐⭐⭐ |
| `os.rmdir(path)` | 删除空目录 | ⭐⭐⭐ |
| `os.rename(src, dst)` | 重命名文件/目录 | ⭐⭐⭐⭐ |
| `os.replace(src, dst)` | 重命名并覆盖目标 | ⭐⭐ |

```python
import os

# 获取和改变工作目录
print("当前目录:", os.getcwd())
os.chdir("..")

# 列出目录内容
for item in os.listdir('.'):
    print(f"  - {item}")

# 创建目录
os.mkdir("test_dir")                       # 单层
os.makedirs("a/b/c", exist_ok=True)         # 递归——exist_ok 跳过已存在

# 重命名 / 删除
os.rename("test_dir", "renamed_dir")
os.rmdir("renamed_dir")                     # 只能删空目录
```

## 二、路径处理（os.path 子模块）⭐

| 函数                        | 描述            | 常用程度  |
| ------------------------- | ------------- | ----- |
| `os.path.join(a, b, ...)` | 安全拼接路径        | ⭐⭐⭐⭐⭐ |
| `os.path.abspath(path)`   | 获取绝对路径        | ⭐⭐⭐⭐⭐ |
| `os.path.basename(path)`  | 获取文件名         | ⭐⭐⭐⭐⭐ |
| `os.path.dirname(path)`   | 获取目录部分        | ⭐⭐⭐⭐⭐ |
| `os.path.split(path)`     | 分割为(目录, 文件名)  | ⭐⭐⭐⭐  |
| `os.path.splitext(path)`  | 分割为(文件名, 扩展名) | ⭐⭐⭐⭐⭐ |
| `os.path.exists(path)`    | 检查路径是否存在      | ⭐⭐⭐⭐⭐ |
| `os.path.isfile(path)`    | 检查是否为文件       | ⭐⭐⭐⭐⭐ |
| `os.path.isdir(path)`     | 检查是否为目录       | ⭐⭐⭐⭐⭐ |
| `os.path.getsize(path)`   | 获取文件大小(字节)    | ⭐⭐⭐⭐  |
| `os.path.getmtime(path)`  | 获取最后修改时间      | ⭐⭐⭐   |

```python
import os

path = "/home/user/documents/report.pdf"

# 拆分
os.path.dirname(path)      # '/home/user/documents'
os.path.basename(path)     # 'report.pdf'
os.path.splitext(path)     # ('/home/user/documents/report', '.pdf')

# 拼接（跨平台——永不手写分隔符）
config_path = os.path.join("config", "settings", "app.ini")

# 判断
os.path.exists(path)       # True/False
os.path.isfile(path)       # True/False
os.path.isdir(path)        # True/False

# 信息
os.path.getsize(path)      # 字节数
os.path.abspath('file.txt')  # 相对 → 绝对
```

## 三、文件与目录遍历

| 函数 | 描述 | 常用程度 |
|------|------|---------|
| `os.walk(top)` | 递归遍历目录树 | ⭐⭐⭐⭐⭐ |
| `os.scandir(path='.')` | 高效遍历目录（返回迭代器）| ⭐⭐⭐⭐ |

```python
import os

# os.walk —— 递归遍历（最常用）
for root, dirs, files in os.walk('/project'):
    # 跳过隐藏目录
    dirs[:] = [d for d in dirs if not d.startswith('.')]

    for file in files:
        full_path = os.path.join(root, file)
        print(full_path)

# os.scandir —— 更高效（Python 3.5+）
with os.scandir('.') as entries:
    for entry in entries:
        if entry.is_file():
            print(f"文件: {entry.name} ({entry.stat().st_size} 字节)")
        elif entry.is_dir():
            print(f"目录: {entry.name}/")
```

## 四、系统与进程信息

| 函数/属性 | 描述 | 常用程度 |
|----------|------|---------|
| `os.name` | 'nt'(Windows) 或 'posix'(Linux/Mac) | ⭐⭐⭐⭐ |
| `os.sep` | 路径分隔符 | ⭐⭐⭐ |
| `os.linesep` | 行分隔符 | ⭐⭐ |
| `os.getenv(key)` | 获取环境变量 | ⭐⭐⭐⭐⭐ |
| `os.environ` | 环境变量字典 | ⭐⭐⭐⭐ |
| `os.getpid()` | 当前进程 ID | ⭐⭐ |

```python
import os

# 平台检测
print(os.name)       # 'nt' 或 'posix'

# 环境变量
home = os.environ.get('HOME')            # ✅ 推荐：不存在返回 None
username = os.getenv('USERNAME')          # 简化写法
path = os.environ.get('PATH', '/usr/bin') # 带默认值

# 遍历所有环境变量
for key, value in os.environ.items():
    print(f'{key} = {value}')
```

## 五、文件操作与权限

| 函数 | 描述 |
|------|------|
| `os.remove(path)` | 删除文件 |
| `os.stat(path)` | 获取文件详细状态 |
| `os.access(path, mode)` | 检查权限（R_OK / W_OK / X_OK）|
| `os.utime(path)` | 修改时间戳 |

```python
import os

# 删除文件
os.remove('old_file.txt')

# 文件状态
stat = os.stat('file.txt')
print(f"大小: {stat.st_size} 字节")
print(f"修改时间: {stat.st_mtime}")

# 权限检查
os.access('file.txt', os.R_OK)  # 可读？
os.access('file.txt', os.W_OK)  # 可写？
```

## 六、跨平台注意事项

```python
import os, sys

# 判断平台
if sys.platform == 'win32':
    default_path = os.path.join('C:', 'Users', 'Public')
else:
    default_path = os.path.join('/home', os.environ.get('USER', 'user'))

# 环境变量名因平台而异
home_var = 'HOME' if os.name == 'posix' else 'USERPROFILE'
print(os.getenv(home_var))
```

## 关键概念

- **os.path.join**：跨平台路径拼接——永不用 `+` 手写分隔符
- **os.walk**：递归遍历目录树——`(root, dirs, files)` 三元组
- **os.makedirs(exist_ok=True)**：递归建目录 + 跳过已存在——一条命令替代 try/except
- **os.environ.get()**：安全读环境变量——不存在返回 None 不报错

## 可行动建议

- 所有路径拼接用 `os.path.join()`
- 遍历目录优先 `os.scandir()`（比 `os.listdir()` 更快）
- 递归建目录用 `os.makedirs(path, exist_ok=True)`
- 文件操作加 `os.path.exists()` 前置判断
- 执行外部命令用 `subprocess.run()`，不用 `os.system()`
