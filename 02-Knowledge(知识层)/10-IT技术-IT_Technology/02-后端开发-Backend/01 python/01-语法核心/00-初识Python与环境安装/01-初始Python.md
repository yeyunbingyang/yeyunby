# 初始 Python

## 1. 计算机是怎么工作的

> 写程序之前，先弄清楚计算机的基本构成。
> 由硬件系统和软件系统所组成，没有安装任何软件的计算机称为裸机。

硬件（英文名Hardware），计算机硬件是指计算机系统中的各种物理装置的总称。

| 部件   | 作用        | 类比      |
| ---- | --------- | ------- |
| 运算器  | 算术 + 逻辑运算 | 计算的大脑   |
| 控制器  | 指挥协调各部件   | 大脑的指挥中枢 |
| 存储器  | 存放程序和数据   | 记忆      |
| 输入设备 | 键盘、鼠标等    | 感官      |
| 输出设备 | 显示器、打印机等  | 表达      |

CPU = 运算器 + 控制器。
软件 = 系统软件（Windows/Linux/macOS）+ 应用软件（QQ/微信/浏览器）。

## 2. 程序是什么

**程序** = 一组计算机能执行指令的集合，用人能读懂的**编程语言**写成，再翻译成机器能执行的二进制。

### 编译 vs 解释

|      | 编译                     | 解释                    |
| ---- | ---------------------- | --------------------- |
| 翻译方式 | 整体翻译特定的可执行代码，然后执行可执行代码 | 逐句翻译，立即执行             |
| 代表语言 | C、C++、Go               | Python、JavaScript、PHP |
| 执行速度 | 快                      | 慢                     |
| 源码保护 | 无需公开源码                 | 源码即成品                 |

---

## 3. 编程语言简史

- **机器语言**（1946）：纯二进制，`0000,0000,000000010000` ≈ `LOAD A, 16`
- **汇编语言**：用助记符替代二进制，效率高但不通用
- **高级语言**：接近自然语言，跨平台，需编译器/解释器翻译

## 4. 为什么选 Python

### 起源
![[Pasted image 20260612234505.png]]

1989 年圣诞节，荷兰人 Guido van Rossum 想创造一门「介于 C 和 Shell 之间」的语言——功能全面、易学易用、可扩展。名字来自他喜欢的剧 _Monty Python's Flying Circus_。

### 设计哲学

**优雅、明确、简单。** 一件事最好只有一种做法。

### 能做什么

| 领域         | 说明                          |
| ---------- | --------------------------- |
| Web 后端     | Django / Flask / FastAPI    |
| 网络爬虫       | Scrapy / requests           |
| **系统网络运维** | 脚本化日常操作                     |
| 数据分析       | NumPy / Pandas / Matplotlib |
| 人工智能与机器学习  | PyTorch / TensorFlow        |
| 自动化测试      | pytest / Selenium           |


### 优缺点速览

**优点**：易上手、代码少、生态强、跨平台、胶水语言、免费开源

**缺点**：执行速度慢（解释型通病）、源码无法加密

## 6. Python 解释器

| 解释器         | 特点                    |
| ----------- | --------------------- |
| **CPython** | 官方版，C 语言实现，最广泛使用      |
| IPython     | 增强交互体验（`In [1]:` 提示符） |
| PyPy        | JIT 编译，执行速度更快         |
| Jython      | 运行在 JVM 上             |
| IronPython  | 运行在 .NET 平台上          |

> 日常开发选 **CPython**，性能敏感场景可关注 PyPy。
