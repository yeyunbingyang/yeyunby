# requests 核心请求与响应

## 一句话结论

> `requests.get(url, headers=..., params=...)` 发送请求，`response.content.decode()` 拿到响应——前者伪装成浏览器，后者精准控制编码；配合 `timeout`、`verify`、`proxies` 三个辅助参数，覆盖爬虫请求侧的绝大多数场景。

---

## 一、模块简介

### 是什么

`requests` 是一个第三方 HTTP 库，底层封装了 Python 标准库的 `urllib`，提供了更简洁、更人性化的 API。

### 为什么用它

|      | `urllib`                 | `requests`               |
| ---- | ------------------------ | ------------------------ |
| 代码量 | 较多，冗长                   | 简洁，通常几行                  |
| 易用性 | API 分散                   | API 统一，语义清晰              |
| 编码处理 | 需手动处理                    | 自动识别编码                   |
| 工作中 | 基本不用                     | 爬虫工程师最常用的 HTTP 库         |

### 官方文档

- **快速上手**：要求**精读**，涵盖日常爬虫 90% 的使用场景
- **高级用法**：要求**了解**，知道能力边界即可（Session、SSL 证书、流式上传等），用到时再查阅

## 三、基本使用：第一个 GET 请求

```python
import requests

url = "https://www.baidu.com"
response = requests.get(url)

print(response.text)   # 网页源码（字符串类型）
```

三步流程：

```
import requests → 定义 URL → requests.get(url) → response.text → 拿到网页源码
```

## 四、Response 响应对象

`requests.get()` 等请求方法返回一个 `Response` 对象，包含服务器返回的所有信息。

### 4.1 response.text vs response.content

|      | `response.text`        | `response.content`     |
| ---- | ---------------------- | ---------------------- |
| 类型   | `str`（字符串）             | `bytes`（二进制）           |
| 解码方式 | requests 自动推测编码并解码      | 不解码，保留原始字节             |
| 中文   | 推测错误则**乱码**            | 需手动 `decode()`         |
| 推荐度  | 简单场景                   | **推荐方案**，精准控制          |

```python
# 推荐：手动解码，精准控制
print(response.content.decode('utf-8'))
```

### 4.2 自动获取编码

```python
# 查看 requests 自动识别的编码
print(response.encoding)              # 如 'ISO-8859-1'

# 查看响应头中声明的编码
print(response.headers.get('content-type'))

# 从 HTML meta 标签推测编码（需安装 chardet/cchardet）
import chardet
detected = chardet.detect(response.content)
print(detected['encoding'])
```

### 4.3 Response 常用属性速查

| 属性 / 方法                    | 类型          | 说明                |
| -------------------------- | ----------- | ----------------- |
| `response.text`            | `str`       | 响应体，字符串形式         |
| `response.content`         | `bytes`     | 响应体，二进制形式         |
| `response.url`             | `str`       | 最终请求 URL          |
| `response.status_code`     | `int`       | HTTP 状态码          |
| `response.headers`         | `dict`      | 响应头               |
| `response.cookies`         | `CookieJar` | 响应 Cookie         |
| `response.json()`          | `dict`      | 将 JSON 响应转为字典     |
| `response.request.headers` | `dict`      | **实际发出的**请求头（调试用） |

## 五、发送带 headers 的请求

### 5.1 为什么必须带 headers

不带 headers → 服务器识别出 `python-requests/x.x.x` 的 UA → 返回阉割版内容（如百度首页仅 2287 字节）。

### 5.2 基本用法

```python
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                  "AppleWebKit/537.36 (KHTML, like Gecko) "
                  "Chrome/120.0.0.0 Safari/537.36"
}

response = requests.get(url, headers=headers)
print(len(response.content))      # 数据量远大于不带 headers 的情况
```

### 5.3 如何获取正确的 headers

1. F12 → Network → 勾选 **Preserve log**
2. 刷新页面 → 点击第一条 Document 请求
3. 右侧 Headers → **Request Headers** → 复制需要的字段

### 5.4 headers 三剑客

| 请求头          | 优先级    | 说明       |
| ------------ | ------ | -------- |
| `User-Agent` | ⭐⭐⭐ 必带 | 标识浏览器类型  |
| `Referer`    | ⭐⭐ 按需  | 防盗链校验时必需 |
| `Cookie`     | ⭐⭐ 按需  | 需要登录态时携带 |

> 初期只带 `User-Agent` 就足以解决大多数基础反爬。

## 六、发送带参数的 GET 请求（params）

### 6.1 方式一：直接拼接 URL

```python
url = "https://www.baidu.com/s?wd=python&pn=10"
response = requests.get(url, headers=headers)
```

优：直观。劣：参数多时难读，特殊字符需手动编码。

### 6.2 方式二：params 字典（推荐）

```python
url = "https://www.baidu.com/s"
params = {"wd": "python", "pn": "10"}

response = requests.get(url, headers=headers, params=params)
print(response.url)   # https://www.baidu.com/s?wd=python&pn=10
```

|      | URL 拼接 | params 字典 |
| ---- | ------ | --------- |
| 可读性  | 参数多时很乱 | 结构清晰      |
| 特殊字符 | 需手动编码  | 自动 URL 编码 |
| 推荐度  | 快速测试   | **正式代码推荐** |

### 6.3 完整示例

```python
import requests

url = "https://www.baidu.com/s"
headers = {"User-Agent": "Mozilla/5.0 ..."}
params = {"wd": "python"}

response = requests.get(url, headers=headers, params=params)

# 验证
if "python" in response.content.decode("utf-8"):
    print("成功获取搜索结果")
```

## 七、timeout 超时控制

### 7.1 为什么需要

- 默认超时 **180 秒**，太长
- 网络波动或目标无响应时代码会一直卡住

### 7.2 用法

```python
response = requests.get(url, timeout=3)   # 3 秒未建立连接则抛异常
```

### 7.3 配合 try/except

```python
try:
    response = requests.get(url, timeout=3)
except requests.exceptions.Timeout:
    print("请求超时，跳过")
```

> 建议：国内网站 5-10 秒，快速接口 2-3 秒。所有正式爬虫代码都应设置 `timeout`。

## 八、verify 参数 — SSL 证书处理

### 8.1 问题场景

访问自签名证书或非正规 CA 证书的 HTTPS 网站时，报 `SSLError: certificate verify failed`。

### 8.2 解决方案

```python
# 关闭证书验证
response = requests.get(url, verify=False)

# 可选：消除警告
import urllib3
urllib3.disable_warnings(urllib3.exceptions.InsecureRequestWarning)
```

| | `verify=True`（默认）| `verify=False` |
|---|---|---|
| 证书验证 | 开启 | 关闭 |
| 适用 | 正规 CA 网站 | 自签名或非正规证书 |

> 遇到 `SSLError` → 加 `verify=False`，解决 99% 的证书问题。

## 九、代理 proxies

### 9.1 概念

代理（proxy）是一个 IP + 端口，帮你转发请求——目标服务器看到的 IP 是代理的而不是你的。

### 9.2 正向代理 vs 反向代理

| | 正向代理 | 反向代理 |
|---|---|---|
| 谁用 | 客户端（浏览器/爬虫）| 服务端 |
| 客户端知道目标吗 | **知道** | **不知道** |
| 典型例子 | VPN、爬虫代理 IP | Nginx 负载均衡 |

> 爬虫只用正向代理。

### 9.3 代理 IP 分类（按匿名度）

| 类型   | 服务器能否发现真实 IP | 说明           |
| ---- | ------------ | ------------ |
| 透明代理 | **能**        | 直接透传真实 IP    |
| 匿名代理 | 不能，但知道是代理    | 服务器知道这是代理请求  |
| 高匿代理 | **完全不能**     | 服务器甚至不知道这是代理 |

> 爬虫首选**高匿代理**。

### 9.4 用法

```python
proxies = {
    "http": "http://IP地址:端口号",
    "https": "https://IP地址:端口号"
}

response = requests.get(url, headers=headers, proxies=proxies)
```

### 9.5 常见问题

| 现象 | 原因 |
|------|------|
| 代码一直卡住 | 代理服务器无响应 |
| ConnectionError | 代理不可用或协议不匹配 |

> 免费代理存活时间短、不稳定。生产环境建议自建代理池：爬取多个代理网站 → 验证可用性 → 维护可用列表。

## 请求参数速查总表

| 参数        | 用途        | 示例                           |
| --------- | --------- | ---------------------------- |
| `headers` | 伪装浏览器     | `{"User-Agent": "..."}`      |
| `params`  | GET 查询字符串 | `{"wd": "python"}`           |
| `data`    | POST 请求体  | `{"key": "value"}`           |
| `timeout` | 超时控制      | `timeout=3`                  |
| `verify`  | SSL 证书验证  | `verify=False`               |
| `proxies` | 代理转发      | `{"http": "http://ip:port"}` |

## 关键概念

- **Response 对象**：请求的返回值，包含 `text`、`content`、`status_code`、`url`、`headers`、`cookies`
- **编码乱码**：`response.text` 自动推测可能出错 → 用 `response.content.decode('utf-8')`
- **Preserve log**：DevTools 选项，勾选后刷新不清空请求日志
- **查询字符串（Query String）**：URL 中 `?` 后面的 `key=value` 部分
- **正向代理**：客户端主动设置的转发服务器
- **代理池**：维护一批可用代理 IP 的集合，定期更新淘汰

## 可行动建议

- 任何爬虫第一步：从浏览器 DevTools 复制 `User-Agent`，构建 headers 字典
- GET 参数统一用 `params={}` 字典传递，不手动拼接 URL
- 所有爬虫代码都设 `timeout`，配合 `try/except`
- 遇到 `SSLError` 加 `verify=False`
- 不确定时打印 `response.url` 和 `response.request.headers` 验证实际发出的请求
