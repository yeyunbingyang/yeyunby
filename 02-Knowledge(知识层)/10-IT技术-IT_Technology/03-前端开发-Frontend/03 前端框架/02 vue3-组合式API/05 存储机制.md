## 存储机制

在浏览器中，常见的存储机制包括 `localStorage`、`sessionStorage` 和 `cookies`。这些存储机制可以用来保存数据，如用户设置、表单数据、会话信息等。每种存储机制有不同的特性和适用场景。下面是对这些存储机制的详细讲解：

### 1. `localStorage`

- **描述：** `localStorage` 提供了一个在浏览器窗口之间持久保存数据的机制。数据在浏览器关闭后不会被删除，可以长期保存，直到用户主动清除数据或网站使用 JavaScript 删除数据。

- **存储容量：** 大约 5-10MB（不同浏览器可能有所不同）。

- **用法：**

```
// 存储数据
localStorage.setItem('key', 'value');

// 获取数据
const value = localStorage.getItem('key');

// 删除数据
localStorage.removeItem('key');

// 清除所有数据
localStorage.clear();
```

- **适用场景：** 存储需要持久化的用户设置、主题选择、用户认证信息等。

### 2. `sessionStorage`

- **描述：** `sessionStorage` 提供了一个在一个浏览器窗口或标签页的生命周期内存储数据的机制。数据在窗口或标签页关闭后会被删除。

- **存储容量：** 大约 5-10MB（不同浏览器可能有所不同）。

- **用法：**

```
// 存储数据
sessionStorage.setItem('key', 'value');

// 获取数据
const value = sessionStorage.getItem('key');

// 删除数据
sessionStorage.removeItem('key');

// 清除所有数据
sessionStorage.clear();
```

- **适用场景：** 存储会话期间的临时数据，如表单状态、购物车数据等。

### 3. `cookies`

- **描述：** Cookies 是一种在客户端存储少量数据的机制，每次请求都会发送到服务器。它们可以设置过期时间，但数据大小有限。

- **存储容量：** 每个 cookie 的大小限制为 4KB。

- **用法：**

```
// 设置 cookie
document.cookie = "key=value; expires=Thu, 01 Jan 2025 00:00:00 UTC; path=/";

// 获取 cookie
function getCookie(name) {
  const value = `; ${document.cookie}`;
  const parts = value.split(`; ${name}=`);
  if (parts.length === 2) return parts.pop().split(';').shift();
}

// 删除 cookie
document.cookie = "key=; expires=Thu, 01 Jan 1970 00:00:00 UTC; path=/";
```

- **适用场景：** 用于存储会话标识、用户认证信息等需要在服务器端验证的数据。

### 比较总结

- **持久性：**

- `localStorage`: 长期存储。

- `sessionStorage`: 当前会话存储。

- `cookies`: 可设置过期时间，但每次请求都会发送给服务器。

- **存储容量：**

- `localStorage` 和 `sessionStorage`: 5-10MB。

- `cookies`: 4KB 每个 cookie。

- **数据传输：**

- `localStorage` 和 `sessionStorage`: 数据仅存储在客户端。

- `cookies`: 数据在每次 HTTP 请求中都会发送给服务器。

- **使用场景：**

- `localStorage`: 持久化用户设置。

- `sessionStorage`: 会话期间的数据。

- `cookies`: 需要与服务器交互的数据，如身份验证信息。
