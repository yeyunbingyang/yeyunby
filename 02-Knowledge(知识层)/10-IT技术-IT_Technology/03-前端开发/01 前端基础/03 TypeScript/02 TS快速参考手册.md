# TypeScript 快速参考手册

## 一、为什么需要 TS？

JS 是动态类型——参数类型不确定，传错了代码就崩：

```js
function test(obj) {}
test('hello,world')       // obj 是 string
test(() => console.log())  // obj 是 function，完全不同的行为
```

TS 在编译时加类型约束，**代码运行前就发现错误**：

```ts
function test(msg: string) {}        // 限制参数只能是 string
function test(msg: Function) { msg() } // 限制参数只能是函数
```

**核心价值**：更好的 IDE 提示 + 编译时类型检查 + 阅读框架源码更容易。

---

## 二、快速入门

```bash
npm install -g typescript   # 安装编译器
tsc xxx.ts                  # 编译，生成 .js（类型信息被擦除）
tsc --target es6 xxx.ts     # 指定 ES 版本
```

```ts
interface User {
  name: string
  age: number
}
function test(u: User): void {
  console.log(u.name, u.age)
}
test({ name: 'zhangs', age: 18 })
```

## 三、类型速查表

### 3.1 全部类型一览

| 类型                   | 例           | 备注        |
| -------------------- | ----------- | --------- |
| `string`             | `'hello'`   | 字符串       |
| `number`             | `123`       | 数字        |
| `boolean`            | `true`      | 布尔        |
| `null` / `undefined` | `null`      | Nullish   |
| `string[]`           | `['a','b']` | 数组        |
| `any`                | 任意值         | 相当于关闭类型检查 |
| `void`               | 无返回值        | 函数返回值类型   |
| `type` / `interface` | 自定义结构       | 复杂对象类型    |
| `() => void`         | 函数签名        | 函数类型      |
| `'a' \| 'b'`         | 字面量联合       | 限制取值      |
| `<T>`                | 泛型参数        | 类型也当参数传   |

### 3.2 标注位置

| 位置 | 语法 | 示例 |
|------|------|------|
| 变量 | `let x: type = val` | `let name: string = 'John'` |
| 参数 | `(p: type)` | `function greet(name: string) {}` |
| 返回值 | `(): type` | `function add(): number { return 1 }` |
| 泛型 | `<T>` | `function ref<T>(n: T): Ref<T> {}` |

> 变量和返回值的类型标注**通常可省略**——TS 能根据字面量/返回值自动推断。

## 四、复杂类型：type vs interface

### 4.1 基本定义

```ts
// type 定义
type Cat = {
  name: string
  age: number
}

// interface 定义（效果相同）
interface Cat {
  name: string
  age: number
}

const c1: Cat = { name: '小白', age: 1 }
```

### 4.2 核心区别

| 特性 | `interface` | `type` |
|------|-------------|--------|
| 声明合并 | ✅ 同名自动合并 | ❌ 不支持 |
| 被类实现 | ✅ `class X implements I` | ❌ 不能直接实现 |
| 联合/交叉 | ❌ | ✅ `A \| B`、`A & B` |
| 适用场景 | 对象结构、类的契约 | 联合类型、交叉类型、类型别名 |

**选择原则**：定义对象形状 → `interface`；需要联合/交叉/别名 → `type`。

```ts
// interface 声明合并
interface Person { name: string }
interface Person { age: number }
// Person 现在有 name 和 age 两个属性

// type 做交叉类型
type Person = { name: string }
type Age = { age: number }
type PersonWithAge = Person & Age
```

### 4.3 可选属性

```ts
interface Cat {
  name: string
  age?: number       // age 可选
}
const c: Cat = { name: '小花' }  // ✅ age 可不传
```

### 4.4 鸭子类型

```ts
interface Cat { name: string }
function test(cat: Cat) { console.log(cat.name) }

const c1 = { name: '小白', age: 1 }
test(c1)  // ✅ 形状匹配就通过
```

### 4.5 方法类型

```ts
interface Api {
  foo(): void
  bar(str: string): string
}
function test(api: Api) {
  api.foo()
  console.log(api.bar('hello'))
}
```

### 4.6 字面量类型

```ts
function printText(s: string, alignment: 'left' | 'right' | 'center') {
  console.log(s, alignment)
}
printText('hello', 'aaa')  // ❌ 只能是 left/right/center
```

## 五、泛型

把「类型」也当作参数传递，避免写重复的类型定义：

```ts
// 没泛型时——三个只有 value 类型不同的 interface
interface RefString  { value: string }
interface RefNumber  { value: number }
interface RefBoolean { value: boolean }

// 有泛型时——一个搞定
interface Ref<T> { value: T }
const r1: Ref<string>  = { value: 'hello' }
const r2: Ref<number>  = { value: 123 }
const r3: Ref<boolean> = { value: true }
```

函数泛型：

```ts
function ref<T>(n: T): Ref<T> {
  return { value: n }
}
const v1 = ref('hello')   // Ref<string>
const v2 = ref(123.3333)  // Ref<number>
v1.value.toLowerCase()    // ✅ 有准确的类型提示
v2.value.toFixed(2)
```

## 六、Nullish 类型

```ts
function test(x?: string | null) {
  console.log(x?.toUpperCase())  // x 可能是 undefined / string / null
}
test('aaa')
test(null)
test()         // 不传也行，因为有 ?
```

## 七、类（简述）

TS 中 class 不是重点，底层仍是 JS 原型，但它与 interface 配合能提供完整类型约束：

```ts
class User {
  readonly name: string    // TS 特有：只读属性
  constructor(name: string) {
    this.name = name
  }
  study() {
    console.log(`[${this.name}]正在学习`)
  }
}
const u = new User('张三')
u.name = '李四'  // ❌ 编译错误，readonly
```

类与接口配合：

```ts
interface Flyable { fly(): void }
class Animal { name: string; constructor(name: string) { this.name = name } }
class Bird extends Animal implements Flyable {
  fly() { console.log(`${this.name}在飞翔`) }
}
const b: Flyable & Animal = new Bird('小花')
```
