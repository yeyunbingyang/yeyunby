# 运算符与表达式

## 一般运算符

- `+ - * / % **`
- `+= -= *= /= %= **=`
- `++ --`
- 位运算、移位运算
- `== != > >= < <=`

熟悉了 js 的数据类型了，那么我们需要学习 js 中的运算法，js 中的运算规则绝大多数还是和 java 中一致的，具体运算符如下：

| 运算规则 | 运算符 |
|----------|--------|
| 算术运算符 | `+ , - , * , / , % , ++ , --` |
| 赋值运算符 | `= , += , -= , *= , /= , %=` |
| 比较运算符 | `> , < , >= , <= , != , == , ===` 注意 `==` 会进行类型转换，`===` 不会进行类型转换 |
| 逻辑运算符 | `&& , \|\| , !` |
| 三元运算符 | `条件表达式 ? true_value : false_value` |

- `==`：只比较值是否相等，不区分数据类型，哪怕类型不一致，`==` 也会自动转换类型进行值得比较
- `===`：不光比较值，还要比较类型，如果类型不一致，直接返回 false

```js
var age = 20;
var _age = "20";
var $age = 20;

alert(age == _age);   // true ，只比较值
alert(age === _age);  // false ，类型不一样
alert(age === $age);  // true ，类型一样，值一样
```js

在 js 中，虽然不区分数据类型，但是有时候涉及到数值计算，还是需要进行类型转换的，js 中可以通过 `parseInt()` 函数来进行将其他类型转换成数值类型：

```js
// 类型转换 - 其他类型转为数字
alert(parseInt("12"));    // 12
alert(parseInt("12A45")); // 12
alert(parseInt("A45"));   // NaN (not a number)
```js

除此之外，在 js 中，还有非常重要的一点是：0, null, undefined, "", NaN 理解成 false，反之理解成 true：

```js
if(0){ // false
    alert("0 转换为false");
}
if(1){ // true
    alert("除0和NaN其他数字都转为 true");
}
if(""){ // false
    alert("空字符串为 false, 其他都是true");
}
if(null){ // false
    alert("null 转化为false");
}
if(undefined){ // false
    alert("undefined 转化为false");
}
```js

流程控制语句 if，switch，for 等和 java 保持一致，此处不再演示。

## 特殊运算符

### 1) ===

严格相等运算符，用作逻辑判等

```js
1 == 1      // 返回 true
1 == '1'    // 返回 true，会先将右侧的字符串转为数字，再做比较
1 === '1'   // 返回 false，类型不等，直接返回 false
```js

typeof 查看某个值的类型

```js
typeof 1     // 返回 'number'
typeof '1'   // 返回 'string'
```js

### 2) ||

【不推荐，能看懂就行】

需求，如果参数 n 没有传递，给它一个【男】

**推荐**做法

```js
function test(n = '男') {
    console.log(n);
}
```js

你可能的做法

```js
function test(n) {
    if(n === undefined) {
        n = '男';
    }
    console.log(n);
}
```js

还可能是这样

```js
function test(n) {
    n = (n === undefined) ? '男' : n;
    console.log(n);
}
```js

一些老旧代码中可能的做法（不推荐）

```js
function test(n) {
    n = n || '男';
    console.log(n);
}
```js

它的语法是

```js
值1 || 值2
```js

**如果值1 是 Truthy，返回值1，如果值1 是 Falsy 返回值 2**

### 3) ?? 与 ?.

#### ??

需求，如果参数 n 没有传递或是 null，给它一个【男】

如果用传统办法

```js
function test(n) {
    if(n === undefined || n === null) {
        n = '男';
    }
    console.log(n);
}
```js

用 ??

```js
function test(n) {
    n = n ?? '男';
    console.log(n);
}
```js

语法

```js
值1 ?? 值2
```js

- 值1 是 nullish，返回值2
- 值1 不是 nullish，返回值1

#### ?.

需求，函数参数是一个对象，**可能包含有子属性**（去除访问对象中属性的问题）

例如，参数可能是

```js
let stu1 = {
    name: "张三",
    address: {
        city: '北京'
    }
};

let stu2 = {
    name: "李四"
}

let stu3 = {
    name: "李四",
    address: null
}
```js

现在要访问子属性（有问题）

```js
function test(stu) {
    console.log(stu.address.city)
}
```js

现在希望当某个属性是 nullish 时，短路并返回 undefined，可以用 `?.`

```js
function test(stu) {
    console.log(stu.address?.city)
}
```js

用传统办法

```js
function test(stu) {
    if(stu.address === undefined || stu.address === null) {
        console.log(undefined);
        return;
    }
    console.log(stu.address.city)
}
```js

### 4) ...【传递赋值】

展开运算符

**作用1：打散数组，把元素传递给多个参数**

```js
let arr = [1,2,3];

function test(a,b,c) {
    console.log(a,b,c);
}
```js

需求，把数组元素依次传递给函数参数

传统写法

```js
test(arr[0],arr[1],arr[2]);  // 输出 1,2,3
```js

展开运算符写法

```js
test(...arr);                // 输出 1,2,3
```js

- 打散可以理解为【去掉了】数组外侧的中括号，只剩下数组元素

**作用2：复制数组或对象**

```js
let arr1 = [1,2,3];
let arr2 = [...arr1];        // 复制数组

let obj1 = {name:'张三', age: 18};
let obj2 = {...obj1};        // 复制对象
```js

**注意**：**展开运算符复制属于浅拷贝**，例如

```js
let o1 = {name:'张三', address: {city: '北京'} }
let o2 = {...o1};
```js

**作用3：合并数组或对象**

合并数组

```js
let a1 = [1,2];
let a2 = [3,4];

let b1 = [...a1,...a2];      // 结果 [1,2,3,4]
let b2 = [...a2,5,...a1]     // 结果 [3,4,5,1,2]
```js

合并对象

```js
let o1 = {name:'张三'};
let o2 = {age:18};
let o3 = {name:'李四'};

let n1 = {...o1, ...o2};     // 结果 {name:'张三',age:18}
let n2 = {...o3, ...o2, ...o1}; // 结果{name:'李四',age:18}
```js

- 复制对象时出现同名属性，后面的会覆盖前面的

### 5) [] {}【接收赋值】

解构赋值

#### []

用在声明变量时

```js
let arr = [1,2,3];
let [a, b, c] = arr;  // 结果 a=1, b=2, c=3
```js

用在声明参数时

```js
let arr = [1,2,3];

function test([a,b,c]) {
    console.log(a,b,c)   // 结果 a=1, b=2, c=3
}

test(arr);
```js

#### {}

用在声明变量时

```js
let obj = {name:"张三", age:18};
let {name,age} = obj;  // 结果 name=张三, age=18
```js

用在声明参数时

```js
let obj = {name:"张三", age:18};

function test({name, age}) {
    console.log(name, age); // 结果 name=张三, age=18
}

test(obj)
```js

变量名要与属性名一致
