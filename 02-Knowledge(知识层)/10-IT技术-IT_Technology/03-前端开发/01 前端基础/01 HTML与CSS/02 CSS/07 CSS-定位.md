### 1. 相对定位

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1747149390287-f0ec4346-7eeb-4265-8edb-d9694c3fd8db.png)

相对原来位置进行调整、可以设置显示层级。

拓展：很少单独使用相对定位，一般是与其他定位方式配合使

#### 如何设置相对定位

给元素设置 position:relative 即可实现相对定位。

可以使用 left、 right、 top、bottom四个属性调整位置。

#### 相对定位的参考点在哪里？

相对自己原来的位置

#### 相对定位的特点

1. 不会脱离文档流，元素位置的变化，只是视觉效果上的变化，不会对其他元素产生任何影响。
2. 定位元素的显示**层级**比普通元素高，无论什么定位，显示层级都是一样的。

**默认规则是：**

- 定位的元素会盖在普通元素之上。
- 都发生定位的两个元素，后写的元素会盖在先写的元素之上。

3. left 不能和 right 一起设置，top和bottom不能一起设置。

4. 相对定位的元素，也能继续浮动，但不推荐这样做。
5. 相对行为的元素，也能通过margin调整位置，但不推荐这样做。

注意：绝大多数情况下，相对定位，会与绝对定位配合使用。

**应用场景：**

1.微调元素、不会改变文档流

2.配合绝对定位使用

### 2. 绝对定位

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1747150019545-64cd965a-cbc1-4538-8489-c9d19b05b19e.png)

参考包含块：包含这个元素的具有定位属性的父元素

使用场景：子级设置绝对定位，父级设置相对定位【不脱标】（子绝父相）

#### 如何设置绝对定位？

给元素设置 position: absolute 即可实现绝对定位。

可以使用 left、 right、 top、 bottom 四个属性调整位置。

![](https://cdn.nlark.com/yuque/0/2024/png/40487410/1732802295264-663b201c-7b67-431c-9596-2524f86ed591.png)

文字没有像浮动溢出

#### 绝对定位的参考点在哪里？

参考它的**包含块**。

什么是包含块？
1.对于没有脱离文档流的元素：包含块就是父元素；
2.对于脱离文档流的元素：包含块是**第一个拥有定位属性的祖先元素**（如果所有祖先都没定位，那包含块就是整个页面）。

#### 绝对定位元素的特点

1. 脱离文档流，会对后面的兄弟元素、父元素有影响。

2. left不能和 right一起设置， top和 bottom不能一起设置。

3. 绝对定位、浮动不能同时设置，如果同时设置，浮动失效，以定位为主。

4. 绝对定位的元素，也能通过 margin调整位置，但不推荐这样做。

5. 无论是什么元素（行内、行内块、块级）设置为绝对定位之后，都变成了定位元素。

何为定位元素？ —— 默认宽、高都被内容所撑开，且能自由设置宽高。

### 3.固定定位

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1747149478692-b1a4bad1-e7a2-4afb-9612-d327f2f1174f.png)

#### 如何设置为固定定位

给元素设置 position: fixed 即可实现固定定位。

可以使用 left、 right、 top、bottom四个属性调整位置。

会固定在窗口的一个位置

![](https://cdn.nlark.com/yuque/0/2024/png/40487410/1732806362068-f1099d9b-d572-4164-b2b0-0ba34d1c1219.png)

![](https://cdn.nlark.com/yuque/0/2024/png/40487410/1732806424913-ace80187-682b-48e2-b904-aa511964fa84.png)

#### 固定定位的参考点在哪里？

参考它的**视口**

什么是视口？—— 对于 PC浏览器来说，视口就是我们看网页的那扇"窗户"。

#### 固定定位元素的特点

1. 脱离文档流，会对后面的兄弟元素、父元素有影响。

2. left不能和 right一起设置， top和 bottom不能一起设置。

3. 固定定位和浮动不能同时设置，如果同时设置，浮动失效，以固定定位为主。

4. 固定定位的元素，也能通过 margin调整位置，但不推荐这样做。

5.无论是什么元素（行内、行内块、块级）设置为固定定位之后，都变成了定位元素。

### 4.粘性定位

#### 如何设置为粘性定位

给元素设置 position:sticky 即可实现粘性定位。

可以使用 left、 right、 top、bottom四个属性调整位置，不过最常用的是 top值。

#### 粘性定位的参考点在哪里？

**离它最近的一个拥有"滚动机制"的祖先元素**，即便这个祖先不是最近的真实可滚动祖先。【常见body 具有滚动效果】

#### 粘性定位元素的特点

**不会脱离文档流**，它是一种专门用于窗口滚动时的新的定位方式。

最常用的值是top 值。

粘性定位和浮动可以同时设置，但不推荐这样做。

粘性定位的元素，也能通过magin 调整位置，但不推荐这样做。

粘性定位和相对定位的特点基本一致，不同的是：粘性定位可以在元素到达某个位置时将其固定。

### 5.定位层级

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1747149496868-5c0f0b52-c841-4b8e-b2d3-04533f32ed2e.png)

1. 定位元素的显示层级比普通元素高，无论什么定位，显示层级都是一样的。
2. 如果位置发生重叠，默认情况是：后面的元素，会显示在前面元素之上。
3. 可以通过 css 属性z-index调整元素的显示层级。
4. **z-index**的属性值是数字，没有单位，值越大显示层级越高。
5. 只有定位的元素设置z-index才有效。
6. 如果 z-index 值大的元素，依然没有覆盖掉 z-index 值小的元素，那么请检查其包含块的层级。⭐

![](https://cdn.nlark.com/yuque/0/2024/png/40487410/1732808329763-c5f41d97-b445-41a8-a8e3-9ca375f9c6b4.png)

### 6.定位的特殊应用

注意：
1.发生固定定位、绝对定位后，元素都变成了定位元素，默认宽高被内容撑开，且依然可以设置宽高。
2.发生相对定位后，元素依然是之前的显示模式。
3.以下所说的特殊应用，只针对 绝对定位 和 固定定位 的元素，不包括相对定位的元素。

#### 让定位元素的宽充满包含块

1. 块宽 想与 包含块一致，可以给定位元素同时设置 left 和 right 为 0

2. 高度 想与 包含块一致， top和bottom设置为0

#### 让定位元素在包含块中居中

方案一：⭐

```css
left:0; right:0; top:0; bottom:0; margin:auto;
```

方案二：

```css
left: 50%;
top: 50%;
margin-left: 负的宽度一半;
margin-top: 负的高度一半;
```

注意：该定位的元素必须设置宽高！！！

#### 水平垂直居中

![](https://cdn.nlark.com/yuque/0/2025/png/40487410/1747149466437-c5a11c61-3843-4368-9b7b-046a3f02c752.png)

需要移动相对定位元素

移动方法：1.减少外边距 2. transfrom

基于定位的水平垂直居中方案总结

#### 一、绝对定位 + margin: auto（需指定宽高）

```css
.parent { position: relative; }
.child {
  position: absolute;
  top: 0; bottom: 0; left: 0; right: 0;
  margin: auto;
  width: 200px;  /* 必须指定宽高 */
  height: 100px;
}
```

**原理**：通过四边定位为0使子元素虚拟占满父容器，再通过`margin:auto`实现居中。
**注意**：若不指定宽高，子元素将默认撑满父容器。

---

#### 二、绝对定位 + 负margin（需已知宽高）

```css
.child {
  position: absolute;
  top: 50%; left: 50%;
  margin-top: -50px;  /* 高度的一半 */
  margin-left: -100px;  /* 宽度的一半 */
}
```

**特点**：通过`top/left:50%`定位元素左上角至父容器中心，再通过负margin回拉实现居中。
**局限**：需精确计算元素尺寸，不适用于动态内容。

---

#### 三、绝对定位 + transform（无需指定宽高）

```css
.child {
  position: absolute;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);
}
```

**优势**：利用`translate(-50%, -50%)`动态计算元素自身宽高，实现精准居中。
**兼容性**：支持IE9+，推荐现代项目首选方案。

---

#### 四、相对定位 + transform（保持文档流）

```css
.parent { position: relative; }
.child {
  position: relative;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);
}
```

**适用场景**：需保持元素在文档流中相对原位置偏移时使用。
**注意**：父容器需设置定位属性（如`relative`）以限制偏移范围。

---

#### 五、fixed定位居中（相对视口）

```css
.child {
  position: fixed;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);
}
```

**特性**：元素始终相对于浏览器窗口居中，滚动页面时位置不变。
**典型应用**：模态框、全局悬浮按钮等需要固定位置的场景。

---

### 方案对比与选择建议

**推荐实践**：

1. 优先使用`transform`方案，适应性强且代码简洁
2. 需要兼容旧版IE时，选择`margin:auto`或负margin方案
3. 现代项目可结合`flex`布局（非定位方案）简化实现

注：所有定位方案需确保父容器设置`position: relative`（absolute/fixed定位时）或保持默认文档流（relative定位时）。
