# 实战：资源站点批量下载器——DrissionPage 自动化 + OCR 验证码

## 1. 项目背景

### 1.1 需求

需要从某漫画站点批量下载约 144 个章节的 ZIP 压缩包。站点特征：

| 特性 | 说明 |
|------|------|
| Cloudflare 防护 | 无法使用 requests 直接访问 |
| 需登录认证 | 浏览器已有登录 Session |
| 数字加法验证码 | 每次下载前需输入 a+b=？ |
| 广告弹窗 | 点击下载按钮后弹出广告标签页 |

### 1.2 站点流程

```
搜索漫画 → 获取章节列表
  ↓
逐章处理：
  点击下载按钮 → 弹出验证码弹窗 → 广告弹窗出现
  ↓
关闭广告标签 → OCR 识别验证码 → 填入验证码 → 提交
  ↓
验证码正确 → 浏览器触发下载事件 → 下载 ZIP
验证码错误 → 页面无响应 → 刷新重试
```

## 3. 核心挑战与解决方案

### 3.1 Cloudflare 保护

**问题**：站点使用 Cloudflare 防护，requests 直接请求返回 403/验证页面。

**方案**：复用本地 Chrome 浏览器中已有的登录 Session，绕过 Cloudflare。

```python
from DrissionPage import ChromiumPage

# 连接到已登录的 Chrome（端口 9333）
page = ChromiumPage(9333)
page.get('https://example.com')  # 自动携带登录态 Cookie
```

### 3.2 广告标签弹窗处理

**问题**：点击下载按钮会同时弹出验证码弹窗和广告新标签页，广告页可能干扰后续操作。

**方案**：记录进入下载页时的标签页 ID（`tab_id`），触发弹窗后只保留该标签页，其余全部关闭。

```python
# 进入下载页，记录标签页 ID
page.get(download_url)
dl_tid = page.tab_id

# 触发弹窗
js_click('a.triggerpop')

# 关闭所有非下载页标签
for tid in list(page.tab_ids):
    if tid != dl_tid:
        page.close_tabs(tid)
page.activate_tab(dl_tid)  # 切回下载页
```

**关键点**：用 `tab_id` 而不是 URL 来标识下载页，因为 Cloudflare 重定向/广告跳转可能导致 URL 变化。

### 3.3 验证码输入失败

**问题**：使用 DP 的 `el.input()` 方法填入验证码结果不生效，前端框架可能监听 `input`/`change` 事件。

**方案**：先用 DP 的 `.input()` 方法模拟键盘输入（会触发框架事件），兜底使用 JS 直接设置 value + 派发事件。

```python
el = page.ele('#invite_verification')
if el:
    el.input(str(captcha_ans), clear=True)  # 模拟键盘输入
else:
    page.run_js(f'''
        var el = document.getElementById("invite_verification");
        el.value = "{captcha_ans}";
        el.dispatchEvent(new Event("input", {{bubbles: true}}));
        el.dispatchEvent(new Event("change", {{bubbles: true}}));
    ''')
```

### 3.4 验证码正确性判定

**问题**：提交验证码后，只有验证码正确才会触发浏览器下载事件；如果错误，页面无任何反应（不刷新、不跳转、不报错）。如何区分"正确"和"错误"？

**方案**：利用 DP 的 `wait.download_begin()` 方法——它能监听浏览器下载开始事件，而该事件只在验证码正确并提交成功后触发。

```python
page.run_js('document.getElementById("download_submit")?.click()')

try:
    page.wait.download_begin(timeout=5)
    print('验证码正确！')
    page.wait.all_downloads_done(timeout=60)
except:
    print('验证码错误，重试')
    page.refresh()
```

**核心业务逻辑**：
```
验证码正确 → 服务器返回 ZIP → 浏览器触发 download_begin
验证码错误 → 页面无任何反应
```

### 3.5 下载文件接管与重命名

**问题**：浏览器下载到本地目录的文件名是随机的（如 `181026.zip` 或 UUID），需要重命名为固定的 `{标题}_{章节}.zip`。

**方案**：等待下载完成后，扫描目录找到最新的 ZIP 文件，重命名为目标文件名。

```python
# 等待下载开始
page.wait.download_begin(timeout=5)
page.wait.all_downloads_done(timeout=60)

# 找到最新的 zip 文件
newest = None
for fname in os.listdir(save_dir):
    fp = os.path.join(save_dir, fname)
    if fname.endswith('.zip') and _zip_intact(fp):
        mtime = os.path.getmtime(fp)
        if newest is None or mtime > newest[1]:
            newest = (fp, mtime)

# 重命名
src = newest[0]
os.rename(src, target_path)
```

**补充**：`os.rename()` 在不同盘符间会失败，需用 `shutil.move()` 兜底。

### 3.6 OCR 识别率

**问题**：验证码是两位数字加法（如 `12+34`），字体固定但彩色背景干扰大，Tesseract 识别率约 60-85%。

**方案**：多预处理策略 + 正则精确匹配加法表达式。

```python
def _ocr_captcha(captcha_img_el):
    # JS Canvas 截图（无质量损失）
    b64 = page.run_js('''
        var c = document.createElement("canvas");
        var img = document.querySelector("img[src*='captcha']");
        c.width = img.naturalWidth;
        c.height = img.naturalHeight;
        c.getContext("2d").drawImage(img, 0, 0);
        return c.toDataURL("image/png").split(",")[1];
    ''')
    
    orig = Image.open(io.BytesIO(base64.b64decode(b64)))
    
    # 多种预处理路径
    for thr in (50, 80, 100, 120):  # 反色 + 不同阈值
        img = invert(convert(orig, 'L')).point(lambda x: 0 if x < (255-thr) else 255)
        text = pytesseract.image_to_string(img, config='--psm 8 -c tessedit_char_whitelist=0123456789+=')
        
        # 精确匹配加法表达式
        m = re.search(r'(\d{1,2})\s*\+\s*(\d{1,2})', text)
        if m:
            return int(m.group(1)) + int(m.group(2))
```

**关键**：用 `re.search(r'(\d{1,2})\s*\+\s*(\d{1,2})')` 精确匹配加法，比 `re.findall(r'\d+')` 更可靠——避免把 `104` 错当成 `10+4`。

## 4. 关键技术详解

### 4.1 DrissionPage 核心 API

| API | 用途 | 示例 |
|-----|------|------|
| `ChromiumPage(port)` | 连接已有 Chrome | `ChromiumPage(9333)` |
| `page.get(url)` | 导航到 URL | `page.get('https://...')` |
| `page.ele(selector)` | 查找元素 | `page.ele('#id')` |
| `page.run_js(code)` | 执行 JavaScript | `page.run_js('alert(1)')` |
| `page.tab_id` | 当前标签页 ID | 用于标识下载页 |
| `page.tab_ids` | 所有标签页 ID | 用于遍历关闭广告 |
| `page.close_tabs(id)` | 关闭指定标签 | `close_tabs(ad_tid)` |
| `page.set.download_path(path)` | 设置下载目录 | `set.download_path('./downloads')` |
| `page.wait.download_begin(timeout)` | 等待下载开始 | 判断验证码是否正确 |
| `page.wait.all_downloads_done(timeout)` | 等待下载全部完成 | 确保文件完整 |
| `page.cookies()` | 获取浏览器 cookies | `[{'name':'x','value':'y'}]` |
| `page.actions.type(text)` | 模拟键盘输入 | `actions.type('123')` |

### 4.2 标签页管理策略

```
进入下载页 → dl_tid = page.tab_id
  ↓
点击 triggerpop（可能有广告新标签）
  ↓
遍历 page.tab_ids → 关闭所有 ≠ dl_tid 的标签
  ↓
page.activate_tab(dl_tid)  → 回到下载页
```

**不依赖 URL 匹配**：因为 Cloudflare / 广告跳转可能导致 URL 变化。

### 4.3 验证码截图方式对比

| 方式 | 质量 | 适用场景 |
|------|------|----------|
| `element.get_screenshot('file.png')` | 中等（受DPI/CSS缩放影响） | DP4 默认方式 |
| JS Canvas toDataURL | 高（原图质量） | 本方案优选 |
| requests 下载原图 | 最高 | 但可能被 Cloudflare 拦截 |

### 4.4 OCR 预处理策略

```
原图 (RGB)
  ↓
灰度化 (L)
  ↓
多条独立预处理路径并行尝试：

反色处理 → 二值化(不同阈值) → 5倍放大 → Tesseract OCR
灰度低阈值 → 5倍放大 → Tesseract OCR
纯黑像素检测 (R+G+B<50) → 5倍放大 → Tesseract OCR
```

每种预处理路径配合 3 种 PSM 模式：
- `--psm 7`：单行文本
- `--psm 8`：单个单词
- `--psm 6`：统一的文本块

### 4.5 状态文件设计

```json
{
  "https://example.com/album_download/123456": {
    "chapter_title": "第1話",
    "chapter_url": "https://example.com/album_download/123456",
    "save_path": "X:/downloads/标题_第1話.zip",
    "status": "done",
    "verified_size": 11140031,
    "verified_mtime": 1782313187
  }
}
```

- `key = 章节 URL`：用于去重
- `status = pending | done | failed`：用于断点续传
- 启动时校验：`done` 但文件不存在的 → 自动改回 `pending`

## 5. 遇到的坑与解决方案

| 问题 | 症状 | 原因 | 解决 |
|------|------|------|------|
| `ChromiumPage(addr_or_port=9333)` 报错 | DP4 不支持关键字参数 | DP4 改为位置参数 | `ChromiumPage(9333)` |
| 年龄验证按钮 `#chk_cover` 点击报错 | `NoRectError` | 元素 0×0 尺寸，DP click 失败 | `page.run_js(...).click()` |
| `.tabs` 属性不存在 | `AttributeError` | DP4 改用 `tabs_count`/`tab_ids` | `page.tabs_count` |
| `el.screenshot()` 不存在 | `AttributeError` | DP4 元素截图用 `get_screenshot()` | `el.get_screenshot('file.png')` |
| 验证码输入失败 | 填入后 value 为空 | 前端框架监听 input 事件 | `el.input()` 模拟键盘输入 |
| `download_begin` 返回 bool | 无法拿到下载路径 | DP4 的 download_begin 只做信号 | 配合目录扫描 |
| `os.rename()` 跨盘失败 | FileNotFoundError | 临时文件在 C 盘，目标在 X 盘 | `shutil.move()` 兜底 |
| state.json 记录 done 但无文件 | 假成功 | 旧版本 rename 失败被静默吞掉 | 启动时校验文件存在性 |
| OCR 连续失败不刷新 | 死循环 | 同一张验证码多次 OCR 失败 | 10 次失败后 refresh+重新 triggerpop |

## 6. 优化方向

### 6.1 OpenCV 轮廓分割

```
原图 → OTSU 二值化 → findContours → 按 x 排序 → 单字符 OCR
```

替代整图 OCR，识别率从 85% 提升到 95%+。

### 6.2 模板匹配

采集数字 0-9 和加号 `+` 的模板图像，用 `cv2.matchTemplate()` 直接匹配，无需 OCR。

| 方案 | 成功率 |
|------|--------|
| 元素截图 + Tesseract 整图 | 60-85% |
| 原图下载 + Tesseract 整图 | 85-95% |
| 原图 + OpenCV 分割 + 单字符 OCR | 95-99% |
| 模板匹配 | 99%+ |

### 6.3 多线程下载

当前是单线程逐章处理，可改为多线程并发：
- 线程数：2-4 个
- 每个线程独立处理一章
- 共享 state.json（加锁写入）
