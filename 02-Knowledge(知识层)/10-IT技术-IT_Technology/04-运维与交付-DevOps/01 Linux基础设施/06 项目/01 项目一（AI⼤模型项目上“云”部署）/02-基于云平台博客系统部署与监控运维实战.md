## 1. 云服务器介绍

### 1.1 什么是云服务器

云服务器(Cloud Server)，又称云主机或弹性计算服务(Elastic Compute Service, ECS)，是基于云计算技术提供的一种虚拟化服务器。云服务器利用虚拟化技术，将物理服务器的计算资源(如CPU、内存、存储等)封装成一个或多个独立的虚拟环境，用户可以通过互联网远程访问和使用这些资源。

![[917672b99a.png]]

### 1.2 常见的云服务器厂商有哪些

国内市场上提供云服务器厂商，主要包括有：阿里云、腾讯云、华为云、UCloud、百度云、金山云、京东云。

国外市场上提供云服务器厂商，主要包括有：AWS、微软Azure、GCP。

在全球市场份额中，AWS位居第一，占比32%； 而在国内排名第一为阿里云，占比高达36%

### 1.3 云服务器有哪些特点

1. **虚拟化技术**：利用虚拟化将一台物理服务器分割成多个独立的虚拟机，每个虚拟机都有自己的操作系统和资源。
2. **按需分配**：根据业务需要随时申请、调整和释放资源，真正做到用多少付多少。
3. **高可用性和弹性**：服务器故障时，虚拟机可以自动迁移到其他正常运行的物理服务器上，保证业务不中断。
4. **自动化管理**：内置自动扩展、负载均衡、备份和恢复等工具，大幅简化运维工作。
5. **全球分布**：在多个地区设有数据中心，用户可选择最接近客户的服务器，降低访问延迟。
6. **安全性**：提供网络安全、数据加密和访问控制等多层防护措施，确保数据安全。
7. **灵活性和可扩展性**：可以随时增减服务器数量和配置，轻松应对业务波动。
8. **成本效益**：无需大额硬件投入和维护，根据实际使用量付费，显著降低IT成本。

### 1.4 云服务器具备的优势

1. **降低IT成本**：按需付费，避免高额的设备购买和维护费用。
2. **提高业务灵活性**：快速部署和弹性伸缩，帮助企业迅速应对市场变化。
3. **增强数据安全性和可靠性**：专业安全措施和备份恢复机制，全方位保障数据安全。
4. **简化运维管理**：自动化管理工具让运维更简单，无需专业IT技能也能轻松管理。
5. **促进业务创新**：灵活的计算资源支持，使企业能专注于核心业务和持续创新。

## 2. 如何申领阿里云ECS服务器

### 2.1 选择ECS实例规格

服务器根据其CPU、内存、网络、存储等配置，可以拆分为不同规格的服务器，用户在使用云服务器应根据自己的需求选择合适的云服务器产品。

一般选择实例规格，需要考虑以下几个主要因素：

- 1- 计算能力

- CPU：如果应用程序需要处理大量的计算任务，如大规模数据分析或机器学习运算，建议选择具有更多CPU核心的实例类型
- 内存：如果应用程序需要处理大量数据或运行多个应用程序，建议选择具有更大内存的实例类型

- 2- 存储容量

- 磁盘类型：阿里云提供多种磁盘类型，包括SSD云盘、高效云盘和普通云盘。SSD云盘适用于对I/O性能要求较高的应用场景，高效云盘适用于对I/O性能要求不高的应用场景，普通云盘适用于对I/O性能要求较低的应用场景
- 存储容量：如果应用程序需要存储大量数据或频繁进行数据读写操作，建议选择具有更大存储容量的实例类型

- 3- 网络性能

- 带宽：如果应用程序需要处理大量网络请求或进行高速数据传输，建议选择具有更高带宽的实例

不同实例规则的使用场景和特定：

1- 经济性实例：适用于个人开发者、学生、小微企业，特别适用于中小型网站建设、开发测试、轻量级应用等场景。

2- 通用算力型实例：适用于Web前端等计算密集场景，提供高性价比的算力支持

3- 计算型实例：适用于计算密集型应用程序，如科学建模、高性能Web服务器等

4- 企业级实例：适用于对计算能力和稳定性有较高要求的企业应用场景，如大型Web应用、数据库服务器等

5- 异构计算实例：适合需要特定硬件加速的场景，如深度学习、图像处理等

一般在选择的时候根据要运行的应用来确定对应实例类型、实例配置、地域等；

### 3.3 ECS安全组介绍

#### 3.3.1 什么是安全组

安全组是一种虚拟防火墙，能够控制ECS实例的出入站流量。可以将具有相同安全需求并相互信任的ECS实例放入相同的安全组，以划分安全域，保障云上资源的安全。

创建ECS实例时，您需要指定一个或多个安全组。ECS 实例关联的多个安全组的规则将按固定的策略排序，共同决定是否放行实例出入站的流量。

![[d514fac544.png]]

例如图所示，专有网络VPC包含 ECS 1和 ECS 2，两个ECS的主网卡都关联安全组1。假设安全组1是普通安全组，组内连通策略默认为组内互通，那么ECS 1和 ECS 2的内网是互通的，这种互通策略不受您配置的自定义规则的影响。ECS 1和 ECS 2的其他出入方向流量受到安全组1的自定义规则控制。根据安全组1的入方向规则，使用任意IP都可以ping通安全组1内ECS 1和 ECS 2，安全组1未配置出方向规则，默认允许所有出方向的流量。

#### 3.3.2 使用安全组

在创建ECS实例时，如果还未创建过安全组，阿里云会创建一个默认安全组。如果希望ECS实例加入自定义安全组，可以手动创建安全组。

普通安全组的默认组内联通策略为**组内互通**，可修改组内联通策略。

- 1- 进入安全组界面

解决方案：可以通过配置环境变量

**环境变量** 是一组存储在操作系统中的键值对，用于配置系统和应用程序的运行时环境。

如何配置呢？

- 仅对当前用户（用户级别）： 修改 `~/.bashrc`文件
- 对所有用户有效（系统级别）： 修改 /etc/profile 文件

修改系统环境变量，确保所有用户都可以加载到：

```
vi /etc/profile

进入命令行模式后， 输入G，切换到文件底部,然后输入 o 在下一行插入内容

添加以下内容:
# 设置 JAVA_HOME 环境变量
export JAVA_HOME=/opt/jdk1.8.0_241

# 设置 PATH 环境变量，方便在命令行使用 java 命令
export PATH=$JAVA_HOME/bin:$PATH

# 设置 CLASSPATH 环境变量（可选）
export CLASSPATH=$JAVA_HOME/lib:$CLASSPATH

修改后,保存退出 
esc -> :x

重新加载配置信息，让其生效：
source /etc/profile

说明：source 命令会读取并执行指定文件中的命令，因此在执行 source 时，文件中的环境变量或命令就会被当前 shell 会话所执行，并立即生效
```

#### 4.4.7 Nginx服务搭建【node1】

Nginx: Nginx（发音为“Engine-X”）是一款高性能的**Web服务器**和**反向代理服务器, 在此处主要提供二个功能:**

- 1- 高性能能力: Nginx可以处理5w ~ 10w个并发连接
- 2- 请求转发能力: 通过Nginx将访问目标服务的请求转发给WEB服务器,由WEB服务器处理具体的请求资源

![[1899ef9e54.png]]


- 3- 开放防火墙

- 本地服务器

```

firewall-cmd --zone=public --add-port=443/tcp --permanent

# 重新加载规则信息
firewall-cmd --reload

# 查看规则信息

```

#### 4.4.8 Nginx请求转发能力配置

请求转发能力(反向代理): 通过Nginx将访问目标服务的请求转发给WEB服务器,由WEB服务器处理具体的请求资源

![[8e82e676f0.png]]

如何配置呢?

- 1- 修改Nginx的配置文件

```
vim /etc/nginx/nginx.conf

添加以下内容:
location / {
    proxy_pass http://node2.itcast.cn:8080/;
}
```

![[29f281e270.png]]

- 2- Nginx重新加载配置文件

```
两种思路:
1- 重启Nginx服务器: 
systemctl restart nginx

2- 使用Nginx自带的重新加载配置的命令 【推荐】
nginx -s reload
```

![[a162986726.png]]

- 3- 刷新浏览器:

- 浏览器访问: http://nginx服务器的IP地址:80

![[e0c68fb742.png]]

小问题： 设置后， 依然无法访问到博客系统， 一直显示的都是nginx的测试页面

```
原因说明：
    在确认配置没有问题， 并且也执行了  nginx -s reload 重新加载配置命令后 ，可以尝试将浏览器的缓存清理掉，快捷键： ctrl+shift+delete 清理， 如果快捷键无效， 选择浏览器设置-->删除浏览器记录信息相关选项【不同的浏览器略有差异】
```

当访问成功后，此时tomcat的8080端口就不需要进行放行了， 需要在安全组中将其剔除
