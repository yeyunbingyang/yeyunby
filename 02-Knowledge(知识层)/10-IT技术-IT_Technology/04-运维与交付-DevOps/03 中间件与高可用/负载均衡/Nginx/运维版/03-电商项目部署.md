# 一、NiuShop商城

##   
1、NiuShop电商项目概述

NiuShop是基于PHP语言开发的一款开源的电子商城系统，这个系统的运行需要LAMP/LNMP支持。  
Niushop系统是应用ThinkPHP框架开发的完善的电商系统，拥有完善的商品机制，包含普通商品、虚拟商品，同时完善了虚拟商品的核销机制，营销活动支持拼团、分销、多门店砍价等新时代的商业模式，配送方式支持物流配送、门店自提、本地配送，整合了当前电商系统的各种营销以及商业方案，同时支持插件开发，系统完善，成为新时代开源商城的首选。

功能特点：

- 商品功能：支持普通商品、虚拟商品
- 核销功能：支持自提核销、虚拟二维码核销功能
- 营销活动：支持拼团、积分兑换、分销功能
- 配送方式：物流配送、门店自提、本地配送
- 多门店：支持门店商品、收银台功能
- 页面装修：支持平台与店铺手机端自定义页面设计
- uniapp开发：采用一端开发多端使用的uniapp开发机制，可灵活编译

## 3、宝塔面板管理命令

启动宝塔：

```
/etc/init.d/bt start
```

停止宝塔：

```
/etc/init.d/bt stop
```

重启宝塔：

```
/etc/init.d/bt restart
```

检查状态：

```
/etc/init.d/bt status
```

升级宝塔：

```
bt update
# 或
bt update <版本号>
```

卸载宝塔：

```
/etc/init.d/bt stop && rm -rf /www/server/panel && rm -f /etc/init.d/bt
```

宝塔管理：

```
bt
```

输入bt后，会显示一个交互式菜单，可用于执行常见操作，如查看面板状态、修改面板端口、重置面板密码。

服务管理

Nginx：

```
# 启动 Nginx
/etc/init.d/nginx start
# 停止 Nginx
/etc/init.d/nginx stop
# 重启 Nginx
/etc/init.d/nginx restart
# 测试 Nginx 配置是否正确
nginx -t
```

MySQL：

```
# 启动 MySQL
/etc/init.d/mysqld start
# 停止 MySQL
/etc/init.d/mysqld stop
# 重启 MySQL
/etc/init.d/mysqld restart
```

PHP（以PHP7.4为例）：

```
# 重启 PHP 服务
/etc/init.d/php-fpm-7.4 restart
# 检查 PHP-FPM 状态
/etc/init.d/php-fpm-7.4 status
```

数据管理：

```
# 查看面板默认用户名或密码
bt default
# 修改面板访问端口（如改为8888）
bt 8
# 重置面板管理员密码
bt 5
```

日志查看：

```
# 查看网站访问日志（以 example.com 为例）
cat /www/wwwlogs/example.com.log
# MySQL错误日志
cat /www/server/data/mysql.err
# PHP错误日志（以PHP7.4为例）
cat /www/server/php/74/var/log/php-fpm.log
```

项目目录：

```
# 网站文件目录
cd /www/wwwroot/
# 数据文件目录
cd /www/server/data/
```

配置防火墙开放面板端口：

```
# CentOS 防火墙
firewall-cmd --zone=public --add-port=8888/tcp --permanent
firewall-cmd --reload
# Ubuntu 防火墙
ufw allow 8888
ufw reload
```

搭建环境时可以考虑暂时关闭防火墙：

```
systemctl stop firewalld
systemctl disable firewalld
```

原因：因为NiuShop电商平台设置了一个伪静态技术（rewrite）[https://www.kancloud.cn/niucloud/niushop_b2c_v5/3037621](https://www.kancloud.cn/niucloud/niushop_b2c_v5/3037621)

![[ecd9dec541.png]]

1. 后台伪静态设置：

```
location / {
    if (!-e $request_filename) {
        rewrite ^(.*)$ /index.php/$1 last;
        break;
    }
}
```

解析：

- `location /`：匹配任意请求
- `if (!-e $request_filename)`：判断请求的页面是否存在（`-e` 表示 exists，`$request_filename` 对应 `/shop/index/index.html`）
- `rewrite ^(.*)$ /index.php/$1 last;`：重写 URL，将旧链接重定向到新链接 `/index.php/shop/index/index.html`，`last` 表示重写后继续匹配新的 location

1. H5 页面伪静态设置：

```
location /h5 {
    if (!-e $request_filename) {
        rewrite ^/(.*) /h5/index.html last;
        break;
    }
}
```

解析：

- `location /h5`：匹配所有 URL 中包含 `/h5` 的请求
- `if (!-e $request_filename)`：如果访问的手机端页面不存在
- `rewrite ^/(.*) /h5/index.html last;`：将请求重写到 `/h5/index.html` 页面

小结：

安装时，需要绑定数据库，数据库信息可以在宝塔面板中获取

安装完成后可能没办法实时访问，需要设置伪静态（网站后台）+（H5）
