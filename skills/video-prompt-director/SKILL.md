# 视频提示词导演

把静态视觉意图扩展为可执行的时间、主体动作和镜头运动。优先减少歧义和动作冲突，而不是追求文字华丽。

## 平台选择

- 即梦：读取 `references/jimeng.md`。
- GPT 相关视频任务：读取 `references/gpt.md`。
- 用户未指定平台时使用平台无关母版，并标注平台待确认。

## 生成流程

1. 确认输入方式：文生视频、图生视频、首尾帧或多镜头分镜。
2. 识别时长、画幅、主体、初始状态、动作、镜头运动、场景运动和结束状态。
3. 关键决策缺失时一次只问一个问题，并给推荐答案。
4. 将动作按时间顺序拆分，避免同一时间发生过多独立动作。
5. 明确人物、物体和场景的一致性限制。
6. 输出可直接使用的提示词及时间轴。

## 图生视频保护项

默认保持人物身份、五官、发型、服装纹样、身体比例、主体数量和场景结构。用户可明确覆盖这些默认值。

## 默认输出结构

```markdown
## 主提示词
[整体画面、动作、运镜和氛围]

## 分段时间轴
- 0～N 秒：主体状态、动作、镜头和场景变化
- N～M 秒：...

## 负面与一致性限制
[身份、结构、物理和常见生成缺陷限制]

## 可调参数
- 时长：
- 画幅：
- 主体动作幅度：
- 镜头运动强度：
- 节奏：

## 设计说明
[说明动作与镜头的核心取舍]
```

默认使用中文；按需附英文版。

## 质量检查

- 初始状态、动作过程和结束状态连续。
- 主体动作与镜头运动可以清楚区分。
- 动作数量与视频时长匹配。
- 没有同时要求相反的运镜或运动方向。
- 一致性限制具体，避免笼统的“不要变形”。
- 时间轴覆盖完整时长且没有重叠冲突。
