# 图片提示词模板学习日志

记录每次已确认的模板学习结果，让模板的新增、修改、晋升、降级和归档都有依据。这里保存变化摘要，不复制完整提示词。

## 记录规则

- 只记录用户已经确认写入的变化。
- 单纯检索但没有新价值时，可记录“无新增”；无需修改稳定模板库。
- 没有实际生成结果时标记“待反馈”，不计入成功复用。
- 每条记录引用模板 ID 和知识库来源。

## 日志格式

```markdown
### YYYY-MM-DD｜[任务简称]

- 模板 ID：
- 使用平台/模型：
- 动作：无新增 / 新增候选 / 更新证据 / 修改模板 / 晋升稳定 / 降级改进 / 归档
- 生成结果：待反馈 / 成功 / 部分成功 / 失败
- 符合预期：
- 主要偏差：
- 最终采用版本：
- 知识库来源：[[笔记名#章节]]
- 变更摘要：
- 确认依据：
```
