# 稳定图片提示词模板库

本文件保存经过复用验证的可执行模板骨架。知识库原笔记保存完整背景与案例，本文件只保存生成时需要的稳定结构、边界和验证记录。

## 状态说明

- `候选`：结构可复用，但尚未充分实测。
- `实测`：已有真实结果，仍需更多任务验证。
- `稳定`：满足晋升条件，可作为默认首选。
- `改进`：近期失败或平台变化，需要修订。
- `归档`：已被替代，保留历史依据。
