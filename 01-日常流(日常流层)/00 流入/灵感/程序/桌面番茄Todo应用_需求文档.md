## 一、产品概述

### 1.1 产品定位

一款基于番茄工作法的桌面端任务管理与效率工具，将移动端番茄ToDo的核心体验移植到桌面环境，针对桌面工作场景优化交互与功能。支持多种任务完成模式（倒计时、正计时、量词目标、纯打卡）和记忆复习模式，具备智能延期规划能力。

### 1.2 目标用户

- 学生、职场人士、自由职业者
- 需要长时间在电脑前专注工作的用户
- 希望建立系统化任务管理习惯的用户
- 有记忆类学习任务（背单词、考证等）的用户

### 1.3 核心设计理念

> **"规划 → 专注 → 记录 → 分析 → 优化"** 的闭环时间管理

- **极简设计**：界面简洁美观、操作逻辑清晰、学习成本为零
- **灵活适配**：四种完成模式覆盖不同工作流
- **智能辅助**：记忆曲线自动规划、延期智能重排
- **数据驱动**：多维度统计帮助持续改进

### 1.4 参考产品

- 番茄ToDo App（核心功能参考）
- Anki（记忆复习算法参考）
- Todoist（任务管理参考）

## 三、模块1：目标任务管理（待办集）

### 3.1 功能概述

建立结构化的任务库，支持多层级任务组织。采用"待办集"概念，将任务按项目/主题归类。

### 3.2 任务类型定义

| 任务类型 | 定义 | 示例 |
|---------|------|------|
| **长期任务（每日重复）** | 每天都需要执行的习惯性任务 | 每日阅读30分钟、每日代码练习 |
| **短期任务（指定日期）** | 在特定日期范围内需要完成的任务 | 7月15日前完成报告、本周内复习完第三章 |
| **一次性任务** | 单次执行，完成后归档 | 购买显示器、预约体检 |

### 3.3 任务属性

```
任务实体：
├── 基础信息
│   ├── 任务ID (唯一标识)
│   ├── 任务名称
│   ├── 任务描述/备注
│   ├── 所属待办集 (分类)
│   └── 优先级 (高/中/低)
├── 时间属性
│   ├── 任务类型 (长期/短期/一次性)
│   ├── 创建日期
│   ├── 开始日期
│   ├── 截止日期 (DDL)
│   ├── 计划总时长 (预估番茄数 × 番茄时长)
│   └── 重复规则 (仅长期任务: 每日/工作日/自定义)
├── 进度属性
│   ├── 状态 (未开始/进行中/已完成/已归档/已逾期)
│   ├── 已完成番茄数
│   ├── 实际投入时长
│   └── 完成日期
└── 关联属性
    ├── 标签 (可多个: 工作/学习/生活)
    └── 父任务ID (支持子任务拆分)
```

### 3.4 待办集（任务分类）管理

- **创建待办集**：自定义名称、选择图标/颜色、添加描述
- **待办集视图**：以卡片或列表形式展示各待办集及其包含任务
- **待办集统计**：显示该分类下任务总数、完成率、总专注时长
- **快捷操作**：拖拽任务至不同待办集、批量归档

### 3.5 界面要点

- 左侧导航栏：待办集列表（类似文件夹树）
- 主区域：当前选中待办集的任务列表
- 顶部工具栏：新建任务、筛选、排序、搜索

### 3.6 任务状态流转

```
未开始 → 进行中 → 已完成 → 已归档
   ↓        ↓
已逾期   已暂停
```

## 四、模块2：任务规划

### 4.1 核心设计理念

> 任务 = **内容** + **时间约束** + **完成模式**

| 维度 | 说明 |
|------|------|
| **时间约束** | 截止日期（硬截止）、计划日期（软安排） |
| **完成模式** | 倒计时、正计时、量词目标、纯打卡 |

### 4.2 截止日期 vs 计划日期

| 属性 | 截止日期 (Deadline) | 计划日期 (Schedule) |
|------|-------------------|-------------------|
| **性质** | 不可协商的最后期限 | 自己安排的执行时间 |
| **逾期处理** | 标记逾期，统计逾期率 | 自动顺延或手动调整 |
| **显示样式** | 红色警告、倒计时天数 | 日历上的普通安排 |
| **示例** | 7月20日交报告（老板定的） | 我计划7月18-19日写报告 |

### 4.3 四种完成模式

#### 4.3.1 模式A：倒计时模式（限时冲刺）

**适用场景：** 模拟考试、限时写作、专注冲刺、会议计时

```
任务示例：7月20日前完成《需求文档》撰写，每次专注45分钟

配置项：
├── 单次时长：45分钟（可自定义）
├── 循环次数：3次（完成3个倒计时周期）
├── 间隔休息：5分钟（每轮结束后自动提醒休息）
├── 总目标：3轮 × 45分钟 = 135分钟
└── 截止日期：2026-07-20 23:59
```

**界面表现：**
- 大数字倒计时显示（分:秒）
- 进度环：本轮剩余时间
- 总进度：已完成轮次 / 总轮次
- 时间到：全屏提醒 + 音效 + 可选自动开始休息

#### 4.3.2 模式B：正计时模式（记录用时）

**适用场景：** 开放式任务、不确定时长的任务、事后补录

```
任务示例：7月18日前完成代码重构，预计需要4小时

配置项：
├── 预估时长：4小时（仅作参考，可超时不打断）
├── 最小记录单位：1分钟
├── 自动暂停：空闲5分钟后提示是否暂停计时
└── 截止日期：2026-07-18 18:00
```

**界面表现：**
- 正向计时器（已用时间累计）
- 预估时长参考线
- 可随时暂停/继续
- 完成后显示"实际用时 vs 预估用时"对比

#### 4.3.3 模式C：量词目标模式（完成N个单位）

**适用场景：** 刷题、背单词、阅读章节、运动次数、喝水杯数

```
任务示例：7月25日前背完《GRE核心词汇》300个单词

配置项：
├── 总量：300个
├── 单次目标：50个/天（系统建议，可调整）
├── 计量单位：个/页/章/题/组/次/杯/公里...
├── 完成方式：
│   ├── 固定批次：每次完成50个，分6次完成
│   └── 自由进度：随时记录"今天背了30个"
└── 截止日期：2026-07-25
```

**计量单位词库：**

| 场景 | 单位选项 |
|------|---------|
| 学习 | 页、章、节、题、个、组、套 |
| 阅读 | 页、章、本、篇、分钟 |
| 运动 | 次、组、公里、米、分钟、卡路里 |
| 健康 | 杯、毫升、次、分钟 |
| 工作 | 个、封、页、条、小时 |
| 自定义 | 用户可输入任意单位 |

**界面表现：**
- 进度条：已完成 / 总量
- 今日进度：今日已完成 / 今日目标
- 快速记录："+10个" "+50个" 快捷按钮
- 历史记录：每次完成的数量和时间戳

#### 4.3.4 模式D：纯打卡模式（完成即OK）

**适用场景：** 简单日常习惯、无需计时的任务

```
任务示例：每天早起打卡、每日整理桌面

配置项：
├── 重复规则：每日 / 工作日 / 自定义周期
├── 提醒时间：08:00
├── 打卡方式：点击按钮 / 快捷键 / 系统托盘右键
└── 补卡规则：允许补昨天，不允许补更早
```

**界面表现：**
- 大按钮："打卡"（点击后变"已打卡 ✓"）
- 连续打卡天数显示
- 本月打卡日历（小方块显示打卡状态）

### 4.4 模式对比表

| 特性 | 倒计时 | 正计时 | 量词 | 纯打卡 |
|------|--------|--------|------|--------|
| 时间限制 | ✅ 严格限时 | ❌ 无限制 | ❌ 无限制 | ❌ 无限制 |
| 记录用时 | ✅ 精确 | ✅ 精确 | ❌ 不记录 | ❌ 不记录 |
| 进度追踪 | 轮次进度 | 时间进度 | 数量进度 | 完成状态 |
| 适用场景 | 限时任务 | 开放任务 | 计数任务 | 习惯打卡 |
| 打断处理 | 时间到自动停 | 可随时暂停 | 随时记录 | 即时完成 |

## 五、模块3：待办打卡（每日任务）

### 5.1 功能概述

每日实际执行层面的任务清单，结合番茄钟计时完成打卡。这是用户每天交互最频繁的模块。

### 5.2 每日待办列表

```
今日待办 (自动生成 + 手动添加)
├── 来自规划的任务 (按规划时间排序)
├── 临时添加的紧急任务
└── 每日重复任务 (长期任务自动展开)
```

### 5.3 番茄钟专注系统

#### 5.3.1 计时模式

| 模式 | 说明 | 适用场景 |
|------|------|---------|
| 标准番茄 | 25分钟工作 + 5分钟短休，4轮后15分钟长休 | 常规工作 |
| 自定义番茄 | 用户自定义工作/休息时长 | 灵活场景 |
| 正计时 | 无固定时长，记录实际用时 | 不确定时长的任务 |
| 目标时长 | 设定总目标时长，可分段完成 | 大型任务 |

#### 5.3.2 专注界面元素

- 全屏/窗口模式切换
- 翻页时钟显示（桌面端特色）
- 白噪音背景音（雨声、森林、咖啡厅等）
- 励志语录（专注页面显示）
- 进度可视化（环形进度条）
- 暂停/放弃/完成按钮

#### 5.3.3 桌面端特色功能

- **悬浮窗模式**：始终置顶的小计时器，不影响其他工作
- **系统托盘图标**：显示当前计时状态
- **快捷键**：快速开始/暂停/跳过（如 Ctrl+Shift+Space）
- **勿扰模式**：专注期间屏蔽系统通知（可选）

### 5.4 打卡机制

**完成打卡：**
- 番茄钟正常完成 → 自动打卡
- 手动标记完成（适用于非番茄任务）
- 完成时可填写"专注心得"或备注

**打卡记录：**
- 打卡时间戳
- 实际用时
- 完成质量自评（可选：1-5星）
- 中断原因（如被中断，可选填）

**连续打卡激励：**
- 连续打卡天数统计
- 成就徽章系统（如"7天连续打卡"、"100番茄达成"）

### 5.5 今日执行面板（四种模式统一入口）

```
┌─────────────────────────────────────────────────────────────┐
│  今日待办 (2026-07-15)                                       │
```

## 八、模块6：记忆复习模式

### 8.1 核心原理

基于艾宾浩斯遗忘曲线，在关键遗忘节点触发复习，将短期记忆转化为长期记忆。

```
记忆强度曲线
100% ┤●
 80% ┤  ╲
 60% ┤    ╲    ● 复习1后回升
 40% ┤      ╲    ╲
 20% ┤        ╲    ╲  ● 复习2后回升
  0% ┤          ╲    ╲    ╲
     └──────────────────────────→ 时间
      1天  2天  4天  7天  15天  30天
           ↑    ↑    ↑    ↑     ↑
         复习1 复习2 复习3 复习4  复习5
```

### 8.2 复习间隔算法

| 复习轮次 | 间隔时间 | 记忆保持率 | 状态标识 |
|---------|---------|-----------|---------|
| 第1次学习 | Day 0 | 100% | 🆕 新学 |
| 第1次复习 | +1天 | ~35% | 🔁 复习1 |
| 第2次复习 | +2天（距上次） | ~45% | 🔁 复习2 |
| 第3次复习 | +4天 | ~55% | 🔁 复习3 |
| 第4次复习 | +7天 | ~65% | 🔁 复习4 |
| 第5次复习 | +15天 | ~75% | 🔁 复习5 |
| 第6次复习 | +30天 | ~85% | ✅ 固化 |

**自定义间隔：** 用户可调整间隔系数（如"我记忆力好，间隔×1.5"）

**三种预设算法：**

| 算法 | 间隔序列 | 适用场景 |
|------|---------|---------|
| 标准间隔 | 1-2-4-7-15-30 | 通用学习 |
| 激进间隔 | 1-3-7-14-30-60 | 考前冲刺 |
| 保守间隔 | 1-1-2-3-7-15 | 难度内容 |

### 8.5 记忆难度反馈 → 动态调整间隔

| 用户反馈 | 记忆强度评估 | 下次间隔调整 | 算法说明 |
|---------|------------|------------|---------|

- 初始值：2.5
- 每次反馈调整：

  - 😕: -0.2
  - 😐: 不变
  - 😊: +0.1
- 最低不低于 1.3，防止间隔过短

## 九、模块7：意外情况处理（延期规划）

### 9.1 核心场景

> "计划永远赶不上变化" — 生病、紧急任务插入、状态不佳、临时出差...

### 9.2 延期类型与处理策略

| 意外类型 | 触发条件 | 系统处理 |
|---------|---------|---------|
| **主动延期** | 用户手动标记"今天完不成" | 弹出延期规划向导 |
| **被动延期** | 截止日期到达但未完成 | 自动标记逾期，提示处理 |
| **批量延期** | 用户选择"这几天都不做" | 智能重新分配后续任务 |
| **紧急插入** | 新增高优先级紧急任务 | 自动挤出低优先级任务时间 |
| **暂停任务** | 用户选择"暂时不做这个" | 冻结任务，保留进度，恢复时续接 |

### 9.4 智能重排算法

```
输入：
├── 逾期/延期任务列表
├── 任务优先级权重
├── 用户日历空闲时段
├── 用户历史工作效率数据（上午效率高？晚上效率高？）
└── 其他已规划任务（避免冲突）

处理：
Step 1: 计算每个延期任务的"紧急度分数"
        = 优先级权重 × 剩余工作量 / 距新截止日天数

Step 2: 识别空闲时段
        - 扫描未来30天日历
        - 标记已有安排的时间段
        - 识别连续空闲块

Step 3: 分配策略
        - 高优先级任务 → 用户高效时段（如上午）
        - 低优先级任务 → 碎片时间或低效时段
        - 大任务拆分 → 避免连续多天高强度
        - 预留缓冲 → 总时间的20%作为机动

Step 4: 冲突检测
        - 单日总工作量是否超过阈值（默认8小时）
        - 是否与其他截止日冲突
        - 是否连续高强度超过3天

Step 5: 生成方案 + 风险提醒

输出：优化后的日程安排
```

### 9.6 记忆任务的特殊延期处理

```
记忆任务延期规则：
├── 新学卡片延期
│   └── 今天没学新卡片 → 明天继续学，不追赶
│   └── 积压3天以上 → 提示"是否减少每日新学量？"
│
├── 复习卡片延期
│   └── 今天没复习 → 明天优先复习（不降低记忆效果）
│   └── 积压超过阈值（如>100张） → 提示"是否开启'仅复习 overdue'模式？"
│
└── 长期未复习卡片
    └── 间隔>60天 → 自动降级为"重新学习"（回到stage 0）
    └── 用户可手动标记"我记得"恢复原有间隔
```

## 十二、非功能性需求

### 12.1 性能要求

| 指标 | 要求 |
|------|------|
| 冷启动时间 | < 2秒 |
| 番茄钟计时精度 | 秒级，后台运行准确 |
| 数据加载 | 单页面数据 < 500ms |
| 搜索响应 | < 200ms |
| 日历渲染 | < 300ms（月视图） |

### 12.2 数据存储

- **本地优先**：SQLite 本地数据库，确保离线可用
- **云端同步**：可选账户系统，多设备数据同步
- **自动备份**：本地定时备份，防止数据丢失
- **导入导出**：支持 JSON/CSV 格式迁移

### 12.3 桌面端特性

- 系统托盘常驻，右键快速开始番茄钟
- 全局快捷键支持
- 多显示器适配
- 支持 Windows / macOS / Linux
- 悬浮窗始终置顶

### 12.4 提醒机制

- 番茄钟开始/结束系统通知
- 任务截止前提醒（可自定义提前时间）
- 每日待办未完成任务晚间提醒
- 记忆复习到期提醒

### 12.5 安全与隐私

- 本地数据加密存储
- 云端传输 HTTPS 加密
- 用户数据可完全导出/删除
