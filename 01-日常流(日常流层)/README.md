# 日常流层

每日记录、阶段规划、周复盘的时间维度容器。与 02-Knowledge（领域维度）互补，构成"时间 × 领域"的知识矩阵。

## 目录结构

```
01-日常流(日常流层)/
├── README.md              # ← 你在这里
├── 流入/                  # 新内容第一落点（原 01-Inbox），目标保持清空
│   ├── 灵感/              # 创意灵感收集
│   └── ...                # 其他待处理内容
├── 日记/                  # 每日笔记（按 YYYY-MM-DD 命名）
├── 周复盘/                # 每周回顾（按 YYYY-Wxx 命名）
└── 阶段规划/              # 学习阶段/项目阶段的计划与总结
```

## 四种笔记类型

| 类型 | 存放位置 | 频率 | 说明 |
|------|----------|------|------|
| **流入** | `流入/` | 随时 | 新内容、灵感、待整理碎片，目标每日清空 |
| **每日笔记** | `日记/` | 每天 | 当日输入输出、学习记录、待整理内容 |
| **周复盘** | `周复盘/` | 每周 | 一周回顾、流入清空检查、下周计划 |
| **阶段规划** | `阶段规划/` | 按需 | 学习阶段/项目阶段的目标、里程碑与进度追踪 |

## 工作流

```
流入/（刚到未处理）
  ↓ 每日整理
日记/（今天做了什么、学到了什么）
  ↓ 每周提炼
周复盘（检查流入清空、知识迁移）
  ↓ 沉淀
02-Knowledge(知识层)（可复用的知识结论）
```

## 使用规则

- `流入/` 的目标是每天清空——内容要么当天处理，要么移入对应目录
- 每日笔记重点记录"今天学到了什么"，不追求完整
- 每日笔记末尾的"待整理"条目，是次日整理流入的输入
- 阶段规划在开始一个学习模块或项目前创建，结束时写总结
- 周复盘是固定的检查点，与清空规则联动
