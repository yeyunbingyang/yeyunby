# 模板说明

知识库共有 6 种模板，按使用场景分类。使用 Obsidian 的 Templater 插件自动插入（快捷键 `Alt+E` 或命令面板搜索 "Templater"）。

## 模板速查

| 模板 | 文件名 | 适用场景 | 核心产出 |
|------|--------|---------|---------|
| **知识笔记** | [知识笔记-模板](知识笔记-模板.md) | 记录技术概念、方法论、SOP | 可复用的知识结论 |
| **读书笔记** | [读书笔记-模板](读书笔记-模板.md) | 阅读书籍后的系统梳理 | 核心观点 + 行动启发 |
| **项目笔记** | [项目笔记-模板](项目笔记-模板.md) | 追踪项目进展和里程碑 | 任务清单 + 进展记录 |
| **日记** | [日记-模板](00-System(支撑层)/Templates/日记-模板.md) | 每日记录、复盘和规划 | 三件事 + KPT 复盘 |
| **资源条目** | [资源条目-模板](资源条目-模板.md) | 收藏工具、课程、网站 | 用途 + 适用场景 |
| **MOC** | [MOC模板](MOC模板.md) | 创建领域导航页 | 笔记索引 + 关键问题 |

## 选择指南

```
要写什么？
├─ 技术概念 / 方法论 / SOP → 知识笔记-模板
├─ 读完了一本书 → 读书笔记-模板
├─ 启动一个项目 → 项目笔记-模板
├─ 每日记录 / 复盘 → 日记-模板
├─ 收藏工具/课程/网站 → 资源条目-模板
└─ 创建领域导航页 → MOC模板
```

## 模板使用规范

1. **所有模板含 Templater 占位符**（`<% tp.date.now(...) %>`），插入时自动填充当前日期
2. 必填字段：`title`、`summary`、`status`、`created`
3. 所有笔记创建后，**立即填写 `summary`**（一句话核心结论）
4. 模板文件本身不参与日常检索，`tags` 含 `模板` 标签识别
