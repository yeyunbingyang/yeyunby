# 标签系统

标签用于补充 frontmatter `domain` 无法覆盖的交叉维度，辅助跨域检索。

## 内容类型标签

| 标签 | 含义 |
|------|------|
| `MOC` | 地图笔记，领域导航页 |
| `SOP` | 标准操作流程，可复用步骤 |
| `框架` | 思维框架或分析方法 |
| `概念` | 单一概念的深度解释 |
| `案例` | 真实案例分析或复盘 |
| `工具` | 具体工具的使用说明 |
| `读书笔记` | 书籍阅读笔记 |

## 状态辅助标签

| 标签 | 含义 |
|------|------|
| `待整理` | 内容存在但结构混乱，需整理 |
| `待验证` | 结论存疑，需进一步确认 |
| `归档` | 已过时或已封存，配合 status:归档 使用 |

## 跨域主题标签

| 标签 | 含义 |
|------|------|
| `AI` | 与 AI 相关（跨技术与创作域） |
| `效率` | 提升工作/学习效率相关 |
| `系统思维` | 系统思维相关（跨认知与能力域） |

## 使用规则

1. 每条笔记标签数量控制在 **1-4 个**，过多标签等于没有标签
2. `domain` 字段处理归属，`tags` 只处理**补充维度**
3. 不用标签替代文件夹（不用 `#IT技术` 作为领域标签）
4. 新增标签前先查此文档，避免同义词重复（如 `框架` 和 `方法论`）
