# 命名规范

## 基本原则

- 使用中文命名，允许英文专有名词
- 不使用空格，用 `-` 连接多词（例：`Docker-部署流程`）
- 不用日期作为文件名前缀（日期放 frontmatter）
- 名称描述**内容本身**，不描述类型（不用"笔记"、"文档"结尾）

## 知识笔记命名

格式：`{编号前缀}-{主题}.md`

编号前缀继承父文件夹的编号层级，用 `.` 分隔：

```markdown
10.04.01.01-Docker-Compose-部署流程.md      # 10=IT技术域, 04=运维云原生, 01=笔记序号
10.02.01.01.01.01-基础.md                   # 10=IT技术, 02=后端开发, 01=python, ...
20.00.00.01-AI概念全览.md                   # 20=核心能力, 00=AI域, 00=概念, 01=笔记序号
30.03.01-复盘指南.md                        # 30=认知层, 03=学习方法论, 01=笔记序号
```

规则：
- 从笔记所在子域开始，逐层向上提取所有带 2 位数字前缀（后跟 `-` 或空格）的文件夹编号
- 最末段为笔记在同一文件夹内的序号（01/02/03...），按主题逻辑排序手动分配
- 不带数字前缀的文件夹（如 `Git版本控制`）不产生编号段
- 文件名中原有前置数字（如 `01 基础.md` 中的 `01`）被新编号替代
- 文件名中的空格替换为中划线 `-`
- MOC 文件（`-MOC.md`）不参与编号，保持独立命名便于识别

## MOC 文件命名

格式：`领域名-MOC.md`

```
IT_Technology-MOC.md
Cognition-MOC.md
Core_Ability-MOC.md
```

## 模板文件命名

格式：`类型-模板.md`

```
知识笔记-模板.md
读书笔记-模板.md
项目笔记-模板.md
```

## 文件夹命名

格式：`编号-中文名-English`（顶级目录）

```
03-Knowledge/
10-IT技术-IT_Technology/
20-核心能力-Core_Ability/
30-认知层-Cognition/
06-Archive/
```

## 禁止事项

- 禁止使用特殊字符（`/`、`\`、`:`、`*`、`?`、`"`、`<`、`>`、`|`）
- 禁止中英文混用不一致（同类文件统一中文或英文）
- 禁止过长名称（超过 60 字符的名称需简化）
