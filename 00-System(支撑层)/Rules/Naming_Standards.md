# 命名规范

## 基本原则

- 使用中文命名，允许英文专有名词
- 不使用空格，用 `-` 连接多词（例：`Docker-部署流程`）
- 不用日期作为文件名前缀（日期放 frontmatter）
- 名称描述**内容本身**，不描述类型（不用"笔记"、"文档"结尾）

## 知识笔记命名

格式：`{序号}-{主题}.md`

同一文件夹内的笔记按 01/02/03... 顺序编号，按主题逻辑排序手动分配：

```
01-Docker-Compose-部署流程.md
01-SSH服务.md
02-GitHub与GitLab.md
01-基础.md
02-Python编码规范.md
```

规则：
- 序号为 2 位数字，同一文件夹内从 01 开始递增
- 新建笔记插入时允许调整同文件夹内其他笔记的序号
- 文件名中的空格替换为中划线 `-`
- MOC 文件（`-MOC.md`）不参与编号，保持独立命名便于识别

## MOC 文件命名

格式：`领域名-MOC.md`

```
IT_Technology-MOC.md
Cognition-MOC.md
Core_Ability-MOC.md
```

## 模板文件命名

格式：`类型-模板.md`

```
知识笔记-模板.md
读书笔记-模板.md
项目笔记-模板.md
```

## 文件夹命名

格式：`编号-中文名-English`（顶级目录）

```text
02-Knowledge/
10-IT技术-IT_Technology/
20-核心能力-Core_Ability/
```

## 禁止事项

- 禁止使用特殊字符（`/`、`\`、`:`、`*`、`?`、`"`、`<`、`>`、`|`）
- 禁止中英文混用不一致（同类文件统一中文或英文）
- 禁止过长名称（超过 60 字符的名称需简化）
