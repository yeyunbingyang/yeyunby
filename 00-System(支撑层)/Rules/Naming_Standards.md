# 命名规范

## 基本原则

- 使用中文命名，允许英文专有名词
- 不使用空格，用 `-` 连接多词（例：`Docker-部署流程`）
- 不用日期作为文件名前缀（日期放 frontmatter）
- 名称描述**内容本身**，不描述类型（不用"笔记"、"文档"结尾）

## 知识笔记命名

格式：`主题-子主题`（可选）

```
Docker-Compose-部署流程.md
认知偏差-确认偏误.md
结构化表达-金字塔原理.md
```

## MOC 文件命名

格式：`领域名-MOC.md`

```
IT_Technology-MOC.md
Cognition-MOC.md
Core_Ability-MOC.md
```

## 模板文件命名

格式：`类型-模板.md`

```
知识笔记-模板.md
读书笔记-模板.md
项目笔记-模板.md
```

## 文件夹命名

格式：`编号-中文名-English`（顶级目录）

```
03-Knowledge/
10-IT技术-IT_Technology/
20-认知层-Cognition/
30-核心能力-Core_Ability/
06-Archive/
```

## 禁止事项

- 禁止使用特殊字符（`/`、`\`、`:`、`*`、`?`、`"`、`<`、`>`、`|`）
- 禁止中英文混用不一致（同类文件统一中文或英文）
- 禁止过长名称（超过 40 字符的名称需简化）
