# 归档库

封存层，用于存放已归档的笔记，避免文档丢失。

**核心原则：存而不用，查而不改。**

## 什么应该放入这里

- `status: 归档` 的笔记
- 被更完整版本替代的旧笔记
- 重构前的旧结构文件（如本次优化前的旧7域 MOC 骨架）
- 超过 6 个月未更新且已无价值的草稿

## 什么不应该放入这里

- 仍在使用的笔记（即使更新频率低）
- 资源索引（放 `04-Resources`）
- 临时草稿（还没判断价值的放 `01-Inbox`）

## 归档操作

1. 修改笔记 frontmatter：`status: 归档`
2. 将文件移动到 `06-Archive/`（按原域名建子文件夹，便于溯源）
3. 如有其他笔记引用，在原位置留重定向说明

## 建议子目录结构

```
06-Archive/
├── IT_Technology/    # 归档的IT笔记
├── Cognition/        # 归档的认知层笔记
├── Core_Ability/     # 归档的核心能力笔记
└── Legacy/           # 旧结构文件、系统文档历史版本
```
