# 趋势层 MOC

本层追踪外部技术信息流——月度/年度动态、开源项目排行、新兴技术信号。目标不是囤积信息，而是**定期筛选提炼**，将高价值发现转入 [[IT技术-MOC|知识层]]。

## 子域导航

| 子域 | 内容 | 更新频率 |
|------|------|----------|
| [[01-月趋势]] | 月度技术动态、版本发布、模型进展、行业新闻 | 每月 |
| [[02-年趋势]] | State of JS/CS 等年度报告、技术生态年终回顾 | 每年 |
| [[03-GitHub排行]] | 项目 Star 排行、GitHub Trending 精选、开源热点 | 每月 |
| [[04-技术雷达]] | 值得关注的新工具/框架、试用记录与初步评估 | 按需 |

## 工作流

1. 外部资讯 → 直接录入对应子域
2. 每月回顾，筛选高价值条目
3. 值得深挖的 → 提炼为知识笔记放入 [[IT技术-MOC|03-Knowledge]]
4. 纯时效资讯 → 保留或归档
